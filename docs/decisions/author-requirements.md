## AR-01 武学数量比例：天:地:玄:黄 = 1:3:9:9

- **原文**：天地玄黄 武功数量比例应该是 1:3:9:27 的关系。追问后作者定："这样的话，黄不要这么多，黄差不多跟玄一个量就行。"
- **解读与默认值**：
  - 天级仍为基准 §13 的封闭名录（51 门，**不新增**）；地 ≈ 3 × 天 ≈ 153；玄 ≈ 9 × 天 ≈ 459；黄 ≈ 玄 ≈ 459。全部图鉴合计约 **1,100–1,150 门**（替代 C14 的 520 / 650–700 两个方案）。
  - 每个图鉴内部也按 天:地:玄:黄 ≈ 1:3:9:9 配比（以本图鉴分得的天级门数为基数，允许 ±15%）。天级为 0–1 门的图鉴（general、kangxi 等）：总量按 `rulings-v1.md` 分工表目标 × 1.5 取整，并保持 地:玄:黄 ≈ 1:3:3。
  - **词条详略分级**：天、地阶完整条目卡；玄阶紧凑卡；黄阶一行表格条目（ID、名称、门派 / 来源、类别、原生书界、核心效果、前置、出处或（原创扩展））。黄阶允许大量"门派基础招、通用杂学、地方变体、民间粗浅版"。
  - 各书界"可习得池"的品阶占比（`design/05` §14.4）与获取难度同步：天级最稀有。
- **归属与影响**：`design/05` §14（任务 C3 重定）；新图鉴 C1a–f 起草即按此；已有 4 个图鉴由 CXs/CXw/CXd/CXx 扩充；`rulings-v1.md` 图鉴分工表中的数量以本条为准。

## AR-03 冲穴系统（穴道、经脉、周天）

- **原文**：增加冲穴系统（参考最好玩的几种武侠游戏），冲穴内劲由内功提供，越强的内功冲穴越快。每个穴道提供不同加成，一条脉络贯通以后有 combo 属性加成，一次贯通为一个周天，最多可以九个周天（如果周天定义不对，按照中国文化纠正一下）。
- **术语校正**（按传统内丹术 / 中医说法；作者已授权纠正）：
  - 穴道（`ap_*`）挂在经脉上；经脉取**十二正经 + 奇经八脉**（20 条，`mer_*`），游戏用穴道为其子集（默认每脉 6–12 穴，合计约 150–200 穴，穴名用真实穴位名）。
  - "一条脉络贯通" = **通脉**；任、督二脉贯通 = **小周天**；奇经八脉全通 = **大周天**；十二正经全通 = **十二经周流**。
  - "最多九个周天"改用 **九转**（取"九转还丹"之义）：大周天之后进入"周天运转"的九个层次（第一转 … 第九转），每一转对全部已通穴道的加成整体放大并解锁新被动；第九转为上限。
- **规则要点（默认值，归属文档细化）**：
  - 冲穴消耗"内劲"：由主运内功（品阶、层数、`mpMax`、阴阳相性、辅运贡献）折算为冲穴速率；高品阶内功冲得快；调和内功对任何穴道无相性惩罚。
  - 每个穴道给固定小加成（属性、抗性、恢复、技艺、轻功等，用 `design/03` 的属性 ID）；一条经脉全通给该脉的 combo 加成；小周天 / 大周天 / 十二经周流 / 各转给全局加成与被动。全部加成不得越过 03 / 04 的属性与乘区上限。
  - 冲穴进度、周天与转数**跨书界保留**（基准 §3"永久增益跨书界保留"）；被压制时冲穴速率按显示等级折算。
  - 冲穴有失败 / 走火风险，与 05 走火入魔三级衔接；丹药（10）、师父（12）、天书之力（13）可辅助。
  - 参考作品只做机制参照、不抄数值：《金庸群侠传》系列 mod 的经脉 / 穴道、《武林群侠传》/《侠客风云传》、《太吾绘卷》、《河洛群侠传》。
- **归属与影响**：新文档 `docs/design/15-meridians-and-acupoints.md`（任务 M1，含审校）；03（属性接口）、05（内功 → 内劲、专精经脉字段）、06（加成用 Buff 原语表达）、13（成长预算与多周目保留）、14（冲穴界面）、tech/04 / 05（schema 与运行时）。

- **原文**：用统一大地图，但按时代给予不同的入口和状态。地图要包括按照对应历史的重要城市。
- **作者确认的解读**：全作共用**一张中国江湖大地图**（区域 `rg_*`、城市 `city_*`、山川、门派驻地共享全局 ID）；每个书界 = 一个**时代图层**，决定：哪些入口 / 区域开放、各区域与城市的势力 / NPC / 门派 / 资源点 / 营生场所状态、城市在该时代的名称与地位。
- **历史城市**：按各书界对应的朝代收录当时的重要城市（都城、陪都、重镇、商埠、边关），用当时的名称并注明今名，考据不确定的标（待考）。示例（各书界文档定稿）：天龙（北宋 / 大理 / 辽 / 西夏 / 吐蕃）汴梁、大理、上京、兴庆、大同、雁门关；射雕 / 神雕（南宋 / 金 / 蒙古）临安、中都（燕京）、襄阳、和林、大都；倚天（元末）大都、应天、光明顶所在昆仑；笑傲 / 碧血（明）北京、南京、福州、杭州、华山、衡山；鹿鼎（清初）北京、扬州、昆明、台湾、雅克萨；连城 / 白马 / 鸳鸯（清）荆州、高昌故地、晋中；书剑 / 飞狐 / 雪山（清乾隆）北京、杭州、回疆诸城、佛山、长白山。

## AR-06 城市营生：赌场 / 镖局 / 山庄

- **原文**：各个城市有赌场 / 镖局 / 山庄，可以按照武艺当行脚、教头或者客卿，有金钱回报。但不能在多个镖局 / 山庄当客卿。
- **解读与默认值**：每座城市有若干营生场所（`biz_*`）：赌场（赌博小游戏、消息、地下任务）、镖局（走镖任务链）、山庄（世家 / 庄园：护院、争斗、庄务）。玩家按武艺（等级、武学品阶、名望 / 品德检定）受聘为 **行脚**（低门槛、按次结算）、**教头**（中等门槛、按月）、**客卿**（高门槛、按月 + 资源 / 特殊任务）。**客卿职位全局唯一**：同一时间只能在一家镖局或山庄任客卿；教头 / 行脚可多处，但有日程冲突。报酬与 `design/12` 的经济曲线一致。
- **归属与影响**：16（营生主定义，任务 B7）；12（任务类型与 DSL、NPC）；11（场所随城市登记）；各书界文档列本时代的场所与职位。

## AR-07 门派层级与月钱

- **原文**：可以加入门派，修炼门派武功，从外门弟子、入门弟子、闭门弟子、长老、掌门等多个层级，每个层级可以获得月钱甚至资源。

- **归属与影响**：12（门派主定义，任务 B4）；16（月钱 / 资源表）；各图鉴（职级 → 可学武学）；各书界文档（本门派特例）。

## AR-09 NPC 与同伴系统（专项任务 N1）

- **原文**：用一个 traeX cli 的 agent 来进行 NPC 和同伴系统的设计和补全：NPC 都可成为同伴，但难度不一；有名 NPC 需要完成一定任务后才能加入；NPC 有生卒年概念；每进入一本书中的世界，是用长生诀进行沉睡后 X 年苏醒，如果之前的同伴依然健在，可以重新邀请加入。跨小说的 NPC 能力按照小说描写重新设定，如果加入队伍，则保留加入时的能力，并且新增能力 / 新增功力。先围绕故事主线梳理重要 NPC，其次是门派 NPC（结合小说和历史），然后按照每个城市的店铺、赌场、镖局等设施配置一般性 NPC，并最后增加一些路人甲 NPC。
- **解读与默认值**：
  - 新文档 `docs/design/18-npc-and-companions.md`（任务 N1，含审校，开联网核实史实人物）为 NPC 与同伴系统的唯一归属：招募难度分级、有名 NPC 的任务门槛、生卒年、跨书界同伴规则、NPC 分层名录（可拆到 `catalog/npcs-*.md`）。`design/12` 的"NPC / 队友"两节改为引用 18；09 保留战斗内的队友规则（上场 ≤ 6、合击、AI 人格）。
  - **人人可招募，难度分级**（默认 5 级）：D1 路人甲（好感 / 银两）；D2 设施 NPC（好感 + 小任务或雇佣）；D3 门派 NPC（门派职级 / 掌门许可 / 门派任务）；D4 有名 NPC（专属任务链 + 品德 / 声望 / 时机窗口）；D5 主线核心人物（主线关键幕后 + 原著线 / 改命线分支限定，部分时段不可招募；"永不可招募但可结盟"名单由 18 提议、作者定）。
  - **生卒年**：每个有名 NPC 记 `born` / `died`（史实人物用史实年份并给参考；小说人物按原著线索推算，标（推算）或（待考）；设施与路人 NPC 用年龄段）。书界年代（基准 §2）与生卒年共同决定 NPC 在各书界的存在、年龄段与能力段。
  - **长生诀与沉睡**：书眠的机制名为《长生诀》（基准术语"书眠"保留，A3 补注）：进入下一部 = 以长生诀沉睡 X 年后苏醒，X = 两书界年代之差（`design/02` 的年代表给出每次沉睡年数；年代不详的四部按 02 的安排取值）。主角沉睡期间不老。
  - **同伴跨书界**（**覆盖基准 §3"队友不跨书界"**，A3 合入）：曾加入队伍的同伴，在下一书界若仍健在（`died` > 苏醒年份，或原著明确在世），可在其所在地重新邀请加入（可经一段"重逢"任务）；重逢后的能力 = 离队时保存的能力 + 按新小说描写新增的能力 / 功力（只增不减：新增武学、层数、属性成长，按新书界的原著形象补齐）。未曾加入的跨书 NPC，能力按该书的原著描写重新设定。已故者只留传承 / 遗物 / 后人（原创扩展）。
  - 名录分层与撰写顺序：① 主线重要 NPC（14 书界，每部 20–40 人）；② 门派 NPC（按 `design/17` 的门派 × 时代，含史实人物）；③ 设施 NPC（每城的店铺、赌场、镖局、山庄、客栈等，按 `design/11` 城市表与 `design/16` 营生场所配置：模板 + 命名规则 + 各城实例表）；④ 路人甲（模板与随机生成规则）。
  - 队伍上场上限仍为 ≤ 6（基准 §8），随行但不上场的同伴留在据点 / 客栈。
