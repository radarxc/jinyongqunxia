- **鹿鼎记为谷底**（武运 30、等级上限 44），但洪安通是全书界最陡的难度峰值（Boss 局部难度 8）。
- 乾隆朝（书剑→飞狐→雪山）江湖小幅复兴，终章《雪山飞狐》以"劈与不劈"的抉择收束全作；终局另有一场不受天道压制的"天书守卷人"决战（见 `design/13-progression-and-endings.md`）。
- 表中参数为标准规则；自愿开启的天道劫与无天道沙盒仅按 §3 硬规则 11 覆盖，不改变十四书界顺序。

## 3. 境界规则（天道压制）

| 境界 | 入场携带核心武功 | 携带装备 | 外来武学/装备品阶压制 | 武功层数上限 | 书界等级上限范围 | 完整原生天级武学池（计数见 §13） | Boss 超限上限 |
|---|---|---|---|---|---|---|---|
| 高武 `HIGH` | 内功 3 / 拳脚 3 / 兵器 3 | 6 件 | 0 | 10 重 | ≤ 70 | 常见（每书界 6–18 部） | +3 级 |
| 中武 `MID` | 内功 2 / 拳脚 2 / 兵器 2 | 6 件 | −2 小品 | 9 重 | ≤ 60 | 孤本（每书界 1–6 部） | +4 级 |
| 低武 `LOW` | 内功 1 / 拳脚 1 / 兵器 1 | 6 件 | −4 小品 | 8 重 | ≤ 50 | 极罕（每书界 0–2 部） | +6 级 |

硬规则：
1. **核心武功**只包含三类：内功、拳脚（拳掌/指/腿/擒拿）、兵器（剑/刀/棍/枪/鞭/奇门）。轻功、暗器、杂学为非核心，**不可携带**（每个书界重新获得，保证开放世界的轻功门禁在每部都有意义）。
2. 携带武功的**真实层数保留、有效层数截断**：有效层数不超过 `min(trueLayer, 当前生效的书界层数上限, 修为门槛, 武学特殊上限)`，修为门槛按**绝对品阶**与显示等级判定；层数公式与来源修炼门槛见 `design/05` §3.3–3.4。真实层数达到书界层数上限后，新增修炼经验转为**积蕴**（折算、容量与释放见 `design/02` §2.4）；仅卡修为/来源门槛时按 `design/05` §3.3 暂存 `sxp`，不转积蕴。已学会的真实层数不折算、不扣除。招式解锁、威力与层数被动通常用有效层数；天书例外见规则 7，终局/沙盒见规则 10–11。携带装备可为任何品阶（包括天级）。
3. **外来压制**作用于经书眠或藏史带入、`nativeTo` 不等于当前书界的武功/装备；普通完整外来实例的有效品阶为 `max(1, absGrade − S)`，抵消例外见规则 7、9。本土合法习得（含按再遇途径忆起）、完整传承印证及同名原生装备器合可取得本土身份，不受品阶压制，仍受层数上限；残承来源限制优先按 §13 执行，**残承印证不改外来实例的 `nativeTo`**。强化、铭刻、藏史存入/取回本身均不改变归属，细则见 `design/02` §2.2–2.3、§5.7–5.8、§6.6。
4. 角色存在**真实等级**（1–70，只增不减）与通常的**显示等级** `min(真实等级, 当前书界等级上限)`（超限 Boss 例外见规则 8）；所有等级派生属性、等级需求、修为名及**修为突破分配点按显示等级生效**，被压低的分配记录保留（见 `design/03` §2.8）。主角真实等级达到或高于当前书界上限时，后续角色经验转为**修为余韵**，本书界不再升级；同次发放先补到上限、余量再转余韵，折算见 `design/13` §2.6–2.7。
5. 未携带的核心武功、所有非核心武功 → 转为**残篇**（记入武学图鉴；再次遇到时修炼加速；详见 `design/02`）。
6. **书眠生命周期**：金钱、普通物品、当前门派身份与公账、资源库存 / 资源点运行态、家丁合同、家业设施、营生职位、当前任务和活动同伴编组清除；里程碑事实可按归属文档保留。天书实物永久保留且不占装备携带额度，见 `design/13` §4.1。藏史仅依 `design/02` §6.6 寄存装备 / 史笺，不能借此携带秘籍等普通物品，装备额度见 §20。已学**学识**（丹方、菜谱、锻造图谱、铭文）、武学 / 物品图鉴与已授予的**永久增益**保留；永久增益不含依赖当前装配的武学被动，修为突破点仍按规则 4 生效。
   - 同一周目中，经脉状态 `opened`、未完成目标的 `progressH` / 尝试序号及 `turnCompleted` 原值跨书眠保留；轮回清空运行态，只保留账号历史最高转数且不据此恢复奖励。定义见 `design/15`。
   - 同伴保留招募史、关系 / 羁绊、生死事实和离队能力快照，但不保留活动编组、当界位置和装备。苏醒时仍健在且有该时代形态者可经重逢再次加入；能力以离队快照为下限，只合并后世新增能力 / 功力，仍受目标书界等级、品阶与层数压制。定义见 `design/18`。
   - `design/20` 的三卷残本、关键信物与传承源进度放入专用传承匣，作为普通物品清除规则的窄例外；书眠保留，轮回默认重置。
7. **天书之力抵消**：`S` 为当前境界原始品阶压制量（高/中/低武 0/2/4，难度覆盖先计算），`S_floor = ⌈S/2⌉`；天书与自创合算后的外来基础压制 `S_eff` 不低于此下限，本土/残承另按规则 3。抵消量按 `design/13` §4.5 的 `off_skill` / `off_equip` 分流，不把武学与装备抵消相加。仅 1 门本命可获**书界层数上限** +1，仍检查真实层数、修为门槛与武学特殊上限，至多 10 重；等级上限不可抵消。仅《天书现影》按 `design/13` §4.6 限次限时解除品阶压制、把书界层数上限设为 10；《天书微光》仍受品阶下限、不解层数封印，见 `design/13` §3.4.4。两者不改显示等级或修为门槛。`tsp_05_fate`“封印松动”仅对书界层数封印提供解锁例外，不抬有效层数、不绕过修为/来源要求，效果见 `design/13` §4.3；天书之力本身不受外来品阶压制。
8. **Boss 超限**只给每书界明确标记 `capExempt` 的至多 2 名 Boss：其显示等级为 `min(真实等级, 70, 书界等级上限 + 本表超限上限)`，以此计算属性、修为及 Z8，不得再被规则 4 截回普通上限；不放宽品阶与层数。例如洪安通真实 50 时显示 `min(50,70,44+6)=50`，倚天上限仍为 `min(70,70+3)=70`；具体战斗数值见 `design/02` §3.1、`design/09`。
9. **自创武学**（融会贯通）**（原创扩展）**，最高地上 9，携带与层数照常受限；外来压制基数取 `⌈S/2⌉`（中武 1、低武 2）。与适用的非负武学抵消量合算为 `S_eff = max(⌈S/2⌉, ⌈S/2⌉ − off_skill)`，即已经达到半额下限，天书不能再降低；普通外来实例对应 `max(⌈S/2⌉, S − off_kind)`（按武学/装备选对应抵消量）。限时全解仍只按规则 7，产物与修炼细则见 `design/05` §12。
10. **终局**：取得第十四本天书时真实等级补至 70；仍在雪山余韵期时显示等级仍为 58。正式进入终局容器后才关闭天道压制，等级上限 70、书界层数上限 10，残篇以历史最高层数临时回归（仍受真实层数及 §13 残承来源限制）；不新增第十五本天书。见 `design/13` §7.1、§7.3、§7.6。
11. **自愿规则例外**：天道劫 `tj_tiandao` 自天劫第 6 重起累积生效，仅把中/低武 `S` 改为 3/5，压制下限与自创基数相应为 `⌈3/2⌉=2`、`⌈5/2⌉=3`，高武不变；它是唯一调整正常难度压制数值的选项。另设无天道沙盒 `rule_wutiandao`，只关闭品阶压制、把书界层数上限设为 10，真实层数、角色等级、修为/来源及武学特殊上限不豁免；须新局主动选择，成就限制见 `design/13` §5.3–5.4；两者不同时启用。
12. **传承合成例外（⚠️ 待作者确认）**：`learnSource=legacy_synthesis` 的全本保留真实来源品阶，但当界有效品阶另受 `legacyWorldCap` 限制；天龙至侠客为 12，碧血、鹿鼎、连城、书剑、飞狐、雪山为 10，白马、鸳鸯为 9。该上限只作用于当界合成来源；进入后续书界后照普通外来规则计算，`rule_wutiandao` 关闭此专用上限。细则见 `design/20` §7.6。

## 8. 战斗模型（固定）

- **pointy-top 六角格战棋**：规则层使用轴坐标 `(q,r)`，`s=-q-r`；每格有高度 `h`（0–10 级台阶）与地形 `terrain`。斜 45° / 2:1 等距只描述相机与美术投影，不改变六邻接、六角距离或规则朝向。
- **就地开战**：以遭遇点为中心截取当前场景的连通六角格集合，`tileCount≤400`、`qSpan≤20`、`rSpan≤20`，地形与高度原样保留；旧“20×20”只保留约 400 格制作预算，不表示矩形拓扑。
- **朝向与范围**：规则朝向固定六个 `HexDir`；十二向只用于瞄准细分，不改变移动邻接。点、线、环、面、60° / 120° 扇形等范围模板唯一归 `design/09`；武功文档只引用模板 ID 与参数。
- **外放加持（AR-16 / AR-17）**：外放是 `MoveDef.projection:true` 的逐招事实，只适用于明确以真气催动离体指力、掌力、剑气、刀罡、掌风等的招式；不得按整门武学、招名、`ranged` 或旧伤害通道批量推断。大手印跃击形成的掌风算外放。普通乐声、喊声、传讯声不算；只有深厚内力驱动且能主动控制能量 / 方向的音功招才可标 `projection:true`，且音功 0 档按普通音波处理，不享外放专用 Z5M 或范围扩张，选择 1 / 2 档才启用外放加持。三档固定为标准 / 高 / 顶尖：射程增量 +0 / +2 / +4 格，作用范围取图鉴预审的基础 / +1 / +2 档，扩张另耗 0 / 2% / 4% `MPREF`；射程与范围绑定选档，玩家、敌人与召唤物同规。档位门槛、音功分支、点穴 / 堵塞降档与威力曲线见 `design/21` §4.4.1，格集合、遮挡、地形与选目标见 `design/09` §5。数值为 AR-16a 执行默认，⚠️ 待作者确认。
- **集气时间轴（CT）**：UI 显示 0→1000，每 tick 增加量 = `spd` 派生值；达到 1000 行动；行动后按招式“收招”值扣减。内部允许负值（下限 −1000）表示收招中，并保留跨阈值余量；推进细则见 `design/09` §3。
- **速度与首轮**：`Base_spd=72+0.30×agi+0.10×Ld+0.14×qinggong`；`spd=clamp(floor((Base_spd+Σflat)×max(0.2,1+Σpct)×Πmult),30,300)`。合法 STD 的 Lv1 / 35 / 70 结果为 `91/106/126`。战斗中的攻 / 防 / 轻功路线由 `design/21` 结算；轻功路线对 `openingQinggong`、基础 `spd` 与移动力给 6500–13500 bp 的有界修正，标准对标准为 10000 bp，完成质量只在综合 Profile 中兑现一次。先算经脉、后叠擒拿；首轮依修正后的 `openingQinggong → spd → agi → openingPriority → initiativeSideRank → unitIndex` 排序并冻结，其后进入 CT 事件驱动；`spd≤300`、有效收招 `recovery≥500`。具体速度曲线与投影算式只见 `design/21` §4.9。
- **移动力**：`tier=qgTier(qinggong)`，`withinTier=min(1,floor(max(0,qinggong-threshold[tier])/30))`，`baseMove=3+tier+withinTier`；再计轻功招式、Buff、重甲与疲惫，最终钳制 `[1,10]`。经脉速度投影只贡献一个 `[-2,+2]` 的有界增量，具体合成顺序与算式只见 `design/21` §4.9；地形成本在其后扣除。路径成本与接口见 `design/08`、`design/09`。
- **"回合"的定义**：Buff/冷却中的"回合"= **持有者自身的一次行动**。
- 每次行动：可移动一次 + 执行一个行动（招式 / 暗器 / 物品 / 运功调息 / 防御 / 待机，以及援护、撤退、口舌、俘获、看破、救护等），顺序自由；完整行动表见 `design/09` §4.7。
- **免费动作**不占行动、不耗集气、不推进 Buff/冷却回合：每次自身行动号令至多 1 次，明确标为免费动作的天书之力/书契技合计至多 1 次（耗行动的天书主动仍按 `design/13` §4.3 执行）；主副手互换为附加动作，收招代价另计（见 `design/05` §6.4、`design/09` §4.7）。
- 玩家队伍上场人数 ≤ 6（主角 + 5 名队友）；剧情 AI 友军另计，不增加玩家队伍槽位。场上活动单位总预算见 `design/09` §9.1、`tech/03`。
- **绝招资源与节奏**：同一角色的全部绝招共享唯一气势槽 `rage`（0–100），每次施展消耗 100；同一门武学的全部绝招共享 1 次持有者自身行动冷却。施放行动不递减该冷却，紧接的下一次自身行动全程禁用同门绝招，该行动结束才清零。冷却归零后仍不得连续施展同一绝招，须先施展同门另一绝招或同门普通招。环境行动者、免费动作及其他单位行动均不推进此冷却。候选过滤、AI 与表现只见 `design/09`、`design/14`。
- 护体真气 `shield`：先于气血吸收伤害。其后、既有 `mpGuard` 之前可结算 `design/21` 的**护体内劲**：拳脚 / 兵器 / 暗器 / 内劲外放适用率依次为 100% / 25% / 0% / 40%，每消耗 1 内力抵消 2 伤害。未抵消的输出名固定为 `damageBeforeMpGuard`，不是最终 `hpDamage`；击穿产生 150–400 CT 与 800–3000 bp 经脉迟滞，完整容量、破气与守恒公式只见 `design/21` §4.8。
- **环境行动者**在有动态地形时以固定速度驱动火势、水流、冰融等变化；其行动不计为任何单位的回合，不推进单位 Buff/冷却，统一调度见 `design/09` §3.2，地形演化见 `design/08` §7.4。
- **默认战败规则**：气血归零为重伤倒地，非永久死亡；主角倒地即战败，剧情战可改变后果。坠崖离场不等于倒地；自选铁血规则的离队例外见 `design/13` §5.3，普通救护与失败流程见 `design/09` §7。

`P_ref` 使用攻方**显示等级**和当前境界，参考轨迹见 `design/03` §3.5，统一实现与校准归 `design/04`；不得取本次实际武学威力作分母而抵消品阶收益。Z0 只决定开关、条件与概率；`ignoreDef` 的防御处理在 Z2，暴击倍率在 Z6，`asBack/asHigh` 的方位伤害在 Z7，招架减伤在 Z9，均不重复结算。

普通天阶名录的伤害品阶输入按 §13 当前 **59 门 = 天上 9 + 天中 18 + 天下 32** 读取；扩容只改变可引用的武学定义与来源，不改变本节 Z0–Z10 乘区、品阶系数或取整规则。

`MoveDef.projection:true` 的非音功招式在同一个 Z5M 位置改用 `design/21` §4.4.1 的外放专用曲线，替代普通经脉攻击曲线；不得先乘普通曲线再乘外放曲线，也不得另建 Z5P / Z11。非音功选 0 档仍属外放并使用外放曲线。音功是唯一分支：具备外放资格的音功在 `projectionStep=0` 时仍用普通 `attackMeridianMultBp`、基础范围与零额外耗内，`projectionStep≥1` 才使用外放曲线和对应扩张；范围档不再次乘威力。标准对标准仍为 10000 bp，总界仍为 6500–22000 bp。此合并方式与曲线数值为 AR-16b 执行默认，⚠️ 待作者确认；现行 `DamageKind='projected'` 与护体内劲 40% 适用率的兼容边界见 `design/21` §4.4.1。

确定性数值统一使用整数或有理数：百分比例以 10,000 bp 表示；Z1–Z10 及插入的 Z4M / Z5M 每个乘区内部保留精度、区末一次向下取整，不能每次连乘都取整；资源成本与明确写 `round` 的规则用十进制 half-up（负数为 `floor(x+1/2)`）。同一规则在客户端、服务端、工具与录像中不得选择不同取整点。

## 10. Buff 基础规则（固定）

完整规则与目录见 `design/06-buff-system.md`。

- **三大类**：数值类 `stat`（如防御 +X%）、效果类 `effect`（如每回合回血、流血、破刀）、机制类 `mechanic`（如免疫中毒、X 回合无敌、锁血）。
- **极性**：增益 `buff` / 减益 `debuff`。
- **品阶**：1–12（同 §4），通常继承来源武功/物品的品阶。
- **品阶对抗**：免疫、驱散、抵抗对**品阶 ≤ 自身品阶**的效果按各自完整规则生效；设 `Δ = 效果品阶 − 对抗方品阶`，`ρ(Δ)=0`（Δ≤0），`ρ(Δ)=min(0.90, 0.15+0.15Δ)`（Δ≥1）。数值削弱、机制概率与驱散削品的具体用法见 `design/06` §3.5，不把“抵抗全额参与”误作必然免疫。
- **叠加规则**：`refresh` 刷新 / `stack` 叠层 / `independent` 独立并存 / `highest` 取高。
- **持续**：`turns` 持有者行动次数 / `permanent` 永久 / `charges` 触发次数 / `battle` 本场战斗 / `world` 世界时间（时辰）/ `untilCured` 直到解除 / `aura` 光环 / `instant` 瞬时。
- **标签**（用于免疫与驱散）：`poison` 毒、`gu` 蛊、`seal` 穴、`injury` 内伤、`bleed` 流血、`cold` 寒、`heat` 热、`cc` 控制、`guard` 护体、`mind` 心神、`weaponBreak` 破兵、`stance` 架势、`bind` 受制、`veil` 隐匿、`boost` 强化、`weaken` 削弱；子标签用点号（如 `poison.common`），免疫/驱散可精确到子标签，目录见 `design/06` §14.3。

## 16. 原著改编原则（固定）

1. **锚点不可抹除**：每个书界列出 3–6 个锚点事件，它们是天书降临的前提，主线必经。
2. **过程可介入**：玩家可以参与、协助、见证、改变次要人物命运与支线结局。
3. **改命是隐藏的高难分支**：少数"遗憾型"锚点（如雁门关、襄阳城破前后等）提供改命线，改命成功只改变结局文本、天书之力变体与后续书界的彩蛋，不改变下一书界的历史起点。
4. **主角是"变数"而非替身**：主角不顶替原著主角，与原著主角同场（结义、同行、对手皆可）。
5. **原创扩展须标注**：凡原著没有的武学、人物、任务，文档中标注"（原创扩展）"。
6. **考据基线**：以三联/广州版修订版（"新三版"之前的修订版）为基线，涉及新修版差异处注明。
7. **两轴独立**：正 / 邪是玩家立场轴，原著 / 改命是锚点命运轴；原著线不是失败线，邪线也可达成改命。结局判定不得只用最终品德覆盖选择历史。

| 轻功 | 1 | |

装入内功栏的每门内功仍须显式携带 §6 的 `nature`；切换主运时才据新主运重算 `mpNature` 与相性，辅运不得覆盖主运性质。上述栏位数量不因 §4 的目录扩充而增加。

套装只统计当前已装配武学与已穿戴装备形成的唯一成员 ID 集合，同一 ID 即使有多个实例也最多计 1 件；主运、辅运内功均计件，兵器武学因当前武器类别不匹配而暂不可施展时仍计件。设已计件成员的压制后有效品阶升序列为 `E`，`g_set=floor(median(E))`；奇数取正中项，偶数取中间两项均值后向下取整，例如 `[5,6,8,12]` 得 `floor((6+8)/2)=7`。不足 2 件不激活套装；完整规则与正式成员表只见 `design/07` §3–§4、§8.4。

> 高武书界的携带上限（3/3/3）正好等于内功/拳脚/兵器装配栏数量；中武、低武书界装配栏数量不变，只是携带进来的少，需要在本书界重新习得补齐。

**装备栏**（8 格）：主武器 `mainHand`、副手 `offHand`（副兵器/暗器囊/盾）、头 `head`、衣 `body`、护手 `hands`、腰带 `waist`、鞋 `feet`、佩饰 `accessory`。书眠时可携带任意 6 件（不限于穿戴中）。

**成对兵器**的单一装备实例（如 `eq_yuanyangdao`）占主副两格，书眠只计 1 件；两件独立单手兵器即使成套仍计 2 件。**非成对的双手主武器**在手时，副手仅可放暗器囊/名门暗器（不是另持副兵器或盾）；成对实例已占副手，不能再放暗器。细则见 `design/10` §3.3、§3.5、§7.1。采用藏史时，`本次书眠携带装备数 + 本书界新存入藏史的装备数 ≤ 6`（按实例去重计数）；史笺不占装备额度，容量与取回限制见 `design/02` §6.6。
