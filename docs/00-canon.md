## 0. 项目定位

| 项 | 定义 |
|---|---|
| 工作名 | 《金庸群侠传·天书录》（代号 `tianshu`） |
| 一句话 | 一个现代人穿越进金庸小说世界，按故事发生的年代依次闯过十四个"书界"，每个书界取得一本天书，集齐十四天书回到现实。 |
| 类型 | 单人 · 单线（十四书界线性串联）· 多周目（每个书界相当于一次带继承的周目）· 开放世界 RPG · 斜 45° 等距战棋 |
| 平台 | 手机浏览器（横屏优先）＋ PC 浏览器；PWA 可离线游玩；云存档（"Online" 的含义：随时随地在浏览器中继续同一份存档） |
| 用户 | 作者本人自娱。**非商业、不公开分发**。金庸作品版权归权利人所有；AI 素材不得使用任何影视剧演员的肖像。 |
| 基调 | 国风（水墨＋工笔），尊重原著，允许"改命"但以原著为锚。 |

## 3. 境界规则（天道压制）

| 境界 | 入场携带核心武功 | 携带装备 | 外来武学/装备品阶压制 | 武功层数上限 | 书界等级上限范围 | 完整原生天级武学池（计数见 §13） | Boss 超限上限 |
|---|---|---|---|---|---|---|---|
| 高武 `HIGH` | 内功 3 / 拳脚 3 / 兵器 3 | 6 件 | 0 | 10 重 | ≤ 70 | 常见（每书界 6–16 部） | +3 级 |
| 中武 `MID` | 内功 2 / 拳脚 2 / 兵器 2 | 6 件 | −2 小品 | 9 重 | ≤ 60 | 孤本（每书界 1–5 部） | +4 级 |
| 低武 `LOW` | 内功 1 / 拳脚 1 / 兵器 1 | 6 件 | −4 小品 | 8 重 | ≤ 50 | 极罕（每书界 0–2 部） | +6 级 |

硬规则：
1. **核心武功**只包含三类：内功、拳脚（拳掌/指/腿/擒拿）、兵器（剑/刀/棍/枪/鞭/奇门）。轻功、暗器、杂学为非核心，**不可携带**（每个书界重新获得，保证开放世界的轻功门禁在每部都有意义）。
2. 携带武功的**真实层数保留、有效层数截断**：有效层数不超过 `min(trueLayer, 本书界层数上限)`，修为与来源门槛另见 `design/05` §3.3–3.4。书界内修炼不能突破层数上限，其后的新增武学经验转为**积蕴**（折算、容量与释放见 `design/02` §2.4）；已学会的真实层数不折算、不扣除。招式解锁、威力与层数被动用有效层数。携带装备可为任何品阶（包括天级）。
3. **外来压制**作用于经书眠或藏史带入、`nativeTo` 不等于当前书界的武功/装备；普通外来实例的有效品阶为 `max(1, absGrade − S)`，抵消例外见规则 7、9。本土合法习得（含按再遇途径忆起）、完整传承印证及同名原生装备器合可取得本土身份，不受品阶压制，仍受层数上限；残承新学仍受 §13 来源品阶限制，**残承印证不改外来实例的 `nativeTo`**。强化、铭刻等不改变归属，细则见 `design/02` §2.2–2.3、§5.7–5.8。
4. 角色存在**真实等级**（1–70，只增不减）与**显示等级** `min(真实等级, 当前书界等级上限)`；所有等级派生属性、等级需求、修为名及**修为突破分配点按显示等级生效**，被压低的分配记录保留（见 `design/03` §2.8）。真实等级达到或高于当前书界上限时，后续角色经验转为**修为余韵**，本书界不再升级；同次发放先补到上限、余量再转余韵，折算见 `design/13` §2.6–2.7。
5. 未携带的核心武功、所有非核心武功 → 转为**残篇**（记入武学图鉴；再次遇到时修炼加速；详见 `design/02`）。
6. 金钱、普通物品、门派身份、队友不跨书界（书灵除外）；已学**学识**（丹方、菜谱、锻造图谱、铭文）、武学/物品图鉴与已授予的**永久增益**保留。永久增益不含依赖当前装配的武学被动；修为突破点仍按规则 4 生效。
7. **天书之力抵消**：`S` 为当前境界原始品阶压制量（高/中/低武 0/2/4，难度覆盖先计算），`S_floor = ⌈S/2⌉`；天书与自创的永久抵消合算后，外来基础压制 `S_eff` 不得低于此下限，本土/残承印证另按规则 3 处理。仅 1 门本命可获层数上限 +1，且不超过真实层数与 10 重；等级上限不可抵消。限时全解只按 `design/13` §3.4.4、§4.6 的次数/时长执行，显示等级仍不变；天书之力本身不受外来品阶压制。
8. **Boss 超限**只给章节明确标记的至多 2 名 Boss：显示等级 ≤ `min(70, 书界等级上限 + 本表超限上限)`，不放宽品阶与层数。例如洪安通上限 `min(70,44+6)=50`，倚天仍为 `min(70,70+3)=70`；具体战斗数值见 `design/02` §3.1、`design/09`。
9. **自创武学**（融会贯通）**（原创扩展）**，最高地上 9，携带与层数照常受限；外来压制基数取 `⌈S/2⌉`（中武 1、低武 2）。与天书抵消合算为 `S_eff = max(⌈S/2⌉, ⌈S/2⌉ − 抵消量)`，不得再次减半或绕过原始 `S` 的下限；普通外来实例对应 `max(⌈S/2⌉, S − 抵消量)`。产物与修炼细则见 `design/05` §12。
10. **终局**：取得第十四本天书时真实等级补至 70；仍在雪山余韵期时显示等级仍为 58。正式进入终局容器后才关闭天道压制，等级上限 70、层数上限 10，残篇以历史最高层数临时回归；不新增第十五本天书。见 `design/13` §7.1、§7.3、§7.6。
11. **自愿规则例外**：天道劫 `tj_tiandao` 自天劫第 6 重起累积生效，仅把中/低武 `S` 改为 3/5，压制下限与自创基数相应为 `⌈3/2⌉=2`、`⌈5/2⌉=3`，高武不变；它是唯一调整正常难度压制数值的选项。另设无天道沙盒 `rule_wutiandao`，只关闭品阶压制与层数上限，角色等级及修为门槛不豁免；须新局主动选择，成就限制见 `design/13` §5.3–5.4；两者不同时启用。

## 8. 战斗模型（固定）

- **斜 45° 等距网格战棋**；每格有高度 `h`（0–10 级台阶）与地形 `terrain`。
- **就地开战**：以遭遇点为中心截取当前场景（≤ 20×20 格）作为战场，地形与高度原样保留。
- **集气时间轴（CT）**：UI 显示 0→1000，每 tick 增加量 = `spd` 派生值；达到 1000 行动；行动后按招式“收招”值扣减。内部允许负值（下限 −1000）表示收招中，并保留跨阈值余量；推进细则见 `design/09` §3。
- **"回合"的定义**：Buff/冷却中的"回合"= **持有者自身的一次行动**。
- 每次行动：可移动一次 + 执行一个行动（招式 / 暗器 / 物品 / 运功调息 / 防御 / 待机，以及援护、撤退、口舌、俘获、看破、救护等），顺序自由；完整行动表见 `design/09` §4.7。
- **免费动作**不占行动、不耗集气、不推进 Buff/冷却回合：每次自身行动号令至多 1 次，天书之力/书契技合计至多 1 次；主副手互换为附加动作，收招代价另计（见 `design/05` §6.4、`design/09` §4.7）。
- 玩家队伍上场人数 ≤ 6（主角 + 5 名队友）；剧情 AI 友军另计，不增加玩家队伍槽位。场上活动单位总预算见 `design/09` §9.1、`tech/03`。
- 气势 `rage` 0–100：命中、受击、击杀、招架成功时积累；绝招消耗 100。
- 护体真气 `shield`：先于气血吸收伤害。
- **环境行动者**在有动态地形时以固定速度驱动火势、水流、冰融等变化；其行动不计为任何单位的回合，不推进单位 Buff/冷却，统一调度见 `design/09` §3.2，地形演化见 `design/08` §7.4。
- **默认战败规则**：气血归零为重伤倒地，非永久死亡；主角倒地即战败，剧情战可改变后果。坠崖离场不等于倒地；自选铁血规则的离队例外见 `design/13` §5.3，普通救护与失败流程见 `design/09` §7。

|---|---|---|---|
| Z0 | 判定 | `judge` | 命中 → 招架 → 暴击；统一解析 `mustHit`、`mustCrit`、`skipParry`、`noCrit`、`ignoreDef`、`asBack`、`asHigh` 与 `targetParryMult` 等判定开关/乘数 |
| Z1 | 基础伤害 | `base` | 招式威力（品阶 G × 层数 × 招式倍率）÷ 攻方等级/境界期望 `P_ref` × 攻击合成（外/内比例），归一仅一次 |
| Z2 | 防御减免 | `defense` | 比值型减伤（含破防、无视防御） |
| Z3 | 增伤 | `dmgUp` | 攻方所有"伤害 +X%"加法合并 |
| Z4 | 减伤 | `dmgDown` | 守方所有"受到伤害 −X%"加法合并（上限 75%） |
| Z5 | 资质与相性 | `affinity` | 武学资质、内力性质相性、兵器克制（"破 X"） |
| Z6 | 暴击 | `crit` | 暴击倍率 |
| Z7 | 方位与地形 | `position` | 背击/侧击、高低差、地形 |
| Z8 | 境界差 | `realmGap` | 双方显示等级差带来的压制 |
| Z9 | 招架 | `parry` | 招架成功时的减免 |
| Z10 | 浮动 | `variance` | 0.95–1.05 |
| — | 结算 | `settle` | 护体真气吸收 → 气血；附加效果（内伤、Buff 施加、吸血/吸内、反震） |

## 10. Buff 基础规则（固定）

完整规则与目录见 `design/06-buff-system.md`。

- **三大类**：数值类 `stat`（如防御 +X%）、效果类 `effect`（如每回合回血、流血、破刀）、机制类 `mechanic`（如免疫中毒、X 回合无敌、锁血）。
- **极性**：增益 `buff` / 减益 `debuff`。
- **品阶**：1–12（同 §4），通常继承来源武功/物品的品阶。
- **品阶对抗**：免疫、驱散、抵抗对**品阶 ≤ 自身品阶**的效果按各自完整规则生效；设 `Δ = 效果品阶 − 对抗方品阶`，`ρ(Δ)=0`（Δ≤0），`ρ(Δ)=min(0.90, 0.15+0.15Δ)`（Δ≥1）。数值削弱、机制概率与驱散削品的具体用法见 `design/06` §3.5，不把“抵抗全额参与”误作必然免疫。
- **叠加规则**：`refresh` 刷新 / `stack` 叠层 / `independent` 独立并存 / `highest` 取高。
- **持续**：`turns` 持有者行动次数 / `permanent` 永久 / `charges` 触发次数 / `battle` 本场战斗 / `world` 世界时间（时辰）/ `untilCured` 直到解除 / `aura` 光环 / `instant` 瞬时。
- **标签**（用于免疫与驱散）：`poison` 毒、`gu` 蛊、`seal` 穴、`injury` 内伤、`bleed` 流血、`cold` 寒、`heat` 热、`cc` 控制、`guard` 护体、`mind` 心神、`weaponBreak` 破兵、`stance` 架势、`bind` 受制、`veil` 隐匿、`boost` 强化、`weaken` 削弱；子标签用点号（如 `poison.common`），免疫/驱散可精确到子标签，目录见 `design/06` §14.3。

## 16. 原著改编原则（固定）

1. **锚点不可抹除**：每个书界列出 3–6 个锚点事件，它们是天书降临的前提，主线必经。
2. **过程可介入**：玩家可以参与、协助、见证、改变次要人物命运与支线结局。
3. **改命是隐藏的高难分支**：少数"遗憾型"锚点（如雁门关、襄阳城破前后等）提供改命线，改命成功只改变结局文本、天书之力变体与后续书界的彩蛋，不改变下一书界的历史起点。
4. **主角是"变数"而非替身**：主角不顶替原著主角，与原著主角同场（结义、同行、对手皆可）。
5. **原创扩展须标注**：凡原著没有的武学、人物、任务，文档中标注"（原创扩展）"。
6. **考据基线**：以三联/广州版修订版（"新三版"之前的修订版）为基线，涉及新修版差异处注明。

## 20. 武学装配栏与装备栏（固定）

**武学装配栏**（战斗中可用的武功；套装件数只统计装配中的武功与穿戴中的装备）：

| 栏位 | 数量 | 说明 |
|---|---|---|
| 内功 | 3（主运 1 + 辅运 2） | 主运内功决定内力性质与主要被动；辅运只提供部分被动（比例见 `design/05`） |
| 拳脚 | 3 | |
| 兵器 | 3 | 只能使用与当前主武器类别匹配的兵器武学（空手时兵器栏不可用） |
| 轻功 | 1 | |
| 暗器 | 1 | |
| 杂学 | 2 | 医/毒/阵法/音律等主动或被动 |

> 高武书界的携带上限（3/3/3）正好等于内功/拳脚/兵器装配栏数量；中武、低武书界装配栏数量不变，只是携带进来的少，需要在本书界重新习得补齐。

**装备栏**（8 格）：主武器 `mainHand`、副手 `offHand`（副兵器/暗器囊/盾）、头 `head`、衣 `body`、护手 `hands`、腰带 `waist`、鞋 `feet`、佩饰 `accessory`。书眠时可携带任意 6 件（不限于穿戴中）。

**成对兵器**的单一装备实例（如 `eq_yuanyangdao`）占主副两格，书眠只计 1 件；两件独立单手兵器即使成套仍计 2 件。**非成对的双手主武器**在手时，副手仅可放暗器囊/名门暗器（不是另持副兵器或盾）；成对实例已占副手，不能再放暗器。细则见 `design/10` §3.3、§3.5、§7.1。
