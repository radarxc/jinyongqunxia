## 0. 结论先行与交付清单

1. 全作使用一张 **73°E–135°E、18°N–54°N** 的中国及周边江湖底图。它是导航层 / UI 资产，不是可行走地形；玩家选目的地并结算旅行，进入区域后才加载 `tech/02` 的区域地图。
2. 数据采用 WGS84，经纬度保留 **0.01°**。默认投影为球面 Albers 等积圆锥：标准纬线 25°N / 47°N、中央经线 105°E、原点纬线 35°N。4096 × 3072 默认画布留 150 px 边距。
3. `cities.yaml` 收录 **189 个城市 / 历史治所 / 小说锚点**；每条有 6 个历史时期并展开为 14 个 `chNN` 状态。全部点均通过 Natural Earth 陆地多边形或显式小岛、岸线、小说锚点掩膜校验。
4. `sects.yaml` 恰收录 `design/17` 的 **99 个 `sect_*`**，没有另造门派 ID；每派落在真实城市、真实山脉或标明精度的小说锚点，并逐格引用 17 的 14 时代开放矩阵。
5. 真正超出画布的节点只有 **3 个**：波斯明教总教、罗刹国、撒麻尔罕。它们只由一条两端式 `offmap_special` 专线连接驿站或货船码头，`via=[]`、`no_intermediate_stops=true`，途中城市不可见、不可停。
6. `routes.yaml` 含 **24 座驿站、28 个码头、48 条常规官道/驿路/水路、3 条图外专线**。时长与费用是大地图建议档，不替代 `design/11` 的旅行事件与经济终值。
7. `regions.yaml` 给出 **19 个 `rg_*` 草案**、81 个简化陆地多边形、14 组河流和 11 组山脉。海岸与河流基于 Natural Earth 1:50m，写入仓库后渲染不联网。
8. `tools/map/render_map.py` 仅需 Python 3.9+ 标准库；四个 `.yaml` 使用 JSON-compatible YAML 1.2，故无 PyYAML 也能读。`--check` 已通过，`--render` 已生成底图与 14 张时代图。

## 1. 设计目标、边界与事实等级

### 1.1 AR-04 / AR-11 的可执行解释

“统一”指十四书界共享地理 ID、WGS84 坐标和投影，再叠加 `chNN` 城名/地位、`design/17` 门派状态与当期交通；不是让 1093 与 1780 的城名同时出现。遵循作者决定 P53，地图选点只产生旅行意图，探索和战斗进入区域场景后发生。

```text
共同地理底图 + chNN 城市/门派/交通状态 = 当前书界导航地图
```

### 1.2 收录口径

189 条记录取以下并集：AR-04 点名的都城/重镇/商埠/边关；十四书界主支线城市；`design/17` 的驻地与分舵近邻；官道、丝路、茶马道、江河、运河和海路中继；代表性首府、港口；图内小说锚点。它不是历代全部县级名录。9 条 `importance=site` 仅为昆仑或岛屿端点，UI 须用地点符号，不计作城市人口。

### 1.3 坐标与史实置信度

| `coordinate_precision` | 含义 | 展示约束 |
|---|---|---|
| `known_site` / `known_mountain` | 明确遗址或山体 | 可称实地位置 |
| `city_anchor` / `regional_anchor` | 城市中心或活动带 | 不声称精确到门址 |
| `approximate_fictional` | 小说无可证坐标 | 标小说锚点**（原创扩展）** |
| `approximate_pending_research` | 原著/史料未核完 | 标**（待考）** |
| `approximate_original_placement` | 古龙内容映入本时间线 | 标**（原创扩展）** |

现代坐标以 GeoNames WGS84 为底表并抽检民政部地名库；历史行政名参考 CHGIS 后人工整理。CHGIS 不允许商业再分发，仓库只保留整理结果与来源链接。0.01° 约为南北 `111.2×0.01=1.11 km`、35°N 东西 `111.2×cos35°×0.01≈0.91 km`；适合全国导航，不代表虚构地点具有公里级真实性。

### 1.4 历史地名与治所迁移原则

1. `city_*` 表示跨时代地理语义；同址易名写 `history.<band>.name`。
2. 治所确实迁移时写 `seat_moves[]` 的适用时期与 WGS84，渲染点和标签同步迁移。
3. 后世城市尚未形成时标“未建或废弃”，当期聚落名不确定则标**（待考）**。
4. “都城”按当期政权赋值；不得因古都身份将西安、成都等误标。
5. 并立政权可有多个都城，如北宋层的汴梁、辽南京/上京、兴庆与大理。

## 2. 范围、投影与比例尺

### 2.1 地理范围

| 参数 | 值 | 覆盖意图 |
|---|---:|---|
| 西界 | 73°E | 帕米尔、喀什、昆仑西段 |
| 东界 | 135°E | 黑龙江下游、东北东缘、近海岛屿 |
| 南界 | 18°N | 海南南端、南海题签留白 |
| 北界 | 54°N | 黑龙江上游、漠北留白 |
| 默认画布 | 4096 × 3072 px | 4:3 横向导航资产 |
| 内容边距 | 150 px | 题签、墨晕、图例不会被裁切 |

波斯、莫斯科方向与撒麻尔罕均不扩大画布；扩大到 50°E 会压缩中国主体、降低城市可读性，因此用图外题签。

### 2.2 为什么选择 Albers 等积圆锥

- 中国东西跨度大、中纬度为主；两条标准纬线能让主体区尺度均衡。
- 等积性质适合区域面积与空间密度的视觉比较。
- 相比简单经纬度等距，东北和西北不会被横向过分拉伸。
- 本图不用于测地导航；距离仍以 WGS84 大圆/路径数据计算，不能拿 SVG 像素直接算行程。

### 2.3 球面 Albers 正算公式

角度先转弧度。参数：

```text
φ1 = 25°       第一标准纬线
φ2 = 47°       第二标准纬线
λ0 = 105°      中央经线
φ0 = 35°       原点纬线
R  = 6371.0088 km（只在需要米/千米尺度时乘入）
```

中间量与投影：

```text
n  = (sin φ1 + sin φ2) / 2
C  = cos² φ1 + 2n sin φ1
ρ  = R · sqrt(C − 2n sin φ) / n
ρ0 = R · sqrt(C − 2n sin φ0) / n
θ  = n(λ − λ0)
x  = ρ sin θ
y  = ρ0 − ρ cos θ
```

脚本内部先令 `R=1` 得无量纲坐标，再按整个范围的投影包围盒统一缩放。计算常数：

```text
n    = 0.576985981679935
C    = 1.309083430095920
ρ0/R = 1.394284534840312
```

### 2.4 投影坐标到画布

对范围四边各采样 65 点，得到投影包围盒：

```text
xmin = -0.5356905927 R
xmax =  0.5032705046 R
ymin = -0.2971847940 R
ymax =  0.3869147392 R
```

令 `m=150`，画布 `W=4096`、`H=3072`：

```text
sx = (W − 2m) / (xmax − xmin)
sy = (H − 2m) / (ymax − ymin)
s  = min(sx, sy) = 3653.649795 px/R
X  = offsetX + s·x
Y  = offsetY − s·y       // SVG y 轴向下
```

以 `R=6371.0088 km` 解释，标准纬线附近约 `3653.65 / 6371.01 = 0.5735 px/km`，即 100 km 约 57 px。画布实际比例随纬度和方向变化；标尺只能注明“标准纬线附近”。

### 2.5 测试向量

| WGS84 点 | 默认画布坐标（px，约） | 用途 |
|---|---:|---|
| 73°E, 18°N | (150.00, 2467.61) | 西南边界 |
| 135°E, 18°N | (3946.00, 2505.84) | 东南边界 |

### 2.6 可配置画布

`--width` / `--height` 可改变画布，但不能小于 1024 × 768。缩放永远按较小轴取值并居中，不拉伸。默认输出才是仓库审定资产；其他尺寸用于预览或下游切片。

### 3.3 城市记录

核心字段为 `id/modern_name/longitude/latitude/region/importance/history/eras/chapters/sects/businesses/seat_moves/sources`。`history` 存 6 个时期，`eras` 存展开后的 14 格；`importance` 仅取 `capital/major/secondary/site`，是绘图级别。行政地位只取都城、路府州县、军镇、商埠、边关、未建或废弃。完整实例见 `cities.yaml` 的 `city_beijing`。

### 3.4 治所迁移

`seat_moves[]` 以 `eras/name/longitude/latitude` 在指定时期覆盖默认投影点；路线端点、城市符号和标签共用迁移坐标。当前只记录有消费价值的迁移，不把现代地级市内每次县衙搬迁都玩法化。

### 3.5 门派记录

门派仅保留 `id/site_name/city_id/longitude/latitude/coordinate_precision/availability_ref/availability/branches` 等地图字段，不复制武学或人物关系。`availability` 是 `design/17` §3 的机器可读镜像；17 改矩阵时须同步比较，本文不取得开放规则归属权。

### 3.6 路线记录

路线字段为 `id/kind/from/via/to/duration_days/fee_tier/open_chapters/service`；常规路线允许 `via`，图外专线禁止。离散日包含休息、换马、路况与剧情抽样，不是现代驾车时长；费用只给 `low/medium/high/very_high/special/story` 档，金额归 `design/11` / `16`。

## 7. 水墨视觉规范

### 7.1 色板：深 / 中 / 淡三级墨色

| 层级 | 色值 / 不透明度 | 用途 |
|---|---|---|
| 深墨 | `#211f1a`，85–100% | 主海岸、都城、标题、关键山脊 |
| 中墨 | `#554c3e` / `#526d6d`，50–70% | 河流、主要路线、府州 |
| 淡墨 | `#8e8065`，5–35% | 纸纤维、墨晕、次要道路、远山 |
| 宣纸 | `#eee4cc` | 大留白背景 |
| 朱砂 | `#9e3b2f` | 门派印、都城外圈、图外专线、印章图例 |

颜色不表达阵营善恶。状态用形状、透明度与文字共同表达，避免仅靠色觉区分。

### 7.2 纸纹与墨晕

SVG 内建三组滤镜：

1. `paper-grain`：固定 `seed=19` 的 `feTurbulence(fractalNoise)`，以 `multiply` 混入纸色；
2. `ink-bleed`：固定 `seed=11` 的噪声经过 `feDisplacementMap(scale=3.2)` 扰动海岸，再以 `feGaussianBlur(stdDeviation=0.45)` 叠出墨晕；
3. `mist`：`feGaussianBlur(stdDeviation=13)`，预留给 UI / 美术增加云雾遮罩。

固定种子保证输出文本与浏览器渲染稳定；浏览器的滤镜栅格化可能有亚像素差异，像素回归应允许滤镜边缘极小误差**（待实测）**。

### 7.3 海岸、河流与山脉

- 海岸：5 px 深墨主线，圆角连接；同一闭合多边形填淡宣纸色。
- 河流：7 px 青灰中墨，以 `38 7 11 5` 非均匀虚线形成飞白，不用纯蓝。
- 山脉：沿 11 条山系骨架按约 36 px 间距生成短峰笔触；每笔的偏移来自 ID 的 SHA-256，不使用随机数。
- 路：3 px 淡墨虚线；水路为 3.5 px 青灰飞白；图外专线为 4 px 朱砂虚线。
- 海域保持大面积留白，不铺现代行政边界或卫星底纹。

### 7.4 城市符号分级

| 级别 | 符号 | 默认标注 |
|---|---|---|
| 都城 | 10 px 深墨圆 + 朱砂外缘 | 33 px 题名 |
| 重要府州 / 商埠 / 军镇 | 7 px 中墨圆 | 27 px 题名 |
| 次级交通点 | 5 px 淡墨圆 | 仅 `<title>`，放大/交互后显示 |
| 小说地点 / 岛屿 | 8 px 空心圆 | 依重要度显示 |
| 门派开放 `O` | 朱砂菱印 | 显示门派名 |
| 门派隐世 `H` | 48% 透明朱砂菱印 | 默认不强制文字 |
| 驿站 | 10 px 方印 | `<title>` |
| 码头 | 船底弧形符号 | `<title>` |

静态全量图会发生局部标签重叠，脚本只给确定性偏移；正式 UI 应使用 `design/14` 的缩放、避让和选中态。不得为追求单张海报可读而删掉数据点。

### 7.5 竖排与字体回退

题名、城市短名优先 `writing-mode: vertical-rl; text-orientation: upright`。字体回退固定为：

```css
font-family:
  "Ma Shan Zheng",
  "Zhi Mang Xing",
  "STKaiti",
  "KaiTi",
  "Noto Serif CJK SC",
  serif;
```

前两者是 `tech/06` 已列的 OFL 书法字体候选，生产环境须由资产管线做题名子集；SVG 源不嵌字体，避免文件暴涨。缺字时退回系统楷体/宋体。字体实际字面、竖排标点和 Android WebView 表现需真机检查**（待实测）**。

### 7.6 题跋与印章式图例

- 右上竖题“江湖万里图”，旁列当前书界与时代；
- 右下题跋：“一纸载十四世，驿路通万里；地名随时，山河不改。”**（原创扩展）**；
- 图例使用朱砂方印“江湖”，再列都城、府州、门派、水路四个高频符号；
- 图外节点置于左侧留白的朱框题签，明确写“图外专线 · 中途不停靠”。

### 7.7 可访问性底线

SVG 根元素包含 `<title>` 与 `<desc>`；每个城市、门派、路线、驿站和码头都有稳定 DOM `id` 与 `<title>`。生产 UI 不应直接把巨型 SVG 当作唯一信息载体，应从 YAML 构建列表视图、搜索与读屏文本，详见 `design/14`。

## 8. 图层与时代规则

### 8.1 底图层

`jianghu-base.svg` 的固定顺序：

```text
paper / fibers
  → base-geography (land polygons + island masks)
  → rivers
  → mountains
  → era-ch01 ... era-ch14
  → title / colophon / legend
```

每个时代组内部：常规路线 → 驿站/码头 → 城市 → 门派 → 图外题签与专线。这样城市点不会被路线压住，门派朱印又能盖在城市层上。

### 8.2 全时代 SVG 的显示约定

`jianghu-base.svg` 包含全部 14 组：

```xml
<g id="era-ch01" class="era-layer" display="inline">…</g>
<g id="era-ch02" class="era-layer" display="none">…</g>
…
<g id="era-ch14" class="era-layer" display="none">…</g>
```

默认显示 ch01，避免 14 层同时叠出不可读海报。“全部时代图层”意为都存在且可单独切换，不是默认同时可见。UI 切换时只改变 `display` 或 CSS class。

### 8.3 单时代 SVG

`jianghu-chNN.svg` 只有对应 `<g id="era-chNN">`，适合章节包、静态评审与低成本加载。它与 `jianghu-base.svg` 中同一组由相同代码生成；不是人工维护的分叉。

### 8.4 城市开放判定

普通城市以 `eras[chNN].open=true` 显示；`importance=site` 的小说锚点即使行政状态为“未建或废弃”，仍按所属书界显示。该状态表示没有历史行政城，不表示小说地点不存在。剧情封锁由 `design/11` 的 `entryState` 叠加，不能滥用历史状态。

### 8.5 门派开放判定

```text
O → 显示实色门派印
H → 显示半透明隐世印（UI 可默认隐藏）
P/M/N/D → 不显示常驻门派入口
```

门派分舵没有独立 `sect_*`；使用 `branches[].id=site_*` 或由 11 的入口实例承载。

### 8.6 路线开放判定

路线必须包含当前 `chNN` 才显示。常规路径中的 `via` 既是几何折点也是可停节点；图外专线 `via` 永远为空。若下游要把常规长线拆段，应生成新 `route_*`，而不是给图外专线塞中途点。

### 8.7 AR-04 的状态合成接口

本文地理层输出 `cityId + chapterId + displayName + administrativeStatus + lon/lat + openByHistory`；`design/11` 再合成势力、NPC、资源点、营生营业和任务封锁。动态状态不得反写基础 SVG。

## 9. 地理几何与来源处理

### 9.1 海岸线 / 陆地多边形

来源为 Natural Earth 1:50m `land` GeoJSON（public domain），2026-09-26 下载。生成期处理：

1. 读取 Polygon / MultiPolygon 外环；
2. 保留与 72–136°E、17–55°N 加 3° halo 相交的完整环；
3. 经纬度四舍五入到 0.001°；
4. 用 Douglas–Peucker、容差 0.045° 简化；
5. 补闭环，少于 4 点者剔除；
6. 按点数与首点确定性排序；
7. 写成 81 个 `land_polygons`，运行时不读外部文件。

### 9.2 小岛与岸线容差掩膜

Natural Earth 1:50m 会省略极小岛屿，也可能让海岸城市中心落在简化岸线外。因此 `island_masks` 明示三类：

- `small_island`：厦门、澎湖等小岛；
- `shore_tolerance`：威海、福州、海口等岸线简化容差；
- `fictional_anchor`：桃花岛、侠客岛、神龙岛、白云城、蝙蝠岛。

圆形半径只用于渲染和点在陆地侧校验，绝不是实际海岸形状。校验允许城市落入陆地多边形或这些显式掩膜之一。

### 9.3 河流

Natural Earth 1:50m 河流中心线经 0.06° 简化。为保持全国图上的连续叙事，长江、黄河等被分段或稀疏的部分用人工概化折线补齐；人工线明确记录 `hand-simplified reference polyline`，不能用于水文计算。共 14 组：长江、黄河、大运河、珠江/西江、淮河、汉水、澜沧江、怒江、雅鲁藏布江、松花江、黑龙江、辽河、塔里木河等。

### 9.4 山脉

11 条山脉是小比例尺视觉骨架：喜马拉雅、昆仑、天山、祁连、秦岭、太行、大兴安岭、长白、武夷、南岭、横断。它们是人工简化线，不是地形分水岭或精确山脊；门派点位不能用“离折线多少像素”推断海拔。

### 9.5 不绘现代边界

底图只用陆地海岸，不绘现代国界、省界和争议边界，原因有三：

1. 十四书界跨 11–18 世纪，现代边界会制造时代错置；
2. 本图关注江湖路线而非政区主权；
3. 避免 Natural Earth 现代行政多边形被误读为历史疆域。

政权与势力范围应由书界 UI 以低对比墨洗覆盖，并由 `design/11` / chapters 提供时代数据。

## 10. 与其他文档和运行时的接口

### 10.1 `design/11`：区域玩法定稿

`design/11` 应：

- 采用或迁移本文 19 个 `rg_*` 草案；
- 为每个书界给 `entryState`、势力、资源点、营生营业状态与旅行事件；
- 维护区域邻接与可进入条件；
- 不重写 WGS84、历史名称和投影；发现史实问题时回提本文修订。

建议消费键：`cityId + chapterId`。不要以显示名作主键，因为同一地点会从汴梁变开封、临安变杭州、中都变大都/北京。

### 10.2 `design/14`：大地图 UI

UI 应实现：

- 时代组切换、缩放和平移；
- 城市/门派/驿站/码头/任务的筛选；
- 标签避让与聚类；
- 键盘列表、搜索与读屏替代；
- 图外题签点击后的专线确认页；
- P53 的“目的地选择 → 旅行结算 → 加载区域”，不让角色在 SVG 上自由走格。

UI 可以隐藏隐世 `H`，直到线索解锁；SVG 中保留半透明节点是设计审查需要。

### 10.3 `design/17`：门派矩阵

门派 ID、名称、开放状态仍由 17 定义。本文只拥有落点与绘图精度。两边同步检查：

```text
set(sects.yaml.sects.id) == set(design/17 §3 matrix IDs) == 99 IDs
availability[sect][ch] == design/17 §3 cell
```

S1 的地图建议在本文已被正式落点；确址待考并不意味着可以随意移动，修改时须留下迁移说明。

### 10.4 `tech/02`：世界层，而非战斗地形

`tech/02` §7 已明确江湖大地图 SVG 属世界层/UI，不进入 `RegionMapJson` 构网路径。禁止：

- 把海岸多边形三角化为可行走地面；
- 从大地图山笔推导高度；
- 把路线折线当作单位寻路网格；
- 让六角战斗坐标与经纬度直接换算。

区域加载后使用自己的高度、地形、物件与六角坐标。世界层只保留目的地与旅行状态。

### 10.5 `tech/06`：资产格式与分包

当前 SVG 是审查友好的生成源。按 `tech/06`：

- 地图作为 DOM 图像，生产基线转 WebP；
- low 使用 2048 单图；mid/high 使用 4096 并切 512² 瓦片；
- SVG 图标可保留矢量，但整张世界图的生产交付仍服从 DOM 地图格式；
- 共同底图宜进共享“区域基础包”，`chNN` 的时代状态/标签进时代状态包；
- 当前 `tech/06` 仍写每书界 `base` 含“大地图”，需按 AR-04 去重为共享底图 + 时代增量（报告 §6 登记）。

建议素材键：

```text
map/jianghu_world/base
map/jianghu_world/ch01
...
map/jianghu_world/ch14
```

具体键语法与清单仍以 `tech/06` 为准；本文不擅自新增资产 ID。

### 10.6 chapters 接口

每部书界文档只需引用：

```yaml
worldMap:
  base: map/jianghu_world/base
  era: ch04
  initialCity: city_beijing
  entryOverrides: ...   # 归 design/11 / 当前 chapter
```

章节不得复制城市经纬度或改写历史名；剧情别名可放本地文案，但必须关联同一个 `city_*`。

### 11.1 环境


### 11.4 只生成一个时代

```bash
python3 tools/map/render_map.py --render --era ch08 --out /private/tmp/tianshu-map
```

### 11.6 确定性

确定性来自：

1. 输入字段与数组顺序固定；
2. 不调用系统时间、网络或 `random`；
3. 山笔与标签扰动由 `SHA-256(id)` 前两字节决定；
4. SVG 数值统一保留两位并去尾零；
5. 滤镜 seed 固定为 19 / 11；
6. 输出换行固定为 LF；
7. `metadata` 不写当前时间。

本次已连续渲染两次并比较全部 15 文件 SHA-256，结果完全一致。

### 11.7 文件大小

| 文件类型 | 本次范围 | 硬上限 |
|---|---:|---:|

| 单时代 SVG | 167,533–185,243 B | 2 MiB |

1. 全仓搜索拟用 ID；
2. 在相应 `.yaml` 增改记录；

5. 跑 `--check`；

7. 再跑一次并比较哈希；
8. XML 解析全部 SVG；
9. 人工抽查至少 ch01、ch04、ch08、ch14。

## 12. 风险与迁移

- **历史地名**：189 城 × 6 时期中标**（待考）**者仍需历史审校；修订显示名、状态或迁移坐标时保留稳定 `city_*`。Natural Earth 只供海岸，GeoNames 只供现代坐标，CHGIS 只作历史交叉核对。
- **小说驻地**：黑木崖、凌霄城、绝情谷、侠客岛等没有可证精确 WGS84；UI 必须连同 `coordinate_precision` 展示“小说锚点 / 待考”。
- **标签密度**：所有点保留 DOM ID / `<title>`，静态图只常显都城、`major` 城与 `O` 门派；全国/区域层级避让与聚类归 `design/14`。
- **滤镜性能**：MDN 记载 `feDisplacementMap`、`feTurbulence` 已广泛可用，但低端 WebView 仍**（待实测）**；低档可用构建期 2048 WebP，无滤镜时仍保留纸色、折线与符号。
- **区域迁移**：11 若拆 `rg_*`，须给旧→新迁移表，只更新城市 `region`，不改城市、门派、路线 ID，然后重跑校验与渲染。

## 14. 本文新增术语与 ID

### 14.1 术语 / 约定

| 术语 | 定义 |
|---|---|
| 统一江湖大地图 | 共享 WGS84 几何与稳定 ID、由书界时代层改变名称/地位/开放的导航层 |
| 时代图层 | `era-ch01`…`era-ch14`；只承载当前书界可见城市、门派、路线与图外题签 |
| 城市地理语义 | 一个跨时代稳定 `city_*`；显示名与治所位置可随时代变 |
| 治所迁移 | `seat_moves[]` 对特定时期覆盖默认城市投影点 |
| 小说锚点 | 为不可考虚构地点指定的稳定玩法坐标，不宣称现实确址 |
| 图外节点 | 超出 73–135°E / 18–54°N 画布、只在题签框出现的目的地 |
| 图外专线 | 两端式、不含中继、只能从驿站或货船码头登乘的 `offmap_special` 路线 |
| 岸线容差掩膜 | 为小岛/简化海岸或小说岛屿显式加入的点在陆地侧校验圆 |
| JSON-compatible YAML | 同时满足 JSON 与 YAML 1.2 的数据子集，保证标准库可读 |
| 水墨三级 | 深墨、中墨、淡墨；朱砂只作强调，不算第四级墨 |

### 14.2 ID 前缀

| 前缀 | 归属 | 本稿数量 / 例 |
|---|---|---|
| `city_*` | 城市、历史治所与图内地点 | 189；`city_beijing`、`city_xiakedao` |
| `sect_*` | 门派 / 组织 | 复用 17 的 99，不新增语义 |
| `offmap_*` | 图外目的地 | 3；`offmap_mingjiao_persia` |
| `post_*` | 驿站 / 军驿 | 24；`post_kashgar` |

### 14.3 禁止的命名行为

- 不复活 `sect_huashan04`、`sect_jingangmen`、`sect_hengshan`。
- 不用显示名作为 ID；`中都 / 大都 / 北京` 都关联 `city_beijing`。
- 不给每时代复制 `city_beijing_chNN`；时代是状态维度。
- 不把图外目的地命名成 `city_*`，也不让普通 `route_*` 偷接图外节点。
- 不把门派分舵伪装成新的 `sect_*`。
