## 0. 约定与符号

### 0.1 通用符号

| 符号 | 含义 |
|---|---|
| `Lr` | 真实等级（1–70，只增不减，基准 §3.4） |
| `Ld` | 显示等级；普通单位 `min(Lr, chapterCap)`，登记 `capExempt` 的 Boss 见 §9.1；**本文所有公式中的等级一律用 `Ld`** |
| `g` | 品阶 1–12（基准 §4）；`g_eff` = 经天道压制后的有效品阶 |
| `G(g)` | 基准 §4 的品阶系数（1.00 … 3.50） |
| `layer` | 武功层数 1–10；`layer_eff = min(layer, layerCap)`（高武 10 / 中武 9 / 低武 8） |
| `con` `str` `agi` `wis` `wil` `luk` `cha` | 先天属性的**最终值**（含临时加值，见 §2.1），公式中直接用 ID |
| `x⁺` | `max(0, x)` |
| `clamp(x, a, b)` | 截断到 [a, b] |
| `⌊x⌋` | 向下取整 |
| `Σflat_S` / `Σpct_S` / `Σpp_S` | 属性 S 的全部"固定加值 / 百分比加值 / 百分点加值"之和（§11） |
| `HP_LV(L)` `MP_LV(L)` `ATK_LV(L)` `DEF_LV(L)` | 等级基准曲线（§3.1），**全项目唯一的等级缩放源** |
| `STD(L)` | 标准主角参考模型（§3.5），供伤害公式与敌人模板校准 |
| `MPREF(L)` | 耗内基准 = `STD(L).mpMax`（§3.5），design/05 招式耗内的乘数 |
| `P_actual` | 实际招式威力指数 = `G(g_eff) × L(layer_eff) × move.power × Mod_armed × Mod_special`（04 §4.1） |
| `P_ref(L, tier)` | 等级期望威力指数（§3.5）；04 的 Z1 只除一次 |
| `【建议值】` | 本文替下游文档给出的暂定数，下游定稿后以下游为准 |

### 0.2 属性的数值形态

每个属性属于且只属于一种形态，形态决定它能接受哪些修饰（§11.2）。

| 形态 | 代码 | 说明 | 允许的修饰 | 例 |
|---|---|---|---|---|
| 先天 | `INN` | 1–100 的人物底子，永久值 + 临时加值 | 仅 `flat` | `con` |
| 资源 | `RES` | 有当前值与上限的池 | 上限按 `MAG` 处理；当前值只由结算改变 | `hp`/`hpMax` |
| 量值 | `MAG` | 随等级曲线放大的绝对量，参与比值运算 | `flat` `flatLv` `pct` `mult` | `atkOut` |
| 评级 | `RAT` | 与对手的对应评级做**差值**比较的点数，不随等级放大太多 | `flat` `pct` | `hit` vs `eva` |
| 百分点 | `PCT` | 直接就是百分数（单位 pp），只做加法 | `pp` | `resPoison`、`counter` |
| 标志 | `FLAG` / `ENUM` | 布尔、整数等级或枚举 | 规则派生（不进入数值型 `StatModifier`） | `dualWield`、`swimLevel`、`mpNature` |

> 例："攻击 +10%"是属性修饰（`atkOut` 的 `pct`）；"伤害 +10%"**不是属性**，是基准 §9 的 Z3 增伤。两者乘区不同，数据中必须区分。

### 0.3 取整与确定性

- 属性管线内部保留精度，**面板属性在最终边界四舍五入为整数**；百分点配置转换为整数万分点（`BP=10000`）后进入战斗核心。`design/04` 的 Z1–Z10 每个乘区结束向下取整，概率最终向下取整并钳制；资源回复和伤害等结算量按其归属公式向下取整。
- `MPREF` 与招式资源成本按非负数四舍五入；正成本最低 1，显式零成本保持 0。实现统一用 half-up，不依赖语言默认的 bankers rounding。
- 同一属性的修饰按 `(sourceType, sourceId, modifierId)` 字典序求和；三元组在一次属性快照内必须唯一，保证一项来源可合法提供多个修饰且跨平台结果一致（玩法核心为确定性，基准 §19）。

## 1. 属性分层总览

### 1.1 分层图

```
                         ┌────────────────────────────────────────────────┐
  创角 / 修为突破 / 奇遇 │ ① 先天属性 INN   con str agi wis wil luk cha    │  永久值(≤100/120) + 临时加值，最终 ≤120
  丹药 / 装备 / Buff ───►└──────────────┬─────────────────────────────────┘
                                        │  × 等级基准曲线 HP_LV/MP_LV/ATK_LV/DEF_LV (Ld)
                                        ▼
  内功(主运/辅运) ─────► ② 资源 RES   hpMax mpMax staMax shieldMax │ hp mp sta rage shield │ mpNature
                                        │  mpMax → atkIn / defIn
                                        ▼
  装备 / 套装 / Buff ──► ③ 战斗属性    MAG: atkOut atkIn defOut defIn spd
  轻功武学 / 天书之力    (22 项)        RAT: hit eva parry pierce crit tough effHit effRes
                                        PCT: critDmg counter combo seal healPower healRecv
                                        格:  mov jump      轻功: qinggong（→ jump、eva、地形门禁）
                                        ▼
                         ④ 抗性 PCT    resPoison resGu resSeal resInjury resCold resHeat resMind resCC
                                        （+ 抗性品阶 resGrade，与 Buff 品阶对抗）
  ────────────────────────────────────────────────────────────────────────────────────────────
  使用武功 / 修炼 ─────► ⑤ 武学资质 0–100  apFist … apLight（13 项）→ 伤害 Z5、修炼速度
  使用 / 拜师 / 典籍 ──► ⑥ 技艺 0–100     med poi antidote forge alchemy formation music art chess speech
  剧情 / 抉择 ────────► ⑦ 江湖/探索属性 morality fame lore dualWield swimLevel
```

- ①→④ 是**战斗链**：每次重算都从先天属性开始向下推导（§11.4）。
- ⑤⑥⑦ 是**成长链**：不随等级曲线缩放，不受天道压制（§9），跨书界完整保留（`fame` 例外，见 §8.4；`swimLevel` 的行为定义只引用 08 §4.2.3）。

### 1.2 计算顺序（有向无环，必须按此顺序求值）

| 步 | 求值对象 | 依赖 |
|---|---|---|
| S0 | `Ld`、境界参数（layerCap、suppress） | `Lr`、当前书界 |
| S1 | 先天最终值（7 项） | 永久值、修为突破分配（按 `Ld` 生效）、临时加值 |
| S2 | 内功贡献 `innerMpPct` `innerHpPct` `attrs` `mpRegen`（05 §5.5，落点 §3.4）与主运派生项 | 装配内功的 `g_eff`、`layer_eff`、主/辅运比例 `auxRatio`（含相冲/桥接） |
| S3 | `hpMax` `mpMax` `staMax` | S1、S2、装备、Buff |
| S4 | `atkIn` `defIn`（依赖 `mpMax`）、`atkOut` `defOut` | S1、S3 |
| S5 | `qinggong` | S1、`apLight`、轻功武学、主运内功、装备 |
| S6 | `hit` `eva`（依赖 `qinggong`） `parry` `pierce`（依赖 `lore`） `crit` `tough` `effHit` `effRes` | S1、S5 |
| S7 | `spd` `mov` `jump` | S5；移动点最终换算另由 09 消费完整 `qinggong` |
| S8 | 百分点类：`critDmg` `counter` `combo` `seal` `healPower` `healRecv`、8 项抗性、次级属性 | S1、技艺、资质 |
| S9 | `shieldMax` | S3 |

> 任何修饰器不得引用"同步或更晚"步骤的属性作为自身的输入（例如 Buff "按闪避的 10% 提升攻击"不被允许，因 `eva` 在 S6、`atkOut` 在 S4）。若确需此类效果，由 design/06 以"战斗中快照值"实现，不进入面板计算链。

## 2. 先天属性与创角

### 2.1 先天属性的构成

```
perm_X  = create_X + origin_X + talent_X + Σ realmAlloc_X[r | r 已按 Ld 生效] + Σ permBonus_X(奇遇/丹药/天书之力)
perm_X  = clamp(perm_X, 1, cap_X)            cap_X = 100 + 5 × breakCount_X   （breakCount ≤ 4 → cap ≤ 120）
temp_X  = Σ flat_X(内功贡献 attrs、装备词条、内功特有被动、套装、Buff)   （可为负）
X       = clamp(perm_X + temp_X, 1, 120)     ← 公式中使用的"最终值"（基准 §6：先天上限 120）
```

| 规则 | 说明 |
|---|---|
| 只接受 `flat` | 先天属性**不接受百分比修饰**，避免"根骨 +10%"式滚雪球 |
| 突破上限 | 只有标记 `breakCap: true` 的奇遇/丹药能让某项 `cap_X` +5（每项最多 4 次）；每书界此类资源 ≤ 2 个【建议值：10 已落实丹药份额，奇遇投放待 11】 |
| 临时值可超 100 | 例：根骨永久 100 + 内功 `attrs` +8 + 装备 +7 → 115 参与计算；最终上限 120（与基准 §6、design/05 §5.5 一致），超出部分无效并在面板显示为灰色 |
| 负值保护 | 最终值 ≥ 1；所有含 `(X − 50)` 的乘法项另有下限（见各公式） |

## 3. 等级成长曲线

### 3.1 等级基准曲线（全项目唯一的等级缩放源）

```
B(L, k)   = k × (L − 1) × max(0, 1 − (L − 1) / 34)        // 新手补偿项：Lv2–34 为正，Lv1/Lv35+ 为 0
HP_LV(L)  = 300 + 4.10 × (L − 1)² + B(L, 20)
MP_LV(L)  = 200 + 2.45 × (L − 1)² + B(L, 12)
ATK_LV(L) = 0.20 × MP_LV(L)                                // 外内同源：裸装标准人 atkOut ≡ atkIn
DEF_LV(L) = 0.15 × MP_LV(L)                                // = 0.75 × ATK_LV
```

设计要点：
1. **二次曲线**贴合基准 §5 的三个锚点（纯幂函数拟合指数 ≈ 2.02）。
2. 纯二次曲线在前 10 级几乎不涨（Lv1→2 仅 +4 气血），所以叠加补偿项 `B`：它在 Lv1 与 Lv35 严格为 0，**不改变任何锚点**，只让新手期每级有 +8%~10% 的体感成长。
3. `ATK_LV`、`DEF_LV` 直接取自 `MP_LV`，使"内力深厚"与"攻防成长"同源；裸装时 `atkOut : atkIn : defOut : defIn` 的比例在全等级段恒定；典型配装下也只在小幅区间漂移（见 §3.5 比例列），伤害公式配合 `P_ref` 归一后只需一组常数即可覆盖 1–70 级。

### 3.2 锚点校验（主角、裸装、先天 50、无内功）

| Ld | `hpMax` | 基准 §5 | 偏差 | `mpMax` | 基准 §5 | 偏差 |
|---|---|---|---|---|---|---|
| 1 | 300 | ≈300 | 0% | 200 | ≈200 | 0% |
| 35 | 5,040 | ≈5,000 | +0.8% | 3,032 | ≈3,000 | +1.1% |
| 70 | 19,820 | ≈20,000 | −0.9% | 11,864 | ≈12,000 | −1.1% |

> "裸装"在本文定义为：先天七项 = 50、未装配任何内功、无装备、无 Buff。实际玩家的典型值见 §3.5 STD 模型（合法普通配装下 Lv70 气血约为锚点的 `40,409/19,820≈2.04`，即约 2.0 倍；内力约为 `28,887/11,864≈2.44`，即约 2.4 倍，主要来自内功贡献）。

### 3.6 等级封顶后的成长

- 角色达到当前书界 `chapterCap` 后，新增角色经验按 `design/13` §2.6–§2.7 转为**修为余韵**，不再提高 `Lr`；一次发奖跨阈值时先扣到上限所需经验，再转换余量。修为余韵与武功达到层数上限后产生的 `latentExp`（积蕴）是两种资源，不能互换。
- 进入中、低武书界时，普通单位按 `Ld=min(Lr,chapterCap)` 重算属性；此后横向成长来自重新习得/补齐武功、装备、资质、先天、经脉和天书之力。该机制体现“武林衰败、高手亦受时代边界约束”，但不抹除存档里的真实等级与历史成长。
- 取得第十四本天书时由 `design/13` 将 `Lr` 补至 70；雪山余韵期仍按 `Ld=58`，只有正式进入终局容器后才切为 `Ld=70`。
- 运行态等级进度只读取 `design/13` §2.9 的 `ExpState.realLevel` 与整数定点 `expFp`（`EXP_SCALE=100`）；属性快照中的 `Lr` 是 `realLevel` 的只读投影。本文不保存浮点 `exp`，也不自行发放、舍入或迁移经验。

## 4. 战斗属性派生公式

> 通式（§11.2）：`S = (Base_S + Σflat_S) × max(floor_S, 1 + Σpct_S) × Πmult_S`，然后 `clamp` 到 S 的范围。下面只写各属性的 `Base_S`、专属项、下限与范围。`floor_S` 缺省：MAG 取 0.2，RAT 取 0.2。

### 4.1 攻防四项（MAG）

| 属性 | `Base` | 专属 flat 来源 | 范围 |
|---|---|---|---|
| `atkOut` | `ATK_LV(Ld) × max(0.5, 1 + 0.010 × (str − 50))` | 主手兵器主属性、副手副兵器 | ≥ 1 |
| `atkIn` | `0.20 × mpMax` | 少数饰品/Buff | ≥ 1 |
| `defOut` | `DEF_LV(Ld) × max(0.5, 1 + 0.006 × (con − 50) + 0.002 × (str − 50))` | 衣、头、护手、腰带、鞋、盾 | ≥ 0 |
| `defIn` | `0.15 × mpMax` | 衣（内衬）、特定饰品 | ≥ 0 |

- `atkIn`/`defIn` 取**最终** `mpMax`（S3 已含内功与 Buff），所以"内力上限 −20%"类减益（如化功类武学）会同时削弱内劲攻防——这是有意的"化人内力"手感。
- 当前内力 `mp` 不影响 `atkIn`；"内力不足时招式威力下降"如需实现，归 design/04（Z1）或 05。

**装备主属性接口（已由 design/10 §3–§4 定稿）**。`flatLv` 是按当前 `Ld` 的基准曲线缩放的固定值，`G` 取装备的使用品阶 `gUse`；强化、断兵、兵器类别 `kA`、重兵标签 `tagK` 与衣甲 `kD/kI` 均先由 10 解析后再注入本文管线：

| 部位（基准 §20） | 主属性 | 系数 |
|---|---|---|
| 主武器 `mainHand` | `atkOut` | 基准型 `0.30 × G(gUse) × ATK_LV(Ld)`；类别、标签和强化见 10 §4.1 |
| 衣 `body` | `defOut` / `defIn` | 中甲基准 `0.20 × G × DEF_LV` / `0.10 × G × DEF_LV`；轻/中/重甲系数见 10 §3.4 |
| 头 `head`、护手 `hands`、腰带 `waist`、鞋 `feet` | `defOut` / `hpMax`（每件） | `0.05 × G × DEF_LV` / `0.01 × G × HP_LV` |
| 鞋 `feet` 额外 | `qinggong` | `2.5 × g_eff`（固定点，不随等级缩放） |
| 副手 `offHand` | 副兵器基准 `atkOut 0.10×G×ATK_LV`；牌 `parry +(10+3×G)`、`defOut 0.10×G×DEF_LV`；暗器囊/名门暗器见 10 §3.1、§3.5 | — |
| 佩饰 `accessory` | 玉佩任一评级 `+2×gUse`；香囊任一抗性 `+gUse` pp；念珠见 10 §3.1 | — |

> 采用 `flatLv`（随显示等级缩放）而不是写死数值的原因：装备跨书界携带，显示等级会上下变化；`flatLv` 让一件装备在任何等级都保持"同品阶同强度"，天道压制只需降低 `g_eff`（§9.3）。

**兵器类别招架底值 `P_wpn`（10 §3.2 已确认）**：剑 12、刀 10、棍杖 16、枪 12、鞭索 4、奇门 8、空手 0；`heavy` +4、`soft` −4（最低 0）。空手招架来自武学被动，如太极拳。

**攻击合成（design/04 §4.1–§4.2 已采纳）**：招式带“内劲比例” `r_in ∈ [0, 1]`（05 定义），

```
ATK_mix = (1 − r_in) × atkOut + r_in × atkIn
DEF_mix = (1 − r_in) × defOut + r_in × defIn        // 守方按攻方招式的 r_in 取防御
```

```
P_hit   = clamp(0.85 + 0.004 × (hit − eva),      0.40, 0.99)
P_parry = clamp(0.12 + 0.004 × (parry − pierce), 0.00, 0.60)
P_crit  = clamp(0.10 + 0.004 × (crit − tough),   0.02, 0.75)
P_eff   = clamp(baseChance × clamp(1 + (effHit − effRes) / 100, 0.3, 2.0)
                × (1 − res_eff/100) × extraFactor, 0, 1) // 本文 res_eff 用百分数；传入 04 时转小数
```

STD 同级下的结果：`P_hit` 96%（Lv1）→ 93%（Lv35）→ 91%（Lv70）（高手过招更难命中，属有意为之）；`P_parry` 21% → 19% → 17%；`P_crit` 恒 ≈ 12%（完整表见 §4.9）。

### 4.3 速度 `spd` 与集气接口

```
Base_spd = 72 + 0.30 × agi + 0.10 × Ld + 0.14 × qinggong
spd      = clamp(⌊(Base_spd + Σflat_spd) × max(0.2, 1 + Σpct_spd) × Πmult_spd⌋, 30, 300)
```

`qinggong` 已包含身法、显示等级、轻功武学、轻功资质、鞋、主运内功与负重；上式仍给 `agi` / `Ld` 较小的独立权重，以免脱卸轻功后速度完全坍缩，但**不得**再把 `Q_skill` 或 `Q_agi/Q_lv` 分项重复加入。速度修饰通过 `flat` / `pct` / `mult` 管线进入；完整乘算后只在末尾向下取整。“停止集气”不把速度改成 0，而由 09 冻结时间轴。

本文只输出属性快照中的最终整数 `spd`，交给 21 时语义名为 `baseSpd`；它不是把战斗经脉状态写回属性表后的值。开战前先按本节完成属性取整，随后 `design/21` §4.9 才可读取 `baseSpd` 并投影战斗速度。参考：合法 STD `baseSpd` 为 91（Lv1）/ 106（Lv35）/ 126（Lv70）。Lv35 用未取整 `agi=58.576`、未取整 `qinggong=97.794`，得 `floor(72+0.30×58.576+0.10×35+0.14×97.794)=106`；Lv70 的普通鞋受 `gGear=min(gref,9)` 限制，`qinggong=193.7975`，故 `floor(72+0.30×69.35+0.10×70+0.14×193.7975)=floor(126.93665)=126`。不能用未封顶的 11 品普通鞋把轻功写成 198.7975 后反推出 127。

AR-14 的战斗速度接线固定为：

```text
属性快照：effectiveQinggong = roundHalfUp(qinggong)，baseSpd = spd，baseMove = 09 的合法移动点
21 输出：combinedSpeedBp = floor(meridianSpeedBp × grappleMoveBp / 10000)
         openingQinggong = floor(effectiveQinggong × combinedSpeedBp / 10000)
         spd' = clamp(floor(baseSpd × combinedSpeedBp / 10000), 30, 300)
         move' / evadeRatingDelta 见 design/21 §4.9
```

首轮接口的 `effectiveQinggong` 是 §0.3 最终显示边界的 half-up 整数；`baseSpd` 仍须先用未取整轻功完成本节公式，禁止把该整数倒灌重算速度。上框只是 `design/21` §4.9 的接线镜像：其 TypeScript 结果字段实际名为 `openingQinggong/spd/move/evadeRatingDelta`，其中正文记号 `spd'`、`move'` 分别对应字段 `spd`、`move`，不得把撇号写进 schema。

`meridianSpeedBp` 是 21 以已含同路线 STD 归一完成质量的 `MeridianProfile` 直接查曲线所得，标准 10000 bp、硬界 6500–13500 bp；不得把原始 `routeQualityBp` 再混合一次。擒拿在经脉之后进入 `combinedSpeedBp`；其独立 `evadeBp` 由 04 / 06 另结算一次，故 `evadeRatingDelta` 只反映经脉速度，不能同时包含擒拿。

开战首轮由 09 按冻结的 `openingQinggong → MeridianSpeedResult.spd → agi → openingPriority → initiativeSideRank → unitIndex` 排序，不抽随机 `CT0`；战中点穴、胀损、调息或擒拿只使后续 CT / 移动投影变脏，不回溯首轮。其后每 tick 集气、行动阈值、收招、移动力和同 tick 裁决仍由 `design/09` §3 定义。

### 4.4 移动力 `mov` 与跳跃 `jump`

```
jump = clamp(qgTier(qinggong) + Σflat_jump, 0, 6)
qgTier(q) = 0 (q<20) | 1 (≥20) | 2 (≥50) | 3 (≥90) | 4 (≥140) | 5 (≥200)      // 基准 §11
```

`mov` 是 09 在行动开始时计算并回写的**六角基础移动点结果**，供 21 称作 `baseMove`；本文不再给方格时代的基础公式或 1–8 上限。03 向 09 提供：最终 `qinggong` / `qgTier`、`sta` / `staMax`、`Q_load`、装备与 Buff 汇总出的 `flat_mov` / `pct_mov` / `set_mov`，以及疲惫等状态标签；21 再输出 `MeridianSpeedResult.move`（正文记作 `move'`），其 `moveDelta∈[-2,+2]` 且结果钳于 1–10，精确式只见 `design/21` §4.9。六邻距离、地形消耗、移动点钳制和覆写优先级见 `design/09`。这也意味着 `agi` 只能先进入 `qinggong`，不能再独立增加移动点。

- `jump` 只决定**六角战斗地图中单步可跃上的高度差**与**可跨越的沟宽**；平面距离一律用六角距离。台阶、坡道类地形不受 `jump` 限制；下跳免伤高度、跨越消耗等由 `design/08` 定义。
- 探索中的地形门禁判 `qgTier(qinggong)`（**含** `qinggong` 的临时加值——丹药/Buff 是合法钥匙，见 §11.5）；`jump` 自身的 flat 加值只在战斗网格中生效。
- 21 的 `openingQinggong` / `meridianSpeedBp` 只服务战斗首轮、CT、移动与闪避投影；08 的 20 / 50 / 90 / 140 / 200 门禁、`qgTier`、`jump` 与逐格地形成本始终读取本节未乘经脉速度的 `qinggong`，不能靠临时行气越级。

### 4.5 轻功值 `qinggong`（完整公式）

```
qinggong = clamp((Q_agi + Q_lv + Q_skill + Q_ap + Q_eq + Q_inner + Σflat_qinggong − Q_load)
                  × max(0.2, 1 + Σpct_qinggong), 0, 300)

Q_agi   = 0.25 × (agi − 30)⁺                       // 身法 50→5，80→12.5，100→17.5，120→22.5
Q_lv    = 0.30 × Ld                                // Ld 35→10.5，50→15，70→21
Q_skill = QS(g_eff) × (0.40 + 0.06 × layer_eff)     // 装配中的轻功武学（轻功栏 1 格，基准 §20）
Q_ap    = 0.15 × apLight                           // 0–15
Q_eq    = Σ 装备 qinggong（鞋主属性 2.5 × g_eff + 词条）
Q_inner = 3.0 × G(g_eff,主运) × layer_eff,主运 / 10  // 仅主运内功，0–10.5
Q_load  = 装备负重惩罚（10 §3.2、§3.4：重甲 10、heavy 重兵 15，可合计 25；背包物品无重量）
```

## 5. 资源规则

### 5.1 气血 `hp` 与上限

```
hpMax = ( HP_LV(Ld) × max(0.5, 1 + 0.008 × (con − 50)) + Σflat_hpMax ) × max(0.2, 1 + Σpct_hpMax) × Πmult
mpMax = ( MP_LV(Ld) × max(0.5, 1 + 0.006 × (wil − 50) + 0.004 × (con − 50)) + Σflat_mpMax ) × max(0.2, 1 + Σpct_mpMax) × Πmult
```

- `Σpct_hpMax` 含：内功贡献 `innerHpPct`（§3.4）、内功特有被动、装备词条、套装、Buff、丹药/传功永久加成、永久创伤（负值）、天书之力。
- **丹药永久加成一律用 `pct` 存储**（例：服食某灵物 `mpMax +8%` 永久），避免低级时服用的固定值在高级时失去意义；全程封顶：`hpMax` 永久 pct ≤ +30%、`mpMax` 永久 pct ≤ +40%【建议值：10 已按此分配丹药份额，传功份额待 05 定稿】。
- 上限变化时的当前值规则：

| 场景 | 当前值处理 |
|---|---|
| 战斗中上限提高 Δ（Buff） | 当前值 +Δ |
| 战斗中上限降低 | 当前值 = min(当前值, 新上限)；Buff 结束恢复上限时**不**返还 |
| 战斗外换装/换内功/等级变化 | 保持百分比：`cur = cur_old / max_old × max_new` |
| 书眠醒来 | 全满（`hp`、`mp`、`sta`），`rage`、`shield` = 0 |

### 5.2 内力 `mp` 与内力性质 `mpNature`

**性质来源**（机制本体归 design/05 §5.1–5.4，本文只定义它对属性的影响）：
- 每门内功带 `nature ∈ {yang, yin, harmony}`（05/图鉴逐门指定；05 §5.3 已给出代表：九阳/先天功/龙象/蛤蟆功为阳，玉女心经/吸星/葵花/寒冰真气为阴，易筋经/九阴总纲/太玄经/小无相功为调和——均为游戏化判定）。
- `mpNature` = 主运内功的 `nature`；标记 `natureFollowAux` 的内功（乾坤大挪移、斗转星移类）作主运时取品阶最高辅运的性质（05 §5.7）。
- 未装配主运内功：视为调和但**无任何性质加成**（05 相性矩阵"未装配内功"行全为 0）。

| 性质 | 本文的属性效果 | 05 负责的效果 |
|---|---|---|
| `yang` 阳 | `resCold +15pp` | Z5 相性（阳招 +12%/阴招 −12%）、辅运比例、相冲 |
| `yin` 阴 | `resHeat +15pp` | 同上（方向相反） |
| `harmony` 调和 | `resCold +8pp`、`resHeat +8pp` | 调和招 +12%、阴阳招 +4%；桥接 |

**获得"调和"**的途径（均由 05 定义，本文列出以便查阅）：① 主运一门调和内功；② `natureFollowAux` 内功搭配调和辅运。"阴阳相冲"的消解靠**桥接**（装配调和且品阶 ≥ 7 的内功，或 `inner.bridge: true`，05 §5.4），不改变 `mpNature`。

**切换**：战斗外自由调整主/辅运（`mp` 按百分比保留，§5.1）；战斗中使用 05 §5.6 的行动**"易运"**（主运与一门辅运互换，占用本次行动、收招 800、3 回合限 1 次、当前内力 = min(当前, 新上限)）。易运后本文按 §11.4 立即重算：`mpNature`、性质抗性、`innerMpPct`/`innerHpPct`、`mpRegen`、`Q_inner`、`resGrade` 下限同步变化。

**内力回复**：每次自身行动开始时 `mp += floor(真实 mpMax × mpRegen / 100)`，不超过 `mpMax`（§4.8）；封内等暂停回复的状态由 `design/06` 定义。“运功调息”行动的调息分支已由 `design/09` §4.8.4 定稿：立即恢复 15% `mpMax`，本行动未移动再恢复 5%。

**永久内力加成**：丹药与"传功"（05 §8 `inherit`，如无崖子传功虚竹）给予的永久 `mpMax` 加成，数值**【建议值】**：传功者主运天级 +12%、地级 +8%、玄级 +4%；与丹药共用"永久 `mpMax` pct ≤ +40%"的上限（§5.1）。

**给经脉模拟的内力接口**：21 只读取结算后的 `mpMax`、当前 `mp` 与同显示等级 `MPREF(Ld)=STD(Ld).mpMax`，不得把 §3.4 的单门内功 `mpMaxPct` 再加一次。初始化比例为：

```text
mpRatioBp = clamp(floor(mpMax × 10000 / MPREF(Ld)), 5000, 20000)
```

该比值只供 `design/21` §2.3 用整数平方根换算节点容量；`capacity` 不是 `mpMax` 副本，也不是本文的新属性。21 的起始气量 / 逐段注水同样是无量纲运行量，不再从 `mp` 扣除。只有护体内劲结算会读取 `currentMp` 并按 21 §4.8 的 `1 内力抵 2 伤害` 实际扣费；其结果发生在护体真气之后、既有 `mpGuard` 之前，不能回写 `mpMax` 或 `atkIn/defIn`。

### 5.3 体力 `sta`


**消耗（探索，design/08 §4.3 已采纳）**：

| 行为 | 所需境界 | 消耗 |
|---|---|---|
| 疾行（奔跑） | — | 2 / 秒 |
| 纵跃（上高差 / 跨沟），每次 | qg1+ | 4 × 高差级数（或沟宽格数） |
| 攀崖，每级高差 | qg3+ | 5 |
| 踏水，每格 | qg3+ | 4 |
| 树梢移动，每格 | qg3+ | 2 |
| 雪/沙/冰/沼 | qg4+ | 0（被动无减速） |
| 一苇渡江（大江湖面），每格 | qg5 | 3 |
| 云海栈道，每格 | qg5 | 3 |

- **熟练折扣**：`cost × max(0.5, 1 − (qinggong − 该动作所需阈值) / 200)`。例：qinggong 190 踏水（阈值 90）→ ×0.5。
- 这让高阶门禁同时考验"境界"与"续航"：渡 40 格大湖需 120 体力（qg5 刚达标时几乎无折扣），STD Lv60 的 `staMax` 163 可一次渡过；55 格以上的大江需在中途设置落脚点（沙洲、船只，08 配置）。

**恢复**：

| 情形 | 恢复 |
|---|---|
| 探索中 2 秒未消耗 | 每秒 `staMax × staRegen%`（默认 4%，≈6/秒） |
| 打坐（任意安全点，游戏内 1 小时） | 全满 |
| 客栈 / 门派 / 营地 | 全满 |
| 干粮 / 药膳（10 定） | +20 ~ +80 |
| 战斗中每次自身行动开始 | +10 |

**疲惫**：`sta` 降至 0 时获得 `bf_pibei`；恢复到 `sta ≥ ceil(0.20 × staMax)` 时移除。疲惫期间 `eva` flat −15、向 `design/09` 提供 `mov` flat −1（仍受其移动下限约束），禁止疾行、纵跃和所有需要轻功境界的动作；不再额外修改 `spd` 或开场 CT。普通招式**不**消耗体力。Buff 实例、标签和解除事件归 `design/06`，地形动作归 `design/08`。

### 5.4 气势 `rage`（0–100）

| 事件 | 获得 | 备注 |
|---|---|---|
| 自身行动开始 | +3 | |
| 本次行动的招式命中 ≥ 1 个目标 | +8 | 每次行动只计一次 |
| 每多命中一个目标（范围招式） | +2 | 此项上限 +8 |
| 本次行动出现暴击 | +4 | 每次行动只计一次 |
| 受到伤害（含被护体吸收部分） | `+4 + ⌊20 × 伤害 / hpMax⌋` | 单次上限 +15；持续伤害（DoT）不计 |
| 被暴击 | 额外 +4 | |
| 闪避成功 | +5 | |
| 招架成功 | +10 | 基准 §8 |
| 触发反击 | +4 | 反击命中另按"命中"计 |
| 击杀（使敌人倒地） | +15 | 基准 §8 |
| 友方单位倒地 | 全体友方 +20 | "悲愤" |
| 开场 | 自身 `+(wil − 50)⁺ × 0.2`；我方全体再 `+(主角 cha − 50)⁺ × 0.2`；伏击方全体 +20 | |
| 施放绝招 | −100 | 基准 §1 |
| 战斗结束 | 清零 | 不跨战斗保存 |

- 以上所有**获得**乘以 `rageGain / 100`（§4.8），结果向下取整；消耗不受影响。
- 节奏校验：同级普通战斗中，一次典型自身行动约 +3（开始）+8（命中）+6（期间受击一次，约 10% 气血）≈ +17，即**约 6 次行动一记绝招**；Boss 战（12–25 次行动）可放 2–4 次绝招，符合基准 §5 节奏。
- "泄气/鼓舞"类效果（直接增减气势、改 `rageGain`）归 design/06。

### 5.5 护体真气 `shield`

| 项 | 规则 |
|---|---|
| 上限 | `shieldMax = hpMax × (0.25 + Σpct_shieldMax)`，总系数不超过 0.50 |
| 来源 ① 开场护体 | 主运/辅运内功的**特有被动**"护体真气 X% `hpMax`"（05/图鉴），战斗开始时一次性获得，多门相加后受上限截断 |
| 来源 ② 运功护体 | "运功调息"行动的一个分支（09 定义行动本体）：消耗内力 `m` 点，获得 `shield += m × 1.0 × (1 + 0.005 × (wil − 50))` |
| 来源 ③ Buff | 标签 `guard` 的效果（06） |
| 来源 ④ 装备 | 词条（10），如"开场获得 5% `hpMax` 护体" |
| 衰减 | 默认不衰减；战斗结束清零 |
| 结算 | 基准 §9 settle：伤害先扣 `shield` 再扣 `hp`；"破罡"类效果可无视或加倍削减护体（06/04） |
| 与减益的关系（04 §6.2 已定稿） | 一次攻击若被护体**完全吸收**，该次攻击附带的 `injury`、`bleed` 标签效果不施加；其他标签照常判定 |

### 5.6 战后与休息的资源恢复接口

本文只定义 `hp`、`mp`、`sta` 的增减接口；哪些 Buff 跨战、休息降低多少层或品阶、哪些状态只能走专用解法，唯一引用 `design/06` §5.4.2，不在属性文档维护第二张清理表。地点与时间推进由 `design/11`、`design/16` 定义。

| 入口事件 | 本文处理的资源 | 状态处理接口 |
|---|---|---|
| 战斗结束 | 战后调息 `hp += floor(0.10×hpMax)`、`mp += floor(0.30×mpMax)`，均不超过上限；`sta` 不变 | 由 `design/09` §7.4 调度，逐项调用 `design/06` §5.4.2 |
| 探索中自然恢复 | `mp` 每 10 秒 +5% `mpMax`；`sta` 按 §5.3 | 不触发休息清理；见 `design/11` §9.1 |
| 打坐（游戏内 1 小时） | `hp` 恢复至至少 50%，`mp`、`sta` 全满 | 只结算自然世界时间，不触发完整 `onRest`；见 `design/11` §9.2 |
| 客栈 / 门派 / 营地休息 | `hp`、`mp`、`sta` 全满 | 发出同一 `onRest(restType)`，不按地点另写清理规则；见 `design/11` §9.1–§9.3 |
| 医治（`med`，§8.2） | 治疗量走 `design/04` | 发出带医术与药物参数的治疗事件；解除门槛见 `design/06` |

战末阶段的固定顺序为 `onBattleEnd → 清除非 persist 实例 → 跨战实例转 world → 倒地者先结算伤势 bf_shangshi 造成的新 hpMax、再恢复该上限的 10%（同场多次倒地也只增 1 层伤势）→ 战后调息 hp+10% / mp+30% → 奖励`；`bf_shangshi` 的层数、惩罚与解除只引用 `design/06` §5.4.2，执行权威仍是 `design/09` §7.4。所有百分比回复在各自步骤向下取整并封顶。

## 6. 抗性体系

### 6.1 计算

```
res_X = clamp( innateTerm_X + natureTerm_X + Σpp_X , −50, 75 )          // 单位 pp（百分点）
```

| 抗性 | 先天项 `innateTerm`（以 50 为中点，可负） | 专属项 | 主要 `Σpp` 来源 |
|---|---|---|---|
| `resPoison` | `0.2·(con−50)` | `+0.15·antidote` | 内功被动、丹药、奇遇、佩饰、天赋 `tal_yiti` |
| `resGu` | `0.2·(wil−50)` | `+0.10·antidote` | 特定物品（如苗疆类）、Buff |
| `resSeal` | `0.2·(wil−50) + 0.1·(con−50)` | — | 移穴换位类武学、Buff |
| `resInjury` | `0.2·(con−50) + 0.1·(wil−50)` | `+3.0·G(主运)·layer/10`（§3.4） | 内功被动 |
| `resCold` | `0.1·(con−50)` | 阳 +15 / 调和 +8 | 装备、Buff |
| `resHeat` | `0.1·(con−50)` | 阴 +15 / 调和 +8 | 装备、Buff |
| `resMind` | `0.3·(wil−50) + 0.1·(wis−50)` | — | 佛门/道门内功被动、天赋 `tal_xinruzhishui` |
| `resCC` | `0.15·(con−50) + 0.15·(str−50)` | — | 重甲、下盘类武学、Boss 模板（§10） |

### 6.2 上下限与"免疫"的区别

| 项 | 值 | 说明 |
|---|---|---|
| 下限 | −50pp | 负抗性使效果更易施加、更强（06 按 `1 − res` 计算即自然放大） |
| 上限 | **75pp** | 任何来源叠加都不超过 75；超出部分溢出无效（UI 显示灰色溢出值，便于配装） |
| 免疫 | 不属于抗性 | "免疫中毒""免疫中蛊"是**机制类 Buff**（`mechanic`，基准 §10），由 design/06 定义；免疫同样受 Buff 品阶对抗约束 |

### 6.3 抗性品阶 `resGrade` 与 Buff 品阶对抗接口

基准 §10 规定"抵抗只对品阶 ≤ 自身品阶的效果完全生效"。抗性是多来源之和，本身没有品阶，因此为每个抗性标签定义**抵抗品阶**（design/06 §3.5.2 已写明"若 03 另行定义 `resGrade`，以 03 为准"；本文定义与 06 的建议式兼容，只增加 5pp 门槛）：

```
resGrade(tag) = max( g_eff(主运内功) − 3,                                        // 内功护体的底子（06 同式）
                     max{ grade(src) | src 对 res_tag 的贡献 ≥ 5pp },            // 小于 5pp 的零碎来源不抬品阶
                     1 )
  grade(src)：武学被动 / 装备 / 套装 / Buff / 丹药 = 其 g_eff；
              解毒专属项（0.15·antidote 等）= gMax(antidote) = ⌊(antidote + 4) / 8⌋（§8.1）；
              内力性质项（寒/热）= 主运内功 g_eff；先天项不单独计品阶（由"主运 − 3"与下限 1 覆盖）
```

对品阶为 `g_e` 的效果（`Δr = g_e − resGrade`），穿透系数 `ρ(Δ)` **采用 design/06 §3.5.0**（Δ≤0 → 0；Δ≥1 → `min(0.90, 0.15 + 0.15Δ)`，即 0.30/0.45/0.60/0.75/0.90）：

```
res_eff = res_X                         若 res_X ≤ 0（负抗性对任何品阶都全额生效）
res_eff = res_X × (1 − ρ(Δr))           否则
```

- 施加概率采用 design/04 §3.1 的正式式：`P_apply = clamp(baseChance × clamp(1 + (effHit − effRes)/100, 0.3, 2.0) × (1 − res_eff/100) × extraFactor, 0, 1)`；本节 `res_eff` 以百分数表示。
- 持续伤害减免：`resPart = 1 − clamp(res_eff, −50, 75)/100`（06 §5.3.2）。
- "免疫"是机制类 Buff，走 06 §3.5.1 的免疫穿透，不经过本节。
- UI：抗性页每项显示"数值 / 品阶色"，例如"抗毒 36%（地中）"；受穿透时 Tooltip 显示"被〈天中·某毒〉穿透 60%"。

### 6.4 示例

主角 Lv50：`con` 60、`antidote` 40；主运内功地中（g8）且其特有被动"抗毒 +20pp"；佩饰"抗毒 +8pp"（地下 g7）。

| 项 | 值 | 品阶 |
|---|---|---|
| 先天项 `0.2×(60−50)` | 2pp | 不计 |
| 解毒项 `0.15×40` | 6pp | `gMax(40)` = 5 |
| 内功特有被动 | 20pp | 8 |
| 佩饰 | 8pp | 7 |
| 主运底子 | — | 8 − 3 = 5 |
| **合计 / resGrade** | **36pp / 8（地中）** | |

| 来袭毒效果品阶 | Δr | ρ | `res_eff` | `P_apply`（baseChance 60%、effHit = effRes） |
|---|---|---|---|---|
| 地中（8）及以下 | ≤ 0 | 0 | 36.0 | 38.4% |
| 地上（9） | 1 | 0.30 | 25.2 | 44.9% |
| 天下（10） | 2 | 0.45 | 19.8 | 48.1% |
| 天中（11） | 3 | 0.60 | 14.4 | 51.4% |
| 天上（12） | 4 | 0.75 | 9.0 | 54.6% |

### 7.4 对伤害的影响（伤害乘区 Z5 的"资质"部分）

```
apFactor(ap) = 0.80 + 0.004 × ap                       // 0→0.80，25→0.90，50→1.00，75→1.10，100→1.20
A_ap(move)   = (1 − r_in) × apFactor(ap_cat(move)) + r_in × apFactor(apInner)
```

| 招式类别 | `ap_cat` |
|---|---|
| 拳掌/指/腿/擒拿 | `apFist`/`apFinger`/`apLeg`/`apGrapple` |
| 剑/刀/棍杖/枪/鞭索/奇门 | 对应兵器资质 |
| 暗器 | `apHidden` |
| 内功自带招式（若 05 设计） | `apInner`（此时 `A_ap = apFactor(apInner)`） |
| 杂学主动（医/毒/蛊/阵/音律/书画/棋/易容/驭兽/心神） | 无资质，改用 05 §2.3 映射的技艺（或属性）：`artFactor = 0.80 + 0.004 × value`，`value` 取 `med`/`poi`/`formation`/`music`/`art`/`chess`/`cha`/`wil`（**本文确认 05 §2.3 的映射**，含其修炼速度以 `wis` 当资质的约定） |
| 音功 `sonic` | `apInner`（与 05 §2.3 一致），`music` 只作辅助效果强度 |

- `r_in` 为招式内劲比例（§4.1），让"内劲为主"的招式更吃 `apInner`：例如 `r_in = 0.7` 的掌法，`apFist` 40 / `apInner` 80 → `A_ap = 0.3×0.96 + 0.7×1.12 = 1.072`。
- Z5 已由 design/04 §4.5 定稿：`Z5 = A_ap × (1 + 相性加算项 + 破 X 加算项 + 三运同源等)`。design/05 §5.3 提供相性与“破 X”加算项，资质系数 `A_ap` 是 Z5 内的独立乘子。
- STD 参考：Lv1 ≈ 0.90，Lv35 ≈ 0.98，Lv70 ≈ 1.06。

## 9. 天道压制对属性的影响

> 压制规则本体（何为外来、携带数量、残篇）归 design/02；本节只规定**属性如何重算**。

### 9.1 重算清单（进入书界、或 `Ld`/装配变化时）

先求当前规则参数，再进入属性 DAG：

```text
S_base(HIGH/MID/LOW) = 0 / 2 / 4
Ld_normal             = min(Lr, chapterCap)
Ld_capExemptBoss      = min(Lr, 70, chapterCap + delta)
delta(HIGH/MID/LOW)   = 3 / 4 / 6
```

`capExempt` 每书界至多登记 2 名 Boss，且只改变该单位的有效等级上限；不豁免武学品阶、层数、修为门槛或来源限制。以洪安通为例：`min(50,70,44+6)=50`。

| 对象 | 处理 | 影响的属性 |
|---|---|---|
| 显示等级 | 普通单位 `min(Lr,chapterCap)`；`capExempt` Boss 用上式 | 所有 `*_LV(Ld)` 曲线项：`hpMax` `mpMax` `atkOut` `defOut` 基础值、`flatLv` 装备值、评级中的 `Ld` 项、`qinggong` 的 `Q_lv`、`staMax`，以及 04 的 Z8 |
| 修为突破分配 | 只计 `Ld ≥` 突破等级的 `realmAlloc[r]` | 先天 → 全部派生 |
| 武功层数 | `layer_eff = min(layer, layerCap)`（10/9/8） | 内功贡献（05 §5.5）与特有被动、`Q_skill`、`Q_inner`、`mpRegen`、`resInjury`；招式威力（04） |
| 外来武功品阶 | `g_eff = max(1, g − suppress)`（0/2/4） | `G(g_eff)` 进入以上所有被动；Buff 品阶（06）；套装品阶（07）；抗性品阶（§6.3） |
| 外来装备品阶 | `g_eff = max(1, g − suppress)` | 装备主属性（`0.30×G(g_eff)×ATK_LV` 等）、鞋 `2.5×g_eff`、词条（10） |
| **不变** | 永久先天（突破分配除外）、资质、技艺、`lore`、`morality`、天赋、丹药永久加成、天书之力（13 另定） | — |
| 当前值 | 书眠醒来全满（§5.1） | `hp` `mp` `sta` |

天书之力只把 `design/13` §4.5 已算出的武学/装备 `g_eff` 与本命 `layerCap_eff` 交给本文，不改 `Lr`、`Ld`、修为门槛、真实层数或来源限制。`bf_tsp_xianying`“天书现影”才会限时令品阶压制为 0、书界层数上限为 10（仍检查修为、真实层数和来源）；`bf_tsp_weiguang`“天书微光”只抵消 1 小品且仍受 `ceil(S/2)` 下限，不解层数封印。终局 `bf_tsp_xianying_fin` 只进入 Z3/Z4，不生成属性 `mult`；三者定义与计时均见 `design/06` §5.4、`design/13` §4.6。

自愿规则同样只覆写明确字段：`tj_tiandao` 自第 6 重起把中/低武的基础压制改为 3/5；互斥的 `rule_wutiandao` 关闭品阶压制并把书界层数上限设为 10。二者都保留等级、修为、真实层数、武学特殊上限和来源约束，具体开关与成就后果见 `design/13` §5.2–§5.3。

UI：被压制的武功/装备在图标上显示"天道"角标，品阶色按 `g_eff` 着色，Tooltip 显示"倚天剑 天阶上品 → 地阶中品（中武 −2 … 低武 −4）"；属性面板被压低的数值旁显示向下箭头，悬停可见未压制值。

### 10.6 模板敌人的威力归一（design/04 §4.1、§9 已采纳）

模板敌人的招式在 Z1 中**不用自身品阶的 `G × L(n)`**，而是：

```
P_enemy = P_ref(L_敌, tier) × tmplPower           // §3.5；tmplPower 见 §10.3
```

理由：02 的品阶骰让杂兵/精英的武学品阶普遍低于同级主角；模板法若直接使用随机所得 `G×L(n)`，其基础伤害会和属性模板重复降档。替换后，品阶仍决定附带 Buff 品阶、特效、掉落与招式池，模板攻击节奏由 `tmplPower` 与遭遇参数控制。`full` NPC 不做这项**模板替换**，而是使用真实 `P_actual`；两种方式都必须在 Z1 除且只除一次 `P_ref`。正式公式与模拟见 `design/04` §4.1、§9。

### 11.2 叠加管线："基础值 → 加值 → 百分比 → 最终值"

对每个属性 S（按 §1.2 的步骤顺序逐个求值）：

| 步 | 名称 | 规则 |
|---|---|---|
| ① | 基础值 `Base_S` | 由等级曲线 × 先天系数 + 固有常数给出（§3–§6 各公式的 `Base`） |
| ② | 加值 `Σflat_S` | 所有 `flat` 与 `flatLv`（后者先按 `Ld` 解析为数值）**相加** |
| ③ | 百分比 `Σpct_S` | 所有 `pct` **相加**（同属性的加成彼此加法，不连乘）；负值（减益）同池相加 |
| ④ | 独立乘数 `Πmult_S` | 仅限归属文档明确标注 `mult` 的系统层来源；当前已定来源只有敌人模板/流派/难度。`tianshu`、`title`、`meridian` 与 `terrain` 不得自行进入本乘区 |
| ⑤ | 合成 | `S = (Base_S + Σflat_S) × max(floor_S, 1 + Σpct_S) × Πmult_S` |
| ⑥ | 百分点 | PCT 形态属性：`S = Base_S + Σpp_S`（没有②–④） |
| ⑦ | 截断 | `clamp(S, min_S, max_S)`（§12 汇总各属性范围） |
| ⑧ | 覆写 | 机制类 `override`（如"`resCC` 视为 75"、"`hpMax` 锁定为施加时的值"）最后生效，多个覆写取最新施加者；"停止集气"不用覆写实现（§11.5 #3） |

- `floor_S`：MAG/RAT 为 0.2（即任何减益叠加最多把属性压到 20%）；资源上限 `hpMax`/`mpMax` 同为 0.2。
- 与伤害乘区的关系：本管线产出的是**面板属性**。"伤害 +X%"进 Z3、"受到伤害 −X%"进 Z4、"对某类兵器伤害"进 Z5，均**不是属性修饰**，由 design/04 汇总；AR-14 的 `Z4M / meridianDefense` 与 `Z5M / meridianAttack` 也不是 `StatModifier.mult`，只可由 `design/21` 的双方战斗 Profile 输出。数据中以 `target: 'dmgUp' | 'dmgDown' | ...` 区分于 `target: StatId`。
- **实例唯一**：以 `(sourceType, sourceId, modifierId)` 为修饰器唯一键；同键重复输入只生效一次，不同 `modifierId` 可让同一装备、武学或 Buff 合法修改多个属性。Buff 的刷新/叠层/独立/取高由 design/06 在展开修饰器前处理。

示例（`atkOut`，Lv50，`str` 70）：

| 步 | 内容 | 值 |
|---|---|---|
| ① | `ATK_LV(50) × (1 + 0.01×20)` = 1,216.49 × 1.2 | 1,459.79 |
| ② | 地中剑 `0.30 × 2.2 × 1,216.49` = 802.88；词条 +50 | +852.88 |
| ③ | 某内功特有被动 +10%、套装 +8%、减益"筋骨酸软" −15% | Σ = +3% |
| ⑤ | `(1,459.79 + 852.88) × 1.03 = 2,382.05`；面板 half-up | **2,382** |

```ts

type ApId = 'apFist'|'apFinger'|'apLeg'|'apGrapple'|'apSword'|'apBlade'|'apStaff'|'apSpear'|'apWhip'|'apExotic'|'apHidden'|'apInner'|'apLight';

type LvCurve = 'HP_LV'|'MP_LV'|'ATK_LV'|'DEF_LV';

interface StatModifier {
  stat: StatId;
  op: ModOp;
  value: number;               // flat: 点；flatLv: 系数；pct: 小数(0.10=+10%)；pp: 百分点；mult: 倍率
  curve?: LvCurve;             // op = 'flatLv' 时必填
  sourceType: 'level'|'innate'|'talent'|'origin'|'innerContribution'|'innerDerived'|'skillPassive'|'scar'
            |'equipMain'|'equipAffix'|'set'|'buff'|'tianshu'|'pillPerm'|'pillTemp'|'sect'
            |'meridian'|'title'|'terrain'|'enemyTmpl';
  sourceId: string;            // 如 'sk_yijinjing'、'eq_yitianjian'、'set_shaolin_jingang'
  modifierId: string;          // 来源内稳定且唯一，如 'main.atkOut'、'affix.1.resCold'；与前两字段组成去重键
  grade?: number;              // 来源 g_eff（抗性品阶、显示用）
  cond?: string;               // 条件表达式 ID（如 'hpBelow30'），由 09 的条件系统求值；为空=常驻
}

interface SkillRef {
  id: string; absGrade: number; effGrade: number; trueLayer: number; effLayer: number; nativeTo: string;
}
interface ItemRef {
  uid: number; id: string; absGrade: number; effGrade: number; nativeTo: string;
}
type StatSheet = Readonly<Record<StatId, number>> & {
  hp: number; mp: number; sta: number; rage: number; shield: number;
  mpNature: 'yang'|'yin'|'harmony'; dualWield: number; swimLevel: 0|1|2|3;
};

interface CharacterStatsInput {
  progression: Readonly<{ realLevel: number; expFp: number }>; // design/13 ExpState；expFp 为整数，属性层只读
  chapterCap: number; worldTier: 'HIGH'|'MID'|'LOW';
  unitClass: 'player'|'companion'|'namedNpc'|'templateEnemy';
  capExempt?: boolean;          // 仅章节登记 Boss 可为 true；按 §9.1 从 worldTier 推导 +3/+4/+6
  effectiveRules: {             // 由 02/13 先合成天道、天书主动与自选规则，属性层不得再猜一次
    skillSuppress: number; equipmentSuppress: number; layerCap: 8|9|10;
  };
  innatePerm: Record<InnateId, number>; innateCap: Record<InnateId, number>;
  realmAlloc: Partial<Record<2|3|4|5|6|7, Partial<Record<InnateId, number>>>>;
  ap: Record<ApId, number>; arts: Record<ArtId, number>; lore: number;
  morality: number; fame: number; talents: string[]; flags: string[];   // 存档标记，如 'scar_qishang'（05）
  innerSlots: { main?: SkillRef; aux: SkillRef[] };  movement?: SkillRef;
  equipment: Partial<Record<'mainHand'|'offHand'|'head'|'body'|'hands'|'waist'|'feet'|'accessory', ItemRef>>;

interface MeridianAttributeInput {
  currentMp: number;
  mpMax: number;
  mpRatioBp: number;           // 21 输入；由 mpMax 与 MPREF(displayLevel) 求得
  innerNature: 'yang'|'yin'|'harmony';
  effectiveQinggong: number;   // half-up 后；未乘 21 经脉速度
  baseSpd: number;             // 本文最终整数 spd
  baseMove: number;            // 09 已算出的基础移动点
  apInner: number;
  apGrapple: number;
  str: number; agi: number; wil: number;
}

declare function toMeridianAttributeInput(
  stats: StatSheet, displayLevel: number, baseMove: number
): MeridianAttributeInput;
```

公式中的 `Lr = input.progression.realLevel`；`expFp` 不进入任一属性公式，但必须随同一不可变成长快照读取，避免升级边界上把新等级与旧级内经验拼成不可能状态。
`toMeridianAttributeInput` 只是稳定传值适配器：`mpRatioBp` 必须以 §5.2 的 21 口径现场读取 `MPREF(displayLevel)` 后求得；`innerNature` 是 `StatSheet.mpNature` 的跨模块语义名；`effectiveQinggong` 取属性管线最终 half-up 整数；`baseSpd` 取本文整数 `spd`；`baseMove` 取 09 同快照的移动点。其余字段也必须来自该不可变快照。它不运行路线、不读取点穴 / 擒拿、不生成 `meridianAttackBp/meridianDefenseBp/meridianSpeedBp`，也不把 21 的 `MeridianSpeedResult.spd` 回灌 `StatSheet.spd`。

### 11.4 重算时机

| 触发 | 范围 |
|---|---|
| 书眠进入新书界、`Lr` 升级、装配/装备变化、修为分配变化 | 全量重算 |
| 战斗中 Buff 施加/移除/叠层变化 | 标脏受影响属性及其下游（按 §1.2 DAG），在**下一次读取前**增量重算 |
| 属性重算导致 `mpMax/mpNature/qinggong/spd` 改变 | 先完成属性快照，再标脏 21 的容量 / 流畅度或速度投影；保留其迟滞、堆积、胀损和点穴，不从旧 `spd'` 反推新 `spd` |
| 条件修饰（`cond`，如"气血低于 30% 时 +20% 攻击"） | 在每次自身行动开始、每次受击结算后重新求值条件 |
| 伤害结算 | 读取**招式开始结算那一刻**的属性快照；同一招式多段伤害共用该快照 |

### 11.5 边界情况

| # | 情况 | 规则 |
|---|---|---|
| 1 | 先天极低（如根骨 1） | 含 `(X−50)` 的乘法项各有下限 0.5（§3、§4.1、§5.1），`hpMax` 不会低于曲线值的一半 |
| 2 | 减益叠满 | `1 + Σpct` 下限 0.2；PCT 属性按各自范围截断（抗性 −50） |
| 3 | "停止集气"类控制（冰封、定身） | 由 design/09 冻结 CT 实现，**不**把 `spd` 改为 0；`spd` 始终在 [30, 300] |
| 4 | 抗性超过 75 | 溢出无效；UI 显示溢出量，便于玩家调整配装 |
| 5 | 临时 Buff 提升 `qinggong` 跨过门禁 | 探索门禁判定**包含** `qinggong` 的临时加值（丹药/Buff 是合法钥匙）；但 `jump` 自身的 flat 加值只在战斗中生效（§4.4） |
| 6 | `apCap` 因悟性下降而低于当前资质 | 资质不回退，只停止成长 |
| 7 | 空手 | 兵器栏不可用（基准 §20），`P_wpn = 0`，`atkOut` 无兵器 flat；拳脚武学仍按 `atkOut`/`atkIn` 合成 |
| 8 | 未装配主运内功 | `mpNature` 视为调和但无任何性质加成（05 相性矩阵"未装配内功"行全 0），`mpRegen = 1`，`Q_inner = 0`，无 `resInjury` 主运项，`resGrade` 下限 1 |
| 9 | 战斗中升级 | 不会发生：经验在战斗结算后发放（13） |
| 10 | 达到当前书界等级上限 | 此后的角色经验按 `design/13` §2.6–§2.7 转为修为余韵，不再提高 `Lr`；属性只按 `Ld`。第十四天书补级与终局解压见本文 §3.6 |
| 11 | 敌人 `flatLv` | 按敌人自身等级解析 |
| 12 | 同伴 | 与主角、具名 NPC 同走 `full` 管线；`Lr`、当前 `chapterCap`、本土归属及跨界成长由 `design/18` 输入。健在同伴重逢时真实能力只增不减，但显示属性仍按当前 `Ld`、来源和压制重算，本文不得假定其“本书界原生” |
| 13 | 同一套装由外来件与原生件混搭 | 各件按自身 `g_eff` 参与 design/07 的档位判定 |
| 14 | 数值溢出 | `hpMax` 等整数存档字段用 32 位有符号整数；本文合法 STD 与现有终局模板量级远低于 `2^31−1`。任何新增 `mult` 来源或上限突破须先枚举合法组合、以 64 位中间值验算，再决定是否调整存档字段 |
