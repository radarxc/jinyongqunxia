## 0. 约定与符号

### 0.1 通用符号

| 符号 | 含义 |
|---|---|
| `Lr` | 真实等级（1–70，只增不减，基准 §3.4） |
| `Ld` | 显示等级 = `min(Lr, chapterCap)`；**本文所有公式中的等级一律用 `Ld`** |
| `g` | 品阶 1–12（基准 §4）；`g_eff` = 经天道压制后的有效品阶 |
| `G(g)` | 基准 §4 的品阶系数（1.00 … 3.50） |
| `layer` | 武功层数 1–10；`layer_eff = min(layer, layerCap)`（高武 10 / 中武 9 / 低武 8） |
| `con` `str` `agi` `wis` `wil` `luk` `cha` | 先天属性的**最终值**（含临时加值，见 §2.1），公式中直接用 ID |
| `x⁺` | `max(0, x)` |
| `clamp(x, a, b)` | 截断到 [a, b] |
| `⌊x⌋` | 向下取整 |
| `Σflat_S` / `Σpct_S` / `Σpp_S` | 属性 S 的全部"固定加值 / 百分比加值 / 百分点加值"之和（§11） |
| `HP_LV(L)` `MP_LV(L)` `ATK_LV(L)` `DEF_LV(L)` | 等级基准曲线（§3.1），**全项目唯一的等级缩放源** |
| `STD(L)` | 标准主角参考模型（§3.5），供伤害公式与敌人模板校准 |
| `MPREF(L)` | 耗内基准 = `STD(L).mpMax`（§3.5），design/05 招式耗内的乘数 |
| `P_ref(L, tier)` | 等级期望威力指数（§3.5），建议 design/04 在 Z1 中用于归一 |
| `【建议值】` | 本文替下游文档给出的暂定数，下游定稿后以下游为准 |

### 0.2 属性的数值形态

每个属性属于且只属于一种形态，形态决定它能接受哪些修饰（§11.2）。

| 形态 | 代码 | 说明 | 允许的修饰 | 例 |
|---|---|---|---|---|
| 先天 | `INN` | 1–100 的人物底子，永久值 + 临时加值 | 仅 `flat` | `con` |
| 资源 | `RES` | 有当前值与上限的池 | 上限按 `MAG` 处理；当前值只由结算改变 | `hp`/`hpMax` |
| 量值 | `MAG` | 随等级曲线放大的绝对量，参与比值运算 | `flat` `flatLv` `pct` `mult` | `atkOut` |
| 评级 | `RAT` | 与对手的对应评级做**差值**比较的点数，不随等级放大太多 | `flat` `pct` | `hit` vs `eva` |
| 百分点 | `PCT` | 直接就是百分数（单位 pp），只做加法 | `pp` | `resPoison`、`counter` |
| 标志 | `FLAG` / `ENUM` | 布尔、等级档或枚举 | `set` / 规则派生 | `dualWield`、`mpNature` |

> 例："攻击 +10%"是属性修饰（`atkOut` 的 `pct`）；"伤害 +10%"**不是属性**，是基准 §9 的 Z3 增伤。两者乘区不同，数据中必须区分。

### 0.3 取整与确定性

- 内部一律用浮点计算，**只在面板显示和结算写入时取整**（`hp`、`mp`、伤害取 `⌊ ⌋`；评级显示取整数；百分点显示 1 位小数）。
- 同一属性的修饰按 `(sourceType, sourceId)` 字典序求和，保证跨平台结果一致（玩法核心为确定性，基准 §19）。

## 1. 属性分层总览

### 1.1 分层图

```
                         ┌────────────────────────────────────────────────┐
  创角 / 修为突破 / 奇遇 │ ① 先天属性 INN   con str agi wis wil luk cha    │  永久值(≤100/120) + 临时加值，最终 ≤120
  丹药 / 装备 / Buff ───►└──────────────┬─────────────────────────────────┘
                                        │  × 等级基准曲线 HP_LV/MP_LV/ATK_LV/DEF_LV (Ld)
                                        ▼
  内功(主运/辅运) ─────► ② 资源 RES   hpMax mpMax staMax shieldMax │ hp mp sta rage shield │ mpNature
                                        │  mpMax → atkIn / defIn
                                        ▼
  装备 / 套装 / Buff ──► ③ 战斗属性    MAG: atkOut atkIn defOut defIn spd
  轻功武学 / 天书之力    (22 项)        RAT: hit eva parry pierce crit tough effHit effRes
                                        PCT: critDmg counter combo seal healPower healRecv
                                        格:  mov jump      轻功: qinggong（→ jump、eva、地形门禁）
                                        ▼
                         ④ 抗性 PCT    resPoison resGu resSeal resInjury resCold resHeat resMind resCC
                                        （+ 抗性品阶 resGrade，与 Buff 品阶对抗）
  ────────────────────────────────────────────────────────────────────────────────────────────
  使用武功 / 修炼 ─────► ⑤ 武学资质 0–100  apFist … apLight（13 项）→ 伤害 Z5、修炼速度
  使用 / 拜师 / 典籍 ──► ⑥ 技艺 0–100     med poi antidote forge alchemy formation music art chess speech
  剧情 / 抉择 ────────► ⑦ 江湖属性       morality fame lore dualWield
```

- ①→④ 是**战斗链**：每次重算都从先天属性开始向下推导（§11.4）。
- ⑤⑥⑦ 是**成长链**：不随等级曲线缩放，不受天道压制（§9），跨书界完整保留（江湖属性中 `fame` 例外，见 §8.4）。

### 1.2 计算顺序（有向无环，必须按此顺序求值）

| 步 | 求值对象 | 依赖 |
|---|---|---|
| S0 | `Ld`、境界参数（layerCap、suppress） | `Lr`、当前书界 |
| S1 | 先天最终值（7 项） | 永久值、修为突破分配（按 `Ld` 生效）、临时加值 |
| S2 | 内功贡献 `innerMpPct` `innerHpPct` `attrs` `mpRegen`（05 §5.5，落点 §3.4）与主运派生项 | 装配内功的 `g_eff`、`layer_eff`、主/辅运比例 `auxRatio`（含相冲/桥接） |
| S3 | `hpMax` `mpMax` `staMax` | S1、S2、装备、Buff |
| S4 | `atkIn` `defIn`（依赖 `mpMax`）、`atkOut` `defOut` | S1、S3 |
| S5 | `qinggong` | S1、`apLight`、轻功武学、主运内功、装备 |
| S6 | `hit` `eva`（依赖 `qinggong`） `parry` `pierce`（依赖 `lore`） `crit` `tough` `effHit` `effRes` | S1、S5 |
| S7 | `spd` `mov` `jump` | S1、S5 |
| S8 | 百分点类：`critDmg` `counter` `combo` `seal` `healPower` `healRecv`、8 项抗性、次级属性 | S1、技艺、资质 |
| S9 | `shieldMax` | S3 |

> 任何修饰器不得引用"同步或更晚"步骤的属性作为自身的输入（例如 Buff "按闪避的 10% 提升攻击"不被允许，因 `eva` 在 S6、`atkOut` 在 S4）。若确需此类效果，由 design/06 以"战斗中快照值"实现，不进入面板计算链。

## 2. 先天属性与创角

### 2.1 先天属性的构成

```
perm_X  = create_X + origin_X + talent_X + Σ realmAlloc_X[r | r 已按 Ld 生效] + Σ permBonus_X(奇遇/丹药/天书之力)
perm_X  = clamp(perm_X, 1, cap_X)            cap_X = 100 + 5 × breakCount_X   （breakCount ≤ 4 → cap ≤ 120）
temp_X  = Σ flat_X(内功贡献 attrs、装备词条、内功特有被动、套装、Buff)   （可为负）
X       = clamp(perm_X + temp_X, 1, 120)     ← 公式中使用的"最终值"（基准 §6：先天上限 120）
```

| 规则 | 说明 |
|---|---|
| 只接受 `flat` | 先天属性**不接受百分比修饰**，避免"根骨 +10%"式滚雪球 |
| 突破上限 | 只有标记 `breakCap: true` 的奇遇/丹药能让某项 `cap_X` +5（每项最多 4 次）；每书界此类资源 ≤ 2 个【建议值，11/10 落实】 |
| 临时值可超 100 | 例：根骨永久 100 + 内功 `attrs` +8 + 装备 +7 → 115 参与计算；最终上限 120（与基准 §6、design/05 §5.5 一致），超出部分无效并在面板显示为灰色 |
| 负值保护 | 最终值 ≥ 1；所有含 `(X − 50)` 的乘法项另有下限（见各公式） |

## 3. 等级成长曲线

### 3.1 等级基准曲线（全项目唯一的等级缩放源）

```
B(L, k)   = k × (L − 1) × max(0, 1 − (L − 1) / 34)        // 新手补偿项：Lv2–34 为正，Lv1/Lv35+ 为 0
HP_LV(L)  = 300 + 4.10 × (L − 1)² + B(L, 20)
MP_LV(L)  = 200 + 2.45 × (L − 1)² + B(L, 12)
ATK_LV(L) = 0.20 × MP_LV(L)                                // 外内同源：裸装标准人 atkOut ≡ atkIn
DEF_LV(L) = 0.15 × MP_LV(L)                                // = 0.75 × ATK_LV
```

设计要点：
1. **二次曲线**贴合基准 §5 的三个锚点（纯幂函数拟合指数 ≈ 2.02）。
2. 纯二次曲线在前 10 级几乎不涨（Lv1→2 仅 +4 气血），所以叠加补偿项 `B`：它在 Lv1 与 Lv35 严格为 0，**不改变任何锚点**，只让新手期每级有 +8%~10% 的体感成长。
3. `ATK_LV`、`DEF_LV` 直接取自 `MP_LV`，使"内力深厚"与"攻防成长"同源；裸装时 `atkOut : atkIn : defOut : defIn` 的比例在全等级段恒定；典型配装下也只在小幅区间漂移（见 §3.5 比例列），伤害公式配合 `P_ref` 归一后只需一组常数即可覆盖 1–70 级。

**给 design/04、05 的三条结论**：

1. **攻防比例近似恒定**：`atkOut/hpMax` 在 0.13–0.16、`defOut/atkOut` 在 0.68–0.81；后期内功（hp% 与 attrs）使气血略快于攻击增长，同级战斗后期约长 20%（"高手过招"）。
2. **招式威力指数必须归一**：05 的 `G × L(n)`（`L(n) = 0.5 + 0.1n`）从 Lv1 的约 0.8 涨到 Lv70 的 5.25（6.5 倍），而本文攻击/气血比基本不变。若 Z1 直接乘 `G × L(n)`，后期同级互击会从"8 击"缩短到"约 1.5 击"。**建议 design/04 在 Z1 中以攻方的 `P_ref(Ld, worldTier)` 归一**：

   ```
   P_ref(L, tier) = G(gMain(L)) × (0.5 + 0.1 × lref(L)) × τ(tier)       τ：高武 1.00 / 中武 0.80 / 低武 0.75
   Z1 中的威力项 = G(g_eff) × L(layer_eff) × moveMul / P_ref(Ld_攻方, tier)
   ```

   `τ` 取自 design/02 §3.4：中武/低武书界里玩家主力武功的典型威力约为同等级高武线的 80% / 75%（外来压制 + 层数上限）。归一后，"品阶高于本等级期望"仍然直接转化为伤害优势，而全等级段的击杀节奏保持在基准 §5 区间（§10.8 验算）。
3. **耗内基准 `MPREF(L)` = 表中 STD `mpMax`**（design/05 §3/§4 的 `mpCost × MPREF(显示等级)`）。这样"黄 5% / 玄 6% / 地 7% / 天 8%"恰好是**典型配装内力上限**的 5%–8%，与基准 §5"单招消耗约为内力上限 5%–15%"一致；若改用裸装锚点 `MP_LV`，Lv70 实际占比只有约 3%，内力将失去约束。

### 3.6 等级封顶后的成长

- 按基准 §2，倚天结束时真实等级通常已到 70；**笑傲及之后的十个书界，显示等级从入场起就等于书界上限**，此后属性成长只来自：武功（重新习得/补齐栏位/层数）、装备、资质、先天（奇遇/丹药）、天书之力。
- 这正是"武林衰败 → 主角武功随之被压低"的数值体现（§9.4 示例）。
- 封顶后获得的经验如何转化由 design/13 定义【待决 D-06】（design/02 §2.5 建议转为"修为余韵"注入主运内功的积蕴）。

## 4. 战斗属性派生公式

> 通式（§11.2）：`S = (Base_S + Σflat_S) × max(floor_S, 1 + Σpct_S) × Πmult_S`，然后 `clamp` 到 S 的范围。下面只写各属性的 `Base_S`、专属项、下限与范围。`floor_S` 缺省：MAG 取 0.2，RAT 取 0.2。

### 4.1 攻防四项（MAG）

| 属性 | `Base` | 专属 flat 来源 | 范围 |
|---|---|---|---|
| `atkOut` | `ATK_LV(Ld) × max(0.5, 1 + 0.010 × (str − 50))` | 主手兵器主属性、副手副兵器 | ≥ 1 |
| `atkIn` | `0.20 × mpMax` | 少数饰品/Buff | ≥ 1 |
| `defOut` | `DEF_LV(Ld) × max(0.5, 1 + 0.006 × (con − 50) + 0.002 × (str − 50))` | 衣、头、护手、腰带、鞋、盾 | ≥ 0 |
| `defIn` | `0.15 × mpMax` | 衣（内衬）、特定饰品 | ≥ 0 |

- `atkIn`/`defIn` 取**最终** `mpMax`（S3 已含内功与 Buff），所以"内力上限 −20%"类减益（如化功类武学）会同时削弱内劲攻防——这是有意的"化人内力"手感。
- 当前内力 `mp` 不影响 `atkIn`；"内力不足时招式威力下降"如需实现，归 design/04（Z1）或 05。

**装备主属性系数【建议值，最终由 design/10 定】**（`flatLv` = 按当前 `Ld` 的基准曲线缩放的固定值；`G` 此处借用基准 §4 品阶系数作为装备品阶系数的占位）：

| 部位（基准 §20） | 主属性 | 系数 |
|---|---|---|
| 主武器 `mainHand` | `atkOut` | `0.30 × G(g_eff) × ATK_LV(Ld)` |
| 衣 `body` | `defOut` / `defIn` | `0.20 × G × DEF_LV` / `0.10 × G × DEF_LV` |
| 头 `head`、护手 `hands`、腰带 `waist`、鞋 `feet` | `defOut` / `hpMax`（每件） | `0.05 × G × DEF_LV` / `0.01 × G × HP_LV` |
| 鞋 `feet` 额外 | `qinggong` | `2.5 × g_eff`（固定点，不随等级缩放） |
| 副手 `offHand` | 副兵器 `atkOut 0.10×G×ATK_LV`；盾 `parry +20`、`defOut 0.10×G×DEF_LV`；暗器囊 `apHidden` 相关（10 定） | — |
| 佩饰 `accessory` | 任一评级 `+2 × g_eff`，或任一抗性 `+g_eff` pp | — |

> 采用 `flatLv`（随显示等级缩放）而不是写死数值的原因：装备跨书界携带，显示等级会上下变化；`flatLv` 让一件装备在任何等级都保持"同品阶同强度"，天道压制只需降低 `g_eff`（§9.3）。

**兵器类别招架底值 `P_wpn`【建议值，10 定】**：剑 12、刀 10、棍杖 16、枪 12、鞭索 4、奇门 8、空手 0（空手招架来自武学被动，如太极拳）。

**攻击合成（供 design/04 Z1 采用的建议写法）**：招式带"内劲比例" `r_in ∈ [0, 1]`（05 定义），

```
ATK_mix = (1 − r_in) × atkOut + r_in × atkIn
DEF_mix = (1 − r_in) × defOut + r_in × defIn        // 守方按攻方招式的 r_in 取防御
```

### 4.2 判定类评级（RAT）

| 属性 | `Base` | 主要 flat 来源 |
|---|---|---|
| `hit` | `60 + 0.5·agi + 0.3·wis + 0.5·Ld` | 招式命中修正（05）、兵器词条、Buff |
| `eva` | `35 + 0.5·agi + 0.2·luk + 0.5·Ld + 0.10·qinggong` | 轻功武学特有被动（如凌波微步）、Buff |
| `parry` | `15 + 0.3·str + 0.2·wis + 0.3·Ld + P_wpn` | 武学被动（太极类大量）、盾、Buff |
| `pierce` | `10 + 0.3·wis + 0.1·str + 0.3·Ld + 0.2·lore` | 破招类武学（独孤九剑类大量）、套装 |
| `crit` | `5 + 0.3·luk + 0.15·wis + 0.1·agi + 0.2·Ld` | 兵器、佩饰、Buff |
| `tough` | `5 + 0.25·con + 0.2·wil + 0.2·Ld` | 护甲词条、内功被动 |
| `effHit` | `10 + 0.3·wis + 0.2·wil + 0.3·Ld` | 毒/穴/心神类武学；`poi`（毒类，§8.2）；`cha`（魅惑类） |
| `effRes` | `10 + 0.3·wil + 0.2·con + 0.3·Ld` | 内功被动、佩饰 |

- 所有 RAT 下限 0，无硬上限（UI 显示时按下方建议换算成概率）。
- 等级项系数攻守对称（`hit`/`eva` 同为 0.5·Ld），同级对抗时等级项抵消；跨等级的压制由 Z8 境界差负责，评级不重复放大。

**概率换算【建议值，定稿归 design/04】**（UI Tooltip "对同级约 X%" 也用它）：

```
P_hit   = clamp(0.85 + 0.004 × (hit − eva),      0.40, 0.99)
P_parry = clamp(0.12 + 0.004 × (parry − pierce), 0.00, 0.60)
P_crit  = clamp(0.10 + 0.004 × (crit − tough),   0.02, 0.75)
P_eff   = baseChance × clamp(1 + (effHit − effRes) / 100, 0.3, 2.0) × (1 − res_eff)     // res_eff 见 §6.3
```

STD 同级下的结果：`P_hit` 96%（Lv1）→ 94%（Lv35）→ 91%（Lv70）（高手过招更难命中，属有意为之）；`P_parry` 21% → 17%；`P_crit` 恒 ≈ 12%（完整表见 §4.9）。

### 4.3 速度 `spd` 与集气接口

```
Base_spd = 60 + 0.6·agi + 0.2·Ld + 0.08·Q_skill           // Q_skill = 轻功武学项，见 §4.5
spd      = clamp((Base_spd + Σflat) × (1 + Σpct), 30, 300)
```

| 集气接口（机制本体归 design/09） | 规则 |
|---|---|
| 每 tick 集气 | `ctGain = spd`（整数，向下取整） |
| 行动条件 | `CT ≥ 1000` |
| 行动间隔 | ≈ `(1000 + R_move) / spd` tick，`R_move` 为招式"收招"值（09/05） |
| 相对出手频率 | 两单位出手次数比 ≈ `spd_A / spd_B`（忽略收招差） |
| 开场集气【建议值，09 定】 | `CT0 = rand[0,200) + clamp(4 × (agi − 50), −100, 300)`；伏击方 +300 |

参考：STD `spd` 为 92（Lv1）/ 106（Lv35）/ 125（Lv70），即约 10 tick 行动一次；身法 100 + 天级轻功的专精角色约 140–150，出手频率约为 STD 的 1.35 倍。"迟缓/加速"类 Buff 走 `spd` 的 `pct`（06）。

### 4.4 移动力 `mov` 与跳跃 `jump`

```
mov  = clamp(3 + ⌊(agi − 20)⁺ / 30⌋ + min(2, ⌊Q_skill / 50⌋) + Σflat_mov, 1, 8)
jump = clamp(qgTier(qinggong) + Σflat_jump, 0, 6)
qgTier(q) = 0 (q<20) | 1 (≥20) | 2 (≥50) | 3 (≥90) | 4 (≥140) | 5 (≥200)      // 基准 §11

| 身法 | 身法项 | 典型轻功武学项（`⌊Q_skill/50⌋`） | 典型 `mov` |
|---|---|---|---|
| 20–49 | +0 | 黄/玄阶低层 → +0 | 3 |
| 50–79 | +1 | 玄上 6 重（≈50）→ +1 | 4–5 |
| 80–109 | +2 | 地/天阶高层（≥100）→ +2 | 5–7 |
| 110–139 | +3 | — | 6–8 |

- `mov` 的其他修正：体力耗尽"疲惫" −1（§5.3）；重甲 −1（10 定）；Buff（06）。
- `jump` 只决定**战斗网格中单步可跃上的高度差**与**可跨越的沟宽**（二者都等于 `jump` 格/级）。台阶、坡道类地形不受 `jump` 限制；下跳免伤高度、跨越消耗等由 design/08 定义。
- 探索中的地形门禁判 `qgTier(qinggong)`（**含** `qinggong` 的临时加值——丹药/Buff 是合法钥匙，见 §11.5）；`jump` 自身的 flat 加值只在战斗网格中生效。

### 4.5 轻功值 `qinggong`（完整公式）

```
qinggong = ( Q_agi + Q_lv + Q_skill + Q_ap + Q_eq + Q_inner + Σflat_qinggong − Q_load ) × (1 + Σpct_qinggong)

Q_agi   = 0.25 × (agi − 30)⁺                       // 身法 50→5，80→12.5，100→17.5，120→22.5
Q_lv    = 0.30 × Ld                                // Ld 35→10.5，50→15，70→21
Q_skill = QS(g_eff) × (0.40 + 0.06 × layer_eff)     // 装配中的轻功武学（轻功栏 1 格，基准 §20）
Q_ap    = 0.15 × apLight                           // 0–15
Q_eq    = Σ 装备 qinggong（鞋主属性 2.5 × g_eff + 词条）
Q_inner = 3.0 × G(g_eff,主运) × layer_eff,主运 / 10  // 仅主运内功，0–10.5
Q_load  = 负重惩罚（重甲、重兵器，10 定；建议重甲 10、玄铁重剑类 15）
```

|---|---|---|---|---|---|---|---|---|---|---|---|---|

## 5. 资源规则

### 5.1 气血 `hp` 与上限

```
hpMax = ( HP_LV(Ld) × max(0.5, 1 + 0.008 × (con − 50)) + Σflat_hpMax ) × max(0.2, 1 + Σpct_hpMax) × Πmult
mpMax = ( MP_LV(Ld) × max(0.5, 1 + 0.006 × (wil − 50) + 0.004 × (con − 50)) + Σflat_mpMax ) × max(0.2, 1 + Σpct_mpMax) × Πmult
```

- `Σpct_hpMax` 含：内功贡献 `innerHpPct`（§3.4）、内功特有被动、装备词条、套装、Buff、丹药/传功永久加成、永久创伤（负值）、天书之力。
- **丹药永久加成一律用 `pct` 存储**（例：服食某灵物 `mpMax +8%` 永久），避免低级时服用的固定值在高级时失去意义；全程封顶：`hpMax` 永久 pct ≤ +30%、`mpMax` 永久 pct ≤ +40%【建议值，10 落实】。
- 上限变化时的当前值规则：

| 场景 | 当前值处理 |
|---|---|
| 战斗中上限提高 Δ（Buff） | 当前值 +Δ |
| 战斗中上限降低 | 当前值 = min(当前值, 新上限)；Buff 结束恢复上限时**不**返还 |
| 战斗外换装/换内功/等级变化 | 保持百分比：`cur = cur_old / max_old × max_new` |
| 书眠醒来 | 全满（`hp`、`mp`、`sta`），`rage`、`shield` = 0 |

### 5.2 内力 `mp` 与内力性质 `mpNature`

**性质来源**（机制本体归 design/05 §5.1–5.4，本文只定义它对属性的影响）：
- 每门内功带 `nature ∈ {yang, yin, harmony}`（05/图鉴逐门指定；05 §5.3 已给出代表：九阳/先天功/龙象/蛤蟆功为阳，玉女心经/吸星/葵花/寒冰真气为阴，易筋经/九阴总纲/太玄经/小无相功为调和——均为游戏化判定）。
- `mpNature` = 主运内功的 `nature`；标记 `natureFollowAux` 的内功（乾坤大挪移、斗转星移类）作主运时取品阶最高辅运的性质（05 §5.7）。
- 未装配主运内功：视为调和但**无任何性质加成**（05 相性矩阵"未装配内功"行全为 0）。

| 性质 | 本文的属性效果 | 05 负责的效果 |
|---|---|---|
| `yang` 阳 | `resCold +15pp` | Z5 相性（阳招 +12%/阴招 −12%）、辅运比例、相冲 |
| `yin` 阴 | `resHeat +15pp` | 同上（方向相反） |
| `harmony` 调和 | `resCold +8pp`、`resHeat +8pp` | 调和招 +12%、阴阳招 +4%；桥接 |

**获得"调和"**的途径（均由 05 定义，本文列出以便查阅）：① 主运一门调和内功；② `natureFollowAux` 内功搭配调和辅运。"阴阳相冲"的消解靠**桥接**（装配调和且品阶 ≥ 7 的内功，或 `inner.bridge: true`，05 §5.4），不改变 `mpNature`。

**切换**：战斗外自由调整主/辅运（`mp` 按百分比保留，§5.1）；战斗中使用 05 §5.6 的行动**"易运"**（主运与一门辅运互换，占用本次行动、收招 800、3 回合限 1 次、当前内力 = min(当前, 新上限)）。易运后本文按 §11.4 立即重算：`mpNature`、性质抗性、`innerMpPct`/`innerHpPct`、`mpRegen`、`Q_inner`、`resGrade` 下限同步变化。

**内力回复**：每次自身行动开始时 `mp += mpMax × mpRegen%`（§4.8）；"运功调息"行动的回复量归 design/09【建议值：+15% `mpMax`】。

**永久内力加成**：丹药与"传功"（05 §8 `inherit`，如无崖子传功虚竹）给予的永久 `mpMax` 加成，数值**【建议值】**：传功者主运天级 +12%、地级 +8%、玄级 +4%；与丹药共用"永久 `mpMax` pct ≤ +40%"的上限（§5.1）。

### 5.3 体力 `sta`

```
staMax = 100 + 0.5 × con + 0.5 × Ld + Σflat_staMax          // STD：Lv1 126，Lv35 147，Lv70 170
```

**消耗（探索）**【建议值，具体动作表归 design/08】：

| 行为 | 所需境界 | 消耗 |
|---|---|---|
| 疾行（奔跑） | — | 2 / 秒 |
| 纵跃（上高差 / 跨沟），每次 | qg1+ | 4 × 高差级数（或沟宽格数） |
| 攀崖，每级高差 | qg3+ | 5 |
| 踏水，每格 | qg3+ | 4 |
| 树梢移动，每格 | qg3+ | 2 |
| 雪/沙/冰/沼 | qg4+ | 0（被动无减速） |
| 一苇渡江（大江湖面），每格 | qg5 | 3 |
| 云海栈道，每格 | qg5 | 3 |

- **熟练折扣**：`cost × max(0.5, 1 − (qinggong − 该动作所需阈值) / 200)`。例：qinggong 190 踏水（阈值 90）→ ×0.5。
- 这让高阶门禁同时考验"境界"与"续航"：渡 40 格大湖需 120 体力（qg5 刚达标时几乎无折扣），STD Lv60 的 `staMax` 163 可一次渡过；55 格以上的大江需在中途设置落脚点（沙洲、船只，08 配置）。

**恢复**：

| 情形 | 恢复 |
|---|---|
| 探索中 2 秒未消耗 | 每秒 `staMax × staRegen%`（默认 4%，≈6/秒） |
| 打坐（任意安全点，游戏内 1 小时） | 全满 |
| 客栈 / 门派 / 营地 | 全满 |
| 干粮 / 药膳（10 定） | +20 ~ +80 |
| 战斗中每次自身行动开始 | +10 |

**疲惫**（`sta = 0`）：探索中不能疾行、纵跃，直到恢复到 20%；战斗中 `eva −15`、`mov −1`，且不能执行需要轻功境界的地形动作（踏水等，战斗内同样按上表消耗）。普通招式**不**消耗体力。

### 6.1 计算

res_X = clamp( innateTerm_X + natureTerm_X + Σpp_X , −50, 75 )          // 单位 pp（百分点）
```

|---|---|---|---|
| `resPoison` | `0.2·(con−50)` | `+0.15·antidote` | 内功被动、丹药、奇遇、佩饰、天赋 `tal_yiti` |
| `resGu` | `0.2·(wil−50)` | `+0.10·antidote` | 特定物品（如苗疆类）、Buff |
| `resSeal` | `0.2·(wil−50) + 0.1·(con−50)` | — | 移穴换位类武学、Buff |
| `resInjury` | `0.2·(con−50) + 0.1·(wil−50)` | `+3.0·G(主运)·layer/10`（§3.4） | 内功被动 |
| `resCold` | `0.1·(con−50)` | 阳 +15 / 调和 +8 | 装备、Buff |
| `resHeat` | `0.1·(con−50)` | 阴 +15 / 调和 +8 | 装备、Buff |
| `resMind` | `0.3·(wil−50) + 0.1·(wis−50)` | — | 佛门/道门内功被动、天赋 `tal_xinruzhishui` |
| `resCC` | `0.15·(con−50) + 0.15·(str−50)` | — | 重甲、下盘类武学、Boss 模板（§10） |

### 6.2 上下限与"免疫"的区别

| 项 | 值 | 说明 |
|---|---|---|
| 下限 | −50pp | 负抗性使效果更易施加、更强（06 按 `1 − res` 计算即自然放大） |
| 上限 | **75pp** | 任何来源叠加都不超过 75；超出部分溢出无效（UI 显示灰色溢出值，便于配装） |
| 免疫 | 不属于抗性 | "免疫中毒""免疫中蛊"是**机制类 Buff**（`mechanic`，基准 §10），由 design/06 定义；免疫同样受 Buff 品阶对抗约束 |

### 6.3 抗性品阶 `resGrade` 与 Buff 品阶对抗接口

基准 §10 规定"抵抗只对品阶 ≤ 自身品阶的效果完全生效"。抗性是多来源之和，本身没有品阶，因此为每个抗性标签定义**抵抗品阶**（design/06 §3.5.2 已写明"若 03 另行定义 `resGrade`，以 03 为准"；本文定义与 06 的建议式兼容，只增加 5pp 门槛）：

```
resGrade(tag) = max( g_eff(主运内功) − 3,                                        // 内功护体的底子（06 同式）
                     max{ grade(src) | src 对 res_tag 的贡献 ≥ 5pp },            // 小于 5pp 的零碎来源不抬品阶
                     1 )
  grade(src)：武学被动 / 装备 / 套装 / Buff / 丹药 = 其 g_eff；
              解毒专属项（0.15·antidote 等）= gMax(antidote) = ⌊(antidote + 4) / 8⌋（§8.1）；
              内力性质项（寒/热）= 主运内功 g_eff；先天项不单独计品阶（由"主运 − 3"与下限 1 覆盖）
```

对品阶为 `g_e` 的效果（`Δr = g_e − resGrade`），穿透系数 `ρ(Δ)` **采用 design/06 §3.5.0**（Δ≤0 → 0；Δ≥1 → `min(0.90, 0.15 + 0.15Δ)`，即 0.30/0.45/0.60/0.75/0.90）：

```
res_eff = res_X                         若 res_X ≤ 0（负抗性对任何品阶都全额生效）
res_eff = res_X × (1 − ρ(Δr))           否则
```

- 施加概率：`P_apply = baseChance × clamp(1 + (effHit − effRes)/100, 0.3, 2.0) × (1 − res_eff/100)`（§4.2 建议式，定稿归 04）。
- 持续伤害减免：`resPart = 1 − clamp(res_eff, −50, 75)/100`（06 §5.3.2）。
- "免疫"是机制类 Buff，走 06 §3.5.1 的免疫穿透，不经过本节。
- UI：抗性页每项显示"数值 / 品阶色"，例如"抗毒 36%（地中）"；受穿透时 Tooltip 显示"被〈天中·某毒〉穿透 60%"。

### 6.4 示例

主角 Lv50：`con` 60、`antidote` 40；主运内功地中（g8）且其特有被动"抗毒 +20pp"；佩饰"抗毒 +8pp"（地下 g7）。

| 项 | 值 | 品阶 |
|---|---|---|
| 先天项 `0.2×(60−50)` | 2pp | 不计 |
| 解毒项 `0.15×40` | 6pp | `gMax(40)` = 5 |
| 内功特有被动 | 20pp | 8 |
| 佩饰 | 8pp | 7 |
| 主运底子 | — | 8 − 3 = 5 |
| **合计 / resGrade** | **36pp / 8（地中）** | |

| 来袭毒效果品阶 | Δr | ρ | `res_eff` | `P_apply`（baseChance 60%、effHit = effRes） |
|---|---|---|---|---|
| 地中（8）及以下 | ≤ 0 | 0 | 36.0 | 38.4% |
| 地上（9） | 1 | 0.30 | 25.2 | 44.9% |
| 天下（10） | 2 | 0.45 | 19.8 | 48.1% |

`apCap = min(100, 70 + 0.3 × wis)`（悟性 50 → 85，悟性 100 → 100）；奇遇"开窍"类可 +5（每类最多 2 次，不超过 100）。资质**跨书界完整保留，不受天道压制**。

### 7.4 对伤害的影响（伤害乘区 Z5 的"资质"部分）

```
apFactor(ap) = 0.80 + 0.004 × ap                       // 0→0.80，25→0.90，50→1.00，75→1.10，100→1.20
A_ap(move)   = (1 − r_in) × apFactor(ap_cat(move)) + r_in × apFactor(apInner)
```

| 招式类别 | `ap_cat` |
|---|---|
| 拳掌/指/腿/擒拿 | `apFist`/`apFinger`/`apLeg`/`apGrapple` |
| 剑/刀/棍杖/枪/鞭索/奇门 | 对应兵器资质 |
| 暗器 | `apHidden` |
| 内功自带招式（若 05 设计） | `apInner`（此时 `A_ap = apFactor(apInner)`） |
| 杂学主动（医/毒/蛊/阵/音律/书画/棋/易容/驭兽/心神） | 无资质，改用 05 §2.3 映射的技艺（或属性）：`artFactor = 0.80 + 0.004 × value`，`value` 取 `med`/`poi`/`formation`/`music`/`art`/`chess`/`cha`/`wil`（**本文确认 05 §2.3 的映射**，含其修炼速度以 `wis` 当资质的约定） |
| 音功 `sonic` | `apInner`（与 05 §2.3 一致），`music` 只作辅助效果强度 |

- `r_in` 为招式内劲比例（§4.1），让"内劲为主"的招式更吃 `apInner`：例如 `r_in = 0.7` 的掌法，`apFist` 40 / `apInner` 80 → `A_ap = 0.3×0.96 + 0.7×1.12 = 1.072`。
- Z5 合成建议：`Z5 = A_ap × (1 + 相性加算项 + 破 X 加算项 + 三运同源等)`——design/05 §5.3 已把相性与"破 X"定义为 Z5 的**加算项**，资质系数 `A_ap` 作为 Z5 内的独立乘子；最终写法归 design/04。
- STD 参考：Lv1 ≈ 0.90，Lv35 ≈ 0.98，Lv70 ≈ 1.06。

### 10.5 书界难度修正

采用 **design/02 §3.3** 的 `enemyStatMul(D) = 0.85 + 0.05 × D`（D3 → 1.00 … D10 → 1.35；局部难度 `localDifficulty` 可覆盖）。本文规定它**只乘 `hpMax` 与 `atkOut`/`atkIn`**，不乘防御与评级（防御再乘会与 Z2 的比值型减伤重复放大，评级另有模板加值）【待决 D-18】。难度模式（13）的系数与之相乘。

### 10.6 模板敌人的威力归一（给 design/04 的建议）

模板敌人的招式在 Z1 中**不用自身品阶的 `G × L(n)`**，而是：

```
P_enemy = P_ref(L_敌, tier) × tmplPower           // §3.5；tmplPower 见 §10.3
```

理由：02 的品阶骰让杂兵/精英的武学品阶普遍比同级主角低 2–5 小品（鹿鼎普通敌人中位黄上），若按真实 `G × L(n)` 计算，杂兵几乎打不动人（验算中需 20–37 次命中才能击倒主角，低武最甚），节奏无法落在基准 §5 区间。归一后，敌人的武学品阶只决定：其附带 Buff 的品阶（06 品阶对抗）、特效强度、掉落品阶（02 §2.12）与可用招式；数值强度统一由模板与 `enemyStatMul` 控制。**具名 NPC（`full`）不归一**，按其真实 `G × L(n)`。

结论：与 02 的"入场比 0.73、可延后挑战"一致——刚入鹿鼎就去打会非常吃力，先学本地天级再战则回到 Boss 节奏区间。其峰值难度主要来自攻击与机制（教众合击、"美人三招/英雄三招"类招式，chapters/08 定义），而非无限堆气血。

### 11.2 叠加管线："基础值 → 加值 → 百分比 → 最终值"

对每个属性 S（按 §1.2 的步骤顺序逐个求值）：

| 步 | 名称 | 规则 |
|---|---|---|
| ① | 基础值 `Base_S` | 由等级曲线 × 先天系数 + 固有常数给出（§3–§6 各公式的 `Base`） |
| ② | 加值 `Σflat_S` | 所有 `flat` 与 `flatLv`（后者先按 `Ld` 解析为数值）**相加** |
| ③ | 百分比 `Σpct_S` | 所有 `pct` **相加**（同属性的加成彼此加法，不连乘）；负值（减益）同池相加 |
| ④ | 独立乘数 `Πmult_S` | 仅限标注 `mult` 的来源（天书之力特殊项、敌人模板/流派/难度）；**每个属性同时生效的玩家侧 `mult` 不超过 2 个** |
| ⑤ | 合成 | `S = (Base_S + Σflat_S) × max(floor_S, 1 + Σpct_S) × Πmult_S` |
| ⑥ | 百分点 | PCT 形态属性：`S = Base_S + Σpp_S`（没有②–④） |
| ⑦ | 截断 | `clamp(S, min_S, max_S)`（§12 汇总各属性范围） |
| ⑧ | 覆写 | 机制类 `override`（如"`resCC` 视为 75"、"`hpMax` 锁定为施加时的值"）最后生效，多个覆写取最新施加者；"停止集气"不用覆写实现（§11.5 #3） |

- `floor_S`：MAG/RAT 为 0.2（即任何减益叠加最多把属性压到 20%）；资源上限 `hpMax`/`mpMax` 同为 0.2。
- 与伤害乘区的关系：本管线产出的是**面板属性**。"伤害 +X%"进 Z3、"受到伤害 −X%"进 Z4、"对某类兵器伤害"进 Z5，均**不是属性修饰**，由 design/04 汇总；数据中以 `target: 'dmgUp' | 'dmgDown' | ...` 区分于 `target: StatId`。
- **同名互斥**：同一 `sourceId` 的修饰器只生效一次（例如同一件装备的同一词条不会因为重复计算而翻倍）；Buff 的叠加规则（刷新/叠层/独立/取高）由 design/06 在生成修饰器前处理。

示例（`atkOut`，Lv50，`str` 70）：

| 步 | 内容 | 值 |
|---|---|---|
| ① | `ATK_LV(50) × (1 + 0.01×20)` = 1,216 × 1.2 | 1,459 |
| ② | 地中剑 `0.30 × 2.2 × 1,216` = 803；词条 +50 | +853 |
| ③ | 某内功特有被动 +10%、套装 +8%、减益"筋骨酸软" −15% | Σ = +3% |
| ⑤ | `(1,459 + 853) × 1.03` | **2,381** |

### 11.4 重算时机

| 触发 | 范围 |
|---|---|
| 书眠进入新书界、`Lr` 升级、装配/装备变化、修为分配变化 | 全量重算 |
| 战斗中 Buff 施加/移除/叠层变化 | 标脏受影响属性及其下游（按 §1.2 DAG），在**下一次读取前**增量重算 |
| 条件修饰（`cond`，如"气血低于 30% 时 +20% 攻击"） | 在每次自身行动开始、每次受击结算后重新求值条件 |
| 伤害结算 | 读取**招式开始结算那一刻**的属性快照；同一招式多段伤害共用该快照 |

### 11.5 边界情况

| # | 情况 | 规则 |
|---|---|---|
| 1 | 先天极低（如根骨 1） | 含 `(X−50)` 的乘法项各有下限 0.5（§3、§4.1、§5.1），`hpMax` 不会低于曲线值的一半 |

| 11 | 敌人 `flatLv` | 按敌人自身等级解析 |
