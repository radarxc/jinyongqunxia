# 平阳府 / 平阳路·临汾县 · 1217 / 1259 年城图复原依据

> 归属：`design/22` 的逐城规格与复原依据；主规格为 ch02，ch03 只保留同带差量与布局。
> 标注：同期文献可证写“据”；无同期城图的空间落点逐项写（推定）；游戏容量写**（原创扩展）**。
> 图像边界：本次实际看过清代《城池图》，仅作后世回溯线索，绝不冒充金 / 蒙古时期测绘。

## 1. 年代与结论

- ch02 取 1217：平阳府仍是金河东南路重镇，临汾为附郭次赤县；CHGIS记1218年蒙古军始克平阳并改平阳路。
- ch03 取 1259：采用“平阳路·临汾县”；上游 `cities.yaml` 的 ch03 显示名仍是“平阳府”，本任务不改共享名录，只在规格注明史名差异。
- 《金史》可证府级行政、总管府 / 转运司、附郭临汾及汾水，不能证明城垣折点、门位与街坊。
- 清代《城池图》画四门围城、官署、寺观与道路汇向；县志又称明初“因旧城重筑”。这只能提示旧城连续性，不能把清图的门额、瓮城、砖垣和建筑倒投到1217。
- 采用四边围垣、四方门、十字主街、城西汾水画缘；除“治所在今临汾”“汾水存在”外，全部空间几何均为（推定）。
