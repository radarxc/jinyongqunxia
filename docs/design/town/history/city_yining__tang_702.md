## 4. 生成阻断与默认处理

现行 CitySpec 强制 `wall` 与至少一座 `primary` 城门；没有无城墙营地的合同。
渲染器 `visible_wall_cells` 对“游戏包络”的不绘墙特例仅适用于大理，不能应用到伊丽水营地。
工具建筑目录没有帐篷类型；把民居、仓屋或宋衙门改名为帐篷会让总装图错误，因此不这样交付。
将 `era_kit` 设为 `xiyu` 实测触发 `TOWN_SCHEMA_ENUM`；西域素材目录中的建筑 ID 与工具55种目录交集为0。
这些是本地代码与参数验证，不是联网推测。修复归 `design/22` 与 `tools/town/`，本任务无权修改工具。
默认先保留这份可复用依据，等待无墙场景、帐篷和西域目录接入后，再执行完整生成管线。
