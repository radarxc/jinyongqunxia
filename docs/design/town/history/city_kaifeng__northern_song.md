## 1. 年代、对象与证据边界

本单元采用项目《天龙八部》书界锚点 1093 年；城市名录当期名称为“东京开封府（汴梁）”。
当前采用的骨架是：三城环套、四河贯都、开放街巷和皇城中置为强约束；缩景只画最外城环与一条代表河。
本图优先表达“三城、四河、御街与开放街市”；没有同期控制点的门、街、分区与建筑数量全部降级为（推定）或**（原创扩展）**。
现代行政区只用于稳定城市 ID 与检索，不把现代城区、明清城墙或旅游重建直接倒投到 1093 年。
《天龙八部》主线没有为本城给出可量测街巷图；三联／广州修订版的地点描写仍只作剧情索引，不伪造回目号或原文引句。

## 3. 缩比、网格与素材边界

规格使用 `160×160` 规划格，共 `25600` 格；`cell_m=1` 只供运行时，不能解释成历史实尺。
按 `design/22` 画幅，母版地面为 `(160+160)×32 = 10240` px 宽、`(160+160)×16 = 5120` px 高；0.25 预览理论地面为 `2560×1280` px。
历史城域与游戏格不存在统一米／格：本图保留城垣—主街—水系—功能区的拓扑，牺牲真实距离、地块数量和局部角度。
年代套件为 `song_north`；该套件缺失的地面、路边、植物、部分桥栏由渲染器回退 baseline，并在 manifest `notes` 登记。
建筑 ID 全部来自套件或 baseline 已登记目录；候选贴片不能反过来证明具体建筑形制。

## 4. 复原依据与逐要素坐标

| 要素 | 数量 / 布局 | 证据等级 |
|---|---:|---|
| 城垣 | 1 道 | 三城、四河、御街与开放街市；精确折点（推定） |
| 城门 | 2 座 | 方位、门宽与门名（推定）（原创扩展） |
| 街道 | 3 条 | 主关系参考资料；线位与格宽（推定） |
| 水系 | 1 条 | 水陆关系有依据，线位推定 |
| 桥梁 | 2 座 | 保证道路连通的（原创扩展） |
| 功能分区 | 5 区 | 行政、市肆、坊居、寺观、军驿的可玩抽象（原创扩展） |

城墙、门、主街、水、桥、区按对象类别计，坐标推定项为 `14` 项。
自动填充的每栋通用建筑不重复冒充独立史证；其数量只用于判断疏密、通行和素材总装。
没有证据的内城、瓮城、坊墙、井渠和城外寺院均不补画；schema 支持但本轮不以想象填空。

## 5. 剧情对应、配额与验收

本城在 `ch01` 的名称与开放状态引用 `design/map/cities.yaml`；主线唯一归属仍是 `design/story/01`。
本布局只提供城镇旅行候选，不新增 NPC、任务、营生 ID、门派驻地或正式场景引用。
当前构造式生成 `43` 栋建筑、道路 `2061` 格；最终数值以 layout 与批次报告为准。
配额顺序先保官署、客栈、寺观与守舍，再填铺面、摊棚和民居；所有上下限均为**【建议值】（原创扩展）**。
原著考据只需核本城是否在三联／广州修订版被明确提及及其情节位置；未核前不得把地图开放等同原著到访。

## 数据校验规则与测试用例

- 生成 → `check_town --strict-assets` → 平面图 → JPEG 预览；布局不得含 validation error。
- 检查建筑不压水、桥、墙，全部必需入口可达，规划与六角行走层连通。
- 目检城垣／门／主街／水系与本页一致，建筑不出墙；套件回退必须留痕。
- 反例：改成后世城名、把现代街图当1093地籍、把未核门名写入地图，均不得通过历史审核。
