# 沧州旧州城 · 南宋 / 金 / 蒙古年代带布局依据

> 归属：`design/22` 城镇布局；上游为 AR-36 / AR-47、基准、`design/map/cities.yaml`。

> 标记：（史实）为文字可核；（推定）为证据不足；（原创扩展）为游戏配置。

## 1. 场景对象与年代

本图对象是今沧县旧州的沧州州城，不是现代沧州市区长芦城。
名录 `116.85E / 38.31N` 是现代城市导航点，不能当作十三世纪州城坐标。
《金史》卷二十五记沧州为上州、横海军节度，清池县有河仓，长芦在清池属镇之列。
故宫博物院《沧州铁狮》记铁狮在今市东南约20公里的旧州城内、东西门大道北侧。
两项共同约束“旧州州城—东西道路—路北铁狮”的关系，不提供城垣折点或街坊地籍。
主规格 `historical_year: 1217` 是本年代带锚点，不断言该年全部街巷和官署仍为金朝完整旧制。
ch03按批次契约只改 `chapter_id / book_world`，其1217字段仍表示共用骨架锚点，不能解读为《神雕》发生于1217。
本轮未取得1259年前后重筑、战损、官署存废的城内平面，因此同带复用是审慎候选，不是四十余年毫无变化的史实判断。

## 2. 外部来源与看图记录（2026-10-04）

| 键 | 实际读取的来源 | 可信度与用途 |
|---|---|---|
| `src_jinshi` | [《金史》卷二十五·地理中](http://www.guoxue123.com/Shibu/0101/00jins/024.htm)，正文已读 | A-，传世史籍网页；沧州、清池和长芦的建置关系，不给城内坐标 |
| `src_chgis` | [CHGIS：沧州（1369—1911）](http://tgaz.fudan.edu.cn/tgaz/placename/hvd_88239)，正文已读 | A-，学术机构历史地名资料，转引《明史》《大明一统志》《河北省志》；用来区分旧州与长芦 |
| `src_dpm` | [故宫博物院：刘毅《沧州铁狮》](https://www.dpm.org.cn/Uploads/pdf/1953/T00010_00.pdf)，PDF原页已下载、渲染并目检 | B，文博文章；看过铁狮照片与文字，只有物件照片，没有城图 |

共3项实际读到的外部资料；转引书目不重复计数，项目名录不计外部来源。
CHGIS以1369年迁治长芦为界；检索还见1314年迁治说，但未据其摘要裁定差异。
两种说法都晚于1217及1259，本稿只用它们确认“不能搬用后世长芦城”，不替迁治史作终审。
故宫资料引用1933年《沧县志》，属晚期见闻，不能自动证明十三世纪街路原位未动。
检索“沧州旧城遗址平面图”出现的黄骅旧城遗址与本旧州州城不是同一对象；1933蓝本的《沧州老城关图》也不能前推。
没有取得可分期到1217的城垣实测图；资料照片只辅助理解铁狮，不能据照片量出州城。
参考PDF与页面保存在临时目录，不进入资产包；本文平面SVG/PNG是推定成果，不是史料原图。

## 3. 历史空间与缩景规则

规划图北向上，x向东、z向北；所有坐标以游戏格表示。
网格128×128，共16384格；`cell_m=1`仅供运行时，不是历史一米一格。
母版地面理论画幅8192×4096；0.25 JPEG为2048×1024，历史米/格未知。
外垣使用八折包络，保留旧城的不规则意向；没有同期控制点，不称“卧牛形精确复原”。
两处方位门和东西街有晚期文字关系可参考，其位置、门楼与街宽仍逐项推定。
不绘穿城河、城壕或桥：清池条的浮阳水、徒骇河和河仓不足以定位城内水线。
铁狮953年铸成可核；现有套件没有专用铁狮模型，因此不拿普通建筑或其他石兽冒充。
寺域只保留东西大道北侧的关系；匿名寺殿不是开元寺原构，也不证明1217的殿堂存续。
