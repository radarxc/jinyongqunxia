# 南阳县（后升申州）· 1217 年历史布局复原依据

> 归属：`design/22` 城镇规格逐城历史依据；本页只解释 `city_nanyang` 在南宋—金—蒙古年代带的坐标选择。
> 标注：（推定）= 证据不足的关系或坐标；**（原创扩展）** = 玩法设计；**（待考）** = 仍需原始报告终校。

## 1. 年代、政区与对象纠偏

项目 `city_nanyang` 坐标在今南阳市。1217 年这里是金南京路邓州属南阳县，不是邓州州治。
《金史》载邓州倚郭县为穰城，州治在今邓州市；南阳县另列梅溪水、白水、清泠水与张村镇。
故本图只画今南阳位置的“南阳县治”，不能复用此前 `city_nanyang__ch01` 对今邓州古城的考古骨架。

复旦 CHGIS 汇引《大明清类天文分野之书》与嘉靖《南阳府志》，记金正大三年（1226）升申州。
因此 `ch02` 1217 仍称南阳县；`ch03` 1259 采用“申州（南阳县）”作为蒙古统治期沿用候选。
`design/map/cities.yaml` 把整个年代带宽泛标为“邓州”，不适合直接作为城内显示名。

## 2. 实际打开并阅读的来源（2026-10-04）

1. `src_jinshi`：《金史》卷二十五《地理志中》通行本网页。
   - 已读正文；邓州为武胜军节度，倚郭穰城，南阳只是三属县之一。
   - 南阳县条列豫山、百重山、丰山、梅溪水、白水、清泠水与张村镇，不给县城平面。
2. `src_chgis`：复旦 CHGIS“南阳县”。
   - 已读 JSON 正文及引文；约束今南阳市点位、1226 年升申州、1271 年升南阳府。
   - 所引文物地图明确今老城南阳府城址始建于元；不能把元明清府城直接当 1217 县城。
3. `src_nanyang_late`：南阳文明网《南阳府城的岁月印记》。
   - 已读正文并看“南阳府内城俯瞰复原图”“内城街区平面图”。
   - 页面明确现图是在元代城址基础上的明清府城；四经四纬、四门与十二街区均属后世。
4. `src_dengzhou_arch`：河南省文物考古研究院“邓州古城遗址”案例。
   - 已读正文并看发掘位置示意图、宋金古街一期全景。
   - 证实邓州有宋金街、沟渠与城墙，但对象是今邓州、即金代穰城州治，只作误配反证。

## 3. 已看图及局限

- 南阳后世平面图为不规则近方城、四门与纵横街网；资料将其基础明确放在元代以后。
- 本规格不采用后世门名、四经四纬、十二街区、护城河或府衙位置，只保留“老城范围内县治候选”。
- 邓州发掘位置图清楚标示明代内外城和宋金发掘点；它不属于今南阳市，不参与本图坐标。
- 目前未取得 1217 南阳县治墙线、门位或街坊考古图，故采用克制的两门、三街、五区抽象。

## 4. 复原选择与缩比

规格使用 `128×128` 规划格，共 `16384` 格；不能解释成历史实尺或现代街图配准。
母版地面理论尺寸 `8192×4096 px`，主章节只渲染 0.25 JPEG 预览，不生成 fullsize。
年代套件为 `liao_jin_north`；基础地面、道路与植物缺项由 baseline 声明式回退。

| 要素 | 本版表达 | 证据与限制 |
|---|---|---|
| 城址 | 今南阳市老城范围内县治候选 | CHGIS 仅给治所点；精确位置（待考） |
| 城垣 | 紧凑近矩形夯土城 | 宋代缩城仅见后世概述；轮廓（推定） |
| 城门 | 南、北两门 | 门数、门名、位置均（推定）（原创扩展） |
| 主街 | 南北轴 + 东西横街 + 市巷 | 县城玩法通行抽象 |
| 水系 | 西侧梅溪水画缘 | 《金史》仅证县境有梅溪水；岸线与城距（推定） |
| 分区 | 县署、市肆、坊居、寺观、军驿 | 功能与落位均为玩法抽象 |

坐标推定对象计 `13`：1 墙、2 门、3 街、1 河、5 区、1 整体缩比。
自动填充建筑不重复计作独立史证；不放府级王府、州衙或邓州考古地标。

## 5. 章节差量与剧情边界

`ch02`（1217）显示“南阳县”，表达金邓州属县。
`ch03`（1259）显示“申州（南阳县）”，表达 1226 后升州事实；城内几何沿用候选，官署级别变化未具象扩建。
本布局不新增 NPC、任务、营生 ID、机构归属或正式场景引用；原著没有可量测县城图。

## 6. 验收与开放问题

- 两章各跑 `gen_layout.py` 与 `check_town.py --strict-assets`；布局不得含 validation error。
- `plan_view.py` 只从 1217 规格生成一份 SVG / PNG；标题和说明不得冒称史图。
- 目检紧凑城垣、两门、三街、西侧画缘水体一致，建筑不压水、不越墙。
- 若取得宋金南阳县治考古平面，应替换推定墙线；不能以邓州古城或明清南阳府图代替。
