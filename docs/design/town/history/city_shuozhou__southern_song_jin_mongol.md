# 朔州·鄯阳县·1217 / 1259 年城图复原依据

> 归属：`design/22` 逐城规格；ch02 是 1217 年主候选，ch03 是 1259 年蒙古时期章节副本。
> 证据边界：同期文字能证行政、水系与金代寺院遗构；没有同期城图。墙门、街线、功能区及具体坐标均标为**（推定）**，容量标为**（原创扩展）**。
> 回溯限制：北齐至辽金的沿用关系只控制“南北略长的大城”拓扑；当代修复明城照片不能反推金代砖墙、门楼、门名或街巷。

## 1. 年代、治所与结论

- 《金史》卷二十四记朔州为中州、顺义军节度使，户四万四千八百九十二，领县二；附郭鄯阳县有桑干河。
- ch02 取 1217 年金末，表达金西京路朔州治鄯阳的候选拓扑；正史户数不用来反算缩景栋数。
- ch03 取 1259 年蒙古时期；未取得两年之间墙线、街坊或崇福寺损毁重建图，故沿用拓扑但不宣称四十二年间毫无变化。
- 山西省文物局公开摘要支持北齐天保八年在秦汉马邑故城重筑州城；后志汇编称其南北略长、隋唐辽金沿用。
- 国际在线正文与照片支持崇福寺位于朔州老城，弥陀殿、观音殿为金代遗构；规格仅用一座通用殿堂作寺院锚点。
- 因此保留长方大城、四向通路、城外桑干河关系和城内寺院意象；门数、十字街及分区布局均为推定。

## 4. 网格、缩比、章节副本与容量

- 网格 `128×128`，`cell_m=1` 仅用于运行时；历史米/格未知，采用非等比拓扑压缩。
- 后志的1800×1600米数字可信度不足，不换算本图墙体每格米数；只保留“南北略长”。
- 投影每格64×32像素；0.25 JPEG 为2048×1024。分带 `q=[96,79]`、`r=[96,32]`，`formal_scene_refs=null`。
- 章节规格共2份，其中副本1份：ch02 有 layout、preview、manifest；ch03 仅 layout，不渲染、不写 manifest。
- 固定种子下 ch02 实放37栋，ch03实放38栋；差异是章节 seed 流程下的候选容量，不表示人口变化。
- ch02/ch03 两份布局累计生成耗时6.8935秒，主预览4.5201秒；考据与规格收敛约20分钟，为工作记录估算。
