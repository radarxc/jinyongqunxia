# 济南府·历城县·1217 / 1259 年城图复原依据

> 归属：`design/22` 逐城规格；ch02 是 1217 年金末主候选，ch03 是 1259 年蒙古时期章节副本。
> 证据边界：文献可证济南府治历城、唐中叶后不规则合城、金代大明湖及北排水关系；没有同期可配准城图。
> 回溯限制：明清府城图、模数与门名只帮助理解长期地形制约，不精确倒推金代墙线、门位、街巷或湖岸；无控制点内容均标**（推定）**。

## 1. 年代、治所与结论

- 《金史》卷二十五记济南府属山东东路、治历城，领县七、镇二十九；不提供城内平面。
- 山东大学讲座资料支持西晋历城、东城“双子城”，唐中叶合并为不规则城圈，宋金元继续强化区域中心功能与城市肌理。
- 地方志正文支持金初开浚小清河后湖面渐缩，金代已称大明湖，湖水由北部出水入小清河。
- ch02 取1217年；ch03取1259年。未取得期间城垣重修和湖岸变化图，副本保留同一拓扑，不宣称四十二年完全静止。
- 因此表达不规则八点外墙、三座匿名陆门、北部湖面、一个北泄水口与画幅北缘小清河；所有具体坐标均为缩景推定。

## 4. 网格、缩比、章节副本与容量

- 网格 `160×160`，`cell_m=1` 只用于运行时；没有同期周长与控制点，历史米/格未知，采用非等比拓扑压缩。
- 只保持“北部低、湖在北城、北泄入小清河”的关系，不把现代距离或明清模数压成固定比例。
- 投影每格64×32像素；0.25 JPEG 为2560×1280。分带 `q=[96,96,27]`、`r=[96,64]`，`formal_scene_refs=null`。
- 章节副本2份：ch02 有 layout、preview、manifest；ch03 仅 layout，不渲染、不写 manifest。
- 固定种子下 ch02/ch03 各实放44栋；栋数是玩法容量，不代表户数、税额或繁荣度。
- 两份布局累计生成耗时10.6816秒，主预览5.8627秒；考据与规格收敛约22分钟，为工作记录估算。
