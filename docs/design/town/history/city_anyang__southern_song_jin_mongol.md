# 彰德府（安阳）· 南宋—金—蒙古时期城镇布局依据

## 1. 府名与层位边界

《金史》经复旦 CHGIS 引用：明昌三年（1192）升相州为彰德府，治安阳，属河北西路。
蒙古宪宗二年（1252）以彰德为散府，属真定路；至元二年（1265）才改彰德路。
故 1217 与 1259 均显示“彰德府”，1259 说明蒙古统治期，不提前改称彰德路。
项目城址指今安阳老城；殷墟、洹北商城、邺城与彰德府不是同一套城垣。
旧城在治所近旁多次重筑；年代延续不等于所有墙、街、河道从商到金保持不变。

## 3. 已看老城图的用途

老城图显示近矩形城垣、南北大街、偏位横街、院落与西南部天宁寺区域。
它还包含后世机构和民居，故本版不照抄九府十八巷、片字街、钟楼或门名。
天宁寺域放在城西南为位置延续候选，1217 院墙、门位与具体殿堂仍全部（推定）。
今日天宁寺塔的五层、上大下小形制已确认，但现有套件只提供十三层上收辽式塔。
因此不放该塔；用匿名殿堂作寺域代理，并明确不称实测天宁寺殿堂。
外部水系只画洹水北缘，和老城之间留陆地，不虚构整圈护城河或穿城航道。

## 4. 复原取舍与缩比

网格 `128×128`，共 `16384` 个游戏格；采用府城拓扑缩景，不作历史实尺。
外垣范围 `(16,20)—(112,108)`，洹水位于 `z=120`；两者历史距离被显著压缩。
`cell_m=1` 供工具使用，不能把 96 格墙宽解释成金代城宽96米。
理论母版地面 `8192×4096 px`；主章节只出 `0.25`、JPEG q85，预览理论 `2048×1024 px`。

| 要素 | 本版表达 | 证据与限制 |
|---|---|---|
| 治所与名称 | 金代彰德府治安阳 | CHGIS 引《金史》，不再用北宋相州名 |
| 城垣 | 一圈近矩形土墙 | 治所可靠，折点、范围（推定） |
| 城门 | 南北两门 | 门数、宽度、门位（原创扩展） |
| 街道 | 南北通街、折线横街、东南市巷 | 可玩交通抽象，不复刻后世片字街 |
| 洹水 | 北侧画缘横向水系 | 城在河南为跨年代关系，岸线、宽度、流向（推定） |
| 府署 | 西北院区 | 府级功能已证，区位与建筑（推定） |
| 天宁寺 | 西南寺域及一座通用殿堂代理 | 寺塔前于金代，精确寺界和延续（推定） |
| 民居、市场、军驿 | 三组功能区 | 配额、密度、地块（原创扩展） |

推定对象 `14`：1 墙、2 门、3 街、1 河、5 区、1 固定寺域代理、1 整体缩比。
自动填充建筑及植被不再单列独立史证；不放宫城、商王陵、洹北宫殿或后世王府。
