# 太原府·宋金太原城（唐明镇新城）·1217 年城图复原依据

> 归属：`design/22` 的逐城规格与复原依据；ch02 为主规格，ch03 是同一 1217 年历史锚点的章节副本。
> 标注：文献可证的关系写“据”；没有同期测绘控制点的坐标写**（推定）**；为可玩容量设置的街巷、分区与栋数写**（原创扩展）**。
> 关键断代：本页复原的是 982 年在唐明镇营建、金代继续使用的太原府城，不是 979 年被毁并引水浸灌的晋阳旧城，也不是 1375 年以后向北、向东扩展的明太原城。

## 1. 年代、城址与结论

- 1217 年太原府仍在金朝河东北路。《金史·地理志》记太原府为上府、治阳曲，领十一县、八镇；该条能确定行政层级，不能提供城内坐标。
- 太原晚报所引地方文献称：宋太宗毁晋阳后，982 年在晋阳东北约三十里、唐明镇故河东军城处筑并州城；罗城周十里二百七十步、四门，西部包入河东军旧城作为子城。
- 国家图书馆文章对《永乐大典》所存《太原志》作文本分层，指出罗城、子城、官署、门街和坊名的主体来自金代《晋阳志》，更具体地反映大定十一至十四年（1171—1174）面貌。故“大城套西部子城”并非把明城倒投到金代。
- 1217 与 1171—1174 相隔四十余年；没有证据证明每条坊巷和官署在 1217 原位不动。因此只把罗城—子城、四门名称和主要门街当作拓扑骨架，所有格坐标与建筑落点均标推定。
- 晋阳旧城约在新城西南十五公里（另有“三十里”传统表述），已在 979 年被毁；本图不画唐代晋阳三城、跨汾格局或晋阳宫。

## 4. 网格、缩比与容量

- 网格 `160×160`，`cell_m=1` 仅供运行时寻路；若把文献约六公里周长粗略对应 136 格外垣周长，则会得到约 11 历史米 / 格，但本规格没有足够控制点，**不采用这一数值作配准或移动尺度**。
- 投影母版每格 64×32；0.25 JPEG 的地表包围框约 2560×1280，屋顶可能增大边缘。
- 分带为 `q=[73,73,73]`、`r=[80,80]`，`formal_scene_refs=null`，不注册正式 scene。
- 建筑配额下限 / 上限是游戏容量建议，不代表户数或人口；最终 ch02 生成 53 栋，planning / runtime_hex 必需目标均为单连通分量。
- `liao_jin_north` 只提供匿名辽金北方建筑意象；素材形制不能反向证明某座太原官署、寺院或民居的真实外观。
- 最终渲染报告 `missing_assets=[]`、`diagnostic=false`；21 条替代记录来自北/西/东门、土路、夯土地和路缘的正式回退。南门与子城门使用本套件门图；回退不改变历史断代。

- ch02 与 ch03 均锚定 1217；ch03 只改 `chapter_id` 与 `book_world`，避免在没有新证据时虚构 1259 几何演变。

## 数据校验规则与测试用例

1. ch02、ch03 均须 `gen_layout.py` 成功，随后 `check_town.py --strict-assets` 为 0 error；素材替代必须保留 warning 与 manifest 说明。
2. 规格须逐字段比较，除 `chapter_id` / `book_world` 外完全相同；ch03 目录只允许 `layout.yaml`。
3. 建筑不得压墙、堵门或跨越子城；所有必需入口、planning 与 runtime_hex 目标须保持单连通分量。
4. ch02 的 JPEG 必须为 0.25、q85、短边不少于 512，manifest 尺寸 / SHA 与文件一致，`missing_assets=[]` 且 `diagnostic=false`。
5. 目检 plan 与 preview 的罗城、城西子城、四外门和一内门一致；不得出现晋阳旧城的汾河三城或明代八门扩城。
6. 反例：把 ch10 唐晋阳规格复制进本带、把现代叠合图像素当 1217 测量点、把《永乐大典》错行直接画成院落，均不得通过历史审核。
