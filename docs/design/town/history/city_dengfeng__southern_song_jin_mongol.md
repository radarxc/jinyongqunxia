# 登封县 · 南宋—金—蒙古时期城镇布局依据

## 1. 城市对象与时代

复旦 CHGIS 引《金史》确认登封属河南府，元代属河南府路；治所在今登封。
本图画县治，少林寺位于县城西北约 13 公里，不能把整个寺院并入县城围墙。
嵩阳书院、中岳庙、汉崇高城遗址同样各有地理对象，不能把“登封”行政范围当一座城。
1217 采用金河南府属县；1259 采用蒙古统治期县治候选，保持同带几何。
`liao_jin_north` 是批次素材套件；1259 沿用不表示金政权仍存在。

## 4. 规格选择与缩比

网格 `128×128`，`16384` 个游戏格；`cell_m=1` 仅为运行时约定。
县城围墙采用 `(22,16)—(108,112)` 的紧凑纵向包络，并非历史米制测绘。
不使用固定历史米／格缩比；保留县治、道路、补给与城外山行的拓扑关系。
理论母版地面 `8192×4096 px`；主章节渲染 `0.25`、JPEG q85，理论预览 `2048×1024 px`。

| 要素 | 本版处理 | 证据和限制 |
|---|---|---|
| 外垣 | 一圈夯土墙 | 唐以来县城事实；全部折点、尺寸（推定） |
| 城门 | 南北两门 | 门数、门位、宽度（原创扩展） |
| 道路 | 通街、横街、市巷 | 不能把明清十字街当宋金测绘；线位（推定） |
| 县署 | 北部院区 | 后世描述约束方位，1217 延续（推定） |
| 市肆与坊居 | 南市、西南民居、东侧作坊 | 功能、密度、地块（原创扩展） |
| 山行服务 | 北门马厩、守舍 | 体现县城至山寺交通，不作寺庄 |
| 水系 | 不绘河、桥、环城壕 | 同期岸线未锁定；不绘不等于历史无水 |

推定对象计 `12`：1 墙、2 门、3 街、5 区、1 整体缩比。
植被、自动建筑和配额均为玩法建议，不重复计独立史证。
