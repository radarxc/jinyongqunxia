# 解州·解县（今解州镇）·1217 年城图复原依据

> 归属：`design/22` 的逐城规格与复原依据；ch02 为主规格，ch03 是同一 1217 年历史锚点的章节副本。
> 标注：文献可证的关系写“据”；无同期测绘的坐标写**（推定）**；游戏容量写**（原创扩展）**。
> 关键断代：`city_yuncheng` 在本时代层显示“解州”，指今运城市盐湖区解州镇一带的解州 / 解县治，不是现代运城市中心，也不是元末因盐务营建、后来得名“运城”的盐政城。

## 1. 年代、治所与结论

- 1217 年为金代解州，治解县。《金史·地理志》记解州为中州，领解县等六县；CHGIS / TGAZ 的 1127—1217 条目把州治落在解县。
- CHGIS 沿革显示：蒙古军在 1217 年占领这一带；1220 年州治移平陆，后在蒙古 / 元初返回解县。故本批共同锚定 1217，不把 1220 以后的短期迁治误画成同一城市几何。
- 《太平寰宇记·解州》明确“盐池，在县东五里”。这只能约束解县与盐池的东西关系，不能给出 1217 岸线；本图把一段被画幅裁切的盐池边缘放在城东，并保留陆地间隔。
- 运城市人民政府 2025 年文保通知称解州故城仍存宋代城墙遗迹，包括西、南墙段及西门瓮城遗迹；这支持宋金时期有墙城延续，不足以复原完整周界、四门和 1217 门楼。
- 人民网转述地方沿革称“运城”城池在元末因盐运管理而建。1597 年《河东盐池之图》已实际查看，只用于理解解州在盐池以西的区域关系，绝不把其盐政设施、方格路网或明清门名倒投到 1217。

## 4. 网格、缩比与容量

- 网格 `160×160`，`cell_m=1` 仅为运行时寻路；无同期周长和控制点，历史米 / 格未知，采用非等比拓扑压缩。
- 城墙只占画幅西中部，东侧留出陆带与裁切盐池，使“县东五里”在拓扑上可读；这不是把五里压成十四米。
- 投影母版每格 64×32；0.25 JPEG 地表包围框约 2560×1280。
- 分带 `q=[73,73,73]`、`r=[80,80]`，`formal_scene_refs=null`。
- 建筑配额是玩法容量，不代表人口 / 户数；最终 ch02 生成 50 栋，盐池水面 3820 格，planning / runtime_hex 必需目标均为单连通分量。辽金北方匿名贴片也不证明解州具体建筑外观。
- 最终渲染报告 `missing_assets=[]`、`diagnostic=false`；33 条替代记录来自北/西/东门、土路、夯土地、水面、水岸和路缘的正式回退。南门使用本套件门图；回退不提供历史证据。

## 数据校验规则与测试用例

1. ch02、ch03 均须 `gen_layout.py` 成功并经 `check_town.py --strict-assets` 零错误；回退 warning 不得隐藏。
2. 两份规格除 `chapter_id` / `book_world` 外须逐字段相同；ch03 目录只允许 `layout.yaml`。
3. 建筑不得压墙、压水或堵门；盐池与东墙至少留 13 格陆带；所有必需入口和两层行走目标须单连通。
4. ch02 JPEG 须为 0.25、q85、短边不少于 512；manifest 尺寸 / SHA 一致，`missing_assets=[]`、`diagnostic=false`。
5. 目检 plan 与 preview 均须呈现“城在西、盐池裁切边缘在东”，不得把水面移到南侧或贴到墙脚。
6. 反例：复用 ch10 唐代盐池聚落、套入元末运城盐政城、按 1597 图量取 1217 街墙、宣称未打开的政府页已核正文，均不得通过历史审核。
