## 1. 年代、对象与证据边界

本单元采用项目《天龙八部》书界锚点 1093 年；城市名录当期名称为“腾冲府一带（大理国，待考）”。
现有来源只支持“宋时大理国设立腾冲府”这一行政沿革；没有取得可约束 1093 年城形、城门或街网的同期史证。
本图保留闭合外垣、内部分界与十字街，纯为提供可玩的双层空间候选，均属无同期史证的**（原创扩展）**；精确坐标另标（推定）。
现代行政区只用于稳定城市 ID 与检索，不把现代城区、明清城墙或旅游重建直接倒投到 1093 年。
《天龙八部》主线没有为本城给出可量测街巷图；三联／广州修订版的地点描写仍只作剧情索引，不伪造回目号或原文引句。

## 2. 参考资料（访问日期：2026-10-04）

- `src_city`：[腾冲市政府：《云南：腾冲卫城》](https://www.tengchong.gov.cn/info/9617/5857023.htm)。可信度 `B`；仅文字，已打开正文。用途：支持宋时大理国设腾冲府，不支持 1093 年城形复原。
- 阅读结论：正文另载西山坝石城始建于 1445 年、1448 年竣工；隆庆二年曾议筑外城，后因经费不足而罢。两事均晚于本单元，且外城未建成，不能据此推出 1093 年存在内外城关系或网格街道。
- 检索摘要、打不开的页面和下载失败的图片不计来源；项目名录只作上游，不计外部史料。
- 临时参考文件不收入资产目录并在交付前清理；本任务生成的平面图不冒称史料原图。

## 3. 缩比、网格与素材边界

规格使用 `128×128` 规划格，共 `16384` 格；`cell_m=1` 只供运行时，不能解释成历史实尺。
按 `design/22` 画幅，母版地面为 `(128+128)×32 = 8192` px 宽、`(128+128)×16 = 4096` px 高；0.25 预览理论地面为 `2048×1024` px。
历史城域与游戏格不存在统一米／格：本图保留城垣—主街—水系—功能区的拓扑，牺牲真实距离、地块数量和局部角度。
年代套件为 `song_dali`；该套件缺失的地面、路边、植物、部分桥栏由渲染器回退 baseline，并在 manifest `notes` 登记。
建筑 ID 全部来自套件或 baseline 已登记目录；候选贴片不能反过来证明具体建筑形制。

自动填充的每栋通用建筑不重复冒充独立史证；其数量只用于判断疏密、通行和素材总装。
图中的内部分界不称历史内城；没有证据的瓮城、坊墙、井渠和城外寺院均不补画，schema 支持但本轮不以想象填空。

## 5. 剧情对应、配额与验收

本城在 `ch01` 的名称与开放状态引用 `design/map/cities.yaml`；主线唯一归属仍是 `design/story/01`。
本布局只提供城镇旅行候选，不新增 NPC、任务、营生 ID、门派驻地或正式场景引用。
当前构造式生成 `47` 栋建筑、道路 `1625` 格；最终数值以 layout 与批次报告为准。
配额顺序先保官署、客栈、寺观与守舍，再填铺面、摊棚和民居；所有上下限均为**【建议值】（原创扩展）**。
原著考据只需核本城是否在三联／广州修订版被明确提及及其情节位置；未核前不得把地图开放等同原著到访。

- 生成 → `check_town --strict-assets` → 平面图 → JPEG 预览；布局不得含 validation error。
- 检查建筑不压水、桥、墙，全部必需入口可达，规划与六角行走层连通。
- 目检城垣／门／主街／水系与本页一致，建筑不出墙；套件回退必须留痕。
