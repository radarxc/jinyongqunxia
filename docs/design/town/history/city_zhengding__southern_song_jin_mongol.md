# 真定府 · 1217 / 1259 年历史布局复原依据

> 归属：design/22 城镇生成的逐城依据；上游为 AR-36 / AR-47、design/19 和城市名录。
> 本稿是 study 模式、考古拓扑约束下的缩景候选，非宋金城垣地籍复刻。
> （推定）指证据不足；（原创扩展）指游戏抽象；【建议值】为可替换尺寸与配额。

## 1. 对象与年代

city_zhengding 在 ch02 / ch03 的地图名称均为真定府，锚点分别1217 / 1259。
“正定”只用于现代定位与资料检索，不前置为金代城名。
两章落在宋金元城址演变阶段，但蒙古时期不应继续声称属于金朝行政建制。
本城主预览为1217；1259保留街坊拓扑、独立生成layout，并修改章节、书界与历史年。
本轮没有可核的1259当年整城改筑图或战损位置，不虚构逐年墙体差量。

## 2. 实际打开来源（访问日期：2026-10-04）

- src_arch2019：[河北省文物考古研究院：正定古城2019年度考古工作汇报](https://www.hbswwkg.com/2022-02/22/content_8729955.html)。可信度A，考古机构直接汇报，正文已读。
- 该文明确晚唐五代子城的南、西墙及城台，北宋起废弃，至金代城墙完全废弃，两侧成为居民区。
- 该文明确南北、东西街道相连，燕赵大街轴线可追溯唐代；宋金元房址叠压显示街巷局部稳定，并有作坊、商铺。
- 对现东城墙卫前路至4号山段调查只见明代始建，不能拿今日围城轮廓声称为金代精确城界。
- src_research：[中国国家博物馆：赵献超《正定古城平面格局的复原研究》](https://www.chnmuseum.cn/yj/xscg/xslw/201812/t20181224_36605.shtml)。可信度A-，论文摘要已读，仅文字。
- 摘要将唐宝应至明正统划入同一复原阶段，并指明明正统扩城改变东南形态；未取得全文图版，不作角点控制。
- 两来源各自用于考古局部关系和整城分期；国博较早摘要不可压过2019发掘对金代子城废弃的直接证据。
- 共2项有效来源；2021发掘页面返回空内容，本轮不将搜索摘要算作已阅读证据。

## 4. 复原对象与推定清单

| 对象 | 数量 | 依据与限制 |
|---|---:|---|
| 外城游戏包络 | 1 | 排除明正统以后东南城形；矩形范围、角点与尺度均推定 |
| 方位城门 | 4 | 四方可达的游戏出入口，门数、门名、门位均推定 |
| 南北轴、东西街、寺南巷 | 3 | 轴线延续与正交路网有考古据，线位宽度与贯穿全城为推定 |
| 功能分区 | 5 | 寺在轴西、寺南商居有据；官署仓驿、区界与密度为原创扩展 |
| 水系、桥梁 | 0、0 | 局部考古水塘不等于同期整城水系；证据不足暂不合成 |
| 内城墙 | 0 | 金代完全废弃有考古据，不把唐五代子城继承为金代防御环 |

按墙、门、街、水、桥、区对象计，坐标或形制推定共13项；非声称只有13处历史不确定性。
开元寺只以一座套件通用殿堂和西侧宗教区表达，不冒称复原须弥塔、钟楼或原院界。
现代正定“九楼四塔”等整体景观不照抄；本稿没有同期证据支持那些后世视图的完整组合。

## 5. 网格、缩比与建筑

两章均128×128规划格、16384格；cell_m=1供运行时计算，历史城市不是128米见方。
采用非等比拓扑缩景，无统一历史米/格；保留方向邻接，压缩距离、街区数与院落尺度。
64×32母版理论地面8192×4096像素，主阶段0.25 JPEG为2048×1024像素。
年代套件按本批清单用liao_jin_north，地面、道路边和部分门适配由baseline承接；回退见manifest。
每章39栋：官署1、院落2、大屋2、小屋9、客栈1、摊棚8、一层铺8、二层铺3。
另有马厩1、寺堂1、仓房2、守舍1；全部配额为【建议值】（原创扩展），不以建筑数反推古城人口。
ch02/ch03道路分别1617/1613格，必需入口与道路连通分量均为1；无缺失必需建筑。
两章同拓扑与种子，但章节和年份参与布局字节、地面植被等过程，布局不要求字节相同。
