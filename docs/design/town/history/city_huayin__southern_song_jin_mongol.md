## 1. 年代、对象与证据边界

本年代带覆盖《射雕英雄传》书界锚点 1217 年和《神雕侠侣》书界末点 1259 年。1217 年华阴县处金朝统治；1259 年已在蒙古统治期。本任务没有取得金亡后至 1259 年的重筑平面，因此两章共用一个县城拓扑候选，但不声称城墙、街道和院落在四十余年间未变。

必须区分三个对象：

1. **华阴县城**：本图对象。CHGIS 将 762—1911 年华阴县治定位在今华阴县城，并记金属华州。（史实）
2. **华州州治郑县**：《金史》明记华州“治郑”，郑县另有少华山、圣山、渭水等；州城不在本图。（史实）
3. **太华山 / 华山山场**：《金史》在华阴县条列太华山；山峰、栈道、西岳祭祀建筑与门派山场属于城外山岳场景，不能把险峰、悬崖或山门画进县城。（史实边界）

所以本图只表达县城与关中东口交通、水系的关系。画面没有山峰不是否认华山，寺观模块也不得解释成西岳庙或华山派驻地。

1217 精确门址、城墙折点、街坊界和渭水岸线都没有同期控制点；1259 的行政隶属、战损和重筑状态资料更弱。除名称、县治位置和区域地理锚点外，全部降级为（推定）。

## 2. 参考资料（访问日期：2026-10-04）

- `src_chgis`：[复旦大学历史地理研究中心 / CHGIS：华阴县（762—1911）](http://tgaz.fudan.edu.cn/tgaz/placename/hvd_70329)。可信度 `A-`；正文已打开阅读。页面给出县名、时间跨度、治所点 `34.56831N, 110.08936E`，并引《旧唐书》《宋史》《金史》《元史》等说明金属华州、治今华阴县城。该点只能约束县治，不是城墙角点。
- `src_jinshi`：[《金史》卷二十六·地理下（通行点校本网页）](http://www.guoxue123.com/Shibu/0101/00jins/025.htm)。可信度 `A-`；正文已打开阅读。华州条明记州治郑、县五；华阴县条列太华山、松果山、黄河、渭水、潼关以及关西、敷水二镇。它支持区域拓扑，不提供县城平面。
- 项目逐章城市名录把 ch02 / ch03 显示名定为“华阴县”，只作上游项目事实，不计独立外部证据。
- 没有取得可确认为 1217 或 1259 的华阴县城图、考古总平面或可量测城墙图；因此本次外部来源均按“已读文字、未见同期县城平面”登记，绝不把现代华山景区图、后世华阴地图或华州州城资料当成本图控制图。

## 3. 年代判定与审慎沿用

### 3.1 1217（ch02）

- “华阴县”及其为华州属县有直接史籍与 CHGIS 支持。（史实）
- 华州在贞祐三年（1215）升节镇、军曰金安，不等于华阴县城就是州治或节镇驻城。（史实边界）
- 太华山、潼关、黄河、渭水是县境要素，不等于全部能收入 128 格县城场景。（史实边界）

### 3.2 1259（ch03）

- 项目名录继续使用“华阴县”；CHGIS 时间跨度也连续到后世。（项目事实 / 汇编）
- 本轮没有取得 1259 当年政区细目与城防材料；规格不写金朝仍存，也不新增蒙古官署、营盘或战损。（审慎推定）
- ch03 layout 由同种子和同拓扑生成，但 source spec 独立锁定 1259 说明；后续若得到蒙古时期重筑证据，应只校准 ch03 并重跑，不反改 ch02。

## 4. 缩比、网格与素材边界

规格使用 `128×128` 规划格，共 `16384` 格；`cell_m=1` 只供运行时，不能解释成历史实尺。
母版地面理论尺寸为 `(128+128)×32 = 8192` px 宽、`(128+128)×16 = 4096` px 高；0.25 JPEG 预览理论地面为 `2048×1024` px。
历史县城与游戏格不存在统一米／格：本图保留“东西通衢—县署—市肆—坊居—城外渭水”的拓扑，牺牲真实距离、地块数量和局部角度。
年代套件为 `liao_jin_north`；缺少的道路、植物或其他语义片由渲染器回退 baseline，并在 manifest 登记。贴片表现辽金北方的一般材质与构造，不能反向证明华阴某座具体建筑的形制。

## 5. 复原依据与逐要素坐标

| 要素 | 数量 / 布局 | 证据等级 |
|---|---:|---|
| 城垣 | 1 道矩形包络 | 县治点位（史实）；墙线、尺度与矩形形制（推定） |
| 城门 | 东西 2 门 | 通向关中 / 潼关的关系可解释；门址、门名、门数（推定）（原创扩展） |
| 街道 | 3 条 | 东西交通关系；具体线位与格宽（推定） |
| 水系 | 画缘渭水 1 条 | 县境有渭水（史实）；古岸、宽度与城河距离（推定） |
| 桥梁 | 0 座 | 河在城外画缘，不为凑构图虚构跨河门路 |
| 功能分区 | 5 区 | 县署层级可知；市肆、坊居、祠寺、仓驿位置与范围（原创扩展） |

按墙 / 门 / 街 / 水 / 桥 / 区对象计，坐标或形制推定项共 `12` 项。自动填充的每栋通用建筑不重复冒充独立史证；数量只用于判断疏密、通行和素材总装。
没有证据的瓮城、内城、具名坊巷、城壕、山门和西岳庙均不补画。关西镇、敷水镇、潼关与华山只留在区域叙事，不硬塞进县城。

## 6. 剧情对应、配额与验收

本城在 ch02 / ch03 的名称与开放状态引用 `design/map/cities.yaml`；主线唯一归属仍是对应故事稿。
本布局只提供城镇旅行候选，不新增 NPC、任务、营生 ID、门派驻地或正式场景引用。华山论剑、华山派或山道战斗必须使用独立山岳场景，不得复用本县城图冒充。
配额先保县署、旅舍、祠寺与守舍，再填铺面、摊棚和民居；所有上下限均为**【建议值】（原创扩展）**。

## 数据校验规则与测试用例

- 生成 → `check_town --strict-assets` → 平面图 → JPEG 预览；布局不得含 validation error。
- 检查建筑不压水、墙，全部必需入口可达，规划与六角行走层连通。
- 目检县城没有山峰、悬崖、华山栈道或被误标的西岳庙；渭水只在城外画缘。
- 反例：把华州州城郑县画成华阴县、把华山景区画成县城、把金代行政状态延续到1259而不标推定，均不得通过历史审核。
