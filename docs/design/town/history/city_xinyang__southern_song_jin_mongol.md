# 信阳军 · 1217 / 1259 年历史布局复原依据

> 归属：`design/22` 城镇规格的逐城历史依据；只解释本任务坐标。
> 标注：（史实）为来源直接支持；（推定）为跨时段关系或坐标；**（原创扩展）**为玩法抽象。

## 1. 对象、年代与治所边界

本年代带覆盖《射雕英雄传》锚点 1217 年与《神雕侠侣》末点 1259 年。项目名录两章均显示“信阳军”；外部材料能确认宋代信阳军领信阳、罗山二县，军治随倚郭信阳县落在今信阳老城一带，但不能据此宣称 1217、1259 的政权归属和城垣状态完全相同。

1217 年信阳处宋金边界前线。1141 年以后淮水为大体界线，1161 年金军曾攻信阳军；1219 年史籍又记金军“破信阳军之二寨”。这些材料说明它是反复争夺的军镇，不支持把本图写成稳定、完备的金朝腹地府城。本文题名沿项目名录，规格则写“宋金前线军镇候选”。

1259 年金已亡，不能继续标“金治”；项目仍用“信阳军”，故 ch03 只复用治所位置与山水骨架，并明确行政称谓和战损状态待考。

还须区分三处：

1. 信阳军治 / 信阳县倚郭：本图对象，落在今浉河区老城附近。（史实层级，精确城界待考）
2. 罗山县：信阳军属县，不能把元代一度迁州治罗山的后事倒灌到 1217。（史实边界）
3. 义阳故城：文物调查所指古城在浉水南侧山地，与宋代倚郭治所不能未经证据直接等同。（史实边界）

## 3. 复原取舍与时差

采用 `128×128` 格。外垣作八点不规则包络，南侧浉水、东侧青龙河只画在墙外画缘；这来自后世地形连续性的审慎推定，不声称河岸线七百年不变。

东西通衢用于表达军镇连接德安、光州方向的交通关系；两座方位门、十字街、军署、市肆、仓驿、坊居均无同期坐标，全部标（推定）或**（原创扩展）**。不沿用后世望京、镇远、坚山、望淮等门名，不画明代瓮城。

| 对象 | 数量 | 证据结论 |
|---|---:|---|
| 不规则外垣 | 1 | 治所和河间地貌有据；具体八折点（推定） |
| 城门 | 2 | 军镇需通路；数量、方位、门名（推定） |
| 街道 | 3 | 区域通行可解释；线位和宽度（推定） |
| 河流 | 2 条画缘 | 河间老城关系来自后世图；1217 岸线（推定） |
| 功能区 | 5 | 军署、市肆、坊居、寺观、仓驿均为玩法抽象 |

按墙、门、街、河、区逐对象计，共 `13` 个带坐标的推定对象；自动填充建筑不重复冒充史证。

## 4. 章节差量、素材与验收

ch02 用 1217：强调宋金前线、寨防与军需；不在无证据下写死金治或宋治某一日状态。ch03 用 1259：沿用治所和山水候选，但注明金亡后的称谓、重筑与战损待考；不得把 `liao_jin_north` 套件解释成 1259 政权标签。

套件只提供 11—13 世纪北方一般材质。信阳处南北过渡带，素材不能反向证明具体建筑。全图不新增 NPC、门派、任务或营生 ID。

验收：两章各自生成和 `--strict-assets`；平面图须呈不规则墙垣、墙外双河画缘和东西主街；预览不得有建筑压水、出墙或堵门。若未来取得同期城图，只校准有证据的对象，不保留本轮推定坐标。

## 开放问题

默认状态为 `partial_candidate`：军名、属县、治所大区和前线性质可核；1217 / 1259 城垣、门街和河岸不达考古复原级。

后续只有发现可定位的宋金城址发掘简报、同期军城图或明确迁治记载，才足以改动治所大区和外垣；明清方志图不能单独承担这一证据等级。

若取得河道地层或古岸线测绘，应先校准浉河、青龙河与城址的相对关系，再重算墙门和道路，不能只平移现有两条画缘。

若只新增门名、寺名或街名而无位置证据，可更新文字释义，不应据此把匿名功能区升级为历史坐标点。
