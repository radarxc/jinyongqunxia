# 京兆府 · 1217 / 1259 年历史布局复原依据

> 归属：`design/22` 城镇规格的逐城历史依据；只解释本任务坐标。
> 标注：（史实）为来源直接支持；（推定）为跨时段关系或坐标；**（原创扩展）**为玩法抽象。

## 1. 对象与关键纠偏

本图对象是 1217 年金代京兆府城，以及 1259 年蒙古统治下仍沿用京兆府名的项目时代层候选；不是 702 年唐长安外郭城，也不是明代向东、向北扩筑后的西安府城。

唐天祐元年（904），韩建放弃唐长安宫城和外郭城，以唐皇城为基础缩筑新城：封朱雀、延喜、安福三门，保留南侧含光、安上二门，东西顺义、景风二门，北开玄武门；取消坊墙和专设东西市，开放设市，并在城外另筑长安、咸宁两县小城。后来的宋、金京兆府沿用这座约 5.2 平方公里的新城。

因此本规格只保留紧凑长方府城、五门与错位南北街；明确删除唐长安外郭十二门、朱雀大街全轴、东西市、太极宫和大明宫。也不采用明代四门正交、钟楼居中的套图。

## 3. 网格、比例与复原规则

规格用 `160×160` 格。历史新城东西约 2820 米、南北约 1844 米，比例约 `1.53:1`；游戏墙体取东西 132 格、南北 88 格，比例 `1.50:1`，只保形状比例，不以 1 格等于历史米。

五门按继承关系表达：南墙西侧含光门、东侧安上门；西顺义门与东景风门相对；北玄武门偏中。三条门街加两条横向联络路构成开放街巷，不画封闭里坊。护城河因 schema 和桥门负担不画，不能解释为历史无濠。

府署置北中部、市场沿东西通衢和南门街、住宅分东西、寺观与府学意象置东南。所有院落边界、具体市街与迎祥观位置均为（推定）；不把 1344 图的钟楼当 1217 地标。

| 对象 | 数量 | 证据结论 |
|---|---:|---|
| 长方外垣 | 1 | 皇城基址与长宽有据；游戏坐标为缩比 |
| 城门 | 5 | 韩建门制及宋金沿用有据；格坐标为缩比 |
| 街道 | 5 | 东西门相对、南北门错位有据；折点与宽度（推定） |
| 功能区 | 7 | 府署、两县、市场、坊居、寺学、仓驿为压缩抽象 |
| 固定地标 | 0 | 无同期可定位单体，不以唐宫或明钟楼凑地标 |

坐标推定对象共 `13` 项（外垣 1、街道 5、功能区 7）；五门的相对边位有来源约束，但精确格点仍属缩比推定。

## 4. 剧情、章节差量与素材

ch02（1217）为金代京兆府，连接终南山补给；规格只在城内安排 `biz_xian_escort_01` 的匿名护运院，不把全真重阳宫或终南山搬入府城。

ch03（1259）已非金朝；沿用同城骨架仅因没有获得 1217—1259 重筑证据。保留项目名“京兆府”，加入 `biz_xian_casino_01` 地下赌坊外观；不得由 `liao_jin_north` 套件反推蒙古时期政权或官制。

套件表达辽金北方一般建筑材质，不等同金代京兆某栋实物。配额优先府署、食宿、护运 / 赌坊、仓驿，再填沿街铺面和院落；不新增正式场景、NPC 或门派 ID。

## 5. 验收与反例

两章分别生成和 `--strict-assets`；平面图必须呈东西较长的五门小城，南侧双门、东西门对位、北门错位，且没有唐外郭十二门、东西市、太极宫、大明宫或明钟楼中心轴。

预览须检查建筑不出墙、门道可达、沿街市肆不堵通衢。若取得金代同期图，只校准有证据的墙门街区；元《奉元城图》继续保留明确时差，不升格为同期实测。

## 开放问题

默认状态为 `complete_candidate`：城址外框、五门关系和宋金沿用依据较强；城内 1217 / 1259 地块、街巷细线和战损仍是推定。

若发现宋金城门考古位置或同期修城记载，应优先校准五门是否逐门启用及墙体尺度；不能因元图只见单南门就追改 1217 门制。

若取得 1259 前后的街巷、府署或县城材料，应把 ch03 做成真实差量，而不是继续依赖同种子骨架。

护城河只有在桥位、门外道路和 schema 能共同闭合时才加入；仅有“有濠”文字不足以安全生成可通行水障。
