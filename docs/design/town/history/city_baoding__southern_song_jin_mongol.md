# 保州 · 1217 / 1259 年历史布局复原依据

> 归属：design/22 逐城布局依据；上游为 AR-36 / AR-47、城市名录与 design/19。
> 本稿为 study 模式候选，不把现代保定城区或明清“靴子城”当金代精确城图。
> （推定）指关系或坐标证据不足；（原创扩展）指游戏抽象；【建议值】指可替换参数。

## 1. 对象与年代边界

稳定城市键为 city_baoding；主章节 ch02 取 1217，副章节 ch03 取 1259。
《金史》称“保州，中，顺天军节度使”，并列倚郭清苑县；“顺天军”是军号，不能当作和保州并列的两座城。
ch02 显示“保州”，ch03 显示“保州（顺天府）”；地图名录的“顺天军 / 保州（待考）”保留给上游复核。
1217 处在金末战毁与张柔重建之间，不能直接绘成1227以后街坊齐整的都会。
史研所论文引1227营建时“为芜城者，十五年矣”“无寸甓尺楹之旧”，据此采用荒废期表达。
毁城具体纪年常见1213的说法，本轮未成功打开该纪年对应的地方报道，故不作为独立定年证据。
1259 已晚于1227营建，必须单列重建差量；本城不机械复制主章节规格。

## 2. 实际阅读来源（访问日期：2026-10-04）

- src_cass：[中国社会科学院历史研究所：元初汉人世侯张柔与金元之际北方的军事筑城](http://lishisuo.cass.cn/xsyj/gdzwgxs/202011/t20201109_5213109.shtml)。可信度 A-；已打开正文，仅文字。

- 文中引弘治《保定郡志》的1402重修前墙制，并明言保州城迭经修浚；只作后世回溯，不提取为1217墙线。

## 3. 复原方式与主副章节差量

ch02 使用无完整外垣的稀疏临时聚落：不画完整城门、衙署、寺殿，也不虚构确定的毁墙缺口。
walls: none 表示不复原使用中的完整墙环，不是断言历史上已没有任何墙基或故堞。
3条旧路、5个暂居功能区均是游戏开放城镇所需的低密度推定；临时住房与交换点不作存世建筑史证。
ch02 只用小屋、摊棚通用贴片，贴片仍显完整，不能表达真实废墟材质；此项为候选限制。
ch03 恢复一圈外垣游戏包络、四方向出入口、三条正交主次街及官署、市肆、民居、寺舍、仓驿功能。
官署北、居市南是结合《营建记》“北衙”“南宅”的方向抽象；其他功能的具体邻接与范围仍推定。
十坊、十桥与两个水门虽有文字证据，但缺确切线路，不按数量硬塞入128格城图。
本轮两个章节均不画水道和桥；重建态因此是部分复原，不能误读为否认《营建记》的水网与桥梁。
不补大慈阁、莲池等具名地标，也不将明清“靴子形”外垣或四门名称回填到金末。

## 4. 网格、缩比与推定对象

规划网格128×128，共16384格；cell_m=1为运行时契约，不代表历史城域只有128米。
历史实距不具备统一米/格缩比，采用非等比拓扑缩景；真实距离、坊数和单栋形制均不用于反推人口。
64×32母版理论地面8192×4096像素，0.25 JPEG预览为2048×1024像素。

| 对象 | ch02荒废期 | ch03重建期 | 证据与限制 |
|---|---:|---:|---|
| 完整外垣 | 0 | 1 | 毁后不画完整墙；重建墙为推定矩形游戏包络 |
| 城门 | 0 | 4 | 仅方向通口；门位、门名、数量都没有准确图证 |
| 街道 | 3 | 3 | 旧路假设 / 重建裁正街巷的概化，坐标皆推定 |
| 水 / 桥 | 0 / 0 | 0 / 0 | 不具备接入线位，重建水网留待专项复原 |
| 功能区 | 5 | 5 | 1217临时功能全属原创；1259少数方向有据 |

墙、门、街、水、桥、区按对象计，ch02推定8项，ch03推定13项；不把自动填房重复计为史料证据。
