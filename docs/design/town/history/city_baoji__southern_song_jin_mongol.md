## 1. 年代、对象与证据边界

本年代带覆盖《射雕英雄传》书界锚点 1217 年和《神雕侠侣》书界末点 1259 年。1217 年宝鸡县属金凤翔路凤翔府；1259 年已在蒙古统治期。本任务没有取得金亡后至 1259 年的重筑平面，因此两章共用一个县城拓扑候选，但不声称城墙、街道和院落在四十余年间未变。

年代化必须守住名称与城址边界：

1. 隋大业九年（613）陈仓县治迁入留谷城，即今宝鸡市区一带。（地方政府沿革）
2. 唐至德二年（757）陈仓县改名宝鸡县；CHGIS 将 757—1911 的宝鸡县治定位在 `34.38187N, 107.14038E`，宋金仍属凤翔府。（史实 / 汇编）
3. 先秦陈仓上、下城、陈仓故城和“暗度陈仓”的古邑记忆不能直接拼成 1217 县城；“陈仓”在本图只作为古邑沿革、陈仓山及通蜀交通锚点。（史实边界）
4. 《金史》在宝鸡县条列陈仓山、渭水、汧水、大散关，并记武城镇；这些是县境与通道要素，不是县城内部建筑清单。（史实边界）

因此显示名使用“宝鸡县”，不是“陈仓县”或“凤翔府”。项目地图旧历史摘要把 `city_baoji` 显示为“凤翔府”，与县治锚点存在口径张力；本任务不越权修改共享名录，只在城图中按 CHGIS / 正史县目审慎落为宝鸡县，并建议上游复核。

## 3. 年代判定与审慎沿用

### 3.1 1217（ch02）

- “宝鸡县”及其属凤翔府有《金史》县目直接支持。（史实）
- 陈仓山、渭水、汧水、大散关、武城镇是县境锚点；本图仅把渭水压到画缘，其余保留在区域旅行层。（史实边界）
- 城墙、双门和十字主街没有同期图，全部是县城玩法缩景（推定）（原创扩展）。

### 3.2 1259（ch03）

- 宝鸡县名和县治的长时段连续性有 CHGIS 汇编支持，但金代隶属不可机械延续到蒙古时期。（史实边界）
- 本轮没有取得 1259 当年政区细目、战损或重筑材料；规格不写“金凤翔府”，也不新增蒙古总管府、军营或屠城痕迹。（审慎推定）
- ch03 layout 由同种子和同拓扑生成，但 source spec 独立锁定 1259 说明；若后续取得蒙古时期材料，应只校准 ch03。

## 4. 缩比、网格与素材边界

规格使用 `128×128` 规划格，共 `16384` 格；`cell_m=1` 只供运行时，不能解释成历史实尺。
母版地面理论尺寸为 `(128+128)×32 = 8192` px 宽、`(128+128)×16 = 4096` px 高；0.25 JPEG 预览理论地面为 `2048×1024` px。
历史县城与游戏格不存在统一米／格：本图保留“渭河谷东西通衢—县署—市肆—坊居—南向关道叙事”的拓扑，牺牲真实距离、地块数量和局部角度。
年代套件为 `liao_jin_north`；缺少的道路、植物或其他语义片由渲染器回退 baseline，并在 manifest 登记。贴片不能反向证明宝鸡某座具体建筑的形制。

## 5. 复原依据与逐要素坐标

| 要素 | 数量 / 布局 | 证据等级 |
|---|---:|---|
| 城垣 | 1 道矩形包络 | 县治点位与迁治沿革（史实）；墙线、尺度与矩形形制（推定） |
| 城门 | 东西 2 门 | 渭河谷交通关系可解释；门址、门名、门数（推定）（原创扩展） |
| 街道 | 3 条 | 东西交通和南向关道的区域关系；具体线位与格宽（推定） |
| 水系 | 画缘渭水 1 条 | 县境有渭水（史实）；古岸、宽度与城河距离（推定） |
| 桥梁 | 0 座 | 河在城外画缘，不为凑构图虚构县城桥 |
| 功能分区 | 5 区 | 县署层级可知；市肆、坊居、祠寺、仓驿位置与范围（原创扩展） |

按墙 / 门 / 街 / 水 / 桥 / 区对象计，坐标或形制推定项共 `12` 项。自动填充的每栋通用建筑不重复冒充独立史证；数量只用于判断疏密、通行和素材总装。
没有证据的瓮城、内城、具名坊巷、城壕、陈仓山祠、武城镇街巷与大散关堡寨均不补画。

## 6. 剧情对应、配额与验收

本城在 ch02 / ch03 的开放状态引用 `design/map/cities.yaml`；显示名“宝鸡县”按本次史料校正候选登记，共享名录仍由上游归属任务裁定。
本布局只提供城镇旅行候选，不新增 NPC、任务、营生 ID、门派驻地或正式场景引用。大散关、陈仓道、陈仓故城若用于剧情，必须是独立区域节点，不能复用本县城图冒充。
配额先保县署、旅舍、祠寺与守舍，再填铺面、摊棚和民居；所有上下限均为**【建议值】（原创扩展）**。

## 数据校验规则与测试用例

- 生成 → `check_town --strict-assets` → 平面图 → JPEG 预览；布局不得含 validation error。
- 检查建筑不压水、墙，全部必需入口可达，规划与六角行走层连通。
- 目检渭水只在城外画缘；画面不出现被误当县城的先秦双城、陈仓山、大散关或武城镇。
- 反例：1217 / 1259 写“陈仓县”、把凤翔府州城当宝鸡县城、把先秦陈仓上下城画成金代双城，均不得通过历史审核。
