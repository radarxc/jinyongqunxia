# 归德府（睢阳县）· 1217 年历史布局复原依据

> 归属：`design/22` 城镇规格逐城历史依据；本页只解释 `city_shangqiu` 在南宋—金—蒙古年代带的坐标选择。
> 标注：（推定）= 证据不足的关系或坐标；**（原创扩展）** = 玩法设计；**（待考）** = 仍需原始报告终校。

## 1. 年代、政区与对象纠偏

本单元主锚点为 1217 年。金代“南京”是开封府，不是商丘。
商丘于金天会八年（1130）由北宋南京应天府降为归德府；承安五年（1200）将倚郭宋城县改名睢阳县。
因此 1217 年规格采用“归德府（睢阳县）”，不沿用上个书界的“应天府南京”，也不写“宋州”。
`ch03` 的 1259 年处于蒙古统治阶段，本批沿用归德府—睢阳县治所拓扑；具体蒙古占领后官署变更**（待考）**。

CHGIS 引《清嘉庆一统志》与史念海研究，说明金元旧城在今商丘古城稍南约 2 km、老南关村北侧；
1502 年旧城圮于水，1511 年今城始筑。故本图锚定“后世今城之南的旧城”，不复刻现存明清归德府城。

## 2. 实际打开并阅读的来源（2026-10-04）

1. `src_jinshi`：《金史》卷二十五《地理志中》通行本网页。
   - 已读正文；归德府为南京路散府、宣武军，领睢阳等六县。
   - 睢阳条列鹰鹭池、汴水、睢水、涣水；不提供城门或街坊平面。
2. `src_chgis`：复旦 CHGIS“宋城县 / 睢阳县”。
   - 已读 JSON 正文与所引《金史》《嘉庆一统志》、史念海说明。
   - 约束 1200 年改名、归德府治及旧城在今城南；点位不能当城墙测绘控制点。
3. `src_morphology`：法念真等《基于城市形态发生学的商丘归德府古城空间特征分析》。
   - 已读全文并看图 1、图 2；文章明确现存内城始筑于 1511 年，图为明清形态。
   - 图 1“外郭城与内城图”、图 2“内城空间结构复原图”均为后世图，只用于反证不可倒投金代。

## 3. 已看图及局限

- 图 1 画出近圆外郭与方形内城；作者说明外郭城墙由明崇祯年间护城堤改筑。
- 图 2 展示四门、棋盘街与府县衙署；作者说明依据康熙、乾隆图志，且两幅旧图均非实测。
- 两图对应 1511 年后新城，不是 1217 年旧城；本规格不采用外圆内方、四门名、88 街或府学位置。
- 未获得金代归德府平面图、同期门名或考古控制点，故墙形、门位、街线和分区均明确降级。

## 4. 复原选择与缩比

规格使用 `128×128` 规划格，共 `16384` 格；规划格服务玩法，不能解释成历史 1:1 米制。
母版地面理论尺寸 `8192×4096 px`，主章节只渲染 0.25 JPEG 预览，不生成 fullsize。
年代套件为 `liao_jin_north`；基础地面、道路与植物缺项由 baseline 声明式回退。

| 要素 | 本版表达 | 证据与限制 |
|---|---|---|
| 城址 | 今城南约 2 km 的旧城语义 | CHGIS / 后世方志；游戏坐标不做地理配准 |
| 城垣 | 近矩形夯土单城 | 旧城具体轮廓无图，（推定） |
| 城门 | 南、北两门 | 门数、门名、位置均（推定）（原创扩展） |
| 主街 | 南北轴 + 东西横街 + 市巷 | 仅满足府治通行与玩法，（原创扩展） |
| 水系 | 南侧睢水画缘 | 《金史》仅证县境有水；岸线与城距（推定） |
| 分区 | 府署、市肆、坊居、寺观、军驿 | 功能与落位均为玩法抽象 |

坐标推定对象计 `13`：1 墙、2 门、3 街、1 河、5 区、1 整体缩比。
自动填充建筑不重复计作独立史证；配额只用于疏密、通行和素材总装。

## 5. 章节差量与剧情边界

`ch02`（1217）显示“归德府（睢阳县）”，表达金南京路府治。
`ch03`（1259）显示“归德府（睢阳县）”，只把说明改为蒙古统治期沿用候选，不虚构重筑。
本布局不新增 NPC、任务、营生 ID、机构归属或正式场景引用；金庸原著未提供可量测城图。

## 6. 验收与开放问题

- 两章各跑 `gen_layout.py` 与 `check_town.py --strict-assets`；布局不得含 validation error。
- `plan_view.py` 只从 1217 规格生成一份 SVG / PNG；标题和说明不得冒充史图。
- 目检城垣、两门、三街、南侧画缘水体一致，建筑不压水、不越墙。
- 后续若取得旧城金元考古平面，只校准受证据约束的墙、门与水系并重跑；不以明清图补空白。
