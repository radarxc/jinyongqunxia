## 3. 看图所得与分期取舍

旧庭州城为后世北庭城中偏东的核心；子城南北轴线与城市东西横街在图上可辨。
向西扩城后，东西通路继续西延；不能由“均为唐代城墙”推定全部墙段已在702年完成。
PDF结语称西扩与安置瀚海军有关，2026访谈概括为庭州升北庭后的扩建；本次不据概述强定建成年。
后期官署、佛寺、羊马城与回鹘修筑部分须逐一排除或标待考，不能整幅复制进武周场景。

| 要素 | 默认取舍 | 证据 / 不确定项 |
|---|---|---|
| 旧庭州外廓 | 优先采用偏东旧城层 | 分期关系有据；702精确轮廓待考 |
| 西延城 | 先不定为702已完成 | 需建筑层位与纪年证据 |
| 子城 | 保留旧城核心、南北轴 | 具体殿址和年代待考 |
| 横街 | 东西向并接子城 | 街宽、铺面推定 |
| 门位 | 参考已发掘内城北门、西门 | 不能直接将后期封门状态套入702 |
| 城东水系 | 保留城东相对方位 | 古河道折点与流量未知 |
| 佛寺 | 不直接套用回鹘高台寺 | 702佛寺位置需专项证据 |
| 防御附属 | 羊马城、外壕分层处理 | 当前单墙工具不足以总装 |

## 4. 网格与缩比建议

默认中等城景 `128×128` 格**【建议值】**，仅锁画幅，不给未经定年的古城尺数。
图十三没有可供本轮配准的702年实尺控制点，历史米/格未知；最终城圈周长不能直接倒算旧庭州。
