## 3. 续作顺序与验收

第6次按协调者10-03 04:40裁定冻结全量续作，不执行下列旧队列；缩减范围待作者定，续作另登记。两城阻碍见[r6-repair-boundaries.md](r6-repair-boundaries.md)。
旧计划保留追溯：优先太原三城、伊丽水营地，再其余ch10；庭州需地图任务先补键。
旧计划随后ch01至ch14，按importance的capital、major、secondary、site顺序，同档按名录顺序；ch10不重复执行。
同年代带只做一份历史依据，其他章节只改chapter_id和book_world；确有迁城、破城等章节差异再作最小变更并说明。
本轮仅生成独立的唐代带，没有执行跨章复制；不能把进度表中的primary_chapter当复制通过记录。
本轮未连续做完capital与major队列；有网络失败及分期问题的条目仍排在CSV原位，检索交接见[research-r4.md](research-r4.md)。
每项先核done和完整文件，再执行gen_layout、strict-assets、plan_view、render_town，最后目检并登记manifest。
渲染报告必须missing_assets为空且diagnostic=false；严格检查通过仍不能豁免水门、城形等人工检查。
本轮全部图属ch10，因此均保留全尺寸；后续其他章节只有importance最高一城允许全尺寸，其余直接scale 0.5。
同最高importance并列时默认取名录顺序第一座【建议值】，不把并列全都渲染成全尺寸。
全尺寸之外的manifest必须记“全尺寸未渲染；运行时按 layout + 贴片渲染”；full和preview不登记成两条资产。
