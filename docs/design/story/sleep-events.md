## 0. 结论先行

每本正式书都登记一个只依赖“取得本书天书”的保底休眠事件，并可按路线与人物结局开放一个候选；单书可见候选始终为 1–2 个，不超过 `design/25` §7.1 的 3 个上限。鹿鼎及以后只有在 `changshengLayer < 9` 时显示休眠事件；第九层已成则直接进入周游，见 `design/25` §9。

事件只决定“怎样入眠、从哪里接下一书最前期”，不另发天书、不重算结局、不替代 `BS_COMMIT`。天龙“一命换一命”是唯一会在终局窗口内先改写人物去向、再直接入眠的特殊候选。

## 2. 通用事件契约

### 2.1 数据字段

工程侧每条事件使用以下策划字段；字段 schema 与状态机归 `design/12` / 技术数据文档，本表只交内容接口：

| 字段 | 类型 | 内容约束 |
|---|---|---|
| `id` | `slp_*` | 稳定书界编号，不取现行书序 |
| `chapterId` / `nextChapterId` | ID | 当前书与下一书；雪山下一容器为 `ch15_guimeng` |
| `priority` | 整数 | 特殊改命 30、路线候选 20、保底 10 **【建议值】** |
| `requires` | `ConditionExpr` | 只用 `all/any/not/flag/quest/npc/compare`；不得执行自由文本 |
| `entryKnot` | 字符串 | `sleep.<NN>.<slug>.entry`；Ink knot，不是内容 ID |
| `sleepScene` / `wakeRef` | 引用或局部键 | 地点不确定时用 `placeKey`，不伪造全局 ID |
| `cinematicBeats` | 数组 | 3–5 个镜头，含书灵旁白键与资源失败静帧 |
| `outcomes` | 白名单效果 | 只提交事件选择、既有 NPC / 结局事实与 `BS_COMMIT` 请求 |
| `fallbackId` | `slp_*` | 候选失效时回同书保底；保底为 `null` |

### 2.2 触发与求值

```text
sleepEligible = hasCurrentTianshu
             && phase == afterglow
             && not sleepCommitted
             && (changshengLayer < 9 || currentChapter < ch08_luding)
```

“`currentChapter < ch08_luding`”只表达现行书序语义，生产须按书序表比较，不能按稳定编号大小比较。事件求值顺序为：先验九层周游守卫，再验特殊改命、路线候选、保底；可见事件由玩家选定，`BS_COMMIT` 前可撤销。保底 `requires` 只能含当前天书、余韵态、未提交三项，禁止读取可错过支线。

### 2.3 Ink 与演出规则

- Ink 入口统一为 `sleep.<稳定书号>.<拼音 slug>.entry`；选择确认后转 `sleep.common.review`，最终由上游书眠状态机接管。
- 每场先给人物 / 地点余韵，再让《长生诀》运行；书灵只旁白、记录、预览后果，不施法催眠。
- 书灵旁白不仿写原著名句；候选涉及原著场面而动作未核准时只写大意并标 **（待考）**。
- 过场视频仍用 `vid_sleep_*` 逻辑资源；休眠事件本身不是第二段强制长视频，可用实时镜头或静帧。

## 3. 白马与天龙

### 3.1 白马啸西风

#### `slp_10_kongkantingfeng` · 空龛听风（保底）**（原创扩展）**

- **触发条件**：白马天书已取得、处于余韵、尚未提交书眠；不要求残图、同伴或长生诀支线。
- **情节 / 入眠**：主角确认高昌迷宫出口可用，把残图的历史结论记入史匣；实物若依法仍由玩家持有，不强制伪写“封回”。主角在通风空龛旁听风入定，《长生诀》渐行后沉睡。
- **主线 / 改命 / 同伴**：回看李文秀离开西域的自主选择；任何结局都不把她召回陪睡，也不更改两名故人的生死。
- **Ink / 演出**：`sleep.10.kongkantingfeng.entry`；石壁字迹退暗、风卷细沙、白马蹄印向东。书灵旁白键表达“放下不是忘掉”。
- **苏醒衔接**：按 Canon v1.9 §2 以约 641 年离界核算，沉睡约 `1093−641=452` 年，在天龙最前期按 `story/01` / `chapters/01` 的入口醒来；长途与时代切换由转场表现。

#### `slp_10_baimayuansong` · 白马远送（候选）**（原创扩展）**

- **触发条件**：完成李文秀告别，且本人已按结局离场；不要求她成为同伴。
- **情节 / 入眠**：主角在玉门方向界碑送白马远去，结清短约后于背风石坳渐眠。
- **关系 / 演出**：只读取告别态；不定义婚恋、归期或寿命。`sleep.10.baimayuansong.entry`；远景只留人马剪影。书灵旁白要点：“送到路口，便把远方还给她自己。”**（原创扩展）**
- **苏醒**：与保底相同；候选失效回 `slp_10_kongkantingfeng`。

### 3.2 天龙八部

#### `slp_01_yanmenxiexin` · 雁门歇心（保底）**（原创扩展）**

- **触发条件**：天龙任一正式结局、任一天书变体已取得；不要求阿朱或萧峰存活。
- **情节 / 入眠**：主角在雁门关外石台逐项交还军令、封缄与临时身份，确认退兵事实已由众人共同见证；风雪渐紧时运转《长生诀》歇心入眠。
- **关系**：原著线保留萧峰自尽结局；改命但未选舍命事件时，萧峰存活并按既有结局承担余波。阿朱结局只进入回望，不被本事件复活或改派去向。
- **Ink / 演出**：`sleep.01.yanmenxiexin.entry`；折箭、空石台、雪埋脚印。书灵旁白键问“众生之重，是否只能由一人担”。
- **苏醒**：沉睡 `1217−1094=123` 年，于临安府外通往牛家村的 `sc_02_linan_yilu` 醒来；播放 / 兜底 `vid_sleep_01_02`。

#### `slp_01_yiminghuanyiming` · 一命换一命（特殊候选）**（原创扩展·改命）**

- **前提**：玩家已在青石桥前通过 `dc_01_05.A` 救下阿朱，阿朱 `lifeState=fate_rescued`；A5 四项硬条件齐备；辽帝折箭退兵后、萧峰将自尽前；玩家明确确认“舍命后立即离界”。未满足时不显示，回保底。
- **完整情节**：萧峰仍认为只有以死才能使退兵承诺不因人心反复而破。主角先完成跨方约束，再在其作出生死动作的瞬间扑救，将致命后果转到自己身上并坠下关外绝壁。坠落时主角说原创偈语：“一念不以死相证，万念方许众生还。”**（原创扩展）**；它不是佛经原句，不署伪出处。
- **阿朱与萧峰**：阿朱依此前约定赶到，亲自阻止萧峰继续自尽。萧峰闻偈、见阿朱，也看见多方仍在共同承担承诺，遂顿悟“活着守约”并非偷生；二人完成必要善后后远走塞外。此为本作改命，不改变射雕历史起点。
- **入眠地点与方式**：主角坠落后被峡口大风卷入绝壁侧洞；洞口前置枯木、积雪和回旋风道，避免凭空转移。撞击重伤触发《长生诀》护住生机，主角在洞中入眠；生还有代价，不恢复为无伤。
- **Ink / 演出**：`sleep.01.yiminghuanyiming.entry`；确认页明确“将结束天龙余韵”。镜头为扑救、坠落原创偈语、阿朱抓住萧峰衣袖、萧峰望向洞口风雪、侧洞暗下。书灵只在黑场后记录“这一命没有换走另一命，而是换回两个人继续活”**（原创扩展）**。
- **主线结算**：仍写既有 `flags.yanmen_fate_saved=true`、萧峰 `lifeState=fate_rescued`、`tsp_01_fate`；额外休眠事件选择不产生第三天书变体。阿紫按独立生命轴结算，不因阿朱出现而自动获救。
- **苏醒**：洞中沉睡 123 年后，转入射雕既定开场；旧伤只作苏醒镜头，不新增永久数值惩罚。
