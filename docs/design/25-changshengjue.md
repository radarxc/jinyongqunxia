## 0. 结论先行

《长生诀》`sk_changshengjue` 是主线专属九层功法**（原创扩展）**：阿青在越女序章传第一层，七本正式书的复杂支线依次授第二至八层，鹿鼎以满悟性、第八层与和氏璧领悟第九层。它不可遗忘、不可散功、不占 3 武功 + 3 内功，也不作为普通武学进入套装、图鉴数量或天级池。

第九层以前，取得天书后须由契合本书结局的休眠事件入眠，并在苏醒前取舍武学；第九层以后主角不老不眠，跨书改为周游世界，全部武学保留。层数成长只缓和取舍，绝不在九层前提前取消取舍。

## 2. 九层逐层效果

设基础转化率 `R1=60%`，层数为 `n`。第二至八层的转化率为：

`R(n) = 60% + 2% × (n − 1)`，`n=1..7`；第八层固定 `R(8)=72%`。

压制缓和只在第六层解锁并固定为 1 小品，且受 Canon §3 天书抵消共同下限约束；它不能与其他常驻抵消把有效压制降到 `ceil(S/2)` 以下。额外沉睡配点只增加当次可分预算，不提高单项上限，具体点值由 `design/03` 消费。

| 层 | 取得 | 转化率 | 额外效果 | 上限 / 不变式 |
|---:|---|---:|---|---|
| 1 | 越女序章·阿青 | 60% | 休眠；沉睡期间不老 | 仍须 3+3 取舍 |
| 2 | 白马支线 | 62% | 苏醒取舍显示各项转化预览 | 只增信息，不增资源 |
| 3 | 天龙支线 | 64% | 当次沉睡配点预算 +1【建议值】 | 单项与总上限归 03 |
| 4 | 射雕支线 | 66% | 残篇预览显示合法再遇途径 | 不直接忆起 |
| 5 | 神雕支线 | 68% | 当次沉睡配点预算累计 +2【建议值】 | 不再叠加更多点 |
| 6 | 倚天支线 | 70% | 外来武学压制减 1 小品【建议值】 | 共用 `ceil(S/2)` 下限 |
| 7 | 笑傲支线 | 72% | 真元投放时可跨内功性质，无额外损耗 | 不提高已转化总量 |
| 8 | 侠客支线 | 72% | 第九层领悟资格；苏醒前可保存一套 3+3 方案模板 | 不增名额、不取消遗忘 |
| 9 | 鹿鼎领悟 | 不再转化 | 长生 + 螺旋内力；取消书眠、遗忘、散功与 3+3 | 外来压制照旧 |

核算：二至八层的最高率为 `60%+2%×6=72%`，只比基础高 12 个百分点；即使第八层遗忘 10,000 经验，也只得 7,200，仍损失 2,800。第六层的压制缓和在中 / 低武最多把 `S=2/4` 降至 `1/3`，没有超过九层“全武学保留”的质变。

## 3. 螺旋内力

### 3.1 定义与资源

螺旋内力是第九层解锁的战斗运劲方式**（原创扩展）**，不是第四种 `mpNature`。每次施展先声明投入螺旋内力 `spiralSpent`，从当前 `mp` 扣除；每 1 点最多化解目标本次用于攻击、护体或内功伤害的 20 点内力：

`cancelMp = min(opponentMpCommitted, 20 × spiralSpent)`。

若只需化解 `M` 点，最低投入为 `ceil(M/20)`。例：对方本次投入 377 点内力，投入 `ceil(377/20)=19` 点可化解全部，容量为 `19×20=380`，余 3 点不结转。

### 3.2 Z0–Z10 接口【建议值】

螺旋化解在 **Z0 合法性 / 资源锁定之后、护体真气与护体内劲之前**执行，记为 `Z0-CS`。它先削减“本次承诺内力”，再由既有管线用剩余量派生伤害与防护；不建立第二个伤害乘区。

| 对象 | `Z0-CS` 处理 | 后续 |
|---|---|---|
| 内劲攻击 / 外放内功伤害 | 从攻方本次承诺内力扣 `cancelMp`；按 `remainMp=max(0, committed-cancelMp)` 重算该招内力贡献 | 继续 Z1–Z10；招式外功硬功部分不被抹去 |
| 护体真气 | 从守方本次承诺给护体的内力扣除；按剩余内力生成 `shield` | 再进入既有护体真气结算 |
| 护体内劲 | 先扣用于本次承伤的内力预算；剩余预算按 `design/21` 的耗内换伤率结算 | 不改变适用率或击穿迟滞 |
| 纯外功、无内力投入 | `opponentMpCommitted=0`，不可化解 | 正常走 Z1–Z10 |
| 持续伤害 / 已生成场地 | 不追溯取消 | 只对本次新承诺资源生效 |

同一伤害事件只允许一次 `Z0-CS`；多段招共用该事件锁定的总投入，不能逐段重复享受 1:20。预览必须展示双方承诺内力、最低螺旋投入、剩余内力和预计伤害区间；提交后原子扣费，取消预览不消费资源或 RNG。

### 3.3 经脉伤害 100%【建议值】

默认解释：由螺旋内力本身新增的实际伤害 `spiralDamageDealt`，在既有气血伤害结算后，以

`meridianDamage += spiralDamageDealt × 100%`

全额计入经脉伤害；“100%”不是无视全部防御，也不是把整招最终伤害复制一次。经脉伤害的部位分配、封穴、胀损与上限仍归 `design/21`，基础伤害与取整归 `design/04`。此解释待作者确认，见 §13.5。

## 5. 和氏璧

### 5.1 史实与标注

和氏璧相传在秦统一后制为传国玺，后世流转，至五代末下落不明；器物、玺文、缺角与具体亡失过程存在史料与传说混杂，须专题核对**（待考）**。本文不虚构史书引文或断言唯一真相。

### 5.2 本作取得线

本作在倚天支线中发现“后周乱离时被调包、真玺藏入旧都地下库”的线索，并于元末开封故城支线取得和氏璧（建议 ID `it_heshibi`，待 `design/10` 登记）**（原创扩展）**。取得必须完成辨伪、拒绝将其交给任一争位势力、保护知情人三项；选择交权者只得伪玺，余韵期可通过追回真玺补救。

和氏璧收入天书匣的“主线信物格”，不占装备、背包或传承匣容量，不可交易、丢弃、藏史或用于政权判定。它随书眠保留至鹿鼎；九层领悟后标记 `consumedForInsight=true` 但实物仍留作图鉴，不再触发第二次领悟。该窄例外只适用于此信物，不能扩成一般任务物跨书保留。

## 7. 休眠事件框架

### 7.1 入口与候选

天书仍是“完成本书”的唯一标志；取得天书后进入余韵期，并解锁 1 个保底、最多 2 个路线候选休眠事件。事件取代抽象“书眠之门”，但不取代天书、余韵期或苏醒结算。

| 类型 | 典型触发 | 叙事要求 |
|---|---|---|
| 看破 | 完成价值观抉择、主动放下争夺 | 不等于消极自杀；须有安顿当世关系的行动 |
| 心累 | 长期奔走或重大失去后卸下责任 | 不把创伤当作按钮，至少一段余韵恢复 |
| 归隐 | 选择山林 / 边地生活，随岁月渐眠 | 明示时间经过，不从热闹场景瞬间昏倒 |
| 舍命 | 为他人承担致命后果，坠落或被环境带入安全洞穴 | 须预先埋设生还逻辑，不伪造无代价复活 |
| 天地异变 | 雪崩、风暴、山崩等令功法自发护主 | 每书最多一个，避免重复使用巧合 |

候选必须读取本书结局、关键同伴生死、地点可达性与未了任务；玩家选定后仍可在 `BS_COMMIT` 前撤销。没有候选满足时，保底事件必须能由主线完成事实单独触发，禁止因漏支线卡死进度。逐书事件由 `DES-sleep-events` 定稿。

### 7.2 与余韵、天书和书灵的关系

1. 取得天书：写入天书与天书之力，进入余韵；此时主角仍清醒。
2. 选择休眠事件：事件在世界内发生，结束时《长生诀》自发或主动运行。
3. 进入沉睡：冻结旧时代运行态，展示回望与取舍。
4. 苏醒前：完成 §8 的 3+3 与转化，提交后落入下一书界前期。

书灵保留引导、旁白、后果预览和记录职责，因为它能把复杂跨书规则说清；但它不再“写下第一行”、打开门或代主角入眠。这样既保留常驻伙伴功能，又让阿青传功与主角修炼成为因果中心。

### 7.3 天龙规格示例

**一命换一命（建议 ID `slp_01_yiminghuanyiming`，原创扩展·改命）**

| 项 | 规格 |
|---|---|
| 前提 | 玩家已救下阿朱；推进雁门关改命线；萧峰面临原著结局危机 |
| 抉择 | 主角选择舍命替萧峰承受致命后果；必须明确告知将触发离界 |
| 演出 | 主角坠落时说一句原创偈语，不引用或冒充原著；阿朱出现阻止萧峰自尽 |
| 人物结果 | 萧峰闻偈、见阿朱而顿悟，与阿朱远走塞外；这是本作改命，不改变下一书原著起点 |
| 入眠 | 主角坠落后被大风刮入洞中，《长生诀》护住性命并进入休眠 |
| 失败 / 放弃 | 回到其他天龙保底休眠事件；不得因未走改命线卡住书序 |

正式任务须解释洞穴落点、伤势与风势，不能只用“奇迹”跳过因果；偈语文本由剧情任务原创，不在本设计虚构。

## 8. 苏醒取舍流程

| 步 | 内容 | 可撤销 |
|---:|---|---|
| 0 | 自动存档；显示休眠事件结果与下一时代模糊预告 | 是 |
| 1 | 属性确认：所有既有属性保留；若本层提供沉睡配点，按 03 分配六项 | 是 |
| 2 | 选择 3 门武功；拳脚、兵器、轻功、暗器及武艺型杂学合计 | 是 |
| 3 | 选择 3 门内功；标记其中一门主运候选 | 是 |
| 4 | 从保留武功中指定 1 门本命；默认自动沿用上次本命 | 是 |
| 5 | 对其余武功逐门选择“遗忘转顿悟 / 仅留残篇”，对其余内功选“散功转真元 / 仅留痕迹” | 是 |
| 6 | 分配顿悟点数与真元，或选择暂存；显示 60% / 当前层率的逐项算式 | 是 |
| 7 | 选择最多 6 件装备，预览外来压制与时代资产清理 | 是 |
| 8 | 独立确认页：列出保留、遗忘、散功、转化、清空项与苏醒地点类型 | 是 |
| 9 | 长按 1.5 秒确认【建议值】；原子提交，之后只能按 `design/13` 回档规则读取前档 | 否 |

给 `design/14` 的【建议值】：桌面 / 横屏采用“武功、内功、转化袋”三栏；触屏每张卡提供保留、遗忘 / 散功两种互斥动作，资源总额固定在顶部；危险动作不用颜色作唯一提示，并为键盘 / 读屏提供“清单 → 独立确认页”路径。确认文案必须包含“已转化经验不可因日后忆起再次获得”，且将《长生诀》固定显示在栏外。

## 9. 周游世界

第九层领悟后的叙事触发是：主角结束鹿鼎余韵时第一次没有睡意，旧时代的风景连续过渡为后世，书灵确认残卷不再替其“翻页”。此后每两书之间进入周游段：主角清醒生活、旅行、见证城名与人物更替，并在下一书最前期到达指定地点。**（原创扩展）**

本文只定叙事触发：不眠、不老、全部武学记忆连续，书灵仍作同行记录者。周游的玩法时长、资产保留、可做活动、轮回与终局边界引用 `design/13` §4.11；外来压制和时代绑定状态清理引用 Canon §3、`design/02`。

## 10. 出处提示

本作《长生诀》与和氏璧的搭配、螺旋劲概念来自黄易《大唐双龙传》，不是金庸作品；本设计全部标为**（原创扩展）**，只借“长生功法、和氏璧、螺旋运劲”的概念关系，不照搬原文、招名、人物、门派或具体修炼情节。和氏璧虽有史实 / 传说背景，本作取得线仍是原创。
