## 1. 十四书界年代考据

### 1.1 方法与原则

1. **排序原则**（基准 §2）：按**故事主体发生的年代**排序；序幕 / 尾声的年代不改变排序。
2. **证据分级**：
   | 等级 | 含义 | 例 |
   |---|---|---|
   | A 明文 | 书中直接写出年号 / 年份 | 《雪山飞狐》开篇写明乾隆四十五年 |
   | B 史实人物 / 事件 | 书中出现可考的历史人物、战役、制度 | 鹿鼎记：擒鳌拜（1669）、尼布楚条约（1689） |
   | C 门派 / 人物传承 | 与已定年书的人物、门派存在先后关系 | 侠客行：武当派已是大派 ⇒ 晚于倚天 |
   | D 官制 / 地名 / 风物 | 只能粗定朝代 | 连城诀："知府"明清通用 |
   | E 作者说明 | 后记、访谈 | 笑傲后记：本书"没有历史背景"（大意） |
3. **游戏定年** `gameYear`：为书眠过场（"一梦 N 年"）与跨书彩蛋提供一个内部年份。A/B 级证据充分者直接取史实；证据只到 C–E 级的书界给出**（原创扩展）定年**，并在 UI 上一律加"约"字，书灵台词对不详年份使用"不知几度春秋"类模糊表述，避免把游戏定年说成原著事实。

### 1.2 序章《越女剑》（`ch00_yuenv`）的定位

| 项 | 定义 |
|---|---|
| 年代 | 春秋末·越国。线索（B 级）：越王勾践、范蠡、西施、吴王夫差；越灭吴在前 473 年。游戏定年：约前 482（原创扩展定年，越军伐吴之前的练剑期）。 |
| 在时间线中的位置 | 按年代原则天然位于天龙之前；**不属于十四天书**，不产出天书之力。 |
| 叙事功能 | 现代人第一次"入书"：书灵苏醒、立下"十四天书"之约；主题"剑之源"——阿青与白猿的剑是后世一切剑术的遥远源头（原创扩展解读）。 |
| 玩法功能 | 教学关：移动/就地开战/集气时间轴/地形高低差/一阶轻功（`qg1`）/装配栏/**书眠与残篇的完整预演**。 |

| 可跳过 | 跳过时直接发放 `sk_yuenvjian` 残篇（最高层数按 1 计），不给其余奖励；标题菜单"梦回越国"可随时重玩（无奖励）。 |
| 书眠预演 | 序章末尾执行一次"零槽位书眠"：携带界面出现但所有槽位为 0，书灵借此讲解"识海容量由下一书界境界决定"。 |

#### 1.4.5 结论

基准 §2 的顺序在四个维度的加权总分上均为最优或并列最优，且满足三条硬约束：
1. 境界档位全程只变化 3 次：H→M（笑傲）、M→L（鹿鼎）、L→M（书剑），无来回抖动。
2. 武运在"巅峰—衰败—谷底—复兴"四段内部单调（唯一例外是白马的有意下探，§1.4.4）。
3. 跨书人物链中最长的四条（九阴、丐帮、华山、闯王宝藏）均不被打断（§6.2）。

### 2.2 外来与本土的判定

每个武功实例 `SkillInstance` 与装备实例 `EquipInstance` 带一个 `nativeTo: ChapterId`，表示"它属于哪个书界"。

| 事件 | `nativeTo` 取值 |
|---|---|
| 在书界 X 习得武功 / 获得装备 | X |
| 书眠携带到下一书界 | **不变**（因此在新书界成为外来） |
| 在书界 X 由残篇"忆起"（§5.3） | X（忆起视同本书界习得） |
| 在书界 X 锻造的装备（哪怕用了外来材料） | X |
| 对外来装备做精炼 / 镶嵌 / 附魔（`design/10`） | **不变**（杜绝"精炼洗白"） |
| 印证（完整传承，见下） | 改为当前书界 |
| 器合（同 ID 的原生实例并入，见 §5.8） | 改为当前书界 |
| 藏史取回（§6.6） | 不变（仍为存入时的书界，故为外来） |

`isForeign(inst, ch) := inst.nativeTo !== ch.id`。高武书界 `S=0`，外来标记仍然存在，用于 NPC 回响（§6.3）与书眠 UI。

**印证 `attune`**：外来武学在一个"它也原生存在"的书界里重新取得本土身份。

| 类型 | 条件 | 效果 |
|---|---|---|
| 完整传承 `full` | ① 当前书界的再遇表（§5.7）含该武学且类型为 `full`；② 完成该书界配置的印证事件（与原著持有者切磋 / 受其指点 / 读到本书界秘籍原本，三选一，由 chapters/ 文档指定）；③ 满足本书界对该武学的进度门槛（§2.9） | `nativeTo := 当前书界`，压制消失；层数上限照旧 |
| 残承 `partial` | 再遇类型为 `partial`，带残承品阶 `lineageGrade` | 不改 `nativeTo`；写入 `attunedGrade = lineageGrade`、`attunedIn = 当前书界`；有效品阶见 §2.3 |

印证不消耗层数、不重置经验；离开该书界后照常成为外来。

### 2.3 品阶压制公式与边界

```
S(tier)    = { HIGH: 0, MID: 2, LOW: 4 }
effGrade(inst, ch):
  if inst.nativeTo == ch.id:                       return inst.absGrade
  base = max(1, inst.absGrade − S(ch.tier))
  if inst.attunedIn == ch.id:                      return max(base, min(inst.absGrade, inst.attunedGrade))
  return base
```

| 边界 | 规则 |
|---|---|
| 下限 | 黄下（1）。玄中（5）及以下带入低武全部变为黄下。 |
| 跨大阶 | 按整数减，不按"大阶"减：天下 10 −2 = 地中 8。 |
| 绝对品阶 | 永不改变；离开压制书界后按新书界重新计算。 |
| 显示 | UI 显示"天上 → 天下（天道压制 −2）"，原品阶划线、有效品阶用有效品阶主色（基准 §4 色表）。 |
| 不受压制 | 本书界原生武功与装备；天书之力（建议，待 `design/13` 确认）；先天属性、技艺、江湖属性；书灵。 |
| 终局 | "天书守卷人"一战（`design/13`）关闭压制：`effGrade = absGrade`，`layerCap = 10`，显示等级 = 真实等级（建议）。 |

### 2.4 层数截断与积蕴

| 项 | 规则 |
|---|---|
| 真实层数 `trueLayer` | 1–10，只增不减；随武功实例一起携带。 |
| 有效层数 `effLayer` | `min(trueLayer, layerCap(当前书界))`；所有层数相关计算（招式威力、被动数值、招式解锁）都用有效层数。 |
| 修炼上限 | 在书界内修炼只能把 `trueLayer` 提升到 `layerCap`。 |
| 积蕴 `latentExp` | 达到 `layerCap` 后继续获得的该武功修炼经验，按 **50%** 效率存入积蕴；积蕴上限 = 从 `layerCap` 升到第 10 重所需经验之和（层数经验表见 `design/05`）。 |
| 积蕴释放 | 进入层数上限更高的书界（或终局）时自动注入，逐层提升直至用尽或达到新上限；书眠压制预览（§4.3 第 6 步）会显示"积蕴可破至第 N 重"。 |
| 招式封印 | 招式 `unlockLayer > effLayer` 时封印：UI 灰显加锁，提示"天道所限：需第 N 重"。已装配的封印招式不可施放，但保留在招式栏位。 |
| 敌人 | 敌人与队友同样受 `layerCap` 约束；Boss 超限只放宽等级、不放宽层数。 |
| 对 `design/05` 的要求 | 核心武功的绝招 `unlockLayer` 建议 ≤ 7，保证带入低武仍可用；第 9、10 重专属招式仅作为"满重终式"。 |

层数系数 `L(n)`（本文示例使用的建议值，待 `design/05` 定稿）：`L(n) = 0.5 + 0.05 × n`，即 L(10)=1.00、L(9)=0.95、L(8)=0.90、L(7)=0.85、L(1)=0.55。

### 2.7 外来压制逐项计算示例

统一记号：`P = G(effGrade) × L(effLayer)` 为"主力威力指数"（只比较武功本身，不含属性、装备、Buff；L 用 §2.4 建议值）；"原书界 P"为在原生书界满层时的值。装备用 G 作为品阶强度的代理指标（装备真实数值见 `design/10`）。

### 2.11 敌人武学品阶分布

**模型**（确定性：品阶骰使用种子流 `rng.stream('grade', encounterId)`）：

```
μ_normal(L, W) = 1 + 7.3 × (0.1 + 0.009 × W) × (L / 70)^0.65     // L = 敌人显示等级
μ_elite        = μ_normal + 1.5
P(g) ∝ exp( −(g − μ)² / (2σ²) ),  g ∈ [1, gmax]，归一化
σ: 普通 1.0，精英 0.9
gmax: 见 §2.1（普通 9/8/7，精英 9/9/8，对应 高/中/低武）
具名 NPC：手工配置（参考中心 μ_normal + 3，可使用本书界原生天级；受 I3 约束）
```

- 取到品阶 g 后，从该敌人所属门派/势力的武学池中选 g 品武学；没有则取最近的更低品阶，再没有则取最近的更高品阶（不超过 gmax）。
- 敌人武学层数：普通 `clamp(round(2 + 5 × L / levelCap), 1, layerCap − 2)`；精英 +1；具名 ≤ `layerCap`。
- 武运使同等级的敌人品阶更高：同为 L=45，巅峰书界的普通敌人中心约玄上，衰微书界约黄上（表 A）。

### 2.12 随机掉落品阶分布

掉落 = 固定掉落（任务/Boss/宝箱配置，含全部天级）+ 随机掉落（本节）。随机掉落先掷**品阶骰**，再在书界掉落表中按品阶挑具体物品（秘籍残页、装备、材料、丹药；物品目录见 `design/05`、`design/10`）。

| 池 | ID | 来源 | μ | σ | gmax（高/中/低） | 天级 |

### 3.4 入场强度对照：玩家 vs 书界

**警告清单**（非阻断，须在第 5 步逐类勾选"已知晓"；阻断错误只有"超槽位"与"`noCarry`"两种）：

| `SHIYIN_UNUSED` | 史印未使用 | "史印未用，入眠后失效" |

**书灵推荐** `autoPick`（两遍式）：
1. 武学：对每个候选计算
   `score = P_target × roleW + setΔ + attuneBonus`，其中 `P_target = G(effGrade_target) × L(effLayer_target)`；
   `roleW`：内功 1.2（主运候选），拳脚 1.0，兵器 1.0（若与第 2 遍选出的主武器类别不符则 0.8）；
   `setΔ`：保留成套可得的套装评分（`design/07` 提供 `setScore`）；
   `attuneBonus`：目标书界再遇表为 `full` +0.3，`partial` +0.15。
   同分时绝对品阶高者优先（"携带看绝对品阶"）。每列取前 N。
2. 装备：`score = G(effGrade_target) × slotW + setΔ + matchW`；`slotW`：主武器 1.5、衣 1.2、其余 1.0；`matchW`：主武器类别与已选兵器武学一致 +0.5。取前 6。
3. 回到第 1 遍按选定主武器重算 `roleW`，至多迭代 2 次。
4. 每项推荐附一句理由："绝对品阶最高""下一书界可印证""维持套装 X"。

**撤销**：`BS_COMMIT` 之后不可在游戏内撤销；标题菜单"读档"中的"书眠前·<书界>"存档可回到第 0 步之前。

commitBookSleep(state, plan):
  if plan.id in state.bookSleepLog: return                      // 幂等
  assert validate(plan, tierRule(plan.targetTier))               // 槽位、6 件、noCarry
  for s in state.skills:
    if s.instanceId in plan.skills: keep s                        // nativeTo / trueLayer / latentExp 不变
    else: upsertFragment(state, s); grantInsight(state, s)        // §5.2、§5.5

  archiveChapter(state, plan.from)                                // 结局、天书之力、统计写入 chapterHistory
  clear(state.money, state.items, state.sectMemberships, state.companions, state.chapterQuests)
  state.chapter  = plan.to
  state.displayLevel = min(state.realLevel, chapter(plan.to).levelCap)
  state.bookSleepLog.push(plan.id)

## 5. 残篇机制

### 5.1 生成规则

| 情形 | 是否生成残篇 |
|---|---|
| 书眠时未被携带的核心武功（内功/拳脚/兵器） | 是 |
| 书眠时的全部非核心武功（轻功/暗器/杂学） | 是（基准 §3-1：非核心不可携带） |
| 序章结束 | 是（`sk_yuenvjian`） |
| 书界内主动散功 / 被废武功（若 `design/05` 设计此类机制） | 否（由 `design/05` 自行处理） |
| 已有残篇的武学再次被遗忘 | 更新原记录（不新建） |

### 5.2 残篇数据（保留什么、丢弃什么）

### 5.3 再次习得（忆起 `recall`）

| 项 | 规则 |
|---|---|
| 触发 | 在任一书界"接触"该武学的来源：① 该武学秘籍 / 残页；② 拜师或受原著持有者指点；③ 在战斗中观摩持有者施展 ≥ 3 次且武学常识 `lore` ≥ 40。满足任一即可"忆起"。 |
| 本土性 | 忆起视同本书界习得：`nativeTo := 当前书界`，**不受品阶压制**。 |
| 起始层数 | `startLayer = clamp(floor(maxLayer × 0.5), 1, layerCap − 2)` |
| 修炼加速 | 经验 ×2.0，直到有效层数达到 `min(maxLayer, layerCap)`；此后 ×1.0 |
| 门槛 | 属性 / 资质门槛 ×0.8；**进度门槛（§2.9 R3）不降低**，防止天级提前回归 |
| 招式 | `unlockLayer ≤ startLayer` 的招式立即可用；曾解锁的招式不再播放首次解锁演出 |
| 预算 | 忆起的天级计入本书界 `playerTianBudget` |

起始层数速查：

| 历史最高层 | 高武起始 | 中武起始 | 低武起始 |
|---|---|---|---|
| 10 | 5 | 5 | 5 |
| 9 | 4 | 4 | 4 |
| 8 | 4 | 4 | 4 |
| 6 | 3 | 3 | 3 |
| 4 | 2 | 2 | 2 |
| 1–3 | 1 | 1 | 1 |

耗时估算（建议值，按 `design/05` 层数经验表每层 ×1.3 的几何增长估算）：第 1–5 重约占第 1–10 重总经验的 19%；跳过这部分并以 ×2.0 修炼余下部分，忆起到原层数的耗时约为首次修炼的 **40%**。

### 5.5 武学感悟 `insight`（永久小加成）

残篇生成时（每个武学 ID 只结算一次，之后若以更高最高层数再次遗忘则**补差**）发放：

`insight = baseByGrade[absGrade] × clamp(maxLayer / 10, 0.3, 1.0)`，且要求 `maxLayer ≥ 3`（防止"学一重就丢"刷感悟）。

| 品阶 | 黄下 | 黄中 | 黄上 | 玄下 | 玄中 | 玄上 | 地下 | 地中 | 地上 | 天下 | 天中 | 天上 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| `baseByGrade`（资质点） | 0.2 | 0.3 | 0.4 | 0.6 | 0.8 | 1.0 | 1.3 | 1.6 | 2.0 | 2.5 | 3.0 | 4.0 |

发放去向：

| 武学类别 | 加到 | 换算 |
|---|---|---|
| 拳掌/指/腿/擒拿 | `apFist`/`apFinger`/`apLeg`/`apGrapple` | ×1 |
| 剑/刀/棍杖/枪/鞭索/奇门 | `apSword`/`apBlade`/`apStaff`/`apSpear`/`apWhip`/`apExotic` | ×1 |
| 内功 / 轻功 / 暗器 | `apInner` / `apLight` / `apHidden` | ×1 |
| 杂学·医/毒/阵法/音律/书画/棋 | `med`/`poi`/`formation`/`music`/`art`/`chess` | ×2（技艺刻度更细） |
| 杂学·蛊/易容/驭兽/音功/心神 | 武学常识 `lore` | ×2 |

**天级余韵**（绝对品阶 ≥ 10 的残篇额外发放，一次性）：

| 类别 | 余韵 | 乘区 | 单项上限 |
|---|---|---|---|
| 内功 | 内力上限 +1% | 属性（`design/03`） | +5% |
| 拳脚 | 拳脚类武学伤害 +1% | Z3 `dmgUp` | +5% |
| 兵器 | 兵器类武学伤害 +1% | Z3 `dmgUp` | +5% |
| 轻功 | 轻功值 `qinggong` +2 | 属性 | +10 |
| 暗器 / 杂学 | 效果命中 `effHit` +1% | 判定（`design/04`） | +5% |

**上限**：单项资质来自感悟 ≤ +15；全部资质合计 ≤ +60；单项技艺 ≤ +20；`lore` ≤ +20。超出部分在图鉴中显示为"感悟已满"。

示例：天上品九阴真经最高 10 重时遗忘 → `apInner +4.0`、内力上限 +1%；地上品某剑法最高 6 重 → `apSword +1.2`；黄上品罗汉拳最高 3 重 → `apFist +0.12`。

**器合 `attune`（装备）规则**：
1. 玩家持有外来实例 X，并在当前书界按该书界配置的途径取得 X 的原生实例 → 两件合为一件，`nativeTo := 当前书界`。
2. 精炼 / 镶嵌等强化字段逐项取较高者；多出的一件转为材料"器魄" `it_qipo`（用途由 `design/10` 定义）。
3. 原生实例若为锚点所需（`anchorLocked`），锚点完成前不可取得。
4. 不愿器合时，可按书界配置"归还"外来实例给原主，换取势力回报；归还后该实例消失。
