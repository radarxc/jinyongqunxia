## 2. 男女主色：证据与项目取色

### 2.1 如何解释“偏好”与“万能”

舆服志首先记录身份、礼仪与禁制，不能推出全国男女的单一偏好排名；墓衣、俑和彩绘只证明某类穿用或表现存在。下表分别登记“可据史料的色系”和“本批主色”。把主色扩为六档常服是 **（原创扩展）**，史料原色名也不等于可复原的现代标准色值；不用 RGB 数字冒充古染复原。

男装通用色按作者决定采用 **本白、玄**：本白是未染麻丝的暖白，玄为深黑中可带微赤的暗色。女装选 **素白一种万能色**：先秦素沙／素屦，以及《宋史》涉及女性白色毛段的禁令，证明部分时期确有女性用素或白料的语境，但不能证明八朝女装都以素白为常见主色，更不能证明“八朝女性都最爱白色”。通用于本项目配装与搭色的决定为 **（原创扩展）**，其逐朝女装实证仍 **（待考）**。素白不自动等同丧服；身份、纹饰、场合仍须逐件判定。

月白在明清服饰语汇中可指很浅的蓝色，不能与未染本白、纯素白无条件合并；同一器物仅换“白／雪白”同义词仍须去重。北宋《宋史·舆服五》记录过对白／褐毛段与淡褐匹帛的局部禁令；因此万能色不是“所有时期、身份都无禁制”的历史结论。女装素白款的八朝可用性由本作原创世界处理，不冒称史实。

## 6. 数值区间、核算与转换

### 6.1 总表 `values` 的读取合同

总表是设计数据，**不是**可直接加载的 `ItemDef`。每个数值带均为 `[下限,上限]`；本轮同档同部位不因染色改变性能，故系数带为定值区间。`preview` 给出推荐Ce区间两端的主属性点数，使下游能核算，不是额外随机属性或等级限制。数值一律取未强化、完整、满效装备；运行时重算仍见 `10` §4.1，受 `effGrade`、`gUse`、强化及损坏影响。

| 字段／部位 | 本表数值从何处推出 | 下游如何读取 |
|---|---|---|
| `defOutK`、`defInK` | 衣轻0.16／0.12、中0.20／0.10、重0.28／0.07，乘G；内甲0.10／0.08乘G | 此表已经乘满效G；转换到旧名录基底系数时**除回G**，运行时按实际 `gUse` 再乘；不能二次乘G |
| 头／腰／鞋 | `defOutK=0.05G`，`hpMaxK=0.01G` | 按 `DEF_LV`／`HP_LV` 生成已有 `flatLv` 主属性 |
| 披风 | `defOutK=0.025G`，`hpMaxK=0.005G` | 只占 `cape`，不把肩披两槽的总数值塞进一件 |
| 固有项 | 轻衣 `eva=2G`；重甲 `resCCPp=2G`、`tough=2G`、`Q_load=10`、`mov=-1` | `eva/tough` 为点，`resCCPp` 为百分比点；不乘强化R；内甲与头饰没有身体轻重固有项 |
| 鞋 | `qinggong=2.5×grade`；`agi=0` | 运行时用 `gUse`，轻功不乘强化；没有额外身法叙事所以0合法，不把轻功再加成身法 |
| `projection.def` | `roundHalfUp(100×kDef×G)`；衣 `kDef=kD+kI`、内甲0.18、小件0.05、披风0.025 | 只作 `10` §4.10 摘要；不另加一次防御，鞋 `agi` 与 `def` 同列 |
| `preview` | `Ce` 两端的上述系数乘精确曲线，最后统一 `roundHalfUp` | 仅核算，不写成固定点词条；不预先取整曲线或使用 Python 银行家舍入 |

### 6.2 可复算实例

沿 `03` §3 的精确曲线：令 `x=Ce−1`，`HP_LV=300+4.1x²+20x×max(0,1−x/34)`，`MP_LV=200+2.45x²+12x×max(0,1−x/34)`，`DEF_LV=0.15×MP_LV`。这里只列核算式，定义权仍归 `03`。`10` 的旧文字称Ld，而当前 `03` 已采用Ce；总表预览统一按Ce，运行接口同步需求登记于 §10.2。

| 核算件 | 算式／系数 | 推荐区间两端的结果 |
|---|---|---|
| 黄2轻衣 | 外防 `0.16×1.10=0.176`；内防0.132；投影 `round(100×0.28×1.10)=31` | Ce4–11：外防7–14、内防5–10；闪避2.2点 |
| 地上9轻衣 | 外防0.384、内防0.288；投影67 | Ce35–59：外防175–486、内防131–365；同档五色款不增加强度 |

例如玄上鞋Ce22：`MP_LV=200+2.45×21²+12×21×(1−21/34)=1376.802941…`，外防 `0.085×0.15×1376.802941…=17.554237…→18`；Ce38端的临时补项为0，`0.085×0.15×(200+2.45×37²)=45.3141375→45`。不同朝代同档同部位数值完全一致；织物与甲片差异由既有轻重系数区分，绝不以颜色追加攻击、防毒或原著免疫。
