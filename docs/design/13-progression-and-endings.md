## 2. 角色经验与等级

### 2.1 术语与存档字段

| 术语 | ID / 字段 | 定义 |
|---|---|---|
| 角色经验 | `exp` | 角色等级的进度（区别于武学经验 `sxp`，05 §3.2）；存档中为"当前级内已得经验" |

### 2.2 升级经验曲线 `need(L)`

```
need(L) = round10( 0.1·L³ + 3.2·L² + 26·L + 40 )            L = 1..69；round10 = 四舍五入到 10
        = round10( expVal(L) × k(L) )
expVal(L) = 10 + 5·L                                          // 普通敌人经验
k(L)      = 4 + 0.6·L + 0.02·L²                               // 同级普通敌人"击杀当量"/级
```

设计要点：

1. **可解释的分解**：`need = expVal × k`。`k(L)` 就是"同级普通敌人要打多少个才升一级"（不计任务）：Lv1 ≈ 5 个、Lv10 = 12 个、Lv35 ≈ 50 个、Lv50 = 84 个、Lv69 ≈ 141 个。前期升级快、后期慢，贴合"天龙快速入门、倚天磨出化境"的体感。
2. **锚定基准 §2 的分书界升级数**：天龙要升 34 级、射雕 15 级、神雕 12 级、倚天 8 级，而四部高武书界的内容量相近（05 §3.2：约 150–160 场战斗）。三次曲线让四部的**总经验需求**分别为 9.6 万 / 21.7 万 / 34.4 万 / 35.0 万，与"每场标准遭遇经验 `bexp(L)`"随等级线性增长相乘后，四部书界的战斗经验占比都落在 47%–57%（§2.5），节奏一致。
3. **整数友好**：`round10` 后全表为 10 的倍数；累计到 70 级共 **1,006,850** 经验。
4. 敌人经验 `expVal(L)` 与 05 的武学经验 `sxpVal(L) = 10 + 3.3·L` 同形（线性），两者比值约 0.66–0.68，便于在同一场战斗里一并结算（§3.2）。

### 2.4 经验来源与公式

经验只在**结算时点**发放（战斗结束、任务步骤完成、事件结束），战斗中不升级（03 §11.5 #9）。所有来源先乘 §2.6 的节奏系数（追赶 / 越限），再乘难度倍率 `dm_exp`（§5.1）。

#### 2.4.1 战斗经验

```
battleExp = Σ_敌 expVal(L_敌) × typeMul × diffMul(L_敌 − Ld) × expScale(ch)
typeMul   : 普通 1 / 精英 3 / 头目 5 / Boss 10 / 战阵 0.5 × 阵中人数上限（09）/ 召唤物 0.2（09）/ 剧情杂兵 0
diffMul   : L_敌 ≥ Ld + 1       → 1 + min(0.30, 0.03 × (L_敌 − Ld))    // 以弱胜强，至多 +30%
            Ld − 10 ≤ L_敌 ≤ Ld → 1.0
            Ld − 20 ≤ L_敌 < Ld − 10 → 0.3
            L_敌 < Ld − 20     → 0
expScale(ch) : 书界校准系数，默认 1.00（§2.5 给出校准方法，允许 0.85–1.20）
```

| 规则 | 说明 |
|---|---|
| 分配 | 主角独得整份（队友不计经验，等级规则见 §2.8）；与 05 §8.2 "每名我方单位各得一整份 `sxp` 池"互不干扰 |
| 等级差阈值 | 与 05 §8.2 的 `sxp` 等级差系数同阈值（−10 / −20），玩家只需记一套规则 |
| 逃跑 / 战败 | 0 经验；战败重试后胜利按正常结算 |
| 切磋（非敌对比武、喂招）/ 擂台 | ×0.5；切磋同一对手每游戏日 1 次有经验；擂台每场 ×0.5（09 §11.2） |
| 主角状态 | 战斗结束时主角仍倒地（队友取胜）→ 本场经验 ×0.5（09 §11.2 `stateMul`） |
| 溃逃离场的敌人 | 该敌 ×0.5（09 §11.2） |
| 速战（09 §10.7） | ×0.8 |

**与 09 §11.2 的对齐**：09 的 `exp_unit` 草案以本节为准——已吸收其战阵/召唤物系数、`stateMul`（主角部分）与 `modeMul`；**不采纳**其三项建议：① `expVal = 10 × sxpVal`（会把全部数字放大 7–10 倍，与 §2.3 的 `need(L)` 标定不符）；② Boss 系数 12（保持与 05 §8.2 `sxp` 的 Boss 系数 10 一致）；③ 更细的等级差梯度（与 05 的 −10 / −20 两档阈值统一，玩家只记一套；且 09 梯度会使低武书界战斗经验再降约 20%，超出 `expScale` 钳制）。队友不计经验（§2.8），故 `stateMul` 的"替补 0.3"不适用。

**例**：天龙中期，`Ld = 20`，击败 3 名 Lv20 普通 + 1 名 Lv22 精英：`3 × 110 + 1 × 120 × 3 × 1.06 = 330 + 381.6 ≈ 712`（约为 `need(20) = 2,640` 的 27%）。

### 2.6 节奏保障：幕保底、追赶、越限

| 机制 | ID | 规则 | 适用 |
|---|---|---|---|
| 幕保底 | `actFloor` | 主线第 a 幕（共 A 幕）完成时，若 `Lr < actFloor(ch, a)`，直接提升到该级（本级进度归 0），提示"修为追上了你的见识"；补足部分不受难度倍率、不产生余韵 | 高武四部 |
| 追赶 | `catchUp` | `Lr < L_in(ch)` 时所有经验 ×1.5，到达 `L_in` 当刻停止（同一次发放跨越阈值时按两段计算） | 射雕、神雕、倚天 |

| 修为圆满 | `perfection` | 取得第 14 本天书时 `Lr := 70`、`exp := 0`（§7.3） | 终局 |


### 2.7 修为余韵（经验溢出）

#### 2.7.1 产生与折算

```
yuyunUnit(ch)  = need(ch.levelCap − 1) × (本书界已得余韵 ≥ 16 ? 2 : 1)      // 第 17 点起单位翻倍（防刷软上限）
yuyun.progress += 溢出经验
while yuyun.progress ≥ yuyunUnit(ch): progress −= unit; points += 1; gainedThisChapter += 1
书眠：progress_new = progress_old × unit_new / unit_old      // 保留"已攒的比例"；gainedThisChapter 清零
```

UI：角色面板显示"Lv 60 · 宗师（真 70 · 余韵 12）"；溢出时飘字"修为余韵 +1"；余韵进度条为金色细条，位于经验条原位置。

### 2.9 数据结构与伪代码

```ts
// packages/core/src/progression/types.ts
export interface ExpState {
  realLevel: number;            // Lr 1..70
  exp: number;                  // 当前级内已得经验（0..need(Lr)−1）
}
export interface YuyunState {
  points: number;               // 未花费的余韵点
  progress: number;             // 未满一点的溢出经验
  gainedThisChapter: number;    // 本书界已得点数（软上限 16）
  log: { kind: 'infuse' | 'temper' | 'refine'; target: string; cost: number; chapter: ChapterId }[];
}
export type ExpSource = { kind: 'battle' | 'quest' | 'event' | 'floor'; ref: string };
export interface ExpGrantResult { levelsGained: number; yuyunGained: number; floorApplied: boolean }
```

```
grantExp(s, raw, src):                                   // raw 已含 expScale 与 wb/typeMul/diffMul
  if src.kind == 'floor': return applyFloor(s, src)       // 保底不走倍率
  ch  = chapter(s)
  amt = raw × dm_exp(s.difficulty)                       // §5.1
  while amt > 0:
    if s.Lr ≥ min(70, ch.levelCap): addYuyun(s, amt); return
    mul  = (ch.tier == 'HIGH' and s.Lr < L_in(ch)) ? 1.5 : 1.0
    room = (need(s.Lr) − s.exp) / mul                     // 以"原始经验"表示的本级剩余
    if amt < room: s.exp += amt × mul; amt = 0
    else: amt −= room; s.Lr += 1; s.exp = 0; emit('levelUp', s.Lr)   // 修为突破（03 §2.8）由监听者处理

addYuyun(s, e):
  s.yuyun.progress += e
  loop:
    unit = need(ch.levelCap − 1) × (s.yuyun.gainedThisChapter ≥ 16 ? 2 : 1)
    if s.yuyun.progress < unit: break
    s.yuyun.progress −= unit; s.yuyun.points += 1; s.yuyun.gainedThisChapter += 1
    emit('yuyun', s.yuyun.points)

onActComplete(s, ch, a):
  if ch.tier == 'HIGH':
    f = actFloor(ch, a)
    if s.Lr < f: s.Lr = f; s.exp = 0; emit('levelUp', f, { reason: 'actFloor' })
```

### 3.1 双轴模型

| 轴 | 进度量 | 管什么 | 来源 | 跨书界 | 天道压制 |
|---|---|---|---|---|---|
| **角色轴** | `exp` → `Lr` / `Ld` | "底子"：气血/内力/攻防曲线（03 §3.1）、修为突破点（03 §2.8）、修为门槛 `gateCap`（05 §3.3）、Z8 境界差（04）、装备与武学的等级需求 | 战斗、任务、事件（§2.4） | `Lr` 保留 | `Ld` 截断到书界上限 |
| **武学轴** | `sxp` → `trueLayer` / `effLayer`（05 §3） | "招式"：威力 `L(n) = 0.5 + 0.1n`、招式/绝招解锁、被动、内功贡献 `innerScale(n)` | 实战、闭关、指点、丹药、顿悟（05 §8）、余韵灌注（§2.7） | 携带者保留真实层数；未携带者化为残篇 | 层数上限 10/9/8 + 外来品阶压制 |

### 4.2 结构："本义 + 变体"

- **本义**（`core`）：体现关键词、原著线与改命线**共有**的小效果，确保"不管这本书你怎么走，它都给了你同一个主题"。本义不可温养。
- **变体**（`variant`）：原著线 / 改命线各自的主效果，可温养（§4.7，个别除外）。
- ID：基准 §12 的 `tsp_NN_canon` / `tsp_NN_fate` 各自包含本义；本义不单独编号。
- 改命锚点只给**建议**（原创扩展），以 chapters/NN §5 为准；基准 §16-3：改命只改变结局文本、天书之力变体与后续彩蛋，不改变下一书界历史起点。

### 4.5 天道压制的部分抵消（总规则与上限）

```
S(tier)        = { HIGH: 0, MID: 2, LOW: 4 }                        // 基准 §3
S_floor(tier)  = ⌈S / 2⌉ = { 0, 1, 2 }                               // 永久效果抵消后的最低压制
off_skill      = Σ 持有的"武学压制抵消"（目前唯一来源：tsp_05_canon = 1）
off_equip      = Σ 持有的"装备压制抵消"（目前唯一来源：tsp_08_canon = 1）
S_eff(inst)    = max( S_floor, S − off_kind(inst) )                  // kind = skill | equip
effGrade(inst) = 02 §2.3 公式中以 S_eff 代替 S（印证、残承、器合规则不变）
layerCap_eff(skill) = min( 10, trueLayer, layerCap(tier) + (skill 为本命 ? off_layer : 0) )   off_layer = 1（tsp_06_canon）
临时全解：天书现影 / 天书微光期间 S_eff、layerCap_eff 按其条目（§4.6、§3.4.4）计算，不受 S_floor 约束（有次数与时长上限）
```

| 无抵消（基准） | −2 | −2 | −4 | −4 | 9 / 8 |

| 《天书现影》期间（至多 3–4 次自身行动） | 0 | 0 | 0 | 0 | 10（全部武学） |

**"绝不让压制失效"的四道保险**：① 永久抵消下限 `⌈S/2⌉`；② 等级上限从不抵消（`Ld` 恒为 `min(Lr, 上限)`）；③ 层数抵消只作用于 1 门本命、至多 +1；④ 全解只以《天书现影》形式存在，每书界 1 次（挫败兜底 +1）。当前内容下低武武学最多只能抵消到 −3（下限 −2 预留给未来扩展，不在本版使用）。

### 7.5 书契：十四书界积累的结算

```
shuqi[k] = min( 100, T_k + B_k + W_k + Q_k + A_k )           k = 01..14
  T_k 天书之力：原著线 30 / 改命线 50
  B_k 羁绊：书界 k 中羁绊最高的队友 ≥ 60 → 10；≥ 90 → 20（刻度见 12）
  W_k 卷势武学：守卷人在书卷 k 使用的代表武学（§7.7 表）中，玩家曾习得（含残篇）每门 +5，至多 15
  Q_k 支线：书界 k 支线完成率 ≥ 50% → 5；≥ 80% → 10
  A_k 锚点：书界 k 全部锚点事件均"亲历"（未错过、未跳过过场）→ 5
```

| 书契作用 | 规则 | 落点 |
|---|---|---|
| 卷势削弱 | 守卷人施放书卷 k 的代表武学时 Z3 −(0.4 × `shuqi[k]`)%（`bf_juanshi_ruo`，按书卷分键；至多 −40%） | Z3（守卷人） |
| 卷气血 | × (1 − 0.25 × 本卷书契均值 / 100)（至多 −25%） | 气血 |
| ≥ 50 | 解锁书卷 k 的书契技（§7.8，终局中 1 次） | 规则 |
| ≥ 60 / ≥ 90 | 书卷 k 的卷机制被削弱 / 被破解（§7.7） | 规则 |

**典型书契**：

| 画像 | T | B | W | Q | A | 书契 | 效果 |
|---|---|---|---|---|---|---|---|
| 只走主线、原著线 | 30 | 0 | 5 | 0 | 5 | 40 | 卷势 −16%，无书契技 |
| 标准、原著线 | 30 | 10 | 10 | 5 | 5 | 60 | 卷势 −24%，书契技 ✓，机制削弱 ✓ |
| 标准、改命线 | 50 | 10 | 10 | 5 | 5 | 80 | 卷势 −32%，书契技 ✓，机制削弱 ✓ |
| 全勤、改命线 | 50 | 20 | 15 | 10 | 5 | 100 | 卷势 −40%，机制破解 ✓ |

**积累如何决定胜负**（设计意图）：同一个 Lv70、无压制的主角，书契均值 40 时终局约 36 轮、守卷人卷势全开、无书契技、书影多为墨侠——可胜但艰险；书契均值 80 时约 26 轮，13 个书契技在手——这正是"十四书界的积累作为胜负关键"。

### 9.3 书眠前自动存档与回档限制

"书眠回档" = 在 `BS_COMMIT`（02 §4.2）之后读取 `save_booksleep_chNN`，回到上一书界余韵期、书眠第 0 步之前（02 §4.4"撤销"）。

| 难度 / 规则 | 书眠回档 | 记录与影响 |
|---|---|---|
| 江湖 / 侠客 | 不限次数 | `rollback.count += 1`；本周目"落子无悔"失效 |
| 宗师 | 每书界 1 次（`rollback.perChapter[NN] ≤ 1`；超出返回 `ROLLBACK_LIMIT`） | 同上 |
| 天劫 / 一命规则 | 禁止：书眠前存档只能"回看"（只读浏览当时的角色、武学与装备，不可载入） | — |

**允许回档的理由**（为何不全面禁止）：
1. **确定性随机**：品阶骰、掉落、奇遇的种子流随存档保存，回档后再来一次结果不变——"刷携带"刷不出任何随机收益。
2. **预览即所得**：书眠预览（02 §4.3 第 5 步）已展示下一书界的境界、压制后的全部数值；回档能换来的新信息只剩"下一书界开局长什么样"。对自己玩的单机游戏，这是剧透自己，不是破坏平衡。
3. **容错**：书眠是全游戏最重的不可逆操作；长按确认虽已防误触，但一次误选不应毁掉十几小时的心血。
4. **分层**：追求"落子无悔"的玩家可选宗师、天劫或一命规则，并有成就与称号作认可。

**防止"反复刷"的规则**：

| # | 规则 |
|---|---|
| RB1 | 读档不重掷（§9.2）：进入新书界后的随机结果与首次一致，除非玩家改变行动顺序 |
| RB2 | 回档后原有的"之后"存档不删除（可切回），但本周目标记"曾回档" |
| RB3 | 账号级数据不随回档撤销，但也**不重复发放**：成就与轮回点每项只发一次 |
| RB4 | 回档次数写入存档头与结局统计（后日谈末尾"此次重读，回头 N 次"） |
| RB5 | 天意规则的"逆天"重抽次数不因回档返还 |
| RB6 | 回档不影响书界内普通存档：书界内读档（未跨书眠）不计入 `rollback` |
