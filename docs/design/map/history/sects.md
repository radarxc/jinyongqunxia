## 3. 方法

1. 按作者 10-11 补充「搜一下先匹配一下即可」，每个门派只查一两个可靠来源：原著明写的地名（如星宿海、凌霄城、铁掌峰、黑木崖、神龙岛、侠客岛、桃花岛、绝情谷、万安寺、燕子坞、聚贤庄、剑湖宫、缥缈峰）照原著；原著不著州县的沿用现有坐标并标（待考）；章节文档已定锚点的（郑州聚贤庄、西安周威信）随章节。
2. 有实地对应的取实地坐标（真实寺观、山体、城镇），小说地名取所在山系 / 水域的示意点；依附城取原著州府，或最近的、在门派开放章节里开放的地图节点（门派 `region` 由依附城派生，`render_map.py --check` 校验落在陆地 / 岛屿掩膜上）。
3. 图标按原著门派性质：僧寺 / 尼庵 / 喇嘛寺院为 `temple`，道士宫观为 `daoist`，俗家门派、帮会、世家、朝廷与部族一律 `sect`；崆峒、昆仑、华山虽在道教名山，原著为俗家门派，记 `sect`。
4. 古龙组织沿 `design/17` §3.5「投放状态」口径，只在原作地望可查时改挂（恶人谷在昆仑、无争山庄太原、万梅山庄姑苏），其余保持原创投放。
