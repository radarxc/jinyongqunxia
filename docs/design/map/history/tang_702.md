## 1. 结论

- **基准年**：武周长安二年（702）。年号长安（大足元年十月改元长安）；国号周，史书仍以唐代地理志记其州县。武则天长安元年（701）十月入京师、长安三年（703）十月还神都，故 702 年朝廷驻长安（《资治通鉴》卷 207）。
- **189 城统计**（`eras.ch10.status`）：都城 4、路府州县 110、军镇 8、边关 13、商埠 2、未建或废弃 52（含 8 个小说 / 古龙岛屿锚点）。开放 136 城（昆仑山道为边关但不开放）。逐城置信度：A 123、B 41、C 17。
- **都城 4**：长安（京城·雍州，朝廷所在）、神都（洛州，武周正式都城）、并州（北都，690–705 年陪都，按本数据惯例与宋西京 / 南京、辽五京同记都城）、逻些（吐蕃）。
- **唐代边镇**：安西都护府（龟兹）、疏勒镇、于阗镇三镇在图内（第四镇碎叶在图外）；焉耆 702 年为都督府、未列四镇（开元七年才复备）。庭州长安二年十二月改置北庭都护府，图上以庭州属县轮台代表（`city_urumqi`），吉木萨尔的庭州城本身没有城市键。
- **数据写法**：`history.tang` 与其余六档同结构；`chapters.ch10 = {year: 702, era: 唐·武周长安年间（原创扩展定年）, band: tang}`；`city_wuhan` 的首条治所迁移加入 `tang`（鄂州治江夏，与宋同点）。其余章节的名称、地位、开放一律未改。

## 2. 方法

1. **时间切片**：用哈佛—复旦 CHGIS V6 的 TGAZ 公开接口取 702 年有效地名（2218 条：州 692、县 1418、都护 / 都督 / 城 / 诏等），按每城锚点求最近州县治所作底稿；CHGIS 中起止年为 0 或 1911 这类泛化记录、坐标为 0 的记录剔除。只在本地临时分析，不入库、不再分发 CHGIS 数据。
2. **正史逐条核对**：凡涉及武周改名、置废年份、治所迁移者，逐条在《旧唐书·地理志》《新唐书·地理志》《元和郡县图志》《唐会要》《资治通鉴》原文中检索；改名以「改 / 复」两端年份夹住 702 才采用。
3. **显示名规则**：锚点即州治写「某州（某县）」；锚点为非治所县写「某县（所属州）」；都护府 / 都督府 / 军镇写机构名；境外政权写当年称呼；无城邑写「某地（未建城 / 未置县）」并关闭。
4. **地位规则**：都城＝当期政权都城（含陪都，沿本数据惯例）；路府州县＝唐正州及其属县治所；军镇＝都护府、四镇及军城；边关＝关隘、羁縻都督府 / 羁縻州城与边地城邑；商埠＝以互市港埠为主要职能者；未建或废弃＝702 年不存在或无对应城邑（一律不开放）。
5. **开放规则**：702 年有城邑即开放；没有的关闭。小说岛屿锚点（桃花岛等）在 702 年唐代层一律关闭；生成器写死的起点 `city_dali` 保持开放（洱海河蛮城邑史实上成立）。
6. **拿不准不硬编**：异说并存的写「（待考）」并在 §7 登记；谭其骧《中国历史地图集》第五册与地方志纸本本轮未能在线核验，未作引用。

## 4. 702 年格局要点

- **两京一陪都**：京城长安（雍州，开元元年才改京兆府；《新唐书》「上都，初曰京城，天宝元年曰西京」，而《资治通鉴》长安三年已有「西京留守」之称，本表从《新唐书》作京城）；神都洛阳（洛州，光宅元年改东都为神都，神龙元年复东都，开元元年才改河南府）；北都并州（天授元年置、神龙元年罢）。
- **武周改名仍在行用**（702 均处改名区间内）：华州→太州、华阴→仙掌（686–705）；真定→中山（690–705）；南阳→武台（698–705）；金华→金山（688–705）；嵩阳→登封（696 起）。
- **治所与名称易错点**：今福州 702 年叫泉州（治闽县），今泉州为武荣州（700 复置）；登州 692 年初置时治牟平（近今烟台），707 年才移蓬莱；漳州 686 年置于漳浦西林（今云霄），龙溪 702 年属武荣州；唐崖州在今海口一带，今三亚为振州；隆州 712 年才改阆州；衡州治临蒸（732 年复名衡阳）；兰州属县 671–742 年叫金城。
- **北边**：云州永淳元年（682）为突厥所破而废，至开元中复置，故大同 702 年无城；后突厥默啜强盛，702 年寇盐、夏、并州；单于大都护府垂拱二年降为镇守，圣历元年改隶安北都护（安北治所有异说，见 §7）；妫州长安二年移治清夷军城（今怀来）。
- **东北**：万岁通天二年（697）营州陷于契丹，神龙元年（705）侨治幽州界，辽西走廊无唐城；安东都护府仪凤二年（677）移新城，圣历元年（698）改安东都督府；698 年大祚荣于东牟山（今敦化）建震国，渤海上京尚未出现。
- **西北与西域**：凉州赤水军、甘州建康军（695）、灵州丰安军（696）、鄯城河源军已置；豆卢军（705）、伊吾军（710）尚未置。长寿元年（692）王孝杰复四镇，安西都护府驻龟兹，四镇为龟兹、于阗、疏勒、碎叶；庭州 702 年十二月改北庭都护府、置烛龙军（703 改瀚海军）；突骑施乌质勒以碎叶川为大牙、弓月城与伊丽水为小牙。
- **西南**：洱海六诏并立（南诏统一在 738 年），唐以姚州都督府（今姚安）与羁縻州遥领，吐蕃势力南下；吐蕃赞普器弩悉弄（都松芒波杰）在位，都逻些。
