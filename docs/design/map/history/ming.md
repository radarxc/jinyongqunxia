## 2. 方法

1. **时间切片**：用 CHGIS V6 的 TGAZ 公开接口按章节年份取有效地名（每档 1700–1900 条，按转写前缀分批抓取，覆盖不全，北方辽金、西域、吐蕃记录尤少），逐城求名称匹配与最近州县治所作底稿；泛化记录（起止 0 / 1911 或跨度过长）只作参考。只在本地临时分析，不入库、不再分发 CHGIS 数据。
2. **正史逐条核对**：凡涉及升府、改名、置废、治所、都城者，在本档对应正史地理志 / 本纪原文中检索（见 §3）；改名以「改 / 复」两端年份夹住章节年份才采用。
3. **章节年份与年末状态**：同一档覆盖多章时逐章覆盖 `eras.chNN`，不拿后来的名字套前面的章节；章节年份内发生的改名 / 升降 / 易主按**该年年末状态**取值，并在 `note` 写明月份。`history.<band>` 只作档内摘要：各章一致时与 `eras` 相同，不一致时写成「甲（年）→ 乙（年）」，地位取档内首章。
4. **显示名规则**：沿用原数据的州府名写法，改正错名，去掉已能判定的「（待考）」；锚点不是治所时写「某县（所属府州）」或「某地（说明）」；括号前为地图标签短名，括号内写治所、归属或地位说明。
5. **地位规则**：都城＝当期政权都城，含陪都 / 留都（宋四京、辽五京、金诸京、明南京、清盛京，沿本数据惯例）；失守、已亡政权的旧都改记实际名称与地位；路府州县＝正式府州县治所；军镇＝卫所、镇城、将军 / 副都统驻地等军事建置；边关＝关隘、羁縻与边地城邑；商埠＝以港埠、互市、商镇为主要职能者；未建或废弃＝当年不存在或无对应城邑。
6. **开放规则（与唐 702 档同标准）**：当年有城邑即开放，没有的关闭，关闭条目地位一律记「未建或废弃」。三类例外均写明并标（原创扩展）：① `design/chapters/NN` 开放城市表已用作剧情 / 支线锚点的节点保留开放；② 丝路等长程路线的端点（敦煌）在关外废弃期仍作驿路节点开放；③ 小说岛屿与古龙支线锚点（`importance: site`）的开闭沿用原值，本轮不改。生成器写死的起点 `city_dali` 各章保持开放。
7. **拿不准不硬编**：异说并存、只能推定的写「（待考）」并在 §7 登记；谭其骧《中国历史地图集》与地方志纸本本轮未能在线核验，未作引用。

## 4. 明 1523 / 1582 / 1644 格局要点

- **三章逐章覆盖**：1523（嘉靖二年）、1582（万历十年）、1644（崇祯十七年 / 顺治元年）。档内改名：长治 1523 潞州（1529 升潞安府）；商丘 1523 归德州（1545 升府）；腾冲 1523 腾冲军民指挥使司（1524 置腾越州）；贵阳 1523 贵州城（宣慰司、布政司同治；1569 才有贵阳府）、1644 贵阳军民府（1601）；安康 1644 兴安州（1583 改名）；遵义 1644 遵义军民府（1601 平播）。
- **1644 年末格局**：北京（三月李自成破城，十月清顺治帝定都）记都城；南京弘光政权、西安大顺西京、成都大西西京、盛京（清旧都、迁都后为留都）、拉萨甘丹颇章（1642）均记都城；锦州 1642 年入清，辽阳为后金东京城旧地、清辖；台南为荷兰大员（热兰遮城，1624）开放；澎湖 1624 年后明军汛守开放。
- **关外与边地**：敦煌 1523 年为罕东左卫（沙州故城，1528 内徙），1582、1644 年空其地，作丝路驿路节点保留开放；哈密卫嘉靖初废，后两章记「卫废，吐鲁番据」；叶尔羌汗国（1514 起）都叶尔羌；归化城 1572 年始筑，1523 年关闭；宁古塔旧城只在 1644 年开放；吉林乌拉、朵颜三卫牧地、河套、阿勒泰、漠南草原无城邑，关闭。
- **易错名**：明定海县治今镇海，舟山只设所城（记「舟山（定海卫舟山所）」）；锦州城设广宁中屯卫（广宁卫在今北镇）；淄博锚点为淄川县（济南府属）；唐山为开平中屯卫（永乐元年徙治石城废县）；秦皇岛为山海卫海口。
