## 0. 阅读指引

### 0.1 文档边界

本文是《书剑恩仇录》书界的可制作内容合同，不是原著梗概，也不复制通用系统定义。尤其需要注意：

1. 第 4 节只把 `design/story/12-shujian.md` 的 22 个正式任务编排为 9 个制作阶段，并给其他系统接口；剧情、对白、事件顺序与选择后果以故事文档为准。
2. 第 3 节采用作者 AR-04 / AR-11 的“本时代图层”：区域只用 `design/11` 的全局 `rg_*`，章节专属空间用 `sc_12_*`；不创建旧式按书界编号的区域 ID。

4. 武学名称、品阶、前置与招式只引用图鉴；本章任务只发放来源或学习资格。
5. 资源、职位、门派月钱、Boss 模板和天书效果均引用上游，本文只做本界实例与算式核对。
6. 正线与邪线都是完整路线；“邪线”表示以官面秩序和筹码优先的叙事视角，不等于强制屠戮，也不降低天书资格。

### 1.2 主题与体验支柱

本界的主题句是：**恩可以成为同行的凭据，也可能被误作索取服从的债券；仇可以要求追责，却不能替当事人决定代价。**

| 支柱 | 玩家体验 | 系统承载 |
|---|---|---|
| 红花会群像 | 同一目标由不同当家承担，救人、筹谋、侦察与断后不可由一个“主角替身”包办 | §10.1 群像调度；`design/09` 多队战 |
| 乾隆身世 | 把“小说中的身世传说”拆成线索、知情者、可信度和用途，不写成历史事实 | §10.2 证词账；故事 `dc_12_04/08` |
| 江南—回疆长旅 | 水网、城墙、驿路、荒漠、雪岭和宫禁形成连续空间语法 | §3；`design/08` 地形 / qg 门禁 |
| 两条完整路线 | 正线先救人，邪线以筹码换秩序；两线都能看见锚点、达成改命和取得天书 | §4–§5；故事 §3–§7 |
| 可信改命 | 不是临场按钮，而是民众信任、宫中接应、背约证据、撤离路线四项长期建设 | §5；四旗标逻辑合取 |
| 中武成长补齐 | 入场 2/2/2 后，本土内功、拳脚、兵器各至少再学一门，可填满 3/3/3 | §9；`skills-qianlong` §9.1 |

### 1.3 叙事原则

- 玩家不顶替陈家洛、霍青桐或喀丝丽；只在信息、路线、战场目标和承诺落实处成为“变数”。
- 经书归还、文泰来被捕与获救、黑水营战局、乾隆背约等原著锚点保持；具体顺序以已审校故事文档为准。
- 改命线只改变结局文本、天书变体、个别人物命运和后世彩蛋，不改变 `ch13_feihu` 的历史起点。
- 涉及回部的文本采用原著时代语境，同时避免把一个阵营或人物行为泛化为现代民族判断。
- 乾隆身世明确标作小说设定 / 民间传说；史实生卒只用于年龄和健在判定。

## 2. 穿越开局

### 2.1 苏醒地点与共有钩子

主角从 `ch11_yuanyang` 书眠约十三年后，在 `rg_jiangnan_taihu` 的杭州府外围苏醒。普通身份位于商号后院，隐藏身份位于红花会外围舵口；两者都在两日时限内接到一封西北急信 **（原创扩展）**，随后汇入正式共有任务 `q_12_main_c_01`。

苏醒场景只承担四件事：确认时代、重建携带栏、提示外来压制、交付急信。不得重复序章教学，也不得提前告诉玩家乾隆身世或正邪路线标签。主角性别由玩家选择，不改变任务门槛。

### 2.2 可选开局身份

| 身份 | 解锁 | 起始区域 / 场景 | 门派影响 | 首条支线 | 主线汇合与边界 |
|---|---|---|---|---|---|
| 江南商号临时账房兼驿路脚夫 **（原创扩展）** | 默认 | `rg_jiangnan_taihu` / `city_hangzhou` 商号后院 | `sect_honghuahui` 好感 0；无正式门派身份 | `q_12_side_01`“驿脚识路” | 商号承揽西北急信；完成后进入 `q_12_main_c_01` |
| 红花会外围舵口伙计 | 完成本书改命线后，按 `design/13` §6.4.2 解锁 | `rg_jiangnan_taihu` / 杭州外围舵口 `sc_12_hangzhou_duokou` | 红花会好感 +10 **【建议值】**；仍不是 L1 会众 | `q_12_faction_01`“舵口三封信” | 舵口交付同一西北急信；事件、选择、奖励与普通入口汇合 |

只有这两个身份有效；不另造第三个官差身份，以免绕过故事 §2 的信息起点。隐藏身份的 +10 好感仅改变称呼、一次情报检定和舵口支线入口，不预锁正线，也不免除正式入会、职责或贡献。

### 2.3 开局差异矩阵

### 2.4 开局流程接口

1. `BS_WAKE` 从 `design/02` 读取携带的 2 内 / 2 拳脚 / 2 兵器与上一界同伴快照，不把任何旧同伴直接塞进活动队。
2. 对上一界人物逐一运行 `design/18` 的健在判定；`npcs-ch11-yuanyang.md` 生卒未定者得到 `life_unknown`，只显示“线索待访”，不自动重逢。
3. 展示本界 `−2` 品外来压制与本土补位建议，不改写武学绝对品阶。
4. 建立 `stance12=0`、群像席位空表和身世证词账空表；这些是章节状态，不是角色永久属性。
5. 完成对应首条支线后，双方入口都接到西北急信，进入 `q_12_main_c_01`。
6. 主线第一次可见的阵营说明发生在 `dc_12_01`，避免开局身份替玩家做伦理选择。

“模板校准攻击 / 防御”仅是 `full` 面板验收的参照值，不是把 `tmpl_boss.atk×1.25` 再乘一次。具名人物正式手配后，要求攻击与防御各落在该行参照的 0.85–1.15 倍，HP 落在表中目标 ±5%；超出必须在实例说明。乾隆关卡以封锁槽和护卫战阵承压，不把皇帝虚构为同级绝顶武者。

张召重终盘主力按已登记 `sk_wujixuangongquan`（7 地下）9 重计算：`P_actual=G(7)×L(9)=2.00×1.40=2.80`；D5 只影响其面板 HP / 攻击，不直接再乘武学威力。采用示例招式“火手判官”倍率 2.90 时，外 / 内混合取 `r_in=0.45`：

```text
ATK_mix = 0.55×2,779 + 0.45×2,496 = 2,651.65
P_ref(Lv52,MID) = 3.92
D1 = floor(2,651.65 × 1.24 × (2.80×2.90) / 3.92) = 6,806
DEF_mix（对同级标准目标 1,963 / 2,169） = 0.55×1,963 + 0.45×2,169 = 2,055.70
F_def = 1.20×2,651.65 / (2,055.70 + 1.20×2,651.65) ≈ 0.608
Z2 后基伤 ≈ floor(6,806×0.608) = 4,137
```

这是不含命中、招架、暴击、Z3–Z10、难度模式与场景修饰的抽查值；正式结算仍逐乘区取整，见 `design/04`。`design/02` 的旧校准建议曾把张召重主力写作“地上 9·9”，与当前图鉴的地下 7 冲突；本章不虚构一门地上攻击技，而用凝碧剑、完整法先天与可破解的阶段机制校准难度，并在文末登记同步项。

| 统筹 | `npc_chenjialuo`、`npc_xutianhong` | 显示目标冲突与替代次序 | 调整 `openingOrder` 或预警信息，不加行动次数 | 不替玩家做选择，不自动解谜 |

| 接应 / 护送 | `npc_luobing`、`npc_jiangsigen`、`npc_yangchengxie` | 护送伤员、船工、信使或撤离队 | 生成 AI 剧情友军 / 退路格；倒地按剧情后果 | 不占玩家队伍又接受玩家逐步控制 |
| 断后 / 守点 | `npc_wuchen`、`npc_changhezhi`、`npc_changbozhi`、`npc_zhangjin`、`npc_shishuangying` | 守桥、守门、截援或延时 | 将一波敌军留在侧战线，或作为 `offgrid` 援军 | 不直接删除 Boss 阶段或免除主目标 |
| 医护 / 联络 | `npc_wentailai`（康复后）、`npc_yuyutong` 及通用会众 | 建立伤员点、传信、修复失联 | 战后伤势 / 补给与信号事件 | 不在战中无成本复活，不替代医术检定 |

“合法指派”要求人物处于当前剧情时空、未死亡 / 被捕 / 重伤锁定、关系允许且没有被主线占用。张召重、乾隆等非红花会人物不能被塞入本系统；周绮、李沅芷等盟友可以在具体任务中提供一次协作，但不占“十四席”显示。

#### 10.1.2 调度规则

1. 每个群像节点提供 3–5 个岗位，标出必需标签与相冲目标；玩家在出发前指派，开战后不可无代价换岗。
2. 每名人物同一时段只占一个岗位；被编入玩家六人队的人不能同时产生场外成功效果。
3. 岗位结果为 `ready / strained / failed / unavailable`：满足标签且人物可用为 `ready`；勉强匹配为 `strained`；无人或任务失败为 `failed`；人物状态冲突为 `unavailable`。
4. `ready` 只带来情报、少一波援军、额外退路或伤亡缓冲之一；每个岗位至多影响一个关卡变量，禁止叠出纯属性碾压。
5. `strained` 保留效果但产生代价，如该人物战后轻伤、关系芥蒂或额外耗时；代价在确认页明示类别，不提前泄露具体剧情。
6. `failed` 不使主线断裂：关卡回到标准难度与标准路线，失去的是准备优势；涉及四个改命旗标时，必须仍有另一条故事文档已登记的补救路径。
7. 同一事实只结算一次。人物既在侧线护民又在主战成为剧情友军时，关系、经验、货币和贡献不得双发。
8. 主线关键人物由故事锁岗：例如被囚的文泰来不能提前担当联络；黑水营由霍青桐负责军略，玩家只能给她配置侦察 / 接应资源，不能改名为自己的统筹成果。

#### 10.1.4 UI 与系统接口

- **出发前**：横屏左侧显示五类岗位，右侧显示可用人物头像；拖放时只显示“擅长 / 可胜任 / 冲突”，隐藏底层评分。已进活动编组者显示“随队”，不能重复指派。

- **结算页**：按“谁完成了什么、付出什么代价、影响哪个目标”列因果；失败岗位保留记录和补救入口，不写成“陈家洛包办”。
- **任务接口（12）**：读取任务状态、人物可用性与关系；写稳定的岗位结果事件，奖励保持幂等。
- **战斗接口（09）**：只配置剧情友军、`offgrid`、波次、退路格、弱点与目标；不突破玩家 ≤6、mid 档活动单位 ≤24 **【建议值，待实测】**。
- **人物接口（18）**：伤势、被捕、死亡、同行窗口与能力画像实时重验；阵亡人物不会因旧调度表复活。
- **成长接口（13）**：群像任务经验进入本界预算；天书和结局只读已发生事实，不给席位数量乘法加成。

### 10.2 乾隆身世证词账 **（原创扩展）**

#### 10.2.1 设计目标与事实分层

身世系统不是让玩家拼出“历史真相”，而是管理小说内部的线索、证词、实体材料、盟誓条款与背约证据。界面标题固定为“身世线索 / 盟约证据”，史实栏始终显示：**乾隆史实身份不由本系统裁定；小说中的海宁身世属于文学设定 / 民间传说。**

| 证据域 | 例 | 可支持的结论 | 明确禁止 |
|---|---|---|---|
| `lineageClue` 身世线索 | 海宁墓前所见、文泰来口述 | 小说中存在身世疑云；可开启六和塔对质 | 不能证明乾隆即将背约，不能写入史实档案 |
| `lineageMaterial` 身世材料 | 雍邸索子短札、陈夫人亲笔信、于万亭供词、血衣、雍正遗旨 | 在小说叙事内补强身世说；决定乾隆回应与陈家风险 | 不能直接点亮 `flag_12_betrayal_proof` |
| `oathTerm` 盟誓条款 | 六和塔承诺、即时放人 / 撤兵的可验证条款 | 建立“承诺了什么”的基线 | 不能单独证明违约已经发生 |
| `betrayalProof` 背约材料 | 违约军令、灭口调令、矛盾军令或合法证词 **（原创扩展材料）** | 与一项盟誓条款互证后，可派生背约证明 | 不能拿身世材料冒充，不能靠单份传闻完成 |
| `contact` 接应线索 | 宫中换班暗号、联络人、侧门时间 **（原创扩展）** | 支撑 `flag_12_palace_contact` 与撤离 | 不证明血统或背约 |

#### 10.2.2 收集、互证与用途规则

1. 每条记录保存来源人 / 物、取得幕、原件或口述、当前保管人、是否独立、公开范围及考据状态；同一来源抄三份仍只算一条。
2. 身世材料按“小说内可信度”显示 `unverified / corroborated / contested`，不显示百分比，也不把 `corroborated` 翻译成“史实为真”。
3. 背约证明要求 `≥1 oathTerm + ≥1 independent betrayalProof`；若故事分支明确要求“两类独立材料”，则同一签发链的抄本不能凑数。
4. `dc_12_04` 决定用途：公开施压、封存保护、有限交易；它可以切换正邪路线、改变陈家风险与乾隆态度，但不会销毁主线保底的身世事实。
5. `dc_12_08` 决定终局处置：公布背约、换俘、封存身世或混合处置；身世域和背约域分别结算，玩家可以封存身世而公布背约。
6. 任何任务失败都不能凭空改写材料内容；最多造成原件失去、只剩可信抄本、公开范围扩大或联络人暴露。主线保底材料按故事文档取得，原创背约材料有替代路径。
7. 乾隆、陈家洛、文泰来和于万亭等人物的陈述按“谁说、何时说、是否亲见”存储；不把角色地位直接等同可信度。
8. 本系统只发任务事实和关系后果，不增加武学品阶、Boss 属性或天书效果。

#### 10.2.4 UI 与系统接口

- **证词账页**：按“身世 / 盟誓 / 背约 / 接应”四栏，而非一条混合进度条；每张卡显示来源、取得时点、原件 / 口述、保管、小说设定 / 原创材料标签。
- **关系图**：只画“互相支持 / 互相矛盾 / 同源抄本”，不画“真相百分比”。选择节点前高亮会被公开、封存或拿去交换的记录。
- **风险提示**：公开身世前显示“可能牵连陈家”；公开背约前显示“清廷敌对将上升”；不泄露未发现结局名或隐藏数值。
- **任务接口（12）**：证词取得与处置写成幂等 effect；抄本不得重复计数，遗失原件须保留因果日志。
- **战斗接口（09）**：证据可开启劝退守卫、揭示灭口组或改变护送目标，不直接给 Z3 / Z4 加成。
- **成长接口（13）**：只把 `fateRoute12`、`tsp_12_canon/fate`、后日谈与改命代价交给成长系统；天书数值不在证词账计算。
- **人物接口（18）**：证词必须引用当时人物状态；已故于万亭只以历史记录出现，陈世倌只以墓碑 / 文书出现。

### 10.3 两套系统的联动与降级

群像调度回答“谁把事实与人送到正确位置”，证词账回答“送到的是什么、能证明什么”。两套系统只通过稳定事件相接：侦察岗位可发现记录，接应岗位可保护保管人，断后岗位可争取撤离时间；岗位成功不会自动提高证据可信度，材料齐全也不会自动让任何当家到场。

| 异常 | 降级行为 | 主线保证 |
|---|---|---|
| 群像人物受伤 / 不可用 | 岗位转 `unavailable`，开放通用会众或路线替代 | 保留标准敌人波次与必需退路 |
| 证据原件丢失 | 若故事允许，降为可信抄本或转独立证词；原创材料走替代军令 | 五锚点仍可完成；改命硬条件可能需补救 |
| 玩家无 qg 门槛 | 用向导、门派引见或较长路线 | 不锁主线、天书或两门天级的唯一叙事入口 |
| 活动单位逼近性能上限 | 非关键群像改为场外图标 / 波次，保留规则结果 | 玩家 ≤6、mid 活动单位 ≤24 **【建议值，待实测】** |
| 正式套装表缺失 | `setTags` 仅展示“候选联动未启用” | 武学、任务和人物仍可独立通关 |

## 12. 难度与数值要点

### 12.1 D5 曲线定位

本界是低武链结束后的第一部中武复兴书界。固定参数为 W55、D5、Lv52 上限、40–52 敌人带、9 重上限、外来 −2 品和 2/2/2 核心携带；均不得被章节配置覆盖。D5 只给同等级敌人的气血与攻击乘：

```text
enemyStatMul(5) = 0.85 + 0.05×5 = 1.10
```

它不乘防御或评级；标准难度 `diff_xiake` 再乘 `dm_hp=1.00`、`dm_atk=1.00`、`dm_rat=0`。因此本节所有表默认侠客难度，其他难度只通过 `design/13` §5 的正交系数变化，不能修改章节 D、W、等级带或武学品阶。D5 对应 `ai_adept`、Boss 2 阶段、精英词条数 `floor(5/3)=1`。

书剑的终盘强度不能靠虚抬张召重武学品阶实现。上游旧对照表曾用“地上 9·9”，而当前图鉴正式画像为 `sk_wujixuangongquan` / `sk_rouyunjian` 7 地下、`sk_tiyunzong` / `sk_chunyangwuji` 8 地中；本章以当前图鉴、凝碧剑、完整人物属性和两阶段机制为准。

### 12.5 张召重终盘伤害抽查

沿 §8.6 的图鉴合法值，张召重以 `sk_wujixuangongquan` 地下 7、9 重为主力：

```text
P_actual = G(7)×L(9) = 2.00×1.40 = 2.80
ATK_mix = 0.55×2,779 + 0.45×2,496 = 2,651.65
D1 = floor(2,651.65×1.24×(2.80×2.90)/3.92) = 6,806
DEF_mix = 0.55×1,963 + 0.45×2,169 = 2,055.70
F_def = 1.20×2,651.65/(2,055.70+1.20×2,651.65) ≈ 0.608
Z2 = floor(6,806×0.608) = 4,137
```

这里 `2.90` 是已登记招式倍率，`P_ref(Lv52,MID)=3.92`；D5 已包含在张召重的攻击面板，不能再在 Z1 乘 1.10。4,137 只是命中且未招架时的 Z2 抽查，后续仍走 Z3–Z10、相性、暴击、地形、护体和最低伤害。

### 13.4 史实、小说与玩法的显示约定

- **史实层**：乾隆生卒与在位时段可以标“史实”；小说行为、盟誓和身世不能倒灌史实资料卡。
- **小说层**：原著事件用“小说中”描述；具体动作未终校时不使用引号，不伪造原句。
- **玩法层**：所有任务补救、证据品类、资源点、营生、Boss 阶段、关系数值和跨书彩蛋均显示“本作扩展”。
- **地图层**：`cities.yaml` 的时代名是制作权威；章节挂点不是考古结论，图外节点只经专线。
- **人物层**：故事审校后的生死事实优先于尚未同步的名录旧行；冲突须在报告中要求上游同步，不在本章暗改目录。
