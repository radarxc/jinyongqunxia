## 0. 阅读指引

### 0.1 一句话结论

《天龙八部》是十四书界的首个完整垂直切片：玩家以无籍行脚人身份从无量山进入“大理—宋—辽—西夏—吐蕃—天山”的多国江湖，在不替代段誉、萧峰、虚竹的前提下，用救人、取证、结盟与主动舍弃独占利益来回答“众生是否值得同渡”。

## 2. 穿越开局

### 2.1 固定身份与苏醒地点

玩家承接序章书眠，在约 1093 年醒于 `rg_dali_cangshan` 的无量山外围驿路 `sc_01_wuliangyidao`。真实身份固定为“失籍行脚人”**（原创扩展）**：没有宋、大理、辽任何一方正式户籍，由途经茶商为“路上救起者”作临时保结。此设定逐项引用 `design/story/01-tianlong.md` §2：无籍、无阵营、不替代段誉，男女主角两版均可使用。

书灵仅留下“此卷以众生为题”的墨影，不剧透萧峰结局。起始等级为 1、正式携带为空、区域声望为 0；`morality` 是否承接序章只按 `design/03` 的全局规则读取，本文不另定。

### 2.2 三种自述身份

三项是别人可核验的临时谋生自述，不改变“失籍行脚人”真实身份。它们均在同一区域汇合 `q_01_main_c_01`，只影响短入口、首个门派介绍人与第一条支线。

| 自述 | 起始短入口 | 门派 / 势力影响 | 首条支线 | 初始便利 | 永久边界 |
|---|---|---|---|---|---|
| 识字抄录 | `sc_01_jianhugong` 外院账棚 | 无量剑派允许旁听比剑；不自动入门 | `q_01_side_71` 玉璧剑影 | 可识别壁上残字与账目矛盾，不加 `wis` | 不可据此读取完整秘籍 |
| 草药急救 | `sc_01_wanjiangu` 外围药径 | 神农帮从敌对改为警戒；天龙寺获得一名药僧介绍人 | `q_01_side_74` 生死符之困 | 开局可救中毒脚夫并标记常见药材，不加医术等级 | 不免疫毒，也不跳过后续求药 |
| 脚程探路 | `sc_01_wuliangyidao` 商队落脚点 | 无量剑东西宗均可递挑战帖；茶商提供大理路引 | `q_01_faction_71` 无量比剑 | 第一次山路盘查可改走安全旧径**【建议值】** | 不获得轻功数值或门派职级 |

“草药急救”的首条支线只在开局建立司空玄与生死符的远期线索，真正解除仍需灵鹫宫阶段；不会提前开放西域。

### 2.3 开局流程与第一选择

1. **书眠苏醒**：确认无携带，播放书灵墨影，取得茶商临时保结。
2. **自述落位**：选择一项谋生自述，加载对应短入口与任务线索。
3. **山道教学**：在 `tr_pingdi`、`tr_zhulin`、`tr_huacong`、`tr_suishi` 间完成寻路、救治和非致死制服。
4. **冲突入场**：发现无量剑派 / 神农帮争斗与钟灵求援，不默认任何一方为善。
5. **局部选择**：在 `q_01_main_c_01` 中触发局部键 `dc_01_01`，先救中毒脚夫、追钟灵或循段誉足迹找秘径。
6. **锚点成立**：玩家从外围见证段誉卷入并失踪；段誉自己的核心机缘不由玩家取得或阻止。
7. **共同汇合**：三种自述在福地外围汇合，开放大理城和后续救援；不提前锁正邪线。

### 2.4 防死档与开局数据夹具

- 段誉不会因玩家探索或长休死亡；延误只减少钟灵 / 脚夫的人情奖励。
- 无量剑与神农帮同时敌对时，茶商路引仍能通往大理；主线不得要求先加入任一门派。
- 局部门禁键 `gateKey:wuliangyidao` 的 qg1 奖励岔道可绕行；琅嬛福地核心传承仍由段誉先取得。
- 任何自述都能在第一小时获得一门通行黄阶根基，不把选错背景变成成长死档。

## 3. 开放世界地图

### 3.1 本时代图层与入口原则

本界使用全局江湖地图的 `ch01` 时代图层，视觉底图为 [`jianghu-ch01.svg`](../map/jianghu-ch01.svg)。区域沿用 `design/11` 定稿的全局 `rg_*`；本界专有山谷、庄院、洞窟、追逐段与副本只用 `sc_01_*`。城市显示名以 `cities.yaml.eras.ch01` 为底，再按 `design/11` §11 的 22 城制作范围取交集；底表仍存旧区域 ID 的问题只登记同步，不在本文回退。

| 图层规则 | 本界落地 |
|---|---|
| 完整开放区域 | 9 个；进入后可自由探索并承载资源、营生、支线与回访 |
| 实际开放城市 | 22 座；其他时代 `open=true` 城仅作题签、旅行中继或背景 |
| 区域间旅行 | 大地图选目的地，经驿路 / 水路 / 商队专线结算遭遇；不做第二套可行走大地图 |
| 图外节点 | 仅剧情或商队专线抵达；不写入相邻区域，也不生成徒步路径 |
| 主线轻功门禁 | 常规最高 qg2，必须有正门、船、路引、绳索或剧情同伴等替代 |
| 支线 / 隐藏门禁 | 常规最高 qg3 / qg4；唯一 qg5 须有合法临时 `qinggong +12`，失败可退 |
| 门禁阈值 | qg1/2/3/4/5 = 20/50/90/140/200；完整定义见 `design/08` §6 |

长途路径可以穿越未制作区域，但中继题签不能下车。成都、兰州、辽南京、越州等即使承担路线或题签功能，也不因此计入 22 座可玩城市。波斯总教等图外对象在本界不开放；若后续彩蛋使用，只能由专线进出。

### 5.2 原著线 `tsp_01_canon` 达成路径

1. 亲历 A1–A4，不论正线、邪线或中途付代价切线。
2. 完成 `q_01_main_z_10` 或 `q_01_main_x_10` 的南京营救与雁门止战，写入 `flags.a5_yanmen_resolved=true`。
3. 在 `dc_01_09` 选择尊重萧峰原著决定，或改命四项未全部满足，或保留独占利益。
4. 萧峰按原著线结束生命轴，书页以“有人以一身止万人刀兵”的回望现世；授予 `tsp_01_canon`。
5. 此路径是完整结局，不是失败奖励；效果、温养、Buff 和跨界规则仅见 `design/13`。

### 5.3 改命线 `tsp_01_fate` 达成路径

改命必须同时满足四项，不能四选三：

```text
fateReady = size(crossFactionRescueFactions) >= 2
          && (livingKeyWitnesses >= 1 || sealedIndependentEvidence >= 2)
          && bond(npc_xiaofeng) >= 80
          && relinquishedExclusiveGain == true
```

| 条件 | 合法来源 | 防刷 / 防替代 |
|---|---|---|
| 跨势力救援 ≥2 类 | 大理 / 天龙寺、宋地群雄 / 丐帮、灵鹫 / 洞岛、辽军民等实际救援 | 按势力类别集合去重；交钱、声望或同一势力重复救援不计 |
| 活证 ≥1 或独立封缄 ≥2 | 阿朱等实际存活关键证人；少室档案、大理密封、辽军命令等 | 两份证据须来源独立且封缄完整；人物名单按 story 与 `design/18` |
| 萧峰羁绊 ≥80 | C03 起的坦白、救援、并肩与尊重选择 | 礼物不能越档；80–89 是 `design/18` 的高羁绊档 |
| 永久放弃独占利益 | `dc_01_09.A` 焚毁 / 公托 `exclusiveGainRef` | 必须不可装备、出售、找回；终战胜利不能替代 |

条件齐备时，跨方约束无需再以萧峰之死作押，他选择存活并承担宋辽两侧敌意**（原创扩展）**；写 `lifeState=fate_rescued`，授予 `tsp_01_fate`。改命只改变结局文本、天书变体、人物生命事实与后世彩蛋，不改变 `ch02_shediao` 的 1217 年起点。

### 5.4 次级救援与天书边界

阿朱、游骥、游驹、岳老三、叶二娘、玄慈、童姥、李秋水、段正淳、刀白凤、游坦之等均可按 story §6.3 获得独立救援窗口**（原创扩展）**。这些救援写各自生命轴、羁绊与后日谈，但：

- 不产生第三个天书变体；
- 不自动满足 A5 的全部条件；
- 曾入队同伴的首次命定死亡改写，修为余韵 / 欠债只按 `design/13` §6.6；
- 救一人不自动救其亲属或同场角色；
- 同伴在 1094 年获救不等于 1217 年仍健在。

### 5.5 天书现世断言

| 用例 | 前置 | 期望 |
|---|---|---|
| 五锚点缺一 | A1–A5 任一 false | 不现世，回到缺失节点补救 |
| 五锚点全、改命不足 | `a5=true`、`fateReady=false` | 只可获得 `tsp_01_canon` |
| 条件前三项全、未舍弃独占利益 | `relinquishedExclusiveGain=false` | 原著变体；不可用终战胜利绕过 |
| 四项全并选 A | `fateReady=true` | 只获得 `tsp_01_fate`，萧峰 `fate_rescued` |
| 重复结算 | 已有任一 `tsp_01_*` | 幂等，不重复发天书或奖励 |

### 10.1 珍珑棋局（`featureKey: zhenlong`）

#### 10.1.1 叙事约束与入口

### 10.3 带头大哥谜案（`featureKey: daitoudage`）

#### 10.3.1 证据不是“猜名字”

谜案从 A2 杏子林开启，贯穿 Z/X01–08，在 A4 少室山由原著人物自行认亲、对质与承担。玩家的目标是区分亲见、转述、伪证、物证与动机，保护证人并选择公开复核或三方密封；不能在早期靠 UI 猜中姓名而改写事实，也不能用伪证制造另一名带头大哥。

#### 10.3.2 证据图规则

| 字段 | 规则 |
|---|---|
| 节点 | `statement / object / record / locationTrace / identity` 五类；每条保留来源 NPC / 地点、取得时间与封缄状态 |
| 来源独立性 | 同一原始口供的抄本、转述、易容复述只算 1 个 `sourceRoot`；不同持有人不自动独立 |
| 可信度 | `unverified / corroborated / contradicted / forged`；只由交叉验证动作改变，不按玩家猜测改变 |
| 证人 | `alive / missing / protected / dead`；死亡不删除已封缄证言，未封缄转述降为不可作关键证据 |
| 关键门槛 | A5 的证据项要求 1 名存活关键证人，或 2 份 `sourceRoot` 不同且封缄完整的证据 |
| 正线 | 公开原证、允许当事人回应；获得 `witnessChain`，但公开会提高证人风险 |
| 邪线 | 以把柄换证、拆分控制权、三方密封；可以完整查明，但伪证仍不能通过真相校验 |
| 收束 | A4 固定写 `flags.leader_mystery_resolved=true`；真相由玄慈、萧远山、慕容博等原著人物行动揭示，扫地僧保留止斗位置 |

```yaml

opensOn: flags.a2_xingzilin_witnessed

  - id: clue_01_yanmeng_jiuhen

    sourceRoot: yanmen_cliff_trace
    obtainedAt: sc_01_yanmenguan
    seal: witnessed
    credibility: corroborated
  - id: clue_01_shaolin_dangan
    kind: record
    sourceRoot: shaolin_archival_chain
    obtainedAt: sc_01_cangjingge
    seal: split_three_way
    credibility: corroborated
criticalEvidenceRule:
  anyOf:
    - { livingWitnessCount: { op: ge, value: 1 } }
    - { independentSealedSources: { op: ge, value: 2 } }

  questRefs: [q_01_main_z_08, q_01_main_x_08]
```

`revealActors` 是本章局部叙事示例；进入正式构建时，萧远山必须解析为已登记的 `npc_xiaoyuanshan`，不得继续把中文显示名当持久化外键。

#### 10.3.3 UI、失败保护与隐私

- UI 用可缩放证据图：实线为同源、虚线为推断、红色叉为矛盾；颜色同时配图标。点击节点显示“谁亲见 / 谁转述 / 谁封存”，不显示系统预知的真凶答案。
- 证人临近命定死亡窗时显示“此证言尚未封缄”的风险提示，不提示必死；死亡后仍保留合法封缄证据。
- 关键证据被偷或毁时，必须有独立来源、活证人或三方密封中的至少一条恢复路径；不得因一场可败战锁死 A4 / A5。
- 谜案提交与任务阶段、NPC 状态、声望 / 品德、物品所有权必须同一事务原子写入；中途崩溃全部回滚。
- `design/09` 只处理追证遭遇与 A4 止斗；`design/12` 处理任务 / 分支；`design/18` 处理证人生死；`design/13` 读取 A5 的证据项，不由谜案 UI 直接授天书。

## 12. 难度与数值要点

### 12.1 D4 基线与三条独立轴

本界固定高武、W85、D4、等级 1–35。W 只决定敌人武学品阶分布，D 决定同级敌人的气血 / 攻击、AI、阶段与精英词条，玩家所选难度模式再独立相乘；三者不得合并成一个“战力倍率”。侠客难度是本文全部建议值的验收基准。

```text
enemyStatMul(D4) = 0.85 + 0.05 × 4 = 1.05
defaultAI        = ai_adept
bossPhaseCount   = 2
eliteAffixCount  = floor(4 / 3) = 1
displayLevel     = min(realLevel, 35)       # 本章 capExempt=0
```

- `enemyStatMul=1.05` 只乘模板敌人的 `hpMax` 与 `atkOut/atkIn`，不乘防御、评级、速度或 MP，见 `design/03` §10.5。
- 具名 `full` NPC 的攻击只乘 D4 的 1.05，不再乘 Boss 模板攻击 `×1.25`；HP 可取同级 Boss 模板的 0.6–1.2，见 `design/03` §10.1。
- `ai_expert` 不是 D4 默认值。§8 中鸠摩智、萧峰、丁春秋、童姥、李秋水、玄慈、慕容复、慕容博的建议脚本用它，是具名高手为体现招法组合而做的逐场覆写；段延庆、游坦之保留 `ai_adept`。覆写只提高决策能力，不偷偷改属性、阶段或奖励。
- 局部难度若使用 `localDifficulty`，只能在 `4±3` 内并写入遭遇数据；开局教学可取 D2，具名高手脚本则优先用 AI 覆写而非抬 D。
- 江湖 / 侠客 / 宗师 / 天劫的 `dm_hp`、`dm_atk`、`dm_ai`、援手与悔招均只引用 `design/13` §5；本文不能为天龙另造一套简易 / 困难倍率。
