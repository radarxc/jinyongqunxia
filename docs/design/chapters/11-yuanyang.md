## 0. 阅读指引

### 0.1 本文怎么读

本文是《鸳鸯刀》书界的内容总装文档，不是第二份剧情剧本。

1. 第 1–3 节确定基准参数、唯一开局身份和乾隆初时代图层。
2. 第 4 节只索引已审校的 `design/story/11-yuanyang.md`，不复述其对白与幕内流程。
3. 第 5 节把四个锚点、原著 / 改命两条结果路径和天书现世条件对齐。
4. 第 6–9 节负责可选任务、组织、人物、武学、装备、冲穴与前代传承投放。
5. 第 10–12 节配置喜剧夺刀、非致命解决、跨界接口与数值验算。
6. 第 13 节集中标注原创内容和待考事项，避免把玩法填充冒充原著事实。

### 0.2 四条边界

- **剧情边界**：共有幕、正邪线、选择节点、锚点结果和四类本地结局均服从 `design/story/11-yuanyang.md`；本文只建立它们与地图、支线、门派、人物和战斗的接口。
- **地图边界**：本界采用 `design/11` 的全局 `rg_*` 与 `map/cities.yaml` 的 `eras.ch11` 名称；旧稿 `rg_11_guandao`、`rg_11_xiaofu`、`rg_11_shanlin` 只作为迁移语义，不再作为区域 ID。
- **内容边界**：武学、装备、合击、降服、冲穴、资源经营、前代传承与天书效果由各自归属文档定义；本文只配置来源和章节状态。
- **史实边界**：约 1740 是游戏定年，不把小说官职、人物年龄或地望自动等同史实；刘於义的史实原型与小说角色须分开表述。

### 1.2 主题与体验支柱

| 支柱 | 玩家体验 | 系统承载 |
|---|---|---|
| 人人争刀 | 同一只包袱在镖局、四侠、官差、双侠之间反复易手 | 喜剧夺刀状态机、证词可信度、临时保管 |
| 人比刀重 | 赢下遭遇不等于杀光敌人，保护人质与旁观者才是高阶解 | 降服、停战、撤离、欺敌与零击杀计数 |
| 误会可解 | 追逐、假盲、抱错孩子和错认关系都可用观察与口才拆开 | `lore` / `speech` / 关系门禁、失败补证 |
| 双人成招 | 单人能用夫妻刀法，两名互信同伴才触发额外合击 | `sk_fuqidaofa`、`cmb_fuqidao`、羁绊 |
| 低武重建 | 外来绝学受压后，本土三类核心武学各至少三门 | 图鉴投放、门派晋升、人物授艺 |
| 仁者有力 | “不杀”不是逃避战斗，而是在能控制局势时选择留手 | 非致命证明键、四锚点、两种天书变体 |

### 1.3 八小时时长与节奏

| 内容桶 | 占比 | 时长 | 关键体验 |
|---|---:|---:|---|
| 主线 | 45% | 3.6 h | 松林—甘亭—枣香林—紫竹庵—萧府—中条山 |
| 开放内容 | 35% | 2.8 h | 20 条支线中择玩、10 条奇遇链、营生和资源点 |
| 成长整备 | 15% | 1.2 h | 门派晋升、三类装配补齐、轻功与冲穴指引 |
| 余韵 | 5% | 0.4 h | 归刀、后日谈、传承结算、书眠 |

D3 不靠越级 Boss 制造难度。压力来自多方互相误伤、护送目标、证据时限、身份冲突以及“赢而不杀”的额外目标。任何一次误判都应有代价，但不能因漏听一句梦话或输掉一场演武而断主线。

### 1.4 原著与扩展分界

威信镖局押刀、太岳四侠劫镖、林玉龙与任飞燕争斗、袁冠南和萧中慧相遇、卓天雄夺刀、紫竹庵传艺、萧府寿宴、两家身世及“仁者无敌”刀铭，取自原著情节骨架；事件细节和地望仍按 §13 集中考据。主角介入、正邪分线、可招募状态、资源经营、官府职位、零击杀审计、前代遗藏和大部分支线均为 **（原创扩展）**。

## 2. 穿越开局

### 2.1 固定苏醒地点与唯一公开身份

主角承接 `ch10_baima` 书眠约十四年，于约 1740 年在 `rg_guanzhong` 西安府东出官道的 `sc_11_xian_dongguan` 苏醒，最近城市为 `city_xian`。公开身份固定为“向京畿行走、暂随商旅互保的外乡行脚人”**（原创扩展）**。这与 `design/story/11-yuanyang.md` §2 完全一致，不另造三条互斥身世。

主角起初只知道明镖是盐银，不知道包袱中为鸳鸯双刀。镖队把主角当可临时护车的行脚人，太岳四侠把主角当可拉拢的见证人。隐藏身份“镖局趟子手”只来自 `design/13` 的改命周目规则：它提供初始镖局关系与较早的人质情报，仍不能跳过 `dc_11_01`。

### 2.2 三种行动身份

三项是苏醒后选择的行事侧重，不改变公开身份、出身、门派或主线事实。

| 行动身份 | 初始专长 | 起始区域影响 | 门派 / 势力影响 | 首条支线 | 代价 |
|---|---|---|---|---|---|
| 临时护车人 | 首次护送站位教学；护送目标相邻时首次招架检定 +10【建议值】 | `rg_guanzhong` 官道驿点先显；完成 C01 后标出平阳镖路 | 威信镖局观察值 +10；不是 L1 | `q_11_side_01`“空车暗号” | 对四侠的首次口才无加值 |
| 江湖见证人 | 首次止战 / 说情检定 +10【建议值】 | 松林侧径与伤者点先显；甘亭仍按剧情开放 | 太岳四侠关系 +5；不视为其成员 | `q_11_side_02`“金钗回礼” | 不提前获知镖车暗格 |
| 驿路勘验人 | 首次足迹 / 封印辨伪检定 +10【建议值】 | C01 后提前标出 `rg_hedong_jinzhong` 的甘亭方向 | 清宫只记“可用线人”0 级接触，不给官籍 | `q_11_side_03`“错伤盐商” | 开局补给少一份任务药包 |

“起始区域影响”只指首批地图知识与支线标记；肉身苏醒点始终为西安府东出官道，三项都会进入 `q_11_main_c_01`。专长在 `q_11_main_c_02` 后只作为已完成教学记录，不形成永久职业。

### 2.3 开局四段节奏

| 段落 | 目标 | 教学 | 失败保护 |
|---|---|---|---|
| 醒于官道 | 辨认年代、检查携带与外来压制 | 书眠结算、地图、装备 | 误走时由驿卒引回官道，不消耗任务时限 |
| 临时互保 | 接受周威信短程雇请或在五格外观察 | 护送目标、队列、身份 | 拒绝雇请仍可随四侠进入松林 |
| 松林拦镖 | 观察明镖 / 暗镖矛盾并处理双方倒地者 | 降服、士气、撤离 | 主角倒地后被带至甘亭，丢失首个关系加成但不断线 |
| 夜宿甘亭 | 见证连环误会并确认双刀 | 证词、立场、限时选择 | 漏听梦话时由第二次梦话或官差口供补证 |

目标总时长 35–50 分钟【建议值】。首战不是杀敌测验：以降服、停战或双方撤开且无人死亡结束，才登记非致命证明 `songlin_jiebiao`。

### 2.4 首个选择与分线时点

`dc_11_01` 位于松林冲突收束前，完整选项见 `design/story/11-yuanyang.md` §5.2。它只形成第一次倾向：止伤、护车、查暗格或替四侠保全面子全部进入共有幕 C02。真正的首条分线由甘亭夜话末的 `dc_11_02` 决定。

| 节点 | 本文接口 | 不得发生 |
|---|---|---|
| `dc_11_01` | 写入首次关系、见证与非致命状态；全部汇合 C02 | 不在角色创建菜单预锁正邪线 |
| `dc_11_02` | `stance_11≥+1` 进正线，`≤−1` 进邪线，0 取该节点最后选择 | 不因属性不足让所有选项同时锁死 |
| 隐藏趟子手 | 可提前知周家受制并获得护车身份选项 | 不自动知道真刀位置，不跳过两节点 |

### 5.2 原著线 `tsp_11_canon`

原著线不是失败线。满足以下条件即可在任一最终立场完成：

1. 四个锚点全部完成，且 `flag_11_truth_known`、`flag_11_motto_revealed` 为真。
2. 在 `dc_11_08` 完成合法归刀或独占选择，任何必要证人未处于 `unknown`。
3. 若圆满条件任一不成立——例如发生击杀、证明少于三、有人未获救或玩家独占双刀——结算本地 `z_canon` / `x_canon`。
4. 获得 `it_tianshu_11` 与 `tsp_11_canon`；效果完全引用 `design/13`，本章不复制 Z4 或效果抗性数值。

### 5.3 改命线 `tsp_11_fate`

```text
allKeyNpcAlive = every(14 keyNpcIds, lifeState in {alive, fate_rescued})
chapterZeroKill = chapterKillCount(ch11_yuanyang) == 0
nonLethalProof  = distinct(nonLethalProofKeys).length >= 3
relinquished    = finalBladeCustody != protagonistExclusive
fateQualified  = allKeyNpcAlive && chapterZeroKill && nonLethalProof && relinquished
```

十四人集合为袁冠南、萧中慧、萧半和、林玉龙、任飞燕、周威信、卓天雄、太岳四侠、袁夫人、杨夫人、刘於义。只接受 `alive` 或既有 `fate_rescued`；`unknown` 不算存活。本书没有命定死亡被救回，正常不会发送新的 `companionFateRescued`。

四个证明键只来自四场不同冲突：

| 键 | 合格收束 | 不合格 |
|---|---|---|
| `songlin_jiebiao` | 松林双方降服、停战或撤开，四侠与镖师无人死亡 | 同场反复击倒刷次数 |
| `dumo_zhazhuo` | 利用毒墨、威慑或撤离逼卓退去，无人死亡 | 最后补刀或把俘虏处决 |
| `zizhu_tuizhuo` | 庵中平民已安全，卓被退、擒或自行离开 | 只保护主角而让庵中人受害 |
| `xiaofu_weizhan` | 围府开放平民通道，官兵与宾客均无死亡 | 把无限刷出的援兵当计数来源 |

击杀任何普通敌人也会令 `chapterZeroKill=false`。降服、劝降、俘获与击杀经验同为 ×1.0，引用 `design/09` 与 `design/13`，所以改命不是经验惩罚路线。

## 10. 本书界特色系统

本界用两个彼此咬合、但不互相代替的机制承载短篇气质：**喜剧夺刀**负责“东西为何总在换手”，**仁者非致命解决**负责“有能力伤人时为何仍能收手”。两套系统均为 **（原创扩展）**；原著只提供多方争刀、误会反转和“仁者无敌”的叙事依据。

### 10.1 喜剧夺刀：目标与边界

夺刀系统不是随机偷包，也不是把唯一神兵复制给多名角色。它追踪两柄真刀、赝品、外匣、信息与保管合法性，使玩家能靠观察、布局、关系和战斗控制改变易手过程，同时保证四个锚点仍然发生。

设计目标：

1. 每次易手至少改变“谁以为刀在哪”和“谁能证明保管权”之一，不做无意义重复追逐。
2. 喜剧来自角色动机与信息错位，不来自羞辱、随机失忆或把关键人物写傻。
3. 两柄真刀是一个唯一装备的两件剧情实体；合并结算后才形成一件 `eq_yuanyangdao`。
4. 锚点前 `anchorLocked=true`：玩家可暂管、调包或封存，但不能带离书界、出售、拆解或锻毁。
5. 每个夺刀节点都有战斗、交涉 / 欺敌和撤离 / 追踪中至少两种完成方式。

### 10.2 双刀与认知状态

| 层 | 字段 | 取值 / 规则 | UI 表现 |
|---|---|---|---|
| 实物 | `bladeRef` | `yuan_true`、`yang_true`、`decoy_short`、`outer_case` | 只在玩家验明后显示真伪；未验显示“某柄刀 / 长盒” |
| 位置 | `holderRef` | NPC、队伍任务背包、官库或场景容器引用 | 时间线显示最后确认地点，不做实时透视 |
| 合法性 | `custodyBasis` | `commission`、`family`、`temporary`、`court_seal`、`common_trust`、`none` | 保管标签与可交割对象 |
| 认知 | `beliefByActor` | 每个阵营对“持有人 / 真伪”的独立判断 | 证词卡以“亲见 / 听闻 / 推断 / 已证伪”区分 |
| 封签 | `sealState` | 完好、可疑、破损、重封及见证人 | 不用颜色作唯一信号；提供文字与图形 |
| 易手史 | `transferLedger` | 有序、不可删除的易手事件 | 玩家可回看，但未知字段保留遮罩 |

真实位置不因 NPC 猜错而改变；认知也不因玩家打开菜单自动同步。剧情只能通过已登记的验刀、目击、口供、痕迹或合法文书更新 `beliefByActor`。赝品可误导人物，但不得触发 `anc_11_04`、授予 `eq_yuanyangdao` 或解锁刀铭。

### 10.3 易手动作与喜剧强度

| 动作 | 前置 | 结果 | 失败结果 |
|---|---|---|---|
| 验刀 | 持有、近看或可信见证人 | 写真伪与封签事实 | 只写“未能辨明”，不反向生成假事实 |
| 暂管 | 当事人同意、战后缴械或任务保护 | `custodyBasis=temporary`，设置归还时点 | 关系下降或引出跟踪，不直接偷走 |
| 调包 | 有赝品、容器接触和敏捷 / 手法条件 | 两物交换，目击者认知按证据更新 | 留下可追索痕迹 |
| 封存 | 官凭、清宫关系或两名见证人之一 | 生成封签与交割责任 | 无合法性时只是强占 |
| 护送 | 指定目的地与持有人 | 启动 09 护送遭遇 | 失镖后生成追索，不销毁唯一刀 |
| 交割 | 双方、标的、条件与见证齐全 | 原子更新保管权、承诺和奖励 | 条件不齐不扣物；可改谈判 |

系统每幕维护 `comicBeat` 0–3【建议值】：0 克制、1 误会、2 连环误会、3 闹剧峰值。它只影响台词节奏、动画和部分口才 DC，不直接改伤害或掉落。连续两幕为 3 时下一幕强制回落到 ≤1，避免寿宴认亲和人质段落被喜剧吞没；任一关键人物重伤、失踪或被挟持时立即钳到 0。

“笑点债”用于保证玩家能看懂反转：每次镜头外易手使 `unexplainedTransferCount+1`；进入下一主线幕前必须通过目击回放、痕迹或证词解释，且值不得超过 1。系统禁止为了笑料在 UI 外连续调包。

### 10.5 喜剧夺刀 UI 要点

- **双刀轨迹**：以两条并行时间线展示最后确认位置；未知段为虚线，赝品用文字“疑似”而非只用颜色。
- **认知切换**：玩家可切换“我所知 / 镖局所信 / 官府所信”，但不能查看未获得的信息。
- **交割预览**：明确显示交出哪一柄、换回谁、是否有书面承诺、是否影响改命与装备归属。
- **一次确认**：临时保管可普通确认；出售、毁坏、独占、终局交割均因 `anchorLocked` 被拒或二次确认。
- **喜剧节拍**：动画可快，但易手后必须停留一张可读摘要卡；支持降低镜头晃动与跳过重复动画。

### 10.6 “仁者无敌”非致命解决：目标与规则

本节配置的是取得天书前也可使用的章节解法；`design/13` 中天书本义“点到为止”是通关后才解锁的全局能力，两者不可倒置。章节内非致命解法通过 `design/09` 已有切磋、投降、降服、俘获、撤退与战后处置落地，不另造第二套气血或死亡规则。

合格解法分五类：

| 类别 | 战斗 / 任务条件 | 结果 | 可计正式证明 |
|---|---|---|---|
| 降服 | 合法“点到为止”脚本、切磋或任务允许的 0 HP 转降服 | 单位退出战斗、存活、战后可交谈 | 是，若该遭遇绑定四键之一 |
| 劝退 / 停战 | 士气、证据、关系或口才满足；双方停止敌对 | 不要求削至 0 HP | 是 |
| 欺敌 | 如毒墨骗局，证据链完整且目标主动撤离 | 不把说谎自动等同邪恶或成功 | 是，仅 `dumo_zhazhuo` |
| 撤离 / 护送 | 所有保护目标抵达安全区，敌方仍可存活 | 任务胜利，战利品减少 | 是 |
| 缴械 / 俘获 | 先通过 09 的控制与战后处置，再由有权主体收押或释放 | 俘虏不可被当作物品 | 是 |

`chapterKillCount` 统计本界内玩家及受控单位造成的确认死亡，换线、读档后的合法进度分支、队伍解散都不能清零。召唤物、持续伤害和环境推落须归因到责任单位；非玩家阵营互杀若玩家主动诱发，同样计入。训练木人、假身和本来非生物机关不计“人类击杀”。

四个证明键只来自 `songlin_jiebiao`、`dumo_zhazhuo`、`zizhu_tuizhuo`、`xiaofu_weizhan`，按集合去重；同一场反复降服、重进地图或换一种收束不增加计数。改命要求其中至少三个不同键，同时 `chapterKillCount==0`，二者不能互相替代。

### 10.7 怜悯意图、倒地与误杀保护

玩家在允许的遭遇中可为单个攻击设“留手意图”**【建议值】**。该标记只让任务脚本在伤害结算后请求合法 `surrender/subdue`，不修改 Z0–Z10 伤害公式，也不保证 Boss 必然接受。

```text
若 target 为 human 且 encounter.nonLethalEligible
且 damage 将 target.hp 降至 0
且 target 不是剧情明确不可降服状态：
  请求 design/09 的降服收束；成功则 state=surrendered，killDelta=0
否则：
  走 design/09 正常倒地 / 死亡 / 战败流程
```

| 风险 | 预警 | 补救 / 后果 |
|---|---|---|
| 追击、反击或 DOT 会越过留手 | 行动确认前显示“可能致死来源” | 可禁用对应自动反应；若仍确认，后果照记，不暗改随机数 |
| 敌人被第三方补刀 | 时间轴标出高危行动 | 援护、控制、撤离；玩家主动诱发仍计责任 |
| Boss 不接受降服 | 展示其当前破局条件 | 用证据、缴械、护送目标或阶段弱点先解除 |
| 普通通关已经有人死亡 | 改命卡显示不可满足 | 仍可完成 `canon`，不删主线或天书 |
| 误操作攻击投降者 | 攻击按钮二次确认 | 伤害与阵营、品德、击杀后果照常结算 |

## 12. 难度与数值要点

### 12.1 D3 定位与硬边界

鸳鸯是低武尾段的 D3 书界：敌人边界 36–48，显示等级上限 48，武运 40。它比白马的上限高 2 级，但仍不靠超限高手、额外血条或天级武学制造难度；核心压力来自四方混战、保护目标、易手信息差与零击杀约束。

```text
enemyStatMul(D3) = 0.85 + 0.05×3 = 1.00
精英词条数 = floor(3/3) = 1
基础 Boss 阶段数：D1–D3 = 1
等级上限 = 48；本界登记 capExempt 数 = 0
```

“假盲揭破”“援军抵达”“合击教学”和“谈判开放”都是同一阶段内的脚本状态变化，不得借此给六个遭遇追加第二条完整血条。太岳四侠和林任夫妇是同阶段多单位遭遇，也不按多阶段 Boss 计。

### 12.3 模板 Boss 完整数值复算

统一计算顺序如下；基础属性函数、派生属性公式和取整点只引用 `design/03`，伤害结算只引用 `design/04`：

