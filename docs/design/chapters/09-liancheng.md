体验弧线是“乡野误会 → 牢狱辨心 → 菊窗毒局 → 雪谷照心 → 佛腹毒金”。玩家不是狄云的替身，也不能凭全知视角跳过入狱、雪谷或天宁寺；玩家的力量在于保存证据、承担代价、给当事人选择，并决定自己是否也把人当作筹码。

### 1.3 设计支柱与边界

1. **真相分层**：目击、口供、实物、时序必须互证；高 `speech` 只能让人开口，不能令伪证变真。
2. **低武不低险**：危险来自狭窄牢房、饥寒、雪坡、毒物和背叛，而非人人拥有高品武学。
3. **改命有代价**：丁典、凌霜华双救必须牺牲神照经捷径或宝藏分成；不能同时拿满关系、秘籍捷径与金银。
4. **正邪均可通关**：正邪是证据用途与待人方式，不是天书资格；命运轴只由 `dc_09_03` 决定。
5. **财富不可失控**：天宁寺毒金是剧情危险物，不进入无限经济循环；处置只改变关系、证据与结局修饰。
6. **每幕有非战斗路**：正邪每幕至少两种解法，至少一种用调查、潜行、医毒、书画、口才、人情或交易完成；奖励差保持 ±10%。

## 2. 穿越开局

### 2.1 共通苏醒与不可改写事实

主角在鹿鼎书界约 1690 年离界，依《长生诀》书眠约 15 年，于本作推定约 1705 年苏醒。默认苏醒地点是辰州府沅陵南郊的麻溪铺 **（村址待考）**；另两种身份以书灵安排的合理履历在荆州府醒来。主角只保留基准允许的 1/1/1 核心武学、6 件装备、永久学识与跨书状态，不携带旧门派身份、金钱、普通物品或队友。

无论身份如何，`q_09_main_c_01` 都会使狄云蒙冤入狱。身份只改调查顺序、初始通路、门派引荐和第一条支线，不允许狱卒开局直接放人，也不允许熟读者一句话揭开连城剑谱。

### 2.2 三种开局身份

| 身份 | 苏醒地点 / 起始区域 | 初始门派与势力影响 | 首条支线 | 首幕差异 |
|---|---|---|---|---|
| 麻溪铺药铺帮工（默认）**（原创扩展）** | `sc_09_maxipu`；`rg_huxiang` | 梅念笙—戚门传承好感 +1 档；万家门陌生；不等于已拜师 | `q_09_side_01`“药篓与旧伤” | 可辨普通跌打伤和药材账，但不能直接识出金波旬花；随送药 / 带路队伍去荆州 |
| 荆州府行栈抄书人 **（原创扩展）** | `sc_09_jingzhou_hangzhan`；`rg_jingxiang` | 万家门可疑度 −1 档、行栈关系 +1；可申请门客考核，但不是门人 | `q_09_side_02`“砖灰账” | 先见万府请帖、异常砖料与货签；`art` / `lore` 检定多一个账页入口 |
| 荆州大牢狱卒（隐藏）**（原创扩展）** | `sc_09_jingzhou_laoyu`；`rg_jingxiang` | 官府关系 +1、丁典初始警戒 +1；滥权即失去身份 | `q_09_side_03`“少一串钥匙” | 提前看到换班簿与固定受刑记录，随后被派去万府押送差事；仍不能私放囚犯 |

隐藏身份解锁沿用 `design/13` §6.4.2。三身份初始战斗强度等价：只给信息入口与关系偏置，不额外发高品武学。若某身份使首条支线无法进入，则在第一幕结算时以书灵投递线索补入口，不补双份奖励。

### 2.3 第一选择与身份收束

第一选择节点固定为 `dc_09_01`“谁拿到第一份证据”，完整选项与立场变化见剧情稿 §2.3、§5.2。此处只约束接口：

| 选择方向 | 路由 | 身份反馈 |
|---|---|---|
| 交戚芳并留副本 | `q_09_main_z_01` | 药铺身份可用伤情作旁证；抄书人能复制账页；狱卒能保押票副联 |
| 封存并继续查 | 暂不定线 | 三身份各保留一类独立证据，不改变锚点一 |
| 交万圭换内宅身份 | `q_09_main_x_01` | 抄书人最易进入；另两身份需额外交易或易容 |
| 交官并暗留副本 | `q_09_main_x_01` 双面变体 | 狱卒入口最短，但被发现后永久失去官府身份 |

开局完成后，身份不再提供永久属性加成；其价值沉淀为联系人、证据来源和首条支线状态，避免重复选择中的最优解锁死。

### 6.3 任务链互锁与失败回退

- 开局三任务互斥为“首条支线”，但在第一幕结束后开放其余两条的无身份版本；每条奖励只结算一次。
- `q_09_bond_02` 与 `q_09_qiyu_03` 能提供改命前置，但主线自身另有同类别证据，错过支线不会锁 `dc_09_03`。
- `q_09_bond_04/05/06` 改写人物生死时，使用 `design/18` 的 `fate_rescued` 与 `canonicalDied`；不改变 `tsp_09_*`。
- 门派、羁绊与营生若共享同一事件，只指定一个 `economySource`；不可同时领取任务银两、职位薪酬和门派月钱三份。
- 任何涉及空心菜的任务都把她作为受保护人物，不作为物品、抵押、诱饵或可牺牲资源。
- 七个奇遇根任务均至少有一条非战解；拒绝赌博、退派、放弃资源点都不使线索永久消失。

## 10. 本书界特色系统

### 10.1 共通原则与接口边界

三个特色系统都属于章节玩法层：它们维护 `lc09.*` 局部状态，向任务系统发受控事件，不直接改人物属性、Buff、武学层数或结局。任务状态机与奖励命令见 `design/12`，地形及门禁见 `design/08`，Buff 与解除见 `design/06`，战斗阶段见 `design/09`，经验、天书之力和余韵见 `design/13`。

共通不变量如下：

- 调查成功可以避战、削弱阶段或改变站位，但不能删除五个锚点。
- 失败必须给“付出时间 / 关系 / 补给后继续”的出口；只有剧情明确的不可逆生死窗可关闭分支。
- 同一事实只由一个权威状态键结算；UI 推断、Ink 台词和战斗演出均不能直接写结局。
- 每个非战解的角色经验与对应战斗路径保持 `0.90R≤reward≤1.10R`，沿用 `design/02` §7.3 与 `design/12`。
- 所有随机路遇使用章节 RNG 分流；谜题答案、证据真伪和资源扣除不随读档重掷。

### 10.2 狱中与雪谷生存

#### 10.2.1 双阶段状态机

狱中不是逐日模拟四年，而是六个关键时段的压缩生存段；每段先选一项维生行动和一项调查 / 关系行动，再推进剧情时钟。雪谷按“入谷准备—雪崩封锁—严冬共生—雪融回程”四阶段运行，每一世界日结算一次队伍补给。两者共用账本结构，但不把狱中余粮带入雪谷。

| 阶段 | 共享量 | 主要输入 | 归零后果 | 恢复方式 |
|---|---|---|---|---|
| 牢狱 `prison` | 口粮 `food`、伤势照护 `care`、丁典 / 狄云互信 | 送饭、换班、医药、钥匙、守约 | `food=0` 时本段挂既有 `bf_xuruo`；`care=0` 时不能执行高风险越狱动作；不即时死亡 | 分食、换药、向狱卒交易、放弃一次调查 |
| 雪谷 `snow_valley` | 口粮 `food`、燃料 `fuel`、庇护 `shelter`、药材 `medicine` | 入谷携带、马匹 / 枯木、山洞、搜救、天气 | 缺粮累计 `foodDebt`；缺热源由 `tr_xuedi/tr_shenxue` 正常施加 `bf_shouhan/bf_hanqi`；伤员无药则延迟救援 | 狩猎、拾柴、修洞、节约、队友分工、雪融补给 |

雪谷一单位口粮供一名成年人一日；每日消耗 `foodNeed=activeAdultCount`。燃料需求采用 `fuelNeed=max(0,2+stormGrade−shelterGrade)` **【建议值】**，其中暴雪 `stormGrade=2`、普通雪夜 `=1`、无雪 `=0`，庇护品级 0–3。未满足的每一点写入 `coldExposure`，再由地形 / Buff 接口结算，章节不得另扣一遍气血。

`foodDebt` 每累计 2 点，在下次遭遇开始时挂一次既有 `bf_xuruo` **【建议值】**；进食先清债再补库存。系统不提供“食用遗体”按钮，不把任何人物遗体序列化为食物资源；花铁干的相关行为只以剧情、证据和关系后果呈现，不能成为最优生存配方。

#### 10.2.2 行动、失败与战斗接口

| 行动 | 检查 | 成功 | 失败 / 回退 |
|---|---|---|---|

### 10.3 识破谎言与证据链

#### 10.3.1 不是读心术

系统判断“某项说法是否被材料支持”，不把人物永久标成“说谎者”。证据分为口供 `testimony`、文书 `document`、实物 `material`、时序 `chronology` 四类；同一来源的抄本仍只算一类。状态依次为 `heard → suspected → corroborated/contradicted → resolved`：

- 出现一项内部矛盾，只写 `suspected`，开放追问，不直接显示真相。
- 来自两个独立类别的支持可写 `corroborated`；两个独立类别的反证可写 `contradicted`。主线的毒棺、夹墙均沿用“候选三项取二”。
- `speech` 负责让人继续开口；命中证词、利益、忌讳三个线索时每项令 DC −5、合计最多 −15，引用 `design/12`，不把高口才当测谎仪。
- `lore/wis/art/med` 只检查各自可理解的载体；玩家输入一个正确专名但没有角色证据时，不写状态。
- 对质失败仅降低关系、推进对方警戒或换一条取证路；除生死窗外不销毁全部证据。

| 主链 | 候选材料 | 两项互证后的接口 | 后续价值 |
|---|---|---|---|
| 早期构陷 | 财物清单、桃红口供差异、提前写成的押解票 **（原创扩展载体）** | `lc09.evidence.early_case` | 不阻止入狱；降低后续万府对质门槛 |
| 菊窗毒棺 | 药材单、花房残叶、棺工口供 **（原创扩展调查）** | `lc09.poison.suspected` | 开双救准备、绕凌府正门 Boss |
| 雪谷真相 | 冰坡痕迹、幸存者证言、花铁干矛盾口供 | `lc09.evidence.snow_truth` | `dc_09_06` 可澄清、封存或利用 |
| 万府夹墙 | 桃红证词、砖灰新旧、万震山砌墙动作 | `lc09.evidence.hidden_wall` | 开暗墙 / 会审路径，免清空普通弟子 |

### 10.4 唐诗剑法密码

#### 10.4.1 三槽解码

谜题只使用剧情稿确认的三类输入：棺盖数字或凌霜华本人授予的数字、唐诗剑法 / 剑谱次序、《唐诗选辑》对应版本。正文和 UI 都不伪造诗句，也不在考据完成前展示完整密码。

| 槽 | 合法来源 | 缺失时替代 | 作用 |
|---|---|---|---|
| 数字 `numbers` | 原著线棺盖信息；改命线丁凌亲授 | 可信拓本与两份见证交叉确认 | 决定取字序列；不能由玩家现实知识直接填写 |
| 剑序 `swordOrder` | `sk_tangshijian`、`sk_lianchengjianli`、三门旧债 | 言 / 万 / 戚三路剑痕两份互证 | 排除错序，并开放伪码制作；学会剑招本身不等于知道宝藏 |
| 诗书 `anthology` | 麻溪铺旧物、万府原本、江南书坊异本 | `q_09_qiyu_05` 保存漂页后校本 | 提供可检索文本载体；只显示经版本审校的片段 |

三槽齐全后，`lore≥30` 或 `art≥30` **【建议值】**可完成正解，唯一写入 `sc_09_tianningsi` 指向；能力不足时可请狄云 / 戚芳辨识童年记忆，或完成校本支线，代价是时间与关系而非永远卡关。制作可被识破的伪码需 `art≥40`、保有可靠拓本并进入 `dc_09_08`，只改变敌人到场顺序，不产生第二处真宝藏。

候选提交采用确定性状态：同一组输入只判一次，错误候选保留“哪一槽矛盾”的反馈；只有新增证据或更换校本后才允许新提交。暴力枚举不发经验，正确解码按书界级谜题经验结算。

```yaml
schemaVersion: lc09-feature.v1
chapterId: ch09_liancheng
feature: poetry_cipher
stateKey: lc09.cipher
inputs:
  numbers: verified
  swordOrder: corroborated
  anthology: verified_edition
checks:
  any:
    - { skill: lore, atLeast: 30 }
    - { skill: art, atLeast: 30 }
fallbackQuestRefs: [q_09_faction_05, q_09_qiyu_05]
success:
  destinationSceneRef: sc_09_tianningsi
  writeState: lc09.cipher.destinationKnown
  emit: { name: lc09CipherSolved, chapterId: ch09_liancheng }
forgeOption:
  choiceRef: dc_09_08
  artAtLeast: 40
  requiresReliableCopy: true
```

UI 是三只可折叠资料托盘与一条“候选路径”预览，不要求玩家在屏幕键盘输入古诗。读屏模式按证据取得顺序朗读；关键数字可复制为游戏内便笺但不能复制到聊天自动求解。成功后地图只标“荆州府城南方向—天宁寺”，进入寺内仍要识毒、疏散或处置争宝者，不能以解谜代替锚点四。

### 12.3 入场、终盘与 Boss 威力比

威力指数只用 `P=G(effGrade)×L(effLayer)`，其中 `L(n)=0.5+0.1n`；伤害 Z1 再且只再除一次同级 `P_ref`。三组关键核算如下：

| 对象 | 有效状态 | P 核算 | 对血刀老祖 D4 指数的比值 |
|---|---|---:|---:|
| 外来天上 12、真实 10 重 | 低武 −4 → 地中 8，有效 8 重 | `2.20×1.30=2.86` | `2.86/(3.12×1.05)=0.872≈0.87` |
| 本土神照经天下 10、有效 8 重 | 本土不降品，低武截到 8 重 | `2.80×1.30=3.64` | `3.64/(3.12×1.05)=1.111≈1.11` |
| 血刀老祖地上 9、有效 8 重 | 具名本土武学 | `2.40×1.30=3.12`；D4 参照 `3.12×1.05=3.276≈3.28` | 1.00 |

因此入场携带的顶级外来武学仍能压制杂兵，但低于终盘首领；本界练成神照经后才获得约 11% 的终盘指数优势。这个比较只用于内容曲线，不把难度 HP / 攻击倍率误乘进玩家实际 `P_actual`，正式伤害仍完整走 `design/04`。

### 12.6 失败保护与数值验收
