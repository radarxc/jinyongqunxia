**首书入场属性。** 长白山初眠的可配项固定为臂力、根骨、内息、悟性、身法、定力；福缘、魅力保留但默认不参与配点（AR-27）。在 `design/03` 完成配点池与上下限定稿前，本章只采用六项各 50、合计 `6×50=300` 的均衡期望 **【建议值】**，不把 300 写成玩家必须拥有的预算，也不另造派生公式。

**定年依据与叙事用法。** 640 年唐灭高昌、置西州并以交河为西域军政节点；702 年庭州升置北庭都护府。这使“亡国六十二年后，故城之下仍流传王室藏物”的传说有明确时间纵深：`702−640=62`。游戏将高昌王室藏宝、秘道和藏宝图继续视为小说核心，具体迷宫结构仍是虚构；唐代行政史只解释为什么旧城、遗民、戍军和商队会在同一空间相遇。702 年严格说处武周年号，本作所称“唐代化”是广义隋唐文化史分期，不把“长安二年”误写为唐高宗年号。**（原创扩展）**

### 1.2 主题与体验支柱

| 支柱 | 玩家体验 | 系统承载 |
|---|---|---|
| 大漠求生 | 水、风向、坐骑与退路比正面硬闯更重要 | 旅行补给、`tr_shadi`、`tr_liusha`、风沙事件 |
| 人先于藏 | 高阶遗物与受困者同时出现，选择必须留下永久代价 | `dc_10_07`、迷宫坍塌、不可逆确认 |
| 旧怨问证 | 玩家查清事实，却不能替当事人自动和解 | 证物、双边信任、`old_case_complete` |
| 放下而非占有 | 天书来自离开宝藏与情感执念后的选择 | 四锚点、东归、两种天书变体 |
| 低武重建 | 外来绝学受压后，以本土内功、拳脚、兵器与轻功补齐栏位 | §9 产出、门派五级成长、支线师父 |

### 1.3 时长与节奏

| 内容桶 | 占比 | 时长 | 核心内容 |
|---|---:|---:|---|
| 主线 | 45% | 3.6 h | C01–C05 与选定的正 / 邪 8 幕 |
| 开放内容 | 35% | 2.8 h | 20 条支线中的选择性游玩、10 条奇遇链、12 个触点 |
| 成长整备 | 15% | 1.2 h | 门派晋升、武学补栏、营生、冲穴辅助 |
| 余韵 | 5% | 0.4 h | 东归后告别、资源结算、书眠 |

本界不是用更高数值制造压力，而是用“补给有限、路径可错、关系不能全得”的短篇密度形成难度。D2 仍须保留失败分支、补救路径与不可逆选择，不能等同无挑战。序章已教移动、调查、基础战斗和第一次书眠，本界不重复弹窗；它负责第一次完整书界循环：探索与补给 → 营生 → 组织职责 → 正邪选择 → 天书结算 → 休眠事件 → 苏醒取舍预演。

### 1.4 原著与扩展的分界

李文秀幼年逃亡、狼皮旧事、部落关系、血显地图、高昌迷宫、瓦耳拉齐与马家骏旧怨及李文秀东归，均取自原著情节骨架；结局必须保留“那都是很好很好的，可是我偏不喜欢”的意旨：旁人眼中的美满不能替李文秀选择所爱与去向。具体先后与细节须按三联 / 广州修订版逐字复核，见 §13。玩家介入、正邪任务结构、可加入组织、经营、资源点、机关解法、人物招募与救下命定死者均为 **（原创扩展）**。

## 2. 穿越开局

### 2.1 长白山苏醒与西行过场

主角承接序章 `ch00_yuenv`：约前 482 年离开越国，阿青传授《长生诀》第一层后，在长白山遭雪崩、埋入洞穴并不由自主入眠；`702−(−482)=1184` 年后在原洞苏醒。初眠、沉睡配点和不老规则只引用 AR-26、`design/02`、`design/03` 与 `design/25`，本章不重定义。主角以唯一身份“异乡行者”进入第一本正式书。

苏醒后用 45–60 秒不可迷路、可整段跳过的水墨过场完成长白山 → 关中 → 河西 → 西州西行 **（原创扩展）**：残卷指向高昌旧物，主角随驿路、军粮车和粟特商队换程，不把 3,000 余公里表现为瞬移。过场只交代旅途，不结算营生、关系、经验或物品；第一帧可操作画面直接落在 `rg_xiyu_beijiang` 的 `sc_10_fengshi_feiyi`。

年代揭示分三层，避免讲史压住开场：画面题签“长安二年（702）·西州以北” **（原创扩展）**；残卷旁白点出“高昌国亡已六十余年，故城仍在”；驿卒对白提及庭州新置北庭都护府。玩家只需理解“这里已是唐代西域”，不要求记官制。

书灵 / 旁白文案要点：

- “雪压洞门，再开时已过千年。”——说明睡眠跨度，不宣称主角知道全部史事。
- “城国已亡，城与人仍在。”——把高昌亡国史与小说迷宫传说分开。
- “第一卷，从一囊水、一匹白马和一个不肯替别人选择的人开始。”——落到“放下”书眼。
- 禁止写阿青随行、书灵代替主角旅行，或把西州、庭州说成同一城。

### 2.2 M1 冷入口最小场景

M1 只制作一个区域 `rg_xiyu_beijiang`，优先完成场景 A；场景 B 是同一区域的可选扩展，不阻塞 M1。两场景均为 **（原创扩展）**。

冷入口只需一段可本地化对话：沈青禾问“从东边来的？水先拿稳。这里是西州北路，往北便是庭州地界”；远处成年李文秀视觉代理牵白马停步，提醒“风要转了，别追着旧路走” **（原创扩展）**。主角可答“问年份 / 问故城 / 先帮收散落药囊”，三项汇回同一出口，不建路线分歧。

可选小遭遇是两名逐水盗抢夺驮囊：1 个教学目标“护住驮囊 3 回合”或直接退回安全院；胜负都不伤具名人物、不掉唯一物、不阻断对话。序章已经教过移动和基础攻击，本战只验证就地开战、撤退与战后恢复。M1 可不做此战。

**M1 精确停止点：**过场可播 / 可跳 → A 场景加载 → 玩家移动 → 完成上述对话 → 东口亮起 → 自动存档可读。出现“第一卷·白马啸西风”题签并恢复自由操作即通过；无需进入 B、无需触发 C01 锚影，也无需交付遭遇、营生、门派、迷宫、天书或下一次书眠。

### 2.3 冷入口后的正式开局

正式版在 M1 停止点之后，由沈青禾用一囊水与一匹驮马换取短程护送。旧鞍上的褪色黄线触发 `q_10_main_c_01`“黄沙旧页”；玩家在书页锚影中有限介入多年前的追逐，不是肉身再次穿越。成年李文秀视觉代理承载回忆镜头；文字可说明“当年的她”，但不制作、展示或操控幼态角色。

- 把李文秀的东归决定变成玩家好感奖励；
- 用宝藏或天书复活 C01 多年前已经发生的死亡；
- 把邪线短约洗白为陈达海等人无条件永久入队；

## 6. 支线任务

### 6.1 任务配置原则

- 本节配置 30 条有 ID 的内容：普通 10、门派 4、人物羁绊 6，合计 20 条支线；另有完整奇遇 10 条，分布在 12 个区域触点。

## 10. 本书界特色系统

### 10.1 高昌迷宫的设计目标

高昌迷宫不是随机刷新的地下城，而是把“地图不完整、足迹真假、退路与宝藏冲突”组合成一座可验证、可回溯、可留下永久选择的叙事迷宫。原著只提供迷宫与寻宝情节骨架；房间拓扑、机关语言、状态机和 UI 均为 **（原创扩展）**。

系统目标：

1. 玩家可以迷路，但不会因随机重排永久失去主线。
2. 地图、足迹、灯火与声音是四种独立证据，任何两种都可找到保底出口。
3. 轻功 qg2 只提供捷径，qg3 只提供隐藏奖励，主线不存在 qg3 硬锁。
4. 取得遗物与救人必须在同一倒计时中冲突，且选择有清晰、永久、可预览的后果。
5. “高昌迷宫”是小说场景，不复原现实遗址结构，也不鼓励现实盗掘。

### 10.2 空间层与进度状态

| 层 | 场景 | 主要地形 | 核心问题 | 主线保底 |
|---|---|---|---|---|
| 外环 | `sc_10_gaochang_migong` 入口至第一石门 | `tr_shadi`、`tr_suishi`、`tr_migong` | 地图载体是否可信；第二足迹属于谁 | 血显线索 + 可见风痕 |
| 回环 | 迷门、灯室、假鬼声廊 | `tr_migong`、`tr_jiguan`、`tr_shizhen` | 声音、灯火与脚印互相矛盾 | 每两次错误后开放回到已知节点的粉笔线 |
| 证室 | 壁画厅、旧针证物区 | `tr_shibi`、`tr_shinei` | 身份与旧案的多源问证 | C04 已取得的第二足迹 + 任一人物证词 |
| 内环 | `sc_10_gaochang_inner`、通风井、坍塌区 | `tr_jiguan`、`tr_shibi`、`tr_dongku` | 退路能否独立于藏宝 | 主线 qg2 绳路 / 机关复位二选一 |
| 离场 | 无水沙路与界碑 | `tr_shadi`、`tr_liusha`、`tr_suishi` | 残图是否害人、谁承担后果 | 烟讯、交水或公议任一路 |

### 10.3 地图碎片与可信度

`it_gaochangditu` 是任务抽象键，不预断言载体是纸图。系统维护四层知识：

| 层 | 来源 | 能回答什么 | 可能被伪造 |
|---|---|---|---|
| `routeMarks` 路线记号 | 手帕 / 摹本 / 玩家手绘 | 房间相邻关系 | 是 |
| `footprints` 足迹 | C04、奇遇回访 | 最近谁走过 | 可踩乱，不可凭空生成时间 |
| `airflow` 风与水 | 通风井、烛火、水囊 | 哪条路能活着离开 | 否，但可能暂被机关阻断 |
| `testimony` 证词 | 李文秀、陈达海、瓦耳拉齐、马家骏 | 动机与旧案 | 会隐瞒；须双源核对 |

地图可信度不显示为一个“真相百分比”，UI 按每条边显示“亲历 / 摹本 / 他人声称 / 已证伪”。玩家制作假图时只改变可交付副本，不改自己已验证的 `routeMarks`。

### 10.4 机关与失败保护

| 机关 | 读法 | 错误后果 | 合法解法 | 永久性 |
|---|---|---|---|---|
| 转门 | 地面磨痕、风向 | 回到前一环，增加疲劳 | `formation`、`sk_gaochangjiguan`、观察两次或跟向导 | 否 |
| 假鬼声源 | 声音延迟、灯影、第二足迹 | 落石 / 可绕过敌群演出，不即死；演出无独立 HP，不生成必经援军血池 | 找真声源、封一条回音孔、诱敌触发 | 否 |
| 流沙井 | 沙粒流向、绳结 | 位移与补给损失 | qg2、绳索、机关复位 | 否 |
| 三枚旧针证物 | 人物证词与物证 | 误判降低一方信任 | 双源问证；医药 / 机关检定只作辅助 | 证词选择可补，销毁证物不可逆 |
| 内殿坍塌 | 8 个行动轮【建议值】 | 受困者与遗物同时失去 | 先救人或先取物；L4 多一条通风井解法但不取消代价 | `dc_10_07` 确认后永久 |

所有机关失败都回到最近已知安全节点或产生可追索状态，不删除 `it_gaochangditu`、天书或人物生命。只有经过二次确认的 `dc_10_07`、`dc_10_08`、`dc_10_09` 才写不可逆状态。

### 10.6 UI 要点

- **双层地图**：左侧为玩家实走拓扑，右侧为当前载体 / 证词摹本；两者差异用虚线，不自动帮玩家判真假。
- **证据抽屉**：按路线、足迹、风水、证词分栏；每条显示来源人物、取得时间和是否被第二来源验证。
- **路径预览**：长按出口显示预计水耗、行动轮、qg 门槛与是否会进入不可逆节点。
- **可访问性**：声音机关必须同时有字幕、方向箭头和灯光节奏；颜色不作为真假唯一信号。
- **不可逆确认**：`dc_10_07` 明示“取物将永久关闭主改命”，`dc_10_08` 明示生死结算，`dc_10_09` 明示队伍出发后不可撤回。
- **手机端**：证据抽屉默认收起；迷宫节点最小触控尺寸和横屏安全区引用 `design/14`，本文不另定像素。

### 10.8 构建与回放校验

1. 从入口到每个主线节点至少有一条 qg≤2 的路径。
2. 任意节点到 `fallbackExit` 可达，且不依赖已消耗的唯一任务物。
3. `dc_10_07` 前存在至少一条 `safeExitKnown=true` 的可建路线。
4. 假图只能影响交付对象的路由，不污染玩家已验证边。
5. 双刃战的两名具名单位在同一阶段运行，不能以“第二阶段”规避 D2 一阶段限制。
6. 固定种子回放中，同一输入的转门、落石与证据结果逐事件一致。
7. 离开副本后重新进入，已验证证据保留，临时敌群按任务状态重建，不重复发唯一奖励。

## 12. 难度与数值要点

### 12.1 难度定位

白马是序章后的第一本正式书，采用低武 `LOW`、D2、Lv20 上限。它不靠超限高手或多阶段血条制造峰值，而以沙漠补给、地图可信度、保护目标和不可逆选择教会第一次完整书界循环；《天龙八部》作为第二本正式书，可从 Lv20 平顺衔接至其既定 Lv35 上限。

```text
enemyStatMul(D2) = 0.85 + 0.05×2 = 0.95
精英额外词条数 = floor(D/3) = floor(2/3) = 0
基础 Boss 阶段数：D1–3 = 1
等级上限 = 20；与天龙上限的余量 = 35−20 = 15 级
```

### 12.2 区域与遭遇等级带

### 12.7 难度模式与失败保护

- 难度模式的 `dm_hp`、`dm_atk`、`dm_rat` 在 D2 之后独立结算，不能把选项难度改写为书界 D。
- 迷宫迷路、护送失镖和资源点失守均提供追索 / 修复路线，不随机删除唯一物。
- `dc_10_07`–`09` 的不可逆只来自玩家看见后确认的选择，不来自 RNG。
- Boss 控制抗性、递减、倒地、投降、拆招与保护目标引用 `design/09`；剧情非杀伤胜利不得偷换成“气血归零即死亡”。
