## 0. 阅读指引

### 0.1 一句话结论

《雪山飞狐》书界是十四卷历史旅程的最后一界：玩家以玉笔山庄外聘门客身份，在暴雪封山、众口异词和闯王宝藏的利害网中保存或操纵证据，最后面对胡斐举刀时的“劈、不劈、还是令刀剑同停”。

### 1.2 主题与体验支柱

1. **众口不等于真相**：宝树、平阿四、陶百岁、苗若兰等人的讲述带有目击范围和利害关系；玩家必须以物证和独立证言交叉核验。
2. **封闭环境放大利害**：断索、缺粮、暴雪、洞窟和悬崖让“先救谁、先信谁、先拿什么”成为可操作抉择，而非纯对白选项。
3. **正邪都有完整理性**：正线守证止杀，邪线控词夺势；两线都有调查、战斗、宝藏处置和终章，不把邪线写成删减内容。
4. **不替胡斐挥刀**：主角可以找齐事实、赢得双方信任并放弃先攻，却不能代替胡斐和苗人凤作人格决定。
5. **最后一卷仍可漫游**：终章之前开放六区，终章之后保留余韵期，让玩家清支线、冲穴、合成传承和整理同伴，再主动进入归梦。

### 1.3 时间与空间结构

| 层次 | 时间尺度 | 玩法方式 | 边界 |
|---|---|---|---|
| 玉笔峰现时 | 暴雪中的一日一夜至黎明 | 封闭场景、证词、限阶段抉择、洞战、雪崖终决 | 阅读对白不消耗墙钟；阶段截止前预警 |
| 胡苗旧案 | 数十年回忆 | 水墨证词重演、可核物证、有限互动 | 田归农、胡一刀、胡夫人、南兰不生成 1780 活体 |
| 六区开放世界 | 主线前后可插入数日 | 走镖、访证、门派、资源、传承 | 主线紧迫阶段暂停自由远行，余韵全部恢复 |
| 雪山余韵 | 第十四天书现世后 | 清支线、招募、冲穴、宝藏后日谈 | 显示等级仍 58，外来压制仍在 |
| 归梦终局 | 玩家主动提交后 | 书眠结算、真实等级显示 70、守卷人决战 | 进入 `ch15_guimeng` 才解除压制 |

### 1.4 时长拆分

按 `design/01` / `design/11` 的 `45% / 35% / 15% / 5%` 预算：

| 内容 | 算式 | 目标时长 |
|---|---:|---:|
| 主线 | `9×45%` | 4.05 h |
| 开放世界与支线 | `9×35%` | 3.15 h |
| 成长整备 | `9×15%` | 1.35 h |
| 余韵 | `9×5%` | 0.45 h |
| 合计 | `4.05+3.15+1.35+0.45` | 9.00 h |

互斥支线和正邪分支不要求首轮看全；上述 9 小时按一条完整主线、约六成支线和一次核心传承合成估算。

### 1.5 入界与离界状态

- 入界时完成 `BS_COMMIT` 后才装载 1780 时代层；飞狐门派职级、资源点经营和城市职位已按书眠规则卸载。
- `echo_13_hushixueshu` 等白名单回响、同伴快照、经脉进度、图鉴和传承匣按各归属文档保留。
- 第十四天书取得后，真实等级立即补到 70；雪山余韵 UI 仍显示 58，区域压制与敌人等级仍按本界执行。
- 玩家在余韵界面确认“赴归梦”后才进入 `ch15_guimeng`；此时显示 70、解除外来压制，并读取 `echo_14_xueshan` 生成终局问答。

## 2. 穿越开局

### 2.1 固定身份与苏醒地点

本节严格承接 `design/story/14-xueshan.md` §2，不把三种履历写成三个互斥身份。

| 字段 | 定案 |
|---|---|
| 真实身份 | 玉笔山庄外聘门客，兼管峰下接引、雪路簿册与临时库房 **（原创扩展）** |
| 苏醒时点 | 杜希孟赴宁古塔后、第一批争盒群豪抵达前 |
| 苏醒地点 | `regionId: rg_liaodong`、`cityId: null`、`sceneId: sc_14_yubifeng_lower_station`、`placeKey: yubifeng_lower_station` |
| 最近城市 | `city_shenyang`，1780 年显示“盛京奉天府” |
| 初始权限 | 峰下栈房、客簿柜、空库箱、吊篮点检；无权进入庄主密室 |
| 初始已知 | 杜希孟留话照帖接客；山上存粮有限；会有携铁盒者来访 |
| 初始未知 | 宝树身份、珠钗暗图、毒谋、清廷围捕、胡斐准确到达时刻 |

主角醒来时只听见雪林兵刃声与吊篮绳索摩擦声。书灵提醒“这是最后一卷，纸边已结霜”，但不解释悬刀结局；第一项可控行为仍是 `dc_14_01` 的救人、取盒或以吊篮名额止斗。

### 2.2 三种可选职责履历

| 履历键 **【建议值】** | 对外职责 | 起始区域 / 可用权限 | 初始关系影响 | 首条支线 |
|---|---|---|---|---|
| `opening_14_jieyin` | 雪路接引：验帖、安排吊篮与救援 | `rg_liaodong`；可先开接引站药箱和备用绳 | 平通镖局、陶氏父子初见 +1；天龙门中立 | `q_14_side_01`“雪路三帖” |
| `opening_14_kuguan` | 临时库管：清点客簿、铁盒暂存与粮册 | `sc_14_yubifeng_manor` 的外库权限提前开放 | 玉笔山庄 +1；宝树会优先试探 | `q_14_side_02`“十日粮册” |
| `opening_14_chuanyi` | 传驿门客：往盛京奉天府送取庄信 | `rg_liaodong` 与 `city_shenyang` 已发现；可用一次驿站折返 | 清宫观察值 +1，苗若兰不受影响 | `q_14_side_03`“宁古塔回封” |

三项只改变第一小时的区域可见性、关系起点和首支线，不锁正邪线、不改变真实身份，也不让玩家开局知道宝藏。任一履历都能在 C01 前取得基础救援工具、看见铁盒并赶上登峰。

### 2.3 开局流程

1. **醒于峰下**：检查佩带与书眠留物；携入武学按 2/2/2 槽位和外来 −2 小品结算。
2. **履历交接**：于姓管家作为设施职能槽交付钥匙、客簿或驿封，不新建静态 `npc_*`。
3. **一项短差**：完成所选支线的第一步，学习时代层、资源和门禁 UI；未选两条在 C03 后仍可接。
4. **听见争斗**：陶氏、天龙门与平通镖局在雪路交错；系统提示 `dc_14_01`，不显示“善 / 恶答案”。
5. **登峰前汇合**：无论选项结果，铁盒至少被玩家见过，主要来客完成登记，吊篮仍是唯一常规登峰方式。
6. **进入共有幕**：提交 `q_14_main_c_01` 的前置状态，主线正文转交 story 文档。

### 2.5 首个选择与防死档

- 先救雪沟中的人：写 `fl_14_saved_roadside`，`morality +5`，但铁盒可能先到他人手中。
- 借验物先拿铁盒：写 `fl_14_box_held`，`morality −3`，但不直接锁邪线。
- 用吊篮名额换停手：写 `fl_14_pass_debt`；若之后失约，扣关系而非封死登峰。
- 玩家战败时由宝树压住局面，主角晚一步随末班吊篮登峰；遗留物由管家暂存。
- 真正第一次定线在 `dc_14_03`，开局履历和 `dc_14_01` 只形成推荐倾向。

## 10. 本书界特色系统

### 10.1 罗生门叙事

#### 10.1.1 目标与边界

系统把同一旧案拆成“事实命题—证词片段—物证—玩家对外版本”四层。讲述顺序、身份和口才都不直接决定真假；系统事实层不可被邪线篡改，玩家只能保存、控发或改写其对外记录。剧情输入与结果以 `design/story/14-xueshan.md` 为准，任务状态机仍归 `design/12`。

#### 10.1.2 收集、核验与版本规则

| 步骤 | 规则 | 正线用途 | 邪线用途 | 防死档 |
|---|---|---|---|---|
| 收录 | 每段口述保存讲述者、目击 / 转述 / 推断、利害标签、可核物证与原始版本哈希 | 保护原卷、邀请签认 | 拆分供词、控制流向 | 原卷损毁时保留“曾听见”状态 |
| 拆命题 | 一段证词可支持或反驳多个事实；同一事实也可挂多段证词 | 看见分歧而不急判 | 找出可交易的矛盾 | 不以单段丢失删除事实节点 |
| 核验 | “已证实”至少需要两项独立来源，或一项来源 + 一件可检物；同一利益控制者的副本只算一源 | 建立公开事实链 | 建立内部真相表 | 通关只需最低链；两全要求完整毒谋链 |
| 版本 | 原始记录只追加；公开版、受控版、篡改版另存差异和责任人 | `fl_14_record_preserve` | `fl_14_record_controlled/altered` | 不覆盖原始层，避免读档后自相矛盾 |
| 交付 | 给胡斐、苗人凤、清宫或群豪的是具体版本快照 | 形成双方硬信任 | 形成筹码、契约或反制 | 交付后保留收件回执，不复制任务物 |

核心毒谋只有在 `fl_14_truth_poison_order`、`fl_14_truth_poison_access`、`fl_14_truth_miao_unaware` 均真且存在独立可检物时，才派生 `fl_14_poison_plot_complete`。多数人重复同一句不增加独立性；高 `speech` 只能获得追问机会，不能把矛盾口述掷成真相。

#### 10.1.3 数据结构示例

  chapterId: ch14_xueshan
  recordMode: preserve       # preserve | controlled | altered
  claims:
    - factKey: poison_order  # 章节局部键，不是全局 ID
      truthState: corroborated
      fragments:
        - fragmentKey: tao_account
          speakerId: npc_taobaisui
          knowledge: participated   # eyewitness | participated | hearsay | inference
          interestTags: [self_protection]
          originalIntact: true
      evidenceRefs: [poison_container_trace]
      independentSourceCount: 2
  editions:
    original: {immutable: true, digest: xs14_original_digest}
    public: {derivedFrom: original, redactions: [], alterations: []}

`sys_14_rashomon`、`factKey`、`fragmentKey`、`knowledge` 与版本字段均为本章接口约定**（原创扩展）**；物证实体若需进入背包，必须由 `design/10` 登记 `it_*`，不能把示例局部键冒充物品 ID。

## 12. 难度与数值要点

### 12.1 D7 曲线与区域等级带

本界固定 `D=7`，故：

```text
enemyStatMul = 0.85 + 0.05 × D
             = 0.85 + 0.05 × 7
             = 1.20
eliteAffixCount = floor(D / 3) = floor(7 / 3) = 2
```

`enemyStatMul` 只乘敌人的 `hpMax`、`atkOut`、`atkIn`，不乘防御和评级；D7 使用 `ai_expert`、Boss 2–3 阶段。属性模板见 `design/03` §10，最终伤害见 `design/04`，本章不另加“终章隐藏倍率”。

### 12.3 具名 Boss 的 `full` 管线
