### 0.3 核心体验

1. 从牛家村旧案进入“守约”，在中都、桃花岛、君山、铁掌峰与漠北反复回答力量为谁所用。
2. 正邪路线都能完成五个锚点，也都能在桃花岛付出明确代价救下五怪；邪线不是坏结局快捷键。
3. 高武探索以 qg3 主线、qg4 支线 / 隐藏内容封顶；水路、山崖、草原骑行和阵法迷径各有非轻功替代。
4. 四项特色系统分别承担技艺竞逐（华山论剑）、多源证据（九阴收集）、生活 / 羁绊（黄蓉厨艺）和大规模战斗（西征大战）。

## 2. 穿越开局

### 2.1 固定苏醒与不可改写的前因

主角从天龙余韵期经《长生诀》沉睡 `1217−1094=123` 年：标准“北来行脚”在临安府外通往牛家村的驿路 `sc_02_linan_yilu` 苏醒，轮回隐藏“牛家村酒店帮工”则在酒店旧址 `sc_02_niujia_jiudian` 苏醒。楔子发生在约 1199 年，玩家只能在共有幕 `q_02_main_c_01` 查证旧案，不能回到当年阻止郭杨两家离散。此口径与 `story/02` §2 完全一致。

天龙遗物 `it_shijian_xiaofeng` 若已取得，只提供“前代侠者为止战而死”的主题回响；未取得时书灵给无名残页替代，不锁射雕内容。上一界门派身份与活动编组已经清空，携带与关系保留规则只引用 `design/02`、`design/18`。

### 2.2 可选开局身份

| 身份 | 解锁 | 苏醒 / 首个自由活动区 | 门派与势力影响 | 首条支线 | 对共有幕的边界 |
|---|---|---|---|---|---|
| 北来行脚 | 默认 | `sc_02_linan_yilu`；`rg_jiangnan_taihu` | 无初始门派；丘处机与七怪均保持中立 | `q_02_side_01`“旧雪下的账” | 完整经历 `c_01`、`c_02`；默认持一张郭杨旧案拓片 **（原创扩展）** |

### 5.2 A4 原著线与改命线

两线在 `dc_02_06` 前都必须得到“伪证存在矛盾”的可靠来源；正线可由朱聪式辨伪、周伯通或梅超风线索互证，邪线可由假经纸墨与第二来源互证。改命不是一次战斗的完美胜利，而是跨幕准备的原子判定：

```text
anchor_02_taohua = fate iff
  flag_02_false_evidence_contradiction
  AND available_rescue_companions >= 2
  AND flag_02_divine_clue_abandoned
  AND life(npc_zhucong)     == alive
  AND life(npc_hanbaoju)    == alive
  AND life(npc_nanxiren)    == alive
  AND life(npc_quanjinfa)   == alive
  AND life(npc_hanxiaoying) == alive
otherwise canon
```

- **原著线**：在 `dc_02_06` 选择追经、追凶或救援准备不足；玩家仍须保存柯镇恶 / 遗物证言，在铁枪庙重建凶手路线。结果为 `anchor_02_taohua=canon`。
- **改命线**：先核验伪证、备齐至少两名可分路同伴，并显式放弃一条尚未领取的天级线索候选，再完成三路救援。五个 `life(...)` 必须同时为 `alive`，结果才是 `anchor_02_taohua=fate`。
- 张阿生在大漠旧事中早亡，不属于 A4 的五人集合；不能拿他的状态替代任何一项。
- 放弃天级线索是进入救援前展示的选择，不暗扣已学武功；少一项即清楚列出缺口并按原著结果继续，绝不形成死档。

### 5.3 天书现世与失败降级

`it_tianshu_02` 的效果、携带和两种天书之力只引用 `design/13` §4.1、§4.3；本文只定义射雕叙事条件：

1. A1–A5 全部为 `resolved`，A4 恰为 `canon` 或 `fate`；
2. `dc_02_09` 已锁定本界最终立场，西征账本、军令或护民证言至少保留一项；
3. 完成华山论剑的参与结算；胜负只影响名次、声望和成就；
4. 返回漠北完成“英雄之问”，由玩家承认武功、军功与护民责任的差别；
5. A4=`canon` 时授 `tsp_02_canon` 资格，A4=`fate` 时授 `tsp_02_fate` 资格；效果不在本文重抄；
6. 结算后只发一件 `it_tianshu_02`，开启余韵期与 `vid_sleep_02_03`。

任一非 A4 证据不足时，由原著人物完成该锚点的最低行动，玩家损失关系 / 声望 / 奖励但继续前进；A4 条件不足则明确回落 `canon`。正线不保证改命，邪线也不排除改命。

## 10. 本书界特色系统

### 10.0 共通边界与状态原则

四项特色不是四套平行的角色、战斗或任务引擎，而是章节侧对通用系统的装配：

| 特色 | 主要通用系统 | 章节只保存的状态 | 不得复制的定义 |
|---|---|---|---|
| 华山论剑 | `design/09` 擂台 / 切磋、`design/13` 成就 | 资格、对局结果、最佳评价 | CT、伤害、认输、场间恢复 |
| 九阴真经收集 | `design/12` 任务 / 证据、`design/10` 奇书、`design/05` 学习 | 卷册现持有人、真伪与来源核验、合参状态 | 武学层数、秘籍通则、背包唯一性 |
| 黄蓉厨艺 | `design/12` 生活技能、`design/10` 菜谱 / 菜肴、`design/18` 羁绊 | 菜谱解锁、熟练、当前教学步骤 | 新增 `cook` 属性、食品 Buff 效果 |
| 西征大战 | `design/09` 大规模战斗 / 战线 / 号令、`design/12` 后果 | 战区目标、平民撤离事件、军令选择与战后账 | 单位属性、士气公式、战争经济 |

状态写入遵循三个原则：任务效果以 `effectId` 幂等；战斗随机结果由 encounter seed 固化；同一事实只存权威键，其余 UI 派生。章节 YAML 均为 JSON-compatible：不用锚点、别名、合并键、日期隐式类型或重复键。下列 `schemaVersion: chapter-feature.v1` 是本章所需的内容装配形状 **（原创扩展）**，字段级编译 schema 仍应由内容技术文档归档。

### 10.1 华山论剑

#### 10.1.1 开放、赛制与结算

论剑在 `q_02_main_z_10` / `q_02_main_x_10` 的华山段开放，地点为 `sc_02_huashan_juefeng`。A1–A4 已 `resolved`、`dc_02_09` 已锁定即可参加；主线只要求完成“到场、见证旧怨、继续赴漠北”，不要求主角夺魁。历史 / 小说中的五绝名位由原著人物关系表达，玩家取得的是本轮“外席胜者”评价 **（原创扩展）**，不得把自创角色写成原著五绝之一。

流程分四步：

1. **验帖与布装**：检查华山旧坛残笺、任一路线终幕资格；允许在入口更换武学和装备，进入首战后不可换人。
2. **三席试艺**：身法席、守势席、论招席各一场；分别强调不落台、接招 15 轮、击破预警。前两席失败可继续，记录评价而不重置剧情。
3. **高手请教**：从黄药师、洪七公、周伯通中选择一名 `full` 对手非死斗；欧阳锋终局由主线遭遇 `enc_02_ouyangfeng_huashan_nijing` 独立处理，不能当可反复刷的普通擂台。
4. **问武不问侠**：结算战绩、声望和 `ach_huashan`；随后明确显示“武功胜负不代替漠北英雄之问”，继续 A5 后半。

所有对局沿用 `design/09` §2.6：台外即负，常规时限 12 轮；“三百招”接招局按其原创换算为 15 轮，原著措辞与具体对手仍 **（待考）**。禁物品、暗器与毒；场间按上游恢复 `hp +30%`、`mp +50%`，清冷却 / 气势 / 非永久 Buff。玩家可随时认输，不产伤势、不掉落装备。

| 评价 | 判定 | 奖励边界 |
|---|---|---|
| 到会 | 完成验帖并至少打一席 | 开放 A5 后续；无论胜负均成立 |
| 入席 | 三席试艺至少完成两席目标 | 华山声望与史笺；不发随机天级 |
| 外席胜者 | 三席目标全成，并在高手请教中胜出 / 接满 | 解锁 `ach_huashan`；固定收藏评价 |
| 以武止争 | 主线终战达成生存 / 击退，未杀害受保护观战者 | 结局文本与品德事件；不改变 A4 变体 |

所谓“胜出”包括把对手逼到认输线、接满规定轮数或按该席特定条件得分，不要求击杀。高手请教每名只结算一次正式评价；余韵期重赛只给武学经验 / 观摩，不重复给成就、声望或天级候选。

### 10.2 九阴真经收集

#### 10.2.1 证据图、真伪与合参

本系统同时追踪“经卷在哪里”和“玩家凭什么相信它是真的”。物品唯一性以 `design/10` 为准；章节不复制经文正文，也不把知识旗标伪装成实体副本。节点分为：

| 节点 | 内容 | 可用来源 | 状态 |
|---|---|---|---|
| 上卷 | `it_miji_jiuyin_shang`，内功总纲 | 周伯通保管线、桃花岛旧案 | `unknown / located / held / relinquished / lost` |
| 下卷 | `it_miji_jiuyin_xia`，招式卷 | 黑风双煞旧案、曲三旧窖、梅超风证词 | 同上 |
| 纸墨 | 纸纤维、墨色、页序 | `q_02_qiyu_05` | `unchecked / consistent / contradictory` |
| 人证 | 周伯通、黄药师、梅超风等各自可知部分 | 主线 / 羁绊 | `unheard / recorded / corroborated / disputed` |
| 伪经链 | 欧阳锋受骗与嫁祸线索 | `z/x_04`、A4 | `unknown / suspected / proven` |

一卷成为 `verified`，需满足以下任一确定性条件：有一名具备亲历资格的权威 NPC 确认，或“实体卷册来源 + 两项相互独立的纸墨 / 页序 / 人证”一致。NPC 的“权威资格”由剧情绑定，不以好感购买；互相抄录的两份纸本只能算一个来源。任何关键证据出现矛盾时先标 `disputed`，不掷 RNG 决定真伪。

合参条件为上、下卷均 `verified` 且当前可合法研读；然后才向 `design/05` 请求 `sk_jiuyin`、`sk_yihun`、`sk_jiuyinshenzhao` 等各自候选来源。两卷齐不等于属性 / 武学前置齐，也不绕过 §9.1 的 7 份天级总账。下卷错练观察只可开辨伪 / 反噬教学，不能直接生成正法。

A4 把“救人”和“追神功”摆在同一时间窗：走改命线并写入 `flag_02_divine_clue_abandoned=true` 时，放弃的具体卷册 / 权威证词记录为 `relinquished`；本周目系统保留已知目录、真伪结论与图鉴，不生成替代副本。原著线也不能靠见死不救自动获得经卷，仍须完成所有权交接与辨伪。无论收集成败，A4 真凶判定都至少保留 §5 所列的非经卷证据路径。

### 10.3 黄蓉厨艺

#### 10.3.1 协作规则与四味进程

厨艺线从 `q_02_bond_01`“蓉儿四味”展开，`q_02_qiyu_16` 提供其中一道菜的替代学习入口。黄蓉是名厨与叙事主体：玩家负责寻材、辨材、刀工 / 控火、分餐或记录菜谱；关键原著宴席由黄蓉完成，玩家不能用一个高熟练检定夺走她的功劳。

本系统不新增第十一项 `cook`，也不读取 `alchemy`。每张 `rc_*` 独立使用 `design/12` §10.4 已定义的 `recipeMastery=1–10`、三步小游戏、成功率、63 批满熟练和跨书知识保留规则。章节只配置四张菜谱的来源、场所上限、任务评价和人物反应：

| 次序 / 菜谱 | 开放地点与协作 | 关键判断 | 产出与羁绊 |
|---|---|---|---|
| 1 `rc_jiaohuaji` → `it_jiaohuaji` | 临安 / 嘉兴郊外；采买、荷叶与泥封 | 不漏必需材料；火候教学允许重试 | 初学熟练 1；洪七公评价、黄蓉羁绊；不自动授降龙 |
| 2 `rc_yudishuijiatingluomei` → `it_yudishuijiatingluomei` | 太湖 / 桃花岛厨房；五味辨材 | 五种主材不能用稀有度替代；刀工顺序影响品级 | 高级菜肴与洪七公试艺；物品效果只读 `design/10` |
| 3 `rc_haoqiutang` → `it_haoqiutang` | 桃花岛 / 海上补给；黄蓉主厨、玩家控火 | 同席名单与关系选择；不得靠重复食用刷羁绊 | 每人每书界一次羁绊收益，重复只恢复 / 饱腹 |
| 4 `rc_ershisiqiaomingyueye` → `it_ershisiqiaomingyueye` | 岳州宴席或 `q_02_qiyu_16` | 二十四份分餐、先给伤者的隐藏评价 **（原创扩展）** | 菜谱 / 黄蓉羁绊；闭关效果见 `design/10` |

每次制作按通用事务预扣一批材料，确认必需材料后才进入刀工 / 火候；中途退出返还尚未处理的材料，已经切配或烧坏的部分不回滚。失败产“家常饭”并保留剧情进度，但不记成功熟练；剧情首次教学允许黄蓉出手保底得到一份任务菜，同时玩家本人的 `recipeMastery` 不因此跳级。营地制作上限、厨房场所加成和最终菜品品阶全部由上游计算。

评价由三个正交维度组成，不相加冒充生活技能：

- `craftResult`：通用烹饪判定的成败与实际品阶。
- `hospitality`：分餐对象、是否先照顾伤者、是否尊重食客禁忌等任务选择 **（原创扩展）**。
- `mentorCredit`：由黄蓉独立完成 / 玩家协作 / 玩家独立复现；只决定对白、熟练来源和羁绊，不改食品效果。

洪七公传艺只把菜品作为建立信任的一个条件；还要满足 §9.1 的守诺、资质与天级额度。买到同名菜、从仓库取成品或让黄蓉代做，可以推进宴席对白，但不能伪造玩家已学菜谱或成功烹饪记录。

- 同席收益逐人显示“本书界已享用”，重复菜仍保留食品效果但不再次增加羁绊；任务奖励、菜品效果与师父授艺分三张卡结算。
- 物品接口生产 `design/10` 既有菜品；任务接口记录 `q_02_bond_01` 阶段和幂等效果；人物接口写羁绊事件；成长接口仅保存菜谱学识 / 熟练，不写 `alchemy`，书眠时只留知识而不带材料与成品。

### 10.4 西征大战

#### 10.4.1 战役结构与选择后果

西征在 `dc_02_08` 后进入 `q_02_main_z_09`“破城不屠”或 `q_02_main_x_09`“奇袭取城”。战场经和林军营、喀什噶尔驿站和 `route_offmap_samarkand` 专线加载，是图外一次性战役实例，不新增全局 `rg_*`，也不允许战后占领当地资源点。原著对应的具体花剌子模城名、攻城计策与先后仍须逐字核对，正文和 UI 在考据完成前只显示“西征前线 / 花剌子模城”**（待考）**。

战役按同一地图、不同军令重点分四段：

1. **军议**：读取 `dc_02_08`；正线绑定“破城且护民”，邪线绑定“军功优先”，但两线仍允许对掠夺与平民撤离作独立选择。`sk_wumuyishu` 提供额外部署信息，不是必需钥匙。
2. **侦察 / 奇袭**：玩家在三条入口中选择一条；轻功、军伍、口才 / 伪装均有解，失败增加首波压力而不重掷地图。
3. **攻城主战**：使用 `mass`，场上活动单位 ≤24（玩家 ≤6、剧情友军 ≤6、敌方 ≤12）；普通士卒用 3–6 人战阵，援军按轮界加入。玩家可用号令指挥友军，同时照看城门、城墙和撤离三条局部战线。
4. **战后账**：固定展示军令执行、己方伤亡档、敌军投降 / 溃逃、平民撤离批次、掠夺约束和《武穆遗书》使用方式。账本成为 `dc_02_09` 与 A5 英雄之问的事实材料；不把一个抽象总分替玩家回答价值选择。

本战主角倒地按剧情战正常重试 / 援手处理；城门先破或撤离不足是“目标失败但剧情继续”，产生增援、关系与战后记录，不要求重读存档。正线的最低完成条件是夺取战术目标且打开至少一个民用出口；邪线的最低完成条件是夺取战术目标，但若默许掠夺会明确写入不可逆后果。任何路线都不能通过多杀模板敌人抵消已发生的平民损失。

| 局部量 | 初值 / 变化 | 用途 |
|---|---|---|
| 城防对象有效耐久 | `round(111,694×0.83)=92,706` | §8.4 已校准的 Lv50 战役对象总预算；不是史实名将 `full.hpMax` |
| `civilianSafety` | 100；每个撤离失败事件按脚本扣 10–25 **【建议值】** | 只分档为安稳 / 受损 / 危急，不映射具体死者数 |
| `discipline` | 读取军令与玩家战中行为，0–100 **【建议值】** | 决定友军是否响应“护卫 / 撤退”与战后掠夺事件 |
| 三条战线 `hold` | 各 100 | 按 `design/09` §9.5 的 `pressure/defense/k` 结算 |
| 场上总数 | `6+6+12=24` 上限 | 低档设备把同类普通敌人合为战阵，不改变规则结果 |

`civilianSafety` 和 `discipline` 是本战局部 gauge；建议值只决定分档阈值与脚本节拍，人物生死和品德变化仍由任务事件明列。正式数值归属补齐前，默认 `≥70 / 30–69 / <30` 三档 **【建议值】**，并在本文末登记。

## 12. 难度与数值要点

### 12.1 曲线位置与区域等级梯度

射雕是全作高武峰段的第二站：从天龙上限 35 / D4 进入射雕上限 50 / D8，下一界神雕再升至上限 62 / D9。玩家预期入界显示等级 33–35，普通敌人全界闭区间固定 28–50；低于 28 或高于 50 的普通 / 精英配置均为构建错误。唯一登记的超限 Boss 是 Lv53 欧阳锋，满足高武 `capExemptMax=+3` 且没有占用第二个可用名额。

### 12.2 D8 的唯一乘区与模式叠加

本界固定难度 `D=8`，所以：

```text
enemyStatMul = 0.85 + 0.05 × 8 = 1.25
aiTier        = ai_expert
bossPhases    = 3
eliteAffixes  = floor(8 / 3) = 2
```

`enemyStatMul` 只乘敌方 `hpMax` 与 `atkOut/atkIn`；不乘 `mpMax`、防御、速度或八项评级。模板单位先按 `STD_E(L,W,tier,kind)`、模板倍率和流派修正生成，再施加 1.25；具名 `full` 人物走与主角相同的先天 / 武学 / 装备管线，只在攻击和配置目标气血上应用难度，不能再乘模板攻击倍率。伤害 Z1 对 `P_ref` 除且只除一次。

玩家所选难度模式与 D8 独立相乘，不能拿模式倍率替换 1.25：

| `diff_jianghu` | `1.25×0.80=1.00` | `1.25×0.80=1.00` | 八评级 −8、速度 ×0.95、AI −1；剧情战可用援手 |

| `diff_tianjie` 第 n 重 | `1.25×(1.25+0.05n)`，即 1.625–2.125 | `1.25×(1.15+0.03n)`，即 1.475–1.775 | 八评级 +9～+17、速度 ×1.05、AI +1 |

### 12.5 经济、成长与可达性约束

- 经验只按 `design/13` 的任务 / 敌人公式结算；章节不给“到 Lv50”固定经验包。入场 33–35 到上限 50 的成长由主线、30 支线、16 奇遇和探索共同覆盖。

- 经脉在本界新增 27 穴 / 3 通脉 / `H=11,880`，射雕结束累计 45 穴 / 5 通脉 / `H=18,360`；各来源只解锁 `design/15` 的合法动作。

- 主线 qg3 可达且总有长山道、船、飞爪、向导或机关解；qg4 只锁隐藏观潮、绝壁史笺、急流支路等非主线内容。
- 低性能档只降表现：战阵合并、远景快演和特效裁剪不能改变 RNG、行动次序、目标结果、经验与 A4 / 西征旗标。
