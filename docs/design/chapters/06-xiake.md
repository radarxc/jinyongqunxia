## 0. 阅读指引

### 0.1 本文边界

本文是《侠客行》书界的可生产内容清单，不复制已经审校的正邪双线正文。

- §1～§3 冻结书界参数、共同开局和本时代地图实例。

### 0.2 本界一句话

玩家在“人人都想替别人命名”的江湖里，陪一个无名少年从玄铁令走到无字石壁：既可公开还名、止住错杀，也可借误认重排权力；无论正邪，最终都必须回答——传承究竟属于文字、权位，还是亲身可验证的体验。

### 0.3 权威冲突的读取顺序

1. 主线以 `story/06-xiake.md` 为唯一剧情源。本文件不把 16 幕实玩路径压成旧预算的 8 幕。

### 1.2 体验支柱

1. **身份可核验，不可代答。** 任务让玩家拆分相貌、伤疤、口供、责任和本人意愿，但不给石破天一个“系统认证真名”。
2. **力量越高，克制越重要。** 中武高段人物能在船、雪地和狭室造成强压；关键战均以保护、制服、撑过、见证为胜利条件。
3. **书写不是唯一知识。** 石壁谜题允许字义、动作、呼吸、穴位四路观察；石破天的独特顿悟仍不可被玩家抢走。
4. **旧账跨书而来。** 赏善罚恶使读取跨书累计品德与关键行为摘要，不把一个瞬时数值等同于善恶全貌。
5. **江湖先要活下去。** 长乐帮、雪山派、镖局、山庄、港口与资源点构成十小时内可选择的生计，不让世界只剩主线走廊。

## 2. 穿越开局

### 2.1 固定苏醒与共同身份

玩家自 `ch05_xiaoao` 书眠 57 年后，于约 1582 年初冬在开封府 `city_kaifeng` 东门外驿路苏醒；随后步行抵达侯监集 `sc_06_houjianji`。书灵补出的共同合法身份是“替故人送还旧物的无籍游客”**（原创扩展）**，与 `story/06-xiake.md` §2.1 完全一致：无官府告身、无本界门籍、`fame=0`，但保留跨界 `morality`。

下面三项不是三份相斥身世，而是玩家为同一“无籍客”选择的临时谋生口径。它们只调整苏醒点百步内的入口、初见关系和第一条支线，不改玄铁令必经事实。

### 2.2 三种可选开局口径

| 开局口径 | 起始区域 / 微场景 | 初始门派影响 | 首条支线 | 初始物与限制 |
|---|---|---|---|---|
| 走脚镖客 **（原创扩展）** | `rg_zhongyuan` / 侯监集东驿栈 | 金刀寨关系 +5；仅是旧日同路印象，不授门籍 | `q_06_side_01`《烧饼铺后的伤者》 | 取得一份路线简图；须先救伤者，晚 3 分钟抵达争令外围**【建议值】** |
| 山野药徒 **（原创扩展）** | `rg_zhongyuan` / 驿路药棚 | 上清观关系 +5；开放游方医者介绍信，不自动入观 | `q_06_side_02`《阴阳两味》 | 取得黄阶药材样本；首战少一个补给槽**【建议值】** |
| 游方抄手 **（原创扩展）** | `rg_zhongyuan` / 侯监集旧书摊 | 玄素庄关系 +5；只因辨出旧剑谱纸张 | `q_06_side_03`《有字无凭》 | 提前解锁证据对照 UI；没有额外战斗加成 |

三者都在 12 分钟内汇入 `q_06_main_c_01`**【建议值】**。任何首条支线失败都不会让少年失去玄铁令、让谢烟客拒绝履诺，或改变 `flag_06_xuantie_delivered=true`。

### 2.3 开场状态与教学复用

| 项 | 结算 |
|---|---|
| 等级 | 真实等级保留，显示等级钳制到 Lv58；详见 `design/02` |
| 武学 | 从上界核心栏选择内功 / 拳脚 / 兵器各 2；外来武学有效品阶 −2 小品 |
| 经济 | 银两、普通库存、资源点、家丁、营生职位与门派身份按书眠规则清空 |
| 地理 | 旧地图发现以淡墨记忆显示，不绕过本时代入口和路况 |
| 品德 / 声望 | `morality` 继承；`fame` 清零 |
| 教学 | 复用移动、调查、非致死战斗、证词比对；不重教基础战斗 |
| 首次门禁 | 侯监集仓顶 qg1（20）；不会挡主线，地面有同目标路线 |

### 2.4 开场不可越界事项

- 玩家不得凭现代读者知识直呼少年“石破天”或断言其为石中坚；UI 在当事人接受姓名前显示“无名少年”。
- 不把“不识字”做成智力减益；它在普通书面交互中只改变可用方法，在图形与动作辨识上反而开放专属选项。
- 玄铁令必须由少年取得并交到谢烟客手上，玩家只能保护见证、救人和决定证据保存方式。
- 大悲老人、侍剑、梅芳姑可有普通人物改命窗口，但不替代五个天书锚点，也不允许改写石壁最终毁去的事实。

### 5.2 原著线：`tsp_06_canon`

原著线达成条件只写叙事门槛，天书之力效果引用 `design/13` §4.3：

1. A01–A04 的硬事实完成；局部支线可以成功或失败。
2. `dc_06_08` 已冻结合法名单，玩家经专线抵岛。
3. 石破天本人完成不拘文字的会意；玩家未用抢答或夺谱替代他。
4. `dc_06_09` 选择“止笔，只见证一人顿悟”，或抢残片失败后接受石壁不可复原。
5. 石壁毁坏、龙木二岛主逝去、群雄与仍健在旧客归返；这些结果不能被普通救援分支改写。
6. 结算 `it_tianshu_06` 与 `tsp_06_canon`，并原子写入取得记录，防止重入重复发奖。

其叙事含义是“无字之会意属于当下的人”，并不宣称文字无用，也不否定岛上群雄多年参悟。

### 5.3 改命线：`tsp_06_fate`

改命保存的是可互证的方法，不保存石壁、不复活二岛主、不复制完整《太玄经》：

```text
fateReady = trust_long
         && trust_mu
         && count(recordKinds) >= 3
         && (count(publicSectWitnesses) >= 3
             || count(secretCustodians) >= 2)
         && !flag_06_forced_shipotian
         && !flag_06_false_blame
         && identityEvidence != destroyed
```

- `recordKinds` 只允许 `motion / breath / meridian / semantics` 四类，`3/4` 给一类观察失败的容错。
- 正线以至少三派公开互证；邪线以至少两名自愿、彼此制衡的保管者密盟传灯。
- 石破天仍先会意，龙木分别核验可重复性；玩家不能取得“完整太玄秘籍”物品。
- 代价沿用 story：放弃独占残壁、一个天级秘籍奖励位和一项门派专属回报**【建议值】**。
- 结算 `it_tianshu_06` 与 `tsp_06_fate`；实际天书效果仍只见 `design/13` §4.3。

### 8.5 Boss 模板算式与 full 落地约束

D6 难度倍率：

```text
enemyStatMul = 0.85 + 0.05×6 = 1.15
```

Lv51–60 属宗师段，Boss 模板气血 `×6.5`；模板攻击先 `×1.25`，再只对攻击与气血乘 `1.15`；防御 `×1.20`、内力 `×2`、评级 `+15`、速度 `×1.06`、八项抗性 `+30pp`、`resCC` 再 `+40pp`。例如白自在 Lv55：

```text
hpMax = round(STD_E_base_hp(55,W70,MID) × 6.5 × 1.15) = 129,383
atkOut = round(STD_E_base_atkOut × 1.25 × 1.15) = 3,451
defOut = round(STD_E_base_defOut × 1.20) = 2,416
mpMax = round(STD_E_base_mp × 2.0) = 10,994
```

谢烟客 Lv52 亦在宗师段；丁不四 Lv50 属绝顶段，气血倍率为 `×6.0`，故其 HP 低于 Lv52 的阶跃结果。龙木 Lv60 的数值不是把 Lv58 面板乘 `60/58`，而是以 `Ld=60` 重跑全部等级曲线。正式 `full` 配置须另给先天、合法层数、装备和流派，再以同级模板 HP 的 `0.6–1.2` 倍校准，并跑 `design/04` 的战斗模拟；不得直接把上表模板复制为最终人物面板。

## 10. 本书界特色系统 / 机制

### 10.1 石壁“不识字”解谜：目的与边界

该系统把“解释文字”与“观察身体路线”拆开。原著事实是石破天不识字，反而从石壁图形与经脉意象贯通绝学；玩家玩法、书灵冥想、记录类别和 UI 均为**（原创扩展）**。解谜绝不能导出以下错误结论：识字有害、石破天只是碰巧猜中、玩家可比他先顿悟，或一张拓片就是完整《太玄经》。

系统有三个不同产出：

1. 石破天的剧情顿悟：由 `q_06_main_c_05` 固定发生，是原著硬事实。
2. 玩家的学习资格：完成合法观形链后创建 `sk_taixuan` 的 `LearnSource`，不直接增加层数、不生成秘籍；真正修炼仍走 `design/05`。
3. A05 的互证记录：`motion / breath / meridian / semantics` 四类中至少三类，用来决定 `tsp_06_fate`，但它们本身不是武学来源。

### 10.2 石壁规则与状态机

| 阶段 | 输入 | 规则 | 输出 / 失败 |
|---|---|---|---|
| S0 旁听诸家 | 抵达石室、`q_06_main_c_05` | 逐室听取字义与门派解释；只写图鉴见闻 | 可得 `semantics` 记录；**不增加**观形进度 |
| S1 卸下注解 | `lore≤20`，或完成书灵“忘文”冥想 | 逐字阅读模式关闭；高 `lore` 不永久下降 | 获本次石室会话的 `wangwen=true`；离开石室即失效 |
| S2 观形描线 | 选择壁面图形起点 | 按形迹把点、线、转折看成动作 / 经脉路线；门槛严格引用 `design/05` §7.6 `stroke` | 成功写一个 trace group；失败只消耗 1 游戏时辰，不损坏石壁 |
| S3 身证 | 已完成该组描线 | 让当前角色按安全速度复演；呼吸、步位、经脉提示分开核验 | 可写 `motion`、`breath` 或 `meridian`；走火风险只调用 `design/05` / `15` |
| S4 互证 | 至少三种记录；龙、木分别认可 | 对照不同人的动作，标出一致处与矛盾处 | 写 A05 条件；不会产生“唯一注解” |
| S5 崩壁与结算 | 石破天已顿悟、`dc_06_09` 已锁定 | 停止任何新观形，提交已取得记录与学习资格 | 未完成记录按原著线继续；不得在崩壁后刷进度 |

观形资格是硬门槛：

```text
canTrace = (lore <= 20) OR wangwen
```

通过硬门槛后不再叠加连续速度倍率：`design/03` §15.3 D-16 已撤回旧式 `1.5−0.01×max(art,lore)`，故本文只保留 `design/05` §7.6 的 `lore≤20 / wangwen` 二值资格。`design/08` §4.1 当前仍残留旧公式，属于待同步上游债，不能作为生产配置；合资格者每组统一消耗 1 游戏时辰**【建议值】**。

生产上把原著石室群打包成 6 个交互组 **【建议值】**；每组至少有一种非文字记录，全部 6 组完成才授玩家学习资格。原著石室确数与图文分布仍需考据，交互组数不声称等于小说石室数。石破天无需经过玩家的六组进度条，他按剧情独立顿悟。

- **门槛可解释**：`lore>20` 时按钮不写“你太聪明”，而写“你总把形迹读回字句”；旁边提供可执行的“随书灵忘文”入口。

### 10.5 赏善罚恶使的跨书界品德清算

本系统读取 `design/12` 的全局 `morality` 与品德事件账，不重算品德，也不以门派、正邪路线、声望或胜负替代行为。原著的赏善罚恶使、铜牌与邀约是剧情依据；“审阅玩家前五书的行为日志”是本作**（原创扩展）**。

清算在 `dc_06_05` 前冻结一次快照，范围只含已完成的 `ch01_tianlong` 至 `ch05_xiaoao`；ch06 当下行为另作“今账”提示，不与旧账争四个展示位。每个候选事件必须有：

- 非零品德变化；
- `reasonCode`、受影响对象 `targetRef`、来源 `questId / encounterId`；
- 稳定 `effectId`，且已在 `appliedEffectIds` 中提交；
- 原始变化 `deltaBeforeClamp` 与实际变化 `appliedDelta`；达到 ±100 后实际变化为 0 的事件仍可说明，但不进入“最善 / 最恶”四项排序。

四项摘要采用确定性算法：

```text
eligible = committed events from ch01..ch05 where appliedDelta != 0
dedupe   = within (reasonCode, targetRef, sourceRef), keep largest abs(appliedDelta)
good     = sort(delta desc, chapterOrder asc, effectId asc), take 2
evil     = sort(delta asc,  chapterOrder asc, effectId asc), take 2
```

若同一 `reasonCode + targetRef` 在不同任务代表同一持续行为，只保留绝对值最大的一笔，避免刷日常善举挤掉关键事件。某侧不足两项就显示“无可核验记录”，不得以路线标签补造罪名或善举。排序只决定展示代表项，不改变现有 `morality`。

### 10.6 清算结果、申辩与战斗映射

| 当前全局品德 | 初始牌序 | 试炼变化 | 叙事称谓 |
|---:|---|---|---|
| `morality≥40` | 赏先、罚后 | 接受完整旧账时免一项普通战斗检定；不免 Boss 阶段 | 侠义及以上，沿用 `design/03` 分段 |
| `10≤morality≤39` | 赏罚交替 | 标准三轮 | 良善 |
| `−9≤morality≤9` | 赏罚交替，先展示绝对值较大项 | 标准三轮 | 中立 |
| `−39≤morality≤−10` | 罚赏交替 | 首轮控制预警提前显示 | 乖张 |
| `morality≤−40` | 罚先、赏后 | 先受“罚”的试炼；仍保留非战斗补偿路 | 邪道及以下 |

清算不是判死刑，也不改变已完成事件。`dc_06_05` 的处理方式按 story 结算：

| 处理 | 系统写入 | 后果边界 |
|---|---|---|
| 坦白接受 | `auditDisposition=accepted` | story 可结算 `morality +4` **【建议值】**；同一效果只一次；二使信任提高 |
| 实际补偿 | `auditDisposition=compensating` + 指向具体对象的补救任务 | 原记录保留并标“后续补偿”；新善举另记新事件，不倒删旧恶 |
| 暂缓 / 交换情报 | `auditDisposition=deferred` | story 可结算 `morality −5` **【建议值】**；获得路线情报但降低见证资格 |

“双使验心”只把摘要映射为三阶段战斗脚本：赏阶段测试保护与放弃独占收益；罚阶段复现控制 / 护送压力而不生成过去受害者幻象；问心阶段要求玩家保护一个与旧账无关的帮众。攻击、控制、AI、失败与非致死结算完整引用 `design/09`；清算系统只提供 `phaseOrder`、四张摘要卡和处理结果。

### 10.8 清算 UI 与通用系统接口

- **四卡摘要**：默认显示行为、对象、发生书界和后果，不显示内部排序权重；玩家可展开“为何记下”查看 `reasonCode` 的本地化解释。

- **无死档**：无论品德区间或旧账数量，都能进入后续主线；差异只在试炼顺序、二使关系、名单见证与 A05 改命资格。

## 12. 难度与数值要点

### 12.1 D6 总体口径

本界保持基准的中武、武运 70、难度 D6、敌人 Lv46～58、章节上限 Lv58，不因太玄经是天上品而临时抬高整个世界。D6 只把敌方模板气血与外 / 内攻击乘：

```text
enemyStatMul(6) = 0.85 + 0.05 × 6 = 1.15
```

防御、内力、评级不乘 1.15；难度模式的 `dm_hp / dm_atk / dm_rat` 另由 `design/13` 合成。AI 使用 `ai_adept`，Boss 通常 2～3 阶段，精英词条数 `floor(6/3)=2`。局部难度只能在 D6 上下 3 档内覆盖，且不得借新手区改低原著宗师的完整人物画像。

| 区域 / 阶段 | 普通敌人 | 精英 / 头目建议 | 关键对手 | 数值意图 |

### 12.2 模板 Boss 可复算表

下表复述 §8.4 的章节验收值，并补齐生成口径。它们来自 `STD_E(L, W=70, tier=MID, kind=boss)`，再施加 Boss 模板与 D6；具名 NPC 的生产配置仍须走 `full`。

| Ld | 适用人物 | HP / MP | 外攻 / 内攻 | 外防 / 内防 | 等级合法性 |
|---:|---|---:|---:|---:|---|
| 50 | 丁不四 | 96,921 / 8,852 | 2,853 / 2,545 | 1,998 / 1,812 | 普通上限内 |
| 52 | 谢烟客 | 113,485 / 9,565 | 3,083 / 2,750 | 2,159 / 1,958 | 普通上限内 |
| 54 | 张三、李四 | 124,751 / 10,602 | 3,328 / 3,048 | 2,330 / 2,163 | 普通上限内 |
| 55 | 白自在 | 129,383 / 10,994 | 3,451 / 3,161 | 2,416 / 2,243 | 普通上限内 |
| 60 | 龙岛主、木岛主 | 153,838 / 13,066 | 4,101 / 3,757 | 2,871 / 2,666 | `min(60,70,58+4)=60` |

模板计算顺序：

```text
HP   = round(STD_E.baseHp × bossHpMul × 1.15)
Atk  = round(STD_E.baseAtk × bossAtkMul × 1.15)
Def  = round(STD_E.baseDef × bossDefMul)
MP   = round(STD_E.baseMp × bossMpMul)

Lv51～60：bossHpMul=6.5
Lv50：bossHpMul=6.0
bossAtkMul=1.25, bossDefMul=1.20, bossMpMul=2.0
```

反推抽查白自在：

```text
baseHp≈129,383/(6.5×1.15)≈17,309
baseAtkOut≈3,451/(1.25×1.15)≈2,401
baseDefOut≈2,416/1.20≈2,013
baseMp≈10,994/2≈5,497
```

先乘模板再乘难度与按上式合并相乘在精确计算中等价；实现必须遵循 `design/03` 的统一取整边界，不能拿反推近似值再算一遍。

### 12.3 `full` 人物落地与越级限制

七名关键 Boss 都是原著具名人物，应以手配先天、真实图鉴武学、合法层数和装备跑 `full` 管线：攻击只乘 D6 的 1.15，不再乘模板攻击 1.25；模板只提供 HP 目标区间、评级 / 速度 / 防御 / 抗性的合法修正。每人的目标 HP 可取同级模板的 `0.6～1.2`，超过时必须有剧情机制理由并重新模拟。

龙、木二岛主恰好占满本界两个 `capExempt` 名额。中武例外上界是：

```text
chapterBossCap = min(70, levelCap + 4) = min(70, 58 + 4) = 62
authorLevel    = 60 <= 62
```

例外只放宽显示等级；二人仍受中武 9 重层数上限、图鉴品阶、装备来源和 Z8 等全部规则。本文明确不把二岛主配置为已完整习得 `sk_taixuan`：长期参研、懂得核验和掌握岛上基础武学，不等于石破天式完整会意。其余 Boss 即使叙事上强，也不得偷偷设 `capExempt=true`。

### 12.4 伤害节奏与阶段预算

伤害逐段走 `design/04` 的 Z0～Z10；模板敌人的普通招在 Z1 使用 `P_ref×tmplPower` 归一，具名 `full` 人物用真实 `P_actual`，两者都只除一次 `P_ref(Ld,tier)`。章节不得用 HP 表反推技能倍率。

现行模拟对侠客行给出的回归目标是：

| 遭遇类 | 主 / 敌等级 | 主角击倒敌方所需命中 / 行动轮 | 敌方击倒主角所需命中 / 行动轮 | 命中率（主 / 敌） | 用途 |
|---|---:|---:|---:|---:|---|
| 普通 | 58 / 58 | 4.1 / 4.1 | 10.4 / 12.5 | 99.0% / 83.4% | 野外与门派日常，不拖长探索 |
| 精英 | 58 / 58 | 8.8 / 8.9 | 10.1 / 11.5 | 99.0% / 87.8% | 双账、舟路、雪地小队 |
| Boss 基线 | 58 / 62 | 67.1 / 23.5 | 6.8 / 7.2 | 92.2% / 94.6% | 越级单 Boss 的耐久边界 |

“命中”与“行动轮”都是裸模板回归值，不是剧情承诺；Boss 行动轮已计四人队伍等价。现行中武遭遇层把 Boss 有效耐久乘 `0.77`；实际双岛主战必须按同场阶段、环境目标、队友阵容与非致死 / 剧情撤退条件另跑模拟。推荐三阶段：第一阶段分别核验招路，第二阶段交替守卷，第三阶段处理崩壁环境；任何一阶段都不以“击杀岛主”为目标。
