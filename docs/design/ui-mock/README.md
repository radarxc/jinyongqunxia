# 天书录 · 六屏方向样稿

直接打开 [index.html](index.html)。无需构建；图片在 img 内，只有字体请求 Google Fonts。断网时使用系统中文回退字体。

- 底栏或键盘 1–6：大地图、城镇对白、战斗、行囊、图鉴、人物。
- Esc / 面板右上角关闭：从工具回到之前的大地图、城镇或战斗。
- 右上角昼卷 / 夜读：比较阅读面材质；物品格、分类、图鉴页签与人物可点选。
- 地图点张掖后“入城一览”；对白按钮翻句；战斗按钮只演示动作选中与落印反馈。
- 建议审图视口 1280×720 与 390×844；竖屏册页内容可纵向滚动，底栏保持可达。

这是一份视觉方向稿。六屏评审底栏不是正式游戏工具清单；地图位置、路线、资源与解锁数量都是排版示意，没有规则结算。人物先天八项的 60 不是推荐开局配点；资源统一以 100 为示意上限，墨条比值为 84/100=84%、68/100=68%、92/100=92%，不替代 `design/03` 的真实资源公式。十一装备槽沿 `design/10` §3.1；原八槽为主副手、头、衣、手、腰、足、佩饰，再加内甲、护肩、披风。

图片源与缩图尺寸见 [ASSETS.md](ASSETS.md)。对白与物品短笺均为原创演示文字，不是原著引文。城镇是既有预览图，六角战场是叠加的示意格，不是运行中的游戏渲染器。

验证记录（2026-10-03）：DOM 模拟 73 项断言通过，包括六屏点击 / 键盘、关闭回源、物品过滤、图鉴切页、主题与动作预览；HTML 标签闭合、图片路径与目录体积检查通过。现有 Chromium / Chrome 在本环境启动失败（SIGABRT / TargetClosedError），未取得两尺寸实际浏览器截图，不能将 DOM 模拟视为像素布局或触屏真机验证。正式实现还须按 `design/26` §9、§13 验收。
