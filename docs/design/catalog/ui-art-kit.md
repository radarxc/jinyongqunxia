## 0. 生产约定

- `asset_id` 是美术逻辑键，沿 `tech/07` 的 ui_ 前缀；复用已出现的 `ui_frame_scroll_9s`，其余为本清单登记的新 UI 美术键，不是游戏内容 ID。真正入库由 ART 按 manifest / AssetKey 归一化约定执行，本轮不写 assets。
- 母版为 sRGB PNG；图标母版 512×512 RGBA，运行时 128 / 64 图集承接 `tech/07` §5.6.4；表内同时给可用绘制框。边框母版允许非正方形；T/R/B/L 为母版像素，切片后缩放不拉伸角饰。
- 透明“是”要求真实 alpha，不能画棋盘格冒充；“否”是完整底纹。图集格间预留 4 px 扩边 **【建议值】**，极端缩放检查漏色；背景与框分层，图标不自带方卡。切片为 0 表示不可 9-slice，保持比例。
- 提示词可逐件直接交 codex image_gen。将 `assets/default/baseline/map/ref_map_jianghu__ch01_base01.png` 及同目录已审 S2 参考作为风格输入，只取线条、淡设色与材质，不截取原画装饰。图标与正文必须由代码分别排版；禁止生成文字、水印、伪字与整页 UI。
- 提示词生成母版，精确边距、alpha、无字由 ART 后期校正，不能假设模型一次输出即符合像素规格。明暗主题复用同一纹理蒙版与轮廓，朱砂 / 哑铜用 tokens 赋色；若需独绘变体，先评审再登记后缀，不暗增数量。
- 风格分工承接 `tech/07` §2.1：UI 图标使用 S3 游戏化工笔、2–3 阶色阶；S2 基线只取配色与墨韵，不把复杂场景皴法缩进图标。S3 图标不烘焙纸纹，透明背景上不画纸板；宣纸 / 绢 / 木底纹是独立材质层，按需与轮廓组合。
