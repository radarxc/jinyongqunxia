> 归属（基准 §18）：剧情插图（`cg_`）的选景、画面瞬间、构图、身份参考与生产门禁名录；剧情事实仍归各书 `design/story/NN-*.md`，资产流水线仍归 `tech/07-asset-generation.md`。
>
> 上游：`docs/decisions/author-requirements.md` AR-26、AR-29、AR-30；`design/story/00-yuenv.md` 至 `14-xueshan.md`；`design/chapters/00-yuenv.md` 至 `14-xueshan.md`；人物层级与身份立绘来自 `assets/default/prompts/characters/**` 及对应 manifest。
>
> 引用而不重定义：回目、锚点、改命结果与人物生死只引用各书 story；`npc_*` 的生卒、招募与外貌归 `design/18`；`por_*`、`cg_*` 的格式与生产状态归 `tech/07`。本文不把候选插图当成运行时场景 `sc_*`。
>
> 标注约定：**（原创扩展）** = 原著没有的内容；**（待考）** = 须以三联 / 广州修订版逐字核对；**（待核实）** = 技术事实尚未联网确认；**（待实测）** = 需真机或真账号验证；**【建议值】** = 依赖其他文档的暂定值；**（生产门禁）** = 提示词可用，但须等指定立绘通过审核后才可出图。

## 0. 使用口径

1. 本名录共 **102** 个多人情景图候选：序章 4 个，十四本正式书各 7 个；算式为 `4 + 14 × 7 = 102`。每书 7 个低于 `tech/07` §2.4 单书正式剧情 CG 不超过 20 个的预算，本批仍是候选，不自动计入正式交付数。
2. 资产 ID 使用 `tech/07` §1.4 已登记的 `cg_`，格式为 `cg_chNN_<语义>`。Canon §12 已废止旧 `scn_*`；运行时 `sc_*` 只表示章节相位 / 关卡实例，不用于本名录。
3. 每张为 1536×1024、3:2 横幅源图，服从本任务直接要求。若进入运行时 16:9 CG 管线，必须另做安全区裁切验证，见文末依赖。
4. `reference_upload` 只允许主角或 `tier: S` 人物；A / B 级即使已有 PNG 也只写文字外貌。表格每行列出与同 ID 提示词 frontmatter 完全一致的精确 `por_*` asset_id 及上传顺序；参考图只锁定本人面容、成年年龄、发式与本场适用服饰，不复制原图姿势、背景或光线。
5. 全体人物按一眼可辨的成年样貌表现。原著早年 / 童年事件只以成年化追忆、远景剪影或改选成年阶段处理，不生成幼态主体；不复刻真人、演员或剧照面容。
6. 打斗强调关系、阵势与动作方向，不表现血腥特写。亲昵或玩闹强调诙谐与心动，衣着完整，不做性化处理。
7. 下表“文字外貌”只服务本场出图，不重定义人物名录。没有合法身份图、身份图待重出或跨书一致性未通过时，场景保留 `status: ready` 仅表示提示词已完成，并受“生产门禁”约束。
