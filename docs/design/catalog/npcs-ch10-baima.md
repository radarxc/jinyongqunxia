## 1. 改编总则

- 原著人物关系、计老人真实身份、迷宫与旧怨骨架不变；名字能保留即保留。唐代身份只替换时代外壳，不声称原著发生于唐代。
- 稳定键 `sect_hasake` 不改，运行时显示“铁延部 / 庭州草原共同体”：这是突厥—铁勒背景的虚构混合牧部 **（原创扩展）**，不用一个真实部族承接所有小说人物。
- “晋威镖局”只留在原著考据栏；游戏中显示“晋威号河东护商结社 / 追图劫伙” **（原创扩展）**，避免把成熟后世镖局制度移入 702 年。
- 所有人物图像一律成年。原著早年 / 童年段用同一成年演员式视觉代理加时间字幕，不制作幼体、少年脸或儿童战斗精灵；不用真人或演员姓名。
- 汉人束发戴幞头或裹巾，穿圆领袍、窄袖袍或便于骑行的翻领胡服；女子可用短襦 / 半臂、高腰长裙、披帛，行动段收束披帛。草原人物用辫发、毡帽、翻领窄袖袍、长裤与软靴；粟特商旅用翻领长袍、织带、软帽与驮囊；唐军用幞头 / 兜鍪、圆领缺胯袍和札甲。具体纹样不得冒充已知族群标识。

## 3. 23 张立绘与战斗精灵口径

- 重出 `21+2=23` 张：上表 21 名静态 NPC，加 `npc_zhujue` 男 / 女各 1 张唐代西域行旅变体。现有清初剃发留辫、瓜皮帽、清式袍褂的 23 张旧资产全部不得沿用为成品；本任务不修改提示词文件。
- 每张必须是单人、全身、成年、无真人姓名；发式、主服色和标志物逐行命中上表。李文秀无论早年锚影还是主时间都用成年年轻女子模型。
- 战斗精灵最小 12 套：主角男女 2、李文秀、苏普、阿曼、苏鲁克、车尔库、桑斯儿、瓦耳拉齐、马家骏、陈达海、霍元龙；其余人物可按汉人行旅 / 铁延牧人 / 粟特商旅 / 唐军四种体型变体组合，但面部与标志物不得混用。

## 数据校验规则与测试用例

- 静态人物恰为 `18+3=21`，加男女主角唐代变体恰为 23 张；三个无名槽不计静态人物或立绘数。
- 21 行逐人具备成年阶段、发式、主服色和标志物；任何幼体、清廷辫发 / 瓜皮帽、清式官服、真人姓名均阻断验收。
- `sect_hasake` 只在数据键 / 历史迁移说明出现，运行显示必须为铁延部；晋威人物不得映射 `sect_weixinbiaoju`。
- 能力栏引用的 `sk_*` 必须在正式图鉴解析；D 级不代替职级或习得前置。首领七参只读 `chapters/10-baima` §12。
