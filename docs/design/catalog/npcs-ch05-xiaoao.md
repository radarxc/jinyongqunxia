- 人物表须恰为 26 个互异 `npc_*`，能力栏的 `sk_*` 须在现有图鉴解析；门派与人物分级只引用 `design/17` / `design/18`。
- 具名首领以 `chapters/05-xiaoao.md` §12.6 为完整配装索引；仅作首领配装的外来武学不得据本名录变成本界玩家可学来源。

- 当前未启用救援的东方不败、定闲、任我行、左冷禅、平一指、木高峰、余沧海不得生成存活改命或跨书同行出口；后续新增支线须先同步 `story/05-xiaoao.md` §8 / 开放问题。
