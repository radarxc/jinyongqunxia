# NPC 形象图鉴 · 历代路人服饰与立绘提示词索引

> 归属（基准 §18）：作为 `design/18-npc-and-companions.md` 与 `design/catalog/npcs-commoners.md` 的外观模板补充，定义无名路人的时代 / 地域形象，不定义具名 NPC、战斗数值、城市或历史年代。
> 上游：AR-30 第 4 条、AR-26 白马唐代化，`docs/00-canon.md` §2/§12/§16，`design/02` §1，`design/19`，`tech/07` §1.4/§2.7，`assets/default/prompts/characters/GUIDE.md`。
> 引用而不重定义：运行时生成、招募、年龄与伦理限制见 `design/catalog/npcs-commoners.md`；书界年代见 `design/02`；区域与城市见 `design/19`；立绘规格与素材 ID 见 `tech/07`。无名人仍用 `roleKey` / 运行时 UUID，不注册静态 `npc_*`。
> 标注约定：服装组合和普通人面貌均为 **（原创扩展）**；史料只能旁证其所示时代、地域和身份，不把图中人物当本作真人原型。证据跨地域、跨阶层或依后世材料类比时标 **（待核实）**。

## 0. 结论与使用边界

- 本册登记 **228** 个 `por_role_*` 外观模板：12 个时代各 19 个，满足“每时代不少于 12 种”；其中唐、明、清再拆地域目录。`228 = 12 × 19`。
- 每时代覆盖 17 类角色：掌柜、伙计、士兵、军官、文官、衙役 / 巡卒、书生 / 书吏、农夫、渔夫 / 船夫、樵夫 / 猎户、小贩、护卫 / 镖师、宗教人物、乞者、郎中、铁匠、歌伎 / 卖艺人；掌柜和农户各做男女两版，故为 19 款。
- 全部人物为 `young_adult`、`prime`、`mature` 或 `elder` 成年样貌；本批不生产 `child` / `youth`。女性是有具体职业的成年人，不作为装饰性陪衬。
- `por_role_*` 是可复用的立绘资产 ID，不是内容 NPC ID；运行时同一外观可由多个无名实例引用。不得由文件名反推姓名、族属、阶层或固定生卒。
- 清单中的“官员”“军官”均为低阶通用槽，不使用帝王、勋贵或具名历史人物服制；未获身份依据时不得给普通人穿龙纹、蟒纹、品级补子或礼仪冠服。
- AR-26 高于旧基准：`ch10_baima` 在本册按唐代处理，不再使用清初回疆套件；其精确游戏年份待 `DES-baima-tang` 在唯一归属文档定稿。

### 0.1 字段与生成对接

| 字段 | 规则 |
|---|---|
| 形象 ID | `por_role_<职业或职业_专长>__<时代地域>_<m\|f>`；`m/f` 只表达本张身体表现，不建立性别职业限制 |
| 角色枚举 | 优先复用 `npcs-commoners.md` §4；本册所需但上游尚缺的枚举只标“拟增”，不在此平行定义 |
| 年龄段 | 仅采用既有成年段；具体岁数由运行时种子在段内决定，立绘不得画成儿童或幼态成人 |
| 服饰 | 固定写首服 / 发式、上衣、下装、鞋、配饰、颜色与材质；汉式交领默认右衽，异族左衽只在行内明确时使用 |
| 史料 | `Sxx` 对应 §1；一手实物 / 同期图像优先，制度文献只约束身份，近时代类比不能升级成“复原” |
| 提示词 | 每行恰对应一份 `assets/default/prompts/characters/commoners/<时代地域>/<形象ID>.md`；`status: ready` 只表示文本可出图，不表示图片已生成或批准 |

1. 清单必须恰有 228 个唯一形象 ID，匹配 `^por_role_[a-z0-9_]+__[a-z0-9_]+_[mf]$`；不得出现 `npc_*` 注册。
2. 12 个时代各恰有 19 款、至少 17 类角色；总数核算为 `12 × 19 = 228`。
3. 每个 ID 必须恰有一份同名 `.md`；目录等于时代地域键，`asset_id` 等于文件名。
4. `gender` 只能为 `male` / `female`，且必须与 `_m` / `_f`、`output` 的性别目录一致。
5. `tier` 固定为 `C`，`status` 固定为 `ready`；输出必须是 1024×1536 对应的 2:3 立绘路径。
6. 年龄段只能取 `young_adult`、`prime`、`mature`、`elder`；提示词必须明确成年人并排除幼态。
7. 每行服饰必须同时出现首服 / 发式、上衣、下装、鞋、配饰、颜色与材质；每行还必须有道具、体态气质、史料码与书界。
8. 每份提示词必须包含单人全身、写实手绘古风、低饱和、暖浅灰纸底、极淡水墨远山、普通人差异、跨朝禁项与现代物件禁项。
