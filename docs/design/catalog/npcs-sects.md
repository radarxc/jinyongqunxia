# NPC 名录 · 门派、世家与组织

> 归属：`design/18-npc-and-companions.md` 的门派 NPC 分层名录；组织身份、五级职级、时代状态与驻地只引用 `design/17-sects-compendium.md`，本文不重定义。
> 上游：`design/17` §1–§3、§5–§11；具名人物的主线层级与能力画像引用本目录对应 `npcs-ch*.md`。
> 标注：`[L5] / [L4] / [L3]` 分别表示掌门（或组织首领）、长老（或横向主事）、亲传（或骨干）生产槽；“无名槽”不是人物姓名，不生成静态 `npc_*`。原著人名未逐字核对者标 **（待考）**。
> 时代码：`O/P/M/H/D/N` 的含义和全部 14 格以 `design/17` §0.2、§3 为准；本表只摘录人物投放所需的主要时代，不复制权威矩阵。

## 0. 生成与招募口径

- 每个 `O` 时代至少生产 1 个 L5/L4 主事槽、2 个 L3 骨干槽和若干 L1–L2 弟子槽；原著没有具名角色时全部使用运行时无名槽。
- `P` 只可生成地方传统、共同体或前身角色，不得让其自称尚未成立的组织；`M` 只生成残部 / 过渡人物；`H` 只生成遗迹看守、残承弟子或史实场所人员；`D/N` 不生成当代门人。
- 普通 L1–L3 门人默认 D3；具名 L4 通常 D4；掌门、政治首领和主线核心通常 D5。镖局普通镖师、军府杂役等可按设施身份降为 D2，但组织身份招募仍须满足 D3 门槛。
- “掌门 / 长老 / 亲传”是字段语义，不强迫原著组织使用这些称谓；实际显示名必须取 `design/17` §1 对应模板。例如朝廷 L5 显示为统帅 / 君主，部族 L4 显示为长老 / 队长。
- 同一具名人物只在主线文件拥有一个 `npc_*` 定义。本表出现姓名是反向索引，不重复声明生卒、武学或任务。
- 史实人物只证明人物或制度背景，不证明小说门派武学真实存在，也不自动生成可招募角色。
