## 1 背景

现行贴合（E2b `--push-mode volume`）是"关节对齐 → 模板最近面权重 → 体表位移场推离 + 限拉伸垂坠 → 减面 / 翻边 → 遮罩 → validate"。它只解决"别穿进去"：不管衣服大小是否合身、不区分材料软硬，换体型（small / tall）只能每个模板从头再推一遍；按别的体型做的甲（宽 / 窄 / 高 / 矮）没有对齐办法。

作者方案：衣服与素体是两个 3D 模型，本质是对齐。① 竖直（作者说的 Z 轴，本仓库 glTF 的 +Y）按"颈 → 下摆"缩放，下摆落到肚脐 / 臀下 / 膝 / 踝上等标注位置（素体与衣物都要标）；② 水平中心对齐；③ 自颈到下摆按高度切片，每片由素体切面算衣物切面：弹性切面 = 外环点 B 向中心的射线交内环 A、交皮肤 C，A 挪到 C 沿法向 1 mm 处、保持内外环距离得 newB；非弹性切面 = 衣物切面整体放大 ratio，取使内环全在体外的最小 ratio；最终 = r × 弹性 + (1 − r) × 非弹性（r：板甲 0、明光铠 0.2、锁子甲 0.3、普通衣物 0.9、劲装 1）；④ 沿高度平滑拟合出衣物模型，贴图与素材不变。

## 2 合理性结论

**合理，可作为"版型 / 尺寸对齐"一步，放在现行 3D 推离之前**：竖直按标注分段对齐 + 水平对中 + 按切面做"贴体 / 整体缩放"两种极端再按材料系数 r 混合，这正是 `volume_push` 缺的东西（大小、体型差、材料软硬），且逐顶点映射天然保留拓扑、UV 与贴图。但作者框架里有 8 个前提在真实素材上不成立，必须按下表修正（全部保持"竖直对齐 → 水平对中 → 切片 → 弹性 / 非弹性按 r 混合 → 沿高度平滑重建"的骨架，不换方法）。切片法只看水平截面，近水平体表（肩顶、胸上坡、臀下）看不见，所以它**不能单独替代 3D 复核**：切完仍要一次只推不拉的 3D 残余外推（刚体件改为整件放大），之后照旧走权重 / 姿势蒙皮 / 遮罩 / validate。

| # | 作者前提 | 实际 | 修正（框架不变） |
|---|---|---|---|
| 1 | 一个水平面截素体得到一个闭合图形 | A 字手臂 23.6° 斜穿水平面：胸高处是躯干 + 两臂三环；裆下是两腿两环；胸前还有乳沟小环 | 按部件切片：躯干沿竖直轴水平切；袖子沿素体臂骨弦（肩 → 腕）垂直切；衣物顶点按素体蒙皮权重分部件、过渡带混合，分开的连通块（甲片、单缝袖管）整块归一个部件。素体截面取该部件各环的**凸包**（绷紧的布跨过乳沟、腿间，裙装在裆下自然包住两腿） |
| 2 | 衣物切面是双环（内 / 外） | Tripo 抽取件是单层开口面（劲装 1 个连通块、4 个开口），交领 / 腰带处 2–4 层叠、腰带尾单独垂下；甲是厚壳，但常分片 | 不认"双环"，按**角度匹配**：每个角度取衣物最内层交点作内环，其余层保持到最内层的径向距离（单层即厚度 0）——作者"保持内外环距离"的推广 |
| 3 | 外环点 B 向中心射线唯一交到 A | 非星形截面（褶、叠层）一条射线多个交点 | 不做逐点射线，按角度分箱取最内交点（`ray_hits_2d`），位移场在（高度 × 角度）网格上定义 |
| 4 | 水平中心对齐用截面中心 | 衣片自身包围盒中心被局部件带偏：首版原型里腰带尾切片"绕自己 100% 覆盖"，被当成整件撑到臀围大小（Δ = +140 mm，最大位移 198 mm） | 覆盖率绕"素体对齐后的中心"量；中心差先取中位数再按覆盖率复选，沿高度平滑；刚体件取常数 |
| 5 | "沿法向 1 mm" | 水平截面里的法向是 2D 的；斜坡上水平 1 mm 的法向间隙不到 1 mm；近水平体表（肩顶、胸上坡）水平切面完全无能为力 | 水平间隙 = 1 mm × √(1 + s²) / cosβ（s 体表倾斜、β 射线与凸包法向夹角，封顶 4 倍）；盖顶处交 3D 残余外推（伪法向判内外、只推不拉、位移按网格局部摊开） |
| 6 | 非弹性取每片最小 ratio | 逐层独立缩放让刚性甲片在每个高度不同比例变形；肩坡一片的尖峰还会被平滑带到腋下，把甲衣两侧撑进 A 字手臂 | ratio 沿高度取 **Lipschitz 上包络**，斜率 ≤ 0.1·r /cm：r = 0 时为全件常数（整件相似：竖直一段线性、水平统一 ratio、常数平移）；盖顶格（倾斜 > 56°）不参与 ratio；刚体件 3D 复核仍有躯干穿入时整件放大（≤ 1.15 倍），不局部推 |
| 7 | r = 1 即内环贴体 1 mm | Tripo 件的褶皱烘在网格里（深 5–10 mm、宽 4–8 cm）。字面贴体把褶压平：劲装 medium 边长合格率 90.73%、翻面 290（保褶版 98.61% / 52，见 §9），贴图上画的褶也对不上 | 另设**褶皱尺度 foldMm**（衣物标注）：弹性位移场用"上包络平滑"，比 foldMm 小的褶随形保留、只把最深褶谷顶到体表 + 1 mm。r 管低频体型差，foldMm 管高频；光顺件（盔甲）foldMm = 0 即字面贴体 |
| 8 | 颈 → 下摆一段竖直缩放，领口 / 下摆即衣物最高 / 最低处 | 一段线性只能对齐两点；身材差异在胸 / 腰 / 胯处并不同比；袖长不该按竖直缩放。衣缘也不是全件极值：劲装下摆内折（开口边在可见下沿上约 4 cm），前襟腰带垂尾比下摆低 72 mm，侧颈峰比后领高 21 mm，后领口锯齿（后中扇区内 p10–p90 跨 25 mm）；模板骨架 Hand 关节左右不对称（离肩 428 / 474 mm，网格前臂最细处在 436 / 439 mm） | **衣缘锚点从衣物几何量**（§4）：领口 / 下摆以后中为准（服装"后中长"口径），后中 ±45° 扇区逐 2.5° 取最高 / 最低点为衣缘点，锚点 = 中位高度；袖口沿臂弦取远端包络中位。**目标**取设计体上离锚点最近且差 ≤ 10 mm 的标注面，都更远时取夹住它的两面按比例 t（各体型同一 t），与锚点分字段存。锚点必经；弹性件另取锚点之间、离锚点 ≥ 40 mm 的设计体标注面作单调 PCHIP 中间对应，锚点之外平移；刚体件两锚点一段线性。袖弦肩 → 腕，腕取网格前臂最细处 |

未覆盖、需另立：动作中的穿插（E2c 姿势蒙皮 + 手臂外展角）；"落肩"类版型的腋下（劲装袖窿比素体腋下低 5 cm，躯干 / 袖两部件在此夹挤，残余翻面集中于此）；分腿裤装（`legs: split`，需按腿骨轴部件，未实现，CLI 明确报错）；多 mesh / 多 primitive / 多材质衣物（下一步：逐 primitive 共用一个位移场、原样写回各 primitive 与材质；现 CLI 明确报错）；布料物理垂坠。

## 3 决策

1. 采纳作者框架，按第 2 节 8 条修正实现为 `slice_fit.py fit`：输入素体 GLB + 衣物 GLB + 两份 `slice_landmarks.json`，输出素体 bind 空间的静态 GLB（拓扑、UV、贴图逐字节不变）+ 诊断 JSON + 三视图 / 切面图。**输入范围**：衣物须为单 mesh 节点 / 单 mesh / 单 primitive / 至多一个材质（现有 Tripo 抽取件与测试甲都是），其他输入明确报错（退出码 2），多 primitive / 多材质保持分区列入下一步。
2. 定位为 P2 / P3 第 4 步"贴合"的**前置**（版型 / 尺寸对齐），不替代 3D 推离：其后 `fit_garment.py --align none`（其余同 E2b P2 ①：模板权重、3 mm volume 推离 + 限拉伸垂坠、贴图肤色清理）→ `pack_glb.mjs --simplify 0.25 --no-meshopt` → `untangle_glb.py` → `pack_glb.mjs` → （E2c 姿势蒙皮、`bake_hide_mask.py`）→ `validate.py`，门禁阈值不变。`slice_fit.py chain` 一条命令跑完切片与该链。**几何门量在链尾**（翻面 0、边长比 [0.7, 1.4] 内 ≥ 99%、bind 穿透 0，validate 以 fit.json 的源即切片件为参照）；切片这一步自身相对原始件的翻面 / 边长只报不判，与链尾"相对原始件"的同口径数字一起写进诊断。
3. 默认用于：按别的体型做的甲 / 衣物；跨模板（medium → small / tall）——每个模板直接从同一源件 + 同一份衣物标注各跑一次，替代 `refit_template.py`；作者要按材料控松紧时。Tripo 在本模板板上生成的件在本模板上可不走此步（E2b 已够）。
4. 标注落盘规则：能自动求的由脚本求（`body-landmarks`、`garment-landmarks`），看叠图确认后落盘并写 `confirmed`；衣物的领口 / 下摆 / 袖口锚点一律从衣物几何量、目标按设计体自动选（`--expect-collar / --expect-hem` 只核对不覆盖），不手填高度；测试件由 `armor-fixture` 确定性生成（锚点同法从生成几何量，且须选回设计的上 / 下沿面）。
5. 竖直核验分两种残差：**标注数值映射残差** = 锚点源值经映射后与目标之差（应 ~0）；**实际衣缘落点残差** = 同一批衣缘点经整个切片贴合（映射、部件混合、切片、残余外推、折角平滑）后的中位位置与目标之差，门槛 ≤ 1 mm（测试硬断言）。结果上重新分格取点只报（后领锯齿、袖子转角带动方位中心时会换点，不是映射误差）。

## 4 标注规范（`tianshu-dressup-slice-landmarks.v1`，坐标 mu，+Y 上、+Z 前）

数值字段一律带单位后缀（`Mu` 模型单位、`Mm` 毫米、`M` 米、`Deg` 度、`Sec` 秒）；比例、系数、计数为无量纲，不带后缀。

**素体** `templates/<tpl>/slice_landmarks.json`（`slice_fit.py body-landmarks`）：`levels.<名>` = `{label, yMu, method, centerMu[x,z], widthMu, depthMu}`，`centerMu` 为该高度躯干凸包面积质心（裆下为两腿凸包）；`limbs.armL/armR` = `{shoulderMu, elbowMu, wristMu, handMu, wristJointMu}`：肩 / 肘为 `Arm / ForeArm` 关节，腕 = 肘 → 中指指根 50–90% 段前臂垂直截面凸包周长最小处的质心（网格），`handMu` = `HandMiddle1` 关节（只作腕外侧的比例目标），`wristJointMu` 只记录骨架 `Hand` 关节；`limbs.legL/legR` = `{hipMu, kneeMu, ankleMu}`；`heightMu`、`mPerMu`、`source`（body / skeleton sha256）、`confirmed`。标注面与自动规则：

| 名 | 中文 | 规则 | 名 | 中文 | 规则 |
|---|---|---|---|---|---|
| neckBase | 颈根 | 自规范颈环向下，躯干截面宽首次 ≥ 1.5 × 颈宽 | pelvis | 胯 | Hips 关节高 |
| shoulder | 肩 | 腋下与颈根之间躯干截面最宽处 | hip | 臀围 | 裆与腰之间凸包周长最大处 |
| armpit | 腋下 | 自下而上两臂独立环并入躯干环处 | crotch | 裆 | 自下而上两腿两环合成一环处 |
| bust | 胸 | 腰与腋下之间前缘最突出处 | belowHip | 臀下 | 裆下大腿后缘外凸 > 3 mm 的最低处 |
| underBust | 胸下 | 自胸向下前缘首个局部最低处 | aboveKnee / knee | 膝上 / 膝 | 膝 + 0.25 ×（裆 − 膝）/ Leg 关节 |
| waist | 腰 | 胯与腋下之间凸包周长最小处 | aboveAnkle / ankle | 踝上 / 踝 | 踝 + 0.15 ×（膝 − 踝）/ Foot 关节 |
| navel | 肚脐 | 腰下前中线前缘最深凹点（深 > 1.7 mm） | midThigh / calf | 大腿中 / 小腿肚 | 裆膝中点 / 膝下 0.3 段 |

**衣物 / 盔甲** `garments/<id>/slice_landmarks.json`：`elasticity`（r）、`clearanceMm`（默认 1）、`foldMm`（褶皱尺度）、`rigid`（r = 0 时为真）、`legs`（`tube`；`split` 未实现）；`levels.<名>.yMu` = 该件**设计体**的同名标注面在衣物坐标里的高度（Tripo 在模板板上生成的件即该模板标注），只作锚点之间的中间对应，`alignLevels` 为其名单；`anchorRule` = 量锚点与选目标的参数（`sectorDeg` 90、`binDeg` 2.5、`cuffBinDeg` 10、`cuffNeighborhood` 2、`toleranceMm` 10、`minKnotGapMm` 40）。

- `collar` / `hem` = `{anchor, target, designTargetYMu, anchorMinusDesignTargetMm}`。`anchor` = `{method, yMu, p10YMu, p90YMu, bins, centerMu}`：绕衣物竖直轴（全部顶点 x、z 中位数）取后中 ±45° 扇区，每 2.5° 方位格取最高点（领口，`backSectorUpperEnvelopeMedian`）/ 最低点（下摆，`backSectorLowerEnvelopeMedian`）为衣缘点，`yMu` 为其高度中位数——是衣物自身几何量出的源高度。`target` = `{level}`（设计体上离锚点最近且差 ≤ 10 mm 的标注面）或 `{between: [下面, 上面], t}`（都更远时夹住锚点的两面与比例）；各体型上按同名面（或同一 t）解出目标高度。
- `sleeves.L/R` = `{axis, cuff, axisSource}`：`axis` = 设计臂的 `{shoulderMu, elbowMu, wristMu, handMu}`（Tripo 件取设计模板臂点，与 `levels` 同源）；`cuff.anchor` = `{method: distalEnvelopeMedian, tMu, p10TMu, p90TMu, bins, vertexSet, vertices, axisPoints}`：绕设计臂弦（肩 → 腕）每 10° 方位格取袖口附近顶点沿弦最远点，`tMu` 为其沿弦坐标中位数；袖口附近 = 开口件离设计腕点最近的开口环质心 2 倍环半径内的顶点（`cuffLoopNeighborhood`），闭合壳件离臂弦最近的独立连通块（`sleeveComponent`）；`cuff.target` 同上（`{point}` 或 `{between, t}`，候选为肩 / 肘 / 腕 / 指根）。量不出袖口的骨架臂不登记为袖。
- `note`、`source`（源件 sha256）。

## 5 弹性系数与褶皱尺度

| 类 | r（作者） | foldMm | 实际含义 |
|---|---|---|---|
| 板甲 | 0 | 0 | 整件相似：竖直一段线性、水平统一 ratio、常数平移；仅碰 A 字手臂处局部顶开 |
| 明光铠 | 0.2 | 0 | 80% 整件缩放 + 20% 贴体；ratio 斜率 ≤ 0.02 /cm |
| 锁子甲 | 0.3 | 0 | 70% 整件缩放 + 30% 贴体 |
| 普通衣物 | 0.9 | Tripo 件 75 | 低频基本贴体，褶随形 |
| 劲装 | 1 | Tripo 件 75 | 低频完全贴体（最深褶谷到体表 + 1 mm），褶随形；foldMm = 0 即字面贴体 |

宽松部位（长裙下摆、广袖）用作者的单件 r 会被收紧（r = 0.9 的长袍会贴腿），需要按标注面分段给 r（后续：`elasticityByLevel`）或保持该部位 r 小。

## 6 与现行流水线接口

- 输入：素体 `templates/<tpl>/body.glb` + `slice_landmarks.json`；衣物源件（抽取件 / 测试件，任意坐标）+ `slice_landmarks.json`。
- 输出：`<id>.slice_fit.glb`（素体 bind 空间、无 skin、unlit 双面、原贴图原字节；中间件，不入库）+ 诊断 JSON（`params`、`vertical`（映射对、必经对、丢弃对）、`anchors`（领口 / 下摆 / 袖口：源值、目标、移动量、`mappingResidualMm` 标注数值映射残差、`landingResidualMm` 实际衣缘落点残差、`resampledResidualMm` 重新分格只报、`storedMinusMeasuredMm` 落盘值与复量之差）、`verticalCheck`（两种残差最大值与逐对残差）、`verticalStretch`（领口—下摆跨度比 `spanRatio`、设计体上的 `designSpanRatio`、映射斜率范围）、`extremes`（全件最低 / 最高点，只报）、各部件中心差 / ratio 曲线 / 盖顶格数、输入 → 对中 → 切片 → 外推四级间隙、厚度 / 层距、边长与翻面、对照件表面距离；`reproduce` 记复现命令与输入 SHA，不记不入库文件的 SHA；`chain` 段记链尾 GLB / fit / report 的路径与 SHA、三项门、只报项、"相对原始件"翻面 / 边长与链尾衣缘落点 `anchorsReportOnly`）。三视图首行虚线 = 衣物自身锚点高度、细实线 = 素体目标高度，后两行只画目标线。
- 下游：`slice_fit.py chain` 自动接 `fit_garment.py --align none` → 减面 → 翻边 → 压缩 → `validate.py --level draft`，链尾件放 `garments/<id>/slice_fit/`；切片中间件写在其 `_work/<模板>/` 下供 fit.json 的 source 回指，跑完删除（复核时按诊断 `reproduce` 命令加 `--keep-work` 保留，或单跑同参数 `fit` 子命令，产物与 fit.json 记的 source.sha256 逐字节一致）。跨模板时每个模板各跑一次，不再派生 refit。

## 7 后果

- 好处：材料软硬有了一个参数；按别的体型做的甲能对齐（实测见报告）；跨模板直接从源件重跑；标注即文档。
- 代价：多两份标注；劲装 5.7 万顶点切片每模板约 50 s、整条 `chain` 约 10 min（其中 validate 约 6 min；机器 load ≈ 15 时实测）；切片法看不见盖顶，必须保留 3D 复核；r 是单件常数，宽松件要分段；字面 r = 1 会压平 Tripo 褶皱（需 foldMm）。
- 风险：标注面或衣缘锚点取错就整段比例错（如后中开衩宽过扇区一半时锚点会取到开衩顶）：标注时 `--expect-collar / --expect-hem` 核对目标面，三视图画锚点 / 目标线，`verticalCheck` 量映射与落点两种残差；3D 残余外推碰斜坡会把衣缘托高（锁子甲领口 +1.9 mm）；落肩版型的腋下夹挤需姿势蒙皮 / 外展角配合。

## 8 备选

- 维持现状（只 `volume_push`）：不处理大小与材料，换体型需每模板重推；按别的体型做的甲无法对齐。
- `refit_template.py` 骨相对派生：E2b 起已弃用（母版变动后需同步，且只适用于路 A 共拓扑模板）。
- 逐点最近点法向投影（E2 做法）：交领多层互穿、折面（E2b 报告：翻面 309–504）。
- 布料物理模拟（Blender / XPBD）：效果最好但重，主链不依赖 Blender（AR-104），留作兜底。
- 作者方案字面实现（单射线、整身一个中心、逐层独立 ratio、字面贴体）：原型实测出现腰带尾撑大、肩坡尖峰撑进手臂、褶皱压平折面等问题，见第 2 节。
