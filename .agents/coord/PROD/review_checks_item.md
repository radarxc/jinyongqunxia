# 物品图批量生产（ART-item-*）合入前审核要点（协调者，2026-10-01；作者：验收不要太复杂，按基线出口验收）

**审核纪律**：必须先实际执行检查命令、看图、核对文件，再写结论；无法执行的项写 ⚠️ 并说明原因，不计为 ❌。写着"尚未执行 / 尚未核实"的 ❌ 一律无效，会被当作审核失败重跑。

只审下面 5 条，每条 ✅ / ❌ 附依据；最多细看 4 张图（天 / 地 / 玄 / 黄各抽 1 张），其余只扫缩略：

1. 数量与登记：目录里 PNG 数 = 名录该表行数，文件名 = 物品 ID；manifest 每条 `size` / `sha256` 与磁盘一致，`status: candidate`；`check_assets.py` 通过。
2. 画风对基线：抽的 4 张与 `assets/default/baseline/item/` 两张比——细墨线、薄罩染、浅暖灰底、单一完整物品、四边留白 ≥ 10%、无地面 / 投影；不一致的超过 1 张判 ❌。
3. 干净：抽的 4 张无文字 / 伪字 / 印章、无品阶框、无人物或手、无发光 / 魔法 / 粒子特效（缩略扫一遍其余）；任一张有判 ❌。
4. 对题：抽的 4 张对照名录"子类"与"外观要点"——类别画错（药材画成成药、兵器画成别类、鞋只画一只等）判 ❌；品阶 / 年限信号弱只列出不判。
5. 禁止项与报告：manifest 提示词里无演员 / 画师 / 具体影视游戏作品名（grep 一遍）；报告逐项表与目录一致。
6. 真生成：manifest 每条 `tool` 为 image_gen **或其他真实的图像生成端点**（如 `codex exec · image_gen`、`Codex image edit endpoint`、`gpt-image`——如实写出用的是什么即可，不要求统一字样）、`model` 为真实模型名或端点名；出现 `fallback` / `Pillow` / `none` / 程序绘制字样，或素材目录里有 `.py` 等生成脚本，判 ❌——这是伪造素材，直接 FAIL，返修说明写明须全部用真实图像生成重出并删掉脚本。manifest `notes` 里如实记录"已替换旧 Pillow 程序图"这类历史说明不算伪造字样。

裁定：1、3、4、5、6 任一不成立判 FAIL；2 超过 1 张不一致判 FAIL。返修说明只写要重出的 ID 与原因。

**口径**：只有上面写明判 FAIL 的条件是阻断项；审核不得新增判定标准（不评审美、不要求更多细节），其他观察只列出不影响结论。
