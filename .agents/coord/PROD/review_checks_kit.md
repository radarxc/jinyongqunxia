# 批量生产 · 建筑套件 合入前审核要点（协调者 2026-09-30 21:35 重写；作者：验收不要太复杂，按基线出口验收）

**审核纪律**：必须先实际执行检查命令、看图、核对文件，再写结论；无法执行的项写 ⚠️ 并说明原因，不计为 ❌。写着"尚未执行 / 尚未核实"的 ❌ 一律无效，会被当作审核失败重跑。


**只有下面 6 条是阻断项。逐条给 ✅ / ❌ 附依据；6 条都 ✅ 就 `VERDICT: PASS`。审核不得新增判定标准；本文件没写的（占地比例、门孔宽度、投影轴斜率、构图相似、元数据文件、史料深度、审美）只能在"逐项结论"末尾用一段"其他观察"列出，不影响结论。**

1. **命令**：任务说明"检查"一节的命令（两条 `check_assets.py` + `check_ids.py --strict`）全部通过。
2. **数量**：建筑 ≥ 18 张且覆盖任务说明的功能类型（地域替换按对应表算覆盖）；贴片 ≥ 5 张且含城门 ≥ 1。
3. **透明底**：每张 RGBA、alpha 同时含 0 与 255（允许用脚本批量核）。
4. **视角**：45 度俯视、2:1 投影——以底面轴斜率落在 **0.35–0.70** 为准；超出的张数 **> 4** 才 ❌（≤ 4 列出即可）。光源左上、阴影右下（明显相反的张数 > 4 才 ❌）。
5. **登记**：manifest 每条 `file` 存在、`size` / `sha256` 与磁盘一致、`status: candidate`、ID 命名 `bld_kit_<kit>_<type>` / `tex_town_<kit>_*`；`building.footprint` / `tile` 字段存在（数值与画面的偏差不作判定，由渲染时按画面重登记）。
6. **禁止项**：没有文字 / 伪字 / 水印、现代元素、人物面部（逐张或总览图检查）。

返修说明：只写 ❌ 那条对应的具体文件；不要把"其他观察"写进返修说明。
返修口径补充：第 4 条不通过时，返修说明写明用 PIL **仿射校正**（纯几何剪切 + 缩放把底面轴拉回 2:1，重登记尺寸 / sha），不重出图。
