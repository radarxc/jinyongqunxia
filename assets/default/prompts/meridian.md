# 经脉图提示词模板 · default

> 类别：其他·写实（`meridian`）。本模板用于经脉图基线审批及其后的素材生成，不定义游戏经脉规则。
> 风格以 [`STYLE.md`](../STYLE.md) 作者原文为准；穴名、经脉名及 ID 只引用 `docs/design/15-meridians-and-acupoints.md`；登记格式见 [`assets/README.md`](../../README.md)。
> 本轮两张基线均为 `candidate`，经作者审定后才能作为批量生成母版。具体生成记录以各自 manifest 为准。

## 1. 风格关键词

- 解剖写实、成年人体自然比例、真实骨性标志与肌肉轮廓、克制的人体线描、透明淡彩。
- 米白纸底、细而稳定的墨褐轮廓、低饱和肤色、均匀柔光、轻微纸纹；纸纹不吞没细线与点位。
- 经脉用清楚连续的细线，穴位用可辨的小圆点；经脉是游戏文化示意层，不画成解剖可见的血管或神经。
- 线路颜色遵循 `design/15` §10.4：阴经青 / 阳经赤 / 调和金；本类任脉、手厥阴心包经用靛青，督脉用朱赤，穴点随所属经线配色。
- 表现重点是身体结构、经脉位置与点位辨识；不加入真气光柱、火焰、符阵或战斗动作。
- 无具体原著人物身份，不借用演员脸；人体图解采取中性、平静姿态，骨盆以朴素布遮覆。

## 7. SVG 标注层规范

- 每张配套 `<同名>.labels.svg`，透明背景，与 PNG 同尺寸；根节点 `width`、`height`、`viewBox` 精确对应实测像素。
- SVG 不嵌入 PNG，不使用外链图像；只含文字、引线、必要的描边 / 点位定位标记，单独文件可透明叠放。
- 每穴一个分组，`id` 等于规范 `ap_*` ID，并写 `data-meridian-id` 与 `data-standard-code`；同文件中 ID 唯一。
- 可见文本采用规范简体穴名；机器属性保留完整 ID 与代码，经脉标题使用规范名称。不要仅靠文字排序推断 ID。
- 引线落到 PNG 实际可见穴点；无穴点或穴点位置错误时先修订候选图，不能用引线掩盖错位。
- 标签不得压住穴点、手指、关节或其他文字；渲染 PNG 与 SVG 的临时合成预览检查可读性，原 PNG 保持无文字。

## 8. 已审定基线的复用方法

1. 检查 manifest 中目标条目已由作者审定为 `approved`；当前 `candidate` 不当作已获批母版。
2. 用 `view_image` 将已审定 PNG 载入对话，实际查看线条、淡彩、人体比例与经脉线点层级。
3. 填好本模板题材、书界、年代、参考图四类占位符，附本次规范穴位清单，再调用 `image_gen` 生成位图。
4. 有本地路径时，以 `referenced_image_paths` 传入已审定参考图；不同时传 `num_last_images_to_include`。PNG 图解默认保留纸底。
5. 将实用的完整正向提示词与排除文本写入新 manifest，登记 `references`、原图路径、实际工具、尺寸与 SHA-256。
6. 针对新图重新定位 SVG 标签；不能因构图相似直接复用旧像素坐标。保留审批状态与版本追溯，不擅自覆盖已审定基线。

## 9. 质检与定位边界

- 风格：确为解剖写实线描加淡彩，人体结构优先；背景、纸纹、阴影不妨碍线点可读。
- 结构：前后视图同体型同尺度；四肢完整；手掌侧、拇指侧和中指明确；无额外或融合手指。
- 经脉：任脉前正中、督脉后正中、心包经上肢内侧；检查局部转折，不把简化游戏连线声称为经典循行全文。
- 配色：按 `design/15` §10.4 核对阴经青 / 阳经赤 / 调和金；任脉及 6 点为靛青、督脉及 7 点为朱赤、心包经为靛青，旧配色不得残留；SVG 锚点描边与位图一致。
- 选穴：分别核对 13 / 9 个点位及名称—ID—标准代码；郄门、间使、内关、大陵不可等距排布；内关不是手背外关。腕横纹到肘横纹按 12 寸核对，从腕横纹沿前臂长轴量起，内关为全长的 2/12、间使为 3/12、郄门为 5/12；记录实测横纹位置、各点坐标及换算寸数，不只凭目测宣称“非均匀”。
- 劳宫：保留掌心辨识度，依 AR-18 用朱赤红心双环表示阳掌“气过阴门”的出口 **（原创扩展）**；此红心是出口强调，心包经主线仍为靛青且续至中冲，不改变劳宫所属的手厥阴心包经。
- 标注：PNG 无字；SVG 同尺寸、透明、无嵌图；标签与实际点位逐个对照，检查字形、碰撞、越界与重复 ID。
- 入库：只保留选中 PNG，基线状态为 `candidate`；未审定不扩批，校验命令见任务报告与 manifest。
