# default · 物品提示词模板

> 范围：兵器、秘籍、丹药及其容器等武侠器物；本地若存在返修基线则保持原字节，AR-20 十一类按 §8 的名录契约批量生成。
> 风格上游：[STYLE.md](../STYLE.md)；登记约定：[assets/README.md](../../README.md)。2026-09-29 作者新风格与本任务工具要求优先于 tech/07 的旧工具及存储口径。
> 年代、物品与武学只引用各自归属文档；具体造型无原著依据时标 **（原创扩展）**，原著外观与年代疑点标 **（待考）**。

## 1. 风格关键词

武侠、名剑辨识度、精工华贵、修长直身双刃、完整剪影、清晰材质、清楚纤细的墨线外轮廓、薄层罩染、克制手绘笔触、冷青灰钢刃、窄银白锋线、银灰装具与少量浅旧金嵌线、墨青缠柄、纸页纤维、柔软哑光纸书衣、细四眼订线、低饱和色、浅暖灰近象牙底、左上柔光、无字、无投影。

- 兵器靠轮廓、刃线与装具表达身份；秘籍靠封皮、页口与装订表达身份；丹药靠形状、表面和经核对的容器表达身份。
- 名剑造型与风格要求：挺拔尖锋、镂空卷云护手、收尖剑根装具、呼应的如意瓣剑首与细回纹；华贵集中在装具，金色克制，不指定或复制任何具体作品的设计。
- 普通器物可以古朴；天下名剑不能把“克制”误解为素圆盘剑首与无识别点的小护手。具体轮廓、纹样、嵌片与比例均为 **（原创扩展）**。
- 光泽、旧化服务材质识别，不把所有物品做成破旧出土物；名剑刃口保持完整。
- 采用墨线与薄层明暗组织形体；同类基线保持手绘程度一致，排除照片级写实与3D渲染感，不烘焙品阶框、文字或游戏数值。
- 秘籍书衣以柔软薄纸、微翘角与边缘少量毛损表达轻度旧化；不画厚硬皮革、大面积龟裂或绳索般粗线。
- 钢、铜、纸、纤维必须有不同质感；药瓶形制、釉色、封口及器物纹饰逐题材核对，不从秘籍基线复制。

| 视角 | 轻微三分之四俯视，主体完整 | 兵器少缩短透视；书册同时显示封面、页口和装订边 |

| 背景 | 均匀浅暖灰近象牙色，匹配已通过书图的RGB中位值(230,225,216) | 无投影、地面、明显底纹或渐变；微小色值波动需实测登记，不能声称逐像素纯色 |
| 文字符号 | 全部留空 | 书名只存元数据，空题签允许；后续界面另排文字 |
| 图标派生 | 保全物品轮廓后缩放；必要时重新生成透明派生图 | 禁止为填满方框截断剑尖、剑首、书角；本设计任务不交付运行时图标 |

以上占幅、留边是美术构图建议，不是战斗数值。历史返修记录中的剑为返修D、`candidate`，书为已通过基线、`approved`；记录称两图均为 RGB、不带透明通道，外圈 60px 的 RGB 中位数均为 (230,225,216)。这些记录不证明当前工作副本仍有对应文件；实际生成前须按 §6 重新检查，不能把浅底误判为 alpha。正式图标应按 tech/07 §2.1、§2.4、§5.6 单独处理背景。

## 6. 参考图使用与登记

1. 先检查 `assets/default/baseline/item/` 与其中的 `manifest.yaml` 是否同时存在。只有 manifest 条目为 `approved`、条目指向的 PNG 确实存在且哈希核对一致时，才能把该图用作参考；任一条件不满足就按 §8.1 的文字骨架无参考生成。
2. 核对新题材的 `eq_*` / `it_*` / `sk_*`、书界与年代；在全仓搜索拟用素材 ID，再按 tech/07 §1.4 命名。
3. 仅在第 1 条全部成立时，用 `view_image` 载入已审定基线的本地 PNG。每张输入明确标为“风格参考图”，同时核对画中缺陷是否已在审批时豁免；目录或文件缺失时跳过本步，不虚构载入结果。
4. 再调用内置 `image_gen`：填入上面的新题材描述；有合格参考图时，`referenced_image_paths` 只能指向第 3 条实际载入的文件，且不与 `num_last_images_to_include` 混用；无合格参考图时省略这两个参数。不通过 CLI/API 另换图片模型。
5. 需要透明背景时明确要求真 alpha，并设 `transparent_background: true`；浅灰底图设为 `false`。不把白底或棋盘格当作透明。
6. 每个返修素材生成 2–4 张候选，逐张先用 `view_image` 检查；选出合格图后从工具原始目录复制到获授权的同名路径。本地若存在已审定基线，其 PNG 与 manifest 条目均逐字节保护，不删除工具原图。
7. 登记新图的完整实际提示词、排除项、参考图 ID/路径、来源、时间、尺寸、哈希与状态。实际无参考输入时写 `references: []`；只有实际输入且通过第 1 条检查的基线才可列入引用。

## 7. 质检与待确认

- 风格：并排检查剑与书是否都有清楚纤细墨线、薄层罩染、克制手绘笔触；书衣柔软、轻旧化，无摄影/3D感、皮革龟裂或过重毛损。
- 名剑辨识：检查护手与剑首的轮廓、精细无字纹样是否形成呼应；不能只给普通剑增加金色。金属局部高光允许比纸册硬，仍须保留线描和薄染，不能靠强光掩盖结构。
- 结构：剑刃/护手/柄/剑首轴线连续；书右边四眼订线须用细线穿孔、沿孔连贯并绕书脊，页口合理，不能只是贴上线条；药瓶口、塞、器壁不穿插。
- 构图：完整主体与剪影、无截尖断角；逐张记录左/上/右/下留边，四边均须≥10%；图标裁切先保证物品完整，再考虑填框。
- 背景：浅暖灰近象牙纯色，无接触投影、落地影、地面或底纹；色值可抽样核对，生成细微偏差需如实登记。
- 年代：按具体书界、族群与身份检查；区分项目定年、原著事实、原创造型与待考事项，不把一般古风当成考据结论。
- 禁止项：无字无伪字，无演员肖像、画师姓名、影视/游戏造型复刻、现代元素、波浪刃文；不搜索或输入影视游戏图片，实际参考只登记已通过自生成基线；原始溯源信息保留。

## 8. 按名录批量出图（AR-20）

### 8.1 输入、拆批与共用骨架

输入固定为 `docs/design/catalog/items-*.md` 十一表。程序逐行读取七列，**一行只生成一项**；输出键使用第一列完整 ID，不按同名合并，不从效果字段反推未写明的外观。每批只取同一文件、同一品阶，便于并排质检；失败重试不得改 ID、名称或出处。
