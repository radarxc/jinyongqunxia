## 1. 风格关键词

按武学的表现材质分开生成，不能把所有招式统一画成水墨。

- **掌劲 / 降龙**：金色为主、整掌宽面生发、大尺度回旋、磅礴动势；金色设色结合水墨虚实、透明叠化、飞白与边缘消散。掌根、大小鱼际、指根下方共同透出宽气幕；不是掌心一点喷墨。龙首略实，龙身透底，不画成金属雕塑或实体龙。
- **气剑类（以内力凝缩成剑的武学，如六脉神剑）不用水墨笔触与晕染**：高密度凝缩、半透明薄刃、锐利边缘、清澈折射、细微震荡环、轻盈错落、离指后才成剑。手、衣袖、背景也全部使用非水墨画法；不靠墨迹、飞白、宣纸或一笔涂开表现运动。
- **六脉配色**：近无色刃体，极浅青 / 赤刃缘作经脉识别。少商 / 中冲 / 少冲青，商阳 / 关冲 / 少泽赤；推导与边界见 §3。不要六色霓虹，也不因整门 `harmony` 而全画金色。
- **背景服务材质**：降龙可用浅暖纸底；六脉用简洁、低反差的冷灰石庭，衬出透明刃面与空气折射，不画纸纹或晕染背景。
- 两张均为概念参考。**画内半透明不等于 PNG alpha**；本轮为 RGB。正式贴图另生成真透明输出并验证合成，不将纸底 / 石庭直接当运行时贴图。

## 2. 构图与画幅

| 项 | 默认值 / 检查口径 | 理由 |
|---|---|---|
| 画幅 | 横幅 3:2；本轮实测 1536×1024 | `1536÷1024=1.5`，为手部与气劲方向留空间 |
| 手部 | 近景，完整五指、合理指节、短指甲 | 先检查手型，再判断气势；不能靠遮挡解释增缺指 |
| 降龙起势 | 整个掌面等宽透出，掌纹仍可辨 | 经脉端穴引用不意味着画成单点喷嘴 |
| 六脉起势 | 指端凝聚，离指后成刃；指尖与气刃间有完整背景净空 | 缩略图也必须看出分离，不能似长指甲或接触皮肤的光剑 |
| 主体布局 | 起手偏左，发力向右；可按题材重新构图 | 六路不交叉；允许长短、角度与远近错落，避免机械排线 |
| 边距 | 手指、剑尖、龙首与角须完整入画 | 入选降龙最上角尖余量紧，后续母版应增加安全边距 |
| 留白 | 旧掌劲约 40% / 剑气约 50% 为试用【建议值】 | 本轮降龙优先磅礴大尺度，未实测分割比例，不强行套旧留白值 |
| 光线 | 金色内光 / 气刃微光可以使用；皮肤结构与透明层次仍清楚 | 不以过曝遮手，不用强光柱替代凝缩质感 |

六脉最终静图表现“气剑已经射出”，凝聚和消散由演示说明。画面净空量不是战斗射程。左右手不得通过水平镜像后处理来纠正映射。

## 4. 排除项

- 通用：文字、汉字、书法、题签、印章、签名、水印、标志、边框、分镜格；图片标注另用排版。不得后处理去除或伪造工具溯源。
- 来源：演员脸、具体影视 / 游戏独创造型、现成插画 / 剧照 / 截图构图；提示词不写演员、画师、公司或作品名；不输入或联网寻找这些参考图。
- 形制：现代物件、现代服装、跨朝代饰物、汉族交领左衽、清式马蹄袖、日式服饰、奇幻甲胄；增缺指、融合指、异常关节、断腕、长指甲。
- 降龙：掌心单点喷口、窄墨管、黑墨球盖掌、由腕部发射、实体金属雕龙、全身硬鳞、带翼西方龙。**金色与金光允许且为主色**，但不能过曝抹掉手部结构和虚实层次。
- 气剑：水墨笔触、墨迹、飞白、宣纸、湿边晕染（包括手 / 袖 / 背景）；气刃贴着指甲、接触手指的连续光尾、六道全出自一指或掌心；实体剑柄 / 护手、冰晶、机械平行激光、浓烟、能量球。
- 两类均避免科幻法阵、游戏 HUD、火焰、电弧、低幼卡通、血腥、裸露；光色服务于气劲，不能替代形态与力量。

材质分支：{掌劲：金色、整掌宽气幕、龙形虚实与透明飞白；或气剑：全画面非水墨、高密度半透明锐刃、折射与微弱震荡}。
发力约束：{全掌宽面同时透出；或六个指端先凝聚、离指保留完整背景净空后成形射出}。
颜色：{有依据的主色与原创边界；六脉按指别映射极浅青赤刃缘，主体近无色}。
背景与光：{降龙浅纸底 / 六脉冷灰简洁石庭}；{内光或微光}，保持皮肤与透明层次可读。
参考输入：{无；或已审定自有基线的准确路径及角色；编辑候选时明确其只是编辑目标}。
原创边界：这是视觉意象，不声称复原原著一帧、医学定位或现实武术动作。

## 6. 使用方法与登记

1. 先核 manifest 的状态和最新作者意见。本轮仍是两张 `candidate`，本类尚无 approved 基线；不得据此启动正式批量生成。
2. 新图每个题材出 2–4 张；每张用 `view_image` 自查后比较。已审定基线作参考或自生成候选作编辑目标时，先查看实际本地文件并在请求中明确角色。
3. 仅使用内置 `image_gen`；纯新图省略参考参数，有本地编辑目标使用 `referenced_image_paths`，不要同时设置 `num_last_images_to_include`。
4. 纸底 / 石庭概念图设 `transparent_background: false`；正式透明贴图设 `true`，另验 alpha 和边缘，不以白底或画内透底冒充透明文件。
5. 入选 PNG 从工具原目录逐字节复制至同名路径，保存原图；不裁切、重编码、镜像或去除溯源。落选图不复制到基线目录。
6. 更新 `subject`、实际 `prompt` / `negative` 全文、`references`、`source_path`、实测 UTC 创建时间 / 尺寸 / SHA-256、作者原话与复核局限；`status` 保持 `candidate`。
7. ID 复用现有两条；新 ID 须先全仓查重。基线 `ref_`、正式特效 `vfx_` 的定义归 `tech/07` §1.4。本轮覆盖已被要求返修的条目，approved 文件与条目保持逐字节不变。
8. `model: gpt-6-astra`、`effort: ultra` 沿 `assets/README.md` 指定执行配置；工具没有返回独立图像后端型号，不将这些字段写成后端实测结论。

## 7. 质检与演示

| 检查项 | 通过口径 |
|---|---|
| 降龙主色与力度 | 金色主导，整掌宽幕生发，大尺度前冲回旋；没有中央喷口或实体金属雕龙 |
| 降龙虚实与透明 | 龙首较实、身体透底，飞白和边缘消隐保留；金光不盖掉五指与掌纹 |
| 气剑材质 | 内力凝缩、薄刃锐缘、透明折射；手 / 袖 / 背景同样无墨迹、晕染或纸纹 |
| 气剑离指 | 六枚气刃与对应指尖之间均有完整背景净空，缩略图不似长指甲；六路主刃可数、非六条拖尾 |
| 气剑色序 | 对照指别与归经逐路检查；近无色主体＋淡青赤边光，不能把 UI 色说成原著固定颜色 |
| 手型与边界 | 每手五指、指节合理、指甲短、腕掌相连；遮挡仍有疑问须报告，不宣称精细解剖母版 |
| 原著边界 | 年代标游戏推定，指法 / 固定颜色待考；原创可见化与六路同帧不改玩法 |
| 图像卫生 | 无文字、印章、人脸、现代物件、外部作品复刻或工具溯源改动 |
| 元数据 | ID / 文件 / 尺寸 / 哈希 / 来源 / 实际请求一致；演示 code 路径存在；状态仍 candidate |

两个自包含演示分别为 `../baseline/vfx/ref_sk_liumai__ch01_base01/index.html` 与 `../baseline/vfx/ref_mv_xianglong18_kanglong__ch02_base01/index.html`，manifest 均登记 `code`。直接打开或使用 `<iframe sandbox="allow-scripts" srcdoc="…">`；无网络、外部资源、localStorage 或父页面访问。均提供暂停 / 重播、强度或浓淡、速度、空格 / R 快捷键；减少动态默认静帧，隐藏时不推进。

- 六脉：清晰石庭与手部示意；指端凝聚 → 离指至少 150 逻辑像素后成形射出 → 消散。循环 5.6 秒，每路错开 0.06 秒；每路 0–0.8 秒凝聚、0.8–3.0 秒成形 / 飞行、3.0–4.1 秒消散。青赤映射见 §3；强度默认 100%。不使用水墨绘制、晕染动画或笔迹渐显。
- 降龙：整掌区域生发宽金气，龙首凝形与龙身飞白；循环 5.6 秒，0–1.9 秒生发，3.8 秒起退隐；浓淡默认 82%。保留金色、水墨虚实与透明叠化。
- 两者逻辑画布 1400×788，DPR 上限 2，滑杆强度 / 浓淡 40–140%、速度 0.5–1.5×。全是本地审美默认，秒数不换算战斗 CT；HTML 是独立程序化概念演示，不是 PNG 逐帧转换。
- 本轮已做 JS 语法、隔离 Canvas 行为 / 控件测试和外部资源扫描；真实浏览器预览因工具权限未完成，sandbox 中的真实渲染、跨设备兼容性和帧率仍**（待实测）**，不把脚本桩测试当作视觉验收。
