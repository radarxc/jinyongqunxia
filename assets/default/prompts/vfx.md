## 1. 风格关键词

水墨意境、虚实相生、墨分浓淡、透明叠化、湿墨晕染、干笔飞白、断续轮廓、以留白写气、收锋与消隐。力量通过墨迹的疏密、方向、粗细与消散速度表现。

- 掌劲：发力起点略实，浓墨仅作骨架；气劲扩展后仍能透底，龙形可辨但不凝成实体动物。
- 指端剑气：淡墨侧缘、纸白核心、断续而尖细的收笔；六道可数，空白之间不以雾团连成一片。
- 色彩：以墨色和浅暖灰为主；纸白参与构图，少量肤色与布料色服务于手部结构。
- 此轮为审美概念图，浅纸底可保留。**图内半透明观感不等于 PNG alpha 透明**；正式运行时贴图须另做透明输出与合成验证。
- 不用旧 S3 图标规则强行增加粗描边、饱和度或满屏金光；不把参考图当作可直接装箱的运行时贴图。

## 2. 构图与画幅

| 项 | 本轮默认值 | 质检理由 |
|---|---|---|
| 画幅 | 横幅 3:2；本轮实测 1536×1024 | `1536÷1024=1.5`，为手部起点及气劲方向留空间 |
| 视角 | 手部近景，三分之四侧面或略俯视 | 掌心或发射指尖必须可见，不能由衣袖替代起点 |
| 主体布局 | 发射源在左侧约 1/4，气劲向右展开 | 仅为本轮构图偏好，可重新构图；人物与手部不得水平镜像纠错 |
| 留白 | 掌劲约 40% 起、剑气约 50% 起【建议值】 | 供风格审阅，非自动分割测量结果、非运行时硬预算 |
| 画内边界 | 所有关键起点与主要收梢留在画内 | 降低后续裁切截断与首尾不清问题 |
| 光线 | 漫射环境光，左上微亮；不以发光表现力量 | 由墨色层次与负空间保持可读性 |
| 人物信息 | 默认只画手腕、手掌与少量袖口 | 暂不引入人物脸型、具名服装与建筑考据变量 |

手型检查必须先于气势判断：一手五指，指节连接合理；掌劲由掌心、剑气由指端，不能从腕部或悬空点出发。遮挡无法判明时保留候选并登记问题，不宣称通过解剖验收。

## 4. 排除项

- 不要文字、汉字、书法、题签、印章、签名、水印、标志、边框、分镜格；标注另用字体 / SVG，不让图像模型写字。
- 不要现代元素、现代服饰、跨朝代服装、汉族交领左衽、清式马蹄袖、明代网巾、日式服饰、欧式奇幻甲胄。
- 不要真人演员肖像、剧版独创造型、已有画作 / 插画 / 剧照复刻；不用在世或近现代画师姓名作风格词。
- 不要霓虹、激光、蓝色电弧、火焰、满屏金光、科幻法阵、游戏 HUD、塑料 3D、动漫大眼、血腥、裸露。
- 不要多指、缺指、融合指、断腕、异常关节；不要把全部六道剑气从一根手指或掌心发出。
- 降龙额外排除实体龙、带翼西方龙、全鳞片硬壳、金龙；六脉额外排除实体剑、能量球、机械平行光束。

负面提示词只约束新画面；不得通过后处理去掉或伪造生成工具自带的水印 / 溯源标识。

## 6. 使用方法与登记

1. 查看 `../baseline/vfx/manifest.yaml`。本轮两张均为 `candidate`，**尚无 approved 基线**；作者审批后才进入正式批量参考集。
2. 在 manifest 中确认参考条目已获审定，再用 `view_image` 载入它的实际本地 PNG，让图像出现在对话中。
3. 把模板里的 `{题材}`、`{书界}`、`{年代}`、`{参考图}` 及其余占位符填成明确描述，说明参考图只承担风格参考角色。
4. 调用内置 `image_gen`。本地参考图通过 `referenced_image_paths` 提供；目标只有对话图像时使用最小必要的 `num_last_images_to_include`，两者不要同时用。新建基线无参考时两项均省略。
5. 纸本概念图设置 `transparent_background: false`；正式要求透明贴图时设置 `true`，生成后实测 alpha 与边缘，不以浅白底冒充透明底。
6. 每个新题材独立调用，保留原图。复制选中 PNG 到所属目录，登记原始路径、实际尺寸、SHA-256、完整实际提示词、排除项和实际参考列表。
7. 基线用 `ref_`，正式特效按 `tech/07` §1.4 使用 `vfx_`。新增 ID 先全仓查重；不能覆盖原基线来伪造审批历史。
8. 本轮实际完整请求见 manifest 的 `prompt`；其中已含 `negative` 的逐字文本。`model: gpt-6-astra`、`effort: ultra` 按任务要求记录执行配置；独立图像后端型号未由工具返回。

## 7. 质检与演示

| 检查项 | 通过口径 |
|---|---|
| 虚实 | 浓墨只在必要结构；边缘消隐，不能整条气劲同样实 |
| 透明叠化 | 能在淡墨层之间看见纸底；图内观感与文件 alpha 分别记录 |
| 墨晕与飞白 | 湿边有晕开、干笔有断续；不能仅用平滑烟雾或高斯模糊代替水墨 |
| 出手位置 | 掌劲接掌心，指气接指尖；手部五指可数，发力点不被墨团遮挡，不出现悬空气劲 |
| 六脉计数 | 六条独立主路径；飞白碎线不能被误看成额外剑气；手别与指别需复核 |
| 原著边界 | 不编引文 / 回目；年代注明游戏推定；新视觉隐喻注明原创 |
| 图像卫生 | 无文字、印章、演员脸、现代物件、明显手型错误；不去除工具溯源 |
| 入库一致性 | 文件名、ID、尺寸、哈希、参考来源、candidate 状态一致；落选图不入库 |

六脉附带 `../baseline/vfx/ref_sk_liumai__ch01_base01/index.html`。直接双击打开即可循环播放；页面提供暂停、重播、墨浓与速度控制。它以六个抽象指端表现分路与墨迹变化，属于**（原创扩展）**独立效果实验，不是位图替代品，也不是招式伤害、距离、行动 CT 或医学模型。参数与完整用法见 HTML 头部注释。
