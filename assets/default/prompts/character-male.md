> 用途：`assets/default` 男性人物基线与后续批量生成；本文件提供提示词，不定义人物、年代或运行时立绘规格。
> 上游：`assets/default/STYLE.md` 作者原文、`assets/README.md`；年代见 `docs/design/02`，服饰与素材 ID 见 `docs/tech/07` §2.7 / §1.4。

> 标注约定：美术补足为**（原创扩展）**；未完成三联/广州修订版逐字核对为**（待考）**；后端与接口能力未核实为**（待核实）**。当前两张均为 `candidate`，尚不能充当已审定参考。

## 1. 风格关键词

武侠、男性偏写实、真实骨相、自然不对称、皮肤与筋腱质感、可信年龄、布料纤维与受力褶皱、朴素材料、江湖气、克制的手绘笔触、低饱和设色、简洁淡墨或纯色背景。

写实程度服从 `STYLE.md` 的作者新要求，不强制套用 `tech/07` §2.1 旧版工笔重描边。皮肤保留细节；俊美、粗犷、衰老分别服从人物描述，不把所有男人画成同一张粗糙脸。武侠气质由神态、姿态、衣装和兵器表达。

## 2. 构图与画幅

- 默认单人全身立像、三分之四正面、平视，完整保留头顶、双足、兵器尖端；允许七分身，但须在提示词和清单写明，不在关节或兵器关键部位随意裁切。
- 竖幅 `2:3`；本轮实际输出 `1024×1536` RGB PNG、非透明背景。它是风格参考，不是 `tech/07` §1.3 的 `2048×3072` RGBA 正式立绘母版。
- 成年人物比例参照 `tech/07` §2.6 的约 7.5 头身；体型、年龄与伤残状态优先于比例模板。
- 人物占画高目标 88–92%（引用 `tech/07` §1.3），背景低对比；逐张检查头顶、足底和兵器周围留白，不将目标冒充实测值。
- 柔和左上主光，脸、手、衣料和兵器结构可读；不以强逆光、雾气或特效遮住结构。灰暖纸底可以带轻微纹理，不烘焙文字、印章和复杂场景。
- 汉地交领衣必须右衽：穿着者左襟压右襟。禁止水平翻转图片；不要用画面左右代替人物自身左右。

## 4. 排除项清单

不要文字、伪字、题款、签名、印章、logo、装饰水印；不要现代服饰、拉链、腕表、运动鞋、数码物件；不要真人演员脸、明星相貌、剧照构图和影视独创造型；不要以在世或 20 世纪以后画师姓名作风格词，不以受保护的具体画作为复制源；不要动漫大眼、偶像磨皮、塑料皮肤、模型渲染感、日式刀具、欧式奇幻铠甲、赛博或蒸汽朋克；不要日式浪人式松散发髻飘带、前结宽腰带、日式圆盘镡或菱形缠柄；不要非乞丐身份的撕裂式破衣，华山弟子不得有撕裂、毛边和碎布条；不要时代混搭、错误衣襟、额外人物、多余肢体或手指、手物融合、悬空装备、弯曲断裂剑刃、容不下剑刃的短鞘；不要血腥、裸露、恶搞丑化、夸张肌肉、发光兵器、龙形能量和复杂背景。

不去除或伪造工具自带的溯源标识；要求不生成装饰水印不等于允许后期去标。后续作者提及的其他作品角色图仍须先确认来源与使用范围，本模板默认仅使用项目自生成且已审定的基线。

## 6. 使用步骤

1. 读取当前 `STYLE.md`、人物分册、章节与年代条目，先确定身份阶段；在全仓搜索目标素材 ID，复用已有 `npc_*`，不覆盖旧图。
2. 从 `baseline/character/male/manifest.yaml` 选择作者已确认、状态为 `approved` 的基线。本轮为监督返修，两图仍待作者审批，当前 `candidate` 不直接升格为批量参考；返修结果见清单 `notes` 与报告第 7 节。
3. 用 `view_image` 载入选中的本地基线到对话，明确“仅作风格参考”，然后将其实际绝对路径传入 `image_gen` 的 `referenced_image_paths`，配合替换完成的新题材提示词。不要仅写文件名便假称模型已看过图片。
4. `image_gen` 生成新图时维持本模板质感、光向与背景；新角色的脸、服饰与时代按描述重建。同一人物的变体则明确哪些面部识别点必须保持。真实调用参数和最终完整提示词逐次登记，参考资产写入 `references`。
5. 首次新基线或按文字重新生成候选、没有图像参考时，不传 `referenced_image_paths` 或 `num_last_images_to_include`。后续同时存在本地路径的参考只用 `referenced_image_paths`，不同时传两个参考参数；逐次登记实际调用，不能把早先轮次的次数沿用到返修。
6. 逐张检查第 7 节。保留工具原文件，将入选原图复制入获授权目录，用 Pillow 实测尺寸、`shasum -a 256` 实测哈希；不擅自裁切、镜像、放大或去标。未通过的项写进 `notes`。
7. 新产物默认 `candidate`；作者审批后才成为批量生成基线。正式 `por_*` 等产物还须满足各自运行时母版规格，本轮 `ref_*` 不直接入运行时。

## 7. 质检要点

| 项 | 人工检查 |
|---|---|
| 人物与阶段 | 是否为要求的人物、年龄与身份；是否误用后期官爵、门派或装备 |
| 写实程度 | 骨相、皮肤、手部和布料真实，性格可读；不统一成偶像脸或同一张粗犷脸 |
| 年代与服饰 | 汉地汉式交领默认右衽，其他服制按已核实的人物设定检查衣襟；发式、袖口、鞋履与身份一致；族群不能覆盖成长背景；不能水平翻转 |
| 网巾 / 裹巾 | 令狐冲额上能看见黑色细网带箍发、头顶束髻；萧峰深色裹巾整体包住发髻；无松散发髻、飘带式浪人造型 |
| 衣物整洁与时代差异 | 令狐冲为明代直身 / 道袍式士庶常服，白色护领、开衩、普通布带，仅少量风尘；萧峰灰色旧袍只少量磨损，不共用撕裂破衣模板 |
| 手与兵器 | 手指数量与关节自然、握柄合理；剑刃笔直且与柄对齐；中式小型剑格，无日式圆盘镡或菱形缠柄 |
| 剑鞘长度 | 入鞘时剑柄、剑格、剑首与长鞘连接清楚，鞘须足以容纳整把剑刃；出鞘时空鞘与剑刃等长或略长，封尾完整、挂点可解释 |
| 构图 | 头足与兵器端点不被裁切；留白足够；姿态不依赖遮挡掩盖手和器物结构 |
| 质感一致性 | 同系列主光、写实程度、背景与布料相近；角色之间保留骨相、体型和身份差异 |
| 原创与考据 | 衣色、衣装选款和磨损等美术补足明确登记；指定版本未逐字核对时保留（待考） |
| 禁止项 | 无文字、现代物件或影视独创造型；未使用演员/剧照参考。人工相似性复核不等于对全部演员零相似的认证 |
| 文件与清单 | PNG 可打开，尺寸/哈希一致，原路径可追溯；完整 prompt/negative、实际参考、工具与状态准确 |
