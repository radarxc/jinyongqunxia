# 地图提示词模板 · default 古风水墨

适用：`assets/default` 地图基线与审批后的地图素材。风格依据 [STYLE.md](../STYLE.md)，目录、工具、入库和状态依据 [assets/README.md](../../README.md)。作者 2026-09-29 的决定优先于 `docs/tech/07-asset-generation.md` 中旧风格、旧工具入口及“二进制不入 Git”口径；本轮使用 `image_gen`，PNG 原图入库。

年代只引用 `docs/00-canon.md` §2 与 `docs/design/02-timeline-and-world-tiers.md` §1；地名、地理数据与时代状态只引用 `docs/design/19-world-map.md`、`docs/design/map/cities.yaml.eras[chNN]` 及对应章节。本文不另定城市开放状态、边界、投影或旅行距离。

## 1. 风格关键词

- 古风水墨、山水写意、宣纸纤维、温暖纸白、浓淡干湿墨、飞白、疏朗留白、远山淡墨、烟岚轻染。
- 以墨色层次区分山脊、水系、城池和道路；城墙、塔、驿路是小幅地图符号，山川仍是主体。
- 水面以留白、淡墨岸线和少量细波表现；道路用细淡墨笔触，避免高对比网格和现代公路图感。
- 光线为均匀柔和的纸面散射光；不出现摄影棚高光、油亮材质或强烈电影光效。
- 地名、题签、方位与图例由独立 SVG 排版。位图不生成汉字、伪字、印文、签名或装饰性书法。

## 2. 构图与画幅

| 项 | 默认规范 |
|---|---|
| 基线目标 | 横向 3:2；本轮两图 Pillow 实测均为 1536×1024，后续输出仍逐图测量并登记 manifest `size` |
| 全国总览 | 北上、南下、西左、东右；近俯视的山水地图，保留主要山系、水系与政权的相对位置 |
| 地方局部 | 北上；苍山在西侧、洱海在东侧，城与三塔位于苍洱之间；重点地标清楚而不铺满画面 |
| 边缘与留白 | 四边保留纸面余量；提示词沿 `tech/07` S2 请求留白至少 35%，水面、云雾和平缓地带提供标签空隙；本轮未作面积分割测量，不把目检估算写成实测值 |
| 比例与视角 | 山峰和地标可为识别适度夸张，整体朝向固定；不水平翻转、不为了构图倒置东西关系 |
| 精度声明 | 本类 PNG 是风格与构图参考；人工估位标签不具备 `design/19` 正式 Albers 投影或 WGS84 精度 |
| 生产尺寸 | 正式导航底图、分块和运行时规格另见 `design/19`、`tech/06`；不由本轮目标尺寸覆盖 |

本轮两幅均需保留可识别的地理关系。全国图不用现代国界、省界或硬政区分割；“大宋、大辽、西夏、大理、吐蕃”是时代语境标签，不据此宣称完成历史疆域考定。

## 4. 可替换提示词

填写占位符后，把正向模板与本节负向清单完整合并为实际 `image_gen.prompt`；manifest 分别保存实际使用的 `prompt` 和 `negative`，不只登记模板名。当前工具没有独立负向字段时，负向文字仍须送进 prompt。

```text
为《金庸群侠传·天书录》默认风格包制作一幅古风水墨地图。
题材：{{题材}}。书界：{{书界}}。年代：{{年代}}。
参考图：{{参考图}}；只继承已审定参考的水墨层次、纸本质感、留白和地图符号语言。
地理依据：{{地理依据}}。必须保持的相对位置与方向：{{相对位置}}。
主要地标：{{地标}}。画面边缘延伸方向：{{画外方向}}。
构图：{{构图}}，北上南下、西左东右，近俯视山水地图，横向3:2，目标1536×1024。
山脉用浓淡墨和干笔皴擦，河流与湖面以留白和淡墨线表现，城池与道路用细小墨笔符号。
温暖纸白、细微宣纸纤维，柔和均匀纸面光，疏朗云雾；纸纹不盖住河道、城墙或佛塔。
在{{标签留白区}}保留疏朗空隙，水面、云雾、平地纸白合计目标至少35%。地图默认无人物，不生成任何文字、题字、印文或方位字。
形制：{{年代形制}}。此图为山水地图美术示意，不作精确历史疆域图或建筑复原图。
排除项：{{排除项}}。
```

通用排除项全文：不要文字、汉字、字母、数字、伪字、书法、题跋、印文、签名或装饰水印；不要现代城市天际线、公路、铁路、汽车、电线、现代桥梁、景区设施、卫星底图、经纬网、现代国界省界；不要跨时代城楼宫殿、日式鸟居、欧美城堡或奇幻铠甲；不要摄影写实、3D 塑料材质、赛博朋克、霓虹、动漫大眼、艳丽重彩；不要人物特写、真人演员脸、影视独创造型；不要在世或近现代画师姓名风格、受版权保护的具体画作或剧照复制；不要血腥特写或裸露；不要错误方位、重叠城池、断裂主河、湖中城墙或缺失／增生佛塔。

“不生成水印”指不主动画装饰水印；不得删除、掩盖或伪造工具自带的溯源标识，沿用 `tech/07` §2.9、§9 的项目约束。

## 5. 基线状态与复用流程

| 基线 ID | 题材 | 本轮状态 |
|---|---|---|
| `ref_map_jianghu__ch01_base01` | 天龙书界山川总览：大宋、大辽、西夏、大理、吐蕃 | `candidate`，待作者审批 |
| `ref_map_dali__ch01_base01` | 大理苍山洱海、国都、崇圣寺三塔与无量山方向 | `candidate`，待作者审批 |

两图都属于本轮审图候选，**当前不得据此开始批量生成**。后续必须确认对应 manifest 已由授权流程登记 `status: approved`；文件存在、自动检查通过或生成者自评合格，都不等于作者审批。

1. 读取已审定基线条目，确认 ID、`file`、`sha256` 和批准状态；选择与新题材相符的全国或局部基线。
2. 用 `view_image` 打开该 PNG 的本地绝对路径，并把预览载入对话；先检查纸纹、浓淡、留白和地标语言。
3. 以第 4 节的新题材描述调用内置 `image_gen`；本地参考通过 `referenced_image_paths` 传入同一 PNG 绝对路径，`transparent_background: false`。
4. 已有本地路径时不用 `num_last_images_to_include`，更不能与 `referenced_image_paths` 同传；文字写“参考某图”不能代替实际传图。
5. 基线图只负责风格一致性；新书界地理、时代城名、形制和开放范围重新读取上游，不能继承旧图地名或错误方位。
6. 生成后用 `view_image` 审图；保留原文件，复制入授权目标目录，再建同尺寸 SVG。不通过者不混入选中素材目录。
7. 按 `assets/README.md` 登记原始路径、完整实际提示词、负向文本、参考 ID／路径、时间、实测尺寸和 SHA-256；新生成图仍从 `candidate` 开始。

调用关系示意（占位符须替换；不是 shell 命令）：

```text
view_image({path: "{{已审定参考PNG绝对路径}}"}) → 载入对话并查看
image_gen({
  prompt: "{{完整正向描述与排除项}}",
  referenced_image_paths: ["{{已审定参考PNG绝对路径}}"],
  transparent_background: false
})
```

本轮为从无到有的基线生成，manifest `references: []`；不为它们倒填尚不存在的审定参考。实际工具按本任务登记 `tool: "codex exec · image_gen"`、`model: gpt-6-astra`、`effort: ultra`，不把会话模型名解释为已验证的底层图像模型版本。

## 6. SVG 标注叠加层

- 每张位图配 `<同名>.labels.svg`，`width`、`height` 与 `viewBox` 均按 PNG 实测宽高设定；背景透明，文字保持可编辑。
- 标签使用规范简体中文，字体优先清晰的中文宋体／衬线回退；需交付字体时另按许可证登记，不把字体名称当作已经嵌入。
- 根据选中图可见的山、湖、城和塔估位，必要时用短引线；标签不压住关键形状，不飘出画布，预览时与 PNG 等比同原点叠合。
- 总览优先标“大宋、大辽、西夏、大理、吐蕃”和少量城名；城名取 `eras.ch01`，例如“东京开封府（汴梁）”“兴庆府”“上京临潢府”。
- 局部优先标“苍山”“洱海”“大理国都（羊苴咩城）”“崇圣寺三塔”“往无量山”；方向提示放在南偏东的画面出口，可另加“方向示意”。
- 三塔按题材标“崇圣寺三塔”。天龙寺与崇圣寺的关系仅沿 `design/17` §5.3 的小说映射，不把小说院落当作测绘事实；江南线的“天宁寺”不得混入。
- 明示“北”可放在 SVG 方位箭头旁；不在位图中请求模型写字。不得添加会使人误以为有精确投影或实测比例的经纬格、公里尺。
- 在 manifest `notes` 写明 SVG 文件名、人工估位、北上构图，以及地望或形制待考事项。SVG 不计入基线 PNG 数量。

## 7. 质检与验收

| 检查项 | 通过条件 |
|---|---|
| 风格 | 山水写意、纸本质感、留白、浓淡墨均清楚；城市与道路和地貌同属水墨语言 |
| 方向 | 北上；全国五地相对位置合理；局部苍山西、洱海东，无量山向南偏东延伸 |
| 年代 | 本轮约 1093–1094；城市按 `ch01` 显示；没有明清或现代形制混入 |
| 地标 | 三塔数量与高低关系可辨；大理城、三塔与洱海不互相吞并；不把小说锚点实测化 |
| 干净位图 | 无生成文字、伪字、印文、签名或额外装饰水印；工具溯源标识保持原状 |
| SVG | XML 可解析、与位图实测尺寸相同；字形可读、位置有对应、地名无错别字 |
| 追溯 | 原图存在，文件复制与 SHA-256 一致；实际提示词、负向文本、尺寸、时间、状态齐全 |
| 审批 | 自动检查与作者审批分开；候选不标成 `approved`，不提前批量 |

本轮目录门禁：`python3 tools/agents/check_assets.py assets/default/baseline/map --min 1 --max 2`。另需逐张 `view_image` 检查画面，并叠合预览 SVG；目录检查通过不代替视觉、原著或历史地理核对。
