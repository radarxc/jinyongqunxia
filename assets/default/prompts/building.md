## 结论先行（TL;DR）

建筑采用写实古风：以真实空间、木石瓦材质和自然光影表达年代；按具体地域、功能、等级及修缮阶段选择形制。后续生成应加载作者已审定的同类基线，继承写实程度和材质表达，再按新题材重建结构。宋寺的灰瓦、大斗拱与清宫的黄琉璃、官式彩画分别适用，不能互相搬用。

## 1. 风格关键词

- 写实古风、历史建筑环境概念图、可信大木作、可读柱网与承托关系、整齐瓦垄、克制旧化、在用建筑。
- 木纹、朱漆、石础、灰缝、陶瓦或琉璃的不同反光；自然日光、清楚的檐下环境光与接触阴影。
- 通过屋顶坡度、出檐、斗拱尺度、屋脊和梁枋彩画区分时代；同时检查地区、建筑等级和用途。
- 不烘焙水墨晕染、宣纸纹理或游戏 UI；此类采用作者新的写实要求，旧 S2 水墨留白比例不直接套用。

## 2. 构图与画幅

| 项 | 【建议值】与执行要求 |
|---|---|
| 基线画幅 | 横向 3:2，目标 1536×1024；两张现有候选均实测达到。公式：1536÷1024＝1.5＝3÷2 |
| 基础机位 | 正常建筑摄影透视，约 35mm 观感、三分之四视角；保持垂线与可信尺度，非鱼眼 |
| 主体安排 | 一座单体或一组有明确主次的建筑；完整保留脊顶、檐角、柱脚，避免植被遮住识别特征 |
| 组景 | 寺院可斜向展示山门与后殿，宫城可展示角楼与相接城墙；殿序调整须标（原创扩展） |
| 光线 | 默认秋日左上侧柔光；阴影可读，不用逆光剪影或浓雾代替斗拱细节 |
| 人物与文字 | 基线默认无人、无文字、无牌匾字；如需地名，由后续独立叠加层排版 |
| 交付 | 保留原始 PNG；不为凑画幅拉伸、裁断屋脊或上采样冒充生成尺寸；短边至少 512 像素 |

本表仅约束风格参考，不改变 `tech/02` 的运行时相机、像素密度或精灵规格。每次生成后以实际尺寸登记；工具能力不由提示词目标值保证。

### 3.2 本轮两个年代的区别与考据边界

| 检查轴 | 北宋少林候选 | 清初紫禁城角楼候选 |
|---|---|---|
| 形制 | 宽缓屋面、深出檐、山门与主殿的木构层次 | 紧凑复合歇山屋顶；城墙约10米、外侧连续雉堞垛口；角楼坐于城隅墙顶须弥座，石栏在垛口后 |
| 斗拱 | 较大、疏朗、承重关系可读 | 相对柱身较小且密集规整，不能变成宋寺大铺作 |
| 屋脊 / 瓦作 | 灰筒板瓦与克制吻饰 | 黄琉璃与复合屋脊；不画成普通宝塔 |
| 彩画 | 暗朱木柱与少量低饱和梁枋装饰 | 朱红、蓝绿及点金；角楼按旋纹彩画语汇研究 |
| 材质 | 木材、灰陶瓦、石阶，有限风化 | 釉瓦、朱漆、石台、砖墙，有维护痕迹 |
| 未核部分 | 1093–1094年的殿序、具体面阔、山门、大殿、石栏灯幢、地貌与彩画 | 康熙年间的台基栏杆、精确十字平面、屋面接合、脊兽和彩画 |

上述是两张候选的视觉对照，不是“所有宋建筑都如此、所有清建筑都如此”的通则。少林三间山门 / 五间主殿是提示词中的概念目标（原创扩展），不能据此宣称图片已满足开间数或史实。

初祖庵的北宋建造记录不能直接证明天龙年份的大雄宝殿原貌；其用途是提醒研究者区分单体与时期，见 [郑州市文物局·初祖庵](https://wwj.zhengzhou.gov.cn/country/3175053.jhtml)。

故宫资料记载角楼明建清修，屋顶为歇山组合，使用黄琉璃及旋纹彩画；本轮据此选取清式视觉语汇，康熙时期的每一处细部仍（待考），见 [故宫博物院·角楼](https://www.dpm.org.cn/explore/building/236522.html)。

材质与光线：写实古风，{木材/瓦/石/砖/漆/釉}；{主光方向与天气}，暗部构件可读，自然接触阴影，克制旧化。
复原边界：{有史料的部分}；{原创布局与待考细节}，不将概念图称为测绘复原。
人物与文字：{默认无人、无文字、无牌匾字；有额外需要则单独声明}。

## 5. 排除项清单

通用负面提示词全文：

```text
不要文字、汉字、伪字、匾额字、书法、签名、品牌、主动添加的可见水印、图例、边框、拼图或游戏UI；保留工具原生水印及溯源信息。
不要现代建筑、混凝土结构、电线、天线、电灯、监控、消防器材、扩音器、旅游标牌、隔离栏、车辆、游客或现代天际线。
不要真人演员脸、影视剧版独创造型、受版权保护具体画作或剧照的直接复制，不使用在世或20世纪以后画师姓名作为风格词。
不要日式鸟居、日式天守阁、欧式奇幻、赛博或蒸汽朋克、仙侠悬浮宫殿、卡通、动漫大眼、水墨晕染、宣纸纹理或塑料渲染。
不要跨朝代斗拱、屋顶、彩画、服饰和器物；不要额外堆叠层檐、夸张反卷飞檐、无支撑屋顶、熔化构件、错位柱网、穿插屋脊或杂乱断裂瓦垄。
不要过度HDR、泛光、镜头光晕、浓雾遮挡、漆黑檐下或夕阳剪影；不要裸露、血腥、恶搞人物。
```

年代追加：宋寺排除清宫黄琉璃满铺、清式密集小斗拱和后世御笔匾额；紫禁城角楼排除泛化宝塔、天坛、天安门和无依据的全金和玺；不要把城墙画成灰瓦墙帽的院墙，不要缺少雉堞，不要在护城河岸上加汉白玉栏杆，不要在河岸与城墙之间画成排树木，不要外凸石砌墩台；驳岸用条石垒砌、垂直陡直。追加项须按新单体核查，不能把灰瓦 / 琉璃瓦选择当成唯一断代依据。

## 6. 加载参考图与入库用法

1. 先查 [建筑清单](../baseline/building/manifest.yaml) 的 `status`；只选作者明确批准的 `approved`。当前两张均为 `candidate`，本轮在交付审批材料后结束。
2. 用 `view_image` 加载已审定的本地 PNG，使参考图进入对话。明确说明它是“风格参考”，同时填写新题材、书界、年代和形制；跨朝代只迁移写实表现，不复制时代构件。
3. 调用内置 `image_gen`，本地参考用 `referenced_image_paths` 传入上述路径；不同时设置 `num_last_images_to_include`。纯文生新基线不传这两个字段，`references: []`。
4. 每题材独立调用。完整保存实际提示词和排除项；实景网页只作文字研究，不把页面照片自动当图生图参考。
5. 先看图再选择。选中图从工具返回的真实 `source_path` 复制到授权资产目录，保留原文件，不修改工具标记；不用代码绘图代替生成，也不以代码重绘修补构件。
6. 按 `tech/07` §1.4 先全仓检索拟用 ID；基线用 `ref_<已有主体ID>__chNN_<变体>`。正式建筑使用 `bld_`，正式任务再确定路径，不能把参考图直接登记为运行时建筑。
7. 清单顶层用列表，完整字段依 `assets/README.md`。`references` 登记实际输入的参考图 ID、路径及版本 / 哈希；无图片输入就为空。原始提示词、实测尺寸、SHA-256、生成时间与来源路径逐张记录。
8. 执行下列校验；脚本只验证文件和元数据，不替代历史、审美及作者审批。

```bash
python3 tools/agents/check_assets.py assets/default/baseline/building --min 1 --max 2
```

本轮实际调用为 `image_gen({prompt: 正文 + 两个换行 + 排除项, transparent_background: false})`，未传任何参考图参数。清单 `prompt` 已包含这一完整字符串，`negative` 另存相同排除项便于检索；复跑清单时直接使用 `prompt`，不再重复拼接 `negative`。

## 7. 质检要点

| 检查 | 通过条件 | 未通过处理 |
|---|---|---|
| 题材 | 山门与大殿 / 角楼与城墙（含雉堞）可辨，主体完整；驳岸无栏杆，石栏仅在墙顶基座周边 | 重新生成或定向修改；不得靠文件名补足缺失主体 |
| 年代 | 形制、斗拱、脊饰、瓦作、彩画与目标年代及建筑等级相容 | 标明资料不足；明显时代冲突不得批准 |
| 结构 | 柱础落地、梁枋承托、斗拱与屋檐连接清楚，复合屋顶无明显断裂 | 放大原图核查并登记；风格图不能充当施工或测绘资料 |
| 材质与光 | 木、瓦、漆、石可区分，阴影和高光可信，无塑料感 | 调整材料描述或光线 |
| 两朝区别 | 宋寺与清宫从轮廓、构件尺度、瓦色和彩画都能区分 | 按形制返工，不仅调色 |
| 排除项 | 无文字水印、现代物、跨时代装饰、肖像或未授权参考输入 | 淘汰并记录原因；不擦除工具原生标记 |
| 来源 | 作者批准的参考图和实际调用文本可追溯，概念复原注明原创与待考 | 保持 `candidate`，补齐资料再审 |
| 文件 | 原PNG、尺寸实测、哈希一致、ID无冲突、清单可解析 | 先修元数据或文件，再执行脚本 |
