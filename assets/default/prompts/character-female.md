## 1. 风格关键词

武侠、女性偏美丽、古典东方审美、清丽、自然精致五官、青年而不低幼、真实骨相、写实偏理想化、细墨线、柔和层染、丝织物自然垂坠、轻微纸本质感、克制光影、简洁背景。

- 面容美丽但保留骨相与人物差异；避免统一网红脸、动漫大眼、摄影级毛孔锐化和塑料皮肤。
- 工笔式细线用于面部、发丝和衣缘，水墨只辅助气氛；衣褶、手部和轮廓必须可读。
- 表情、姿势、发髻和衣着共同表现人物身份。王语嫣以文静博学为锚，小龙女以素白清冷为锚。
- 参考图提供线条、明暗、材质和美感尺度；不得把参考人物的脸、衣色、发饰无差别复制给新人物。

## 2. 构图、画幅与交付规范

| 项 | 本轮 / 后续用法 |
|---|---|
| 画幅 | 竖版 `2:3`；本轮两张实测 `1024x1536`，用于风格参考；正式立绘母版规格另见 `tech/07` §1.3，不将基线等同正式母版 |
| 取景 | 默认完整全身；可按任务改为七分身。平视、正面或轻微三分之四侧身，中性透视，不使用广角畸变 |
| 占幅 | 全身提示目标为约九成画高；发髻、手指、衣摆、鞋尖不得裁断。七分身须在描述中明确裁切位置 |
| 姿势 | 单人单视图，站姿重心可信，衣袖不掩盖全部手部；不加无关人物、分格、面部特写框 |
| 背景 | 不透明纸白、纯色或无具象物体的极淡墨气息；轮廓须与背景分离；人物识别不依赖场景 |
| 光线 | 左上方柔和漫射光；白衣用浅青灰褶皱分层，不画强泛光或硬地面投影 |
| 文件 | 保留工具原始 PNG，复制入库；不镜像、不裁切、不重新编码，不去除工具自带的溯源信息 |
| 文字 | 不生成题字、标注、印章、署名和书本伪字；确需标注时另做叠加层，本类别本轮无叠加层 |

先填完占位符再提交。无图初创省略 `Input images`；使用图像参考时必须实际加载对应文件，不可只在提示词里写路径。

```text
Use case: stylized-concept
Asset type: 《金庸群侠传·天书录》default 风格包，人物·女，单人角色设定参考。
Primary request: {题材：人物姓名、既有 npc_ID、身份与性格}；{书界：chNN_名称}；{年代：朝代、地域、族群与原著阶段}。按已核实的小说描述作原创视觉设计，不参照真人演员或影视造型。

Subject: {年龄段、骨相、眉眼、脸型、体态、独有识别锚}。古典东方审美、女性偏美丽，自然精致、无低幼或网红化；各人物应有清晰不同的脸型与神态。
Costume and hair: {符合该书界年代、族群、身份的衣服形制、配色、发式、饰件}。交领左右衽按身份核对，衣料不透明，衣褶受力真实。{原著明确细节及来源；其余具体设计注明原创扩展}。
Pose and composition: {全身或七分身、正面或轻侧、自然姿势、是否持已核实道具}；单人单视图，平视、中性透视，主体轮廓完整，手和衣着结构可读，不裁断发顶、手指或鞋尖。
Style/medium: 武侠人物插画；细墨线勾勒，柔和层染，轻微水墨气息；写实偏理想化的自然骨相与温润肤质，真实布料垂坠，精致手绘感。
```

通用排除项：不要文字、伪字、题字、印章、署名、水印、logo；不要现代元素；不要真人演员脸、明星脸、剧照、剧版独创造型；不要在世或二十世纪以后画师风格名，不复制具体画作；不要动漫大眼、低幼脸、统一网红锥子脸、丰唇滤镜、浓妆磨皮、摄影写真或三维塑料感；不要裸露、透明服装、色情化、血腥特写或丑化；不要日韩动漫风、和服、欧式奇幻铠甲、赛博或蒸汽朋克；不要时代与族群混搭、错误的衣襟叠压、无依据的兵器与仙法特效；不要多肢、多指、粘连手指、错接手腕、失重衣料、裁断头脚；不要复杂场景、多人物、分格、强烈泛光。

宋代本轮追加排除项：不要唐代齐胸襦裙、明式马面裙、清式旗装、马蹄袖、大拉翅、夸张头冠和无依据的繁复珠宝。其他年代须改为对应错误项，不能把宋代专用排除清单直接用于明清人物。

“不要水印”是请求不生成装饰性水印；工具已有水印、元数据或溯源标识原样保留，不去除、不伪造。

## 5. 参考图用法与登记

1. 查看 `assets/default/baseline/character/female/manifest.yaml`；只有作者已批准且登记为 `approved` 的条目才能用于正式批量生成。当前两项仍是 `candidate`。
2. 从归属的 `chapters/`、`catalog/npcs-*` 获取新人物 ID、年龄段与阶段，查 `design/02` 年代、`design/19` 地点及 `tech/07` §2.7 服饰方向；先检索 ID，复用已有主体。
3. 用 `view_image` 载入已审定基线到对话，实际查看图像。调用 `image_gen` 时用 `referenced_image_paths` 指向已查看的本地图，并在提示词中注明“风格参考：保留线条、材质、美感尺度；人物身份、五官、服饰按新描述生成”。不要仅把路径写进文字充当图像输入。
4. 所有参考图都有本地路径时统一使用 `referenced_image_paths`；若有只能从对话引用的图，按工具契约用最小必要的 `num_last_images_to_include`，两种机制不同时填写。本轮无输入参考，生成调用未填写两者，登记 `references: []`。
5. 每个题材独立调用一次内置 `image_gen`。完整保存实际提交的 `prompt`（包括 `Avoid` 段）和同文 `negative`；模板不是本轮调用日志，精确原文在 manifest。
6. 生成后逐张目检，选中 PNG 原字节复制至任务指定目录，保留原始生成文件；使用 `ref_<npc_ID>__chNN_baseNN` 形式命名参考图，正式立绘另依 `tech/07` §1.4 用 `por_`。
7. 记录来源路径、ISO 时间、实际尺寸、SHA-256、工具与参考输入。新图始终从 `candidate` 开始，不能因校验脚本通过自动升级为 `approved`。

本轮按任务要求登记 `tool: "codex exec · image_gen"`、`model: gpt-6-astra`、`effort: ultra`。其中 model/effort 为任务指定的执行配置标签；本次 `image_gen` 返回图片与原始路径，未回传底层图像模型或推理档位凭据，不把标签当作已核实的图像服务模型名称。

## 6. 质检要点

- 题材：人物身份、书界和时代一致；王语嫣不做战斗动作，小龙女白衣清冷，不以神仙特效代替气质。
- 美感：古典、精致而自然；不是幼童、动漫、网红写真或真人演员肖像。作者仍须复核主观相似性，不能声称已穷举排除所有演员。
- 差异：比较脸型、眉眼间距、嘴角、下颌、发髻和姿态，防止新人物只改衣色；本轮两图面部与发式较近，列入审批关注点。
- 服饰：服装、发式、饰物适合朝代与身份；沿实际覆襟边线判断左右衽，禁止镜像。具体裁制未经专项考证的保持原创设计标记。
- 结构：手指、手腕、肩颈、重心、衣褶与落地关系自然；小龙女的同色领层须细看，不用一条内层斜线代替覆襟判断。
- 构图：头发、四肢和衣裙未异常裁切；全身或七分身符合要求；背景简单、主体可分离。
- 画质：无伪字、文字水印、额外人物和现代元素；白衣不融进纸底，阴影不过重。保留工具自带溯源信息。
- 工程：顶层列表、每图一条、`candidate`、原图来源完整；尺寸与哈希实测；运行 `python3 tools/agents/check_assets.py assets/default/baseline/character/female --min 1 --max 2`。
