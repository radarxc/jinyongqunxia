## 结论先行（TL;DR）

三张内置 `image_gen` 白底原件，每张四帧，分别为家族、碧回归一、观潮归元。
三记普通招共用家族；五招均为 `inner / yin / projection:false`、支援自身。
掌图仅用于独立示意，直接引用 `../emitters/palm/`，不复制或改变发出方原件。
`moves/` 每招的 YAML 是合成参数真值，JSON、peak 和 demo 均由现有脚本导出，全部 `candidate`。

## 造型与原著边界

图鉴明确将本功名称、五个招名、机制标为（原创扩展）。青碧来自阴性风格要求，无已核原著显色描写。
家族是双股回环青气与花瓣形内息；碧回归一是瓣状回卷聚拢；观潮归元是层叠潮环回收，均为（原创扩展）。
“潮”仅是形态意象，不构成音波、离体伤敌或新增治疗段；恢复、护盾、Buff 唯一按图鉴执行。
黄药师以内力驱动碧海潮生曲的叙述仅引用图鉴；三联 / 广州修订版《射雕英雄传》的相关人物、情节措辞尚未逐字核对（待考），不写引文或回目号。

## 原件、切帧与标定

每套只生成 1 候选并选入该候选。真实请求全文见 `source_requests.json`，工具未披露图像后端型号或 effort。
请求尺寸为 1024×1024，实际原件均为 1254×1254；按真实尺寸切 2×2 格，每格 627×627，保留原件字节。
顺序为左上初聚、右上峰值、左下持续、右下消散；普通相位 `[0,5/12,0.8,1]`，绝招 `[0,7/18,0.8,1]`。
使用 `white_key / cutoff=250 / key_full=163 / dewhite=true`，不腐蚀、不裁掉墨点、不重画轮廓。
试算 `white_luma` 的深青像素最大误差达 6/255；选定现有参数后最大误差 1.014534/255，低于 2/255 建议。
三套黑 / 灰 / 白预览均已 `view_image` 查看后删除；12 帧 8 px 边框残留、残余白边比均为 0。

| 效果套 | 共用局部锚点 | 峰值根宽实测（alpha≥128 连续段） | 参考长（峰值前端边界 − 根 x） |
|---|---|---|---|
| family | `(112.5,321)` | x=112，y=193..448；`448−193+1=256` | `568−112.5=455.5 px` |
| 碧回归一 | `(115.5,299.5)` | x=115，y=106..492；`492−106+1=387` | `584−115.5=468.5 px` |
| 观潮归元 | `(155.5,317)` | x=155，y=87..546；`546−87+1=460` | `567−155.5=411.5 px` |

锚点是峰值主根连续段的像素中心中点，各帧共用同一根部接触位置；并非假定生成器严格实现提示词坐标。
残余尾丝不用于根宽，参考前端按 `alpha>1` 可见像素半开边界取值。帧间墨纹变化交 crossfade；真实连续观感（待实测）。

## 长度与节奏核算

共用掌面：原锚点 `(850,704)`、方向 `[1,0]`、截面 320 px。示意缩放 0.6，基尺 `W=320×0.6=192 px`。
本套所有 `range_hex=0`，显式正 `length_px` 遵循 `design/23` §4.2 自指局部图约定；不用 `0×pixels_per_hex` 生成零长效果。
`pixels_per_hex=256` 是未启用的演示标尺；五招没有外放升档，不套 `projectionSpreadSteps` 或 +2/+4。

两模板直接来自 §5.2；峰值为 `(c+r)/T`，亮度 `[0.8,1,1,1,0.8]`、normal 混合、纸底 `#EFE6D2`；不把收招 CT 换成秒。

## 复现与验收

仓库根目录执行（已有合格 RGBA 时跳过切帧）：

```sh
for e in assets/default/vfx/sk_taohuaguiyuanjue/effect/*/effect-set.yaml; do
  python3 tools/vfx/cut_frames.py --config "$e" --output "$e" --root assets/default/vfx/sk_taohuaguiyuanjue
done
for c in assets/default/vfx/sk_taohuaguiyuanjue/moves/*/composition.yaml; do
  python3 tools/vfx/compose.py "$c" --root assets/default/vfx
  python3 tools/vfx/build_demo.py "$c" --root assets/default/vfx
done
```

共享发出方要求 root 为 `assets/default/vfx`；单门检查再约束 effect 只能在本套、emitter 只能在共用池。
`validation.json` 保存几何、尺寸、视觉检查与共享原件 SHA-256；五招 schema / HTML 检查记录归档在 `.agents/coord/_asset_logs/assets/default/vfx/sk_taohuaguiyuanjue/vfx-check.jsonl`。
已查看碧回归一、观潮归元、潮回护体的峰值，掌面接续、方向、留白合格，未见白边；其余普通招复用同一原料与锚点。
