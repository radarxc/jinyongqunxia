城门逻辑占地采用上游 `(k+4)×4`、通行孔 `k×4`，非历史测量。其他占地为 **【建议值】**。高度对象的画布没有 2:1 比例要求；2:1 指地面格投影。

规范化取原图可见底面左、右接触角点 `L/R` 的水平跨度，尺度 `s=32×(w+h)/(R.x-L.x)`；两门地面跨度目标 384/448，直墙 64，墙角 128，桥 256，葡萄架 224 px。**不以 PNG 包围框宽、屋顶或树冠代替地面标尺。** alpha≥16 包围框只裁掉外部噪点留白；裁图按上述单一尺度等比缩放，再补四周 8 px。PNG 含挑出部位，最终宽不必等于地面目标宽+16。

## 已检查与限制

- 第2轮仅对点名六项调用内置 image_gen，共 10 次有效生成：k4 / 直墙 / 墙角 / 桥各 2 次，k6 / 葡萄架各 1 次；每个源图与规格化成图均经 `view_image`。第1轮 13 个候选及一次无效墙角路径调用的记录继续保留；胡杨本轮无调用。
- 七张成品为 PNG RGBA，alpha 实测 0–255；源图真透明，门洞可见灰底贯通，树叶 / 栏杆 / 架柱间留透明。缩放使用 LANCZOS，插值可能让源图 254 的最高 alpha 达到 255，未手工补实心点。
- 无人物、文字、现代配件或整块土地底座；轮廓完整且有透明边。暖浅土墙、素木、灰绿叶色与宋包写实材质 / 左上光基本一致；西域土色明显更暖，为地域差异。
- 第2轮 k4 首候选仍误用了风格参考的窄进深，选第二张仅按精确几何参考纹理化；两门改为直墩、平顶土墙与木楣，保留土砖写实语汇，属于地域游戏构型 **（原创扩展）**，不声称历史门形复原。
- 第2轮桥首候选前轴约 +0.536，第二张 +0.520 通过；墙 / 墙角首张底面已通过，但高度不统一，第二张统一 3 m。第1轮比较量点与提示词仍见历史 `geometry-qa.jsonl`、`source/refinement-records.jsonl`；本轮每次真实调用另存 `source/round2/*-record.json`，不覆盖原记录。
- 已解决：六项严格双轴与宽深比验收均通过（见上表）。城门前孔已量测；完整碰撞孔掩膜、墙件连续接缝及桥面通行层仍未总装测试，不能以渲染 PNG 轮廓反推碰撞。`candidate` 沿用原登记状态。
- 本轮只含 `r000` 门与桥、一个外墙角，未覆盖四向或所有内外转角；不通过二维旋转生成缺失朝向。

## 开放问题（附默认值）

- 三城与不同书界的具体年代形制：默认通用绿洲地域意象，史证不足部分标 **（待考）**，不引用现代重建门楼作为历史原样。
- 灌渠木桥是否使用：默认仅在布局已有可跨小渠时装配，不强加河道、不启用港口服务。
- 胡杨、葡萄架是否作为城内常设植物：默认留作可选装饰，由布局选择可种植地块，不能堵路或城门通行孔。
- 运行时四向 / 精确掩膜 / 无缝墙件：默认本包供静态预览及候选参考，正式运行依 `design/22` §4.3 的 3D / 掩膜契约补齐。
