## 生成追溯与复验

`manifest.yaml` 登记7个选中成品；`source/` 保留当前选中原图、历史源及输入副本。`generation.jsonl` 保留提示词、候选历史、源图与输入哈希、人工测点。第3轮只重出k4，2候选选2，新增2次内置 `image_gen`（此前18次，本套件贴片累计20次）；旧选图保存在`__before_repair3_selected.png`，两候选与提示词见`__revision3_c1/c2.png/.json`。其余6贴片及登记逐字节不动。未知底层模型、seed与effort不编造；created取原文件mtime转UTC。k4比例从3.2972改善至2.2465，仍未通过10%占地阈值；默认继续candidate，不宣称返修全部通过。

`normalize.py` 可从保留的原图重放首轮裁切、等比缩放（整数像素舍入）和透明padding；墙角第10轮仿射由 `../building-map/qing_north/repair_affine.py` 的同批流程及manifest矩阵追溯。不使用外部抠图或新增运行时依赖。

```bash
python3 assets/default/tile/qing_north/normalize.py
python3 tools/agents/check_assets.py assets/default/tile/qing_north --min 5 --max 10 --min-side 32
```

数量、尺寸、hash与manifest检查已通过。自动检查器不检查斜率、物种、历史准确性或门洞碰撞对齐，不能把结构检查通过写成上述项目全部通过。
