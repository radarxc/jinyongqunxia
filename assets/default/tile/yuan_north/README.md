## 几何处理与自查

仅作矩形裁边、等比 LANCZOS 缩小、四周补 8 px 透明边；不涂改 RGB，不以透视变换冒充纠正相机。第3轮两门沿引导每米(64,32)源像素，精确1/2缩小到既定(32,16)标尺；不靠改占地追认图形。其余硬体仍按底面宽度 `32×(w+h)` 缩放，锚点按同一变换转换。植物没有可见方形底面，采用树高 5 m **【建议值】** 与 `tools/town/render_town.py` 的垂高系数 `16√6 px/m` 推导等比尺度；虚拟种植菱形不视为视觉量测。

全部源图与成品分别 `view_image` 自查，PIL 确认为 RGBA、背景及门洞采样 alpha=0。源图预览的暖色晕圈多数在 alpha=0 像素内；成品缩放保留透明，没有绘制棋盘背景。所有素材维持宋基线低饱和灰瓦、土木石细颗粒和左上光的密度；植物按华北类型变化。

已解决第2轮两门净孔3.701/5.570m及k4右轴−0.3878的问题：第3轮k4全底面`+0.5020/-0.5058`、k6`+0.5016/-0.5039`，门墩各段底边与木楼底框也在±0.03内；净孔分别`257×0.5/32=4.015625`、`384×0.5/32=6.000000`格（脚点±2源px，约±0.03格/点）。已解决：直墙与墙角轴约`±0.504`，共尺度垂高约117.5px，折算2.998m≈3m（见两墙`__qa.yaml`），原角件1.8m问题已修正。桥仍`+0.529/-0.471`，两植物无平直边，不在本轮返修范围。

桥为整体石拱桥候选预览件，桥面和近侧栏尚未拆成不同绘制层，不能声明已支持行人栏杆遮挡。`autotile_mask:null` 表示单件定向放置，没有伪造完整自动拼接表。已解决：墙高与几何接续统一；仍有可见重复纹理接缝，门孔、其他方向及整城装配留待后续验收。
