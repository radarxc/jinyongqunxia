## 生成、处理与验证

- 初版与第2轮使用内置 `image_gen`；第3轮返修经同一Codex图像后端API，两门各2候选取第2。源图与成品均逐张 `view_image`；候选原图不计交付数量。
- `manifest.yaml` 记录最终提示词、输入、哈希与保存位置；`source/` 保留历史及第3轮 `__r03c*.png/json`，图像JSON不含凭据或图像正文。
- PIL仅作裁切、等比LANCZOS缩放与透明补边；k4另修除右石基底边下方0–7源像素抗锯齿毛边。没有RGB重绘、孔洞补画、拉伸、旋转或透视变换。
- 初版其余贴片曾用alpha≥128轮廓拟合 `32×(footprint.w+footprint.h)` px；第3轮两门改按alpha≥2裁框、620px内容宽等比缩放。阈值仅用于测量/裁框，不代表底面对格。
- 7张成品均为RGBA、alpha范围0—255；第3轮两门补16px透明边，其余5件文件字节不变；锚点均未越界。
- 历史第2轮源图预览的棕色外晕是alpha0隐藏RGB；第3轮成品边界alpha=0，无实际背景。
- 已运行 `python3 tools/agents/check_assets.py assets/default/tile/mongol --min 5 --max 10 --min-side 32`，7图、0问题；`python3 tools/lint/check_ids.py --strict` 退出0。

## 装配限制与默认值

- 门外宽 `k+4`、进深4、左右门墩各2格沿用 `design/22` §4.3；4格门8×4 / 通行孔4×4，6格门10×4 / 通行孔6×4。逐图 `metadata/` 记录 `G` / `P` 局部整数掩膜、偶数偏置和 `G-P` 碰撞规则。
- 第3轮两门锚点按实测外底角L/R中点换算 **【建议值】**。k4轴率+0.4614/-0.6148、宽深比2.0444；k6为+0.5095/-0.4673、宽深比2.4642；均满足审核轴率0.40–0.62与比例误差≤30%的口径。
- 可见前门孔占长边比例为0.4444/0.5942（目标0.5/0.6），折算约3.556/5.942格。k4视觉孔偏窄约0.444格，仍由4×4逻辑掩膜保证通行并保持candidate；k6视觉孔已对齐。详情见metadata的`geometry_qa`。
- 木栅直段、转角接缝，桥栏遮挡和图内高度比例尚未做运行时装配验收。桥为完整静态带栏精灵，后续动态单位遮挡需拆分栏杆；本轮不修改装配器。
- 仅交付本轮要求的单视图，不冒充四向齐备。植物是地面装饰意象，非 `design/22` §4.4 单独审批的宋城 `prp_*` 公告板植物；精确物种及古代分布 **（待考）**，默认采用通用草原禾草 / 旱生灌木意象。
