## 几何与验收边界

1. 第4轮仅返修两门与墙角：城门按门墩/净孔/门墩的2:k:2前沿控制点作分段横向缩放与逐列纵移；墙角对三格L形候选按外轴与接口高规格化。三者均保持竖线竖直，其余4项逐字节未动。
2. 建筑性物件按目标包络 `32×(w+h)` 与人工读出的源底面宽度计算缩放；底面 / 根部锚点单独人工估测，不从透明包围框下沿猜测。植物占地为冠幅建议值。
3. 7 张成品 alpha 实测均为0–255且四边透明；两门净孔最终实测4.000/6.000格，墙角接口高124px，与直墙一致。运行时碰撞仍 **（待实测）**。
4. 第4轮两门和墙角双轴实测均为+0.500/−0.500；门宽深比、净孔和墙角高度已按像素坐标复算通过。整城接缝、碰撞与遮挡仍 **（待实测）**。
5. 门楼只交本次要求的单方向候选。`geometry.yaml` 的 8×4 / 10×4 外框和 4×4 / 6×4 通行孔是逻辑目标，需在后续总装配准；不以绘画轮廓自动生成碰撞。
6. 石桥为本次整跨静态贴片，不替代运行时分离桥面 / 近侧桥栏的遮挡实现。植物未交 design/22 §4.4 的两变体、公告板截根与四向视图合同。
