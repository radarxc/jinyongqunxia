# 明 · 江南建筑套件

19张透明PNG地图单体，全部 `candidate`；本批与7张 [年代贴片](../../tile/ming_south/README.md) 配套。
用于南京、苏州、杭州地域意象，全部为匿名原创建筑组合，不是具名古建测绘复原。

- [浏览本套件](preview.html)：19建筑与7贴片，直接显示入库PNG。
- [统一清单](manifest.yaml)：最终ID、完整实际提示词、真实参考输入、占地、底面锚点、尺寸及SHA。
- `sources/`：选中源图、逐张提示词与候选记录；部分弃选候选保留用于追溯。
- `normalize-root.py` / `normalize_major.py`：两组几何规格化记录的重建脚本；各自产出清单片段，统一清单为交付入口。

画风取宋江南基线的写实瓦木石质感，明江南变化为更鲜明的白灰墙、灰黑瓦、直线木窗、天井商住和护运货栈。历史文字依据与访问日期见提示词模板§11及任务报告；未把古建网页图片下载进模型。
部分调用直接输入宋图作编辑目标，另有从头生成或以本轮候选作目标的调用；后两类以人工目视比对和文字约束对齐宋基线，不能宣称每次都作宋图条件生成。具体输入以 `references` 为准。

## 尺度与可用边界

1. 逻辑尺度引用 `design/22`：每格64×32px；底面包围宽 `32(w+h)`，高 `16(w+h)`。此2:1指地面投影，不是PNG画布宽高比。
2. 明代冻结占地为小民居7×6、商铺7×5、衙门16×13、镖局15×12、王府22×18、寺观14×11。其余为宋江南同功能占地 **【建议值】**，大民居按院落10×8；详见清单。
3. `building.anchor` 是最终PNG左上原点下的底面中心估计；用源地面角点的对角线中点推算，再随对应几何变换、裁框与 padding 换算，不用PNG中心或底中点代替。
4. 第4轮对审核点名的13项作分段横向缩放与逐列纵移；以三处底面实测点锁定精确±0.5轴和登记占地比例，且保持所有竖线竖直。其余6项逐字节未动，完整矩阵与哈希见 `revisions_r4/verification.json`。
5. 原图alpha=0处可能保留灰褐RGB，判断可见背景以alpha合成为准。保留原始生成通道；小软影与半透明抗锯齿边缘不强行全不透明。
6. 第4轮返修的13项双轴实测均为+0.500/−0.500，水平分量比与 `building.footprint` 一致；底面对角线中点锚点已复算。其余6项沿用已通过审核结论；整城拼装仍 **（待实测）**。
7. 每类型只有原向一个视图，入口约朝画面左下；没有GLB、四向图、碰撞或遮挡多边形。运行时不得旋转PNG冒充另一方向；河埠仅装饰，不新增港口服务。
8. 每类最多2次生图候选；每张成品单独 `view_image`。原生地面尺度独立于透明画布，禁止导入时再按整张PNG宽度缩至占地。

`created` 为本轮生成 / 规格化登记时间（ISO），不表示历史建筑建造时间；底层图像模型与seed未由工具披露，不编造版本。软件版本、API价格和浏览器兼容性不属于本批新增事实。
整城贴图、墙门接缝、人物遮挡仍 **（待实测）**；本轮点名13项严格几何已通过像素复算，具体年代细部与作者画风认可仍保持开放，默认不升级为 `approved`。
