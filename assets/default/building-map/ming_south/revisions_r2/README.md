# 第 2 轮返修候选档案

仅针对合入审核点名的 13 张建筑；既有通过项不重出。
本目录中的图片不是新入库成品，不应被城镇总装扫描使用。
当前交付仍以父目录 `manifest.yaml` 为入口；拒选源图不改变该清单。

每个子目录记录本轮最多两个 `image_gen` 候选、原始提示词与实测底面角点。
`guide.png` / `geometry-guide.png` 是代码绘制的底面几何参考，不是建筑素材。
灰底或标线图仅用于质检，不得当透明素材导入。

双轴按同一地面左角 L、前角 F、右角 R 计算：

- `m₁=(Fy−Ly)/(Fx−Lx)`，`m₂=(Ry−Fy)/(Rx−Fx)`，目标 `+0.5/−0.5`、容差 `±0.03`。
- 水平分量比 `(Fx−Lx)/(Rx−Fx)` 必须对应原登记 `w/h`。
- 相对比例误差为 `abs(实测比/(w/h)−1)`；不能修改逻辑占地来迁就画面。
- 人工测点有像素读数误差；底面应避开台阶不同高度、屋檐及阴影。

工具原始预览可能显示 alpha=0 区域残留的 RGB 光晕；须以实际 alpha 合成判断背景。
拒选不等于返修完成。最终结果与三项指定检查见 `tools/agents/reports/KIT-ming_south.md`。
