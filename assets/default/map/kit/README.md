共 `12 + 4 + 6 = 22` 件小样；另有1张对照表，不计入小样件数。
大体量地形、河流与大城为1024方图；道路、关隘、小聚落和标记为512方图。
所有PNG均为RGBA，四角及整个最外缘alpha为0。原图的真实alpha由内置image_gen生成并保留。
为满足规格，完整原画幅等比缩到目标边长的90%，居中补透明边距；未抠底，未裁主体，未用代码绘制素材内容。
manifest含完整逐图提示词、两张基线输入、原始保存路径、原始/交付尺寸与SHA-256；独立图像后端未披露，不猜测型号。
`prompts.json`为实际提示词集合，`generation.jsonl`为生成来源记录，`validation.jsonl`为逐图数值校验。

笔墨以深/中/淡灰墨皴擦为主，沿用基线淡赭、灰绿树点与极淡灰青水色。
主体内保留宣纸纤维与纸白雪坡，整幅宣纸底由后续渲染器统一提供，避免贴图各带矩形纸块。
建筑均为识别性概念（原创扩展）；具体时期的城垣、屋脊与宗教建筑形制（待考），本轮不作历史复原。
山岭、湖岸、河流的轮廓只供审样，后续仍须受GIS几何约束，不能直接充当真实地理数据。
两条河流和两条道路是独立笔触样本，端部自然收笔；未实现沿任意曲线连续铺设或无缝拼接。

合计 `22 + 41 = 63` 件贴图；加1张对照表，manifest登记64张PNG。新增8件1024方图、33件512方图；完整原画幅等比缩至目标边长90%并居中透明补边。41件均由内置 `image_gen` 单独生成真透明底，输入江湖总图、大理两张基线和同类小样；山峰原无小样，参照已通过的山脉小样笔墨。各件重设计轮廓与构图，保持三级墨、披麻皴、飞白、湿墨渗化、淡赭灰绿与灰青水色，以及主体内纸感和近俯视散点透视。

`kit`用于拼合取件，63件贴图及对照表均有该字段：

- `kind`：`map_kit_`之后的首段；标记取`ico_map_kit_`之后的首段。
- `volume`：`large / medium / small`，表示画面体量；已有小样尺寸保留。
- `orient`：山脉、雪山、关隘填写`ew / ns / nesw / nwse`，表示画面长轴或地景走向；其余为`none`。河谷关隘为纵向河谷，长墙段为横向墙线。
- `anchor`：以左上为原点，取alpha≥32有效主体包围盒`[l,t,r,b)`的底边像素中点，`x=(l+r-1)/(2W)`、`y=(b-1)/H`，保留六位小数，排除极淡漂浮墨点；用于主体落位与遮挡排序，非地理坐标或点击范围。

`role: sample`表示原22件，`role: variant`表示新41件。拼合器按`kit.kind`取这两类；`role: contact_sheet`必须排除，对照表的`kind: contact`只是清单描述。
[_contact_sheet.png](_contact_sheet.png)改为20组品类分行，同类小样在前、新件在后，标品类名、合计与小样/新件数；浅格和深底预览仍仅属于对照表。
