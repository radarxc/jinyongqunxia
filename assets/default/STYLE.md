# 默认风格包（default）

## 作者原文（2026-09-29，照录）

> 现在减少并行的traeX到8个（重新分配一下任务）。然后新开一组Assets的创作任务，调用本地的gpt（gpt-6 astra ultra）生成所有素材（8个子agent）
>
> Assets将按照统一风格创建，目前一个风格，未来可能有多个风格（多个mod）
>
> 默认风格
> 地图 - 古风水墨
> 城镇 - 写实古风（按城市和对应年代生成，符合年代特征）
> 建筑 - 写实古风（符合年代特征）
> 人物 - 武侠 + 女性偏美丽，男性偏写实
> 招式 - 水墨意境（虚实，透明等）可以是运行的视觉效果代码
> 物品 - 武侠
> 其他- 写实 - 经脉图等
>
> 要求
>
> 1. 城镇、建筑、人物（男女）、招式、物品、经脉图等 先生成一到两张，风格符合要求的，作为后续基线参考（这一批生成后，我审批，然后再继续）
> 2. 后续生成的assets，每次生成，输入对应的基线参考和描述，人物可以再加上知名作品的角色画像，生成最终assets

> 不是调用traex，是调用gpt-cli，我已经装了gpt本体了

> 二进制素材要入库，在本地repo里开一个assets/default目录，存相关assets，最终要提交

> 城市图要45度视角（主角要能在城市地图上移动）

> 建筑分两种， 一种是类似立绘，另一种是要拼到城市地图上，第二种要45度

## 各类风格规则（默认风格）

| 类别 | 目录 | 风格 | 要点 |
|---|---|---|---|
| 地图 | `map` | 古风水墨 | 山水写意、留白、纸本质感；地名用规范字，文字尽量由代码 / SVG 叠加 |
| 城镇 | `town` | 写实古风 | 按具体城市与所属书界年代生成，城墙、街市、屋顶形制、服饰人群须符合年代特征；城市图为 45 度视角，主角要能在城市地图上移动（作者原文） |
| 建筑·立绘式 | `building` | 写实古风 | 类似立绘的单张建筑图；形制、斗拱、屋脊、材质、彩画符合年代特征（宋 / 元 / 明 / 清等） |
| 建筑·地图拼接 | `building-map` | 写实古风，45 度 | 要拼到城市地图上的建筑，45 度视角（作者原文）；视角、投影方向、光源、比例须与城镇 45 度图一致 |
| 人物·女 | `character/female` | 武侠，偏美丽 | 古典东方审美，服饰符合书界年代；不写实到失去美感，也不低幼化 |
| 人物·男 | `character/male` | 武侠，偏写实 | 真实骨相与质感，服饰、兵器符合年代与身份 |
| 招式 | `vfx` | 水墨意境 | 虚实相生、透明叠化、墨迹晕染；可交付可运行的视觉效果代码（如自包含 HTML / Canvas / WebGL）配概念图 |
| 物品 | `item` | 武侠 | 兵器、秘籍、丹药等；质感清晰，适合图鉴与图标裁切 |
| 其他（经脉图等） | `meridian` | 写实 | 解剖写实风格的经脉图；经脉与穴位以 `docs/design/15-meridians-and-acupoints.md` 为准，文字标注优先由代码 / SVG 叠加，避免图像模型写错字 |

## 通用约束

- 年代依据：`docs/design/02-timeline-and-world-tiers.md`（书界年代）、`docs/tech/07-asset-generation.md` §2.7（服饰时代感）；城市依据：`docs/design/19-world-map.md`。
- 禁止项沿用 `docs/tech/07` §2.9 与 §9：不用真人演员肖像、不仿在世画师风格名、不以受版权保护的具体画作做图生图源。作者"人物可以再加上知名作品的角色画像"一条，用于后续正式生成，具体来源与授权范围待作者确认后再启用。
- 每张素材都要在所在目录的 `manifest.yaml` 登记（字段见 `assets/README.md`）。
