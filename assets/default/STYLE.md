## 各类风格规则（默认风格）

| 类别 | 目录 | 风格 | 要点 |
|---|---|---|---|
| 地图 | `map` | 古风水墨 | 山水写意、留白、纸本质感；地名用规范字，文字尽量由代码 / SVG 叠加 |
| 城镇 | `town` | 写实古风 | 按具体城市与所属书界年代生成，城墙、街市、屋顶形制、服饰人群须符合年代特征；城市图为 45 度视角，主角要能在城市地图上移动（作者原文） |
| 建筑·立绘式 | `building` | 写实古风 | 类似立绘的单张建筑图；形制、斗拱、屋脊、材质、彩画符合年代特征（宋 / 元 / 明 / 清等） |
| 建筑·地图拼接 | `building-map` | 写实古风，45 度 | 要拼到城市地图上的建筑，45 度视角（作者原文）；视角、投影方向、光源、比例须与城镇 45 度图一致 |
| 人物·女 | `character/female` | 武侠，偏美丽 | 古典东方审美，服饰符合书界年代；不写实到失去美感，也不低幼化 |
| 人物·男 | `character/male` | 武侠，偏写实 | 真实骨相与质感，服饰、兵器符合年代与身份 |
| 招式 | `vfx` | 水墨意境 | 虚实相生、透明叠化、墨迹晕染；可交付可运行的视觉效果代码（如自包含 HTML / Canvas / WebGL）配概念图；气剑类（如六脉神剑）例外：是靠内力凝缩的气剑效果，不用一笔画出再晕染的水墨效果（作者原文）。**外放招式制作方式（作者原文）**：分两部分——① 外放效果白底图（连续多帧，Python 抠成多张透明 PNG）；② 发出方图（掌法用掌，剑法用剑加手）；程序按发出方向把效果叠到发出方上成整图，多帧加 Python 过渡成动效。作者 2026-09-30 再次明确：「其实就是几个图，然后用代码合成」——每招的原料只有两张生成图（一张白底效果帧图、一张发出方图），其余全部由 `tools/vfx/` 的代码切帧、合成、出动效，不另外手绘或逐帧生图 |
| 物品 | `item` | 武侠 | 兵器、秘籍、丹药等；质感清晰，适合图鉴与图标裁切 |
| 其他（经脉图等） | `meridian` | 写实 | 解剖写实风格的经脉图；经脉与穴位以 `docs/design/15-meridians-and-acupoints.md` 为准，文字标注优先由代码 / SVG 叠加，避免图像模型写错字 |
