## 2. 敦煌同址双相位

唐代保存中轴与两翼回廊；六室包络、入口 (46,69)、核心 (46,21)、奖励 (54,21)、回返厅 (16,63) 在清代全部复用。`X` 是场内回返厅标记，沿南廊回到 `E`，不创建第二个地理 POI 或虚构外部传送目标。

清代在中轴 `q44–48/r34–36` 静态封门，西廊 `q20–22/r24–26`、东廊 `q70–72/r26–28` 坍塌；入口、两侧室淤沙，西室经 `(26,36)→(30,36)→(30,27)→(36,27)` 的盗洞进入核心。封门是不可走地形，不是剧情门禁对象；所有剧情属性仍留默认。

从磁盘比较两份地形层：859 格 GID 不同，95 格唐代地面在清代变阻挡，新增可走格 47，清代淤沙 603 格、碎石 63 格；可走格 `2112−95+47=2064`。封闭盗洞喉口 `q29–31/r31` 后，唐代奖励仍可达、清代不可达，证明路线发生实际变化。此封闭仅用于检查，不写入交付图。地下结构与唐初建 / 清残损均为原创布景，不能据此宣称历史遗址复原。

## 3. 对象与内容交接

复用原 `terrain.tsj` / `height.tsj`，GID 起点 1 / 49；地图头为 Tiled 1.12.2、有限正交，48 px 编辑格。`terrain/height/deco/objects` 齐全，deco 空；没有新 tileset 或贴图。

`entry` 保持 `safe=true, entry=true, facing=0`；`return_exit` 为可反复触发的安全位置。`survey_1…3`、`core_inspect`、`reward_inspect` 及各 `*_inspect` 都是合法局部 Trigger，未写 `eventId/action/textKey`；没有伪造 `Chest.lootRef`、`EnemyZone.encounterId`、Door 或 QinggongGate 引用。`Light` 与 `CameraHint` 只给表现参数。

达摩洞的 `q_01_qiyu_82`、若耶溪的 `q_01_qiyu_75` 与可靠题签仍交 CONTENT 绑定；达摩后壁只有壁前调查位，额外 qg4 观察位及入口与少室山的双端门仍需下游补完整。九老洞、华山、敦煌的深入条件按上游**（待设计）**，本批不授予剧情通行许可。回返 Trigger 也尚未绑定离场动作；图中 R 不会实际发奖。

除达摩洞外各留一个 7×7=49 格候选战区，共 5 个；`4+4=8≤49≤400` 且两轴跨度 `7≤20`，是沿第一批的站位容量**【建议值】**，并非敌人投放数量。核心调查点落在战区，奖励位留在战区外缘，便于 CONTENT 绑定交涉 / 解谜替代战斗。

## 4. 验证记录

- 场景档位：2 微型 + 4 标准；29 房 / 区；chunk 总数 `4+4+9+6+9+9=41`，与编译后的 RegionMap 逐图核对一致。
- 磁盘格网共 14,000 有效格；步行白名单为平地、碎石、沙地、泥沼、浅水、室内、洞窟、墓室，合计 8,582 格全连通。六邻固定为 `(1,0),(1,-1),(0,-1),(-1,0),(-1,1),(0,1)`，相邻高度差至多 1。
- 逐图再去掉全部战区、浅水、泥沼，入口至奖励六邻最短边数依表顺序为 32 / 34 / 77 / 84 / 48 / 86；外围、回返锚点也可达，所有路径均可反向走。步数不折算游玩时长。
- 六张最终 PNG 均从落盘地图绘制，并分别用 `view_image` 检查出入口、岔路、核心和奖励可读性；不是只看联系表。预览粗线是 chunk 边界，白阶线是华山实际高度边界。
- 必需命令均退出 0：冻结安装；`content:validate`（987 files / 925 objects / 62 maps）；`content:build`（984 objects / 15 chapters）；strict ID（新增失败 0，仅原有 `sk_babuganchan` 基线）。Tiled property types `--check` 同样通过。
- 本批所入区域叶片最大 53,167 B，低于 262,144 B；有效位计数与源图逐张一致。未做 Tiled GUI、实际游戏事件、运行时寻路或真机验收，均为**（待实测）**。
