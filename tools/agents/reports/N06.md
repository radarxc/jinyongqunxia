### 3.2 控制、时钟与护体

| 项 | 定稿 / 核算 |
|---|---|
| 条件硬控 | 仅受擒 9 级与穴位受封 9 级派生 `exg_control_hard`；1–8 级不增加 `ccCount`、不触发 `bf_jianyi` |
| 受擒重击降级 | 单次实际气血伤害阈值 `ceil(hpMax×800/10000)`；如 `hpMax=5000`，阈值 `ceil(400)=400`，命中后降 2 级 |
| 点穴实例上限 | 不同穴最多 3 个；第 4 个按等级最低 → 剩余最短 → `acupointRef` ASCII 最小替换 |
| 自解穴 | AR-14 不执行旧 S5 免费自解；正式战只走 21 的调息、队友解穴、合法道具与到期，旧公式仅供 v1 录像 runner |
| 时钟桥接 | E2 递减后只更新 remaining 待投影值；全局 `battle tick` 对每个活动模块只调用一次 `tick`，`0` 清镜像、字段缺省保持 |
| 护体顺序 | `护体真气 → 护体内劲 → mpGuard → 气血`；中间剩余量固定名 `damageBeforeMpGuard` |
| 护体守恒例 | `postShield=1600`、内力 300：`cancelled=min(eligible,capacity,2×300)=600`，`mpSpent=ceil(600/2)=300`，余 1000 进入 `mpGuard` |
| 反震 | 以 `cancelled` 为基数，`reflectBp≤2000`；如抵消 1000、输入 2500 bp，钳后反震 `floor(1000×2000/10000)=200` |
| 破气 | `breakGuardBp` 黄 / 玄为 0、地 3000、天 6000 **【建议值】**；多来源取最高，最终钳 8000 |
| Boss | 受擒 1–8 固定 1 次自身行动且不计硬控；点穴 7–8 降为对应类别 `flowBp−3000`；9 级失败在同穴退为 6 级、剩余 1 |
