- 已把 `design/21` v2.0 的招式路线、经脉速度、护体内劲、调息与逐单位实例契约接入少林、道家、通行三册图鉴。

## 3. 关键结论与数值

| 项 | 结论 / 核算 |
|---|---|
| 高阶覆盖 | 少林 `29 / 145 / 29`、道家 `26 / 146 / 26`、通行 `19 / 78 / 19`，依次为武学 / 招式 / 绝招；合计 `74 / 369 / 74` |
| 路线 schema | `MeridianRouteDef.id/moveRef/ultimate/purpose/requiredNature/steps`；步骤为 `acupointRef/segmentCt/riskBp`；每招引用同名派生 `mfr_<move 去 mv_>` |
| 路线硬界 | 1–18 个不重复穴位；每段 40–120 CT、风险 0–1200 bp；本组模板实际 2–10 段、60–90 CT、50–450 bp；最大核算 `1200+800=2000 CT` |
| 独立乘区 | 顺序固定为 `Z0–Z4 → Z4M → Z5 → Z5M → Z6–Z10`；攻 / 防 / 速度标准对标准均 10000 bp，硬界依次为 6500–22000 / 5000–13000 / 6500–13500 bp |
| 护体内劲 | 位于护体真气后、`mpGuard` 前；拳脚 / 持械 / 暗器 / 外放适用率 `10000/2500/0/4000` bp，1 内力抵 2 伤害；图鉴 `IG` 固定展开为 `reflectBp:0` |
| 轻功 | 少林 / 道家 / 通行分别 5 / 16 / 13 门，合计 34 门；只产出 movement 路线，不写回基础 `Q_skill`、轻功门禁或地形成本 |
| 调息 | `BreathProfile.id/grade/layer/nature/scope/ct/mpCostBp`；49 门内功均为 `ct=1000`、`mpCostBp=0`，运行时读取 `effGrade/effLayer` |
| 调息复算 | 非调和 10 重：`relief=1300+100g`、`repair=300+24g`；调和再乘 1.05 并向下取整，理顺上限 2500。混元方桩 7 品为 `floor(2000×1.05)=2100`、`floor(468×1.05)=491` |
| 特殊挂接 | 金刚不坏金身接 6 段防守护体；`ps_taijiquan_siliang.routeOnTriggerRef=mfr_taijiquan_rufeng`；形意“进退连环 / 安身炮”固定 6 段，分别 `1450 / 1740 CT` |
| 实例与预览 | 每个独立行动单位一个 `MeridianFlowModule`；同模板敌人不共享可变节点；`preview` 不改状态、不消费 RNG |
