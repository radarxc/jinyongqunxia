## 3. 关键结论与数值

| 项 | 落地结论 |
|---|---|
| 路线引用 | `MoveDef.meridianRouteRef` 是唯一主动主路线；被动防守 / 身法用 `routeOnTriggerRef`；轻功武学顶层用 `movementRouteRef` |
| 路线模板 | `MoveDef` 只引用已展开的 `mfr_*`；21 §5 的七类形态和 A–G 是配表方法，不另造 `routeTemplateRef`，也不复制 `steps/segmentCt/purpose` |
| 路线时间 | 单段 40–120 CT、1–18 段；满路线须满足 `recovery+ΣsegmentCt≤2000`；硬封预检为 0，中途卡住计实际尝试段 |
| 十八掌算例 | `mfr_eighteen_palms_chain` 为 10×80 CT；`1200+800=2000`，`power` 仍为 2.00 |
| 独立乘区 | `…Z4 → floor(Z4×meridianDefenseBp/10000) → Z5 → floor(Z5×meridianAttackBp/10000) → Z6…`；标准对标准均 10000 bp |
| 绝招 | 继续复用 `ultimate:true`；路线镜像值只能断言相等，不新增能量、ID 或配额 |
| 调息 | `InnerDef.breathProfileRef` 引用 21 的 `txp_*`；沿用 `yunjin:tiaoxi`，基础 1000 CT、经脉处理 0 额外内力，9 级点穴禁止自行调息 |
| 护体内劲 | `InnerDef.innerGuard={enabled,reflectBp?}`；来袭破体 / 破气经 `InnerGuardInput.breakGuardBp` 输入，0–8000 bp，不能误作防守内功常量 |
| 抵消边界 | 护体真气后、`mpGuard` 前；拳脚 / 兵器 / 暗器 / 外放适用率 100% / 25% / 0% / 40%，1 内力抵 2 伤害；公式唯一见 21 §4.8 |
| 轻功 | `movementRouteRef` 仅输出经脉速度投影，不改基础 `qinggong/spd`、20 / 50 / 90 / 140 / 200 门禁或地形成本 |
| 实例粒度 | 同一单位攻、防、轻功与调息共享一份 `MeridianFlowModule`；每个可独立行动的我方 / 敌方单位各有独立实例 |
| 数量 | §14 保持黄 / 玄 / 地 / 天 `459 / 459 / 169 / 51`，合计 `1,138`；`mfr_*` / `txp_*` 不计武学或绝招 |
