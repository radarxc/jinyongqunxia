## 3. 关键结论与数值

### 3.1 配装与经脉口径

| 项 | 本组落地口径 |
|---|---|
| Boss 内功 | 每人 3 门：1 门主运 + 2 门辅运；主运优先人物原著 / 门派图鉴，缺专属项才用合法通行链 |
| Boss 外功 | 每人 3–5 门，优先人物原著武功，再按门派 / 来源补足；不为缺口虚造 `sk_*` |
| Boss 七参数 | `kind=boss`；随后 `主运品阶/9; 13000; 9000; 13000; 主运性质; fullTemplate; 当界里程碑` |
| 精英七参数 | `kind=elite`；随后 `主运品阶/8; 10500; 7500; 10500; 主运性质; schoolCore; 当界精英里程碑` |
| 里程碑 | 01–02 `M0`；03 `M1`；04 精英 `M4E`、Boss `M4B`；05 `M5`；06 `M6`；07 `M7` |
| 实例边界 | 每个独立武学行动者一实例；同角跨战复用静态画像但重建动态态；阵法、共享耐久不共享经脉态；纯环境无实例 |

`effGrade/effLayer/innerNature` 只取主运内功经压制后的最终有效值，不取最高外功、阵法或关卡威胁预算。本轮因此纠正了段延庆、萧峰、童姥、陈梅、黄药师、裘千仞、李莫愁、公孙止、玄冥二老、三渡、岳不群、玉真子等旧表的“按外功 / 场景品阶填经脉”问题。

模板零漂移的原因不是主运变化“没有影响”，而是标准对标准时 Z4M、Z5M 与速度均为 `10000 bp`。相对强度回归仍有效：强一档 `Z5M=12053 bp`，TTK `9→7`；强两档 `Z5M=14456 bp`，TTK `22→15`；弱一档 `Z5M=9157 bp`，TTK `5→6`。模板“标准对标准”轮数不反映逐单位相对 STD 的经脉强度差异；依 `design/21` §3.4，品阶、`mp`、容量与里程碑都会改变结果，逐单位节奏交 NAudit / 实测复核。
