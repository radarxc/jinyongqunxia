## 3. 关键结论与数值

- 源图金色来自 `nature:harmony` 与风格要求；旋涡、双旋、向心形均为（原创扩展），未冒充小说颜色描写。
- 共用掌点 `[850,704]` → E=`[700,540]`；手缩放 0.6，名义掌面宽 `320×0.6=192 px`；手图与 YAML 均同 HEAD 字节一致。
- 示意标尺 256 px/hex；卸劲 `L=1×256=256 px`。护体局部 `1×256=256`、两绝招局部 `1.5×256=384 px`【建议值】，后三者 `range_hex=0`。
- `sx=L/reference_length`；家族 / 颠倒 / 归一参考长 539 / 629 / 632、根宽 201 / 201 / 171 px；`sy=192/root_width×scale[1]`。护体 / 卸劲横向修正 0.75 / 0.55，其余 1。
- 家族锚点 x=160.5，四帧 y=239 / 239.5 / 215.5 / 235.5；峰值根宽 `340−139=201`，参考长 `699.5−160.5=539 px`。
- 家族第二候选原件 SHA-256：`a999b2561195049284631e3c59b806beec490a72235fab5ff1c9bfb02df9a33e`；首版原始路径、提示词及哈希留在 `request.json`。
- 普通 pulse=`0.10+0.15+0.25+0.10=0.60 s`、绝招 wave=`0.15+0.20+0.40+0.15=0.90 s`；峰值 `5/12` / `7/18`，不换算收招 CT。
- 12 帧 8 px 边框残留 / 残白边比例均 0；家族重建最大误差 `0.881958/255`，全套上限仍 `1.01454/255<2/255`；家族抠白阈值 246、绝招 250，色键全保留差值 163。
- 全阶段几何最小安全边距 112.57 px、包围盒估算留白下限 60.86%；无越界裁边。
- 护体 / 卸劲 / 颠倒 / 归一 HTML 为 1,986,364 / 1,966,189 / 2,590,618 / 2,016,308 bytes，全部原尺寸无损 WebP 内嵌。
