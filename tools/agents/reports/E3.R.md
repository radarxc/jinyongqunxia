### 3.3 技术事实核查

- 2026-09-26 访问的 12 个官方资料 URL 均返回 HTTP 200。three.js 官方文档确认 WebGPURenderer 优先 WebGPU、不可用时回退 WebGL 2，forceWebGL: true 可强制 WebGL 2；GitHub API 显示 r186 发布于 2026-09-24。
- MDN 确认 WebGPU 非 Baseline 且要求 secure context；StorageManager.persist() 只请求持久化并返回是否获准；measureUserAgentSpecificMemory() 要求 secure context 与 cross-origin isolation，兼容性有限。
- Cloudflare 官方页当日公开值：Workers Free 100,000 请求 / 日、10 ms CPU、128 MB / isolate；Paid 最低 US$5 / 月并含 1,000 万请求 / 月、3,000 万 CPU ms / 月；R2 Free 含 10 GB-month、100 万 Class A、1,000 万 Class B / 月。部署日仍须重核。
- OFL FAQ 确认网页字体可用；子集化属于修改，必须逐字体检查 Reserved Font Name。具体字体文件、中文字形覆盖和嵌入结果仍**（待核实）**。
