## 3. 关键结论与数值

### 3.1 合法 STD 与节奏

CN-09 的修复边界是：**只截断玩家普通武器与普通装备品阶**，即主武器使用 `min(gMain,9)`、其余普通装备使用 `min(gRef,9)`；玩家内功仍可取 10–12 品，敌人模板也不套玩家装备上限。

| 锚点 | 结果 |
|---|---:|
| `STD(35).hpMax` | 7,176 |
| `MPREF(35)=STD(35).mpMax` | 4,697 |
| `STD(70).hpMax` | 40,409（旧模拟为 41,314） |
| `STD(70).mpMax` | 28,887 |

保持 Z1–Z10 常数与语义不动，在遭遇层重校：HIGH 耐久 `0.960/0.720/0.720`，MID `1.000/0.800/0.770`，LOW `1.000/0.800/0.900`；LOW 普通敌普攻预算由 `1.76` 调为 `1.79`。重生后的十四书界 × 三模板结果为：

| 硬指标 | 结果 | 基准窗口 |
|---|---:|---:|
| 普通敌人主角击杀命中 | 3.36–4.90 | 3–5 |
| 普通敌人击倒主角命中 | 8.74–11.69 | 8–12 |
| 普通战主角行动轮 | 3.40–4.95 | 3–5 |
| 精英主角行动轮 | 7.07–9.94 | 6–10 |
| Boss 主角行动轮 | 14.31–24.91 | 12–25 |
| 单招耗内 / `mpMax` | 7.00%–8.01% | 5%–15% |

`python3 tools/balance/damage_sim.py --report` 的完整输出已与 04 §9.2–§9.3 逐行精确一致。

### 3.2 经脉与结算边界

- 经脉回归共 `3 profiles × 3 r_in × 42 encounters = 378` 组；相对同内劲比的无经脉基线，最大主角轮数下降 `6.72%`、最大敌方击倒命中增长 `2.41%`，65% 外劲 / 35% 内劲代表招在三档下均通过硬区间。
- `design/05` 仅输出有效品阶、有效层数、真实 `mpMax`、主运性质、`MeridianId[]` 与已折算 `auxRatio`；20 个经脉 ID、冲穴、周天、九转和失败规则仍唯一归 `design/15`。单门专精只令该门自身内劲贡献 `×1.20`，空数组表示无专精。
- `simultaneous` 批次对共享护体、代伤 MP、复活次数采用 `(target.unitIndex, segmentIndex)` reservation ledger；同一资源不能在快照批内重复消费。
- `settledIncoming` 保持 core 内部派生量，不加入公共 `Settlement`；跨包公开前必须先修改 04 的契约。
- `dealDamage` 且 `dmgType:true` 的规则真伤不跑 Z0–Z10，因此不进入 Z8；护体、致死与 cap 由条目显式字段决定。

### 3.3 04 / 05 一致性结论

- AR-02 调和主运对阳/阴招统一为 `+6%`；对调和招 `+12%`、中性招 `+2%`。
- Z7 先取六向几何的正面 `1.00` / 侧击 `1.10` / 背击 `1.30`，再加 `directionAdd`；`+0.05/+0.15` 不误入 Z3。

- CN-05 采用 C3 既定结果：独孤破剑 / 刀 / 枪 / 鞭 / 掌 / 箭六式 `(1+0.12+0.30)×0.85−0.10×0.60=1.147`；`power:1.10` 的差为 `−0.047`，合法。
