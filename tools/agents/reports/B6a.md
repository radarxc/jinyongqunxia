## 3. 关键结论与数值

| 领域 | 终值 / 结论 | 核算或口径 |
|---|---|---|
| 预算维度 | `QualityTier = low / mid / high / ultra`；`memClass = S / M / L`；`fpsMode = auto / 60 / 30 / battery` | 有效显存 = `min(gpuByTier, gpuByMemClass)`；S 级封顶 128 MB |
| 内存 | GPU 96 / 160 / 256 / 512 MB；JS 堆 96 / 160 / 256 MB；进程总占用 450 / 800 / 1,536 MB；PCM 16 / 24 / 48 MB | S 级 PCM 样例 `1.92 + 5.76 + 7.68 = 15.36 MB ≤ 16 MB` |
| 视频 | 480p / 720p / 1080p 的 4 张 RGBA 等价峰值为 6.56 / 14.75 / 33.18 MB | `宽 × 高 × 4 B × 4 帧`；始终只有一个活动 decoder |
| 帧预算 | 60 fps：P95 ≤16.7 ms、P99 ≤25 ms、`workMs` ≤6 ms、主线程 ≤8.5 ms、GPU ≤11 ms；30 fps：33.4 / 50 / 10 / 14 / 22 ms | 时间是发布预算，须由三机生产构建实测；桌面 CI 不冒充真机 GPU 结论 |
| 自适应质量 | low/mid 0.70–1.00、high 0.75–1.00、ultra 0.85–1.00；步进 0.05；会话内自动只降不升 | 缩放实验改善 ≥20% 才判 GPU-likely；30 Hz vblank 封顶先切预算，不误降画质 |
| 温控推断 | T0 <15%；T1 ≥15%；T2 ≥25%；T3 ≥40% | 比较同 `costKey` 的前 2 分钟基线与 5 分钟 EMA；不读取温度、不显示摄氏度 |
| 测试 | 六场景：title / explore / battle / mass / region-cycle / ui；计数精确门禁，时间同 runner 中位数 +10% 报警 | `window.__tsPerf` v1 含 8 个接口；不支持指标写 `null`，污染轮直接失败 |
| 离线 / 弱网 | 应用外壳 + 已下载书界 + 本地存档；普通内容寻址文件 ≤8 MB、关键文件优先 2–4 MB、视频段 ≤4 MB | 恢复时补完整文件差集；Cache Storage 不写网络 206；无 SW 默认在线 |
| 发布矩阵 | 作者主力手机 + 一台中端 Android + 一台 iPad | 固定 iPhone 仅可选扩展；型号和环境必须随证据登记 |
