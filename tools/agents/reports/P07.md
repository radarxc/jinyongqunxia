## 3. 关键结论与数值

### 3.1 书界边界与路线结构

| 项 | 结论 |
|---|---|
| 书界参数 | `ch07_bixue`；1630–1645，主体 1640–1645；中武、武运 62、难度 6、等级上限 56、携带 2/2/2、外来压制 −2 |
| 前后书界 | `ch06_xiake` → `ch07_bixue` → `ch08_luding`；1645 至 1669 的书眠跨度为 `1669 − 1645 = 24` 年 |
| 玩家身份 | “袁党送信人”**（原创扩展）**；承担取证、资源分配、护送与谈判，不替代袁承志的身世、师承、主决斗和情感选择 |
| 正线 | 公开证据、守约、护民与问责；不是效忠明廷 |
| 邪线 | 以秘密网络、把柄和资源控制建立民间撤离能力；不是滥杀路线，也不是惩罚性坏结局 |
| 换线原则 | 不回滚既有死亡、公开、资源消耗或关系债；按同一阶段进入另一线路，不重播旧幕 |

路线建议式为：

```text
bx_stance = clamp(bx_stance + stanceDelta, -3, 3)
moralWeight = clamp(sign(morality) * floor(abs(morality) / 10), -3, 3)
routeScore = moralWeight + bx_stance
routeScore >= 1  -> 正线
routeScore <= -1 -> 邪线
routeScore == 0  -> 最近一次明确立场
```

`bx_stance` 的普通 / 重大选择建议为 `±1 / ±2`，属 `design/12` 待定值。穷举 `morality ∈ [-100,100]` 与 `bx_stance ∈ [-3,3]` 共 `201 × 7 = 1,407` 个初态后，任一状态均可在不超过 3 次同向重大选择内转入目标路线，满足“可切换但有代价”。

### 3.2 原著覆盖、锚点与结局

49 项原著事件的唯一主要去向为：

```text
双线共有 16 + 正线 7 + 邪线 7 + 选择节点 9
+ 锚点 8 + 支线 1 + 不采用 1 = 49
覆盖率 = 49 / 49 × 100% = 100%
```

五个锚点严格沿用 `design/01` §7.8：华山学艺与金蛇遗藏、温家旧案与金蛇因果、闯王军中与军饷 / 宝藏、北京城破前后的李岩线、长平公主与明亡。A07-1/2/3/5 在所有通关路径完成；A07-4 必须且只能取 `canon` 或 `fate`。

四个完成态结局为“碧血留证”（正 × 原著）、“蛇影去国”（邪 × 原著）、“旧稿出关”（正 × 改命）、“蛇网换生”（邪 × 改命）。路线不直接决定天书：A07-4 原著结果授 `tsp_07_canon`，双人改命结果授 `tsp_07_fate`，同周目互斥。

### 3.3 唯一主改命的可计算条件与代价

李岩、红娘子必须同时获救，单救一人不算主改命。建议硬条件为：

```text
evidenceCount >= 3 / 4
AND civilianReputation >= 3 / 4
AND rebelReputation in [2, 3] / 4
AND distinctEscapeRoutes >= 2
AND 已见李岩
AND 已见红娘子或持其暗语
AND 明亡已发生
AND 玩家确认关闭闯军军需 / 晋升路线
```

正文分别给出正、邪改命最小账本，证明四证据、双声望、两退路、人物相识和时序条件均有生产路径。成功后：

1. 关闭闯军军需、晋升、战役援军与相关余韵路线；邪线另永久消耗一个蛇网节点。
2. 北京失守、明亡、吴三桂与清军入关不变，不允许以人物改命覆盖历史锚点。
3. 待 `design/18` 补齐两个人物后，只发一次 `companionFateRescued(ch07_bixue, [npc_liyan, npc_hongniangzi])`。
4. 依 `design/13` §6.6，本书界首次触发统一支付 2 点修为余韵；同次救两人仍只计一次，不足记入 `yuyun.fateDebt`。该系统代价与剧情资源代价叠加。

温仪、焦公礼和更多百姓获救只属于局部人物改命，不改变天书变体。阿九必须断臂存活并沿用 `npc_ajiu` 跨入鹿鼎；明亡不可逆。

### 3.4 数据与实现边界

- 8 个选择节点均有 4 个选项，并显式列出位置、时机窗口、条件、后果、可逆性和汇合点；条件覆盖品德、全局声望、门派职级、同伴在场、前置旗标和时间窗。
- 战斗只写普通 / 精英 / Boss，阶段机制引用 `design/09`，未越权配置伤害或 Boss 数值。
- 授艺、遗物和技能只引用 11 个已有 `sk_*`；剧情仅开放合法学习机会，不绕过 `design/05` / 图鉴门槛。
- 任务与选择 YAML 是对未来 `design/12` 的保守兼容示例，不宣称最终 schema；`q_07_main_c/z/x_NN` 与 `dc_07_NN` 的全局命名仍须基准采纳。
- 联网只用于交叉核对二十回目录、事件相对顺序和版本变动；三联 / 广州修订版纸本仍为最终基线，未核细节均标（待考）。
