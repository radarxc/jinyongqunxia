## 3. 关键结论与数值

- E=`[600,540]`、方向 0°、掌图缩放 0.5；根部截面 `320×0.5=160 px`。未修改掌图原件。
- 标尺 256 px/格；归一 `2×256=512`，五岳 `3×256=768`；石壁图意 / 飒沓 / 十步近身示意均 `1×256=256 px`。
- 归一三档均 single；五岳 line n3/n4/n5，本演示采用基础 n3，横向不加宽；高档只消费上游已解算事件，未冒充三档实战演示。
- 十步 1–3 格为角色突进，飒沓 r2/60° 为逻辑扇形，不当作远程束长。所有 Composition 均为 baseline。
- wave=`0.15+0.20+0.40+0.15=0.90 s`，pulse=`0.10+0.15+0.25+0.10=0.60 s`；峰值分别 7/18、5/12，不换算收招 CT。
- 四套 `sy=160/{294,236,111,191}`；逐招 `sx=L/参考长`，原料放大仅属表现层。全帧 / 阶段极值安全边距最小 167.85 px，留白下限最小 56.12%。
- 16 帧边框残留 / 残白比均 0，white_key 128 的白底重建最大误差 `0.725495/255<2/255`。
- 归一 / 飒沓 / 十步 / 图意 / 五岳 HTML 分别 2,085,098 / 1,174,972 / 1,328,934 / 1,719,665 / 1,799,925 bytes；均原尺寸无损 WebP 内嵌。
