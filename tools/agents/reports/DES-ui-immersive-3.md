无字后武学摊卷 / 图鉴合册仍需辨识复核；战斗 / 招式、行囊 / 道具复用同图，移步借体力叶形图不够直观，合卷借地图图。默认保留母版、固定位置和浮名，交 ART 提独立动作 / 返回候选；人物无五官问题沿第二版保留。
默认格高 48 / 36、人物 75%、手机七格放大 1.5 倍（格宽≈46.77≥44），双指缩放 1–2.5 倍；均待真机试用，不改规则尺度。默认拼景不视为白马张掖的植被事实。
系统 WebKit 宿主无活动窗口焦点：聚焦可达性与 CSS 规则已检，原生焦点 / hover 实际显隐未验；长按取消 / 吞 click、放大点选、在线字体、150% 字号、读屏、真机与游戏性能仍待 ENG 验收。
