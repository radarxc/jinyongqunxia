- 固定链为 `Z4 → Z4M → Z5 → Z5M → Z6`，Z4M / Z5M 各自向下取整；标准档均为 10000 bp。
- 五档 Z5M 为 10000 / 12053 / 14456 / 9157 / 18265 bp；伤害为 849 / 1145 / 3720 / 777 / 1550，TTK 为 5 / 7 / 15 / 6 / 2。
- 强一档防守例：`1000 → floor(×9361)=936 → floor(×9200)=861`。
