## 3. 关键结论与数值

1. **缺路线不再隐身**：正式图鉴会独立扫描正文绝招真值；即使完全没有 `mfr_*` 目标，也会以 `mv_*`、所属 `sk_*` 和行号报“正文 `ultimate:true` 缺路线”。同一行多份完整合同按各自前置 `mv_*` 绑定；只有一个末尾合同的紧凑卡仍优先绑定唯一显式“绝招”标签。
2. **裁定表不再冻结行数**：真实表测试从 §3 当前表格动态提取 `{skill_id: 裁定值}` 并与解析器结果完整比较。当前没有“过时裁定”实际命中；新增天中 / 地中武学有 30 门“未入裁定表”提示，仍按合法区间回退。
3. **多样性输出语义分离**：`--diversity` 的完全重复标题 / 明细使用 `EXACT` / `EXACT sequence`，退出 0；`--diversity-strict` 使用 `ERROR` / `ERROR exact sequence`，完全相同有序序列令其退出 1，非完全相同的 ≥80% 重合仍只警告。
4. **末端审计口径**：掌含劳宫；指含六指端之一，六脉具名招要求对应指端；腿含足阳明 / 足太阳 / 足少阳任一穴（厉兑 / 至阴 / 足窍阴为推荐端点）；兵器含五个腕部 / 导引穴。上述四类所需穴位须在最后三段，否则单列 `-tail`。`purpose:attack` 的内功含任 / 督穴，`projection:true` 另含 13 个手部端点；这两类仅要求经过，不检查位置。
5. **保守分类**：明确 `category` / `subType`、武学名或招式动作才触发动作规则；旧“拳脚 / 拳掌”与 `subType:fist` 不自动等于掌。`misc/mind` 架势中的“下次剑招”等效果文字不会污染当前招式类别；无法可靠分类的 191 条只计数、不猜测。
6. **全仓统计**：25 册物理路线 642 条，加 `design/21` §12.1 的降龙三条跨文档路线，共 645 条；454 条已分类。动作规则检查 `63+20+3+190+37=313` 次，外放规则再检查 37 次，总计 350 次。
7. **当前命中**：158 条缺失诊断落在 157 条路线，分布为兵器 107、掌 35、攻击内功 11、指 2、腿 2、外放 1；另有 25 条位置诊断（兵器 23、掌 1、指 1）。两类路线不重叠，合计 183 条诊断 / 182 条路线。
8. **退出语义**：`--delivery` 无论是否发现缺失或位置违规均只报告；原 `--strict` 不调用末端分析，也不会因这 183 条诊断失败。
