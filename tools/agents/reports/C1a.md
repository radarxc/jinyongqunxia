# C1a 报告 · 图鉴 skills-yitian（倚天诸派）

## 1. 摘要（3–6 行）

已完成倚天诸派武学图鉴，共定义 88 门可习得武学，品阶严格按 AR-01 收敛为天／地／玄／黄 `4/12/36/36`。
四门天阶仅采用基准 §13 的封闭锚点；明教、天鹰教、峨眉、昆仑、崆峒、华山倚天支、汝阳王府及三个小帮会均具备入门、进阶和套装闭环。
天／地阶逐招完成倍率核算，玄阶核算抽样为 `11/36=30.56%`；18 门内功均标 `nature`，并按 AR-03 登记经脉建议值。
静态检查未发现配额、天阶集合、公式、Buff、前置引用、表格列数或围栏错误；原著名目仍有 11 组逐字考据事项，已如实列入正文与本报告。

### 3.2 数值预算

- 招式统一按 `P = 1×(1+范围+控制+状态+位移+破防+特殊)−多段税−安全税` 核算，天／地完整卡共 64 招，逐招误差均不超过 `±0.05`；支援招按 0 倍率登记。
- 内功按 `IP = mpMaxPct + hpMaxPct + 2×属性点 + 5×mpRegen` 核算，正文使用的贡献值为 `154`、`135.5`、`83`、`57`、`48.5`、`41.5`、`30`，并与各自品阶预算对应。
- 轻功最高为玄上 6；按 03 §4.5，文中实际使用 `QS(2/3/4/6)=38/45/56/74`，未越过倚天地上 9 的书界上限。
- 地阶中代价型 1 门（`sk_qishangquan`）、誓约型 0 门、`special.combo` 0 门。按 AR-01 后全图鉴约 153 门地阶估算，本组代价型贡献为 `1÷153≈0.65%`，合击贡献为 0。

### 3.3 覆盖、套装与引用

- 每个可加入组织均有至少一门黄阶入门拳或剑、一条明确的黄→玄→地硬前置链，以及一个成员双向登记的 `setTags` 组合。
- 倚天本组本土可学池包含内功18、拳脚26、兵器26，均远高于每类 3 门下限；正文另给出 1/1/1 与 2/2/2 入界装配样例。
- §7 列出 15 个倚天套装候选，另引用 `set_wudang_zhenwu`；合计涉及 13 个本文新候选与 3 个既有候选 ID。奖励数值与唯一成员表留给 `design/07`。
- 正文引用 37 个 `bf_*`，全部已在 `design/06` 目录中找到；新增 Buff 为 0。
- 16 张天／地完整卡共有 64 个招式和 56 个被动；本文 88 个武学 ID 唯一。与其他文档的定义式命中均属于已知上游锚点或跨文档引用。
- 经脉暂用 8 个预留 ID：`mer_renmai`、`mer_dumai`、`mer_chongmai`、`mer_daimai`、`mer_yinqiao`、`mer_yangqiao`、`mer_yinwei`、`mer_yangwei`。
