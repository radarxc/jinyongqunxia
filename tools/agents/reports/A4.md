## 3. 关键结论与数值

- 伤害链在 Z4 后插入守方 `Z4M / meridianDefense`，标准 10000 bp、硬界 5000–13000 bp；在 Z5 后插入攻方 `Z5M / meridianAttack`，标准 10000 bp、硬界 6500–22000 bp。两区各自在区末向下取整，具体曲线与兑现算式只见 `design/21`。
- 护体内劲位于护体真气后、既有 `mpGuard` 前，输出为 `damageBeforeMpGuard`。拳脚 / 兵器 / 暗器 / 内劲外放适用率为 `100% / 25% / 0% / 40%`；1 内力最多抵 2 伤害；击穿产生 150–400 CT、800–3000 bp 迟滞。
- 经脉速度为 6500–13500 bp，先经脉后擒拿；投影必须满足移动增量 `[-2,+2]`、`spd≤300`、`recovery≥500`。探索门禁始终读取未经经脉修正的轻功值。
- `design/15` 拥有 20 脉 / 180 穴、开通、冲穴、周天、九转；`design/21` 拥有战斗动态、攻防轻功路线、乘区、护体内劲、绝招补充、擒拿点穴与调息。
- 经脉确定性契约固定为一独立行动单位一实例、preview 无副作用、Core 注入唯一全局 `battle` 随机流、固定事件 / 节点顺序、单位快照不复制 RNG、TypeScript / Python golden 全字段对拍。
- 普通武学闭合为 `51+169+459+459=1,138`；套装例 `[5,6,8,12] → floor((6+8)/2)=7`，同 ID 去重，辅运及暂不可施展的已装兵器武学仍计件。
- 提案统计为 33 行：27 行采纳 / 沿用、1 行部分采纳、5 行不采纳 / 不升格、0 行新增待作者确认。
