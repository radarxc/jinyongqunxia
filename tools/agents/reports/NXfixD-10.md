《白马啸西风》没有本轮跨书界替换项；NXB10 已落盘的现行首领主运 / 外功均为合法 `sk_*`，本次终审未改配装。

1. 本书跨书替换数为 0。瓦耳拉齐 / 马家骏继续主运 `sk_huahuixinfa` 地上 9、8 重、阴，分别以 `sk_walalizhi` / `sk_majiajunfeizhen` 为 9 品核心外功；部族演武首领主运 `sk_hasakeyunqi` 玄中 5、8 重、阳。
2. 华辉遗谱原子组为 `it_miji_huahuixinfa`、`it_miji_walalizhi`、`it_miji_majiajunfeizhen`，均为 `partial`、`maxLayer=8`。任一写入失败整组回滚；重复触发不补发、不折现。
3. 遗谱只在 `q_10_bond_05` 旧案问证、无毒检查、双方安全隔离并由李文秀辨认后发放；人物死亡线只认任务预先保全的谱本，禁止瓦耳拉齐 / 马家骏尸体掉落。
4. 双人剧情战 `totalHp=64,534`【建议值】，按 §8.8 编组顺序分为马家骏 `30,116`、瓦耳拉齐 `34,418`；算式为 `round(64,534×0.80/(0.80+0.70))=34,418`，余数 `30,116`。
5. 守藏试炼 `totalHp=61,796`【建议值】，固定三具机关傀儡 **（原创扩展）** 分为 `20,599 / 20,599 / 20,598`；两个多人遭遇都只消费一次总耐久。
6. 旧 Buff `bf_fengxue / bf_fengnei / bf_fengjingmai / bf_chanrao` 的运行时引用为 0，Buff 迁移数为 0；“来源扩展待登记”“待补专属”“待补本门武学”标注也均为 0。
7. `boss_pacing.py` 精确结果：瓦耳拉齐 / 马家骏均 `18.4402757386`，霍元龙 / 陈达海均 `16.3159971010`；均返回 `estimateOnly=true`、`recommendedMultiplierToWindow=1.0`。
8. 瓦耳拉齐 / 马家骏的战斗地位下限 `9/8` 已明确对齐 `design/18` §1.3.1，且 BM-V22 增加七参不得低于该下限的校验；瓦耳拉齐“一指镇江南”称号补 **（待考）**，字形“镇 / 震”仍待版本核对。
