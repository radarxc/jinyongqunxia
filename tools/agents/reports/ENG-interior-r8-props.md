# ENG-interior-r8-props 报告 · 城镇 3D 古建 · 室内家具道具库（≥ 36 件）+ 室内拼装与灯光烘焙

## 1. 摘要（3–6 行）

完成 43 件稳定下标程序化低模（DSL 只依赖 buildgen core，未 import Three、未新增依赖）；`buildInterior` 生成设施地面与家具室内批，写 unit、bit2/bit5、8 层 props 材质、AO 与 2.5 m 暖灯衰减。
家具与柜台/炉火灯直接使用 i1 世界坐标；事务缓冲保证超限时不提交部分批次。药铺/客栈/铁匠及逐件契约由 123 条专项测试覆盖。
本轮返修补齐无灯/灯内/灯外的自定义 RGB 与默认白色断言，并修正动态 `import('three')` 源码扫描；Prettier 与四条门禁均通过。

## 2. 产出（文件、行数、主要章节）

- `mesher/fixtures/**`：10 文件 / 1,543 行；DSL、43 项注册、家具/工坊/寺庙与室内拼装。
- `__tests__/props.test.ts`：833 行 / 123 用例；含世界坐标、硬预算、data 对拍、结构/AO/饰面、三态 RGB 与灯光三维截止断言。
- 验收：frozen install 634 ms（锁文件未改）；buildgen 21 文件 / 364 用例（2.77 s）、render typecheck 通过；全量 check 见 §7。

## 4. 开放问题（附默认值）

- i1 模板实现未在本工作区合入，故药铺/客栈/铁匠仍用逐字照 i1 世界坐标语义的夹具（i1 求解器输出的 fixture 已是世界坐标、yaw 已叠加建筑偏航）；默认不假定其具体组合。`FixtureTuple` 无灯点字段；默认由柜台/门/炉推导，扩灯点时由类型归属任务扩契约。
