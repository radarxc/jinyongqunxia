## 3. 关键结论与数值

### 3.1 配额与最终数量

采用 AR-14h 的逐品默认值：天上 / 天中 / 天下为 `3 / 2 / 2`，地上 / 地中 / 地下为 `2 / 1 / 1`，玄上为 1，玄中以下为 0。

| 图鉴 | 天阶核算 | 地阶核算 | 玄上核算 | 最终合计 |
|---|---|---|---|---:|
| 五绝 | `3×3+2×2+8×2=29` | `6×2+6×1+11×1=29` | `27×1=27` | 85 |
| 逍遥 | `1×3+4×(2或3)+5×2=22`，其中天中为 `3+3+2+2=10` | `5×2+4×1+5×1=19` | `26×1=26` | 67 |
| 合计 | 51 | 48 | 53 | **152** |

调整前按 NC2 口径是每门天 / 地阶各 1 记、玄上 0 记，共 60 记；最终增加 92 记。其中降龙十八掌的 2 记由上游 M4 已先行定义，本任务在两册新标其余 90 记。

### 3.2 招式、路线与资源

- 新增招式 ID 为 0：原著有据 0、原创扩展 0。全部从本门既有 `mv_*` 升格，因而没有编造原著招名或回目。
- 新标的 90 记绝招中，37 记复用其既有逐招路线，53 记新增独立 `mfr_*` ID；同门多绝招之间不共享路线 ID。
- 两册 §0.12 显式登记 149 条最终路线；加上 `design/21` §12.1 唯一归属的降龙 3 条，共 152 条。
- 资源统一为 `rageCost:100`、`cd:0`、`recovery:1200`；耗内按天 / 地 / 玄上为 10% / 9% / 8%。
- 路线均为 1–18 段内、单段 40–120 CT、同一路线穴位不重复且穴位存在。本册显式行单段为 65–90 CT；计入上游降龙路线后，五绝为 65–95 CT、逍遥为 65–90 CT；最大总时长为 `1200+800=2000 CT`。
