## 3. 关键结论与数值

1. 降龙十八掌有 19 个具名动作：除“潜龙勿用”外恰有 18 个 `projection:true`，即 15 个常规伤人动作 + 3 记绝招；实际伤害段统一为 `DamageKind='projected'`，该字段不写入严格 `MoveDef` 顶层。
2. 三记绝招的 `[0]` 均深等于基础 `aoe`：十八掌连环为 60° 锥 `r3/r4/r5`，神龙摆尾为 120° 锥 `r1/r2/r3`，震惊百里为 `around/disk r2/disk r3`。
3. 外放反击架势主动命令固定 `target:self`、`range 0–0`；三档都以持有者为原点，来袭者固定为主目标，`+0/+2/+4` 不增加瞄准射程。反应态 `aoe_self` 只命中来袭者。
4. 真气外放兼容式为 `max(buffRangeBonus,[0,2,4][projectionStep])`；地阶旧 Buff 为 `+1`、天阶为 `+2`，不得与 AR-16 相加，AR-16 自身硬顶为基础射程 `+4`。
5. 只有逐招已标 `projection:true` 的音功才启用外放档：0 档为普通音波，1 / 2 档才显示内力外放；AI 按实际新增目标 / 控制收益扣除额外耗内，同形同收益稳定选择 0 档。
6. Boss 静态公式仍为 `Rraw=R0×10000²/(A×D)×H`，Boss 目标 12–25 个主角行动轮、精英 6–10；多人 / 多阶段只消费一次遭遇级 `totalHp`。雪山 B05 / B06 / B07 锚点分别为 `round(139931×0.75)=104948`、`round(150048×0.75)=112536`、`round(184548×0.75)=138411`。
7. 正式具名 `bsc_*` 必须复用 tech/05 §14.3 的 `BattleReplayV1`，冻结版本、种子、初态、已接受命令、检查点与终态 hash；V8 / JSC 重放 Core 结果一致，但 AI 搜索过程不要求跨引擎一致。
8. 常长风墓碑仍按副手牌结算，只对明确写入 `weaponReq.altItems` 的武学暴露 `exotic/misc`，不得重复获得奇门主属性。三组共享载体按 2 / 3 / 2 条单 `skill` 秘籍原子发放。
