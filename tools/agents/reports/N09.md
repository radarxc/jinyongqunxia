## 3. 关键结论与数值

### 3.1 战斗调用链

- `createBattle` 按 `unitIndex` 为每个需要武学规则的独立行动单位创建一个 `MeridianFlowModule`；动态节点不跨单位共享，RNG 只由 Core 的唯一 `battle` 流持有。
- 招式事务按 `preview → F0 校验 → F1 快照 → F2 支付 → commit 攻 / 防路线 → Z4M / Z5M → settle → 点穴 / 擒拿 → 反应 → E6 收招` 执行；非法命令整体回滚，途中卡住是合法提交并保留已发生的成本、RNG、节点伤势和 CT。
- settle 顺序为“无敌 / 转移 / 单击上限 → 护体真气 → 护体内劲 → `mpGuard` → 气血”。护体内劲类别适用率为拳脚 10000、兵器 2500、暗器 0、内劲外放 4000 bp；每 1 MP 抵 2 伤害。
- 点穴 / 擒拿在本次直伤 settle 后施加，不反向削弱本次护体；护体击穿的 `delayCt=150..400` 交 09 时间轴，21 写入的 800..3000 bp 迟滞不得重复追加。
- `guard` 的完整防守路线和未移动 `wait` 的轻防预置持续至下次正常行动 S 段开始；即时防守路线把 CT 记为 `reactionRecoveryDebt`，下次正常行动 E6 只消费一次。
- `{t:'yunjin',mode:'tiaoxi'}` 保留 1000 基础收招与 0 额外 MP 成本，在同一事务中先执行既有回内 / 防护，再调用 21 `regulateBreath`；9 级点穴禁止自行调息。`unseal` 一次只处理一个穴位，`struggle` 只处理通用擒拿 1–8 级，9 级直接跳行动。

### 3.2 CT 与速度

```text
rec_eff = clamp(round(rec_base × (1 + Σrec_pct))
                + flowCt + otherΣrec_flat, 500, 2000)
combinedSpeedBp = floor(meridianSpeedBp × grappleMoveBp / 10000)
spd = clamp(floor(baseSpd × combinedSpeedBp / 10000), 30, 300)
move = clamp(baseMove + moveDelta, 1, 10)
```

- `flowCt` 只累计实际尝试段：硬封为 0；途中第 3 段卡住且每段 70 时为 `3×70=210`。基础收招 900 时，`rec_eff=900+210=1110`。
- 经脉速度硬界 6500–13500 bp，`moveDelta` 为 −2..+2。Lv35 锚点依次为：同档 `98/106/6/0`；强档 12239 bp 为 `119/129/7/+22`；9 级封路为 `63/68/4/−35`；强档叠 5 级擒拿时 `floor(12239×6000/10000)=7343`，结果 `71/77/5/+22`。最后一项只取纯经脉 `evadeRatingDelta`，擒拿闪避倍率由 04 / 06 另算一次。
- 同场参考过滤为“敌对、有实例、在场且可被正常选择”；强度升序后奇数取正中，偶数取中间两值之和向下除 2，空集取 10000。输入只用已归一 `MeridianProfile`，不再传原始 `routeQualityBp`。
- 首轮全序为冻结的 `openingQinggong → spd → agi → openingPriority → initiativeSideRank → unitIndex`；战中路线、点穴、胀损、调息、擒拿或相关 Buff 改变只标脏，在下一次 CT 推进 / 移动预览前重算，不追溯已积 CT。

### 3.3 地形轻功与 AI

- 轻功境界阈值仍为 20 / 50 / 90 / 140 / 200。门禁、`qgTier/jump/maxRun/moveMode`、体力、逐格成本与合法边均不读取经脉倍率；经脉只改变战斗中可花的最终 `mov`。
- 普通六邻步行不提交路线；位移、跃起、追击、脱离、闪避身法或战斗踏水类招式必须引用 21 的 `purpose: movement` 路线。探索不创建 / 持久化战斗经脉实例。
- movement 提交后若卡住使预算下降，只执行最终 `mov` 内的最长合法路径前缀；不可拆纵跃边不能部分执行，但提交产生的资源、RNG、节点伤势与 `flowCt` 保留。
- AI 预览路线质量、Z4M / Z5M、CT、卡住 / 胀损风险、护体和调息收益；最终只提交一个候选。经脉优势已包含在伤害预测中，不再重复乘一次；防守、挣脱与调息有独立决策约束。
