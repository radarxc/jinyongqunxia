## 3. 关键结论与数值

| 项目 | 定稿值 / 规则 | 核算或约束 |
|---|---|---|
| 资源等级 | 天地玄黄四阶 × 九品，共 36 级；一品最高、九品最低 | `resourceLevel=9×T+(10−rank)`；黄九 = 1，天一 = 36 |
| 材料映射 | 每三品映射 `design/10` 的一档材料品阶 | `materialGrade=3×T+1+floor((9−rank)/3)`；7～9 / 4～6 / 1～3 对应下 / 中 / 上 |
| 资源价值 | 12 档材料基价 × 同组三档质量 × 13 类资源倍率 | `Vbase=Pmat(g)×q(rank)`，类别中值再乘 `C(category)`；玄四品药材为 `2.5×1×1.10=2.75 两` |
| 资源点预算 | 十四界合计 229 个时代实例；逐界 22/20/21/21/18/15/16/16/12/12/11/18/15/12 | 原样复用 `design/11` §10.2；另有 280 个营生时代实例 |
| 资源点产出 | `A=0.45经营+0.35生产+0.20专业`；`M_a=0.70+0.006A`；`M_l=0.70+0.15L` | 示例 `base=4,L3,A=61.5,i=2` 得 `floor(5.90088)=5` 单位 |
| 防等待 | 每 3 游戏日形成候选周期，且需 45 分钟有效经营时间、默认 2 职责块；最多囤 2 周期 | 空等、菜单挂机和重复长休不推进有效经营时间 |
| 经营成本 | 家丁日薪 `0.005h×I×skillMul×dutyMul×食宿修正`；点维护 `0.005h×L×I+5% 毛值` | 天龙熟手日薪 0.10 两；天龙 L3、毛值 6 两时维护 0.6 两 |
| 家丁边界 | 默认不上场、不占六人编组；同一 NPC 的家业任职与随队 / 留守状态互斥 | 招募须自愿、工资与离职条件；袭击只参与后台防卫检定 |
| 职位 | 行脚按次；教头按月且可多处；客卿按月且全存档只允许 1 份活动合同 | 所有职责争用十二时辰日程块；客卿只允许镖局 / 山庄 |
| 职位报酬 | 行脚 `I×分钟/60×规模×风险×结果`；教头 `0.20h×I×规模×职责比`；客卿 `0.35h×I×规模×职责比` | 天龙普通场所足月教头 4 两、客卿 7 两；均受营生 10% 池约束 |
| 门派月钱 | L1～L5 现金为 `0.03/0.06/0.10/0.16/0.22 × I`，资源为 `0.02/0.04/0.07/0.10/0.15 × I` | 30 日月结并乘职责比例；掌门不重复领取长老月钱 |
| 收入结构 | 任务 40% + 战利品 25% + 敌人现银 10% + 营生 10% + 资源点 8% + 门派 5% + 其他 2% | 合计精确 100%；转仓、买卖、封装、返还本金等资产变形不重复计值 |
| 十四界总盘 | 目标净值合计 16,641.2 两，目标时长合计 162 小时 | 逐界 `B(ch)=I(ch)×expectedHours(ch)`；天龙 300 两；倚天 6,900 两 |
| 书眠 | 银两、资源库存、点状态、家丁合同、职位、门派身份 / 公账和家业设施不跨界 | 只保留上游允许的配方 / 图谱学识、图鉴、成就与经营里程碑事实；当前 28 条天书之力无例外 |
