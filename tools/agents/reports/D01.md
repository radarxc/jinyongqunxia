## 5. 对基准的修改提案（编号 / 提案 / 理由）

| 编号 | 提案 | 理由 |
|---|---|---|
| TL-P01 | 基准 §12 的区域格式改为全局稳定 `rg_<拼音>`，章节独有场景用 `sc_<NN>_<拼音>` | AR-04 已覆盖旧格式，实际大地图和本章都使用全局区域 |
| TL-P02 | 基准 §12 增列 `city_*`、`sc_*`、`gate_*`、`rp_*`、`biz_*`、`job_*`、`sys_*` 的前缀、归属与生命周期 | 作者需求已把时代城市、资源、营生和特色系统纳入生产数据，现有 ID 表不足 |
| TL-P03 | 基准 §17 吸收 AR-04、AR-07–AR-11、AR-13 的章节模板变化 | 防止后续章节私建区域、复写已审校主线、越权造人物或传承 |
| TL-P04 | 基准 §18 增列 story、地图、经脉、经营、门派、人物、传承与章节系统接口的唯一归属 | 专项文档已建立，唯一归属表需要同步真实边界 |
| TL-P05 | 基准 / 存档规则明确回响布尔键可使用“仅真值存在，缺失为假”的稀疏语义 | 避免 `echo_01_fate` 的显式 false 与旧存档 / canon 回响产生歧义 |
