## 3. 关键结论与数值

- 图片数量：`1 张亢龙 + 1 张六脉 = 2 张`；首轮调用 2 次，本次仅降龙逐张调用 3 次，累计 5 次生成 5 张、淘汰 3 张。无 API / CLI 替代出图、无代码绘图冒充位图。HTML 不计图片数量。

- 文件模式均为 RGB：图内透底与半透明成立，但不能宣称有 alpha；浅纸底是本轮概念参考的主动选择。
- 已复用 `mv_xianglong18_kanglong` / `sk_liumai` 作为主体，新增两个 `ref_` 素材 ID 前完成全仓查重；未新增武学、招式、穴位或玩法 ID。
