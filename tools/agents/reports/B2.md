## 3. 关键结论与数值

1. **世界结构**：一张中国江湖大地图承载十四个正篇时代图层，另有春秋越国教学层；城市名、地位、入口、势力、NPC、资源点与营生场所随时代切换。大地图只负责导航 / 旅行，区域内才可行走。
2. **书眠**：机制名为《长生诀》，沉睡年数 `X = 下一书界入场年 − 当前书界出场年`；正篇 `ch01→ch02` 至 `ch13→ch14` 共 13 段视频，逻辑 ID `vid_sleep_NN_MM`，目标 24 秒、合法范围 20–30 秒。序章转场和“归梦”不占此序列。
3. **主角**：按 P05 固定为男女可选且无数值差异；首周目提供 5 个现代身份，均满足 `OriginBonus` 的先天净额 ≤ +12、资质合计 ≤ +30、技艺合计 ≤ +40、单项限额与 `lore ≤ +10`。轮回身份 `origin_shuoshu` 是明确标记的预算特例。
4. **循环节奏**：分钟级 3–12 分钟、小时级 45–120 分钟为建议值；每书界固定 8–15 小时，十四界合计 `14×8=112h` 至 `14×15=210h`。含完整序章与终局的规划包络为 `0.75+112+1.5=114.25h` 至 `0.75+210+3=213.75h`。
5. **书界内容**：锚点数依次为 `5,5,5,6,5,5,5,6,5,4,4,5,5,4`，合计 69；每界恰好 1 个主改命，合计 14，并与 `design/13` §4.4 的 `tsp_01_*`—`tsp_14_*` 主题对齐。
6. **序章**：8 段上限核算为 `4+5+7+7+8+7+4+3=45` 分钟。`sk_yuenvjian` 为阿青 / 剑源版、地上 9；`sk_yuenvjian02` 为韩小莹版、玄下 4，二者分立。跳过时只补 `sk_yuenvjian` 一重残篇及无收益基础见闻，不给感悟、物品或其他数值奖励。
7. **叙事收束**：守卷人默认是失去自我的前代穿书者；回到现实不改写现实原文，而是让主角把十四次选择形成的理解带回日常。书灵默认真名“余墨”，只在“同归”结局揭示。
