# L1 报告 · ID 一致性检查脚本 tools/lint/check_ids.py

## 1. 摘要（3–6 行）

已完成跨文档 ID 一致性检查器、使用说明与标准库单元测试，未改动职责范围外文件。
脚本从 Canon §12 动态解析 53 个前缀，按 Canon §18 的可配置归属映射保守区分定义与引用。
当前全仓扫描 31 个 Markdown 文件、17,146 个 ID 出现和 5,308 个定义，五类问题数为 24 / 0 / 5 / 9 / 0。
默认模式在发现问题时仍退出 0；当前 `--strict` 因第 1、4 类共 33 条记录而按约定退出 1。
12 个 `unittest` 用例全部通过；套装检查因 `docs/design/07-set-system.md` 尚不存在而明确跳过。

## 4. 开放问题（附默认值）

1. **近似 ID 的处置**：是否把第 3 类的已确认合法近名加入永久白名单？默认不加入，
   继续显示给 F2 人工复核；仅 `sk_emeijiufa` 按很可能的真实不一致推进修正。
2. **缺失归属文档时是否报前向引用**：`set_`、`npc_`、`q_` 当前在全部 owner 缺失时
   暂停第 1 类。默认保持暂停，以降低分阶段写作中的大规模误报；owner 一出现即启用。
3. **旧 ID 是否同时出现在第 1、4 类**：默认保留。第 1 类按“无现行定义”计唯一 ID，
   第 4 类按重命名表计每个活动出现位置，两种视角均对审校有用。
4. **名称之外的重复字段比较**：默认先只比较名称；品阶、类型、数值字段格式尚未完全
   统一，贸然比较会制造误报，后续可随数据 schema 稳定后扩展。
