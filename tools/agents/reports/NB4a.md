# NB4a 报告 · 首领配装按统一口径修正与逐单位节奏复核（书界 01–07）

## 1. 摘要（3–6 行）

已按 `design/21` §11.9 复核书界 01–07 的 71 个非默认行动画像，并保留每界唯一“本界精英默认”锚。
NB3 指出的 48 条不合规表行均已改写：主运按来源四档或地位下限升档，七参随主运重算，Boss 配齐 1 主运槽 + 2 辅运与 3–5 门逐门标阶外功。
逐单位静态节奏全部回到 Boss 12–25 / 精英 6–10 轮；超窗项只调整整场 HP 倍率，防御倍率保持 1.000，没有压低经脉强度。
续作已落实作者决定（2026-09-27）：神雕金轮 `11/8`、五绝 `11/9`、杨过 `12/9`，严格体现“金轮 < 五绝 < 杨过”。
现有图鉴仍使神雕 6 个画像、倚天成昆共 7 个画像触发生产构建阻断；其余专属缺口均明确现用替补或地位兜底，未新造 `sk_*`。

## 3. 关键结论与数值

- 书界 01–07 的 `G` 为 `7/8/9/9/8/7/7`；Boss 主运至少 `G`，手配精英至少 `G−1`，默认精英锚仍按 `G/8` 且至多小周天。
- Boss 七参统一为 `effGrade/effLayer; 13000; 9000; 13000; innerNature; fullTemplate; milestones`；除 §11.9.1 地位兜底外，`effGrade/effLayer/innerNature` 都取最终主运，辅运不抬强度。
- 71 个非默认画像均为 1 个主运槽、2 门玄 / 黄基础辅运、3–5 门外功；外功闸门是至少一门 `≥G`，不是 `≥effGrade`。
- 轮数按 `R=R0×10000²/(A×D)×hpMultiplier×defenseMultiplier`；超窗 Boss 取 `M≈23/Rraw`，精英取 `M≈9/Rraw`。显示倍率保留四位小数，工具使用未舍入原值。
- 02 的倍率为 `0.8919/0.8295/0.8002`，03 为 `0.8370/0.7959/0.7885/0.7646`，05 为 `0.8127/0.7612/0.7435/0.7984/0.7739`，06 为 `0.8584/0.8429`；01、04、07 均保持 1.000。
- 作者决定（2026-09-27）将神雕地位下限定为金轮 10、五绝 11、杨过 12；金轮的 `sk_longxiang` 已是天中11，故以 `effLayer 9→8` 落实严格次序，最终为 `11/8 < 11/9 < 12/9`。
- 多人 Boss 的倍率只乘整场共享总耐久或目标进度；每个行动者仍独立初始化经脉动态态，绝不复制完整 Boss HP。
