## 3. 关键结论与数值

### 3.1 审校后的设计结论

1. 正邪是可切换的立场轴，原著 / 改命是独立命运轴；D04 首次分线，D05 / D06 可付代价切线，D06 后锁立场，D08 锁命运。
2. 正线以救援、公开证词与公议为核心；邪线以残图、短约、欺敌和秘密制衡为核心。两线均能完成阿曼救援、身份揭晓、旧案、Boss、天书与结局，不把邪线写成惩罚性死路。
3. 与 `design/01` §7.11 一致的四锚点为：大漠追逐与李文秀身世、哈萨克部落与情感纠葛、高昌迷宫与瓦耳拉齐旧怨、白马回中原。唯一主改命仍是第三锚点。
4. 改命须同时满足完整旧案、双方分别信任、不依赖宝藏的退路、先救人、永久放弃高阶遗物五组事实；不足时原著命运始终可选，因此不形成死档。
5. 原著命运授予 `tsp_10_canon`“得失”，改命授予 `tsp_10_fate`“白马西风”；两名命定死亡同伴若有人曾入队，只发送一次 `companionFateRescued(ch10_baima, npcIds)`，合计支付 2 点修为余韵。
6. 为给改命留下可操作窗口，z03–z04、z06、x05–x06 把“先致命互伤、后相认与揭旧案”重排为“先截停、问证、再结算”，现已逐处标为 **（原创扩展重排）**。

### 3.3 考据与数据校验结果

- 对照可访问在线八回后，纠正了上官虹用两柄匕首造成二人同时中刀、丁同由计老人肘击毙命、陈达海两次胁迫阿曼、苏鲁克 / 车尔库到场受伤、阿曼到第八回才明说识破女装等顺序。
- 明确桑斯儿与“骆驼”在入口中针后死亡，假鬼随后先杀马、翌夜再杀无名青年；救活均是次级 **（原创扩展）**，不冒充原著结果。
- 明确瓦耳拉齐先叫破并揭下马家骏假面，师徒致命互伤后马家骏自认，李文秀再由声音认出华辉；旧案随后展开。马家骏先死，瓦耳拉齐后来仍试图发针并最终死亡。
- 残图措辞统一为抽去“十来根”毛线、地图少“十几根”线；陈达海等渴死只是人物预想，正文不再宣称已见其死亡。
- `npc_ningqiangdao` 可解析，但上游显示名“宁强盗”与在线第五回“姓宋的强人”冲突；本文沿用旧 ID 并纠正显示，不另造重复实体。
- 机器检查通过：0–9 一级章节、60 个事件、21 个幕的九类固定字段及 3–8 步流程、10 个节点字段、Markdown 表格、成对代码围栏、3 个 YAML 解析、占位词扫描和 `git diff --check`。
- `tools/lint/check_ids.py --strict` 全仓仍报 235 个未定义引用 + 1 个废弃 ID，共 236 个既有严格失败；过滤目标文件后为 0 个未定义、0 个废弃、0 个冲突定义，仅有合法近似名 `npc_sangsi` / 其他文档 `npc_sangjie`。
