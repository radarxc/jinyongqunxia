# ART-dressup-d2c-head-align 报告 · 3D 纸娃娃换装 · D2c · 拼头对位（颈子截面对中）与身体染色对准下接缝 → 重切穆念慈 / 黄蓉三体型
## 1. 摘要
- 作者两条要求都已落到 `cut_head.py`：① 切口处头皮截面中心对到模板颈子截面中心（切口高度上模板颈子圆心在颈骨轴前 5–10 mm、右 2–4 mm，头颈子圆心在轴左约 3 mm、后约 1 mm，按骨骼对位后头整体偏后偏左）；② skinTint 增益改为"切口头色 ÷ 下接缝附近可见身体色"。
- 两人三体型（两行口径改正后）重切 6 份，level 均 draft、V4 门禁零失败、阈值未动。头整体平移 7.5–12.4 mm；交付网格上切口截面中心差 0.06–0.67 mm（< 1 mm）。
- 5173 实拍：主干版侧面喉部、后颈在切口处的台阶（作者说的"错开"）消失，正面颈到肩同色。
## 2. 产出
- `cut_head.py`：`center_neck_section` / `_section_center` / `angle_ranges`（切面定下后、颈部单调适配前平移整头，重算包络与切面；诊断 `neckCenter` 含平移量、两边圆心、所用角度 `anglesDeg`）；`bake_strip` 增下接缝条带（遮罩平面 ±2 mm）与 `gainSeamMean`，切口头色按任务口径严格取切口以上首两行（`CUT_COLOR_ROWS = 2`；D1b 起此处注释写两行、代码实取三行，审核 r1 指出后改正）；`process_head` 按下接缝口径染色并量 `deltaE`，同高度口径记 `deltaESameHeight` 只报。
- `tests_head.py`：合成 `test_center_neck_section`（偏轴 (5, 8) mm、缺后颈 100°、椭圆截面、超限报错、角度区间）、`test_body_tint_seam_reference`（颈子上浅下深时下接缝残余增益 1；头皮第三行换成另一种颜色，断言增益只由首两行决定——取三行时该测试失败，已实测）；真实资产对带 `neckCenter` 的头断言截面中心差 < 1 mm、`neckMatch.reference == headCut/bodySeam`、`deltaE < 3`。
- `heads/npc_munianci`、`heads/npc_huangrong`：head / fit / report / hidemask / preview / self_check × 3 体型与 manifest；`shots/align.tpl_f_{medium,tall,small}.jpg`（现在主干 vs 新 × bind / walk@0.35 / run@0.5 × 侧面 / 侧后 / 正面 / 后颈）。

## 4. 开放问题（附默认值）
- 黄蓉颈子比模板细约 4 mm（半径 38.8 vs 43.0 mm）：对中后由单侧台阶变为整圈均匀内收 3.1–3.5 mm（腰线只报）。默认接受；若要消除需另议模板颈片顶端收细或头颈加粗。
- 非正圆截面的"圆心"随角度集合变（黄蓉换一组同样合理的 A 区角度差 1.3 mm）：测试改在生产记下的 `anglesDeg` 上复量，并要求这组角度 ≥ 90% 落在测试独立判出的 A 区，防止按看不见的颈皮对中。
## 5. 对基准的修改提案
- D2c-P1：tech/12 §1 V4 的颈色差改为"切口颈色 vs 下接缝身体色"，同高度口径只报；§2 P5 切头步骤增"颈子截面对中"（对中角度记入 `diagnostics.neckCenter.anglesDeg`）。
