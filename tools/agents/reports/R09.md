## 3. 关键结论与数值

### 3.1 六角空间契约

- 使用 pointy-top 轴坐标 `(q,r)`，派生立方坐标 `s=-q-r`；六邻依次为 `(1,0)`、`(1,-1)`、`(0,-1)`、`(-1,0)`、`(-1,1)`、`(0,1)`。
- 距离为 `max(abs(dq),abs(dr),abs(-dq-dr))`；稳定遍历按 `(r,q)`，范围目标再按 `(distance,r,q)`，保证回放与 RNG 消耗确定。
- 外接圆半径 `R=2/3 m`【建议值】：轴坐标行距 `3R/2=1 m`，六邻中心距 `sqrt(3)R≈1.1547 m`。斜 45°只表示正交相机偏航，不再表示方格拓扑。
- 就地开战窗口为实际可用格集合，硬约束 `tileCount≤400`、`qSpan≤20`、`rSpan≤20`；每格继续保存 `h` 与 `terrain`。
- 规则只存 6 个 `HexDir`；关键角色资产仍为完整 `battle8`，固定镜头驻留 6 个映射视图。本文方向到 tech/02 展示编号的映射为 `[0,5,4,3,2,1] → H[0,1,2,3,4,5]`。
- 方位按目标到伤害来源的首个六向判定：正/侧/背对应 Z7 伤害 `1.00/1.10/1.30`，招架方向倍率 `1.00/0.75/0.50`，均直接引用 04。

### 3.2 轻功移动与出手顺序

`spd` 修订提案：

`Base_spd = 72 + 0.30×agi + 0.10×Ld + 0.14×qinggong`

`spd = clamp(floor((Base_spd + Σflat_spd) × (1 + Σpct_spd)), 30, 300)`

它让轻功值直接主导长期集气，同时保持 03 的 Lv1 / 35 / 70 旧节奏锚点附近约 92 / 106 / 125–127。开战首轮不再随机 `CT0`，固定按 `qinggong desc → spd desc → agi desc → 先机阵营 → unitIndex asc`；首轮后回到 CT 0→1000 与招式收招。

移动力为：

`withinTier=min(1,floor(max(0,qinggong-threshold)/30))`

`baseMove=3+tier+withinTier`

`move=clamp(baseMove+moveSkillFlat+ΣbuffMoveFlat-heavyArmorPenalty-fatiguePenalty,1,10)`

| 轻功境界 | 轻功值 | 基础移动力 |
|---|---:|---:|
| qg0 未入门 | 0–19 | 3 |
| qg1 初窥 | 20–49 | 4 |
| qg2 入室 | 50–89 | 5–6 |
| qg3 登堂 | 90–139 | 6–7 |
| qg4 化境 | 140–199 | 7–8 |
| qg5 绝顶 | ≥200 | 8–9 |

最终可达性再检查 `Σ(moveCost_08+zocCost)≤move`，因此完整函数确实同时消费轻功值、境界、体力、负重、地形与 Buff。负重已在轻功值中扣一次；重甲 `mov−1` 是独立护甲代价，不重复扣负重。算例：轻功 98 得 6 格；轻功 125 得 7 格；重甲令有效轻功降到 88 后基础仍为 6，再扣重甲得到 5。

### 3.3 范围模板与预算

| 基础族 | 生产模板 | 格数 / 规则 |
|---|---|---|
| 点 | `aoe_single` / `aoe_self` | 1 格 |
| 环 | `aoe_ring` / `aoe_around` | `6r`；around 固定 r=1、不含自身 |
| 面·圆盘 | `aoe_disk` | `1+3r(r+1)`；r=1/2/3 为 7/19/37 |
| 面·线 | `aoe_line` / `aoe_bolt` / `aoe_spokes` | 六向直线；首中射线至多 1 单位；六芒射线含中心为 `6r+1` |
| 扇形 | `aoe_cone` | 60° / 120°；默认 6 向，可显式启用 12 向半向瞄准 |

固定六向扇形半径 1/2/3/4 的格数，60° 为 1/4/7/12，120° 为 3/8/15/24；已用与正文几何判定一致的脚本逐项复算。招式范围系数改为 `AF(N)=clamp(roundToStep(1/sqrt(1+0.18(N-1)),0.05),0.35,1.00)`，例如 N=1/6/7/19/37 对应 1.00/0.75/0.70/0.50/0.35。旧 `aoe_sq3/sq5/diamond/cross/x/sweep` 仅供迁移读取，新内容构建报错。

### 3.4 行动、运劲、道具与 Buff

- 一次正常行动统一为“一段移动 + 一个行动”；行动表覆盖招式、暗器、道具、运劲、防御、待机、援护、撤退、口舌、俘获、看破、解穴、挣脱、救护、易运、换兵、分心二用与合击。免费动作继续遵守基准限次。
- 道具引用 10 的类别，普通道具总次数为 `3+floor(med/40)`（3/4/5 次），同 ID 冷却 2 次自身行动；暗器弹药不计入该上限。
- `yunjin` 合并旧“运功调息”，分 `tiaoxi/huti/xuli/bidu/liaoshang/cuiqinggong/huajie`；消耗 MP 并占行动，强度读取内功品阶、层数与阴/阳/调和性质。它不等于 AR-03 的“内劲/冲穴”。
- 作者点名 11 类 Buff 已全部映射。06 已有 `bf_zhongdu`、`bf_hanqi`、`bf_zhuoshao`、`bf_xuanyun`、`bf_mabi`、`bf_jingang`；需补 `bf_hunmi`、`bf_kangfen`、`bf_minjie`、`bf_zhuanzhu`、`bf_muguangruju`，并给 `bf_mabi` 增加 `str−3×G`。
- Buff 的一回合仍是持有者一次自身行动；被硬控跳过也推进，反击、连击、援护与 Boss 连动子行动不推进。
