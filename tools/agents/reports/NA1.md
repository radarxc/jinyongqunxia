## 3. 关键结论与数值

| 项 | 结论 / 核算 |
|---|---|
| 绝招配额 | grade 1..12 固定为 `0/0/0/0/0/1/1/1–2/2/2/2–3/3`；玄上 1、玄中 / 玄下 0 |
| 身份与解锁 | 只以 `MoveDef.ultimate:true` 判定；第一 / 第二 / 第三绝招默认 7 / 9 / 10 重，压制后按最终 `effLayer` 判断可用性 |
| 共享资源 | 同一角色只有一个 `rage 0..100`；每记绝招消耗 100，不建立逐门或逐招气势槽 |
| 共享冷却 | 绝招 F2 支付后本门 `ultimateCooldown=1`；施放当次 E2 不减，下一次正常自身行动全程禁用并在该行动 E2 后清零；环境、他人、免费、再动 / 连动不推进 |
| 重复限制 | 冷却清零后仍不能连续施放同一绝招；成功结算同门另一绝招会更新最近绝招，同门普通招会清空；其他武学普通招不清空 |
| 候选与 AI | 玩家、AI、一键重复、Core 共用过滤器；过滤自身冷却、同门冷却、连续同招与路线硬封。AI 逐招、逐目标 / 朝向按目标数、击杀 / 控制 / 支援、风险、路线堵塞、`flowCt` 及共享资源评分 |
| 轻功构建 | 五绝 7 门＋逍遥 5 门必须生成父对象局部 `basic_movement`，引用 `{skillId}#basic_movement`；不注册全局 `mv_*`，未生成或引用不闭合即拒绝构建 |
| 示例威力 | 独孤三绝招 15.75 / 16.07 / 16.07；易筋“倒拽九牛尾” `3.5×1.5×2.20=11.55`；九阳普照 `3.5×1.5×1.80=9.45`；龙爪捣虚式 `2.2×1.5×2.75=9.075≈9.08` |
| 装备迁移 | 紫薇软剑 12% → 受擒 4 级、2 次自身行动、距离 1；金铃索 8% / 鹤嘴双笔 10% → 穴位受封 9 级、1 次自身行动、目标主要路线关键穴；概率不变 |
