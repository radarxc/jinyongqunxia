## 7. 审校结论

**结论：有条件通过。** 正文已达到可交付的策划与数据接口质量，授权范围内没有仍会阻断正线、邪线、改命或天书结算的问题；条件是后续按归属完成权威底本对校和缺失外部 ID 登记。

### 阻断

- **已处理：正式任务 ID 不符合 `design/12`。** 全部迁移为 `q_08_main_01..18`，并保留无歧义路线别名映射；旧非法 ID 已清零。
- **已处理：YAML 与任务 DSL 不兼容。** 两个示例改用 `quest.v1` 合法字段、布尔条件 AST、动作白名单、显式终态及幂等 effect ID；PyYAML 解析通过。
- **已处理：路线 / 锚点条件存在不可满足与状态歧义。** 补齐三方渠道写入，统一郑氏旗标，并使路线及 canon / fate 结果互斥。
- **已处理：原著事件顺序会令两条主线断裂。** 神龙岛初访、江海 / 罗刹、扬州、神龙终战、通吃岛刺杀与雅克萨重新排到正确回次区间；正邪各可从开局走到四结局矩阵。

### 重要

- **已处理：声望公式算错。** `1800` 改为 `1650`，并证明仍跨过 1600、未跨过 3000。
- **已处理：洪安通等级公式缺少全局约束。** 补为 `min(50,70,44+6)=50`；战斗机制继续只引用上游。
- **已处理：第29回缺少陈近南改命所需伏笔。** 补足冯锡范伏击动机与观察信息，但不伪造缺失 NPC ID。
- **已处理：改命动作会重复发布事件。** 移除显式同名事件，避免余韵被扣两次。
- **已处理：覆盖率与生产拓扑缺少可机检口径。** 现有 50 个逐回事件、18 个任务、10 个节点、6 个锚点和 4 个结局均有校验规则及可达测试。
- **未越权处理：部分具名角色尚无正式 `npc_*`，通吃岛尚无正式地点 ID。** 正文明确列“待补 ID”或使用局部 `placeKey`，同步项见 §6。

### 一般

- **已处理：版本与审校记录缺失。** 文首追加“审校 P08.R（2026-09-26）”。
- **已处理：共享幕奖励、换轨和惨胜支边界不够明确。** 增加 effect ID 去重要求、换轨成功终态和“不发天书—补救回流”规则。
- **已处理：考据置信度表达不足。** 参考资料补访问日期与用途边界；网络文本仅定位，未核细节统一标 **（待考）**。
