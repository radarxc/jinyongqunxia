## 3. 关键结论与数值

| 线 | 隐藏行动 | 代价 / 结果 |
|---|---|---|
| F1 商家堡 | 预查死闩、风向、水井，3 回合内拆闩并分路救人 | 舍账册原本与追兵战利品、商堡关系降档；马行空 / 商老太逐人求值 |
| F2 钟家 | 胡斐离庙前用空车与两处安全点分路撤离，空宅留证 | `fame=max(0,fame−100)`、舍追凤先手与一份证据；灭口意图仍可追责 |
| F3 石屋 | 致命出手后 2 回合内截掌、救徐铮，由马春花本人决定止刀 | 舍福府名单 / 投帖捷径，飞马 / 商堡关系降档；可零 / 单 / 双救 |
| F4 马春花 | 十二时辰静卧不断，截住二次送孩，会后两阶段知情撤离 | 舍大会高价值奖励、福府锁敌对；母子离队隐居 |
| F5 程灵素 | 医、毒、解毒、人情四项合拢，在 `dc_13_10` 共同救治 | 放弃原著天书变体、胡斐长期恢复、珍稀资源；成功授 `tsp_13_fate` |

- 局部门槛默认 `bond>=60`；主改命程灵素 `bond>=80`。8 品检定由 `T(8)=8×8−4=60` 推得。
- 对应 `design/13` 代价表：天书之力仅 F5 二选一；同伴离队 / 休养；声望、关系、证物或奖励支付；后世仅进本界后日谈、回响与书契。
- 任一事件中获救者曾入队时触发同伴改命事实；本书界第一次才支付 2 点修为余韵，不足记 `yuyun.fateDebt`，同事件多人及其后同界救援均不重复收费。
- 新增【建议 ID】：无；未新造 `npc_*` / `q_*`，仅用 `story13.localFates.*` 私有状态。
