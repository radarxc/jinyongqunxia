# NXB09 报告 · 书界 09《连城诀》首领所缺武学补录与替补替换

## 1. 摘要（3–6 行）

完成万圭、凌退思两个首领缺口：新增万家门与荆州官差体系各一内一外，共四门玄中 5 品武学。
四门均为**（原创扩展）**且按门派职级、教头传授或武册正常开放；没有人物独占武学，也不把描述性名称冒充原著招名。
书界配装已移除 `sk_jianghutuna`、`sk_wuyingshou` 两组主力替补，七项参数按新主运性质复算。
三阶段静态节奏为万圭 `19.62→20.00→20.00`、凌退思 `19.33→19.71→19.71`（原 4 品画像 → NB4 临时替补 → 本次正式武学）；都在 12–25 轮窗口，无需调整血量或防御倍率。
来源扩展、跨书界待替换、未能补齐缺口均为 0。

## 3. 关键结论与数值

- 复用审计：`sk_wanjiaxinfa` 仅玄下 4，不能满足万圭主运 5 品下限；`sk_jianghutuna`、`sk_wuyingshou` 是江湖通行替补；`sk_yuzhongqinna` 是丁典—狄云狱中来源，均不能闭合本次门派 / 来源要求。`sk_jundituna` 军旅吐纳虽为玄中 5、军中通行且 `ALL14`，适合作荆州官差精英的通用主运，但其阳性跨书界军伍定位不能表达凌退思所缺的荆州衙门组织传承与调和主运画像，故保持现有新增选择。
- 四门新增武学均取 **5 玄中**，满足 `design/21` §11.9.1 对低武普通 Boss 主运 / 主力武学的下限，又不把万圭、凌退思拔高为高阶武者。每门 3 招、3 被动、0 绝招，符合玄中 3–5 招、2–4 被动、0 绝招。
- 两门内功均按 `17+10+2×7+5×1.5=48.5 IP` 配置；`txp_wanjiazhengqi` 为阳性 `1800/420`，`txp_jingzhouyangqigong` 为调和 `1890/441`，二者均 `scope=2`、`ct=1000`、`mpCostBp=0`、`outOfBattleScaleBp=15000`。
- 十二式经逐招外放审计，均为自身运功或 1 格接触式拳肘 / 擒拿，`projection:false`，外放招式数为 0，不配置 `projectionSpreadSteps`。
- `boss_pacing.py` 精确结果按“原 4 品画像 → NB4 临时替补 → 本次正式武学”计：万圭 `19.6173309698→19.9995242390→19.9995242390`，凌退思 `19.3333497168→19.7113450375→19.7113450375`。临时与正式方案同品阶、同七参强度，本次替换不改变静态轮数；两人 `recommendedMultiplierToWindow=1.0`，故血量 / 防御倍率均保持 `1.00 / 1.00`。
