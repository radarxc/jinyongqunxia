## 3. 关键结论与数值

### 3.1 独立乘区与强度

| 项 | 定稿口径 |
|---|---|
| 经脉强度 | 气量 30% + 容量 25% + 流畅度 25% + 完成质量 20%，总分钳制 4000–18000 bp |
| 路线兑现 | `min(10000, 3000 + floor(7000n/18))`；1 段 3388 bp，18 段 10000 bp |
| 攻击 | `Z5M / meridianAttack` 位于 Z5 后、Z6 前，向下取整，硬界 6500–22000 bp |
| 防守 | `Z4M / meridianDefense` 位于 Z4 后、Z5 前，向下取整，承伤倍率硬界 5000–13000 bp |
| 成长边界 | 冲穴、周天、九转只抬强度输入，不抬乘区上限；外来压制先进入最终强度快照，不重复相乘 |

五档黄金对战：同等 `10000 bp，849→849，TTK 5→5`；强一档 `12053 bp，950→1145，9→7`；强两档 `14456 bp，2574→3720，22→15`；弱一档 `9241 bp，849→784，5→6`；高手对杂兵 `18265 bp，849→1550，3→2`。主动防守例为 `1000 → Z4M 936 → Z5M 859`。

### 3.2 护体内劲与速度

| 项 | 定稿口径 / 黄金结果 |
|---|---|
| 护体位置 | 护体真气之后、`mpGuard` 之前；拳脚 / 兵器 / 暗器 / 内劲外放适用 100% / 25% / 0% / 40% |
| 资源兑换 | 1 内力抵 2 伤害；维持例抵消 1000、耗内 500、反震 100；守恒含奇数向上取整 |
| 击穿 | 容量不足或内力耗尽都算击穿；内力击穿例抵消 600、气血伤害 1000、延迟 400 CT、迟滞 3000 bp |
| 速度 | 经脉速度 6500–13500 bp；先经脉后擒拿，`spd≤300`、移动增量 `[-2,+2]`、`recovery≥500` |
| 标准 / 强者 / 封路 | `10000/12239/6500 bp`；首轮轻功 `98/119/63`，`spd 106/129/68`，移动 `6/7/4`，闪避评级差 `0/+22/-35` |
| 频率硬界 | 极端配置每 1000 tick 最多 600 次行动；修正轻功只用于首轮排序，不绕过 08 的 20/50/90/140/200 门禁 |

擒拿 / 点穴与护体的顺序为直伤先过护体、控制随后独立检定；除非招式声明“必须击穿”，抵消伤害不自动免疫控制。破体 / 破气、点穴、兵器、持续压制和耗尽内力均可破局。
