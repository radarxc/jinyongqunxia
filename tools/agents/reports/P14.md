## 3. 关键结论与数值

1. **书界硬参数**：1780 年，中武，武运 60（`WY3`），难度 D7，显示等级 46–58，上限 58；终章 Boss 超限候选苗人凤 Lv62 = 58 + 4。
2. **幕结构**：`q_14_main_c_01..03` 为 3 个共有幕，`q_14_main_z_01..09` 和 `q_14_main_x_01..09` 各 9 个专属幕；单条路线均为 3 + 9 = 12 幕，落在 8–14 幕验收区间。
3. **原著覆盖**：50 / 50 关键事件有明确去向，第一至第十回 10 / 10 覆盖；按首要去向统计为共有 / 锚点 27、正线 4、邪线 2、选择节点 10、锚点直达 4、支线 2、不照搬原表现 1，合计 50。
4. **选择节点**：`dc_14_01..08` 共 8 个，选项数依次 3 / 4 / 3 / 4 / 4 / 4 / 4 / 3；`dc_14_04`、`06`、`07` 允许付代价切线，`dc_14_07` 后锁线但不锁结局。
5. **品德建议值**：`Δmorality = sign × 3 × severity`，`severity ∈ {1,2,3,4}`，故本文单次只用 ±3 / ±6 / ±9 / ±12，全部落在 `design/03` 规定的 ±1–±15 范围内；它是 **【建议值】**，等未来 `design/12` 定稿。
6. **四锚点**：A1 玉笔峰群雄聚会 → A2 胡苗范田旧怨复盘 → A3 闯王宝藏与毒谋揭露 → A4 胡斐对苗人凤“劈与不劈”，与 `design/01` §7.15 一致。
7. **两全判定**：`crossBookEvidence && hufeiTrust && miaorenfengTrust && poisonPlotComplete && bothFlawsSeen && renounceFirstStrike && noIrreversibleHarm`，共七个布尔项 / 六组条件；高 `speech`、高 `morality`、胜过 Boss 都不能单独替代。
8. **结局与天书**：正 / 邪 × 劈 / 不劈 / 两全 = 6 个完成态。`pi`、`bupi` 都发 `tsp_14_canon`；`liangquan` 只发 `tsp_14_fate` 并计 `F +1`。本文默认“劈”为苗人凤死、“不劈”为胡斐死，均明标原创补写。
9. **等级与终局**：第十四天书后真实等级补至 70，雪山余韵仍显示 58，进入 `ch15_guimeng` 才解除显示压制；雪山不发 `it_shiyin`。
10. **NPC 口径**：使用 23 个已有具名 `npc_*`，其中 19 个 1780 活体都有加入 / 限时受控窗口，4 个前史人物只用 `reference`；另有于姓管家、胡斐左右双童 2 类无静态 ID 职能槽。
11. **地点口径**：玉笔峰统一用 `rg_liaodong + cityId:null + placeKey`，不伪造城市 ID；最近补给城 `city_shenyang` 在 1780 年显示“盛京奉天府”。
12. **数据接口**：登记 49 个 `flag_14_*`、4 个锚点完成态、6 个非全局结局组合键和 5 个局部 `placeKey`；任务幕 / 选择节点两段 provisional YAML 可解析，但不冒充未来 `design/12` 正式 schema。
