## 3. 关键结论与数值

### 3.1 敌方模板与实例边界

| 项 | 本组落地口径 |
|---|---|
| 精英默认 | 当界主力品阶 / 8 重，`mpRatioBp=10500`、`practiceBp=7500`、`capacityScaleBp=10500`、`openPolicy=schoolCore` |
| Boss 默认 | 首领表品阶 / 9 重，`mpRatioBp=13000`、`practiceBp=9000`、`capacityScaleBp=13000`、`openPolicy=fullTemplate` |
| 性质 | `innerNature` 只取 `yin/yang/harmony`；能从主武学解析者不在章节猜值，缺正式武学者阻断生产 |
| 路线 | `routeRefs = unique(actionTable[*].MoveDef.meridianRouteRef)`；未知 / 缺路线构建失败，不建章节私有 `mfr_*` |
| 实例 | 每个独立武学行动者一个 `MeridianFlowModule`；跨遭遇只复用静态模板，动态态重建；纯环境对象不实例化 |
| RNG | 模块不持有 RNG；Core 按 `unitIndex` / 提交顺序注入唯一全局 `battle` 流，不派生单位子流 |
| 有效输入 | `effGrade/effLayer` 均为 `design/13` 完成外来压制、难度与规则开关后的最终值 |

静态里程碑严格取自 `design/15` §10.1：01、02 无周天 / 0 转；03 小周天 / 0 转；04 小周天 + 大周天 / 1 转；05 为 2 转；06 为 3 转；07 补十二经周流并到 4 转。`meridianComplete:true` 只表示路线所涉经脉全通，不表示 20 脉全开。
