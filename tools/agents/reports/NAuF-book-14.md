## 3. 关键结论与数值

### 3.1 多人耐久及两种余数方案（本次不改数值）

七场遭遇的 `totalHp` 依次为 `74,132 / 10,000 / 83,033 / 90,905 / 104,948 / 112,536 / 138,411`；均已有遭遇级分配，阶段回复 / 新血条为 0。B02 的 10,000 是五个必经目标的等价进度，不是玩家可击破 HP。

| 遭遇 | 比例份额与余数核算 | 最大余数法 | 余数全给最后目标 |
|---|---|---|---|
| B05，槽序：首领 00 / 镖局 10 / 山寨散人 20 / 军伍 30 / rescue / fireControl / exitRoute | `104948×(4000,1000,1000,1000,1000,1000,1000)/10000`；`41979.2+6×10494.8`；向下取整和 `104943`，余 5 | **现值** `41979 / 10495 / 10495 / 10495 / 10495 / 10495 / 10494`；六项余数同为 .8，按稳定序前五项各补 1 | `41979 / 10494 / 10494 / 10494 / 10494 / 10494 / 10499` |
| B06，槽序：首领 00 / 第一波 10 / 第二波 20 / 分支目标 | `112536×(5000,1500,1500,2000)/10000`；`56268 / 16880.4 / 16880.4 / 22507.2`；向下取整和 `112535`，余 1 | `56268 / 16881 / 16880 / 22507`；两波 .4 并列，第一波优先 | **现值** `56268 / 16880 / 16880 / 22508` |

四个候选分配均分别精确求和为 104,948 / 112,536。统一最大余数法只需改变 B06 第一波 `+1`、目标 `−1`；统一末目标补余则 B05 三精英及前两目标各 `−1`、末目标 `+5`。本任务只核算和记录；唯一规则交 NAuF-sysA 在 `design/09` §8.8.11 定，NAu-final 同步所有章节引用与夹具。

- B05：1 首领 + 镖局 / 山寨散人 / 清宫军伍各 1 精英，三精英运行时各 10,495；`41979+5×10495+10494=104948`。Z04 / X04 追图和提前援军占既有 20 / 30 槽，入洞、换幕仅迁余额。
- B06：首领 56,268；两波各 1 名精英、0 普通单位，各 16,880；分支目标 22,508，`56268+2×16880+22508=112536`。X07 苗人凤仅占 00 槽，翻转把当前余额迁给赛总管，不复制 B07 HP。
- B07：单池 138,411；`round(138411×0.70)=96888`、`round(138411×0.35)=48444`、最终 1 HP 转悬刀，三终局不回复、不复起。
- B02：双童分别为 9 品 / 8 重精英主运、至多小周天；保护方 HP 各 20,486 仅作失败阈值。`3×2000+2×2000=10000`：三次止围攻 + 双童各自安全离场；双童和全部围攻者均不可成为玩家伤害目标，断路锚点保留。
