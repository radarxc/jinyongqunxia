## 3. 关键结论与数值

### 年代地域定位与依据

- 玩法定年为 702–703 年（武周长安年间，按广义唐代文化分期），核心空间为西州、庭州 / 北庭、天山北麓。640 年灭高昌置西州，702 年置北庭；`702−640=62`，足以形成“故国旧藏 + 遗民改筑”的传说层。迷宫本体仍属小说 / 原创设定，不声称考古实证。
- 序章约前 482 年→白马 702 年：`702−(−482)=1184` 年；白马 703 年→天龙约 1093 年：`1093−703=390` 年。
- 原著关系、天铃鸟、计老人 / 马家骏身份、华辉 / 瓦耳拉齐旧怨、迷宫无传说金银而存典籍器物、李文秀东归及“那都是很好很好的，可是我偏不喜欢”的意旨均保留。

### 首书曲线、冷入口与 M1 范围

- 第一正式书采用低武 D2、Lv20；`enemyStatMul=0.85+0.05×2=0.95`。Lv14 / 16 / 18 / 20 夹具为 5,950 / 7,170 / 8,536 / 10,047；双人战 `4,689+5,358=10,047`，守藏三目标 `2,845+2,845+2,846=8,536`。
- 初眠六项为臂力、根骨、内息、悟性、身法、定力；均衡期望暂取各 50、`6×50=300` **【建议值】**，正式池与上下限仍归 `design/03`。
- M1 仅需 `rg_xiyu_beijiang`：A 场景 `sc_10_fengshi_feiyi` 48×32、安全院 12×10；B 场景 `sc_10_tieyan_caopo` 64×40、近景 40×32，可延后。
- 通过链为：长白山 / 西行过场可播可跳→废驿加载→可移动→一段对白→东口亮起→自动档可读→“第一卷·白马啸西风”题签后恢复操作。C01、B 场景、可选逐水盗战、营生与门派均不阻塞 M1。跳序章用 ≤90 秒摘要写入初眠兼容状态后进入同一入口。

### 长生诀、休眠与武学物品改动

- 长生诀候选：空龛异文（拓意不取原件）、井渠听息（先救人后得线索）、商队旧简（护送守约后获抄录）；三选一，均不授层、不新建任务 ID，交 `DES-changsheng-core` / sidelines 定夺。
- 休眠候选：保底“空龛听风”；替代“白马远去”“废驿归环”。三者同数值，均落实“放下”，随后预演首次 3 武功 + 3 内功取舍。
- 武学 ID 全不改：`sk_hasakeyunqi` 来源显示由“哈萨克部族”改为“铁延部草原体系”，`sect_hasake` 及以 `hasake` 开头的既有技能 ID 仅作兼容键；华辉心法、瓦耳拉齐指、马家骏飞针改按 702 年人物 / 旧案来源表述，不冒充原著定名。
- 兵器表现统一为唐代可接受的横刀、长枪、直刃剑、复合弓与实体针；禁用清式腰刀、火器及后世镖局制式。旧 D3 / Lv46 节奏只留迁移快照，生产标准改为 D2 / Lv20。

### 素材需求摘要

- 现有 `xiyu` 中清真寺穹顶、邦克楼等不得直接复用；只可逐件审计沙土、碎石、枯草等中性地表。新套件覆盖土坯城垣 / 民居、佛塔 / 石窟寺、烽燧 / 戍堡、驿站、毡帐、粟特驼队、葡萄园、露天渠 / 抽象井渠遗迹与迷宫入口，共 12 类地表。
- 人物最小量：23 张全部重出的成年全身立绘、12 套具名战斗精灵、4 套群体变体、23 头像；另含 14 图标、5 VFX、4 过场、7 组环境声与 3 首 BGM。M1 仅取废驿包、主角男女 / 沈青禾 / 李文秀、年代题签、对白、过场及存档 / 出口 / 风向图标。
