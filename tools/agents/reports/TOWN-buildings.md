- 以 TOWN-design 快照的两套各19类、合计38个宋建筑type为建筑清单；不生成元/明/清初骨架。

## 3. 关键结论与数值

- 原向占地 `w×h` 的地面包围范围为 `32(w+h)×16(w+h)` px：6×5 民居为352×176，3×2摊棚为160×80，18×14宫室为1024×512。PNG画布可大于该范围。
- 从同一底面读左右对角 L/R 与前角 F。`anchor_source=(L+R)/2`，`s=32(w+h)/(Rx−Lx)`；成品锚点为裁切后同一 s 缩放再加粘贴偏移。隐藏后角未实测，平行四边形不充分时仅为代理。
- 两轴目标为 +0.5 / −0.5，容差 ±0.03 引用 design/22 §9.3。宽深比误差 10% 是本轮额外制作告警阈值 **【建议值】**，不代表允许把正式占地改大 / 改小，也不替代精确比例验收。
- 38件建筑最终画布短边≥512，低件不为凑512而放大其地面。保留所有非零alpha像素后扩边；PNG本身不画棋盘格。低alpha噪点只影响裁边，不进入遮挡代理；遮挡代理读取alpha≥192包围框，未修改PNG alpha。临收植物另按最新§4.4原生小尺寸与透明裁边步骤处理。
- `building={type,footprint,anchor,era}` 按本任务明确格式登记。当前 schema.yaml 仅定义 CitySpec/TownLayout，尚未定义这一素材扩展；不能称为通过现有 schema 的独立素材验证。
- 每张只提供原向单视图，目标相机为45°，`png_rotations_available:[0]`、`allowRotation:false`。目录的四向允许布局不等于本轮已交四张视图；不镜像、不旋转PNG冒充新视图。
- 用户明确要求左上光、右下短影，覆盖快照 §7.4 的“右略上”旧口径。大范围投影、角色遮挡和屋顶淡出交运行时。
- 底层图像模型 / seed / 图像推理档位未由工具披露，清单如实登记，不把旧任务的编排模型名冒充本次图像引擎回执。
