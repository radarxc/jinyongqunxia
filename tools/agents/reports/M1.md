# M1 报告 · 15 冲穴、经脉与周天（作者需求 AR-03）

## 1. 摘要（3–6 行）

已完成 `docs/design/15-meridians-and-acupoints.md`，将 AR-02 / AR-03 与作者 G1 确认收敛为冲穴系统的唯一归属规则。

## 3. 关键结论与数值

| 主题 | 定稿结论 / 核算 |
|---|---|
| 术语与顺序 | 一脉全开称通脉；任督均通为小周天；奇经八脉全通为大周天；十二正经全通为十二经周流；大周天后进入第一至第九转，第九转封顶。第四转另要求十二经周流 |
| 内容规模 | 20 条 `mer_*`、180 个唯一 `ap_*`；每脉 6–12 穴。接入分类为本经 132、交会 42、借穴 6；标准穴位代码也保持 180 个唯一值 |
| 内劲 | `Qi(m)=Σ[G(g_i)×L(n_i)×r_i×spec(i,m)]`；`L(n)=0.5+0.1n`，单门专精当前经脉时 `spec=1.20`，否则 1.00 |
| 速率 | `RateRaw=80×Qi×Affinity×M×D×T×(1+AidRateBp/10000)×ModeRate×Disorder`；`M=sqrt(clamp(mpMax/MPREF(Ld),0.50,2.00))`，`D=clamp(0.65+0.01Ld,0.75,1.35)`，每本天书令 `T` 增 1% |
| 三档锚点 | 无辅助、同性、`mpMax=MPREF` 时，Lv35 高武稳/催为 446/602H；Lv70 终局为 1,341/1,810H；真实 Lv70、低武显示 Lv44 为 566/764H |
| 关隘与总工量 | 单穴 `H=200+60t+25(j−1)`；180 穴合计 94,045H。第 k 转 `H=4,000+1,000k`，九转合计 81,000H；全系统合计 175,045H |
| 成本 | 每小时 `ceil(mpMax×(0.025+0.003t)×模式倍率×(1−减耗))` MP，稳/催倍率 1.00/1.50，减耗封顶 20%。Lv35、t4、`mpMax=4697` 为 174/261MP；减耗 15% 后为 148/222MP |
| 成功率 | 基值 6,500bp，叠加主运有效品阶、层数、意志、性质和辅助，再扣催冲/紊乱，最终钳在 3,500–9,800bp。示例 g9/7 重、t4、意志 65、3 本、同性为 8,425bp；催冲为 7,225bp |
| 失败 | 仅触及关隘时掷骰；失败进度回到 `floor(0.75H)`，按失败余量施加内伤 1–4 层及走火 0–3 级，接入 05 / 06 既有三级走火规则；已开穴、通脉、里程碑与已完成转不回退 |
| 九转 | 穴道原始奖励放大系数 `F(k)=1+0.05k`，第九转为 1.45；通脉、周天静态项与被动不再放大。九转天书门槛为 4/5/6/7/8/9/10/12/14，第九转还要求进入 `ch15_guimeng` |
| 满九转静态量 | `atkOut/atkIn +2.50%`、`hpMax +1.45%`、`mpMax +1.95%`、`defOut/defIn +1.45%`、`mpRegen +0.634pp`、`qinggong +3.82`、`combo +1.50pp`（20 脉各 +0.05pp，另含周流 +0.50pp）、`spd +1`、`effRes +3`、`resInjury +2.435pp`、`resSeal +2.58pp`、`apInner +1.555`，均低于本文的经脉来源内部上限 |
| TTK 敏感性 | 满九转单次命中一阶增量约 +3.4%～+4.0%；允许连击的单体招式计入 `combo` 后约 +4.2%～+4.8%。Lv35 / Lv70 / 低武 Lv44 普通与鹿鼎 Boss 的上界约 4.38 / 4.20 / 3.34 / 20.1，仍在 04 目标区间 |
| 持久化 | 同一周目书眠完整保留已开穴、当前 H、尝试序号和已完成转；压制只按显示等级与有效内功降低新修炼速率。轮回清空运行态，只把历史最高转数写入 `meridianMaxTurn`，不得据此恢复奖励 |
| 确定性 | 逐小时 session 原子提交；RNG 键为 `hash(runSeed,'meridian',targetId,attemptOrdinal)`，不消费战斗 RNG。奖励由事实状态重建，不把累计面板值作为真值保存 |
