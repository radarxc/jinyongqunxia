## 3. 关键结论与数值

1. 武学型 Boss 必须逐单位满足 `1` 主运 + `2` 玄 / 黄辅运、`3–5` 外功、至少一门外功 `>=G`；跨两类主要外功时至少两门 `>=G`。正式构建若见“地位下限兜底 / 缺专属主运”、缺可解析主运 `sk_*` 外键或静默回退 `1/1/harmony`，均以 `TS-CONTENT-BOSS-021` error 阻断；仅离线 `boss_pacing.py` 可读兜底行且必须输出 `estimateOnly=true`。纯环境机关才可豁免。
2. 多人 Boss / 多阶段战以整场共享总血量、全部阶段有效耐久或非击杀总进度计一次；超出 Boss `12–25` 轮或精英 `6–10` 轮时，先调耐久、阶段或目标，不压主运、里程碑或经脉七参。
3. `sonic && projection && projectionStep==0` 使用普通 Z5M、图鉴基础范围、外放额外耗内 `0`；从 1 档起才启用外放曲线、范围扩张和额外耗内。静态 `projected` 类别及护体内劲 40% 适用率不变；大手印跃击仅落点掌风伤害段算外放。
4. 人物下限固定为：射雕五绝 `10/9`；神雕金轮 `11/8 <` 五绝 `11/9 <` 杨过 `12/9`；陈家洛、胡斐、苗人凤 `9/9`；瓦耳拉齐、马家骏 `9/8`。其余 `design/21` §11.9.1 默认人物组也已完整登记在 `design/18`。
5. 普通天阶闭集为 `59=天上9+天中18+天下32`。完整原生池：天龙 17、射雕 16、神雕 18、倚天 13、笑傲 6；范围为高武 `6–18`、中武 `1–6`。
