# M2 报告 · 21 经脉运行、招式路线、绝招与擒拿点穴（作者需求 AR-14）

## 1. 摘要（3–6 行）

已完成 AR-14 的唯一归属设计：以穴位节点和经脉河道构成战斗内河流模型，并把路线收益接入既有 Z3。
“大招”正式采用“绝招”，继续复用 `MoveDef.ultimate`；擒拿与点穴分别形成外功 / 内功 1–9 级控制，调息合并 09 既有行动。
已完成每个独立行动单位一个 `MeridianFlowModule` 的标准库参考实现、固定种子黄金向量、敏感性与退化分析。
经脉模拟、旧伤害回归、严格 ID 检查和 lint 单测均通过；原著逐字考据、下游正式接线和手机性能仍明确留待后续。

## 3. 关键结论与数值

| 主题 | 定稿结论 / 核算 |
|---|---|
| 术语与归属 | 正式称“绝招”，复用 `ultimate:true`；15 拥有 20 脉 / 180 穴与战外成长，21 拥有战内动态投影 |
| 实例粒度 | 主角、每名同伴、普通敌人、精英、Boss，以及独立施展武学的召唤 / 环境行动者各一实例；只读基底可共享，动态节点与 RNG 子状态不得共享 |
| 路线上限 | `routeCapBp(n)=floor(1200n/(n+6))`；1/2/6/10/18 段为 171/300/600/750/900 bp，严格递增且始终 `<1200 bp` |
| 伤害与时间 | 实际质量按充盈率 × 有效流畅度计算，路线结果加入既有 Z3 `dmgUp`；每个实际尝试段累计 40–120 CT，不新增 Z11 |
| 卡住与胀损 | 卡住仅通过 40% 吞吐，剩余形成 backlog 并抬升迟滞；超过随迟滞下降的 120%～90% 容量阈值即胀损并封路 |
| 控制 | 擒拿 1 为酸软、7 锁兵器招、9 无法行动；点穴 1 流畅 −500 bp、8 封内功类行动、9 封路且禁自行调息 |
| 调息 | 合并 `{t:yunjin,mode:tiaoxi}`，1000 CT、本文不另收 MP；顶级调和档 `relief=2500 bp`、修复 617、默认触及 3 节点 |
| 招式样本 | 44 条金庸样本均引用现有 `sk_* / mv_*` 并保留（待考）；15 条现实武术样本由 8 个公开来源核名，路线 / 品阶均标原创设计 |
| TTK | 同一锚点接入前后：普通 `5→5`、精英 `9→8`、Boss `22→21`，分别保持 3–5、6–10、12–25 行动目标 |
| 敏感性 | 基准平均伤害 881、`TTK×100=451`、攻击频率 5450 bp、调息占比 1192 bp；单段 CT ±20% 对频率影响最大（5899 / 5063 bp） |
| Golden | 固定种子 `20260927`；SHA-256 `21a72a607a99848879e68324087f992d5dbb6505e9236bdb2e9296738a59600e`；输入显式记录单位序号、容量倍率与单位种子，并固定真实 `commit` 后 RNG 状态 |
