## 3. 关键结论与数值

| 主题 | 结论 / 数值 | 核算或约束 |
|---|---|---|
| 部署 | 当前只实施 Cloudflare Worker + D1 + R2；矩阵为 Cloudflare **92**、阿里 FC **75**、腾讯 SCF **75**、境外/香港轻量 **65**、内地轻量 **68** | 服从作者决定 P03；国内云和 Node 仅是退出路径，不建设镜像 |
| 同步 | 完整 TSAV 快照 + 服务端 `rev` CAS；创建用 `If-None-Match: *`，覆盖/删除/恢复用 `If-Match`；自动档按设备分区，具名槽冲突人工选择，落选版至少保留 30 天 | 避免 last-write-wins；同设备并发仍由 CAS 仲裁；写入 ID 保证重试幂等 |
| 离线与迁移 | IndexedDB/Dexie 应用层 outbox；不依赖 Background Sync 或 unload `keepalive`；Safari ↔ iOS 主屏用 6 位、10 分钟一次性迁移码 | Background Sync 非全浏览器可用，keepalive 请求体受 64 KiB 约束 |
| 认证 | MVP：128-bit 主配对密钥 + 8 位、5 分钟临时码；`ts_s` 为 HttpOnly/Secure/SameSite=Lax Cookie，30 天滚动；Phase 3：Passkey 主登录 + 8 位邮箱恢复码 | 不用魔法链接，避免 Safari 与 iOS 主屏容器隔离导致登录态落错容器 |
| TSAV 限额 | 对象 **8 MiB**；明文头 **64 KiB**；声明解压上限 **32 MiB**；Meta **512 KiB** | 上传先检查 8 MiB + 1 byte；服务端只解析外壳且不解压玩法状态 |
| D1 / R2 | DDL 共 **19 张表**；每账号存档上限 **5,000 对象 / 2 GiB**；R2 对象不可变，以 D1 指针发布当前版 | 存档 blob 不进入 D1，规避 D1 单行/单 BLOB 2 MB 上限 |
| 容量 | 常态存档约 **157.5 MiB**；乘 4 裕量约 **630 MiB** | `12×40×250 KiB + 40×250 KiB + 3×3×10×250 KiB + 35×250 KiB`，低于 2 GiB 配额 |
| 请求与写量 | 非 AI 约 **8,030 请求/月**；D1 约 **318 写/日** | 单作者个人负载，低于选定免费额度；正文保留分项估算与突发裕量 |
| AI NPC | 默认关闭；`claude-opus-5`、effort low、`max_tokens=600`、SSE、`fallbacks: default`；失败用预写文本 | 地区、隐私、预算、金标、回退五项闸门全过才逐 NPC 启用 |
| AI 预算 | 单请求预留 $0.15；日硬限 **$0.80**、月硬限 **$10**；离线内容生产总预算 **$150** | 高估 20 轮长谈约 `$0.0925 + 19×$0.0235 ≈ $0.54` |
| 遥测 | 默认关闭；**2 MiB/次、16 MiB 解压声明、1 GiB/账号、180 天**；摘要 100%、可重放日志 10% | 服务端只存；V8/JSC 离线复放及哈希归 `tech/05` 最终定义 |
| 运维 | D1 Time Travel + 每日加密逻辑导出 + R2 每周异地副本；季度从零恢复；完整导出由客户端流式组 ZIP | 平台恢复、逻辑备份、异地对象副本分别覆盖不同故障域 |

## 4. 开放问题（附默认值）

| 编号 | 问题 | 本文默认值 / 继续实施方式 |
|---|---|---|
| O-01 | D1 并发能否守住单槽唯一 current | 先用 D1 条件事务；若属性测试出现一次不变量失败，改每账号 Durable Object 串行写，REST/ETag 不变 |
| O-02 | 8 MiB 边界样本能否满足 Workers Free CPU | 正常档维持整包；极限档超限时先升 Paid 或采用分块候选 + manifest 原子发布，不抬 8 MiB 上限 |
| O-03 | Vitest workspace 隔离 | `services/api` 独立锁 Vitest 4；配置失败才退回 Wrangler `getPlatformProxy()` |
| O-04 | Safari、主屏 Web App、微信/QQ WebView 行为 | 容器一律视为独立设备；配对码常驻；Safari ↔ 主屏用 6 位迁移码；按 P01 真机矩阵验收 |
| O-05 | D1 与 AI placement 实际时延 | D1 先用 `apac` hint；AI 先用 `host: api.anthropic.com:443`，各 30 次首 token/总时延后再调整 |
| O-06 | Passkey、Ed25519 与 SimpleWebAuthn 兼容性 | 先 capability probe；Passkey 回退配对/邮箱码，Ed25519 回退带 RFC 向量的固定纯 JS verifier，绝不跳过验签 |
| O-07 | 真账号告警与费用能力 | 能配置则采用平台告警；否则由应用硬拒绝 + GitHub Actions/邮件通知，不能只依赖控制台软提示 |
| O-08 | 第二家备份存储 | 作者现有 NAS 或非 Cloudflare 的私有 S3 桶；`rclone copy`；90 天版本 + 12 个月快照，不作为公开镜像 |
| O-09 | 浏览器大 ZIP 流式导出 | 并发 3 下载；失败则每卷不超过 128 MiB 或逐文件下载，不在 Worker 压 ZIP |
| O-10 | AI 模型、fallback beta、价格、地区及保留政策变化 | AI 维持关闭；仅五项前置全过才按 Opus 5、low、600 tokens、server fallback 启用，任一不符即回退预写文本 |
| O-11 | 单人遥测的实际收益 | 默认关闭；启用时摘要 100%、重放 10%、云端 180 天/1 GiB，调数值一律人工审阅 |
| O-12 | 未选择轻量服务器的动态价格、带宽和备案资格 | P03 不变时不采购、不写死价格；只有作者重开 P03 或触发 Cloudflare 退出条件后，按当日官方信息重做 ADR |

O-01～O-10 集中了 preview、真机或真账号验证项；O-11 需一个内容迭代后复盘收益；O-12 是正文唯一仍保留的实质性“（待核实）”技术项。
