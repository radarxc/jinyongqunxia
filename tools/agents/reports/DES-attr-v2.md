# DES-attr-v2 报告 · 设计补充 · 属性与数值体系 v2（AR-27：八项先天属性含内息、沉睡六项配点、速度 / 攻击公式、门槛带与平衡）
## 1. 摘要（3–6 行）
已在五份归属文档落实 AR-26 / AR-27：新增 `bre` 内息，形成八项先天属性；新周目战斗底子改由长白山初眠及后续书眠分配。
攻击改为硬功与外放两支，防御按根骨硬防与内息内劲抵抗分支结算；速度只计算一次“身法 × 轻功基本系数 × 对应经脉增幅”。
武学增加 `trainingAttrs`，重建类别 × 品阶门槛带、迁移算法及 30 门代表样例；熟练度 / 真元与既有 `ap*` 并存。
本轮审核返修拆清战斗速度 / 探索轻功两条链，删除敌方中位数归一，并以逐书耐久、敌攻预算完成 protocol 4 十四书 42 格闭环。

悟性路线：初眠 `wis=80`，前三次投入 `4+5+5` 到 94，第四次获得 7 后投 6，于倚天入场前达 100；若延后，鹿鼎入场前累计已有 52 点。代价是其他五项初眠均值 44。

速度：战斗链直接读 S1 `agi`、轻功有效 `g/n` 与 21 的标准锚增幅，不读探索 `qinggong`：`qgBaseBp=clamp(7000+180g+120n,7000,10360)`；`spd=floor(agi×qgBaseBp×correspondingStrengthAmpBp/10000²)`。早 / 中 / 后例 `36/65/104`；21 不按敌人归一，09 不再二次乘算。探索 `qinggong/qgTier` 另供跳跃 / 门禁。

白马七项门禁复算：初得草上飞为 `5.25+0.30+22.04+3=30.59`（qg1）；书末为 `5.50+3+28.88+5.25+7.50=50.13`（qg2）。主线只需 qg1，qg2 放末段 / 支线，qg3 不作自身门禁。

攻击：`hard=floor(Aref×str×wOutBp/(50×10000))`；`outward=floor(Aref×bre×wInBp×operationBp/(50×10000²))`。protocol 4 强一档 10 段的普通 / 外放 `baseOperationBp=12053/13581`；完整周天乘 13500 后为 `16271/18334`，`c=9999` 则仍为 `12053/13581`。取 `Aref=1000,str=60,bre=55,wOut/wIn=4500/5500`，硬功 540；外放完整 / 9999 为 1109 / 821，总攻击 1649 / 1361，四例 Z5M 均为 10000。三组 Z2 结果：金钟罩高根骨 795、外放高手 5304、轻灵剑客 1190。

防御：硬防 / 内防基值分别为 `floor(Dref×con/50)` / `floor(Dref×bre/50)`，各自再走统一静态属性管线。内防例 `Dref=600,bre=75,flat=100,pct=10%` 得 `900→1100`；`meridianDefenseBp=8000` 不改面板，只令 Z4M 的 `D4=1000→800`，禁止在 Z2 / 面板预乘。

十四书节奏：代表招 `wOut/wIn=6500/3500`、`operationBp=13500`、`P/P_ref=15000 bp` 不变；逐书 / N-E-B 用 `durabilityBp=min(10000,floor(target×10000/R0))`，敌方用目标命中数 `10/9/8` 反算 `attackBudgetBp`。重校后普通 `3.47–4.75`、精英 `7.33–9.50`、Boss `15.31–24.00`，42 格全进 `3–5/6–10/12–25`；白马暂用旧 LOW 默认。

门槛主 / 次带：黄 `20/25/30`、`15/20/25`；玄 `30/35/40`、`25/30/35`；地 `45/50/55`、`35/40/45`；天 `60/65/70`、`45/50/55`。再按内功、拳掌、剑、刀、枪棍、奇门、暗器、轻功、横练选属性并作少林 / 逍遥 / 武当等 ±5 源流修正。

`trainingAttrs` 只在真实 3/6/9 重首次发放，每里程碑 1–4，单门 ≤12、角色总计 ≤48、单项累计 ≤24；轻功默认 `agi +1/+1/+1`，横练默认 `con +1/+2/+2`，内功吐纳默认 `bre +1/+2/+2`。

内息容量 / 回复：`breMpBp=clamp(10000+60×(bre−50),7000,14200)`；`mpMax` 在资源根值后乘该系数，`mpRegen` 基线为 `1+0.02×(bre−50)` pp。示例 `mpRoot=1222,bre=80`：`floor(1222×11800/10000)=1441`。

熟练度按 12 个外功 / 轻功类别计可消费武功经验；真元是内功经验。二者与 `ap*` 并存：`ap*` 继续表示学习效率 / 潜质，不转换；旧使用次数和真实层数只作一次迁移补偿。60% 遗忘 / 散功转化归 `design/13`。

名录不在本任务修改。按约 1,237 门、自动迁移 85% 估算，需手配 / 复核 `ceil(1237×0.15)=186` 门，重点是誓约、自损、逆练、横练链、三属性与非典型主属性名功。

## 4. 开放问题（附默认值）
1. `luk/cha` 是否永久排除沉睡配点：默认是，只由身份、奇遇、事件、装束改变。
2. 奇遇 / 事件常规永久属性总预算：默认全程 24；破 100 的稀有来源另最多 20。
3. 白马唐代化后的境界、武运、等级带：默认先保留旧 LOW 回归行并标非最终值，待 `DES-baima-tang` 后重跑。
4. `trainingAttrs` 达角色 48 上限后的奖励：默认等量转类别熟练度，内功转真元。
5. protocol 4 是否保留完整周天 `13500 bp`：默认保留，但只合入 `operationBp` 并由 Z1 外放支消费；Z5M 恒 10000。
