## 3. 关键结论与数值

| 主题 | 结论 / 核算 |
|---|---|
| 布局基准 | 安全区内 960×540（16:9）与 1260×540（21:9）【建议值】；12 列、8 间距、12 边距，960 宽列宽 `(960−24−88)/12=70.67` |
| 触控 | 触屏采用 60×60 CSS px【建议值】，由 `44 pt×96/72=58.67 px` 向上取整；纯精确指针 PC 可用 44×44 CSS px |
| 装配与携带 | 武学固定 13 栏、装备固定 8 栏；书眠高/中/低武容量分别 3/3/3、2/2/2、1/1/1，携带与本次藏史按实例去重后合计不超过 6 |
| 背包 | 初始 80，三次各扩 20，故上限 `80+3×20=140`；仓库 200，待拾物不超过 20 |
| 六角范围 | `ring(r=2)=6×2=12`；`disk(r=2)=1+3×2×3=19`；六向 60°/120°扇形为 4/8 格，十二向半向为 5/7 格 |
| 战斗时间轴 | 首轮只显示有效轻功排序；后续为 CT 0～1000，示例 `ct=700、ctGain=60` 得 `ceil((1000−700)/60)=5` 刻 |
| 地图 | W1 为 4096×3072、4:3、14 个时代组、约 1.02 MB / 10,468 个 SVG 元素；运行时不得整图内联 DOM，采用派生位图或受控渲染层 |
| DOM 与图片 | 常驻 HUD 计划 264 节点（距 300 上限余 36）；地图计划 583（距 800 目标余 217）；全局 >800 警告、>1,200 错误；合成层 ≤24、同屏位图图标 ≤60、大图同时解码 ≤3 |
| 存档与同步 | 手动 12、快速 1、自动 3、书眠前 14、苏醒 14、终局 7、通关每周目 1、一命 1；四种可见同步状态；冲突以 `rev` + CAS 处理并保留双份，落选版本至少保存 30 天 |
| Vue/core 边界 | UI 仅消费只读视图模型并发送语义命令；预览不消耗 RNG，提交由 core 重新校验；UI 不自行计算伤害、月钱、冲穴成功或地图可达性 |
