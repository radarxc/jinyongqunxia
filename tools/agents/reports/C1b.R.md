## 7. 审校结论

### 7.1 结论

**有条件通过。** 本文范围内的阻断问题已全部修正，规模、天阶白名单、字段、预算、Buff、装配证明、套装武学成员和格式均达到交付标准。通过条件是第 6 节所列下游归属文档继续完成投放、经脉、套装和候选清单同步；这些缺口不应在本图鉴越权定义。

### 7.2 按严重度列出的发现与处理

| 严重度 | 发现 | 处理 |
|---|---|---|
| 阻断 | 部分完整卡招式数不足 `design/05` §3.5，且有字段对象缺冒号、`sect` 条件形态错误 | 为侠客岛掌法、踏雪无痕、神行百变各补一式；统一 `sect {id:...,rank:...}` 与对象字段语法 |
| 阻断 | 8 处关键数值/公式不闭合或成本套用错误 | 按 §3.2 表逐项重算并改值；18 条抽查全部进入 ±0.05 |
| 阻断 | `bf_xianji` 被误用于回合中即时收益，语义与 06 目录不符 | 改用 `bf_piaohu`、`bf_jisu`、`bf_ruiyi`；保留唯一合法开战触发 |
| 重要 | 原稿未按已存在的 `design/17` 对齐组织边界与职级；金乌派被混入雪山职级 | 重写 §0.4；金乌刀法改为史小翠个人/`sect_jinwupai` 来源，不计雪山职级或独立配额 |
| 重要 | 本土“数量≥3”尚不能证明单周目、非互斥、前两幕可达 | 为两书界各补三条基础访学三联和 `reqsOverride` 契约，并登记 01/02 下游落地 |
| 重要 | 跨图鉴紫霞神功引用用了漂移 ID `sk_zixia` | 改为已定义的 `sk_zixiashengong` |
| 一般 | 若干未逐字核对的石室数量、雪山/金乌招名、劈卦刀与金蛇招名写得过实 | 增加 **（待考）** 或 **（原创扩展命名）**，集中登记 §19.4 考据清单 |
| 一般 | 局部特殊收益折价容易被误读成全局公式 | 全部改为条目级 **【建议值】**，并登记给 05 统一定价 |
