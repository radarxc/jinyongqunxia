## 3. 关键结论与数值

1. Canon v1.2 的正式主线格式是 `q_<NN>_main_<c|z|x>_<nn>`；无路线码流水号不再是生产主键。08–14 的 story / chapters 主线集合逐本完全一致：08 为 18 / 10（主线 / 选择），09 为 25 / 9，10 为 21 / 10，11 为 22 / 8，12 为 22 / 8，13 为 26 / 10，14 为 21 / 8。
2. 相邻书眠年数按 `design/02` 年表核算：07→08 `1669−1645=24`，08→09 `1705−1690=15`，09→10 `1725−1712=13`，10→11 `1740−1726=14`，11→12 `1753−1740=13`，12→13 `1766−1759=7`，13→14 `1780−1771=9`。
3. `design/20` 的投放式为主载体 `ceil(openRegions/2)`、后人 `ceil(carrier/2)`、新残本 `2×carrier`、新信物 `carrier`。故 08–14 依次为 `4/2/8/4`、`3/2/6/3`、`3/2/6/3`、`3/2/6/3`、`4/2/8/4`、`4/2/8/4`、`3/2/6/3`。
4. 洪安通速度统一为 `floor((72+0.30×72+0.10×50+0.14×59)×1.06)=113`；旧 103 / 123 均为失效快照。
5. 神龙岛削弱条件统一为 `{ quest: { id: q_08_faction_02/03, state: completed } }`；任务完成态不是 `q_*_done` 任务 ID。
6. 雪山取得第十四天书后进入余韵，再由 `FN_ENTER` 进入 `ch15_guimeng`；不存在普通第十五书界、`vid_sleep_14_15` 或第十五天书。
