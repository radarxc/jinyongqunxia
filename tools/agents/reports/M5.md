# M5 报告 · 外放武功的经脉范围与威力加持（AR-16）：21 新节、04、参考实现

## 1. 摘要（3–6 行）

已逐字登记 AR-16，并把外放收敛为 `MoveDef` 逐招事实：离体指力、掌力、剑气、刀罡可标，同门近身招不自动继承。
`design/21` v2.3 已定义经脉输入、0–2 档射程 / 范围扩张、额外耗内、路线端点、封路降档、敌我对称及三个作者示例。
威力不增设乘区，而是在 04 既有唯一 Z5M 内以外放曲线替代普通曲线；标准对标准仍为 ×1.0000，既有节奏零漂移。
新增标准库参考实现 `projection_sim.py`，并在 `damage_sim.py` 接入显式逐招标记及兼容回归。
四项指定校验、Python 编译、ID 严格检查和 `git diff --check` 均通过；硬值与曲线仍按默认值待作者确认。
