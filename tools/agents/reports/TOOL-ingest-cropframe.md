# TOOL-ingest-cropframe 报告 · 工具 · 物品图入库裁框：crop_frame() 遇左右白框会切掉主体（扫描线只取另一轴框以内的像素），补合成图回归测试

## 1. 摘要（3–6 行）
- `crop_frame()` 改为先在必定越过外框的中央区判定左右框，再让上下扫描线只统计左右内框内像素，并迭代复核一轮。
- 阈值 `7 / 14`、扫描上限 `lim = 15%`、背景色补正方形及无框图返回约定均未改变。
- 新增 6 条纯 PIL / numpy 合成图回归，覆盖四边、单轴、无框、深色框及贴近内沿主体。
- 三张只读原件均完成像素量测与人工查看，主体完整且四边不贴边；未复制或重新入库图片。

## 2. 产出（文件、行数、主要章节）

## 3. 关键结论与数值
- 算法保持 `bg` 环带、差异阈值 `7 / 14` 与 `lim = int(min(h, w) × 0.15)` 不变；首轮左右扫描取纵向 `16%–84%` 中央区，随后上下 / 左右交替使用另一轴已判定内框，最终再复核上下。
- 主体边距口径：在裁后方图四周各取边长的 `8 / 512 = 1.5625%` 像素求 RGB 中位数；任一通道差 `> 28` 记前景，某行 / 列前景占比 `> 1%` 计入主体包围盒。下表边距顺序均为左 / 上 / 右 / 下，单位 px。
