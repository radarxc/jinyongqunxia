# NB2 报告 · 首领 / Boss 武学配装补全与节奏复核（书界 08–14）

## 1. 摘要（3–6 行）

已完成书界 08–14 的 Boss、头目与武学型精英配装补全，共覆盖 86 个武学配置行：58 个 Boss / 头目行动者行、28 个精英行动者 / 模板行；另保留 1 个纯机关豁免行。
全部武学行动者均固定为主运 1 门、辅运 2 门，外功为 3–5 门；所有引用均复用图鉴既有 `sk_*`，未新建武学 ID。
原先明确或条件性回退 `1/1/harmony` 的角色、遭遇和精英模板均已改为按门派 / 来源解析的主运，并据此重算七项参数。
标准对标准节奏仍为普通 `3.4–4.1`、精英 `7.1–9.3`、Boss `14.3–24.5` 轮；鹿鼎与雪山的弱一档越界分别以既有短路线 / 破绽机制拉回 ≤25。
两套平衡脚本最终门禁通过；多首领共享耐久、非致死阈值及具名行动表仍需生产配置完成后做固定 RNG 回放。

## 3. 关键结论与数值

- 配装总量：86 个武学行动者配置行全部为 3 门内功；外功分布为 28 行×3 门、56 行×4 门、2 行×5 门。白马另有 1 个假鬼机关阵豁免行：`sk_gaochangjiguan` 只标识机关行为，不创建经脉实例，也不虚构内外功。
- 七项参数统一为 `effGrade/effLayer；mpRatioBp/practiceBp/capacityScaleBp；innerNature；openPolicy`。Boss / 头目使用 `13000/9000/13000；fullTemplate`，精英使用 `10500/7500/10500；schoolCore`。
- 层数边界：低武 08–11 均 `effLayer≤8`；中武 12–14 均 `effLayer≤9`；雪山战内 `turns≤8`。
- 经脉敏感性：弱一档攻击 `9157 bp`，强一档 `12053 bp`，强两档 `14456 bp`；强速度 `12239 bp`，封路速度 `6500 bp`；强守输入 1000 结算为 861。
- `damage_sim.py --report` 的七章普通 / 精英 / Boss 标准轮数依次为：鹿鼎 `3.9/8.0/23.4`、连城 `3.6/7.7/18.2`、白马 `3.4/7.3/14.9`、鸳鸯 `3.5/7.1/14.3`、书剑 `4.0/8.2/15.4`、飞狐 `4.0/8.1/15.2`、雪山 `4.1/9.3/24.5`。
- 标准对标准时 Z4M / Z5M 均为 10000 bp，因此补全前后的章节模板轮数不漂移；补全改变的是单位合法配装、经脉性质与路线初始化，不能把模板轮数冒充具名固定 RNG 回放。
- 鹿鼎弱一档为 `ceil(23.4×10000/9157)=26`，必须由宝训 / 内乱、救援、撤离、谈判或目标式收束拉回 ≤25；雪山弱一档为 `ceil(24.5×10000/9157)=27`，必须由停手 / 救人 / 封箱、削护、夺令 / 拆网、双破绽 / 弃地利拉回 ≤25。
- 最终门禁：`damage_sim.py --check` 46/46 通过、known deviations 0；`meridian_flow_sim.py --check` 通过，黄金向量哈希为 `af33dcd10dc196e18811fe485870666ab139c03a17342fa47113ecc19552cd76`。
