## 3. 关键结论与数值

| 项目 | 定稿 / 当前值 | 核算或依据 |
|---|---|---|
| 整数化 | `BP=10000`；Z1–Z10 每区结束向下取整；资源成本四舍五入、最低 1 | 回应 `tech/01` D4/P2，保证跨平台重放 |
| Z1 | `floor(ATK_mix × 1.24 × P_actual / P_ref)` | C01；`P_actual=G×L(n)×power×Mod_armed×Mod_special`，只除一次攻方 `P_ref` |
| 耗内 | `MPREF(L)=STD(L).mpMax`；普通招高武 8%、中/低武 7% | C02；Lv35=4697、Lv70=28887；模拟范围 7.00%–8.01% |
| 回内 | `mpRegen≤6%` | C03，与 05 内功预算同口径 |

| Z3 / Z4 | 各区先加法合并；Z3 系数 0.50–2.00；Z4 减伤池 −50%–+75% | 基准 §9；Z4 75% 后至少保留 25% |
| Z5 | `A_ap` 独立乘；相性、破 X、同源等加算合计 −30%–+50% | AR-02；阴阳相性 ±12%，调和规则沿用 05 |
| Z6–Z10 | 暴击倍率；六向方位/高差/地形；等级差每级 ±1.5% 封顶 ±15%；普通招架保留 50%、绝招保留 75%；浮动 0.95–1.05 | 六角格正后 1 向为背击、侧后 2 向为侧击；Z7 合成后只取整一次 |

| 撞击 | 撞墙=`floor(D_hit×20%)`，被撞单位=`floor(D_hit×10%)`；不重跑 Z0–Z10、不附赠眩晕、每次位移至多一次 | C11 |
| 比例型伤害 | 普通/精英/Boss/守卷人系数 1.00/0.50/0.25/0.15 | 06 的比例伤害口径；DOT 的 `bypassShield` 原样执行 |
| 模拟节奏 | 普通主→敌 3.00–4.59 命中；敌→主 9.04–11.89 命中；普通 3.03–4.64、精英 6.13–10.00、Boss 12.35–24.74 主角行动轮 | 全部落入基准 §5 的 3–5、8–12、3–5、6–10、12–25 区间 |

模拟采用解析期望，不消耗 RNG。Boss 轮数按四人队每主角行动 `3.1` 次标准命中等价折算；高/中/低武的遭遇耐久与模板普攻预算是为了让 03 裸模板覆盖十四书界的遭遇层【建议值】，不会改写角色面板。洪安通采用上游已定的 Lv50、局部难度 8 和同级模板 Boss `hpMax×0.75` 覆盖。
