## 3. 关键结论与数值

1. **唯一作者源与兼容迁移**：正式内容以 `content/common/`、`content/world/`、`content/chapters/chNN_*/` 为主；旧 `content/chNN_*/` 不保留第二棵可编辑树，通过 `content/migrations/path-remaps.yaml` 迁移。既有 `content/common/items/divine.yaml`、`content/world/tiers.yaml`、`content/assets/registry/ch01/portrait.yaml` 等引用均有兼容落点。
2. **schema 权威链**：Zod 源码唯一位置为 `packages/data/src/schemas/**`；跨语言静态快照为 `packages/spec/content/**`；编辑器镜像为 `content/.schema/**`。`packages/data/spec/` 不再作为契约根。schema 使用 strict object、可判别联合、ID 前缀与字段分类，并为 AR-03–AR-07、AR-09 所需类型提供【建议值】接口。
3. **ID 与 remap**：发布 ID 不因文件移动而变化；旧 `bs_*` Boss ID 迁往裁定后的 `bsc_*`，`bs_*` 只留给书眠 Ink 节点。`idRemaps.since` 表示最后可读的前任 `contentHash`，remap 必须无环、目标存在、不可多义。
4. **校验分层**：`pnpm content:validate` 依次执行解析、schema、ID/引用、业务规则、预算、图可达性、包体与兼容检查；CI 另做 schema drift 和双构建逐字节一致性。验证通过不代表原著事实已经人工审核。
5. **招式预算**：`power = AF(tpl) × (1 + Σadj) × K_delivery × K_parry − Σcost_buff − Σcost_disp`，录入值与计算值允许差 `≤0.05`。金样例“震惊百里”为 `0.65 × (1 + 0.36 + 0.10) − 0.25 × 0.30 = 0.874`，录入 `0.85`，差 `0.024`，通过。
6. **内功预算**：`IP = mpMaxPct + hpMaxPct + 2 × Σattrs + 5 × mpRegen`；总量偏差允许 `±5%`，单项默认允许 `±30%`。无豁免且偏差 `>10%` 时提升为 error 是【建议值】。
7. **地图契约**：采用已联网核实的 Tiled 1.12.2；作者坐标 `x → q`、`y → r`，输出 pointy-top 六角轴坐标。每区块 `32×32 = 1,024` 个槽位；对象类覆盖出生点、NPC、遭遇区、轻功门禁、建筑、灯光与镜头提示。共享底图/时代层按 AR-04 预留到 `content/world/regions/`。
8. **Ink 双产物**：各 locale 的可执行 Story JSON 属于文本叶片；分支拓扑、变量、标签和引用归 `DialogueStructureDef` 规则叶片。纯文字修改只改变 `textHash`，结构变化必须改变 `contentHash`；Ink 只能提交意图，由 core 校验并落状态。
9. **移动端解析边界**：Worker 只解压、验 hash 并传递 `ArrayBuffer`；主线程在加载遮罩或 idle 时按叶片解析。游戏中单个未压缩 JSON 叶片必须 `≤256 KiB`，超过即继续拆成 `pNNN`。
10. **书界包与体积**：输出 `chNN.rules.base.json` / `chNN.rules.rg_<id>.json` 与 `chNN.text.<locale>.base.json` / 区域文本叶片；分别计算 `contentHash`、`textHash`、`releaseHash`。P4 规划模型为原始 `3,988 KiB`、gzip 约 `1,039 KiB`，加 25% 余量为 `1,299 KiB ≈ 1.27 MiB`；`≥1.25 MiB` warning，`>1.5 MiB` error，模型仍待实测。
11. **AI 入库闭环**：结构化草稿先进入 `content/_drafts/`，经过 draft validate、人工事实/玩法审核、promote dry-run 和全量构建后才能入正式目录；`content:promote` 不允许覆盖既有正式文件。
