## 3. 关键结论与数值

1. **招募分级**：D1 为好感 20 或 3–30 日短约；D2 为好感 30 + 职业小任务，或付定金雇佣并先安排替班；D3 至少满足职级、掌门许可或门派任务之一；D4 必须有唯一专属任务链、价值观门槛和时机窗口；D5 再叠主线锚点、原著 / 改命分支、锁定预警与命运后果。数值均以 **【建议值】** 登记，等待 12 / 16 定稿。
2. **队伍与关系**：活动战斗编组固定为 `主角 1 + 同伴最多 5 = 总数 ≤6`；满员仍可招募到据点 / 客栈。`affinity`、`bond`、`resentment` 与不可数值替代的 `trustFlags` 分离；羁绊 40 / 60 / 90 分别提供合击候选、稳定资格和终局候选接口，倍率仍归 09。
3. **生卒判定**：`died > wakeYear` 判健在，`died < wakeYear` 判已故，`died == wakeYear` 因年度精度不足返回 `life_unknown`；原著明确在后作出场可由 `explicitAliveAt` 提供正证据。史实、文本、推算、待考和年龄段均有独立字段语义。
4. **年龄能力段**：年龄只修正 `design/03` 的 `full` / `template` 输入，不另造战斗公式。修正覆盖幼年到耄耋七段；保存的武学层数不会因年龄下降，宗师、伤病和残疾通过人物画像覆写或状态表达。
5. **书眠与重逢**：14 段沉睡为 `[1575,123,10,77,160,57,47,24,15,13,14,13,7,9]`。书眠清空活动编组，但保留招募史、关系、生命事实和离队快照；健在故人完成 U0–U5 重逢链后重新加入。
6. **能力合并**：旧快照的先天、真实等级、武学真实层数和永久修正逐项作下限，新书画像取并集 / 最大值，只增不减，再应用目标书界天道压制。正文给出郭靖、黄蓉、周伯通 / 黄药师、张君宝→张三丰、阿九→九难、赵半山六组跨书算例，另有少年杨过的同书成长算例。
7. **命定死亡**：AR-09c 已确定允许改命救回；每书界第一次成功消耗 2 点余韵，同一事件救多人只收费一次，不足写 `fateDebt`。死亡不是普通倒地，未救回者只能留下传承、遗物或后人回响。
8. **名录覆盖**：14 部计数为 `30+30+30+28+25+26+26+30+24+20+20+28+26+25=368`；其中 357 条人物行、11 个无名职能槽。357 行归并跨书复用后为 334 个唯一 ID，故合法额外 appearance 行为 `357−334=23`。
9. **设施与路人**：设施范例为 `8 城×3 场所×4 槽=96`；D1 / D2 日佣分别是 `I_hour×0.25×skillMul` 与 `I_hour×0.50×skillMul`，D2 定金为 3 日。路人年龄权重 `5+12+24+34+16+7+2=100%`；未持久实例可回收，已招募 / 有关系 / 有任务者固化为稳定 UUID。
10. **数据契约**：NPC 记录含身份、生卒、appearance、门派 / 职级、地点、D 级与任务引用、完整 / 模板数值管线、AI、羁绊、跨书和来源。`skills` 只存 `skillId + trueLayer`，武学品阶由 `skillId → SkillDef.grade` 从 `design/05` / 图鉴解析，避免重复定义。

## 4. 开放问题（附默认值）

| 编号 | 开放问题 | 本版默认值 / 当前处理 |

| N18-O01 | “永不可招募但可结盟”是否包含君主、统帅或掌门 | 不包含；所有书内人物至少提供一个短时可控同行窗口。只建议书灵、守卷人两个元叙事角色使用 `allianceOnly=true` |
