## 3. 关键结论与数值

- 普通武学当前为 `51/169/368/332=920`；按约 `1:3:9:9` 的目标为 `51/169/459/459=1,138`，因此只补玄阶 91、黄阶 127，不删除既有地阶。
- 合法普通装备输入下，STD 为 Lv35 `HP/MP=7,176/4,697`、Lv70 `40,409/28,887`，并有 `MPREF(35)=4,697`；速度基准为 `91/106/126`。
- 战斗采用 pointy-top 六角轴坐标；规则六向，十二向只作瞄准细分；战场满足 `tileCount≤400`、`qSpan≤20`、`rSpan≤20`。
- 移动力为 `baseMove=3+tier+withinTier`，最终钳制到 `[1,10]`；比例统一 10,000 bp，Z1–Z10 区末向下取整，资源成本 half-up。
- 内力固定阳 / 阴 / 调和三性；调和主运对阳 / 阴 / 调和 / 中性招式的 Z5 相性依次为 `+6%/+6%/+12%/+2%`。
- 书眠保留经脉同周目运行态、同伴履历及永久事实，清经营运行态、活动编组和门派公账；轮回仅保留经脉历史最高转数。
- 全量处置共 CP-00～CP-48：35 个采纳 / 沿用、2 个待确认、12 个不采纳或不升格；Canon 用 V12-01～V12-15 承载生效硬规则。
