# P11 报告 · 剧情 · 11 鸳鸯刀（正邪两条主线与选择节点，AR-10）

## 1. 摘要（3–6 行）

完成《鸳鸯刀》书界主线唯一归属文档：以 2 个共有幕衔接正、邪各 10 幕，并设置 8 个四选项节点，其中 4 个可跨线、末节点独立决定最终立场。
原著 50 项关键事件全部有明确去向；四个锚点逐项对齐 `design/01` §7.12，正邪两线均能独立经过锚点并进入原著 / 改命结局。
“仁者无敌”采用圆满型改命：14 名关键人物存活、全程零击杀、4 场登记冲突中至少 3 场非致命收束、最终不独占双刀，四项取严格交集。
完成 NPC / 门派 / 招募窗口、已有武学引用、任务 YAML 候选、26 条测试和下游接口；正文定稿为 v1.0。
联网资料只能校对通行文本事件顺序和史实原型，不能替代三联 / 广州修订版纸本，故正式回目与细节仍如实标 **（待考）**。

## 3. 关键结论与数值

### 3.1 书界、路线与锚点

| 项 | 定稿 | 依据 / 核算 |
|---|---|---|
| 书界参数 | `ch11_yuanyang`；约 1740；低武；武运 40；难度 3；等级上限 48；携带 1/1/1；外来压制 −4；关键词“仁者无敌” | 直接引用基准 §2，不在剧情文档重定义 |
| 相邻书界 | `ch10_baima` → 书眠约 14 年 → `ch11_yuanyang` → 书眠约 13 年 → `ch12_shujian` | 引用 `design/02` |
| 路线规模 | 共有 2 幕、正线 10 幕、邪线 10 幕 | `2 + 10 + 10 = 22`，正邪均在 8–14 幕范围内 |
| 选择节点 | 8 个，每个 4 选项 | `dc_11_03/04/05/07` 可幕级换线；`dc_11_08` 只重定向最终立场，不开启新幕 |
| 锚点 | 4 个 | `anc_11_01` 押刀、`02` 多方夺刀、`03` 袁萧结伴与夫妻刀法、`04` 寿宴—身世—刀铭，逐项对应 `design/01` §7.12 |
| 原著覆盖 | 50 / 50 = 100% | 事件编号 01–50 连续；每项标正线 / 邪线 / 共有 / 节点 / 锚点 / 支线去向；不采用 0 项 |
| 结局 | 4 个 | `finalStance ∈ {z,x}` × `fateQualified ∈ {false,true}` |

正邪不是开局阵营，而是章节立场。`stance_11` 仅辅助前期分线；换线保留品德、伤亡、芥蒂、旗标和已关闭奖励。邪线有官府路引、调查、收网与交割收益，可完整通关并取得 `end_11_x_fate`，不是惩罚性坏结局。

### 3.2 改命、非致命与双刀归属

圆满型改命采用以下严格交集：

```text
fateQualified = every(keyNpcIds, lifeState == alive)
             && chapterKillCount == 0
             && distinct(nonLethalEncounterIds).length >= 3
             && finalBladeCustody != protagonistExclusive
```

- `keyNpcIds` 为 14 名原著 / 史实具名人物；刘於义不在前线，默认保持存活，避免未加载场景产生隐藏失败。
- 四个可计数遭遇为松林劫镖、毒墨制卓、紫竹庵退卓、萧府围战；任取 3 场，按 `enc_*` 去重，同场重试不刷数。围府是最后机会，中条山不补刷。
- `dc_11_08.A` 固定最终正立场，B 固定最终邪立场，C / D 保留进入末幕时的路线；C 独占双刀必为 `canon`。
- A 后人共管、B 官府封存换安全、D 镖局见证托管均属于“不独占”；只有 C 把唯一成对装备实例 `eq_yuanyangdao` 转为玩家永久所有。
- 所有结局都完成四锚点并获得一次 `it_tianshu_11`；按结果二选一获得 `tsp_11_canon` 或 `tsp_11_fate`。

### 3.3 NPC、门派与数据接口

- 主剧情实际使用 18 名静态 NPC：14 名原著 / 史实具名人物与 4 名上游原创补员；另有 2 名名录人物保留给 DLC 支线。每个核心 NPC 均引用 `design/18` 的 D 级，并给出 R 阶段、同行窗口和离开条件。
- 组织仅引用 `sect_weixinbiaoju`、`sect_qinggong`；太岳四侠与两家传承不伪建门派。
- 授艺 / 观摩只引用已有 11 个 `sk_*` 和 `cmb_fuqidao`；双刀分持仍只对应一个 `eq_yuanyangdao` 实例。
- `design/12` 尚未落稿，3 段 YAML 明确标为兼容候选**【建议值】**；剧情 ID、路线边、条件语义、失败保底和结果不可在迁移时静默丢失。
