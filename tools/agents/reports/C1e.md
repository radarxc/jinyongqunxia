## 3. 关键结论与数值

1. **品阶配额**：3 天、9 地、30 玄、30 黄，共 72 门。以 3 门天级为基数，理论值为 `3:9:27:27`；玄、黄各取 30，相对 27 高 `3÷27=11.1%`，处于 AR-01 的 ±15% 容差。绝对品级为：2×11、3×19、4×9、5×11、6×10、7×5、8×3、9×1、10×3。
2. **天级闭集**：仅 `sk_baihuacuo`、`sk_paoding`、`sk_hujiadao` 三门，ID、10 品、类别和原生书界均与基准 §13 一致。百花 / 庖丁在飞狐只记录 `lineageGrade:9, partial:true`，不重复定义或计数。
3. **地阶结构**：九门为苗家剑法、药王毒经、七心海棠法、天山鹰扬功、红花会合击、胡家拳、八卦刀、回部奇剑、掌门博艺。代价型 `0/9=0%`、誓约型 `0/9=0%`、强制多人合击 `0/9=0%`，均低于 5% / 5% / 3% 上限。
4. **类别分布**：内功 11、拳脚 25、兵器 23、轻功 7、暗器 3、杂学 3，共 72。11 门内功均有 `nature`：阳 4、阴 3、调和 4；玄中 / 玄下 / 黄上 IP 分别按 `48.5 / 41.5 / 30` 核算。
5. **招式与数据接口**：登记 183 个 `mv_*`、139 个 `ps_*`、17 个 `set_*`、6 个预留 `mer_*`；玄阶预算样本 `13÷30=43.3%`，超过 30% 要求。30 个唯一 Buff 引用与 `design/06` 差集为空。
6. **门派与套装**：13 个正式门派均具备黄阶入门拳或剑、黄→玄→地落点和套装；另为天池 / 关东散承补链。17 组候选套装的本文武学成员均完成双向登记，唯一跨文件成员是 `eq_lengyuedao`。
7. **装配证明**：书剑本土内 / 拳 / 兵为 `3/11/11`；飞狐为 `8/9+/9+`；雪山为 `4/5/9`，均不少于 3。三书最高本土轻功取天山鹰扬功 8 地中，`QS(8)=104`。
8. **敌人专用**：0 门。关东六魔的黄 / 玄阶套路按可缴获残谱处理，计入正常可学池，不使用 `enemyOnly:true` 规避数量。
