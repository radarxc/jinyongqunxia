## 3. 关键结论与数值

**新主线一览**
1. 现代人翻开残卷穿越至春秋末越国，在越女序章临时体验顶级剑法与九层功法。
2. 阿青传授《长生诀》第一层；书灵只引导、旁白、记录与见证。
3. 主角在长白山遭雪崩，洞中被动初眠并分配六项属性。
4. 于唐初白马最前期苏醒；第九层前，每本天书后由休眠事件入眠并作 3+3 取舍。
5. 白马至侠客七条复杂支线依次取得第二至八层；鹿鼎满足条件领悟第九层。
6. 第九层后不老不眠，跨书改为周游世界。

**苏醒取舍算式与核算例**
`eligible=max(0,cumulativeSxp-convertedSxp)`；`rateBp=min(7200,6000+200×(n−1))`；`gain=floor(eligible×rateBp/10000)`。
武功产顿悟、内功产真元；按技能 ID 保存 `convertedSxp` 高水位，忆起后只折新增经验。
例 A：一层剑法 10,000 → `floor(10000×0.60)=6,000` 顿悟。
例 B：五层内功 26,220 → `floor(26220×0.68)=17,829` 真元。
例 C：八层已结算 8,000、现累计 11,000 → `floor(3000×0.72)=2,160` 顿悟。
成长复算：`cum(20)=17,230`；天龙需求 `cum(35)−cum(20)=96,040−17,230=78,810`；A=8 幕保底为白马 `3/5/7/10/12/14/16/18`、天龙 `22/23/25/27/28/30/31/33`。
余韵累计按新序为 `0/0/0/0/0/8/15/23/35/45/51/60/68/73`；经脉阶段终值 `175,045H`。

**周游世界规则**
保留全部武功 / 内功、属性、等级、经脉、顿悟、真元、银两、普通背包与装备；外来压制照旧。
仍清门派身份 / 公账、营生、资源点、家丁合同、家业、当代任务与活动队伍；每段建议 20–40 分钟，不改变下一书起点。
周游是同周目跨书阶段，不是结局后自由世界；雪山后仍进终局，轮回仍按原规则重置。
