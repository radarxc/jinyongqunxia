# DES-destiny-ch11 报告 · 设计补充 · 11《鸳鸯刀》主要悲剧线的逆天改命机会（AR-20）

## 1. 摘要（3–6 行）

- 已为《鸳鸯刀》补齐 4 条主要悲剧线的局部改命：袁杨旧案、萧义残生、袁冠南母子、周家扣质。
- 本书正篇无可信的终幕命定死亡，故不硬造复活线；四案改“旧伤继续伤人”，并保留父辈已亡、净身、早年离散等不可逆事实。
- 四条线复用既有剧情 DAG、任务与人物 ID，具备前中期埋线、三层提示、五维条件、行动、四类代价、成功 / 失败与史自愈边界。
- 局部轴不直接决定 `tsp_11_fate`：圆满主改命仍只读 14 人有效存活、0 击杀、四证明取三、不独占双刀。

## 3. 关键结论与数值

| 悲剧线 | 改命机会 | 主要代价 / 结果 |
|---|---|---|
| F1 袁杨旧案 | 三源护证、遗属确认、密封活人名册 | 父辈不复生；放弃悬赏与证词所有权，清宫关系降档，条件触发时 `fame−300` |
| F2 萧义残生 | 三队撤离、轮换断后、萧义本人选余生 | 净身不逆转；萧义离队，放弃密库 / 寿宴战利品，清宫关系降档 |
| F3 袁冠南母子 | 自愿认亲后共同撤离，私信与信物归还 | 失去年月不返还；放弃证物带来的官府功劳、通行与收藏收益 |
| F4 周家扣质 | 两时辰截报并实际放人，周自由作证 / 履约 / 辞任 | 不洗既往责任；周先离队照料家眷，烧控制名册并放弃官府功劳 |

- 门槛默认：`bond>=60`；8 品技艺 `T(8)=8×8−4=60`，故 `speech/lore/med>=60`。
- 关闭点：F1 `dc_11_08`；F2 / F4 围府第三波；F3 `dc_11_07`。每线保存“未关闭 / 成功 / 原著或补救后果”单调三态。
- 对应 `design/13` 代价表：天书之力不由局部线改写；人物可离队；声望 / 关系 / 证物 / 资源具体支付；后世只写文本。四线不发布 `companionFateRescued`，不收 2 点余韵。
- 书契只由主结果决定：canon T=30，fate T=50，差值 `50−30=20`；F1–F4 不另加固定分。
- 新增【建议 ID】：无；未新造 `q_*` / `npc_*`，局部三态作为既有任务实现状态处理。
