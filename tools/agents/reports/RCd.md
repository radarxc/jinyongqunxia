## 3. 关键结论与数值

- 唯一武学 66 门：本文新定义 65 门，另含 05 唯一定义的 `sk_quanzhenjian`；`sk_wudangjiuyang` 只引用、不计数。门派 / 组分布为全真 15、古墓 16、杨过 / 剑冢 7、武当 20、绝情谷 8。

- C22 套装品阶样例已复核：`[5,8,11] → floor(8)=8`；`[5,7,8,11] → floor(7.5)=7`。
