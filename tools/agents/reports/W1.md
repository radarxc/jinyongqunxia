# W1 报告 · 19 江湖大地图：城市 / 门派坐标数据、投影、水墨 SVG 渲染（AR-11）

## 1. 摘要（3–6 行）

- 已建立统一 WGS84 江湖地图数据：189 个城市/历史治所/小说锚点、99 个门派、19 个区域草案、24 座驿站、28 个码头、48 条常规路线与 3 条图外专线。
- 已实现 Python 3.9+ 标准库可运行的球面 Albers 投影、数据校验和确定性水墨 SVG 渲染器，并生成 1 张全时代底图及 14 张单时代图。
- 波斯明教总教、罗刹国、撒麻尔罕均作为图外题签；每个节点只接一条驿站/货船专线，专线无中继且途中不可停靠。
- 说明文档已给出投影公式、历史地名摘要、门派落点、风格、接口、再生成方法与测试，当前为 998 行。
- 自动校验、XML 解析、2 MiB 上限和双次渲染 SHA-256 确定性均通过；受本机沙箱限制，最终浏览器像素审图仍待实测。

## 3. 关键结论与数值

1. 地理范围固定为 73–135°E、18–54°N；画布默认 4096×3072，边距 150 px。
2. 球面 Albers 参数为 `φ1=25°`、`φ2=47°`、`λ0=105°`、`φ0=35°`；`n=0.576985981679935`、`C=1.309083430095920`、`ρ0/R=1.394284534840312`。
3. 默认缩放 `3653.6497951142555 px/R`；取 `R=6371.0088 km` 时，标准纬线附近 `3653.6498÷6371.0088≈0.5735 px/km`，100 km 约 57 px。
4. 城市坐标保留 0.01°；约等于南北 1.11 km、35°N 东西 0.91 km。小说点同样保留两位仅为格式一致，不代表确址。
5. 城市含 9 个 `importance=site` 小说/山口锚点；补齐灵蛇岛、冰火岛与王盘山岛后，倚天主要图内海岛也有专船线路。
6. `sects.yaml` 与 `design/17` 的 99×14 矩阵逐 ID、逐状态比较无差异；未复活裁定废弃门派 ID。
7. 图外节点为 `offmap_mingjiao_persia`、`offmap_luochaguo`、`offmap_samarkand`；三条 `offmap_special` 都满足恰一图外端、陆上端为 `post_*` / `port_*`、`via=[]`、`no_intermediate_stops=true`。
8. Natural Earth 1:50m 海岸/河流经 Douglas–Peucker 简化（陆地 0.045°、河流 0.06°）；全部城市通过点在多边形或显式掩膜校验。
9. SVG 使用深/中/淡三级墨色、朱砂强调、`feTurbulence`、`feDisplacementMap`、`feGaussianBlur`、山脉短笔触、河流飞白、竖排题签与印章图例。
10. 已运行 `py_compile`、`--check`、全量 `--render`、15 文件 XML 解析、大小检查及两轮 SHA-256 比对；确定性成立。
