# 本任务：外放武功的经脉范围与威力加持（作者需求 AR-16）

作者新设定（原文照录，不要改写）：

> 再补一个设定，经脉修为上升后，对外放的武功会有范围加持（比如弹指神通，独孤九剑，降龙十八掌），原理是气是武功外放的能力，经脉运转快真气多，自然外放范围和威力就会剧增

- **经脉影响速度**：21 已定义经脉速度 6500–13500 bp（轻功按经脉运行）。
- **现有节奏**：Boss 节奏按 21 §11.9 与 `tools/balance/boss_pacing.py` 逐单位复核。
