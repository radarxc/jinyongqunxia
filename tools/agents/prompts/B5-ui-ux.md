# 本任务：撰写 `docs/design/14-ui-ux-mobile.md`（手机端 UI/UX）

归属（基准 §18）：手机端 UI/UX。平台为手机浏览器（横屏优先）+ PC 浏览器（基准 §0）；UI 用 Vue 3 DOM 覆盖层（基准 §19）。

## 必读

基准 §0、§4（品阶 UI 主色）、§8、§20；`design/01`；`design/05`（§6 装配规则、§11 武学图鉴、§4 的 28 种范围模板）；`design/09` §10（手机体验）；`design/10`（装备栏）；`design/02` §4（书眠流程）；`design/13`（成就与存档）；`tech/02`（C20 裁定后的品阶边框色值与精灵朝向）；`tech/03`（§2.6 DOM 预算、§6.5 DOM UI 性能契约、§5.5 字体方案、§3 iOS 专项）；`tech/08`（同步状态、冲突、登录）。

## 至少包含

1. **设计原则与布局**：横屏 16:9 至 21:9 的布局网格；安全区（刘海、手势条）；触控目标 ≥ 44 pt；单手 / 双手操作区；PC 键鼠映射。
2. **视觉规范**：配色（品阶色、正邪色、状态色）；字体层级（与 tech/03 §5.5 的字体方案一致）；图标；动效预算（只动画 `transform` / `opacity`）。
3. **信息架构**：全部界面清单与导航图（Mermaid）。
4. **线框图 ≥ 8 张**：用等宽字符画在代码块里，标注尺寸与交互。至少包括：
   - 探索 HUD；
   - 战斗主界面（集气条、行动菜单、招式选择、范围预览）；
   - 武学装配；
   - **书眠携带界面**：识海容量 3/3/3、2/2/2、1/1/1 与 6 件装备的选择，压制预览，残篇提示；
   - 背包与装备；武学图鉴；任务日志；地图；对话；存档与云同步。
5. **关键流程**：新手引导（序章）；书眠流程；一轮完整的战斗操作；装配与套装提示；云存档冲突处理。
6. **战斗交互细节**：等距网格上的选格与范围模板预览；高度差显示；确认与撤销；加速与自动战斗；信息密度控制。
7. **性能与无障碍**：逐条回应 tech/03 §6.5 的性能契约；字号缩放、色弱模式、减少动效。
8. **实现建议**：Vue 组件划分；UI 与 core 的桥接边界（只读视图模型 + 命令）。
9. 本文新增术语与 ID；待决事项 / 依赖。
