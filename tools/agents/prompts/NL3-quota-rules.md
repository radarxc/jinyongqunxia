# 本任务：图鉴检查脚本的绝招配额改为按规则逐门判定（只改 `tools/lint/`）

`tools/lint/check_skill_catalogs.py`（NA2 新建，NL2 扩展）用一张硬编码的快照表 `EXPECTED` 核对各册各品段的"门数 / 绝招总数"，例如少林为 `{"天": (3, 7), "地": (26, 44), "玄上": (10, 10)}`。这张表很脆弱：
- 后续任务 NU5a / NU5b 按 `docs/decisions/ultimate-counts-tianzhong-dizhong.md`（NU5p 裁定表）调整天中 / 地中的绝招数，共升 8 门、降 27 门。调整后各册总数必然变化，正确的修改会被快照判为失败。
- NXc1 / NXc2 会向图鉴补录新武学，门数也会变。

## 要做的事

1. **去掉快照总数，改为逐门按规则判定**：每门武学按其品阶要求绝招数，规则如下：
   - 黄阶、玄下、玄中：0。
   - 玄上：1。
   - 地下：1。
   - 地中：按裁定表该门的"裁定绝招数"精确核对。
   - 地上：2。
   - 天下：2。
   - 天中：按裁定表精确核对。
   - 天上：3。
   - 天中 / 地中的武学若不在裁定表中（例如后续新补录的武学），只要求落在规则区间内：天中 2–3、地中 1–2。另报一条提示"未入裁定表"，这条不计入失败。
   - 降龙十八掌等外部定义的例外（`EXTERNAL_*`）保持现有处理。
2. **裁定表的读取**：解析裁定表的实际表格格式（先打开文件核对，不要猜），按 `sk_*` 建立映射。裁定表缺失或无法解析时，报明确错误，不要静默跳过。
3. **快照相关的其他用法**：
   - `EXPECTED` 目前还被用来决定"哪些册要求带审计版本标记 `AUDIT_VERSION`"。改为按文件名匹配 `docs/design/catalog/skills-*.md` 判定。
   - 如果这个版本标记检查本身没有必要，就删掉它，在报告中说明理由。
4. **顺带修 NL2 留下的三处小问题**：
   - `ap_[a-z0-9_]+` / `mfr_[a-z0-9_]+` 前面加单词边界。
   - `tools/lint/README.md` 中"§0.12.1"的说法，改为如实描述识别范围（不依赖版式，§0.12.x 都能识别）。
   - "只定义一次"测试的断言移进 `subTest`。
5. **测试**：在 `tools/lint/test_check_skill_catalogs.py` 补测试，覆盖：
   - 各品规则值；
   - 天中 / 地中按裁定表精确核对；
   - 未入裁定表时只按区间判定并给出提示；
   - 裁定表缺失时报错。
6. **报告当前主分支的检查结果**：按册列出新配额规则下的违规，应当正好是裁定表中"变动 ≠ 0"的 35 门（升 8、降 27）；另列出"每条路线只定义一次"的 221 条命中。这些都由 NU5a / NU5b 修正，本任务不改图鉴。
7. 同步 `tools/lint/README.md`。

检查：`python3 -m unittest discover -s tools/lint -p "test_*.py"` 与 `python3 tools/lint/check_ids.py --strict` 必须通过。本任务不要求 `check_skill_catalogs.py --strict` 在当前图鉴上通过。不要为降数字放宽其他规则。
