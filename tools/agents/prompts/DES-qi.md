## 要做的事

1. **把作者的概念映射到现有模型并补齐缺口**（design/21 §2–§3 新增小节或改写）：
   - 经脉 / 穴道的**宽度**（= 节点通量上限 flux，整数气单位 / tick）、**长度**（段长，影响气在经脉中运行的 tick 数）、**速度**（运气速度 = 内功心法基础速度 × 层级曲线）、**数量**（当前在途气量）、**丹田产气量 / 单位时间**（内功心法基础产气 × 层级）；每条经脉 / 穴道的通量上限是内功修炼"每个周期跑通后锻炼"出来的属性（给锻炼增量公式与上限）。
   - **攻击时放出的气量** = 丹田产气量、运气速度、路线上各节点通量三者决定的函数（给整数公式与示例数值表：三档内功 × 三档经脉）。
   - **生命 / 内力的来源**：人物无独立等级；`hpMax` / `mpMax` 由所学武功层数（1–9，练习熟练度）与经脉强弱（已通穴位数、经脉强度、穴位强度 天 / 地 / 玄 / 黄 × 1–9 层）决定，给唯一公式；药材 / 丹药对经脉 / 穴位的强化接口（与 design/10 §8 对接，只定接口与数值位，不重写物品）。
   - 与 design/15 的穴位强度 / 开通进度字段对齐；与 AR-14 / AR-16 / AR-18 的已有决定不冲突，冲突处写明以本次 AR-19 为准并给迁移说明。
2. **战斗中的运气与聚气**（design/09 §3 集气时间轴与 design/21 §4.4 的接口处改写 / 新增）：
   - 单位时间（tick）；产气速度 = 每 tick 丹田产气；人物速度 = 行动槽集气速度；行动槽充能期间真气同步运行；集满后两种选择：行动 / **急性聚气**（跳过本回合，继续积攒经脉中的气）；
   - 完整运气（跑通一周天 / 路线）出招的加成与不完整运气的衰减曲线（整数 bp），气量到达经脉承载上限后不再提升；
   - 完整运气打出暴击的判定与**提示文案**（至少 6 条可轮换，含「运转一周天，内劲喷涌而出，难以抵挡」）；提示由 core 发事件、UI 显示（给事件名与字段）。
