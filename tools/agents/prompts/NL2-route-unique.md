# 本任务：图鉴检查脚本增加"每条路线只定义一次"（只改 `tools/lint/`）

NA2（已合入）新增了 `tools/lint/check_skill_catalogs.py`。它检查以下内容：
- V-M01 三方一致；
- 各品配额与 7 / 9 / 10 解锁层；
- 显式路线；
- 同门路线相似度；
- `outOfBattleScaleBp`；
- 旧 Buff。

它**不查同一路线 ID 是否被定义了两次**。NA2 在图鉴文首新增了绝招路线索引块，而更早的旧表中仍留着同一批 `mfr_*` 的步骤，两处穴位序列不同。旧表包括：
- NU1–NU3 的"同门第二 / 第三绝招显式路线"表；
- NU2S 的"§0.12.1 最终绝招路线"表。

受影响的共 8 册 221 个 ID：五绝 82、逍遥 67、少林 22、道家 19、通用 10、倚天 9、五岳 7、侠客碧血 5。

## 要做的事

1. **新增检查规则**：在 `check_skill_catalogs.py` 中新增规则"每个 `mfr_*` 的步骤序列在全部图鉴中只定义一次"。
   - 同一 ID 在第二处出现时，只允许作为引用出现，例如步骤列写"见文首索引"或只列 ID 不列步骤。
   - 如果两处都列了步骤，无论序列是否相同都报错，并给出两处位置。
   - `--strict` 时该项计入失败。
2. **识别写法**：规则要能识别三处写法：
   - 文首索引块；
   - NU1–NU3 的"同门第二 / 第三绝招显式路线"表；
   - NU2S 的"§0.12.1 最终绝招路线"表。

   逐一打开这些表核对实际格式，不要猜。
3. **测试**：在 `tools/lint/test_check_skill_catalogs.py` 补测试，覆盖三种情形：只定义一次通过；重复且序列不同报错；重复但第二处只是引用时通过。
4. **不改图鉴**：图鉴由后续 NU5a / NU5b 统一。报告里给出当前主分支上该规则的命中数（按册），应与上面的 221 相符；如不符，说明差异。
5. **文档**：同步 `tools/lint/README.md` 的规则说明。

检查：`python3 -m unittest discover -s tools/lint -p "test_*.py"` 与 `python3 tools/lint/check_ids.py --strict` 必须通过。
- 本任务不要求 `check_skill_catalogs.py --strict` 在当前图鉴上通过，因为图鉴还没统一。
- 不要为降数字放宽其他规则。
