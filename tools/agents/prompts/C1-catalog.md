## 硬约束

1. 字段与枚举以 `design/05` §2 为准。`reqs` 用 `rulings-v1.md` A4 的新字段（C17：技艺门槛、二选一前置）；`dualWield` 等按 C16。
2. 招式倍率按 05 §4.2 的预算公式配出（允许 ±0.05），每一招都写核算式；内功按 05 §5.5 的贡献预算核算。
3. **不得新增天阶。** 天阶只收基准 §13 中属于本组的条目，品阶、ID、原生书界与 §13 完全一致。
4. 满足 05 §14.6 的全部撰写约束，特别是：
   - 每个门派至少有 1 门黄阶入门拳或剑、1 条"黄 → 玄 → 地"进阶链（写明前置关系）、1 个可成套的组合（`setTags`）；
   - **中武、低武书界**：本组覆盖的每个书界，本土内功、拳脚、兵器各 ≥ 3 门，让只带了 2/2/2 或 1/1/1 的玩家能补齐装配栏。在"境界覆盖与装配可行性"一节逐书界列表证明；
   - 各书界最高原生轻功品阶遵循 05 §14.6 第 7 条；
   - 地阶武学中代价型、誓约型 ≤ 5%，合击类 ≤ 3%；敌人专用武学（`enemyOnly: true`）单独列表、不计入总数。
5. 武学施加的 Buff 只用 `design/06` 目录中已有的 `bf_*`，或 `rulings-v1.md` A5 中已裁定收录的 ID。确需新 Buff 的，在"待决事项"里写"建议 06 收录"并给定义摘要，正文先用该 ID。
6. 引用其他图鉴里的武学只写 ID，不重复定义。每个新 ID 先全仓库 grep 查重。
7. 原著武学与招名注明出处（书名·回目或人物）；原创扩展标（原创扩展）；原著有其人其事而无武学名、由本作命名的，标（原创扩展命名）。
8. 套装候选：给出候选套装的成员与主题，成员双向登记 `setTags`（C22）；规则与最终数值留给 07。

## 作者新增需求（2026-09-26，见 `docs/decisions/author-requirements.md`，覆盖上文与分工表中的数量目标）
