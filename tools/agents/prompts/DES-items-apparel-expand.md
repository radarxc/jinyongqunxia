## 作者要求（2026-10-01 原话）

> 衣服/披风/头饰/腰带/鞋 要有不同年代衣物和制式，在不同书中出现，地/玄/黄 X 上/中/下 X 男/女，每种18个，搜一下历史知识结合历史生成物品清单和描述，写到任务里

协调者解释：五种（衣服、披风、头饰、腰带、鞋）各自要覆盖一张 **18 格矩阵：品阶 地 / 玄 / 黄 × 品 上 / 中 / 下 × 男 / 女**，每格至少 1 件；每件都要落在具体年代与制式上（北宋 / 辽 / 西夏 / 大理 / 南宋 / 金 / 元 / 明 / 清，兼回疆、藏地、蒙古），并写明它出现在哪些书界（design/02 的书界年代）。天级不在矩阵内（已有天级宝衣等保留）。每行一张出图，提示词由脚本从"外观要点"列生成，所以外观要点要能直接出图（男 / 女款差异写清）。

## 要做的事

1. 五种各补齐 18 格矩阵（现有行若恰好落在某格可以算数，但每格至少 1 行；总行数 = 现有 + 新增）：
   - **衣服** → `items-clothing.md`：子类沿用 `衣物·便服 / 劲装 / 袍服 / 礼服 / 骑装 / 氅服 / 潜行服 …`，可加 `衣物·僧道服 / 官服 / 胡服`。年代覆盖至少：北宋（圆领袍、直裰、褙子、襦裙、短褐）、辽 / 金 / 西夏 / 大理（左衽胡服、团衫、吐蕃氆氇 / 大理白族）、元（质孙服、辫线袄、罟罟冠配套）、明（道袍、曳撒、比甲、马面裙、袄裙、飞鱼服慎用）、清（长袍马褂、旗装、坎肩、箭袖）、回疆 / 藏地 / 蒙古（袷袢、藏袍、蒙古袍）。
   - **披风** → `items-accessories.md` 子类 `披风·…`：斗篷、氅、鹤氅、斗笠雨披、毡披、貂裘披、水田披、羽缎披风（清）等，按年代与男女。
   - **头饰** → `items-accessories.md` 子类 `头饰·…`：男（幞头、东坡巾、方巾、网巾、瓜皮帽、暖帽 / 凉帽、毡帽、皮帽、僧帽、道冠、抹额）、女（花冠、簪钗、步摇、冠子、包髻、罟罟冠、钿子、旗头、帷帽、头巾）。
   - **腰带** → `items-belts.md` 子类沿用 `腰带·布绳 / 布带 / 丝带 / 皮革 / 玉带 / 金属 / …`：鞓带、蹀躞带、革带、玉带（品级！）、丝绦、束腰、汗巾、腰封、荷包腰带等，女款注意宋明女子多系绦 / 帛带。
   - **鞋** → `items-shoes.md` 子类沿用 `鞋·草鞋 / 布履 / 布靴 / 轻靴 / 裘靴 / …`：云头履、乌皮靴、翘头履、木屐、麻鞋、毡靴、皂靴、弓鞋（仅限有史实的年代与阶层，不做成人化描写）、花盆底（清旗女）、藏靴、蒙古靴。
   每格至少 1 行；每种 18 格 → 每种至少 18 行（含已有）。品阶列写 `地上 / 地中 / 地下 / 玄上 / 玄中 / 玄下 / 黄上 / 黄中 / 黄下`，`grade=` 分别 9 / 8 / 7 / 6 / 5 / 4 / 3 / 2 / 1；品阶靠材质（麻 → 棉布 → 绸缎 → 锦 / 貂 / 玉）、工艺、阶层（庶民 → 士绅 / 武人 → 官 / 贵）表达，**不靠魔法**。
2. **每行七列**严格按现有格式：`| \`eq_<拼音>\` | 名称 | 子类 | 品阶 | 出处 | 效果字段 | 外观要点（供出图） |`
   - ID：`eq_` + 小写拼音，全库唯一（`check_ids.py --strict`）；同一制式男女两件用 `_nan` / `_nv` 后缀或名称区分。
   - 效果字段沿用各表现有模式（`grade=…; slot=body|cape|head|waist|feet; armorWeight=…; …`），**加 `wearer=male|female`**（矩阵维度），数值无原著定本的标 **（原创扩展）**；不新造 design/06 之外的 Buff / 词条 ID。
   - 出处：写"制式 · 朝代（史料名）· 出现书界 chNN/chNN"；有原著人物穿着依据的加"《书名》·人物概括"（不编造引文）；原创组合标 **（原创扩展）**。
   - 外观要点：形制（领 / 襟 / 袖 / 摆、冠式、带扣、鞋头）、材质与色彩（按阶层与品阶）、纹样（无字）、男女款差异、年代感、尺寸感；按 item.md §8.2 的画法（衣物平展、头饰冠巾不画人头、鞋一双、腰带松弧）。汉式交领一律右衽；僧道官兵异族按身份；不写演员 / 影视造型。
