## 要做的事

1. 逐门核对本组所有天 / 地 / 玄上武学的绝招数量，按上面的规则补足（天阶不足 2 的补到 2–3；地上 / 地中按招式数与原著补到合适数量；玄上每门补 1 记）。超出上限的降为普通招式。
2. **绝招的来源**：优先从本门已有招式（`mv_*`）中选定并标 `ultimate:true`；确需新增招式的，原著有据者按原著命名并写出处，原著无据者标（原创扩展）并用描述性名称，**不冒充原著招名，不编造回目**。每个 `mv_*` 新 ID 先 `grep -rn` 查重。
3. 每记新增或新标的绝招都要有自己的经脉路线（攻 / 防 / 轻功按招式用途），路线写法与本册已有的路线表一致（显式列出 `mfr_*` 与段数、单段 CT、风险），满足 21 的硬约束：1–18 段、单段 40–120 CT、`收招 + 满路线 CT ≤ 2000`、同一路线穴位不重复、穴位在 `design/15` 中存在。
4. 更新本册的统计表（各阶绝招数）、"本文新增术语与 ID"与待决事项；版本行追加"绝招数量调整（{{date}}）"。只增补与改写相关条目，不删无关内容（调度器拒绝缩短 15% 以上）。
