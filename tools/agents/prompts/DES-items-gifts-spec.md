## 要做的事
1. `design/10` §11.5 扩为「收藏品与礼品」：
   - 子类补齐：`porcelain`（瓷器 / 茶具）、`jade`（玉器）、`bronze`（香炉 / 铜器 / 金银器）、`qin`（琴与乐器）、`calligraphy`（书法、拜帖、名家手迹，沿用）、`stationery`（笔墨纸砚，笔为主）、`antique`（其他：铜镜、犀角、玻璃器、珠宝、扇、墨等）；每个子类写一句定义与原著 / 历史例子。
   - 字段：`giftValue`（礼值，整数，按品阶带）、`giftTo`（偏好标签：文士 / 武人 / 僧道 / 女眷 / 权贵 / 商贾 / 门派…与好感增量规则，接 design/18 §3 的软门槛）、`eraRange`（可得年代带：chunqiu / tang / song_north / song_south / yuan / ming / qing，跨朝代传世品写多个）、`provenance`（书中 / 历史 / 原创扩展）、`study`（研读 / 鉴赏收益，沿用）、`appraise`（鉴宝 DC，沿用）；属性投影机器行写法（按 §4.10 的语法，键只能用本节表）。
   - 送礼接口：赠礼好感增量 = f(giftValue, 偏好匹配, 品阶) 的整数化公式与上限（每人每日 / 每书界的礼物好感上限，防止「送礼 100 次」），与 design/18 §2.6「D4 / D5 不得退化为刷好感」一致；拒收与失礼规则（送错对象扣好感）。
   - 按朝代可得性：各朝代典型器物举例表（唐武周：越窑秘色瓷、唐三彩、铜镜；北宋：建盏、汝窑、定窑、宋琴、米芾苏轼帖；南宋：龙泉青瓷、官窑、陆游诗帖；元：青花、赵孟頫帖；明：成化斗彩、宣德炉、文徵明 / 董其昌、湖笔；清：珐琅彩、乾隆御笔、郑板桥；春秋越：青铜器、玉璧），标（待考）/（原创扩展）。
   - 书中宝物举例：每本书 1–3 件原著里出现、可作礼品的物件（如笑傲 梅庄《率意帖》已登记、曲洋刘正风的琴、鹿鼎 康熙御赐之物、书剑 玉瓶 / 玉佩、雪山 / 连城 宝藏珠宝…），只引用，逐件考据交 ART 任务。
2. `design/12`：加「求字 / 求帖」支线模板：主角在各朝代可通过支线向该时代名家求字或换帖（拜帖、题字、手迹），模板含触发（声望 / 好感 / 奇遇）、试炼（送礼、比武、办事）、产出（`it_` 书法收藏品）、每书界 1–2 条；写明挂点由各书 chapters 登记。
