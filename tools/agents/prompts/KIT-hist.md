# 本任务：建筑套件「{{kit_name}}」（`{{kit_id}}`）· 按历史图片参考重出，要有很强的历史细节

本任务重出已有套件的全部建筑与墙门贴片（同 ID 覆盖），不改工具、不改其他套件。"只改负责的文件""不执行改变仓库状态的 git 命令""不要停下来提问""报告如实"照常适用。

## 作者要求（原话，2026-09-30）

> 建筑套件和城市在生成时搜一下历史图片作为参考

> 这个也重新参考一下，希望有很强的历史细节

## 做法

套件目录 `assets/default/building-map/{{kit_id}}/`、贴片 `assets/default/tile/{{kit_id}}/` 里已有一版（ID、占地、类型对应表都保留，只换图）。本任务沙箱已放开网络。对每一类建筑：

1. **搜历史图片**：2–3 张——现存同年代 / 同地域古建或遗址照片、考古复原图、古画 / 舆图 / 界画中的建筑、博物馆模型（优先 Wikimedia Commons、博物馆与考古所官网、学术页面、地方志数字化页）。用 `curl -L -o refs/<type>_<n>.<ext> <url>` 下载到工作区 `refs/`（写集外，不入库），`view_image` 看过，记下取用的细节。下载失败的换一张；一类都下不到就用文字记载并写明。
2. **重出图**：`image_gen` 以参考图为输入（只取形制、比例、材质、构造细节，不复制整图构图，不用影视 / 游戏截图），提示词里逐项写出历史细节：屋顶形式与举折、屋脊 / 鸱吻 / 脊兽、瓦作（筒瓦 / 板瓦 / 灰瓦 / 琉璃）、斗拱层数与出跳、柱网与台基、门窗棂格样式、彩画 / 装饰、墙体砌法（夯土 / 青砖 / 土坯 / 石砌）与地域材料；仍然是斜 45°、俯仰 30°、2:1、透明底真 RGBA、光源左上、占地底边清楚、与宋基线相同的写实程度与细节密度。每张最多 2 候选选 1，`view_image` 自查。
3. **规格化入库**：同 ID 覆盖原图，`manifest.yaml` 更新 `size` / `sha256` / `prompt` / `references`（每张列出用到的参考图 URL 与取用了什么）/ `notes`（历史细节清单）；贴片同理。`assets/default/prompts/building-map.md` 本套件一节补"历史细节要点"。

约束：不改 ID、类型与占地登记（画面占地若与登记偏差 > 30% 再改登记值）；不改 `tools/town/`；每次写入 ≤ 150 行；报告 ≤ 100 行（每类建筑：参考图来源、取用细节、候选数）。

检查：以下命令必须全部通过。
- `python3 tools/agents/check_assets.py assets/default/building-map/{{kit_id}} --min 18 --max 22 --min-side 256`
- `python3 tools/agents/check_assets.py assets/default/tile/{{kit_id}} --min 5 --max 10 --min-side 32`
- `python3 tools/lint/check_ids.py --strict`
