「local dev的操作界面太丑了，太像网页了。这是一个游戏，要有沉浸感。主要视窗（大地图/地图/战斗）+ 工具。参考经典武侠的操作页面，设计菜单、工具、物品、图鉴、状态展示等。文字用古风字体，可操作组件要比较高级和融合的。」

## 要做的事

1. **诊断**：逐页列出现状「像网页」的具体原因（表单式创建页、居中白卡、系统字体、原生 select / radio / 滚动条、整页切换把主视窗切走、按钮像网页按钮……），每条给出改法落在新方案哪一节。
2. **调研**：至少 8 款经典武侠 / 仙侠游戏的操作界面（建议覆盖：金庸群侠传 1996、武林群侠传 / 侠客风云传、河洛群侠传、仙剑奇侠传、古剑奇谭、天涯明月刀、逆水寒、太吾绘卷、烟雨江湖、下一站江湖、鬼谷八荒等），每款写：主视窗与 HUD 布局、菜单 / 工具入口、物品格与品阶表现、图鉴结构、状态展示、字体与材质、沉浸感从哪来、我们借鉴什么 / 避开什么。附录列来源链接。只借鉴结构与手法，不照搬美术。
3. **新方案** `docs/design/26-immersive-ui.md`：
   - 屏幕结构：主视窗（大地图 / 区域与城镇 / 战斗）始终全屏渲染；HUD 分区（时辰节气、年号、地点、银两；小地图或罗盘；队伍头像与气血 / 内力 / 体力；底部或侧边工具栏：行囊、武学、人物、图鉴、任务 / 江湖志、系统；飘字与「印章式」获得提示；对话层立绘 + 卷轴对白）。面板以卷轴 / 册页 / 木匣叠在主视窗上，不切走主视窗；层级与返回契约承接 14 §1.7。
   - 每个界面一节，给线框（ASCII 或内嵌 SVG）、信息清单、组件清单、交互（鼠标、键盘快捷键、触屏手势）：标题、入卷（角色创建改成仪式化：立绘挑选 + 题签填名，不要表单）、开场 / 过场、对话、书眠配点、大地图、区域 / 城镇、战斗 HUD（六角格、招式栏、回合序、气血内力）、行囊（物品格按黄玄地天品阶描边，详情带 lore）、武学（招式 / 内功 / 轻功）、人物状态（先天八项、经脉、八栏装备）、图鉴（人物 / 武学 / 物品 / 地点 / 书界，解锁进度，直接用已落库的立绘与物品图）、任务 / 江湖志、存档、设置。
   - 视觉语言 tokens：材质（宣纸、绢、墨、朱砂印、木、铜）、色彩（含品阶色与语义色）、描边纹饰、阴影光感；明暗两套。
   - **古风字体**：标题用书法类、正文用楷 / 宋 / 文楷类；只选可商用开源授权（OFL 等），写明授权与来源；给出自托管子集化方案（按游戏文本实际用字 + 常用字表生成 woff2 子集；首屏只载标题子集，正文懒加载；中文回退栈）、体积估算、对首屏与 PWA 缓存的影响。
   - **组件库（高级、融合）**：按钮（印章 / 题签 / 墨痕三类）、页签、滑块、开关、下拉替代件（不用原生 select）、题签式输入框、提示框、计量条（墨晕填充）、物品格、头像框、对话框、页内确认（不用原生 confirm）、自绘卷轴滚动条；每件写状态（常态 / 悬停 / 按下 / 禁用 / 焦点可见）、动效（墨晕、卷轴展开、印章落下；尊重 reduced-motion）、音效钩子；全部是 `packages/ui` 的 Vue 组件，只吃投影。
   - 性能与工程约束：动画只用 transform / opacity；框与底纹用 9-slice 图集，图片不 import 进 JS；面板按需加载；60 fps；触控底线承接 14 §1.2。
   - **交 ENG 的拆分**（单独一节）：建议 ENG-ui-shell（全屏主视窗 + HUD 骨架 + 面板栈）、ENG-ui-kit（组件库 + tokens + 字体管线）、ENG-ui-pages（M1 各页按新方案重做：标题 / 入卷 / 开场 / 对话 / 书眠 / 白马城）、ENG-ui-codex（图鉴投影与页面）、ENG-ui-battle-hud；每项写写集、依赖、验收（含截图对比与体积门禁）。
