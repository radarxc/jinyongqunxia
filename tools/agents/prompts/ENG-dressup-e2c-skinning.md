## 背景（E2b 结论，数字见 E2b 报告第 3 节）
E2b 用体表位移场 + 限拉伸垂坠（`--push-mode volume`）修好了劲装版型几何：三模板翻面 0、边长 ≥ 99%、close-fit < 5 mm，胸口不再破。剩下两类问题：
1. **动画穿插（真穿入）**：idle / walk 的可见穿透超过 2%。伪法向复核确认是真穿入，集中在两处：
   - 垂手时宽袖与髋 / 大腿相撞（ForeArm，深 9–28 mm）；
   - 下摆在步态中被大腿顶穿（UpLeg）。
   原因：袖子 / 下摆直接取最近体表点的模板权重，宽松部位在动作中会撞上身体其他部位，属 LBS 蒙皮问题。
2. **A1 符号误判（假穿入）**：bind 时可见的几个"穿入点"其实在体外 22–49 mm（射线奇偶、伪法向两种方法都判在体外）。原因：三模板各有 26–31 个与着色法向相反的面（Spine1 胸下 7–8 个、Head 8、脚趾 8、Spine2 2–3），A1 带符号距离（最近点连线 · 重心插值顶点法向）在附近判反。

## 要做的事
1. **按姿势蒙皮**（宽松部位）：在模板 idle / walk / run 采样帧上求衣物权重，使衣物点不进入身体。
   - 只作用于离体表超过阈值的宽松部位（宽袖、下摆），贴身部位保留模板权重；
   - 带邻域平滑正则（拉普拉斯或权重修补），杜绝逐点独立 LP 的尖刺（traex 在 E2b 曾出现动画尖刺）；
   - 新选项默认关闭，既有行为不变；三模板评估 `penetration.*.visible ≤ 2%`、`holes ≤ 0.05%`，写入报告。
2. **模板倒置面**：两条路选一条，在报告里对比影响面后实施：
   - 修 `templates/tpl_f_*/body.glb` 的倒置面；会改模板哈希，需连带刷新所有引用它的 fit / report；
   - 或把 A1 `common.signed_distance` 的符号改为角度加权伪法向（E2b 已在 `fit_garment.PseudoNormalSign` 实现并有合成回归）。会改变各工具的穿透计数，需重跑受影响素材的 validate，并证明头 / 道具结论不变。
3. 劲装与布衣三模板重跑 validate；三项门全过时才去掉 `experimental`。

## 协调者裁定（2026-10-10 14:30，审核 r1 FAIL 后；作者决定；Claude 直接实现，AR-110）
r1 指出：逐点 ICM 选骨让相邻点一个绑躯干、一个绑手臂，run 中衣片炸开（边长最大伸长 659 mm）；测试没有动态拓扑；布衣 layer.json 留了临时路径与错哈希。协调者复核：主干 E2b 版（模板最近点权重）idle 可见穿透 4.1–4.6%、run 边长最大伸长 103 mm（同样撕开）；穿插主因是待机时手臂从 A 字收回、贴着身体——前臂 / 手压进下摆两侧、宽袖口压进大腿，纯 LBS 改权重压不下去（硬压即撕）。手臂外展实测（模板原权重，24 帧/段）：0° idle 4.47% / walk 2.99% / run 1.18%；4° 1.53% / 0.45% / 0.85%；6° 0.55% / 0.35% / 1.08%。作者 2026-10-10 选定：**衣物声明手臂外展角 + 局部平滑权重**。
1. **外展姿势（数据驱动）**：衣物 fit.json 增加 `poseOffset: { armAbductionDeg }`（劲装 / 布衣 6°）。运行时 actor 在装备时取已装备衣物的最大外展角，每帧动作采样后把左右 Arm 骨（连同子骨）绕身体前向轴向外转该角，不逐帧分配；卸下恢复。validate 的动态穿透 / 破洞、`bake_hide_mask` 的动作采样、`fit_garment` 的姿势蒙皮都按同一角度采样（公共函数放 validate.py，三处共用）。头 / 道具 / 无该字段的衣物行为逐字节不变。
2. **局部平滑姿势蒙皮**（替换 ICM）：按位置焊接后在全部顶点上解连续权重（每点候选骨 = 3 环内模板权重出现过的骨 + 父骨），目标 = 边上权重差平方（基础弱）+ 贴近模板（贴身强、宽松弱）+ 和为 1 + 姿势采样穿入的线性化外推（只计最近体表可见、遮罩不隐藏处；主动集保留且"不再往里"）；每轮按当前解逐边量 72 帧伸长，超过 8 mm 的边平滑权重只增不减；收敛后截 4 骨、固定支撑集再解数轮。原型（medium、外展 6°）：可见穿透 0.50% / 0.23% / 2.17%（近似口径），边长最大伸长 103 → 22 mm。最终以 validate 口径为准，门禁阈值不放宽。
3. **72 帧动态拓扑门**：`tests_garment.py` 对劲装 / 布衣三体型断言 72 帧（含外展）边长最大伸长 ≤ 30 mm、无新塌缩三角（面积 < bind 5%）；先对现有六份产物跑并在报告记录它们失败的数字（E2c 现产物 659 mm、主干 E2b 103 mm）。
4. 重生成劲装与布衣三体型（GLB / fit / 遮罩 / report / manifest）；`eq_buyi_tex/layer.json` 的 plate / basePlate 恢复仓库相对路径，`source.sha256` 与 `source.file` 一致；三项门全过才去 `experimental`。运行时实拍三体型 × idle / walk / run × 正侧背（需外展运行时：用本工作区起的开发服务器拍）。

## 协调者补充裁定（2026-10-10 17:05，实现中；Claude 直接实现，AR-110）
1. **求解方法**：14:30 第 2 条的"每轮钉住当前值 + 阻尼混合"迭代实测不收敛（轮数越多越差：medium 30 轮最大伸长 44 mm、跑步可见穿透 3.0%），改为固定目标的高斯-牛顿 + LM 阻尼 + 线搜索（每步目标严格下降）。目标仍是第 2 条各项：边上权重差平方（基础弱；采样中伸长超过阈值的边只增不减地加强）+ 贴近原权重（贴身强；宽松区只在撕裂边端点 / 可见穿入点附近放松，即"局部平滑"）+ 和为 1 + 穿入铰链 max(0, margin − 法向距离)²（只计遮罩不隐藏的最近体表）；另加伸长铰链 max(0, 伸长 − 20 mm)² 与贴门的第二道 max(0, 伸长 − 27 mm)²。截 4 骨后固定支撑集再解，取各轮里伸长最小且近似可见穿透 ≤ 1.5% 的一轮；收尾对 72 帧仍超 28 mm 的少数边，在两端 2–6 环内做局部拉普拉斯平滑。
2. **第 3 条塌缩三角改为只报**：主干 E2b 版同口径（6° 外展、72 帧）已有 112–137 个"面积 < bind 5%"的三角，全在胯、腋下、肘、胸下折痕，该量分不清折痕与缺陷；以运行时实拍目视为准。72 帧边长最大伸长 ≤ 30 mm 照旧为门（`tests_garment.py` 断言六份产物）。
