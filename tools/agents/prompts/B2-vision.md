## 至少包含

1. **定位**：一句话、电梯陈述；体验支柱 3–5 条，每条写"设计上如何体现"和"反例（我们不做什么）"。
2. **世界观**：现代世界的设定；穿越缘起（为什么是"天书"，为什么按年代走）；天书与书眠的叙事解释；终局"天书守卷人"决战与回到现实的意义；与原著的关系（基准 §16 改编原则在叙事上的落地）。
3. **主角**：
   - 现代身份：3–5 个可选开局身份，写明每个身份的叙事与 `OriginBonus`（符合 03 D-25 的预算）；
   - 性别：按作者决定；未决定时给出默认方案及其对文本、立绘、队友羁绊的影响；
   - 十四书界的心境弧线；
   - "变数而非替身"（基准 §16 第 4 条）的具体表现。
4. **书灵**：人格、功能（引导、旁白、书眠仪式、图鉴解说）、成长与关系演变、台词风格示例（5–10 句）。
5. **核心循环**，分四层：
   - 分钟级：探索 → 遭遇 → 就地开战 → 收获；
   - 小时级：区域 → 支线 → 门派 → 修炼；
   - 书界级：主线幕 → 锚点 → 天书 → 书眠携带抉择；
   - 全作级：十四书界 → 天书之力 → 终局 → 多周目。
   每层配一张 Mermaid 图，并给节奏与时长估算（与 11、13 对齐：每书界 8–15 小时）。
6. **十四部锚点 / 改命总览**：每部 3–6 个锚点事件（原著事件、在主线中的位置、玩家可介入点）；哪些是"遗憾型"锚点、提供改命线（基准 §16 第 3 条）；改命的触发与代价概述（细节交书界文档）；对应的天书之力主题（基准 §2 的关键词；效果归 13）。书界文档会以这张表为准，务必认真考据。
7. **序章《越女剑》**（`ch00_yuenv`，可跳过）：教学目标；流程（关卡、时长 ≤ 45 分钟）；教学的系统清单；跳过规则（跳过时如何补发教学奖励）；序章武学（与 `rulings-v1.md` 图鉴分工一致，越女剑法的品阶按基准 v1.1）。
8. **基调与表现**：国风水墨 / 工笔；文本风格与原著引用尺度；版权注意（基准 §0：非商业、不公开分发、AI 素材不用演员肖像）。
