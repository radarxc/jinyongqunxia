## 作者要求（2026-10-02 晚，逐字）
> 开一个设计任务，结合已有的prompt，写短文，并且给出初步的属性投影。
> 武器 - 攻击（锋利程度），硬度（被格挡后是否会损坏），内力亲和（一般武器亲和为1，即不加成。特殊武器内力注入有特殊效果，按设定来）
> 衣物 - 防御，反伤，防暗器等
> 鞋子 - 防御，身法
> 护腕 - 防御，格挡（硬度）
> 其他装备 - 吉运，防御，放毒，避毒
> 药品 - 补充内力 / 增加内力修为 / 增加根骨 / 治疗内伤（疏通经络） / 治疗外伤，依据物品描述设定
> 食品 - 补充体力 / 治疗内伤 / 治疗外伤
> 其他 - 根据描述设计

本任务只定**规格**（字段、单位、取值带、与现有公式的接口、名录列格式）；逐件写短文与填值由 DES-items-lore-1～8 做，它们依赖本任务。

先读：`docs/design/10-items-and-equipment.md`（物品字段归属文档；现有 `效果字段` 如 `grade=3; cat=sword; hands=1; mainK=1.00`、`healPct`、`dispel`、`slot`、`resBleedPp`）、`docs/design/04-damage-formula.md` §4.1–§4.2（两支攻击：硬功 / 外放）、`docs/design/03-attributes.md`（八项属性含内息、根骨、身法、福缘）、`docs/design/06-buff-system.md`、`docs/design/15`（经脉 / 内伤）、`docs/design/16`（体力）、`tools/content/items_from_catalog.py`（现有名录 → `item.v1` 投影的字段映射）、`packages/data/src/schemas/item.ts`（`text.desc / lore / short`、`extension.equipment` 字段）、名录 `docs/design/catalog/items-*.md` 各一份的表头与 3–5 行样例。

## 要做的事
1. 在 `design/10` 新增「属性投影 v2」一节（版本号 +1，变更记录加一条）：
   - **字段表**（每类）：字段 ID（小写驼峰）、中文名、单位（整数 bp / 点 / 百分比整数）、默认值、取值带按品阶（黄 / 玄 / 地 / 天）、与现有字段的关系（例如「攻击（锋利）」是否就是现有 `mainK`——如是就说明换算，不另起字段；「硬度」新字段 `hardness`（被格挡后损坏的判定：每次被格挡掉硬度，降到阈值即损坏 / 需修）；「内力亲和」`qiAffinity` 默认 100（即 1.00，不加成），特殊武器写 `qiEffect` 引用；衣物 `def`、`reflect`、`antiHidden`；鞋 `def`、`agi`；护腕 `def`、`block`（格挡用硬度）；其他装备 `luck`（吉运）、`def`、`poison`（放毒）、`antiPoison`（避毒）；药品 `restoreQi`、`qiCultivation`（内力修为 +）、`con`（根骨 +，永久，须有总预算上限并引用 design/03 的永久属性预算）、`healInner`（治内伤 / 疏通经络，接 design/15 的经脉伤口径）、`healOuter`；食品 `stamina`、`healInner`、`healOuter`；秘籍等「其他」按描述设计，给出可选字段集与原则）。
   - **接口**：每个字段在哪个公式里消费（design/04 的哪一支、design/06 的哪个 buff、design/15 的哪个量），写出算式或引用；不能落地的标【建议值】并写默认。
   - **名录列格式**：名录表新增「说明」列（短文 60–120 字：来历、用法、江湖传闻，原著有的注出处、原创标（原创扩展））和「属性投影」列（机器行：`atk=…; hardness=…; qiAffinity=…`，与「效果字段」列并存，旧列不删）；写清机器行语法与校验规则（键只能用本节字段表；数值范围按品阶带）。
   - **数据校验规则与测试用例**：V10-* 条目，供 TOOL 任务实现；并在报告第 6 节交待 `items_from_catalog.py` 要新增的映射（`说明` → `text.lore`，属性投影 → `extension` 字段）。
