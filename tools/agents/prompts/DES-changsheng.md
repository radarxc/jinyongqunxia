# 本任务：设计补充 · 《长生诀》主线与书眠重定（AR-26；兼写 AR-27 的基准层要点）

本任务改策划文档，不写代码。"只改负责的文件""不执行改变仓库状态的 git 命令""不要停下来提问""报告如实"照常适用。

## 作者要求

逐字原文与作者对四个追问的回答在 `docs/decisions/author-requirements.md` 的 **AR-26、AR-27**，必须先通读，事实优先级高于基准。要点：

- **主线**：现代人穿越到古代。越女剑序章里，玩家临时体验顶级剑法和一门九层功法；序章结尾由**阿青**传授《长生诀》第一层（休眠、不老）。主角随后在**长白山遭雪崩**、埋入洞穴，不由自主运行《长生诀》入眠；沉睡中做属性配点，然后进入第一本正式书。
- **书序**：白马啸西风改放**唐朝**，排在序章之后、天龙之前，成为第一本正式书；其余十三本顺序不变。
- **书眠入口**：完成一本书后，以契合本书情节的**休眠事件**入眠（看破红尘、心累、归隐山林后渐渐休眠、一命换一命后被大风刮入洞中等），在下一本书的最前期苏醒。天龙的「一命换一命」作者已写明情节，见 AR-26 原文。
- **苏醒前取舍**（第九层之前每次都有）：
  - 属性点保留；
  - 固定保留 3 门武功 + 3 门内功，外来压制（降品阶）照旧；
  - 其余武功可以忘记，按 60% 转化为**顿悟点数**（武功经验，即兵器、拳掌等类别的熟练度，可投到任一类别）；内功可以散去，按 60% 转化为**真元**（内功经验）。
- **层数**：
  - 第一层由阿青传授；
  - 第二至八层来自七本书的「长生诀支线」（特别复杂），每完成一条得一层；
  - 第九层在**鹿鼎记**领悟，条件是悟性满、找到**和氏璧**。
- **第九层效果**：长生加**螺旋内力**。
  - 「消解率 1:20」= 化解对方内力：每 1 点螺旋内力化解对方 20 点内力；
  - 「经脉伤害 100%」，解释见下文第 5 节。
- **九层之后**：书与书之间改为「**周游世界**」，不老不眠，武功、内功不再遗忘。
- **AR-27（属性，与本任务并行的 `DES-attr-v2` 负责细节）**：
  - 先天属性是现有七项（根骨、臂力、身法、悟性、定力、福缘、魅力）加新增的**内息**，共八项；
  - 沉睡配点的是臂力、根骨、内息、悟性、身法、定力六项；
  - 福缘、魅力保留，默认不配点。
