v1.x（M2 / M2.R）把经脉路线加成设计为"上限 12%，并入 04 的 Z3 增伤加算池"。作者看过后做了决定——被问到"招式的经脉路线加成要多强？现在是最多 12%，并且和其他增伤相加"时，作者选择"独立乘区"，并补充（原文照录，不要改写）：

> 独立乘，金庸里内力经脉强则无敌，这里要体现出来。包括防守招式，也要有类似加成。同时增加一个经脉内劲抵消拳脚进攻的机制。

作者决定高于基准（`_common.md` 规则 1）。本任务在 21 号文档内完成设计修订；其他文档的落地（04 / 05 / 06 / 09 / 13 / 14 / 15 / 武学图鉴 / tech/05 / 基准）由后续并行任务按你更新后的 §18.6 同步清单执行，本任务不改它们。

## 要做的事

1. **登记**：在 `docs/decisions/author-requirements.md` 的 AR-14 下追加"作者决定（2026-09-27）"小节，照录上面的问题与原文，并写解读与默认值（替换 v1.x 中与之冲突的默认值，旧值保留为"已被作者决定取代"）。
2. **经脉独立乘区**：
   - 从 Z3 加算池移出，新设独立乘区（命名、在 Z0–Z10 链中的位置、取整点；这是基准 §9 的改动，写成提案）。
   - 体现"内力经脉强则无敌"：乘区取值由**攻方经脉强度相对守方**（气量、流畅度、容量、路线完成质量）决定，给出陡峭但有上下界的曲线与数值表：同等强度 ≈ 1.0（标准对标准的 04 节奏不变，`damage_sim.py --check` 必须保持通过）；明显强于对手时可达"碾压"（写清上界与出现条件，如高一个境界、九阳 / 易筋经大成对普通高手）；弱于对手时明显吃亏。路线越长、完成质量越高，可兑现的倍率越大。
   - 说明它与已有乘区（外来压制、境界、相性等）的叠加顺序，给出防失控的上下界与成长曲线衔接（15 的冲穴 / 周天 / 九转只提高强度，不无限推高倍率）。
3. **防守招式的路线加成**：招架、格挡、卸力、护体运劲、闪避类身法等防守动作也可对应经脉路线；给出守方独立乘区（减伤 / 格挡率 / 卸力比例，命名与位置同样写成基准提案）、每段时间（接 09 的反应机制与待机 / 防御行动）、卡住与胀损规则、绝招级防守（如金刚不坏、九阳护体、太极卸力）示例。
4. **经脉内劲抵消拳脚进攻**：
   - 设计"护体内劲"类机制：守方以经脉内劲抵消来袭的**拳脚**伤害（兵器、暗器、内劲外放类是否受影响、受多少影响要写清）；抵消量由守方经脉强度与流畅度决定，被击穿时产生迟滞 / 胀损与内力消耗；强者对弱者的拳脚近乎免疫（体现"强则无敌"），并可设计反震。
