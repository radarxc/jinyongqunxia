## 做法（AR-83 定稿，协调者口径第 2–7 条；AR-69 的随机与融合并入）

整张图由程序按数据确定地画出来，贴片只提供笔墨质感。

1. **边界**：取 GIS 多边形与折线（海陆、湖、区域），沿边界逐段铺边界笔触条（ART-map-inkkit-tiles）。
   - 按弧长把笔触条沿路径弯曲贴合，例如逐段仿射或网格变形，首尾相接；
   - 拐角与接头要平滑：按转角切分，重叠处用渐变蒙版过渡，不留缝，也不叠出死黑；
   - 粗细按边界类别与比例尺取档，档位写进配置。海岸线、湖岸用 manifest 的 `strip.water_side` 定朝向，水的一侧朝水域。
2. **填充**：同类区域内用对应的填充贴片平铺：水面、湖面、平原、草原、沙漠、高原。
   - 平铺后叠加低频噪声和墨色深浅变化，避免重复感；平铺偏移与旋转按固定种子取；
   - 不同类区域交界按距离场用渐变蒙版过渡，不出现硬分界。
3. **河流**：按流量或等级设最小阈值，低于阈值的支流不画。
   - 等级取 Natural Earth 的 `scalerank`，或由 DEM 算出的汇流量，二选一，写进报告；
   - 阈值写进配置；河宽随等级取笔触条的粗细档。
4. **山川**：由 DEM 高差生成山势图：晕渲、山脊线、坡度分级。再把山势图的轮廓和边缘换成水墨笔触，质感对齐基线。
   - 高山、雪山处点缀少量山峰贴图（inkkit / inkkit-full 的山峰、山脉、雪山），**只作点缀，不再满铺**；
   - 点缀按泊松盘分布，密度随海拔与坡度。
5. **城镇等**：贴入城镇、关隘、标记（inkkit-full 的小景贴图），边缘用消融算法融进底图：羽化、溶解噪声、墨晕。
6. **随机与融合**（AR-69）：
   - 贴图的缩放、旋转、翻转、墨色深浅，按固定种子扰动。默认范围如下，可调，实际取值写进报告：
     - 有上下朝向的（山峰点缀、聚落、关隘、标记）：缩放 ±15%，旋转 ±6°，只做水平翻转，墨色深浅 ±12%；
     - 填充贴片：平铺时可任意角度旋转、水平垂直翻转；
     - 可点击标记：缩放扰动不超过 ±8%，位置不扰动，点击坐标与辨识度不受影响；
   - 同品类在一定半径内不连用同一件变体；
   - 点缀与标记按泊松盘分布；按落脚点（manifest 的 `kit.anchor`）的画布 y 排遮挡，近处压远处；
   - 墨色叠加用乘法一类的混合，越叠越深，不互相覆盖；
   - 最后整体压一层纸纹与墨晕，避免拼贴感。纸纹程序生成、固定种子，不从基线裁取。
7. **确定性**：全程固定随机种子，同一输入出同一张图，逐像素一致。

## 要做的事

1. **生成器** `tools/map/compose/compose_map.py`，按上节做法实现。
   - 参数写进配置文件，如 `tools/map/compose/config.json`：笔触条粗细档、河流阈值、填充噪声强度、扰动范围、点缀密度、消融半径等；
   - 投影到画布按 design/19 §2；
   - 时代图层沿用 design/19 §8：各书界只显示当时开放的城市、门派、路线；
   - `pois.yaml` 的置信度在画法上区分。共 30 条，低置信度 10 条不出精确标记，比如淡墨、不给点击半径，或只在区域图出现。具体做法你定，写进报告。
2. **输出**：
   - 地图 PNG；
   - 标记坐标 JSON：每个可点击标记的 ID、类型、画布坐标、点击半径、书界开放，供游戏点击。
3. **先核对各区取景框**：出样区和区域图之前，核对 `docs/design/map/regions.yaml` 各区的取景框。
   - 交接已指出几处可疑：漠北只有 0.5°×0.5°；辽东东到 133E；东海诸岛、南海诸岛的取景框宽 2000–3000 km。
   - 发现异常就列进报告第 4 节交协调者定，**不要自己改 regions.yaml 的事实**。样区挑取景框正常的区。
4. **本轮只出样区**：大理（基线可对照）或关中，二选一。产物放 `assets/default/map/composed/sample/`，交作者过目；通过后另起任务出全图。样区报告附两组对比，每组同一区域、同一画幅左右并排：
   - **河流阈值两档**：文件名带 `_rivers_compare`；
   - **无扰动 / 有扰动**：只关掉第 6 条的扰动，其余照常，命令行给开关，例如 `--no-jitter`；文件名带 `_jitter_compare`；
   - `--sample --check` 同时核对样区成品与两组对比的确定性。
5. **贴片来源**：
   - 填充贴片与边界笔触条读 ART-map-inkkit-tiles 的产物与 manifest；
   - 城镇、标记、山峰点缀读 inkkit / inkkit-full 的 manifest：品类取 ID 第三段；体量、走向、落脚点优先读 `kit` 字段，没有就按 alpha 包围盒自算；
   - 上游还没合入的品类，先用已合入的件跑通全流程；合入后用同一命令重出，代码不改；
   - 报告写明样区用了哪些件。
6. **测试**：
   - 确定性：同一输入输出 hash 一致；
   - 边界：笔触条沿路径首尾相接，拐角与接头无缝（采样接缝处 alpha 连续）；
   - 填充：平铺无缝，噪声确定；
   - 河流：阈值以下的支流不出现，两档阈值的输出确实不同；
   - 山川：山势图确定；山峰点缀只落在高山、雪山区；
   - 消融：城镇边缘的 alpha 由内向外单调递减；
   - 扰动：同种子同结果、换种子会变；各品类不越出范围；有朝向的不做垂直翻转；
   - 泊松盘最小间距；遮挡顺序按落脚点 y 单调；墨色叠加的结果不浅于任何一层；
   - 标记 JSON 的坐标与 design/map 经纬度投影一致；聚落和标记不压山峰点缀，标记之间留最小间距。
