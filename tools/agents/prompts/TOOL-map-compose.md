## 随机与融合（作者 AR-69）

作者原话：「地图看起来可以，python里增加一点随机和融合算法，让贴图更自然」。在上面的摆放规则之上加以下几层。全部用固定种子，同一输入输出逐像素一致。

1. **扰动**：每件贴图的缩放、旋转、翻转、墨色深浅，按固定种子随机扰动。默认范围如下，可调，实际取值写进报告：
   - 有上下朝向的品类（山峰、山脉、雪山、丘陵、关隘、聚落、标记，近俯视散点透视）：缩放 ±15%，旋转 ±6°，只做水平翻转，墨色深浅 ±12%；
   - 没有朝向的品类（湖泊、海面、平原底纹）：缩放 ±25%，任意角度旋转，水平、垂直翻转都可，墨色深浅 ±15%；
   - 可点击标记：缩放扰动不超过 ±8%，位置不扰动，点击坐标与辨识度不受影响；
   - 变体轮换：同品类在一定半径内不连用同一件变体。
2. **分布**：按地形密度做泊松盘分布，密度越高最小间距越小。山脉沿脊线取样也用泊松盘去重叠。
3. **遮挡**：按前后遮挡排序。落脚点（manifest 的 `kit.anchor`）画布 y 小的先画，近处压远处。
4. **融合**：
   - 每件边缘羽化，不留硬边；
   - 墨色叠加：重叠处用乘法一类的混合，越叠越深，不互相覆盖；
   - 地形过渡用渐变蒙版：山地、丘陵、平原、水域交界按距离场渐变，不出现硬分界。
5. **收尾**：最后整体压一层纸纹与墨晕，避免拼贴感。纸纹程序生成、固定种子，不从基线裁取。
6. **对比**：样区报告附同一区域「无扰动 / 有扰动」两版对比。
   - 无扰动版只关掉第 1 条的扰动，布点、遮挡、融合、纸纹照常；
   - 命令行给开关，例如 `--no-jitter`；
   - 对比图放 `assets/default/map/composed/sample/`，文件名带 `_compare`，同一画幅左右并排，左无扰动、右有扰动；
   - `--sample --check` 同时核对两版的确定性与布点一致。
7. **变体来源**：
   - 贴图按 kit 的 manifest 取件：品类取 ID 第三段；体量、走向、落脚点优先读 `kit` 字段，没有就按 alpha 包围盒自算；
   - ART-map-inkkit-full（补齐变体）合入之前，样区先用已合入的 22 件小样跑通全流程；合入后用同一命令重出，代码不改；
   - 报告写明样区用了哪些件。
8. **测试**，在第 5 条之外再加：
   - 扰动：同种子同结果、换种子会变；各品类的扰动不越出上面的范围；有朝向的品类不做垂直翻转；
   - 泊松盘：任意两点间距不小于当地最小间距；
   - 遮挡：绘制顺序按落脚点 y 单调；
   - 融合：羽化与渐变蒙版取值在 0–1 之间、单调过渡；墨色叠加的结果不浅于任何一层；
   - 对比：「无扰动 / 有扰动」两版布点一致。
