# 本任务：绘制统一江湖大地图（水墨风格）——数据、投影、渲染脚本与说明文档

作者新增需求 AR-11（`docs/decisions/author-requirements.md`，优先级高于基准）：用一个代理进行地图绘制：**水墨风格**；包含金庸世界**所有相关城市、门派**（波斯门派放在地图外，可访问，但通过驿站 / 货船到达，不能访问途中城市）；**城市坐标与实际坐标对齐**，并符合城市历史变迁状态（位置、名称）。本文（及数据）是大地图几何、坐标、时代地名与图外节点的唯一归属；区域玩法归 `design/11`，UI 归 `design/14`。

## 产出（全部由你创建；数据文件用 YAML，若运行环境没有 PyYAML，则脚本内置一个只支持本项目所用子集的简易解析器，或改用 JSON 并在说明中写明）

1. `docs/design/map/cities.yaml`：全部相关城市（预计 120–200 座）。每城：`city_*` ID、现代名、经纬度（WGS84，精确到 0.01°）、所属大区（建议 `rg_*` 名，供 design/11 定稿）、按基准 §2 的 14 书界对应朝代（北宋 / 南宋·金·蒙古 / 元 / 明 / 清初 / 清中）的**时代名称**、行政地位（都城 / 路府州县 / 军镇 / 商埠 / 边关 / 未建或废弃）与**治所迁移**（写各时代坐标）、出现的书界、关联门派与营生场所类型、来源（史料 / 网页 + 访问日期）。
2. `docs/design/map/sects.yaml`：全部门派驻地与分舵（`sect_*` 以 `design/17` 为准；17 尚未写成时按各图鉴"本组门派一览"与 `rulings-v1.md` 分工表）：经纬度、所在城市 / 山、各时代状态引用 17 的开放矩阵；海外 / 域外据点（侠客岛、桃花岛、蛇岛、凌霄城、光明顶、白驼山、灵鹫宫、黑木崖等）在图内给坐标；**波斯明教总教**等真正的域外据点作为"图外节点"（`offmap_*`），列出你判断应为图外的全部节点（如波斯总教、罗刹国等）并说明。
3. `docs/design/map/routes.yaml`：官道 / 驿路、水路（长江、运河、海路）、驿站 `post_*`、货船码头 `port_*`、专线 `route_*`。图外节点只通过驿站或货船**专线**到达：专线只有两端，途中不经过、不可停靠任何城市；写时长、费用档位、开放书界。
4. `docs/design/map/regions.yaml`：大区草案（供 design/11 定稿）与海岸线 / 主要河流 / 山脉的**简化几何**（经纬度折线，用于渲染；写明数据来源与简化方法）。
5. `tools/map/render_map.py`（Python 3.9+，只用标准库 + 可选 PyYAML）：
   - **投影**：经纬度 → 图上坐标的公式（推荐 Albers 等积圆锥：标准纬线 25°N / 47°N，中央经线 105°E，原点 35°N；或说明选其他投影的理由），画布默认 4096 × 3072（可配置），范围覆盖 73°E–135°E、18°N–54°N（含西域、蒙古、东北、台湾、海南、吐蕃）；公式同时写进说明文档供游戏代码复用；
   - `--check`：校验数据（ID 唯一；经纬度在范围内；每城至少一个时代名称；图外节点只连专线且专线无中途点；门派驻地都有坐标或图外标记；路线端点存在；每座城市落在海岸线陆地一侧——用点在多边形内判定），失败打印问题并退出码 1；
   - `--render [--era chNN] [--out DIR]`：输出 SVG：底图（海岸、河流、山脉、纸纹）用**水墨风格**——SVG 滤镜（`feTurbulence` + `feDisplacementMap` 做纸纹与晕染、`feGaussianBlur` 做墨色渐淡）、深 / 中 / 淡三级墨色、留白、山脉用皴法感的短笔触、河流用飞白线；地名用竖排 / 书法感字体的回退方案（`font-family` 列表 + 说明）；叠加该时代的城市（按时代名称与地位分级符号）、门派、驿站 / 码头、专线与图外节点题签框、印章式图例与题跋；不带 `--era` 时输出底图 + 全部时代图层（每个时代一个 `<g id="era-chNN">`，可单独显示）；
   - 输出到 `docs/design/map/`：`jianghu-base.svg`、`jianghu-chNN.svg`（14 个）；单个文件 ≤ 2 MB，几何做简化；渲染必须确定性（同样输入同样输出）。
   - 先运行 `--check` 与 `--render` 确认无错，再把生成的 SVG 一并留在仓库。
6. `docs/design/19-world-map.md`：地图设计说明：范围与投影（公式、参数、比例尺）、风格规范（水墨：墨色分级、留白、题跋、印章式图例、字体回退）、图层与时代规则（AR-04：时代图层 = 该书界开放的城市与状态）、图外节点与专线规则（AR-11）、城市历史变迁表（摘要 30–50 城；全表在 YAML）、门派驻地表（摘要）、与 `design/11`（区域定稿）/ `14`（大地图 UI）/ `tech/02`（大地图只是世界层 / UI 资产，不是战斗地形）/ `tech/06`（资产分包）的接口、如何重新生成、数据校验规则与测试用例、本文新增术语与 ID（`city_` `offmap_` `post_` `port_` `route_`）、待决事项 / 依赖。

## 必读

## 硬约束

- 城市坐标是真实经纬度（不要凭印象取整到整数度）；同一城市治所迁移时写各时代坐标。
- 时代名称按史实：如 汴梁（北宋）/ 开封（元明清），临安（南宋）/ 杭州，中都（金）/ 大都（元）/ 北京（明清），兴庆（西夏）/ 宁夏（明清），大理，应天（明）/ 江宁（清），等等；不确定的标（待考）。
- 波斯明教总教等图外节点：画在地图外侧的题签框内，只有专线可达，专线途中不可停靠。
- 不改动其他文档；需要 11 / 14 / 17 / 图鉴同步的写入报告第 6 节。
