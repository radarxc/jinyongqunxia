## 作者要求（2026-10-02 晚，逐字）
> 开一个设计任务，结合已有的prompt，写短文，并且给出初步的属性投影。
> 武器 - 攻击（锋利程度），硬度（被格挡后是否会损坏），内力亲和（一般武器亲和为1，即不加成。特殊武器内力注入有特殊效果，按设定来）

> 鞋子 - 防御，身法
> 护腕 - 防御，格挡（硬度）
> 其他装备 - 吉运，防御，放毒，避毒
> 药品 - 补充内力 / 增加内力修为 / 增加根骨 / 治疗内伤（疏通经络） / 治疗外伤，依据物品描述设定
> 食品 - 补充体力 / 治疗内伤 / 治疗外伤

## 要做的事
1. 对范围内每一行物品：
   - 在该行新增「说明」列：60–120 字短文——来历（原著出处或原创来历，原著事实没把握标（待考），原创标（原创扩展））、用法 / 讲究、江湖传闻或持有者；语气统一为名录说明文，不写演员 / 游戏公司名。
   - 新增「属性投影」列：按 design/10 v2 的字段表与速查表填机器行（如 `atk=…; hardness=…; qiAffinity=100`），数值落在该品阶取值带内，并与「效果字段」列已有数值一致（如 `mainK` 与攻击的换算）；特殊武器的内力注入效果填 `qiEffect=<buff 或效果 ID>`，没有现成 ID 就写 `qiEffect=（原创扩展：一句话）` 交 design/06 登记。
   - 药品 / 食品的作用按物品描述定（补内力 / 修为 / 根骨 / 治内伤 / 治外伤 / 补体力），一件物品一般只取 1–2 项主效。
