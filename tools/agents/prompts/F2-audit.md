# 本任务：全局一致性审计与修正（TODO F2 收尾）

此时所有文档都已完成并审校，基准已更新到 v1.2。你是最后一道一致性关卡，可以修改 `docs/` 下的任何文档（以及 `tools/lint/`）。

## 要做的事

1. **ID 检查**：运行 `python tools/lint/check_ids.py`，逐项处理：
   - 未定义的引用：补定义，或改用已有 ID；
   - 重命名表中的旧 ID 残留：替换；
   - 拼写近似：确认后统一；
   - 套装成员与 `setTags` 不对称：修正。
   脚本本身有误报的，修正脚本（`tools/lint/**`）。
2. **冲突落实**：逐条核对 C01–C23 的裁定是否已在所有相关文档中落实。报告里给出核对表：冲突 / 文档 / 位置 / 状态。没落实的，直接改。
3. **基准同步**：核对基准 v1.2 变更记录中的每一条都已同步到下游（依据 A3 报告第 6 节）。
4. **数值链抽查**：03 锚点 → 04 模拟（运行 `python tools/balance/damage_sim.py --check`）→ 05 招式预算 → 09 战斗节奏 → 各书界文档的 Boss 数值；02 / 13 的等级上限与经验；10 的装备数值与 04。
5. **归属检查**：同一概念在非归属文档中被重新定义的，改为引用归属文档（基准 §18）。
6. **修改尺度**：以小改为主。需要大改（整节重写）的，列入报告"遗留问题"，不要动手。

## 输出

- 直接修改文档。
- 报告：各类问题的处理前后数量（再运行一次 `check_ids.py`，贴出前后对比）；C01–C23 核对表；遗留问题清单（按严重度排序，写明建议的处理方式）。

调度器会在你结束后运行 `python tools/lint/check_ids.py`，要求退出码为 0。
