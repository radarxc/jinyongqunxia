## 要做的事

1. **读材料**：
   - 本书书界的"图鉴缺口"表和首领配装表。
   - `tools/agents/reports/NB4a.md` 或 `NB4b.md` 的相关条目。
   - 可选参考：协调者保存的中断稿 `/Users/bytedance/Projects/jinyongqunxia/.agents/drafts/NXc1_partial.patch`、`NXc2_partial.patch`。这是原分组补录任务未合入的改动，含部分缺口映射与武学卡草稿。可以借用其中与本书相关的内容，但**只能改写进本书补录图鉴**，不得应用补丁、不得改门派图鉴。
2. **逐个处理缺口**，按优先级：阻断正式构建的画像 → 按地位下限兜底、没有真实主运的画像 → 其余。
   - **先复用**：在全部 `docs/design/catalog/skills-*.md` 中找本门或同来源已有的合适武学，找到就直接用。
   - **来源书界限制**：如果只是某武学的可得书界没有列入本书，且原著或门派传承有依据，不要改门派图鉴。在本书补录图鉴的"来源扩展登记"表中登记（`sk_*` / 需加入的书界 / 依据），配装里照用并标"（来源扩展待登记）"。NXfix 会统一落实。
   - **确实缺的**：在本书补录图鉴中写完整武学卡，按门派分小节。每张卡写明门派 / 来源归属，并写明与哪一册门派图鉴属于同一门派体系。
3. **补录图鉴的写法**：结构仿照现有图鉴（如 `skills-kangxi.md`），依次为：
   - 开头的归属 / 覆盖声明；
   - 文首"绝招显式路线索引"块；
   - 武学卡；
   - "外放候选审计表"；
   - 统计表；
   - "本文新增术语与 ID"。

   **武学卡的要求**：
   - **ID 与名称**：`sk_*`、`mv_*` 先 `grep -rn` 查重。原著名称写明出处；原著没有的标"（原创扩展）"，不冒充原著名称，不编造回目。
   - **品阶**：按使用者在 21 §11.9.1 的目标品阶、地位下限，以及本书上限定。
   - **绝招**：
     - 数量：天上 3、天中 2–3、天下 2、地上 2、地中 1–2、地下 1、玄上 1，其余 0。天中 / 地中按 `docs/decisions/ultimate-counts-tianzhong-dizhong.md` 的判据定。
     - 解锁层：7 / 9 / 10 重。
     - 资源：按 05 的绝招预算。
   - **路线**：天 / 地阶逐招写显式路线，只在文首索引块定义一次。按 21 §4.3.1–§4.3.4 的叙事规则写：出招方式决定终点穴，性质决定经脉族，门派决定核心经脉。须满足：
     - 21 的硬约束；
     - 同门互异（共享穴位 ≤50%，且不是轮换或逆序）；
     - **不得与任何已有路线完全相同**。
   - **内功**：写调息档案 `txp_*`，带 `outOfBattleScaleBp` 与内劲抵消档位。
   - **外放**：按 21 §4.4.1 与 05 的 `MoveDef` 外放字段逐招判定。写 `projection`、`projectionSpreadSteps`，外放路线须经过手部端点白名单。暗器实体、飞刀、弓弩、普通兵刃挥击不算外放。
   - **习得途径**：默认按门派正常途径（门派传授 / 职级 / 秘籍 / 奇遇），主角与其他人物都可学。个人独门功夫另写条件，并列为需作者确认。
4. **替换书界配装**：用复用或新增的 ID 替换本书首领配装表中的替补，去掉对应标注。
   - 按 21 §11.9 重算七项参数，顶尖人物不得低于地位下限。
   - 用 `tools/balance/boss_pacing.py` 重估逐单位轮数。超出 12–25 轮（精英 6–10 轮）的，按 §11.9.2 调血量 / 防御倍率，不压经脉。
   - 更新"图鉴缺口"表：已补的注明新 ID；跨书界待替换的，注明主书界；未能补的，写明原因。
5. **版本行**：书界版本行追加"首领武学补录与替补替换（{{date}}）"。只改相关段落，不删无关内容（调度器拒绝缩短 15% 以上）。
