## 要做的事

1. **攻击位置**（design/09 §5 或新 §5.11 + design/05 §4 MoveDef 字段）：`hitZone ∈ {body, hand, leg}` 绑定招式（擒拿类默认 hand、摔跤 / 腿法默认 leg、其余 body）；被击位置抗性 = f(力量, 韧性, 该位置经脉在途气量)，给整数公式与表。
2. **外放抵消**（design/04 伤害公式接入 + design/21 §4.8 改写）：定义"外放阈值"（经脉在途气量 ≥ 阈值 → 满足外放条件）；抵消规则：100% 抵消攻击的内劲、50% 抵消外劲；攻击公式：真气加成 − 被击者外放内劲，为负则按负值的 50% 抵消基础伤害；与既有护体内劲（AR-14f）的关系：**以本次 AR-19 为准合并为一套**，写迁移说明；提示事件「真气鼓荡震开攻击」（≥ 4 条轮换文案）。
3. **透劲入体与消化**（design/21 新 §4.10 或 design/09 新节，建模要细）：
   - 触发：玄级及以上内功的外放招，且攻击方内力 > 防守方内力（定义比较量：是当前内力值还是内功层级 × 产气，给唯一定义）；
   - 注入：量与速度 = 外放时的量与速度；注入点 = 命中位置对应的穴道；逆向沿经脉向丹田运行（方向、速度、每 tick 推进段数）；
   - 消化：消化比例 `digestRatio`（内功属性，一般 1:1，特殊可达 10:1，给几门示例：九阳 / 化功 / 北冥 / 幻阴指……标原创扩展）；防守方每 tick 可投入的内力与消化进度；未消化前该段经脉阻塞（路线不可用、运气中断）；
   - 丹田受损：逆向真气到达丹田前未消化完 → 丹田受损（伤害、产气下降、持续时间、治疗接口），分级；
   - 斗转星移类（`sk_douzhuanxingyi` 等，标签【建议】`reverseQi`）：不受干扰，按 1:2 引导为己用，经脉反向输出（变成一次反击 / 本回合可用气量）；但量超过可消化或经脉宽度不足时同样受伤（规则与阈值）。
   - 状态机与数据：注入实例列表（来源内功、量、速度、当前位置、剩余未消化量、消化比例）；与 Buff 系统的关系（阻塞 / 丹田受损作为 Buff 还是经脉实例状态，二选一写明）。
4. **打穴**：有 `acupointStrike` 效果的招式用内劲打穴；命中判定要求高准确度（公式）；效果：占据该穴位（穴位被占期间不可运气通过）、消化比例 = 透劲入体的 50%（即需两倍内力）、影响经过该穴的多条经脉；与 AR-14c 擒拿点穴 1–9 严重度的关系（合并或并列，写明）。
5. **负面效果**：中毒、岔气（运气中断 + 一段时间产气减半等）、经脉阻塞、丹田受损、内伤、眩晕、流血…… 给一张表（触发、数值、解除方式、与 Buff IR 的对应）；城镇打坐被攻击 → 岔气的触发写明。
6. **自动战斗**：基于模拟、不考虑站位、"一拳一眼"的回合制求解（双方按 CT 顺序出招、招式选择策略、运气策略、结束条件），与手动六角战旗共享结算公式；给算法伪码与确定性要求。
7. **战斗设置**：每场战斗的参战单位、阵营、胜负 / 结束条件、特殊规则（切磋 / 死斗 / 剧情战 / 守卫）按进入情况（遭遇、剧情节点、城镇打坐被袭）配置；给 `BattleSetup` 字段表（交 tech/04 schema）。
