# 本任务：撰写 `docs/design/15-meridians-and-acupoints.md`（冲穴、经脉与周天）

作者新增需求 AR-02、AR-03（`docs/decisions/author-requirements.md`，优先级高于基准）：增加冲穴系统。本文是该系统的唯一归属文档（基准 §18 由 A3 补登记）：穴道、经脉、通脉 / 小周天 / 大周天 / 十二经周流 / 九转、冲穴速率、加成与上限、失败与走火、与其他系统的接口、数据结构。

- 基准 §3（永久增益跨书界保留、压制）、§5（等级与修为）、§6（属性 ID 与上限）、§9（乘区）、§10（Buff 规则）、§12（ID 规范：本文新前缀 `mer_` 经脉、`ap_` 穴道、`zt_` 周天 / 转，先全仓库 grep 查重）。
- `design/03`（属性、派生公式、各属性加成上限、`mpNature`）、`design/04`（乘区与上限：穴道加成落在哪个乘区）、`design/05` §5（内功：品阶、层数、主运 / 辅运、阴阳相性、内功贡献预算）与 §10（走火入魔三级）、`design/06`（效果原语；穴道 / 周天加成用 06 的原语落地）、`design/13`（成长曲线、多周目与永久增益保留）、`design/12`（师父、打坐地点，若已写成）。

## 至少包含

1. **术语与结构**：十二正经 + 奇经八脉（20 条 `mer_*`：中医名称、走向、所属脏腑各一句话）；游戏用穴道子集（每脉 6–12 穴，合计 150–200 个 `ap_*`，用真实穴位名，标注所在经脉与冲穴顺序）；通脉、小周天（任督）、大周天（奇经八脉）、十二经周流、九转的定义与解锁顺序（先通脉，任督通为小周天，八脉通为大周天，其后九转）。
2. **冲穴规则**：内劲来源 = 主运内功（品阶 G、层数 L(n)、`mpMax`、阴阳相性、辅运贡献）→ 冲穴速率公式；每穴"关隘值"随经脉与穴序增长；冲穴消耗（内力 / 时间 / 打坐）；成功率与失败后果（内伤、走火入魔三级衔接 05 §10）；辅助手段（丹药 10、师父指点 12、天书之力 13、内功的"专精经脉"字段 `meridians:`）。
3. **加成**：每穴固定小加成表（用 03 的属性 ID；属性、抗性、恢复、技艺、轻功等），全部穴道加成合计的上限（与 03 / 04 的属性上限、乘区衔接，写明落在 Z 几）；通脉 combo 加成（每条经脉一个主题）；小周天、大周天、十二经周流的全局加成与被动；九转每一转的放大系数与新被动（第九转为上限）。全部数值给算式与核算表：Lv35 高武、Lv70 终局、低武压制下三档示例，并核对不破坏 04 的 TTK 节奏（引用 04 的表估算影响幅度）。
4. **与境界压制、书眠、多周目**：进度跨书界保留（基准 §3）；被压制时冲穴速率按显示等级折算；余韵期可否冲穴；多周目继承与天道劫下的限制。
5. **与其他系统接口**：03（属性上限、派生公式输入）、05（内功 `nature`、`meridians:` 字段定义）、06（用哪些效果原语表达穴道 / 周天加成，列出需要 06 收录的 `bf_ap_*` / `bf_zt_*` 及定义摘要）、13（把冲穴纳入每书界成长预算）、14（冲穴界面要点：经脉图、穴道选择、进度、周天动画）、12（打坐地点、师父）、tech/05（状态字段、确定性）。
6. **数据结构**：经脉、穴道、周天 / 转、玩家冲穴进度的 YAML 示例与 TS 类型；数据校验规则与测试用例（穴道总数、每脉穴数、加成上限、九转封顶、跨书界保留）。
7. 本文新增术语与 ID；待决事项 / 依赖（对基准的修改提案：§12 前缀、§18 归属、§3 永久增益条目、§6 若需新属性）。
