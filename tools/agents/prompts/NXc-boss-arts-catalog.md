# 本任务：补录首领所缺武学，按门派 / 来源归入图鉴 · {{group_name}}

作者的两条决定，原文照录：

> 专属武学：Boss 用替补武学的，要不要另开任务补专属武学 - 开
>
> 不一定一定是专属啊，比如灭绝师太，武学应该显然是峨眉派的武学，主角和其他人也有机会学

意思是：首领用的武学属于他的门派或来源，应当写进该门派所在的图鉴，主角与其他人物也可以按正常途径习得。只有无师承的个人独门功夫，才另写习得条件。

## 背景

NB1、NB2、NB4a、NB4b 修正首领配装时，缺合适武学的 Boss 暂用已有武学替补，标"（原创扩展配置）"或"（原创扩展配置·待补专属）"。十四部书界末尾都登记了"图鉴缺口"表，见 `docs/design/chapters/*.md`；对应报告为 `tools/agents/reports/NB1.md`、`NB2.md`、`NB4a.md`、`NB4b.md`。已知的缺口举例：

- **倚天**：金花婆婆的杖法 / 暗器，鹿杖客的杖法，鹤笔翁的双笔，成昆的内外功。
- **笑傲**：任我行的外功，东方不败的飞针。
- **侠客行**：丁氏家传武学，谢烟客的外功，侠客岛的非太玄内功。
- **碧血剑**：温家、金龙帮的内功。
- **鹿鼎**：郑氏 / 冯锡范的剑法，雅克萨的本土武艺。
- **白马**：瓦耳拉齐的指法，马家骏的暗器与内伤手法。
- **鸳鸯刀**：卓天雄的掌法。
- **飞狐**：凤天南的五虎刀，药王门的玄阶内功。

## 要做的事

1. **先复用，再补录**：汇总全部十四部书界的缺口并去重。对归属本组的每个缺口，先在所有图鉴中搜索本门或同来源已有的合适武学，例如峨眉派的剑法、内功。有合适的就只记下映射，不新增。
2. **确实缺的，补录完整武学卡**，写进该门派所在的小节。字段按 05，内容包括：
   - **ID**：`sk_*` 先 `grep -rn` 查重。
   - **名称**：原著有名称的用原著名称，写明出处。没有的用描述性名称，标"（原创扩展）"，不冒充原著名称，不编造回目。
   - **品阶**：按门派在本书界的地位，以及使用该武学的首领在 21 §11.9.1 的目标品阶定。
   - **其他属性**：性质、类别。
   - **招式**：写 `mv_*`，原著招名注明出处。
   - **绝招**：
     - 数量：天上 3，天中 2–3，天下 2，地上 2，地中 1–2，地下 1，玄上 1，其余 0。天中、地中按 `docs/decisions/ultimate-counts-tianzhong-dizhong.md` 的判据定。
     - 解锁层：7 / 9 / 10 重。
     - 资源：按 05 的绝招预算。
   - **路线**：天 / 地阶逐招显式写 `mfr_*` 路线，满足 21 的硬约束，同门路线互不相同。玄 / 黄阶按 21 引用模板。
   - **内功**：写调息档案 `txp_*`，带 `outOfBattleScaleBp` 与内劲抵消档位。
   - **习得途径**：默认按该门派的正常途径习得，主角与其他人物都可学。途径包括门派传授、职级、秘籍、奇遇，按 05 与本册的学习规则。只有无师承的个人独门功夫，才写特殊习得条件，并列为需作者确认。
   - **外放标记**：由后续任务 M5c 统一处理，本任务不必写。
3. **更新本册的统计表与"本文新增 ID"**，版本行追加"首领所缺武学补录（{{date}}）"。只增补与改写相关条目，不删无关内容，调度器拒绝缩短 15% 以上。

检查：下列命令必须通过；每次写入不超过约 150 行，逐门推进。
- `python3 tools/lint/check_ids.py --strict`
- `python3 -m unittest discover -s tools/lint -p "test_*.py"`
- `python3 tools/balance/damage_sim.py --check`
- `python3 tools/balance/meridian_flow_sim.py --check`
- `python3 tools/agents/check_undefined_in.py`，参数为本组各册，结果须为 0
