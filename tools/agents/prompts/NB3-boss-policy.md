# 本任务：统一首领 / Boss 配装口径（AR-15）并新增逐单位节奏估算

作者的规则（原文照录，不要改写；"来源西"应为"来源"）：

> 首领没写主运内功时，按照门派、来源西给配一两个符合级别的内功（以及两三个玄/黄级别的基础内功），boss需要有两到三个内功，以及几个安身立命的外功（拳法，剑法，刀法等）。

作者此前对经脉系统的决定（AR-14）："金庸里内力经脉强则无敌，这里要体现出来。"

## 现状：两组落地口径不一致，且节奏只按"标准对标准"复核

- **NB1（书界 01–07，已合入）**："符合本界级别"取主运品阶 ≥ G−1（G 为当界主力，01–07 依次 7 / 8 / 9 / 9 / 8 / 7 / 7），只认人物原著或本门的"合法链"。42 名主运不达标的行动者中，只有萧峰换了主运，其余 41 名保留原低阶主运、只登记为缺口。它还把 `effGrade` / `innerNature` 改为只取主运内功，因此下调了 NCh1 的旧值：萧峰 12→6、段延庆 11→6、裘千仞 10→5、玄冥二老与波斯三使 10→6、玉真子 9→5。
- **NB2（书界 08–14，已合入）**：按门派 / 来源配了符合级别的内功，缺专属武学时用已有 `sk_*` 替补并标"（原创扩展配置）"。例如鹿鼎（低武）的假太后、神龙舰队首领改用洪安通的 `sk_shenlongxinfa`（地上 9），`effGrade` 9。
- **21 §11.9 现行表**写的是 Boss 的 `effGrade/effLayer` = "首领表 / 9"，并不是"只取主运内功"。
- **节奏复核的盲区**：`damage_sim` / `meridian_flow_sim` 只算"标准对标准"模板，逐单位相对强度没有复核。NB1 监督代理用 21 的公式粗估，§11.9 的 Boss 默认参数（mp / 容量 13000、9 重、本界里程碑）本身就让 Boss 达到标准的 1.0–1.36 倍。02 / 03 / 05 / 06 的多名 Boss 因此会落到 25–31 轮，例如方证约 30.6、金轮约 29.3、欧阳锋约 28.9、岳不群约 28.1，超出 04 的 12–25 轮。

## 要做的事

1. **登记 AR-15**：在 `docs/decisions/author-requirements.md` 新增 AR-15。内容包括原文照录、解读与默认值、归属（21 §11.9 与各书界的首领表）、影响（03 / 09 / 18 / 各书界 / 图鉴缺口），并注明"待作者确认"的部分。
2. **在 21 §11.9 新增"首领配装口径"小节**，写成可执行的规则：
   - **"符合本界级别"的定义**：Boss 与精英的主运目标品阶各是多少，与 21 现行"首领表 / 9"、基准 §2 的书界等级带、本土品阶上限（低 / 中 / 高武）如何对应。说明"首领表"在哪里、怎么取值。原著顶尖人物（萧峰、段延庆、鸠摩智、五绝等）的经脉强度不得低于其地位，这是"内力经脉强则无敌"的直接要求。
   - **缺合适主运时的选取顺序**：原著所学 → 本门最高内功 → 同来源（师承 / 地域 / 势力 / 同书界同阵营）内功，标"（原创扩展配置）" → 通行图鉴中同品阶的内功，标"（原创扩展配置·待补专属）"并登记图鉴缺口。除非书界文档写明例外及理由（如剧情上的弱 Boss、傀儡、纯机关），Boss 不得低于目标品阶。
   - **七项参数的派生**：`effGrade` / `effLayer` / `innerNature` 取自主运内功还是首领表，二选一并说明理由；辅运内功是否参与计算。
   - **构建闸门**：每个 Boss 为 1 门主运 + 2 门玄 / 黄辅运内功（共 3 门），外功 3–5 门，其中至少 1–2 门符合本界级别。禁止静默回退为 `1/1/harmony`；纯机关与环境物豁免。精英至多小周天，保留各书界的"本界精英默认"锚点行。
   - **节奏杠杆**：逐单位相对强度偏高时，靠 Boss 的血量 / 防御倍率或阶段机制把轮数拉回 12–25（精英 6–10），**不靠压低经脉强度**。多人 Boss 按整场总血量或目标计轮数。给出按相对强度选倍率的公式或表。
3. **新建 `tools/balance/boss_pacing.py`**（不超过 400 行，只用标准库）：
   - **功能**：以当界标准玩家为对手，输入单位的七项参数与血量 / 防御倍率，估算轮数。优先 `import` 同目录的 `meridian_flow_sim.py` / `damage_sim.py` 中的函数，不复制公式；确实无法复用时在报告中说明。
   - **命令行**：支持直接传参，也支持读一个小 JSON 输入。
   - **`--check` 夹具至少包括**：
     - 标准对标准时等于模板轮数；
     - 一个 1.36 倍强度的 Boss 在不调倍率时超出 25 轮，按推荐倍率调整后落回窗口。
   - **文档**：在 21 §11.9 与 `tools/balance/README.md` 写明用法。
4. 21 的版本行与变更记录追加本条；只改相关段落，不删无关内容。

检查：`python3 tools/balance/damage_sim.py --check`、`python3 tools/balance/meridian_flow_sim.py --check`、`python3 tools/balance/boss_pacing.py --check` 必须通过；每次写入不超过约 150 行。
