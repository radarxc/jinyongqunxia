2. **资源点与占领**：资源点类型；分布原则与每书界数量预算（引用 11 的区域 / 城市，与 11 的预算表一致）；占领方式（战斗 / 任务 / 购买 / 门派授予）；产出公式（等级、家丁能力、投入）；被夺回、骚扰、维护成本；时代图层切换（书眠）时的归属重置；天书之力 / 成就可保留的部分。
3. **家丁**：招募途径、能力值（经营、武艺、忠诚……）、成长、指派与管理界面要点（14）、工资；家丁与队友的关系（不上场；给默认）。
4. **城市营生**：每城的场所类型（赌场、镖局、山庄；可扩展酒楼 / 武馆）；职位 行脚 / 教头 / 客卿 的门槛（等级、武学品阶、名望 / 品德检定）、职责（走镖任务链、教徒、护院、争斗）、报酬（按次 / 按月，与 12 经济曲线一致）；**客卿全局唯一**（同一时间只能在一家镖局或山庄任客卿；教头可多处但有日程冲突）；赌场玩法（小游戏规则、上限、出千检定、消息与地下任务）；声望与门派的联动。

7. **数据结构**：资源、资源点、家丁、营生场所、职位的 YAML 示例与 TS 类型；任务 DSL 的条件 / 动作扩展（交给 tech/05）；数据校验规则与测试用例。
