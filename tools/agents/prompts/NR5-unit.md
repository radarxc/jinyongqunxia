# 本任务：路线唯一性第五轮 · {{unit_name}}（显式普通路线纳入全仓比较后的完全相同与高相似配对）

## 背景

- **规则来源**：21 §4.3.4 与 Canon V17-06。不同武学的路线不得复用完全相同的有序穴位序列（第 2 条，构建失败）。两条路线穴位集合重合 `overlapBp=floor(10000×|A∩B|/min(|A|,|B|))≥8000` 时（第 3、4 条），要么改开，要么在图鉴评审说明中写明理由：
  - 共同门派 / 内功底子；
  - 为何必须共享该核心段；
  - 两招各自的动作末端或关键段。

  "同为阴 / 阳 / 调和"不构成理由，警告也不能用豁免表静默消除。
- **前几轮已做的**：NR1 / NR2 清掉了完全相同的绝招路线；NR3 把跨武学绝招路线的 ≥80% 配对清零；NR4 按 AR-18 让路线体段性质与武学性质一致。
- **本轮新增的范围**：检查脚本维护任务 LINT-outlets（f1c683e）把**显式写出的普通路线**也纳入了全仓比较（绝招 vs 普通、普通 vs 普通）。按 §17.5 绑定共享模板的普通路线天然相同，不在范围内（协调者 2026-09-29 裁定）。全仓实测：654 条绝招 + 207 条显式普通路线，4 对完全相同、182 对 ≥80%。查看命令：`python3 tools/agents/check_route_unique_for.py --all`（加 `--json` 出结构化结果，加 `--strict-normal` 时完全相同会报错）。
- LINT-outlets 同时修了出口识别（位移、内功 / 护体 / 蓄气的任督尾段、人声、拳法与持械出口），个别路线因此新出现性质冲突或动作端点命中，列在下面"本单元额外事项"里。

## 要做的事

1. **逐对处理名下的配对**：
   - **完全相同的配对必须改开**，不能写理由。
   - **优先改开**：替换本侧路线至少 `floor(0.2L)+1` 个穴位（`L` 为本侧路线长度），使 `overlapBp<8000`。一条路线同时出现在多对里时，选同时避开全部对方路线的穴位。替换后仍须满足以下全部要求：
     - 21 的硬约束（§4.6 / §17.1）；
     - §4.3.1 的动作末端规则，且出招方式与动作末端不变；
     - 不低于建议段数、不缩短；逐段 CT / 风险列与段数一致；
     - 同门互异（同一武学内共享 ≤50%，且不是轮换或逆序）；
     - 外放路线的端点仍在白名单内；
     - §2.4 路线体段性质与武学性质一致（AR-18 新口径：体段逐节点计票，出口段不计，冲脉 / 带脉默认不投票）；
     - 不与全仓任何路线完全相同，也不新造任何 ≥80% 配对。
   - **写理由**：只适用于确有共同传承的配对（同门派、同一内功底子，且卡片或原著能说明）。在本册新增或沿用小节"跨武学高相似路线说明（21 §4.3.4）"，每对一行，列出：本册路线 `mfr_*`、相似路线 `mfr_*`、overlapBp、共同门派 / 内功底子、为何必须共享该核心段、两招各自的动作末端或关键段。两个路线 ID 必须写在同一行里，校验脚本按行检查。
   - **10000 bp 的配对**（本侧穴位全部落在对方路线里）原则上改开；确属同一技法家族的，写足理由。
