F2 终审记为中等遗留：十四个书界"全部路线可习得池"的天 / 地 / 玄 / 黄占比均未命中目标。硬约束（F2 §4.1、基准 v1.3）：**不得新增天阶、不得增删武学 ID、不得排除互斥路线来缩小池**；只能调整来源书界、获取途径、路线互斥与前置闭包。`tools/lint/check_source_ratio.py`（L3）是唯一验收口径。

## 必读

- `docs/design/05-martial-arts-system.md` §14（全部）；`tools/agents/reports/L3.md`（口径、`unclassified` 样例、写法统一建议）。
- 11 册 `docs/design/catalog/skills-*.md`；`docs/design/02-timeline-and-world-tiers.md` §2.9（原生天级稀有度 R1–R7）、§5.7（跨书界可再遇表）；`docs/00-canon.md` §3（各境界原生天级数量区间：高武 6–16 / 中武 1–5 / 低武 0–2）、§13。
- `docs/design/chapters/NN-*.md` §9（各书界武学产出表）——本任务**不改** chapters，但重配后与 chapters 冲突的条目要在报告第 6 节逐条列出（给后续同步任务）。

## 要做的事

1. 先运行 `python3 tools/lint/check_source_ratio.py --json` 得到基线；把 `unclassified` 条目按 L3 建议统一写法归类（这是零成本的第一步）。
2. 按书界从偏差最大者开始调整：
   - 黄 / 玄过多的书界：把仅"顺路复现"的低阶通用武学改为"仅见闻"或缩到少数书界；补齐前置闭包（前置武学不可学则本武学不进池）。
   - 地阶不足的中 / 低武书界：把相应门派的地阶武学增加合理复现来源（须符合 02 §5.7 的门派存续与史实，标注**（原创扩展）**）。
   - 天阶：不动数量与品阶；只在 R1–R7 允许范围内调整**获取路线**与互斥，使单周目上限符合 02。
   每一处改动在图鉴条目内写明理由（一句话），保持表格列不变。
3. 每改完一册重跑脚本；最终 `--strict` 通过。若某书界在不违反硬约束的前提下确实无法命中，写清差距、原因与需要作者拍板的选项（例如放宽该书界目标区间），并把 05 §14.4 该行标为"（待作者确认）"而不是改目标数字。
4. 更新 `design/05` §14.4 的两张表为脚本输出（首现表与可习得池表），§14.7 现状核对同步。
