## 背景（协调者 2026-10-09 在 5173 真实运行时实测）
D1 合入主干后，在真实运行时（`MeshBasicMaterial` 单面渲染、UV 遮罩按红通道 > 0.5 discard）里看到四个离线软光栅没有暴露的问题：
1. **颈桥三角朝里**：1,152 个桥三角中 874 个法向朝颈轴；近侧半圈被背面剔除，颈前出现黑色椭圆缝。
2. **头切口没缝严**：桥顶只在 64 个锚点处与头相接，128 个缝合三角全是零面积；锚点之间的锯齿边界与弦之间留有小洞，下巴下方可见碎三角和一块大三角片。
3. **颜色断层**：桥色 = 源头上沿逐列色 + 单一模板平均色，底边与身体之间有明显色阶（作者所说"多了一圈"的主要观感），列间有竖条纹。
4. **底缝细线**：遮罩边界与桥底之间有 1–2 px 断续细缝。

作者要求（2026-10-09）：「再好好迭代一下，写一个渲染截图的工具，快速修改 + 验证。要对着截图验证。思考数值拟合算法，最终形成一个头部拼接的标准工具。」

## 要做的事

2. **头颈拼接标准算法**（`cut_head.py`，命令行与产物接口不变）：
   - **精确裁头**：按切面把源头三角裁开，插值位置、UV 与权重，切口为平滑闭合曲线，不再整三角选取。
   - **模板颈片**：复制模板身体颈根到终止面之间的三角，保留拓扑、权重与原 UV 来源。用双调和位移场（余切拉普拉斯，`L M⁻¹ L d = 0`）变形：底带位移为 0（与身体 G1，且与身体重叠），顶带对齐头表面并略内缩于头皮下（与头 G1，且与头重叠）。
   - **贴图**：颈片重烘到头图集底部的柱面 UV 条带，逐纹素按模板原 UV 采样身体贴图 × `skinTint`（与运行时身体着色一致），向上渐变到头切口处逐角度的头色。两端颜色连续，无竖条纹。
   - **朝向与拓扑**：全部三角统一朝外；新增边一致性与外法向检查；头 ∪ 颈片除预期开口外无洞。
   - **遮罩**：只隐藏重叠带中线以上的颈与模板头（有符号高度场，沿用 D1 的完整性校验口径）。
3. **门禁与测试**：
   - 旧门槛不放宽。新增：朝向一致率 100%、两端接缝色差 ΔE2000 < 2、重叠带宽度与内外偏移、颈片双调和残差、G1 夹角。
   - 合成回归覆盖：裁切插值、双调和带约束求解、朝向、条带贴图两端连续。
   - 测试只写临时目录。
4. **重新生成黄蓉头**；用 `shoot_head.mjs` 出修改前 / 后的对照总图，逐张目检（正 / 侧 / 背 / 仰视 × bind / idle / walk / run）。

## 协调者裁定（2026-10-09 实现中，依据运行时截图与实测）
1. **头资产的 holes 只报不判**：validate 的 holes 判据（被遮罩隐藏、视线上无其他几何的身体片元）是为衣物设计的，前提是"被藏的身体都要被盖住"。头资产按设计用更细的源颈 / 源头替换模板颈头，侧视轮廓在喉部收窄处也会被计入，与真破洞无法区分。真破洞改由以下各项把关：
   - 朝向一致 100%；
   - 底带外移在 73 帧里保持 ≥ −0.05 mm；
   - 顶带在头皮下；
   - **遮罩外渗为 0**：颈片范围外的身体三角不得有顶点被隐藏；
   - 运行时截图。
2. **两端色差在最终 GLB 内的图集上量**：
   - 顶缝：A 区逐 1°，切口上下各 0.25–1.25 mm 的均色；
   - 底缝：底带顶点 vs 模板贴图 × skinTint；
   - 两者都要求 p95 < 2。
   - 图集只编码一次 JPEG，且用 4:4:4 色度。实测 transform 的二次转码和 4:2:0 会把发际线附近的头皮色度带偏 ΔE 2–4。
3. **重叠带两层共用同一权重场** W(θ,h)：
   - W 从切口处模板权重的逐角均值平滑过渡到 Head；
   - 颈片在 G1 裙带里由自身权重渐变进这个场。
   - 实测两层各用各的权重时，动作帧外露 4–18 mm。
4. **喉部内凹只报**：颈片半径剖面的外凸鼓圈（高于两端，即作者说的"多一圈"）< 1 mm 是门禁；下巴下方的内凹是正常的颏颈角，只报告。
5. **重叠带外露的口径（审核 r1 第 3 条落地）**：
   - 重叠带 = 切口以上 0.5 mm 到 TOP_BAND、bind 时最近头皮面在 1 mm 内的颈片点（几何定义，生产与测试同一口径）；
   - 外露只对**皮肤面**量。动作中发片甩进颈部属于垂发穿插，按既有规则只报。实测 222° 处的"外露"即发片三角扫过颈片。
   - 门禁：bind + idle / walk / run 各 24 帧，共 73 帧逐帧最大外露 ≤ 0.1 mm，且 bind 时整带在皮下 ≥ 0.25 mm。
6. **发际线过渡列只报**：
   - 顶缝 G1、外凸鼓包、顶缝色差只在 A 区内部门禁（离任一无头皮角 ≥ 12°）。
   - A/B 交界 12° 内的列全部写进报告，只报不判。
   - 理由：源头皮在发际线边缘自身卷曲（实测 229° 处切口上方以 −32° 向内收，邻列为 −18°），且源颈比模板宽约 6 mm。在这些列上"两端 G1"和"不外凸"在几何上不能同时满足，所以工具在切口处保持斜率，向下的外扩量做饱和处理。
