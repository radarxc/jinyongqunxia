# 本任务：设计补充 · 属性与数值体系 v2：八项先天属性、沉睡配点、速度与攻击公式、门槛与平衡（AR-27）

## 作者要求

逐字原文与作者对追问的回答见 `docs/decisions/author-requirements.md` 的 **AR-27**；相关背景（沉睡配点发生在书眠中、武功的点数门槛要重新平衡）见 **AR-26**。两条都必须先通读，事实优先级高于基准。要点：

1. **先天属性**：
   - 现有七项不变：根骨 `con`、臂力 `str`、身法 `agi`、悟性 `wis`、定力 `wil`、福缘 `luk`、魅力 `cha`，另新增**内息**，共八项。
   - 作者原列的反应、柔韧、平衡并入身法。
2. **沉睡配点**：
   - 配点项为臂力、根骨、内息、悟性、身法、定力六项；
   - 福缘、魅力保留为基础属性，默认不配点，靠奇遇、事件、装束改变（待作者确认）。
3. **速度** = 身法 × 轻功系数；轻功系数 = 轻功基本系数 × 对应经脉强度带来的增幅。轻功修炼升级本身也提升身法。
4. **攻击** = 臂力 × 武功硬功 + 武功外放 × 对应经脉运转算出的系数。武功修炼可以提高这个比例，也可以加根骨、定力、身法等，每门武功按源流和小说描写配不同值。
5. **伤害**沿用现有口径：硬功防御看根骨，另有内劲抵抗机制；武功、内功可以加根骨（如金钟罩内功、横练类外功）。
6. **门槛与平衡**：不同武功对属性有不同点数要求，要重新平衡，设计一套合理、平衡的数值体系。

## 要做的事

### 1. `docs/design/03-attributes.md`
- **内息**：
  - 新增为第八项先天属性。ID 用三字母小写英文，与现有一致，先全仓搜索查重，写明含义。
  - 八项逐项重写总表行：含义、范围、来源、影响的系统、UI。
  - 写明身法吸收了反应、柔韧、平衡的含义；定力和内息怎么分工（例如内息管内力容量、回复与内劲，定力管心志、抗性与走火入魔），用表列出每个二级属性改由谁驱动。
- **沉睡配点**（替代或衔接 §2.4 创角点数，写明创角还剩什么）：
  - 每次沉睡得多少点，写成书序与等级的函数；
  - 初眠（长白山）一次性的初始预算；
  - 单项上限，以及永久 1–100、突破至 120 的规则是否保留；
  - 未分配点数可以留存。
- **速度**：按作者公式重写 §4.3 / §4.5，定义：
  - 轻功基本系数（来自所修轻功的品阶与层数）；
  - 经脉强度增幅（来自 design/21，见第 5 项）；
  - 轻功修炼升级给身法的加成（每层多少、上限）。
  给早、中、后期三个核算例。
- **攻击**：按作者公式重写 §4.1：
  - 「武功硬功」「武功外放」各是武功上的什么字段：与 `wOut` / `wIn` 对接，或新增字段并说明迁移；
  - 「经脉运转系数」来自 design/21；
  - 与 `atkOut` 等二级属性是替换还是映射，要写清楚。
- **防御**：硬功防御（根骨）与内劲抵抗分别由哪些属性和武功驱动。
- **修炼加成**：武功、内功修炼到各层时给属性的加成，例如金钟罩、横练加根骨，轻功加身法。写明：
  - 字段名；
  - 每层加成；
  - 单门上限与总上限；
  - 按武学源流、小说描写配值的规则。
- **熟练度与真元**（AR-26 遗忘 / 散功转化的承接对象）：
  - 「熟练度（武功经验）」按兵器、拳掌等类别计。与现有资质 `ap*` 怎么处理（合并、改名或并存）给出方案，并写迁移；
  - 「真元（内功经验）」的定义和用途；
  - 本文只定义资源本身和怎么用；60% 转化算式由并行任务 `DES-changsheng-core` 写在 design/13。
- **平衡**：
  - 配点预算；
  - 各书界的属性期望值曲线（白马 → 雪山，按 AR-26 的新书序）；
  - 悟性满值：在鹿鼎记之前能达到，但要重投入，给出期望路线和最晚书界；
  - 修炼加成封顶，防止全属性满。
  用表格和算式写，不凭空给数。
