## 背景

作者把城镇图改为程序化生成：城市规格 → 生成布局 → 用贴片渲染底图 → 按坐标贴建筑单体。设计文档、数据格式与清单已定稿：`docs/design/22-town-layout-and-generation.md`（§2 网格与画幅、§4 功能建筑清单、§5 贴片清单、§8 渲染规则）与 `docs/design/town/schema.yaml`。本任务按清单出图，素材会被 `tools/town/render_town.py` 直接拼接，所以规格必须严格：

- 视角：斜 45°、俯仰 30°、2:1 投影（`docs/tech/02-rendering.md` §1.1–§1.3），与 design/22 §2 的像素规格一致（默认每格 64×32 px 的菱形）。
- 光源：统一从画面左上方来，阴影向右下；所有素材一致。
- 风格：`assets/default/STYLE.md` 城镇 / 建筑行（写实古风、按年代）；与已通过的建筑基线（`assets/default/baseline/building/`）气质一致。
- 无文字、水印、现代元素。

## 要做的事

1. **读资料**：design/22 全文、schema.yaml、STYLE.md、`assets/README.md`、tech/07 §1.4 / §2 / §5.5.2；本类涉及的年代与城市资料按 design/22 §3 与 §9 的引用去查。
2. **生成**：用内置 `image_gen` 逐张出图；每张先 `view_image` 自查（视角、光源、透明底、边缘干净、尺寸比例），不合格重出。可以把已通过的建筑基线或本批已合格的一张载入作风格参考，用了就登记进 `references`。透明底素材必须是真 RGBA（用 PIL 实测 alpha 通道，不能是假透明），主体四周留够空白，不贴边、不裁切。
3. **规格化**：出图后按 design/22 的像素规格裁切 / 缩放到规定尺寸（允许用 PIL 做纯几何处理：裁切、等比缩放、透明底修边；不允许重绘内容）。处理前后的原图路径与处理步骤都登记。
4. **入库**：文件放 `{{out_dir}}/`，文件名为 ID 加 `.png`；ID 按 design/22 清单与 tech/07 §1.4。`{{out_dir}}/manifest.yaml` 顶层为列表，每张一条，字段见 `assets/README.md`，另加本类需要的元数据（见上面"具体要求"）；`status: candidate`。
5. **提示词模板**：写 `{{prompt_file}}`，含风格关键词、视角与像素规格、年代要点、排除项、占位符、参考图用法、质检要点、几何后处理步骤。
