# 本任务：撰写 `docs/design/21-meridian-flow-and-moves.md`（经脉运行、招式路线、绝招与擒拿点穴 · 作者需求 AR-14）

作者在本轮提出了新的需求（原文照录，不要改写）：

> 增加擒拿（外功，1到9，1是酸软，9是无法动弹），点穴（内功，1到9，1是气息受阻，9是经脉迟滞无法运气）。
>
> 深化经脉概念，并对武功增加大招招式概念（想一个比较符合武侠文化的名称，绝招？），招式从金庸武侠小说列举和现实著名招数（如形意拳的半步崩拳）获取，高等级武功有多个招式，每个招式对应一段经脉运行，计算招式伤害时，以所用到经脉的强度（气的大小和流畅程度）计算运行长度越长招式加成最大值越大，但每一段的时间会增加，同时如果不熟练，在某一个经脉卡住后会减少威力，甚至会损伤经脉（以河流为模型，每一个经脉点增加水量，但如果经脉点迟滞，则会堆积，甚至胀坏，胀坏后暂时无法通过，需要调息）。经脉在普通攻击中，也会增加攻击力，但路径较短。点穴会影响某个经脉穴位，导致对方武功内力循环受影响甚至无法使用。内功增加调息功能，调息可以将迟滞的经脉理顺打通，不同内功调息能力不同。

作者需求与作者决定同级，高于基准（`_common.md` 规则 1）。本文是以下概念的**唯一归属**（基准 §18 的登记以提案形式提出）：战斗中的经脉运行状态（气量、流畅度、迟滞、胀损）、招式的经脉路线与路线加成、大招（名称由你论证选定）、擒拿与点穴的 1–9 级、调息。`design/15` 仍是经脉 / 穴位定义与冲穴、周天（战斗外修炼）的唯一归属——本文只引用它的 20 脉 / 180 穴与开通状态，不重定义。
