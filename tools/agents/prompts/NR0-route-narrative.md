# 本任务：绝招路线的叙事规则与跨武学多样性检查（design/21 + `tools/lint/`）

作者需求 AR-14 的原意（原文节选）："高等级武功有多个招式，每个招式对应一段经脉运行"。

现状：
- 11 册武学图鉴的绝招路线满足 21 的硬约束与"同门互异"（同一门武学的多个绝招共享穴位 ≤50%、无轮换 / 逆序）。
- 但**不同武学之间大量共用同一条穴位序列**。NU5a 统计：少林 / 道家 / 通行 / 五绝 / 逍遥 / 倚天 6 册共 349 条绝招路线，只有 187 种序列；其中一条 8 穴序列被 33 门武学的绝招共用。另五册也有同类情况，例如 `mfr_taixuan_shibu` 与 `mfr_shenxing_taxi` 9/10 穴位相同。
- 来源：NA2 用脚本按阴 / 阳 / 调和穴位池批量生成路线，早期任务也套用过共享模板。
- 后果：点穴、堵塞、胀损对大批不相干的武学表现完全一样，违背"每个招式对应一段经脉运行"的本意。

本任务先定规则与检查，后续 NR1 / NR2 按规则逐组改图鉴。本任务不改图鉴。

## 要做的事

1. **在 21 中写"绝招路线的叙事规则"**（放在路线相关章节，写成可执行的规则），内容包括：
   - **出招方式 → 终点 / 关键穴位**：掌（如劳宫）、指（如商阳、少商、中冲）、拳、腿（足三阳）、剑 / 刀等兵器（手三阳）、轻功 / 位移（足少阳、带脉、涌泉等）、内功 / 护体（任督、丹田）。穴位以 `design/15` 登记为准，外放招式还要满足 21 §4.4.1.4 的 13 个手部端点白名单。
   - **性质 → 经脉族**：阴、阳、调和各偏向哪些经脉。
   - **门派内功底子 → 核心经脉**：少林、全真 / 武当 / 道家、逍遥、丐帮、峨眉、明教等各给默认，其余按性质回退。
   - **同一武学的多个绝招**：各有职责（破阵、清场、反击、位移），路线体现职责差异。
   - **跨武学多样性**：
     - 不同武学的绝招路线不得完全相同。
     - 与其他武学的绝招路线共享穴位 ≥80% 的，报警告并给出理由要求。
     - 同门派的不同武学可以共享核心经脉段，但终点或关键段应体现各自的出招方式。
2. **检查脚本**：在 `tools/lint/check_skill_catalogs.py` 增加跨武学多样性检查。
   - 用新开关 `--diversity`（只报告）与 `--diversity-strict`（完全相同的序列计入失败，≥80% 的给警告），**不改变现有 `--strict` 的行为**。后续图鉴任务在修完之前仍能过 `--strict`。
   - 补测试。
   - 同步 `tools/lint/README.md`。
3. **报告当前主分支的数据**：按册给出绝招路线数、不同序列数、完全相同的序列组（每组的武学数与涉及的路线 ID）、≥80% 相似的对数。这些供 NR1 / NR2 使用。
4. 21 的版本行 / 变更记录追加本条；只改相关段落，不删无关内容。

检查：以下命令必须通过。
- `python3 -m unittest discover -s tools/lint -p "test_*.py"`
- `python3 tools/lint/check_ids.py --strict`
- `python3 tools/lint/check_skill_catalogs.py --strict`（现有规则，当前应为 0）
- `python3 tools/balance/meridian_flow_sim.py --check`

每次写入不超过约 150 行。
