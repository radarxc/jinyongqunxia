# 本任务：设计补充 · 物品设定按 AR-20 扩充（十一类，天地玄黄分级，年限分级），出机器可读名录供批量出图

本任务改策划文档并新建物品名录，不出图（出图由后续 ART-item-* 任务按本名录批量做）。"只改负责的文件""不执行改变仓库状态的 git 命令""不要停下来提问""报告如实"照常适用。

## 作者要求

`docs/decisions/author-requirements.md` **AR-20**（逐字原话）：对以下物品补充设定并分别生成图——药物、补品、药材、食材、食品；武学秘籍；兵器；衣物；制式盔甲（非官府穿着会被通缉，无法正常进入城市）；内甲（软猬甲等）；护肩、披风、头饰；鞋；腰带；暗器。按小说著名物品列举，药物结合金庸、古龙和其他武侠小说，提供补血、补气、提升能力、提升内力、复活等功能；分别生成天地玄黄等级对应物品；药材可按年限定等级（千年人参、百年人参、十年人参、普通人参等）。

## 要做的事

1. **设定补充**（design/10 在对应章节新增 / 改写）：
   - 十一类各自的子类、品阶（天 / 地 / 玄 / 黄）与数值位（补血 / 补气 / 临时属性 / 永久属性 / 内力 / 复活 / 解毒 / 疗伤 / 经脉穴位强化（接 DES-qi 的接口）），药材按年限分级规则（普通 / 十年 / 百年 / 千年 → 黄 / 玄 / 地 / 天）；
   - 制式盔甲：官府制式，非官府身份穿着 → 通缉状态、无法正常进城（与 design/11 / 12 的身份与通缉接口），给字段；内甲（软猬甲、金丝甲…）的防御与特殊效果；护肩 / 披风 / 头饰 / 鞋 / 腰带的装备栏与数值位（design/10 §3 装备栏若无对应槽位则新增并写迁移）；暗器的类型与命中 / 毒接口；秘籍与 design/10 §10 残页规则的衔接；食材 / 食品与 §9 烹饪的衔接。
2. **名录**（新建 11 份，文件名固定：`docs/design/catalog/items-medicine.md`（药物 / 补品 / 药材）、`items-food.md`（食材 / 食品）、`items-manuals.md`（武学秘籍）、`items-weapons.md`（兵器）、`items-clothing.md`（衣物）、`items-armor.md`（制式盔甲）、`items-innerarmor.md`（内甲）、`items-accessories.md`（护肩 / 披风 / 头饰）、`items-shoes.md`（鞋）、`items-belts.md`（腰带）、`items-hidden-weapons.md`（暗器）；机器行格式与武学图鉴一致：每行一个物品：`| \`it_…\` / \`eq_…\` | 名称 | 子类 | 品阶 | 出处（书名 / 原创扩展） | 效果字段 | 外观要点（供出图） |`）：
   - 按小说著名物品列举：金庸全集为主（如 九花玉露丸、天香断续胶、黑玉断续膏、无常丹、豹胎易筋丸、生生造化丹、断肠草、茯苓首乌丸、雪参玉蟾丸、千年雪参、通犀地龙丸、玉龙苏合散、黑血神针、冰魄银针、含沙射影、倚天剑、屠龙刀、玄铁重剑、金蛇剑、软猬甲、金丝背心、乌蚕衣、烈火旗…），古龙与其他武侠（孔雀翎、碧玉刀、小李飞刀、离别钩、霸王枪…标出处），不足处原创扩展并标注；
   - 每类按天 / 地 / 玄 / 黄各档至少：药物 / 补品 / 药材各 8 档样本（含年限分级示例）、食材 / 食品 12、秘籍引用图鉴已有 `it_miji_*`（只补遗漏）、兵器 24、衣物 12、制式盔甲 6（按年代：宋 / 元 / 明 / 清）、内甲 6、护肩 / 披风 / 头饰 12、鞋 6、腰带 6、暗器 12；
   - 外观要点一栏要能直接给出图用（材质、形制、颜色、时代感、尺寸感）。
3. **ID 注册**：按 tech/04 §2.5 把新 ID 写入注册表（或在报告列出待注册清单，若注册表是生成物）；`python3 tools/lint/check_ids.py --strict` 通过。
4. 在 `assets/default/prompts/item.md` 加"按名录批量出图"一节：每类的提示词骨架（沿用基线物品图画风：细墨线薄罩染、四边留白 ≥ 10%、无文字）、品阶与年限如何体现在画面上（光泽 / 包装 / 年份痕迹）。

约束：每次写入 ≤ 150 行；不改武学图鉴；原创扩展一律标注。

检查：以下命令必须全部通过。
- `python3 tools/lint/check_ids.py --strict`
- `python3 tools/agents/check_item_catalog.py docs/design/catalog`（若无此脚本，本任务顺手写一个：核对每行 ID 唯一、前缀合规、品阶 ∈ 天地玄黄、出处非空；放 `tools/agents/`）
