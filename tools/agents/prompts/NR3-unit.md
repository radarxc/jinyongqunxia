# 本任务：路线叙事第三轮 · {{unit_name}}（跨武学高相似路线与动作末端规则）

## 背景

- **规则来源**：21 §4.3.4 与 Canon V17-06。不同武学的绝招路线不得复用完全相同的有序穴位序列。两条路线穴位集合重合 `overlapBp=floor(10000×|A∩B|/min(|A|,|B|))≥8000` 时，要么改开，要么在图鉴评审说明中写明理由：
  - 共同门派 / 内功底子；
  - 为何必须共享该核心段；
  - 两招各自的动作末端或关键段。

  "同为阴 / 阳 / 调和"不构成理由，警告也不能用豁免表静默消除。
- **前几轮已做的**：
  - NR1 / NR2 清掉了完全相同的路线。
  - 各门派收尾任务 `NXfix-<册>` 与补录收尾 NXfixC 修了掌、指、腿、兵器、攻击内功、外放的末端规则，但留下约 360 对 ≥80% 相似未处理。
- **新增检查**（均为只报告，在 `--delivery` 中）：NAu-nxt 补了拳 / 擒拿末端、位移步法核心脉、护体 / 蓄气任督、非绝招外放路线、路线性质与武学性质冲突（21 §2.4）。

## 要做的事

1. **逐对处理名下的相似配对**：
   - **优先改开**：替换本侧路线至少 `floor(0.2L)+1` 个穴位（`L` 为路线长度），使 `overlapBp<8000`。替换后仍须满足以下全部要求：
     - 21 的硬约束（§4.6 / §17.1）；
     - §4.3.1 的动作末端规则，且出招方式不变；
     - 不低于建议段数、不缩短；
     - 逐段 CT / 风险列与段数一致；
     - 同门互异：共享 ≤50%，且不是轮换或逆序；
     - 外放端点白名单；
     - §2.4 路线性质与武学性质一致；
     - 不与全仓任何路线完全相同，也不新造任何 ≥80% 配对。
   - **写理由**：只适用于确有共同传承的配对，即同门派、同一内功底子，且卡片或原著能说明。在本册新增或沿用小节"跨武学高相似路线说明（21 §4.3.4）"，每对一行，列出：
     - 本册路线 `mfr_*`
     - 相似路线 `mfr_*`
     - overlapBp
     - 共同门派 / 内功底子
     - 为何必须共享该核心段
     - 两招各自的动作末端或关键段

     两个路线 ID 必须写在同一行里，校验脚本按行检查。
   - **10000 bp 的配对**（穴位集合相同、只是顺序不同）原则上必须改开；确属同一技法家族的，写足理由。
2. **新增末端规则**：跑 `python3 tools/lint/check_skill_catalogs.py --delivery --details` 加本任务图鉴路径，逐条修正本单元的全部命中：

   - 位移：含 `mer_zushaoyang` / `mer_daimai` / `mer_yangqiao` 之一或涌泉。
   - 护体 / 蓄气：含任督。
   - 非绝招外放路线：落合法端点。
   - 性质冲突：调整节点使路线性质与武学一致；卡片确要逆性质的，显式写 `allowOpposedNature:true` 并说明理由。

   不能靠改掉出招方式来规避检查。无法可靠分类的不硬套。
